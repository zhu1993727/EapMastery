## 二、背景知识（先读，40 分钟）

### 1. 下载 ≠ 选择
- S7 下载（Day02）只是把配方体存进设备本地；设备可能存几十个 PPID，真正加工用哪一个要再"选择（select）"。下载是仓储动作，选择是生产动作，二者分开才能灵活又受控。

### 2. PP-Select 远程命令
- 通过 GEM S2F41 远程命令：RCMD=PP-SELECT（厂商命名可能为 SELECT_PPG/PP_SELECT），CP 参数携带 PPID、版本（必要时腔号/工艺层）；设备 S2F42 回 ACKC10（0=受理）。
- 沿用 GEM 铁律：S2F42=0 只是受理，真正选中以设备状态变量"当前 PPID/版本"更新并经事件/回读确认为准。

### 3. 选择前置门控（核心，缺一不可）
1. 控制模式：Remote（非 Local 操作员模式、非 Offline）。
2. 设备/腔状态：Idle 或安全片间点，未在加工（加工中禁止换配方）、无未完成作业冲突。
3. 一致性：目标 PPID/版本已下载且 Day03 一致性校验通过（本地==golden），未通过先重下。
4. 工单匹配：所选 PPID/版本与 MES 当前工单/Lot/工艺路线要求一致（防跑错产品配方）。
5. 控制状态：无 Hold/严重 Alarm 联锁、安全条件满足。
- 任一不满足拒绝选择并回明确原因（复用 ACKC/自定义原因码），不允许"先选了再说"。

### 4. 生效确认与回读
- 选择后回读当前配方状态变量（Current PPID / PP Version，必要时每腔一个），与请求值比对一致→Selected/生效；不一致→选择失败、保持原配方、告警。
- 选择成功通常伴随状态事件（S6F11，如 PP Selected/Recipe Ready），作为作业可启动的前置事件之一。

### 5. 与作业启动、多腔的关系
- 顺序：选配方（并确认）→ 资源/作业就绪（E40 PJ/E94 CJ，W16-23）→ 收到启动命令才加工；配方未确认 Selected 不得 Start（门控链：配方→作业→物理片）。
- 多腔设备每个腔可能选不同/相同配方，按腔分别选择与回读，互不影响（与 W31 每腔独立一致）。
- 加工中收到选择请求：拒绝（保证 run 内配方稳定，同 overlay 只在安全点下发）。

### 6. 异常处理
- 选择失败/超时：保持原安全状态、幂等重试（同 PPID+版本重复选择结果一致），多次失败上报；不臆测已选中。
- 版本不符/本地缺失：触发自动下载（Day02）+校验（Day03）后再选，形成"缺则下、下则校、校则选、选则认"闭环。
