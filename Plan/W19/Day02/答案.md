# W19 · Day02 答案与参考实现

## 一、自测题标准答案
1. **为何不能逐盒守恒 / 正确口径**：逐盒守恒要求"每个载具加工前后片数/片集合不变"，但合批把多个源盒的片并入一个目标、拆批/分档把一个源盒拆到多个目标，单个盒的片数必然变化，逐盒比对一定"对不上"而误报。正确口径是**全局片 ID 集合守恒**：加工前把所有源载具的片 ID 取并集 S_before，加工后把所有目标载具与设备内残留的片 ID 取并集 S_after，要求两个集合完全相等（同基数、同 ID、无新增无丢失无错 ID），不关心片最终落在哪个盒。跨盒搬运（W15）已建立此口径，合/拆/分档是其一般化。
2. **MergeSplitAuthorized / 风险**：它是 Host 对"非一一映射搬运"的显式批令授权。正常生产默认假设源目是确定的一一/同盒映射，而非一一映射（多源合一、一源分多、动态分档）改变了片的流向，若没有显式授权，任何因 bug/错料导致的"片跑到别的盒"都会被误认为合法合批，失去防错能力。有了授权位，只有 Host 明确下发的合/拆/分档计划才允许跨集合重排，未授权的非一一映射一律拒绝并报警，把"计划内重组"和"异常串片"区分开。
3. **分档目标确定时点 / 前后保证**：最终目标在**该片完成加工/量测、拿到等级结果之后、AtPlace 放入目标之前**确定（量测前只有候选目标集）。确定前：片在设备内安全位置（Buffer/臂）等待，候选目标载具都已 Loaded；确定时由 SortingPlanner 按等级规则选目标盒槽，且该槽实时为空、目标盒 Loaded 未 Hold；确定后按 W15 六道关 AtPlace 二次确认并放后读回 ID。规则与决定要记录（哪片何等级去何盒何槽）以便审计追溯。
4. **并行+分档顺序处理**：多腔并行使各片完成时刻不同，不能假设"先开始先完成、按源顺序入目标"。做法是片完成加工后进入"待分流"队列，每片独立按量测结果触发 SortingPlanner 决定目标，调度器在全局资源日历上为"腔→对应目标"这段搬运单独排时间区间（不同片目标不同、资源不相交则并行搬运）；目标槽分配随完成动态进行、放一片占一个槽，最终顺序由完成时序和分档规则共同决定，但每片身份全程携带、终验按全局集合核对，与顺序无关。
5. **返工回流守恒**：返工片是已经加工过、需要重新进入流程的片，它不是"新增片"。全局集合仍以最初进入该生产区域的片 ID 并集为基线，回流时该片 ID 已在基线集合内，只是位置从"下游/返工源"重新进入设备源载具/Buffer，守恒等式两边都包含它（位置变化、集合不变）；要在轨迹上标注其为 Rework（第几轮、回流原因），避免被误算成两片或漏算，终验按 ID 去重后集合仍等于基线。
6. **分档目标槽不够**：这是容量约束冲突，不能硬塞或丢片。处理：①该档片先安全停在设备内 Buffer/暂存位（守容量），任务进入等待/挂起；②通知 Host 该档目标载具满，请求更换空目标载具（E87 卸载满盒、装新空盒并 Loaded）；③新盒就绪后把等待片继续分流到新盒对应档槽；④若策略允许也可提前按各档预估数量准备足够目标盒。全程片在设备内有确定安全位置、全局集合守恒，绝不能因为目标满就把片放错档盒或丢弃。
7. **终验为何按全局 ID 集合**：合/拆/分档后单盒数量与源完全不同，按单盒数量无法判断对错（数量对但片串了也发现不了）。只有全局片 ID 集合能同时捕获三类错误：丢失（S_after 少 ID）、新增/错 ID（出现源集合没有的 ID，说明串片/混料）、错位（ID 都在但去错档盒，需要再结合分档规则核对每片目标）。数量守恒只能保证"片数没少"，ID 集合守恒才能保证"每一片都是原来那片、且去向合法"，这是防混料的根本。

## 二、参考实现（net8.0）

### 全局集合守恒
```csharp
namespace EapLab.Cell;
public sealed class GlobalIdBalance
{
    public HashSet<string> Before { get; }=new();
    public HashSet<string> After { get; }=new();
    public bool Conserved => Before.SetEquals(After);
    public List<string> Missing=>Before.Except(After).ToList();
    public List<string> Unexpected=>After.Except(Before).ToList();
    public static GlobalIdBalance Snapshot(SubstrateTracker t,IEnumerable<string> allWaferIds)
    { var b=new GlobalIdBalance(); foreach(var w in allWaferIds)b.Before.Add(w);
      foreach(var w in t.AllWaferIds())b.After.Add(w); return b; }
}
```

### 分档规划
```csharp
public enum BinGrade { Good, Recheck, Reject }
public sealed class BinRule{ public BinGrade Grade; public string Carrier; }
public sealed class SortingPlanner
{
    private readonly Dictionary<BinGrade,Queue<SlotRef>> _slots=new();   // 各档可用空槽
    public SortingPlanner(Dictionary<BinGrade,IEnumerable<SlotRef>> freeSlots)
    { foreach(var(kv in freeSlots)_slots[kv.Key]=new Queue<SlotRef>(kv.Value); }
    public (SlotRef slot,string carrier)? Assign(BinGrade g)
        => _slots[g].Count==0?null:(_slots[g].Dequeue(),g.ToString());
    public int Remaining(BinGrade g)=>_slots[g].Count;
}
```

### 复杂布局编排
```csharp
public sealed class MergeSplitBinningJob
{
    public bool Authorized { get; init; }       // MergeSplitAuthorized
    private readonly SubstrateTracker _t; private readonly SortingPlanner? _planner;
    public MergeSplitBinningJob(SubstrateTracker t,SortingPlanner? planner=null){_t=t;_planner=planner;}

    public void MoveCross(string wafer,SlotRef src,SlotRef dst)
    { if(!Authorized && !SameCarrierOneToOne(src,dst))
        throw new InvalidOperationException("非一一映射需显式批令授权(MergeSplitAuthorized)");
      _t.Move(wafer,new CarrierLocation(src.Carrier,src.Slot).Key,
              new CarrierLocation(dst.Carrier,dst.Slot).Key,WaferState.Completed); }

    public SlotRef BinTo(string wafer,BinGrade g)
    { var a=_planner?.Assign(g) ?? throw new InvalidOperationException($"档{g}目标槽不足,片安全等待换盒");
      _t.Move(wafer,_t.LocationOf(wafer).Key,new CarrierLocation(a.carrier,a.slot.Slot).Key,WaferState.Completed);
      return a.slot; }
    static bool SameCarrierOneToOne(SlotRef s,SlotRef d)=>s.Carrier==d.Carrier;
}
```

### xUnit
```csharp
public class MergeSplitBinningTests
{
    [Fact] public void 两源合批一目标_全局集合守恒()
    { var t=TrackerWithCarriers("A",new[]{"A1","A2","A3"},"B",new[]{"B1","B2","B3"},"C");
      var all=t.AllWaferIds().ToHashSet();
      var job=new MergeSplitBinningJob(t,null){Authorized=true};
      int slot=1;
      foreach(var w in new[]{"A1","A2","A3","B1","B2","B3"})
      { var src=t.LocationOf(w).ToSlot(); job.MoveCross(w,src,new SlotRef("C",slot++)); }
      var bal=GlobalIdBalance.Snapshot(t,all);
      Assert.True(bal.Conserved); Assert.Empty(bal.Missing); Assert.Empty(bal.Unexpected);
      Assert.Equal(6,t.CarrierOccupancy("C"));
    }
    [Fact] public void 未授权合批_拒绝()
    { var t=TrackerWithCarriers("A",new[]{"A1"},"B",new[]{"B1"},"C");
      var job=new MergeSplitBinningJob(t,null){Authorized=false};
      Assert.Throws<InvalidOperationException>(()=>job.MoveCross("A1",new("A",1),new("C",1))); }
    [Fact] public void 分档_按等级入对应盒_集合守恒()
    { var t=TrackerWithCarriers("S",new[]{"W1","W2","W3"},"G","R","X");
      var planner=new SortingPlanner(new(){
        [BinGrade.Good]=new[]{new SlotRef("G",1)},
        [BinGrade.Recheck]=new[]{new SlotRef("R",1)},
        [BinGrade.Reject]=new[]{new SlotRef("X",1)}});
      var job=new MergeSplitBinningJob(t,planner){Authorized=true};
      job.BinTo("W1",BinGrade.Good); job.BinTo("W2",BinGrade.Recheck); job.BinTo("W3",BinGrade.Reject);
      Assert.True(GlobalIdBalance.Snapshot(t,new[]{"W1","W2","W3"}).Conserved);
      Assert.Equal(1,t.CarrierOccupancy("G")); Assert.Equal(1,t.CarrierOccupancy("R"));
    }
    [Fact] public void 档槽不足_不丢片_等待换盒()
    { var t=TrackerWithCarriers("S",new[]{"W1","W2"},"G");
      var planner=new SortingPlanner(new(){[BinGrade.Good]=new[]{new SlotRef("G",1)}});
      var job=new MergeSplitBinningJob(t,planner){Authorized=true};
      job.BinTo("W1",BinGrade.Good);
      Assert.Throws<InvalidOperationException>(()=>job.BinTo("W2",BinGrade.Good)); // 槽不足安全挂起
      Assert.Contains("W2",t.AllWaferIds()); }  // W2仍在, 未丢
}
```

## 三、复杂布局流向（手绘参考）
```
合批: A{a1,a2,a3}+B{b1,b2,b3} --多腔加工--> C{6片}        (多源→一)
拆批: S{6} --------------------------> C{3} + D{3}        (一→多)
分档: S --加工/量测--> Good→G / Recheck→R / Reject→X      (量测后AtPlace前定目标)
混合: A+B 合批加工 → 按量测再拆到 G/R/X (叠加三腔并行, 完成顺序≠源顺序)
守恒: S_before(所有源ID并集)==S_after(所有目标+设备内ID并集), 与落在哪个盒无关
授权: 非一一映射必须 MergeSplitAuthorized; 档满→片安全等待换盒, 不丢不错
```

## 四、今日易错点
1. 用逐盒守恒校验合/拆/分档（单盒数量本来就变，必须全局 ID 集合守恒）。
2. 只比数量不比 ID（数量对但串片发现不了，集合相等才能抓错 ID/混料）。
3. 非一一映射无显式授权也允许（无法区分计划内重组与异常串片）。
4. 量测前就定死分档目标（应量测后、AtPlace 前按等级动态定，且目标空且 Loaded）。
5. 假设并行下完成顺序=源顺序（片独立完成、独立分流，身份全程携带）。
6. 档盒槽满硬塞/丢片（片安全暂存、请求换盒、守恒不破坏）。
7. 返工片当新增片或漏算（ID 已在基线集合，只改位置并标 Rework）。
8. 分档不记录规则与去向（无法审计"哪片为何去哪个盒"）。
