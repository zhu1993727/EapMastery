## 二、背景知识（先读，25 分钟）

### 1. 复杂布局类型（回顾 W15，叠加并发）
- **合批 Merge**：源 A、源 B 的片合并进目标 C（或 A+B→A 剩余槽）。片来源多、去向一。
- **拆批 Split**：一个源的片拆到多个目标（不同工序/不同流向）。来源一、去向多。
- **分档 Sorting/Binning**：根据量测（Metrology）结果/等级，把片动态分到对应目标载具（良品→C、复测→D、报废→隔离）。目标在量测后才能最终确定。
- 都可与多腔并行叠加：片在不同腔加工后，按映射/分档结果被搬到不同目标。

### 2. 守恒口径（关键）
- 简单同盒/一一搬运可逐盒守恒；合/拆/分档**逐盒不相等**，必须用**全局片 ID 集合守恒**：
  - 加工前全局集合 S_before（所有源载具片 ID 并集）。
  - 加工后 S_after（所有目标载具 + 设备内片 ID 并集）。
  - 恒等 S_before==S_after（无丢失、无新增、无错 ID），与在哪个盒无关。
- 合/拆/分档必须有**显式批令授权**（MergeSplitAuthorized）：Host 明确允许这种非一一映射，防止误把异常搬运当合法。

### 3. 分档（Binning）动态目标
- 片加工/量测前只有候选目标集，量测出等级后由 SortingPlanner 决定最终目标槽。
- 动态决定点要在 AtPlace 之前完成，且目标槽当时确实为空、目标载具 Loaded。
- 分档规则可审计（哪片因何等级去哪个盒哪槽）。

### 4. 与多腔并发叠加的难点
- 不同片在 C1/C2/C3 并行，完成时刻不同，完成后按各自目标/档位被搬运，调度器要处理"完成顺序≠加工顺序、目标也不同"。
- 全局资源日历跨所有源/目标载具与腔统一调度（为 W20 多 PJ 铺垫）。
- 每拍仍守位置不变式；终验按全局集合而非单盒。

### 5. 典型现场场景
- 良率分档：蚀刻后量测，按结果分流；返工回流（Rework 片重新进入源）；多批次合并加工提高设备利用率。这些都是先进 FAB 常见场景。
