# W19 · Day07 答案

## 一、费曼讲解参考
1. **ProcessJob 是什么 / 与 ControlJob 关系**：ProcessJob（E40）是最小可独立调度的加工单位，描述一组片按一条工艺路线（若干 Step，映射到具体模块/腔和配方）完成加工，包含 WaferMap（片从哪来到哪去、顺序）、ProcessRoute（步骤/模块/配方/DAG）和状态进度。ControlJob（E94）是它的上层编排：一个 CJ 包含一个或多个 PJ，描述原料载具经过这些 PJ 最终到产出载具的完整跨载具流程，规定 PJ 的顺序、依赖、并行。关系是 CJ 1 对多 PJ：PJ 负责"具体怎么加工这批片"，CJ 负责"这批料整体经过哪些加工、从哪个盒到哪个盒"；Host 通常以 CJ 为单位派工，设备内部把它拆成 PJ 执行。
2. **三条铁律**：①受理≠生效——Host 命令的同步应答（S15F10/S2F42=0）只表接受，真正状态以异步事件（S16F1/S6F11）为准，因为物理过程（到安全点、加工完成）需要时间，拿应答当结果会误判；②物理优先——重启/对账时物理片位置是客观事实，逻辑记忆可能过时，身份明确以物理修账，身份存疑人工，绝不用内存猜物理；③完成必须归位——流程跑完不等于完成，必须全片完成且在声明目标槽、设备内空、终验守恒、无异常、数据全才算 Completed，防止假完成让片滞留/流入下游。
3. **并行下物理正确的机制**：规划层用资源时间区间互斥、固定全序申请+all-or-nothing 防死锁、选腔只选健康可用同型腔、资源不相交才并行；位置层 E90 是唯一改位置入口，进资源=acquire 出=release 与 Move 一一对应，逻辑时钟每拍断言唯一/容量/守恒；状态层 Job 单一状态机+逐片进度+严格完成守卫，异常先到安全点。规划防冲突、位置守物理、状态守任务，三层独立又互相校验，所以高并行仍不出叠片/丢片。

## 二、E40 综合验收卷（10 题）参考答案
1. **PJ 三正交组成**：WaferMap 管"片从哪到哪、加工顺序"（Source/Destination、WaferOrder、执行时载具绑口并核 ID，静态六校验）；ProcessRoute 管"怎么加工"（Step 逻辑步骤、Module 物理模块、Recipe 配方版本，串行/步骤内同型腔并行/回流用 DAG，RouteValidator 查可达）；状态与进度管"做到哪"（Job 整体状态正交于每片 WaferProcess）。三者正交：改布局不改工艺、改工艺不改状态机。
2. **状态集/四终态/命令事件分离**：Queued/Received→Started(过渡)→Executing；Executing→Pausing(过渡)→Paused→Executing；四终态 Completed/Cancelled/Aborted/Failed（无出边）。命令（Host 外部 Start/Pause/Resume/Cancel/Abort）与事件（执行器内部 ReadyToExecute/ReachedSafePoint/WaferAllDone/Fault）分离，因为命令是请求、能否生效取决于 Guard 和物理事实，事件才是状态迁移的真实触发；分离后"受理≠生效"可表达、非法命令零副作用、状态单一写入口。
3. **暂停/安全点/Resume**：三层级=任务级（不再开新片，当前片到安全点全停）、片级（做完当前片再停）、步骤级（当前 Step 到边界停）。安全点四条件=位置确定稳定、工艺可续、资源自洽、账目一致。Resume 靠 ResumeToken（进度游标+已完成片/步集合+每片实际位置+载具快照），配合 E90 逐片核对：已完成跳过、当前片从安全边界续、未开始按序，续前核对位置与守恒，做到不重不漏；现场不一致/身份存疑拒绝自动续。
4. **Cancel/Abort / 三分类**：Cancel 仅无片受影响（都 Waiting 未离槽）时，干净撤回、释放预留、Cancelled 终态；Abort 用于执行中，停调度、当前单元到安全点。三分类：已完成片保持不动（有效成果）、在途/在腔片到安全点后退回源/Buffer/安全保持并记实际位置、未开始片留源；处置经 E90 守守恒，释放可释放资源、锁载具，Aborted 终态不能 Resume，只能新建续跑 PJ/Rollback/人工。
5. **严格完成/Partial/三结局**：五条件=全片 Completed、每片 AtDestination 且设备内空、E90 终验逐片 ID 对且守恒、无 Failed/阻断 Hold/Alarm、数据完整。Partial 用 CompletedList/InFlightList/FailedList 且每片带实际位置、分类守恒，显式标 PartialCompleted（需授权）或随 Aborted/Failed，绝不冒充 Completed，并向 MES 报缺口。三结局=AllCompleted / PartialCompleted（授权）/ Aborted/Failed，集中评估。
6. **调度/防死锁/选腔/节拍**：时间区间互斥（容量 c 允许 c 重叠，冲突顺延到最早空隙）；固定资源全序申请+all-or-nothing 打破循环等待与持有等待，分配图找环兜底；选腔五依据=能力→最早可用→亲和→配方切换→健康，确定性可解释；节拍=瓶颈服务一片时间，Makespan≈首片+(n-1)×节拍，非流水线≈n×全流程。
7. **Swap/锁/乒乓**：Swap 五步=持新到腔前→空手臂取旧（腔空）→旋转换位→放新→持旧离开，腔空才放、干涉区互斥；LoadLock 有门/压力/方向状态机，两门绝不同时开、压力到位才开本侧门（压力互锁）；双锁乒乓让 LL1 供真空侧时 LL2 供大气侧、下拍互换，把抽破真空重叠在对侧动作里，掩盖锁耗时。
8. **恢复/对账/Spool**：重启三分支=一致恢复（Completed 保持、Paused 保持、Executing 先安全挂起）、位置类身份明确以 P 修 L、身份/工艺存疑人工；P/L/H 对账先 P-L 收敛再 L-H 同步（先内后外）；Spool 至少一次按序补发、对端按事件序号去重、ACK 后删，恢复出权威状态后再对外补发。
9. **受理-生效关系**：S14 取定义→S15F1 创建（ACKC）→S15F9/F10 调方法（ACKC=0 仅受理）→状态迁移成功发 S16F1（生效）；S2F41 远程命令→S2F42（ACKC10=0 仅受理）→完成发 S6F11（生效）。两条链都是"同步应答=受理、异步事件=生效事实"，且事件在迁移成功后从同一权威状态同源产生。
10. **反例：两片进同腔的多层拦截**：有 bug 的调度若给两片排了同腔同刻区间——①规划层 ResourceCalendar 容量 1 区间互斥本应把第二片顺延/选腔器改派（若此处 bug 漏过）；②执行器 Enter 时资源 acquire 与 E90 Move 对应，向容量 1 的 Chamber 位置 Move 第二片时，E90 位置层容量校验直接拒绝（位置容量 1，防叠片）并抛异常，动作不发生；③每拍 AssertInvariants 立即在出错点报容量破坏；④即便错误执行，终验会发现同槽/同腔两片（Double）禁止完成。正确修复点在规划层（区间/选腔），E90 是最后物理兜底——这正体现分层防御：单层可能有 bug，多层独立校验保证不出物理事故。

## 三、W20 预热思考题参考
1. **两顺序 PJ 的 CJ 完成条件**：CJ 含 PJ-A（蚀刻）、PJ-B（清洗），A 的输出载具是 B 的输入。CJ 完成要求：两个 PJ 都到 Completed（A 完成且其产出片在中间载具/位置、B 取这些片加工完放到最终目标载具）、全部片在 CJ 声明的最终目标位置、跨 PJ 片 ID 集合全局守恒（A 的输出集合==B 的输入集合，无丢漏）、设备内空、终验通过、无异常数据全。即 CJ 完成=所有子 PJ 完成且片到达 CJ 级最终目的地，不是某个 PJ 完成就算。
2. **CJ Paused、一 PJ Completed 一 PJ Executing 的级联**：已 Completed 的 PJ 保持终态（成果不动、不回退）；Executing 的 PJ 收到级联暂停，进入 Pausing 并让其在途片到安全点后 Paused；当所有"可暂停的活动 PJ"都到安全点、Completed 的保持完成，整个 CJ 才聚合为 Paused。Resume 时 Completed 的 PJ 不重做，从 Paused 的 PJ 恢复点续跑。级联原则：终态子作业保持、活动子作业统一到安全点、CJ 状态是子状态的聚合。
3. **为何以 CJ 为派工单位**：Host/MES 管理的是"一批料从原料载具到成品载具的完整加工流程"，这个流程可能含多个工艺段（PJ）甚至跨载具，CJ 正好对应这个业务粒度：一个 CJ 说清源载具、经过的 PJ 序列/依赖、目标载具与整体状态，MES 以批次/料为单位派工和追踪最自然；若直接派多个独立 PJ，Host 要自己维护 PJ 间顺序、载具衔接和整体成败，复杂且易错。设备内再把 CJ 拆成 PJ 调度执行，实现"业务层派工（CJ）—执行层加工（PJ）"的清晰分层。

## 四、阶段收官自检（E40 是否达到专家级）
- 能闭卷画出 PJ 组成/状态机/并发调度/端到端可靠四图并讲清每个守卫。
- 能独立写出：PjMapValidator/RouteValidator、JobStateMachine、PauseResume/Abort、CompletionGuard、事件溯源恢复、GlobalScheduler/ChamberSelector/DualArm/LoadLock、ConcurrentExecutor、Reconciler3/Spool、Host OSS/RCMD 桥。
- 能对任意异常组合说出检测点、片处置、状态迁移、恢复路径，并保证守恒。
- 三张检查单能用于真实方案评审与现场排障。
- 达成即进入 W20 E94，把多 PJ 编排能力升级为标准 ControlJob。

## 五、E40 阶段总易错清单（W16-W19 浓缩）
1. 把 PJ 当不可拆分黑盒（PJ=WaferMap+Route+状态三正交，最小可调度单位）。
2. 受理当生效、命令事件不分离、事件先于状态迁移。
3. 硬切反应中途、Pause 不到安全点、Resume 不核对现场导致重漏片。
4. Cancel/Abort 混用、Aborted 直接 Resume、Abort 绕过 E90 善后。
5. 循环跑完即完成、Partial 冒充完成、片在臂上也算归位。
6. 并发用真线程、区间允许重叠、不按固定顺序申请致死锁、无老化致饥饿。
7. Swap 腔未空就放片、双臂同入干涉区、LoadLock 两门同开。
8. 执行器绕 E90 改位置、资源占用与 Move 脱节、并发不做每拍断言。
9. 重启 Executing 直接跑、身份存疑自动改账、终态复活、先对外同步后内部对账。
10. S16/S6F11 两份数据、Spool 不按序不去重、ACK 前删事件。
11. 多 PJ 各用资源日历、忽略 PJ 依赖、未过 UnloadGuard 下料。
