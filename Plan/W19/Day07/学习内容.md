## 三、三张专家检查单（产出物，20 分钟）
### 1. 设计检查单（方案阶段）
- PJ 源目映射是否过静态六校验、片集合守恒基线是否建立。
- 工艺路线是否拓扑可达、同型/异型腔能力是否标注、配方两次校验点是否设计。
- 资源拓扑/容量/瓶颈是否识别，调度是否固定顺序防死锁、公平防饥饿。
- 状态机是否覆盖全部状态/终态/非法迁移，暂停安全点与 ResumeToken 是否定义。
- 异常矩阵是否穷尽（类型×时机×局部/全局），fail-safe 兜底是否明确。
- 持久化时机（WAL）、重启恢复三分支、三方对账、Spool 是否设计。
- Host 交互 ACKC、S16/S6F11 同源、采集 CEID/VID 是否规划。

### 2. 代码评审检查单（Review 阶段）
- 是否只有 E90 一个改位置入口、资源 acquire/release 与 Move 是否一一对应。
- 是否复用 W10 泛型状态机、Guard 为假是否零副作用、终态是否无出边。
- 并发是否逻辑时钟确定性、每拍是否断言三不变式。
- 是否存在"循环跑完即完成""Partial 冒充 Completed""硬切反应中途"。
- 事件是否迁移成功后发、数据是否从权威状态现取、序号是否单调。
- 恢复是否幂等、身份存疑是否转人工、终态是否不复活。

### 3. 现场排障检查单（出事时）
- 先问物理：载具/片实际在哪（读码/Mapper），再看设备账 L、Host 账 H。
- 查状态机当前态与最后事件、查 Spool 是否有未确认事件、查守恒在哪一步破。
- 区分计划问题（调度/选腔）、物理问题（位置/传感器）、任务问题（状态/进度）。
- 安全优先：不确定就安全保持人工，不猜身份、不猜工艺完成度。

## 五、W20 预热：E94 ControlJob（20 分钟）
### 1. CJ-PJ 分层（正式建立）
- **ProcessJob（E40）**：最小可独立调度的加工单位，面向一组片的一条工艺路线，在一组模块上执行。
- **ControlJob（E94）**：编排一个或多个 ProcessJob 的控制作业，描述"原料载具→经过哪些 PJ→产出载具"的完整流程，跨载具、可含顺序/依赖/并行。
- 关系：CJ 包含 PJ（1 个 CJ：n 个 PJ）；PJ 干活，CJ 编排；片在 CJ 层面从源载具流向目标载具，在 PJ 层面经历具体工艺。
### 2. 为什么需要 CJ
- 一个完整生产流程常跨多个工艺段/PJ（甚至跨设备逻辑），需要一个上层对象统一描述源目载具、PJ 执行顺序与依赖、整体状态，Host 以 CJ 为单位派工。
- E94 把 W19 Day06 的"多 PJ 全局编排"标准化为对象模型与状态机。
### 3. CJ 状态机级联（预告）
- CJ 也有自己的状态机（Queued/Executing/Paused/Completed/Aborted…），其状态由所含 PJ 状态聚合：全部 PJ 完成 CJ 才完成；一个 PJ Pause/Abort 会影响 CJ（级联策略）。
- W21 专门讲级联规则（一个 PJ 故障是否拖停整个 CJ、其他 PJ 怎么办）。
### 4. W20-W23 路线
- W20 E94 CJ 模型与三层关系（CJ/PJ/片、源目载具、对象属性）。
- W21 CJ 状态机与级联、跨载具流程。
- W22 全链路大串联（E5/E30/E39/E84/E87/E90/E40/E94 贯通）。
- W23 CJ 调度与故障演练（多载具复杂编排+异常恢复综合）。
### 5. 思考题（带进 W20）
1. 一个 CJ 含两个顺序 PJ（先蚀刻后清洗），第一个 PJ 的输出载具是第二个的输入，CJ 完成条件是什么。
2. CJ Paused 但其中一个 PJ 已 Completed、一个 Executing，如何级联。
3. 为什么 Host 通常以 ControlJob 而非 ProcessJob 为派工单位。
