## 二、背景知识（先读，20 分钟）

### 1. 集成分层（工程结构建议）
```
EapLab.Domain            // 通用值对象/状态机(W10)
EapLab.E87 / E84         // 载具管理/并口(W11-13)
EapLab.E90               // 位置空间/SlotMap/交叉/调度(W14-15,18)
EapLab.E40
  .Model .S14 .S15 .S16  // PJ模型/OSS/事件(W16)
  .Fsm                   // 状态机/暂停恢复/中止/持久化(W17)
  .Sched .Runtime        // 资源调度/并发执行(W18)
EapLab.Cell              // 总装: 把上面连成一条线(本周)
```
- 依赖方向单向：Cell→各标准模块→Domain；模块之间通过接口/事件解耦，不互相硬连。

### 2. 端到端正常流阶段（每阶段的门）
1. **物理上料（E84→E87）**：Deposit 稳定去抖→物理在位→Installed→预约核对→Loaded（唯一可自动取片）。
2. **位置注册（E90）**：为每个 Loaded 载具注册 SlotMap、建立基线总数。
3. **PJ 建立（E40/S14/S15）**：WaferMap（源目）+ProcessRoute（步骤/同型腔/配方）→静态六校验→Create 受理。
4. **开工双校验 + Start**：载具绑定口与 ID、配方版本、资源、Hold；通过后 Started→ReadyToExecute→Executing。
5. **多腔并发执行（W18）**：选腔/流水线/双臂/双锁，逐片阶段推进，每拍守恒，发 S16 进度。
6. **跨载具搬运（W15）**：源目映射、AtPick 读码、AtPlace 读回，跨盒全局守恒。
7. **严格完成（W17）**：全片 Completed+AtDestination+设备内空+终验+数据全→Completed。
8. **下料门（UnloadGuard，W13）**：任务全完、片全归位、臂回原点、门关闭、无 Hold→放行→E87 Unload→E84 Pickup。

### 3. 可观测性
- 统一事件总线记录：载具事件、位置迁移、资源占用、Job/片状态、S16 事件，带逻辑时间戳。
- 一次运行产出：事件时间线、最终布局、守恒核对、Makespan、完成结论。

### 4. 集成原则
- 单一事实源：位置只问 E90、任务状态只问 PJ FSM、载具状态只问 E87，任何模块不私改他域状态。
- 门控串联：前一阶段门不过，不进入下一阶段（fail-closed）。
