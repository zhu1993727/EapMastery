## 二、背景知识（先读，25 分钟）

### 1. PJ 的 OSS 全流程（回顾 W09/W10/W16）
- **S14 定义**：Host 先 GetAttr/取 ProcessJob 对象类定义（属性：状态、源目、进度、当前片/步等），空集合回 L,0。
- **S15 创建/控制**：F1/F3 Create（带初始属性）→返回 ACKC；F9/F10 调方法 Start/Pause/Resume/Cancel/Abort；F5 查、F7 改属性（两阶段原子）。
- **S16 事件**：对象状态变化发 F1=L,3[OBJSPEC, CEID, 快照 List]，F2 确认。
- ACKC：0 成功/1 类不存在/2 实例不存在/3 已存在/4 属性不存在/5 只读/6 缺必填/7 类型不匹配/8 状态非法/9 方法不存在/10 参数错/99 内部错。

### 2. 受理≠生效（贯穿，再强化）
- S15F10（方法调用应答）ACKC=0 只代表"请求合法、已受理"，不代表方法已完成；真正状态以随后 S16F1 事件为准（如 Pause 受理→Pausing→安全点→Paused 事件）。
- S2F41 远程命令同理：S2F42 ACKC10=0 只接受，远程命令完成靠对应 S6F11 事件（W07）。
- 这层异步语义是 GEM/OSS 的核心，Host 不能拿应答当结果。

### 3. S2F41 远程命令接入 PJ
- body=L,2 [A RCMD, L,n [L,2 [A CPNAME, CPVALUE]]]。
- 典型 RCMD：START_PJ（CP：JobId）、PAUSE_PJ、RESUME_PJ、CANCEL_PJ、ABORT_PJ、SELECT_PROCESS（选路/配方覆盖，需授权）。
- 流程：校验 RCMD/CP→S2F42 受理→转成内部 JobCommand 交状态机→到生效点发 S6F11（RCMD 完成事件）。
- 非法状态发命令（如 Completed 后 Start）回 ACKC10 非 0 / 状态非法，零副作用。

### 4. 采集联动（S6F11 与 S16 对齐）
- 定义采集三层：VID（变量：JobId/State/CurWafer/CurStep/进度/腔体/片结果）→RPTID 报告组→CEID 事件。
- PJ 关键 CEID：5101 Started/5102 StepEnter/5103 WaferDone/5104 JobDone/5105 Paused/5106 Aborted（W16 教学编号）。
- 同一业务发生点：状态机迁移成功→既更新 OSS 对象（触发 S16F1），又按 CEID 关联的 VID 取值组 S6F11 上报；两者数据来自同一权威状态，保证一致。
- 片级工艺数据（腔、配方版本、量测结果）随 WaferDone 上报，供 FDC/YMS/R2R。

### 5. 交互闭环（今天主线）
```
Host: S14取定义 → S15F1建PJ(ACKC) → S2F41 START(ACKC受理)
设备: 状态机迁移 → S16F1 Started + S6F11(5101)
      每步/每片: S16F1 + S6F11(5102/5103) 带VID快照
Host: S2F41 PAUSE → 受理 → 安全点 → S16F1/S6F11(5105 Paused)
      S2F41 RESUME → ... 直到 5104 JobDone; Abort→5106
全程: Spool保证断线不丢; 重连对账同步当前对象状态
```

### 6. 一致性要点
- 事件只在状态迁移成功后发（先改状态后发事件，W17）；事件数据从权威状态现取，不另存一份易不一致的副本。
- 事件序号单调，配合 Spool/去重（Day04）。
