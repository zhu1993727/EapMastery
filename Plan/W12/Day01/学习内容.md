## 二、背景知识（先读，30 分钟）

### 1. E87 是什么
- E87 = SEMI E87 **CMS Carrier Management Standard（载具管理标准，文档中也称 CMSD Carrier Management System Definition）**。
- 它规定设备如何通过 SECS 接口与 Host 协同管理载具（Carrier：12 寸 FOUP、光罩盒 Reticle Pod 等）在设备 Load Port 上的**逻辑生命周期与准入控制**。
- 核心问题：①哪个 Load Port 上现在有没有盒子；②这个盒子是谁（CarrierID）；③它是否被 Host 预约/授权；④它现在处于什么状态（能否开门取片、能否被取走）；⑤盒内有哪些晶圆（与 E90 配合）。
- 价值：防错料（上错 FOUP/上错口）、防未授权加工、保证物料流与 MES 账实一致、支撑全自动无人上料。

### 2. E87 的核心管理对象
- **Carrier（载具）**：一个 FOUP 就是一个 Carrier 对象。属性：CarrierID（唯一标识）、CarrierType（FOUP/Reticle/FOSB 等）、所在 LoadPortID、Carrier 状态、安装时间、关联 Lot 列表等。
- **LoadPort（装载口）**：设备上的物理工位对象，一台设备通常 2~4 个。属性：LoadPortID、LoadPort 状态、当前 CarrierID（空则无）、预约信息、可用性。
- **CarrierID（载具标识）**：载具身份，通常由载具上的 RFID 标签/条码读出，是和 MES 批次（Lot）、配方、工艺路线绑定的钥匙。ID 读取发生在物理就位之后。
- **Reservation（预约/保留）**：Host 提前告诉设备"LoadPort-1 预期将要上 CarrierID=FOUP-A"，设备记住预约；实际上料读到 ID 后比对，一致才授权装载，不一致拒绝/Hold（防错料核心）。
- **Slot Map（槽位图，与 E90 配合）**：Carrier 内 25 个 Slot 哪些有基板。E87 关心"载具级"，E90 关心"每片基板级"，W14 详讲。
- **Access State（访问状态/操作权限）**：载具在某状态下设备/操作员/Host 各能做什么（能否开门、能否取片、能否卸载），是状态机的行为约束。

### 3. E87 与 E84/E90/E40/E94 的边界（核心考点）
```
E84 物理层：硬线，FOUP 在 LoadPort 与天车之间放/取的动作安全（不管ID、不管状态、不管晶圆）
E87 载具层：SECS，Carrier 逻辑状态、ID绑定、预约授权、准入（管"盒子"整体）
E90 基板层：SECS，盒内每片基板的 Slot 位置/ID/来源目标（管"盒里的货"，W14）
E40/E94 任务层：SECS，ProcessJob/ControlJob 怎么加工这些基板（管"干什么活"，W16+）
```
- 数据流：E84 Deposit 物理就位（硬件事件）→ E87 读 ID、校验预约、迁 LOADED（载具准入）→ E90 读 SlotMap/基板位置 → Host 据此建 E40 ProcessJob / E94 ControlJob → 加工完 E87 迁 UNLOADED → E84 Pickup 物理取走。
- 边界口诀：**E84 管手（动作）、E87 管盒（账与准入）、E90 管片（货位）、E40/E94 管活（加工）**。

### 4. E87 为什么建立在 E39 OSS 之上
- Carrier、LoadPort 天然是"对象"：有类型、属性、方法（装载授权/卸载）、事件（就位/装载/卸载），完全契合 E39 OSS 的对象模型。
- 因此 E87 大量使用：S14 发现 Carrier/LoadPort 类型定义；S15 创建/设置/调用方法（如 Host 授权、下发预约）；S16 对象事件上报（Carrier 安装/状态迁移）。W09/W10 学的 OSS 框架直接复用。
- 部分老设备/实现也用传统 GEM 的 S6F11 事件报告 + S2F41 远程命令表达同样语义；先进 FAB 以 OSS 对象服务为主。两种都要能看懂，本周以 OSS 为主线、标注传统 GEM 对应关系。

### 5. 先进 FAB（长鑫/中芯/台积电类）实践要点（建立认知）
- **预约驱动（Reservation-based）**：全自动产线几乎都是"先预约、后上料、强校验"，没有预约或 ID 不符的载具不会被授权加工，直接 Hold 并报警，杜绝混料。
- **载具 ID 与 Lot/工艺路线强绑定**：Host 侧 MES 掌握"这个 FOUP 装哪个 Lot、该去哪台设备、用什么配方"，E87 上料校验是 MES 防错的执行末端。
- **多 LoadPort 并行与优先级**：设备多个口同时有盒，Host 按调度决定先加工哪个、哪个口预留，E87 状态要实时准确。
- **自动/手动双模式可追溯**：手动上料（E84 Bypass）也要在 E87 补登记并留痕，保证账实一致和可追溯。
