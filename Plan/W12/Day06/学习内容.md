# W12 · Day06（周六，整块 3h）Carrier/LookPort 状态机代码 + 对接 E84 模拟器

> 今天用 W10 的通用状态机框架实现 E87：LoadPort 工位管理、Carrier 四态状态机、预约、ID 校验防错料、授权/卸载命令、异常分支，并把 W11 的 E84 交接结果作为物理触发源接进来——E84 Deposit 成功触发 INSTALLED，E84 Pickup 成功触发移除，形成"物理交接→载具状态→Host 授权"的完整闭环。纯逻辑可单测。

## 一、今日目标
1. 用泛型 StateMachine 实现 Carrier 四态状态机（含守卫、OnEntry 发对象事件）。
2. 实现 LoadPort 工位状态机与 LoadPortManager（多口独立、预约记录、当前 Carrier）。
3. 实现防错料校验器 ReservationVerifier（匹配/不匹配/无预约/读不到四分支）。
4. 实现 Host 命令处理：Reserve/AuthorizeLoad/Unload/CancelReservation/ReleaseHold。
5. 对接 W11 E84 模拟器：E84 Deposit 完成→读 ID→Installed；E84 Pickup 完成→Removed；非正常移除检测。
6. xUnit 覆盖正常闭环 + 六类异常分支。

## 二、设计（先读，20 分钟）

### 1. 复用与命名空间
- 复用 W10 `StateMachine<TState,TTrigger>`（Permit/PermitIf/OnEntry/非法零副作用）。
- 命名空间 `EapLab.E87`；物理触发通过接口 `ICarrierIdReader`（读 RFID，可返回成功/失败）和 W11 的交接结果事件接入。

### 2. 枚举
```
CarrierState: NotInstalled, Installed, Loaded, Unloaded
CarrierTrigger: PhysicalInstall, AuthorizeLoad, Unload, PhysicalRemove, Reject
VerifyState: Unverified, Verified, Mismatch, Unreadable
PortState: Disabled, Empty, Occupied, Fault
ReservationState: Unreserved, Reserved
HoldState: None, CarrierHold, LotHold, EquipmentHold
```

### 3. Carrier 状态机边（守卫是重点）
- NotInstalled --PhysicalInstall--> Installed（OnEntry 发 Installed 事件）
- Installed --AuthorizeLoad [守卫: Verify==Verified ∧ 无 Hold ∧ 口正常]--> Loaded（发 Loaded）
- Loaded --Unload [守卫: 所有访问 PJ 结束 ∧ 无未解除 Hold]--> Unloaded（发 Unloaded）
- Unloaded --PhysicalRemove--> NotInstalled（发 Removed）
- Installed --PhysicalRemove(未授权取走,低危)--> NotInstalled（发 RemovedBeforeLoad）
- Loaded --PhysicalRemove(非正常,高危)--> NotInstalled + 触发 UnexpectedRemoval 告警/事件
- 任意 --Hold--> 冻结（Hold 标志门控 AuthorizeLoad/Unload/取片）

### 4. LoadPortManager
- 持有多个 LoadPort（LP1..LPn），每个独立：PortState、Reservation（预期 ID）、当前 CarrierId。
- Reserve(lp, expectedId)：仅 Empty/可用可预约；CancelReservation；查询。
- OnPhysicalPlaced(lp, readResult)：E84 Deposit 成功回调→读 ID→校验→建 Carrier 走 PhysicalInstall。
- OnPhysicalRemoved(lp)：E84 Pickup 成功/在位 OFF 回调→按当前 Carrier 状态走正常移除或非正常移除。

### 5. 防错料校验器
输入：口预约（有无、预期 ID）、ID 读取结果（成功 ID/失败）。输出决策：Verified / Mismatch(expected,actual) / NoReservation / Unreadable。AuthorizeLoad 只在 Verified 放行。

### 6. 对接 W11 E84
- W11 HandshakeSimulator Deposit 完成（设备回 Idle 且物理 HasCarrier）→调用 LoadPortManager.OnPhysicalPlaced。
- Pickup 完成（在位变空）→OnPhysicalRemoved。
- E84 SafeHold/EStop 时不产生"成功就位"，E87 不建账（联动验证）。

### 7. 事件收集器
- CarrierFsm OnEntry 里把对象事件（Installed/Loaded/Unloaded/Removed/UnexpectedRemoval）推入一个 EventLog，测试断言事件序列，等价线上 S16F1。
