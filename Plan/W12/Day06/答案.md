# W12 · Day06 答案与参考实现

## 一、自测题标准答案
1. **AuthorizeLoad 守卫代码表达 / 为何必须 Verified**：用 W10 泛型状态机的 PermitIf：`PermitIf(CarrierTrigger.AuthorizeLoad, CarrierState.Loaded, () => Verify==VerifyState.Verified && Hold==HoldState.None && Port.IsHealthy)`。必须 Verified 是因为 VerifyState 表示"实际读到的 CarrierID 已与该口预约期望 ID 比对一致"，这是防错料的核心结论；只有 Verified 才证明物理盒子和 MES 计划对得上，未校验/不匹配/读不到时放行就等于让身份不明或错误的盒子进入可加工状态，可能用错工艺报废整批。守卫把这个结论硬性变成"不满足就无法迁移、零副作用"，比靠业务代码 if 判断更可靠（状态机集中拦截、不可绕过）。
2. **ReservationVerifier 输入输出**：输入=①口预约信息（是否 Reserved、预期 ExpectedCarrierId）；②ID 读取结果（读取是否成功、实际 ActualCarrierId）。输出=一个决策枚举：**Verified**（有预约且读取成功且实际==预期）、**Mismatch**（有预约、读取成功但实际≠预期，携带 expected/actual）、**NoReservation**（口无预约但读到了盒）、**Unreadable**（盒在位但 ID 读取失败）。它是纯函数、无副作用，便于穷举单测；AuthorizeLoad 只接受 Verified，其余三种分别进入 Hold/重试/人工流程。
3. **OnPhysicalPlaced 从放好到 Installed 的步骤**：①E84 Deposit 成功回调，确认在位传感器稳定 ON、口为 Empty/可用；②通过 ICarrierIdReader 读 RFID 得读取结果；③创建 Carrier 对象（CarrierId、绑定本 LoadPortId、初始 NotInstalled）；④CarrierFsm.Fire(PhysicalInstall)→Installed，OnEntry 发 Installed 对象事件（带 CarrierID/LoadPortID/State）；⑤调用 ReservationVerifier 得到校验结论并设置 VerifyState（Verified/Mismatch/NoReservation/Unreadable），口置 Occupied；⑥把 Installed 事件与校验结果交 Host（等价 S16F1），等 Host AuthorizeLoad。注意：这一步只到 Installed，绝不自动 Loaded。
4. **LOADED vs INSTALLED 的 PhysicalRemove 为何分开 / 代码区分**：区别在盒内基板是否已被访问。代码在 OnPhysicalRemoved 里先读 CarrierFsm.CurrentState：若是 Installed（还没授权、没取过片）→低危，直接 Fire(PhysicalRemove) 回 NotInstalled、发 RemovedBeforeLoad（撤销性质）；若是 Loaded（已授权、可能有片在设备内）→高危分支：先中止关联 ProcessJob、清点在途基板、发 UnexpectedRemoval 高级告警事件，再强制回 NotInstalled 并锁口待核对；Unloaded 则是正常移除。用当前状态分流，正是"未访问=低危、已访问=高危"原则的落地。
5. **多口不串口的代码结构保证**：每个 LoadPort 是独立对象，各自持有自己的 PortState、Reservation、当前 Carrier 实例和 CarrierFsm，LoadPortManager 用 `Dictionary<loadPortId, LoadPort>` 管理，所有操作都必须显式带 loadPortId 并只作用于该口对象；事件生成时从该口对象取自己的 CarrierId/LoadPortId 绑定上报，绝不用共享字段或数组下标隐式对应。这样 LP1 的读取结果物理上不可能写进 LP2 的状态机。再用交错上料测试（LP1 读到 A、LP2 读到 B，断言各自事件携带正确 ID）验证，从结构和测试两层杜绝张冠李戴。
6. **Hold 如何门控三处**：Hold 是 Carrier/口上的一个状态标志（None/CarrierHold/LotHold/EquipmentHold）。①门控 AuthorizeLoad：PermitIf 守卫要求 Hold==None，有 Hold 不能从 Installed 到 Loaded；②门控 Unload：Loaded→Unloaded 守卫要求允许卸载的 Hold 已解除（某些工程 Hold 下连卸载也受限）；③门控"取片"：在 ProcessJob 取放片入口（E40 层）检查关联 Carrier 的 Hold，Hold!=None 时拒绝启动/继续取片。三处共用同一 Hold 标志做 Guard，保证"被扣留的盒既不能新授权、也不能继续加工、按级别不能卸载"，且只有 Hold 下发方调用 ReleaseHold 清除后才恢复。
7. **E84 SafeHold 为何不建账 / 对接层怎么保证**：E84 进入 SafeHold/EStopHold 表示物理交接没成功、盒可能处于半放半悬、归属不确定，此时"在位稳定就位"这个物理事实并不成立。E87 建 Carrier 账（Installed）的唯一物理触发源是"E84 正常完成 + 在位传感器稳定 ON"。对接层保证：只订阅 E84 的**正常完成回调**（Deposit 走完回 Idle 且物理确认在位）来调 OnPhysicalPlaced；E84 处于 SafeHold/EStopHold/异常时不触发该回调，甚至若传感器瞬变也需稳定去抖才认，从而 E87 不会为一个没放稳/没交接成功的盒创建载具状态。物理层不成功，逻辑层不建账，两层触发严格单向且以物理正常完成为前提。

## 二、参考实现（net8.0，复用 W10 泛型 StateMachine）

### 枚举
```csharp
namespace EapLab.E87;
public enum CarrierState { NotInstalled, Installed, Loaded, Unloaded }
public enum CarrierTrigger { PhysicalInstall, AuthorizeLoad, Unload, PhysicalRemove }
public enum VerifyState { Unverified, Verified, Mismatch, Unreadable, NoReservation }
public enum PortState { Disabled, Empty, Occupied, Fault }
public enum ReservationState { Unreserved, Reserved }
public enum HoldState { None, CarrierHold, LotHold, EquipmentHold }
public enum VerifyDecision { Verified, Mismatch, NoReservation, Unreadable }
public record IdReadResult(bool Ok, string? CarrierId);
```

### 防错料校验器（纯函数）
```csharp
public sealed class Reservation
{
    public ReservationState State { get; set; } = ReservationState.Unreserved;
    public string? ExpectedCarrierId { get; set; }
}
public static class ReservationVerifier
{
    public static VerifyDecision Decide(Reservation res, IdReadResult read)
    {
        if (!read.Ok || string.IsNullOrWhiteSpace(read.CarrierId)) return VerifyDecision.Unreadable;
        if (res.State != ReservationState.Reserved) return VerifyDecision.NoReservation;
        return string.Equals(res.ExpectedCarrierId, read.CarrierId, StringComparison.Ordinal)
            ? VerifyDecision.Verified : VerifyDecision.Mismatch;
    }
}
```

### Carrier 聚合（状态机 + 守卫 + 事件）
```csharp
public sealed class CarrierAggregate
{
    public string CarrierId { get; }
    public string LoadPortId { get; }
    public VerifyState Verify { get; private set; } = VerifyState.Unverified;
    public HoldState Hold { get; private set; } = HoldState.None;
    public bool AllJobsFinished { get; set; } = true;
    private readonly StateMachine<CarrierState,CarrierTrigger> _fsm;
    public CarrierState State => _fsm.State;
    public List<string> Events { get; } = new();

    public CarrierAggregate(string id, string lpId)
    {
        CarrierId=id; LoadPortId=lpId;
        _fsm = new StateMachine<CarrierState,CarrierTrigger>(CarrierState.NotInstalled);
        _fsm.Configure(CarrierState.NotInstalled)
            .Permit(CarrierTrigger.PhysicalInstall, CarrierState.Installed)
            .OnEntry(()=>Events.Add($"Installed:{CarrierId}@{LoadPortId}"));
        _fsm.Configure(CarrierState.Installed)
            .PermitIf(CarrierTrigger.AuthorizeLoad, CarrierState.Loaded, CanLoad)
            .OnEntryLoad(()=>Events.Add($"Loaded:{CarrierId}"))
            .Permit(CarrierTrigger.PhysicalRemove, CarrierState.NotInstalled); // 未授权取走低危
        _fsm.Configure(CarrierState.Loaded)
            .PermitIf(CarrierTrigger.Unload, CarrierState.Unloaded, () => AllJobsFinished && Hold==HoldState.None)
            .Permit(CarrierTrigger.PhysicalRemove, CarrierState.NotInstalled); // 非正常,外部额外处理
        _fsm.Configure(CarrierState.Unloaded)
            .Permit(CarrierTrigger.PhysicalRemove, CarrierState.NotInstalled)
            .OnEntry(()=>Events.Add($"Removed:{CarrierId}"));
    }
    private bool CanLoad() => Verify==VerifyState.Verified && Hold==HoldState.None;
    public void SetVerify(VerifyState v)=>Verify=v;
    public void SetHold(HoldState h)=>Hold=h;
    public void Fire(CarrierTrigger t)=>_fsm.Fire(t);
}
```
> 说明：`OnEntryLoad` 为示意扩展，实际可在 Loaded 的 OnEntry 统一 Add("Loaded")；泛型 StateMachine API 以 W10 Day04 实现为准。

### LoadPort 与 Manager（多口独立、物理触发、命令处理）
```csharp
public sealed class LoadPort
{
    public string Id { get; }
    public PortState State { get; set; } = PortState.Empty;
    public Reservation Reservation { get; } = new();
    public CarrierAggregate? Carrier { get; private set; }
    public List<string> Alarms { get; } = new();
    public LoadPort(string id){ Id=id; }
    public CarrierAggregate? CarrierRef => Carrier;
    public void Attach(CarrierAggregate c){ Carrier=c; State=PortState.Occupied; }
    public void Detach(){ Carrier=null; if(State!=PortState.Fault) State=PortState.Empty; }
}

public interface ICarrierIdReader { IdReadResult Read(string loadPortId); }

public sealed class LoadPortManager
{
    private readonly Dictionary<string,LoadPort> _ports = new();
    private readonly ICarrierIdReader _reader;
    public List<string> GlobalEvents { get; } = new();
    public LoadPortManager(ICarrierIdReader reader, params string[] lpIds)
    { _reader=reader; foreach(var id in lpIds) _ports[id]=new LoadPort(id); }
    public LoadPort Port(string id)=>_ports[id];

    // Host 命令：预约
    public bool Reserve(string lp, string expectedId)
    {
        var p=_ports[lp]; if(p.State!=PortState.Empty) return false;
        p.Reservation.State=ReservationState.Reserved; p.Reservation.ExpectedCarrierId=expectedId;
        return true;
    }
    public void CancelReservation(string lp){ var p=_ports[lp]; p.Reservation.State=ReservationState.Unreserved; p.Reservation.ExpectedCarrierId=null; }

    // E84 Deposit 正常完成 → 读ID → Installed + 校验
    public VerifyDecision OnPhysicalPlaced(string lpId)
    {
        var p=_ports[lpId];
        if(p.State==PortState.Fault || p.State==PortState.Occupied) return VerifyDecision.NoReservation; // 口不可用/已占用
        var read=_reader.Read(lpId);
        string cid = read.Ok ? read.CarrierId! : $"UNKNOWN@{lpId}";
        var carrier=new CarrierAggregate(cid, lpId);
        var decision=ReservationVerifier.Decide(p.Reservation, read);
        carrier.SetVerify(decision switch
        {
            VerifyDecision.Verified=>VerifyState.Verified,
            VerifyDecision.Mismatch=>VerifyState.Mismatch,
            VerifyDecision.NoReservation=>VerifyState.NoReservation,
            _=>VerifyState.Unreadable
        });
        carrier.Fire(CarrierTrigger.PhysicalInstall); // →Installed, 发Installed
        p.Attach(carrier);
        GlobalEvents.AddRange(carrier.Events);
        if(decision!=VerifyDecision.Verified) p.Alarms.Add($"准入异常:{decision} @{lpId}");
        return decision; // 只到 Installed, 绝不自动 Loaded
    }

    // Host 命令：授权装载
    public bool AuthorizeLoad(string lpId)
    {
        var c=_ports[lpId].CarrierRef; if(c==null) return false;
        try { c.Fire(CarrierTrigger.AuthorizeLoad); GlobalEvents.AddRange(c.Events); return c.State==CarrierState.Loaded; }
        catch { return false; } // 守卫不满足(未Verified/有Hold)→非法迁移零副作用
    }
    // Host 命令：卸载
    public bool Unload(string lpId)
    { var c=_ports[lpId].CarrierRef; if(c==null) return false;
      try{ c.Fire(CarrierTrigger.Unload); return c.State==CarrierState.Unloaded;}catch{return false;} }

    // E84 Pickup/在位OFF → 按当前状态分流
    public void OnPhysicalRemoved(string lpId)
    {
        var p=_ports[lpId]; var c=p.CarrierRef; if(c==null) return;
        if(c.State==CarrierState.Loaded)
        {   // 高危：已授权/可能有在途片
            p.Alarms.Add("非正常移除:LOADED在位丢失,中止PJ+账实核对");
            GlobalEvents.Add($"UnexpectedRemoval:{c.CarrierId}@{lpId}");
        }
        c.Fire(CarrierTrigger.PhysicalRemove);
        GlobalEvents.AddRange(c.Events);
        p.Detach();
    }
    public void SetHold(string lpId, HoldState h)=>_ports[lpId].CarrierRef?.SetHold(h);
}
```

public sealed class StubReader : ICarrierIdReader

## 三、对接 W11 E84 的架构图（手绘参考）
```
 W11 HandshakeSimulator(E84硬握手)
   Deposit正常完成(Idle+在位ON) ──► LoadPortManager.OnPhysicalPlaced ──读RFID──►Installed+校验
   Pickup正常完成(在位OFF)      ──► OnPhysicalRemoved(按状态分流正常/非正常)
   E84 SafeHold/EStop           ──✗ 不触发建账(物理不成功,逻辑不建账)
        │
        ▼
 E87: CarrierFsm(四态+守卫) / Reservation / Verify / Hold
        │ 等价 S16F1 事件 / S15F9 命令
        ▼
 Host: 收Installed→校验预约→AuthorizeLoad→Loaded→(E40加工)→Unload→Pickup
```

## 四、今日易错点
1. OnPhysicalPlaced 里直接置 Loaded（必须只到 Installed，等 Host 授权）。
2. 校验器写成有副作用（应纯函数返回决策，便于穷举测试）。
3. 不区分 Installed/Loaded 移除的风险等级（Loaded 要停 PJ+高危核对）。
4. 多口用共享变量存当前 Carrier（必须每口独立对象、显式带 lpId）。
5. Hold 只挡授权不挡取片（取片入口也要查同一 Hold 标志）。
6. E84 异常还触发 E87 建账（只认 E84 正常完成+在位稳定）。
7. AuthorizeLoad 用普通 if 而非状态机守卫（应 PermitIf，非法迁移零副作用、不可绕过）。
8. Unload 不检查 AllJobsFinished（在途片未归位不能卸载）。
