## 四、W13 预热：E84+E87 自动上料综合（30 分钟）

### 1. W13 要做什么
W11 单独学了 E84 硬线握手，W12 单独学了 E87 载具逻辑，W13 把两者**在时间轴上严丝合缝串起来**，实现"AMHS 天车来→自动放盒→自动识别授权→可加工→加工完→自动卸载→天车取走"的无人值守闭环，并处理跨层异常。这是 GEM300 自动物料搬运在设备端的核心集成能力。

### 2. 端到端自动上料链路（先建立全图）
```
①Host 派工：MES 计划 → Host(EAP) 对 LP1 下预约(预期 CarrierID=A)  [E87]
②AMHS 调度：Host 通知搬运系统送 A 到 LP1
③天车到达，E84 Deposit 硬握手放盒（CS/ES/TR_REQ/BUSY/COMPT）     [E84 硬线]
④E84 正常完成 + 在位稳定 ON → 触发 E87 OnPhysicalPlaced          [对接点1]
⑤读 RFID 得 A → E87 Installed 事件上报 Host（S16F1/S6F11）       [E87]
⑥Host 比对预约 A==A 校验通过 → AuthorizeLoad                     [E87]
⑦E87 → LOADED，开放访问                                          [E87]
⑧E90 读 SlotMap（W14 学）→ Host 建 PJ/CJ（E40/E94，W16+）          [E90/任务]
⑨加工（LOADED 期间取放片）
⑩加工完 Host Unload → E87 UNLOADED                               [E87]
⑪Host 通知 AMHS 来取，E84 Pickup 硬握手取走                       [E84 硬线]
⑫E84 完成 + 在位 OFF → E87 OnPhysicalRemoved → NOT_INSTALLED     [对接点2]
⑬Host 更新载具流向，口空可接下一单
```

### 3. 两个关键对接点（W13 重点）
- **对接点1（E84 Deposit 完成 → E87 安装）**：E84 状态机正常回到 Idle 且在位传感器稳定 ON，才调用 E87 OnPhysicalPlaced；E84 SafeHold/EStop 绝不触发。物理成功是逻辑建账的唯一触发源。
- **对接点2（E84 Pickup 完成 → E87 移除）**：E84 正常取走、在位稳定 OFF，才触发 E87 移除；若 E87 还在 LOADED（没 Unload）却检测到在位 OFF，判非正常移除高危。

### 4. 时序咬合的关键约束
- **先预约后到盒**：Host 预约一般早于天车到达；盒到了没预约→准入异常。
- **物理与逻辑顺序不可颠倒**：不能先 LOADED 后等 E84 放盒，也不能盒没授权就开始取片。
- **状态互为前提**：E84 Pickup 需要 E87 先到 UNLOADED（正常下料）；E87 LOADED 需要 E84 先 Deposit 成功。
- **双向异常联动**：E84 故障→E87 不建账/挂起；E87 校验失败→需要再走 E84 把错盒取走。

### 5. 自动 vs 手动模式
- 全自动（Auto）：上述链路无人干预，Host/AMHS 驱动，强校验。
- 手动（Manual/Bypass）：E84 旁路、人工放/取盒，E87 仍要补登记 ID/状态并留痕，保证账实一致。W13 会实现两种模式切换与一致性检查。
