# W12 · Day07 答案

## 一、W12 自测题（10 题）标准答案

### 1. 五类对象 / 手盒片活
五类对象：Carrier（载具）、LoadPort（装载口）、CarrierID（载具标识，RFID）、Reservation（预约）、SlotMap（槽位图，配合 E90），外加 Access State 访问权限。分层：E84 管"手"（物理放取动作安全）、E87 管"盒"（载具状态/ID/预约授权/准入）、E90 管"片"（盒内每片基板槽位位置）、E40/E94 管"活"（加工任务编排）。

### 2. 为何正交状态机 / 四维度
单一状态无法同时表达"生命周期+有没有预约+ID 对不对+能不能访问"，会产生状态爆炸和语义混乱。四正交维度：①Carrier 管理状态（NotInstalled/Installed/Loaded/Unloaded）；②预约状态（Unreserved/Reserved）；③校验状态（Unverified/Verified/Mismatch/Unreadable）；④访问状态（禁止/自动/手动）。主状态迁移由预约、校验、访问维度做守卫。

### 3. 四态含义 / 唯一可取片状态
NotInstalled 口空无盒；Installed 物理在位、已读/在读 ID、等 Host 授权，禁止取片；Loaded 校验授权完成，**唯一允许自动开门取放片、PJ 加工**；Unloaded 访问结束待取走，禁止取片。只有 Loaded 能自动取片。

### 4. 四主迁移触发源与守卫
- NotInstalled→Installed：物理触发（在位 ON，E84 Deposit 完成、去抖），守卫口可用；动作读 ID、发 Installed。
- Installed→Loaded：软件触发（Host AuthorizeLoad），守卫预约匹配+校验 Verified+无 Hold+口正常。
- Loaded→Unloaded：软件触发（Host Unload），守卫所有 PJ 结束、片归位、门关、Hold 解除。
- Unloaded→NotInstalled：物理触发（在位 OFF，E84 Pickup 完成、去抖），动作发 Removed、释放口。

### 5. 预约生命周期 / 防错料
Host 派工前下预约（口+预期 ID）→口 Reserved 保持、不为他盒授权→上料读实际 ID 比对→匹配则授权时兑现预约；盒未到可 Host 取消；长期不到报预约超时；下料也可预约防取错。防错料靠"预期（MES 预约）与现实（RFID 实读）在授权前强制对齐"，不符即 Hold 拦截，绝不加工。

### 6. OSS 消息序列 / ACKC 与 Loaded 区别
序列：S15F9 Reserve→S15F10=0；（E84 就位）S16F1 Installed→S16F2；S15F9 AuthorizeLoad→S15F10=0；S16F1 Loaded；加工；S15F9 Unload→S15F10=0；S16F1 Unloaded；（E84 取走）S16F1 Removed。S15F10 ACKC=0 只表"方法被接受、参数合法"（接受层，状态尚未变）；S16F1 Loaded 表"状态机已实际迁到 Loaded、真正可加工"（完成层）。Host 必须以 Loaded 事件为准，不能拿 ACKC=0 当可加工。

### 7. 传统 GEM 等价表达
预约=S2F41 RCMD=ReserveCarrier（CP 带 LPID/CarrierID），回 S2F42；安装/装载/卸载/移除上报=对应 CEID 的 S6F11 事件报告（先 S2F33 定义报告、S2F35 关联事件）；授权=S2F41 LoadCarrier/SetAccess；卸载=S2F41 UnloadCarrier；查状态=S1F3/F4 读 SVID。OSS 以对象为中心自描述，GEM 以预定义事件/命令为中心，语义等价。

### 8. 六类异常准入/过程 / 判据
准入类（挡在 Loaded 前、盒内未访问、低危）：ID 不匹配、ID 读不到、无预约。过程类（已装载/加工中、可能有在途片、高危）：Hold 扣留、LoadPort 故障、非正常移除。判据：盒内基板是否已被访问或在途——未访问是准入问题（不授权+等纠正），已访问是过程问题（停任务+账实核对+人工）。

### 9. 三种 Hold / 解除 / 门控
Carrier Hold 载具级（针对该 FOUP）、Lot Hold 批次级（MES 对盒内 Lot，影响关联所有载具/任务）、Equipment/Process Hold 设备工艺级（设备故障/工艺条件不满足）。设备不能自行解除，只能由 Hold 下发方（Host/MES/授权质量或工艺工程师）解除。Hold 门控三处：AuthorizeLoad（有 Hold 不能装载授权）、Unload（按级别限制卸载）、ProcessJob 取片入口（有 Hold 不启动/继续取片）。

### 10. LOADED 非正常移除高危 / 设备动作
Loaded 意味着已授权、可能正有片被取到设备内，盒突然消失会造成"片在设备、盒不见"的账实不符，继续动作会撞片丢片。设备：立即中止相关 PJ/运动、冻结取放；强制回 NotInstalled 并标记非正常移除、口回 Empty；发高级告警+事件（口位/ID/PJ/已取片清单）；清点在途基板位置做账实核对；核对清理前锁口；先甄别是否传感器断线。

## 三、W13 预热补充（为综合周打底）
1. **两个对接点是核心**：对接点1=E84 Deposit 正常完成（Idle+在位稳定 ON）才触发 E87 安装；对接点2=E84 Pickup 正常完成（在位稳定 OFF）才触发 E87 移除。E84 异常绝不触发 E87 建账。
2. **顺序不可颠倒**：先预约→E84 放盒→Installed→校验授权→Loaded→E90/任务加工→Unloaded→E84 取盒→移除。物理与逻辑互为前提。
3. **跨层异常联动**：E84 故障则 E87 挂起不建账；E87 校验失败要反向调度 E84 把错盒取走；Loaded 未 Unload 就丢盒按非正常移除高危处理。
4. **自动/手动都要账实一致**：自动链路强校验；手动 Bypass 物理但 E87 必须补登记 ID/状态、留痕；任何时候都能用全量查询做 reconciliation。
5. **多口并行**：每口独立跑完整链路、互不阻塞，上报严格绑定 LoadPortId，W13 Day06 会做多口并发+故障注入大演练。
6. **承上启下**：W13 结束后，物料自动进出设备的"手+盒"就闭环了；W14 起进入 E90，解决盒内"片"的位置跟踪，之后 E40/E94 才知道从哪个 Slot 取、放到哪个 Slot。

## 四、W12 全周易错点汇总
1. 物理在位直接当 Loaded（必须 Installed→校验→Host 授权）。
2. 用单一状态表达正交维度；混 LoadPort 状态与 Carrier 状态。
3. 预约上料后才补、跨口借用预约、多口上报串 ID。
4. 只比 ID 不比对类型/Lot/口位；ID 读不到默认放行。
5. S15F10 ACKC=0 当已 Loaded（以 S16F1 Loaded 为准）。
6. 设备自行 LOADED/自行解 Hold（授权与解 Hold 权在 Host/下发方）。
7. PJ 未结束就 Unload（在途片丢片）。
8. 准入异常当过程异常、或反之（判据=盒内是否已访问）。
9. Loaded 非正常移除当普通移除（高危，停 PJ+核对）。
10. 只发事件不发告警或反之；关键状态事件不走 Spool、重连不对账。
11. E84 没成功 E87 就建账；手动放盒不补登记。
