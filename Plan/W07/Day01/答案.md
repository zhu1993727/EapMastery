# W07 · Day01 答案与参考实现

## 一、自测题标准答案
1. **报警 vs 事件区别 / 报警需要定义报告关联事件吗**：报警（S5F1）是设备**异常状态通知**，告诉 Host"设备出问题了"；事件（S6F11）是设备**状态变化/操作通知 + 数据采集**，告诉 Host"某件事发生了，这是相关数据"。关键区别：①配置方式不同——报警不需要 S2F33 定义报告、S2F35 关联事件，只需要 S5F3 使能/禁用；事件必须先定义报告再关联事件。②body 不同——S5F1 只带 ALID 和 ALTX（报警 ID 和文本），不带变量数据；S6F11 带 DATAID、CEID 和报告列表（包含采集的变量值）。③用途不同——报警是"异常通知"，事件是"数据采集触发器"。报警**不需要**像事件那样先定义报告、关联事件，这是报警机制的设计特点——报警是设备的基础能力，上电后只要使能就能上报，不需要复杂的配置。
2. **报警状态机两种状态 / 状态变化时发什么消息**：报警状态机有两种状态：**SET**（已设置/活动，异常发生）和 **CLEAR**（已清除/非活动，异常恢复）。初始状态为 CLEAR。异常发生时，报警从 CLEAR→SET，设备发 S5F1 通知 Host（报警设置）；异常恢复时，报警从 SET→CLEAR，设备发 S5F1 通知 Host（报警清除）。报警状态变化时设备**主动**发 S5F1，不需要 Host 请求。
3. **S5F3 作用 / ALED=0/=1 / 空 ALID 列表**：S5F3（Enable/Disable Alarm）是 Host 用来**使能或禁用报警**的消息。使能的报警状态变化时才会发 S5F1 上报；禁用的报警即使状态变化也不上报（但设备内部仍记录状态）。ALED（Alarm Enable/Disable）：**0=禁用**，**1=使能**。ALID 列表为空（L,0）表示使能/禁用**全部**报警。设备回 S5F4 ACKC5（0=成功，非0=失败）。
4. **建链后报警相关标准流程**：建链完成后（S1F13/S1F17 之后），Host 报警相关的标准流程：
   1. **查询报警列表**：Host 发 S5F5（空列表=查全部）→ 设备回 S5F6（所有报警的 ALID+ALCD+ALTX），Host 知道设备支持哪些报警。
   2. **使能关心的报警**：Host 发 S5F3（ALED=1, ALID 列表=关心的报警，或空列表=使能全部）→ 设备回 S5F4 ACKC5=0。
   3. **监听报警上报**：设备报警状态变化时主动发 S5F1 → Host 回 S5F2 确认 → Host 处理报警（通知操作员、暂停派工、触发 FDC 等）。
   4. （可选）**维护期间禁用报警**：Host 发 S5F3（ALED=0, ALID 列表=非关键报警）→ 维护完成后重新使能。
5. **禁用的报警设备内部还记录状态吗 / 状态变化时还发 S5F1 吗**：禁用的报警，设备内部**仍然记录状态**（SET/CLEAR），但状态变化时**不发 S5F1**上报。禁用只是"不通知 Host"，不是"不检测报警"。设备内部的报警状态机仍然正常运行，操作员在设备本地仍然能看到报警。当 Host 重新使能该报警时，如果报警当前处于 SET 状态，设备可能立即发一条 S5F1（报警设置）通知 Host（具体以设备实现为准）。这是报警使能/禁用机制的设计——禁用只是屏蔽通知，不影响设备内部状态。
6. **报警设置和清除都发 S5F1，Host 怎么区分**：Host 区分报警设置和清除的方式有几种（具体以设备实现为准）：
   1. **ALCD（报警代码）**：部分设备用 ALCD 的特定位或特定值表示 SET/CLEAR（如 ALCD 的 bit0=1 表示 SET，=0 表示 CLEAR）。
   2. **上下文/状态跟踪**：Host 维护每个 ALID 的当前状态（初始为 CLEAR），收到 S5F1 时，如果当前状态是 CLEAR，则这次是 SET；如果当前状态是 SET，则这次是 CLEAR。这是最可靠的方式，不依赖设备的 ALCD 约定。
   3. **ALTX 文本**：部分设备在 ALTX 中包含"SET"/"CLEAR"或"报警"/"恢复"字样，但这不是标准做法，不建议依赖。
   专家实践：Host 维护 ALID→当前状态的映射表，收到 S5F1 时翻转状态并记录，不依赖 ALCD 或 ALTX 区分 SET/CLEAR。这也是为什么 S5F2 只需要回 ALID（Host 自己知道状态变化）。

## 二、S5 系列消息速查表
| 消息 | 方向 | body | 作用 |
|---|---|---|---|
| S5F1/F2 | E→H / H→E | S5F1: L,2[U4 ALID, A ALTX]（或含 ALCD）；S5F2: U4 ALID | 报警上报/确认 |
| S5F3/F4 | H→E / E→H | S5F3: L,2[U1 ALED, L,n[U4 ALID]]；S5F4: U1 ACKC5 | 使能/禁用报警 |
| S5F5/F6 | H→E / E→H | S5F5: L,n[U4 ALID]（空=全部）；S5F6: L,n[L,3[U4 ALID, U1 ALCD, A ALTX]] | 查询报警列表 |

## 三、参考实现（EapLab.Gem/Alarm/）

### Alarm.cs
```csharp
namespace EapLab.Gem.Alarm;

public enum AlarmState { Clear, Set }

/// <summary>报警定义与状态。</summary>
public sealed class Alarm
{
    public uint AlId { get; }
    public byte AlCd { get; }
    public string AlTx { get; }
    public AlarmState State { get; set; } = AlarmState.Clear;
    public bool Enabled { get; set; } = false; // 默认禁用，Host 使能后才上报

    public Alarm(uint alId, byte alCd, string alTx)
    {
        AlId = alId;
        AlCd = alCd;
        AlTx = alTx;
    }
}
```

### AlarmStore.cs
```csharp
using System.Collections.Concurrent;
using EapLab.Secs2;
using EapLab.Transport.Logging;

namespace EapLab.Gem.Alarm;

/// <summary>报警存储与状态管理。</summary>
public sealed class AlarmStore
{
    private readonly ConcurrentDictionary<uint, Alarm> _alarms = new();
    private readonly ILogSink _log;

    // 报警状态变化事件（上层订阅，用于发 S5F1）
    public event Action<Alarm, AlarmState /*old*/, AlarmState /*new*/>? OnAlarmChanged;

    public AlarmStore(ILogSink log) => _log = log;

    /// <summary>注册设备支持的报警（初始化时调用）。</summary>
    public void Register(uint alId, byte alCd, string alTx)
        => _alarms[alId] = new Alarm(alId, alCd, alTx);

    /// <summary>设置报警（异常发生）。返回是否触发了 S5F1 上报（使能且状态变化）。</summary>
    public bool Set(uint alId)
    {
        if (!_alarms.TryGetValue(alId, out var alarm)) return false;
        if (alarm.State == AlarmState.Set) return false; // 已经是 SET，不重复

        var old = alarm.State;
        alarm.State = AlarmState.Set;
        _log.Log(LogDir.WARN, $"Alarm SET: ALID={alId} {alarm.AlTx}");

        if (alarm.Enabled)
        {
            OnAlarmChanged?.Invoke(alarm, old, AlarmState.Set);
            return true;
        }
        return false; // 禁用，不发 S5F1
    }

    /// <summary>清除报警（异常恢复）。</summary>
    public bool Clear(uint alId)
    {
        if (!_alarms.TryGetValue(alId, out var alarm)) return false;
        if (alarm.State == AlarmState.Clear) return false;

        var old = alarm.State;
        alarm.State = AlarmState.Clear;
        _log.Log(LogDir.INFO, $"Alarm CLEAR: ALID={alId} {alarm.AlTx}");

        if (alarm.Enabled)
        {
            OnAlarmChanged?.Invoke(alarm, old, AlarmState.Clear);
            return true;
        }
        return false;
    }

    /// <summary>使能/禁用报警。返回 ACKC5（0=成功，1=ALID不存在）。</summary>
    public byte SetEnabled(bool enabled, IEnumerable<uint> alIds)
    {
        var ids = alIds.ToList();
        if (ids.Count == 0) ids = _alarms.Keys.ToList(); // 空=全部

        foreach (var id in ids)
        {
            if (!_alarms.TryGetValue(id, out var alarm)) return 1; // ALID 不存在
            alarm.Enabled = enabled;

            // 使能时如果报警当前是 SET，立即触发一次上报（通知 Host 当前有报警）
            if (enabled && alarm.State == AlarmState.Set)
                OnAlarmChanged?.Invoke(alarm, AlarmState.Clear, AlarmState.Set);
        }
        _log.Log(LogDir.INFO, $"Alarm {(enabled ? "enabled" : "disabled")}: [{string.Join(",", ids)}]");
        return 0;
    }

    /// <summary>查询报警列表。空=全部。</summary>
    public IReadOnlyList<Alarm> Query(IEnumerable<uint> alIds)
    {
        var ids = alIds.ToList();
        if (ids.Count == 0) return _alarms.Values.OrderBy(a => a.AlId).ToList();
        return ids.Select(id => _alarms.TryGetValue(id, out var a) ? a : null)
                  .Where(a => a != null).Cast<Alarm>().ToList();
    }

    public Alarm? Get(uint alId) => _alarms.TryGetValue(alId, out var a) ? a : null;
}
```

### 单测
```csharp
public class AlarmStoreTests
{
    private static AlarmStore CreateStore()
    {
        var store = new AlarmStore(new ConsoleLogSink());
        store.Register(1001, 2, "Temperature High");
        store.Register(1002, 1, "Pressure Low");
        return store;
    }

    [Fact]
    public void 设置报警_状态变为SET()
    {
        var store = CreateStore();
        store.SetEnabled(true, new[] { 1001u });
        bool reported = store.Set(1001);
        Assert.True(reported);
        Assert.Equal(AlarmState.Set, store.Get(1001)!.State);
    }

    [Fact]
    public void 清除报警_状态变为CLEAR()
    {
        var store = CreateStore();
        store.SetEnabled(true, new[] { 1001u });
        store.Set(1001);
        bool reported = store.Clear(1001);
        Assert.True(reported);
        Assert.Equal(AlarmState.Clear, store.Get(1001)!.State);
    }

    [Fact]
    public void 禁用报警_状态变化但不上报()
    {
        var store = CreateStore();
        // 默认禁用
        bool reported = store.Set(1001);
        Assert.False(reported); // 禁用，不发 S5F1
        Assert.Equal(AlarmState.Set, store.Get(1001)!.State); // 但内部状态还是 SET
    }

    [Fact]
    public void 查询全部报警()
    {
        var store = CreateStore();
        var all = store.Query(Array.Empty<uint>());
        Assert.Equal(2, all.Count);
    }

    [Fact]
    public void 使能时报警已是SET_立即触发上报()
    {
        var store = CreateStore();
        store.Set(1001); // 禁用时设置，不上报
        bool reported = store.SetEnabled(true, new[] { 1001u }); // 使能时触发上报
        Assert.True(reported); // 使能时报警是 SET，立即上报
    }
}
```

## 四、今日易错点
1. 以为报警需要像事件那样先定义报告、关联事件（报警只需要使能/禁用，不需要 S2F33/S2F35）。
2. 以为禁用的报警设备内部不记录状态（禁用只是不通知，内部状态机仍运行）。
3. 以为 S5F1 只表示报警设置（S5F1 既表示设置也表示清除，Host 靠状态跟踪区分）。
4. 混淆 ALID（报警 ID）和 CEID（事件 ID）——两者是不同体系，ALID 是 U4，CEID 是 U2。
5. 以为 S5F3 空 ALID 列表是错误（空列表=使能/禁用全部报警，是标准用法）。
6. 建链后不查 S5F5 就直接 S5F3 使能（可能引用不存在的 ALID，导致 ACKC5 非 0）。
7. 以为报警和事件完全独立（报警设置/清除时可以触发事件，通过 S6F11 上报更多数据，这是高级用法）。
8. Host 不维护报警状态，靠 ALCD/ALTX 区分 SET/CLEAR（不可靠，应维护 ALID→状态映射表）。
