# W07 · Day05 答案与参考实现

## 一、自测题标准答案
1. **S7F1/F2 vs S7F3/F4 区别 / 场景**：S7F1/F2 是**配方上传**（Host 从设备读取配方）——Host 发 S7F1（指定 PPID），设备回 S7F2（返回 PPID + 配方内容 PPBODY）。场景：Host 需要查看设备上某个配方的内容、备份配方、或对比设备端和 Host 端的配方是否一致。S7F3/F4 是**配方下载**（Host 向设备写入配方）——Host 发 S7F3（指定 PPID + 配方内容），设备回 S7F4（ACKC7 + PPID）。场景：Host 向设备下发新配方、更新已有配方、从 RMS 同步配方到设备。简单说：S7F1/F2 是"读"（设备→Host），S7F3/F4 是"写"（Host→设备）。
2. **S7F3 下载时设备做哪些校验 / 校验失败回什么**：设备收到 S7F3 时通常做 5 项校验：①**PPID 格式校验**（长度、字符集是否符合设备要求）；②**配方内容格式校验**（PPBODY 是否符合设备定义的格式，如文件头、参数结构、校验和）；③**存储空间校验**（设备存储空间是否足够）；④**覆盖策略**（PPID 已存在时是否允许覆盖，部分设备要求先删除再下载）；⑤**配方完整性校验**（多块消息拼接后长度正确、校验和匹配）。校验失败时，设备回 S7F4 ACKC7 非 0（如 1=PPID 格式错误、2=内容格式错误、3=存储空间不足、4=不允许覆盖），并可能在 ERRTEXT 中说明失败原因。
3. **PPBODY 格式 / Host 需要解析吗**：PPBODY（配方内容）是 **B 类型二进制**，格式由设备定义，可以是文本、二进制、JSON、XML 等任意格式。Host **不需要解析配方内容**——Host 只负责存储和传输配方，不理解配方的工艺含义。配方内容由设备解析和执行。Host 可能需要做的是：①存储配方内容（不修改）；②传输配方内容（S7F3 下载、S7F2 上传）；③计算校验和（用于完整性校验，但校验和算法由设备定义）。这是 GEM 设计的解耦——Host 管理配方的"元数据"（PPID、版本、存储），设备管理配方的"内容"（工艺参数、执行逻辑）。
4. **S7F5/F6 vs S7F17/F18 区别 / 推荐用哪个**：S7F5/F6 是**旧版删除配方**消息，一次只能删除一个配方（body=A PPID）。S7F17/F18 是**新版删除配方**消息，一次可以删除多个配方（body=L,n[A PPID, ...]），是 SEMI 标准推荐的删除方式。区别：①S7F17/F18 支持批量删除（效率更高）；②S7F17/F18 的确认消息 S7F18 返回删除的 PPID 列表（更明确）；③S7F5/F6 是早期版本，部分老设备只支持 S7F5/F6。**推荐用 S7F17/F18**（新版、批量、明确），但需要确认设备是否支持（部分老设备可能只支持 S7F5/F6）。专家实践：建链后查询设备能力（S1F3 或设备手册），确认支持哪种删除消息，优先用 S7F17/F18。
5. **配方和 R2R 关系 / R2R 会修改配方主档吗**：配方（基础配方/Base Recipe）存储在 RMS 和设备端，包含工艺的标准参数；R2R（Run-to-Run）控制器根据历史批次的量测数据计算参数偏移量（overlay），用于修正基础配方。**最终执行参数 = 基础配方参数 + R2R 偏移**（例：基础温度 200°C + 偏移 +0.5°C = 执行温度 200.5°C）。**R2R 不会直接修改配方主档**——R2R 偏移是临时的、批次相关的，不修改 RMS 中的基础配方。R2R 偏移通过 EAP 下发给设备（如通过远程命令参数、特定的 S2F41 参数、或 EDA 接口），设备执行时叠加。R2R 偏移和基础配方版本需要对齐（确保偏移是针对该版本配方计算的），并记录审计日志。R2R 的具体实现和 EAP 集成在 M7-M9 进阶阶段细讲。
6. **大配方怎么传输**：大配方（超过单条 SECS-II 消息大小限制，通常是 HSMS 消息体大小限制，如 64KB 或设备定义的上限）通过**多块消息**（Multi-block Message）分片传输。W4 学过多块消息：发送方把大 body 分成多个块，每块带 M 位（More bit）标识是否还有后续块，接收方拼接所有块得到完整 body。S7F2（上传大配方）和 S7F3（下载大配方）都可以用多块消息。Host 下载大配方时，把 PPBODY 分成多块，依次发送 S7F3（每块带 M 位），设备拼接后校验完整性；设备上传大配方时同理。多块消息的拼接和校验在 W4 已实现，今天直接复用。

## 二、参考实现（EapLab.Gem/Recipe/）

### Recipe.cs
```csharp
namespace EapLab.Gem.Recipe;

/// <summary>配方定义与内容。</summary>
public sealed class Recipe
{
    public string PpId { get; }
    public byte[] Body { get; set; }           // 配方内容（二进制，B 类型）
    public DateTime CreatedAt { get; set; }
    public DateTime? ModifiedAt { get; set; }
    public uint Checksum { get; set; }         // 校验和（用于完整性校验）

    public Recipe(string ppId, byte[] body)
    {
        PpId = ppId;
        Body = body;
        CreatedAt = DateTime.Now;
        Checksum = Crc32.Calculate(body);
    }
}

/// <summary>简单 CRC32 校验（实际应使用设备定义的校验算法）。</summary>
internal static class Crc32
{
    public static uint Calculate(byte[] data)
    {
        uint crc = 0xFFFFFFFF;
        foreach (var b in data)
        {
            crc ^= b;
            for (int i = 0; i < 8; i++)
                crc = (crc & 1) != 0 ? (crc >> 1) ^ 0xEDB88320 : crc >> 1;
        }
        return ~crc;
    }
}
```

### RecipeStore.cs
```csharp
using System.Collections.Concurrent;
using EapLab.Transport.Logging;

namespace EapLab.Gem.Recipe;

/// <summary>配方存储：Dictionary<PPID, Recipe>。</summary>
public sealed class RecipeStore
{
    private readonly ConcurrentDictionary<string, Recipe> _recipes = new();
    private readonly ILogSink _log;
    private readonly int _maxRecipeCount = 100;  // 最大配方数量（设备定义）
    private readonly int _maxRecipeSize = 64 * 1024; // 最大配方大小 64KB（设备定义）

    public RecipeStore(ILogSink log) => _log = log;

    /// <summary>下载配方（新增或覆盖）。返回 ACKC7（0=成功，非0=失败）。</summary>
    public byte Download(string ppId, byte[] body)
    {
        // 1. PPID 格式校验
        if (string.IsNullOrEmpty(ppId) || ppId.Length > 8 || !ppId.All(char.IsLetterOrDigit))
            return 1; // ACKC7=1: PPID 格式错误

        // 2. 存储空间校验
        if (body.Length > _maxRecipeSize)
            return 3; // ACKC7=3: 配方太大

        if (!_recipes.ContainsKey(ppId) && _recipes.Count >= _maxRecipeCount)
            return 3; // ACKC7=3: 存储空间不足

        // 3. 存储（新增或覆盖）
        var recipe = new Recipe(ppId, body);
        if (_recipes.ContainsKey(ppId))
        {
            recipe.ModifiedAt = DateTime.Now;
            _log.Log(LogDir.INFO, $"Recipe overwritten: PPID={ppId} size={body.Length}");
        }
        else
        {
            _log.Log(LogDir.INFO, $"Recipe created: PPID={ppId} size={body.Length}");
        }
        _recipes[ppId] = recipe;
        return 0; // ACKC7=0: 成功
    }

    /// <summary>上传配方（读取）。返回配方内容，不存在返回 null。</summary>
    public byte[]? Upload(string ppId)
        => _recipes.TryGetValue(ppId, out var recipe) ? recipe.Body : null;

    /// <summary>删除配方。返回 ACKC7（0=成功，1=不存在）。</summary>
    public byte Delete(string ppId)
    {
        if (!_recipes.TryRemove(ppId, out _))
            return 1; // ACKC7=1: PPID 不存在
        _log.Log(LogDir.INFO, $"Recipe deleted: PPID={ppId}");
        return 0;
    }

    public bool Exists(string ppId) => _recipes.ContainsKey(ppId);
    public IReadOnlyList<string> GetAll PpIds() => _recipes.Keys.OrderBy(k => k).ToList();
}
```

### S7F1Handler.cs（配方上传）
```csharp
using EapLab.Secs2;
using EapLab.Transport.Logging;

namespace EapLab.Gem.Recipe;

/// <summary>S7F1 配方上传处理器（Host 从设备读取配方）。</summary>
public sealed class S7F1Handler
{
    private readonly RecipeStore _store;
    private readonly ILogSink _log;

    public S7F1Handler(RecipeStore store, ILogSink log)
    {
        _store = store;
        _log = log;
    }

    /// <summary>处理 S7F1，返回 S7F2 body（L,2[A PPID, B PPBODY]）。配方不存在返回 null（调用方回 S9）。</summary>
    public SecsItem? Handle(SecsItem? body)
    {
        if (body is not SecsA ppIdItem)
            return null; // 格式错误，回 S9
        string ppId = ppIdItem.Value;

        var recipeBody = _store.Upload(ppId);
        if (recipeBody == null)
        {
            _log.Log(LogDir.WARN, $"Recipe upload failed: PPID={ppId} not found");
            return null; // PPID 不存在，回 S9F3 或 S7F2 带空 body（设备实现相关）
        }

        _log.Log(LogDir.INFO, $"Recipe uploaded: PPID={ppId} size={recipeBody.Length}");
        // 大配方应使用多块消息分片传输（W4 已实现，这里简化为单块）
        return SecsItem.L(SecsItem.A(ppId), SecsItem.B(recipeBody));
    }
}
```

### S7F3Handler.cs（配方下载）
```csharp
namespace EapLab.Gem.Recipe;

/// <summary>S7F3 配方下载处理器（Host 向设备写入配方）。</summary>
public sealed class S7F3Handler
{
    private readonly RecipeStore _store;
    private readonly ILogSink _log;

    public S7F3Handler(RecipeStore store, ILogSink log)
    {
        _store = store;
        _log = log;
    }

    /// <summary>处理 S7F3，返回 S7F4 body（L,2[U1 ACKC7, A PPID]）。</summary>
    public SecsItem Handle(SecsItem? body)
    {
        if (body is not SecsList root || root.Items.Count != 2)
            return Reply(1, ""); // 格式错误

        if (root.Items[0] is not SecsA ppIdItem)
            return Reply(1, "");
        string ppId = ppIdItem.Value;

        if (root.Items[1] is not SecsB bodyItem)
            return Reply(1, ppId);
        byte[] recipeBody = bodyItem.Value;

        byte ackc7 = _store.Download(ppId, recipeBody);
        return Reply(ackc7, ppId);
    }

    private static SecsItem Reply(byte ackc7, string ppId)
        => SecsItem.L(SecsItem.U1(ackc7), SecsItem.A(ppId));
}
```

### S7F17Handler.cs（删除配方，新版批量）
```csharp
namespace EapLab.Gem.Recipe;

/// <summary>S7F17 删除配方处理器（新版，批量删除）。</summary>
public sealed class S7F17Handler
{
    private readonly RecipeStore _store;

    public S7F17Handler(RecipeStore store) => _store = store;

    /// <summary>处理 S7F17，返回 S7F18 body（L,2[U1 ACKC7, L,n[A PPID]]）。</summary>
    public SecsItem Handle(SecsItem? body)
    {
        var ppIds = new List<string>();
        if (body is SecsList list)
        {
            foreach (var item in list.Items)
            {
                if (item is SecsA a) ppIds.Add(a.Value);
            }
        }

        byte ackc7 = 0;
        var deleted = new List<string>();
        foreach (var ppId in ppIds)
        {
            byte result = _store.Delete(ppId);
            if (result != 0) ackc7 = result; // 有失败则标记（简化：取最后一个失败码）
            else deleted.Add(ppId);
        }

        return SecsItem.L(
            SecsItem.U1(ackc7),
            SecsItem.L(deleted.Select(d => SecsItem.A(d)).ToArray())
        );
    }
}
```

### 单测（节选）
```csharp
public class RecipeTests
{
    private static (S7F1Handler, S7F3Handler, S7F17Handler, RecipeStore) CreateHandlers()
    {
        var log = new ConsoleLogSink();
        var store = new RecipeStore(log);
        return (new S7F1Handler(store, log), new S7F3Handler(store, log), new S7F17Handler(store), store);
    }

    [Fact]
    public void 下载新配方_成功()
    {
        var (_, f3, _, store) = CreateHandlers();
        var body = SecsItem.L(SecsItem.A("RCP001"), SecsItem.B(new byte[] { 1, 2, 3 }));
        var reply = f3.Handle(body);
        var list = (SecsList)reply;
        Assert.Equal(0, ((SecsU1)list.Items[0]).Values[0]); // ACKC7=0
        Assert.True(store.Exists("RCP001"));
    }

    [Fact]
    public void 下载已存在配方_覆盖()
    {
        var (_, f3, _, store) = CreateHandlers();
        f3.Handle(SecsItem.L(SecsItem.A("RCP001"), SecsItem.B(new byte[] { 1, 2, 3 })));
        // 覆盖
        var reply = f3.Handle(SecsItem.L(SecsItem.A("RCP001"), SecsItem.B(new byte[] { 4, 5, 6 })));
        Assert.Equal(0, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
        Assert.Equal(new byte[] { 4, 5, 6 }, store.Upload("RCP001"));
    }

    [Fact]
    public void 上传不存在配方_返回null()
    {
        var (f1, _, _, _) = CreateHandlers();
        var reply = f1.Handle(SecsItem.A("NOT_EXIST"));
        Assert.Null(reply);
    }

    [Fact]
    public void 删除配方_成功()
    {
        var (_, f3, f17, store) = CreateHandlers();
        f3.Handle(SecsItem.L(SecsItem.A("RCP001"), SecsItem.B(new byte[] { 1 })));
        var reply = f17.Handle(SecsItem.L(SecsItem.A("RCP001")));
        var list = (SecsList)reply;
        Assert.Equal(0, ((SecsU1)list.Items[0]).Values[0]);
        Assert.False(store.Exists("RCP001"));
    }

    [Fact]
    public void PPID格式错误_ACKC7_1()
    {
        var (_, f3, _, _) = CreateHandlers();
        var body = SecsItem.L(SecsItem.A("INVALID PPID!"), SecsItem.B(new byte[] { 1 })); // 含空格和感叹号
        var reply = f3.Handle(body);
        Assert.Equal(1, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
    }
}
```

## 三、今日易错点
1. 混淆 S7F1/F2（上传/读）和 S7F3/F4（下载/写）——方向搞反。
2. 以为 Host 需要解析配方内容（Host 只存储和传输，不解析工艺内容）。
3. S7F3 下载时不校验 PPID 格式和存储空间（应校验，失败回 ACKC7 非 0）。
4. 以为 S7F5/F6 和 S7F17/F18 完全一样（S7F17/F18 支持批量删除，推荐用新版）。
5. 大配方不用多块消息分片（超过单条消息大小限制时必须用多块消息，W4 已实现）。
6. 以为 R2R 直接修改配方主档（R2R 只下发偏移，不修改基础配方，最终参数=基础+偏移）。
7. S7F2 上传不存在的配方时回空 body（应回 S9 错误或特定错误码，具体以设备实现为准，不能静默返回空）。
8. 配方下载覆盖时不记录修改时间（应记录 ModifiedAt，用于版本管理和审计）。
