# W07 · Day04 答案与参考实现

## 一、自测题标准答案
1. **S2F41Handler 完整处理流程 / 经过哪些校验**：①解析 S2F41 body（L,2[A RCMD, L,n[L,2[A CPNAME, CPVALUE]]]）→ ②状态校验（通信/控制 ON-LINE？否则回 ACKC10=4）→ ③命令名校验（RCMD 在 CommandDefinitionStore 中？否则回 ACKC10=1）→ ④参数校验（遍历参数，CPNAME 在命令定义中？CPVALUE 类型匹配？必填参数都有？否则回 ACKC10=3）→ ⑤设备状态校验（设备忙/报警/Hold？否则回 ACKC10=2 或 5，或排队）→ ⑥入队（调用 RemoteCommandEngine.Enqueue，返回 ACKC10=0）→ ⑦回 S2F42（L,2[U1 ACKC10, A ERRTEXT]）。关键：校验顺序是"先状态、再命令名、再参数、再设备状态"，任何一步失败都回对应的 ACKC10，不继续后续校验。
2. **命令定义表作用 / 为什么需要**：命令定义表（CommandDefinitionStore）告诉 S2F41Handler 设备支持哪些 RCMD、每个命令有哪些参数（CPNAME）、每个参数的类型、哪些参数必填。作用：①命令名校验——判断 RCMD 是否设备支持（不支持回 ACKC10=1）；②参数名校验——判断 CPNAME 是否该命令的合法参数（不认识回 ACKC10=3）；③参数类型校验——判断 CPVALUE 的 SECS-II 类型是否与定义匹配（类型错回 ACKC10=3）；④必填参数校验——判断必填参数是否都提供了（缺失回 ACKC10=3）。没有命令定义表，S2F41Handler 无法校验命令和参数，只能盲目接受所有命令，可能导致执行错误或安全问题。
3. **S2F42 body 结构 / ACKC10=0/1/3/4 含义**：S2F42 body = `L,2[U1 ACKC10, A ERRTEXT]`（部分设备只回 U1 ACKC10）。ACKC10：**0=命令已接受**（已接受并排队，将异步执行）；**1=命令不认识**（RCMD 设备不支持）；**3=参数错误**（CPNAME 不认识或 CPVALUE 类型/范围错误，或缺必填参数）；**4=设备 OFF-LINE**（通信或控制 OFF-LINE，拒绝远程命令）。其他值：2=命令不能执行（设备状态不允许）、5=设备忙（队列满）。
4. **命令状态变化时怎么通过 S6F11 通知 Host / 需要预先配置什么**：命令状态变化时，RemoteCommandEngine 触发 OnCommandStateChanged 事件，CommandEventBridge 订阅该事件，根据新状态调用 EventReportEngine.TriggerEvent(ceid) 触发对应的事件（命令开始/完成/失败），EventReportEngine 查关联报告、采集变量、组装并发送 S6F11。需要预先配置：①Host 通过 S2F33 定义报告（包含命令相关的 DV，如命令名、命令 ID、失败原因）；②Host 通过 S2F35 关联事件（命令开始/完成/失败的 CEID 关联到报告）；③设备端实现 CommandEventBridge 桥接。如果没配置，命令状态变化时不会发 S6F11（EventReportEngine.TriggerEvent 查不到关联就跳过）。
5. **Host 收到 ACKC10=0 但命令很久没完成怎么排查**：①**命令是否在排队**：设备是否忙？队列中是否有其他命令在前面？（查询设备状态 SV）②**命令是否在执行**：设备是否正在执行该命令？执行时间是否正常？（查询命令状态 SV，或看设备本地显示）③**命令完成事件是否配置**：Host 是否通过 S2F33/S2F35 定义并关联了"命令完成"事件？（没配置就收不到 S6F11，但命令可能已经完成了）④**S6F11 是否发出**：设备端抓包/日志，看命令完成时是否发了 S6F11？（发出了但 Host 没收到=通信问题，没发出=配置问题）⑤**S6F12 是否回了**：Host 是否回了 S6F12？（不回可能导致设备重发或状态异常）⑥**命令是否被中断**：命令执行过程中是否触发报警/Hold？（报警可能中断命令，进入 FAILED 状态，触发"命令失败"事件而不是"命令完成"）⑦**主动查询**：Host 发 S1F11 查询命令状态相关的 SV，确认命令当前状态。
6. **CPNAME 不认识 vs CPVALUE 类型错误分别回什么 ACKC10**：都回 **ACKC10=3（参数错误）**。ACKC10=3 是一个通用的"参数错误"码，涵盖：①CPNAME 不认识（参数名不在命令定义中）；②CPVALUE 类型错误（参数值的 SECS-II 类型与定义不匹配）；③CPVALUE 范围错误（参数值超出允许范围）；④必填参数缺失。Host 收到 ACKC10=3 后，需要看 ERRTEXT（如果设备提供了）或设备日志判断具体是哪种参数错误，修正后重新发送。部分设备实现更细的 ACKC10 值区分不同参数错误，但标准是统一用 3。

```csharp
namespace EapLab.Gem.RemoteCommand;

/// <summary>命令参数定义。</summary>
public sealed class CommandParameterDefinition
{
    public string CpName { get; }
    public Type ExpectedType { get; }  // 期望的 SecsItem 类型（如 typeof(SecsA), typeof(SecsU2)）
    public bool Required { get; }

    public CommandParameterDefinition(string cpName, Type expectedType, bool required = true)
    {
        CpName = cpName;
        ExpectedType = expectedType;
        Required = required;
    }
}

/// <summary>命令定义：RCMD + 参数定义列表。</summary>
public sealed class CommandDefinition
{
    public string Rcmd { get; }
    public IReadOnlyDictionary<string, CommandParameterDefinition> Parameters { get; }

    public CommandDefinition(string rcmd, IEnumerable<CommandParameterDefinition> parameters)
    {
        Rcmd = rcmd;
        Parameters = parameters.ToDictionary(p => p.CpName);
    }
}
```

### CommandDefinitionStore.cs
```csharp
using System.Collections.Concurrent;

namespace EapLab.Gem.RemoteCommand;

/// <summary>命令定义存储：设备支持哪些远程命令。</summary>
public sealed class CommandDefinitionStore
{
    private readonly ConcurrentDictionary<string, CommandDefinition> _commands = new();

    public void Register(CommandDefinition def) => _commands[def.Rcmd] = def;

    public bool TryGet(string rcmd, out CommandDefinition? def)
        => _commands.TryGetValue(rcmd, out def);

    /// <summary>预定义标准命令（初始化时调用）。</summary>
    public void RegisterStandardCommands()
    {
        Register(new CommandDefinition("START", new[]
        {
            new CommandParameterDefinition("LOTID", typeof(SecsA), required: true),
            new CommandParameterDefinition("RECIPE", typeof(SecsA), required: true),
            new CommandParameterDefinition("QUANTITY", typeof(SecsU2), required: false),
        }));
        Register(new CommandDefinition("STOP", Array.Empty<CommandParameterDefinition>()));
        Register(new CommandDefinition("PAUSE", Array.Empty<CommandParameterDefinition>()));
        Register(new CommandDefinition("RESUME", Array.Empty<CommandParameterDefinition>()));
        Register(new CommandDefinition("ABORT", Array.Empty<CommandParameterDefinition>()));
    }
}
```

### S2F41Handler.cs
```csharp
using EapLab.Secs2;
using EapLab.Transport.Logging;

namespace EapLab.Gem.RemoteCommand;

/// <summary>S2F41 远程命令处理器。</summary>
public sealed class S2F41Handler
{
    private readonly CommandDefinitionStore _defStore;
    private readonly RemoteCommandEngine _engine;
    private readonly ILogSink _log;
    private readonly Func<bool> _canAcceptCommands; // 设备是否允许接受命令（控制 ON-LINE、无报警等）

    public S2F41Handler(CommandDefinitionStore defStore, RemoteCommandEngine engine,
                         ILogSink log, Func<bool> canAcceptCommands)
    {
        _defStore = defStore;
        _engine = engine;
        _log = log;
        _canAcceptCommands = canAcceptCommands;
    }

    /// <summary>处理 S2F41，返回 S2F42 body（L,2[U1 ACKC10, A ERRTEXT]）。</summary>
    public SecsItem Handle(SecsItem? body)
    {
        // 1. 解析 body
        if (body is not SecsList root || root.Items.Count != 2)
            return Reply(1, "Invalid S2F41 body format");

        if (root.Items[0] is not SecsA rcmdItem)
            return Reply(1, "RCMD must be ASCII");
        string rcmd = rcmdItem.Value;

        if (root.Items[1] is not SecsList paramList)
            return Reply(3, "Parameter list must be List");

        // 2. 状态校验
        if (!_canAcceptCommands())
            return Reply(4, $"Equipment OFF-LINE, command '{rcmd}' rejected");

        // 3. 命令名校验
        if (!_defStore.TryGet(rcmd, out var def) || def == null)
            return Reply(1, $"Unknown command: {rcmd}");

        // 4. 解析并校验参数
        var parameters = new Dictionary<string, SecsItem>();
        foreach (var item in paramList.Items)
        {
            if (item is not SecsList pair || pair.Items.Count != 2)
                return Reply(3, "Parameter must be L,2[CPNAME, CPVALUE]");
            if (pair.Items[0] is not SecsA cpNameItem)
                return Reply(3, "CPNAME must be ASCII");
            string cpName = cpNameItem.Value;
            SecsItem cpValue = pair.Items[1];

            // 参数名校验
            if (!def.Parameters.ContainsKey(cpName))
                return Reply(3, $"Unknown parameter: {cpName} for command {rcmd}");

            // 参数类型校验
            var paramDef = def.Parameters[cpName];
            if (cpValue.GetType() != paramDef.ExpectedType)
                return Reply(3, $"Parameter {cpName} type mismatch: expected {paramDef.ExpectedType.Name}, got {cpValue.GetType().Name}");

            parameters[cpName] = cpValue;
        }

        // 必填参数校验
        foreach (var paramDef in def.Parameters.Values.Where(p => p.Required))
        {
            if (!parameters.ContainsKey(paramDef.CpName))
                return Reply(3, $"Missing required parameter: {paramDef.CpName} for command {rcmd}");
        }

        // 5. 入队
        byte ackc10 = _engine.Enqueue(rcmd, parameters);
        if (ackc10 != 0)
            return Reply(ackc10, $"Command '{rcmd}' rejected: ACKC10={ackc10}");

        _log.Log(LogDir.INFO, $"S2F41 accepted: RCMD={rcmd}, params=[{string.Join(",", parameters.Keys)}]");
        return Reply(0, "Command accepted");
    }

    private static SecsItem Reply(byte ackc10, string errText)
        => SecsItem.L(SecsItem.U1(ackc10), SecsItem.A(errText));
}
```

### CommandEventBridge.cs
```csharp
using EapLab.Gem.DataCollection;

namespace EapLab.Gem.RemoteCommand;

/// <summary>命令状态变化→S6F11 事件通知桥接。</summary>
public sealed class CommandEventBridge
{
    private readonly RemoteCommandEngine _engine;
    private readonly EventReportEngine _eventEngine;

    // 命令状态→事件 CEID 映射（可配置）
    public ushort CommandStartCeid { get; set; } = 3101;
    public ushort CommandCompleteCeid { get; set; } = 3102;
    public ushort CommandFailCeid { get; set; } = 3103;

    public CommandEventBridge(RemoteCommandEngine engine, EventReportEngine eventEngine)
    {
        _engine = engine;
        _eventEngine = eventEngine;
        _engine.OnCommandStateChanged += OnCommandStateChanged;
    }

    private void OnCommandStateChanged(RemoteCommand cmd, CommandState oldState, CommandState newState)
    {
        ushort? ceid = newState switch
        {
            CommandState.Executing => CommandStartCeid,    // PENDING→EXECUTING
            CommandState.Completed => CommandCompleteCeid,  // EXECUTING→COMPLETED
            CommandState.Failed => CommandFailCeid,         // EXECUTING→FAILED
            _ => null
        };

        if (ceid.HasValue)
        {
            // 触发事件，EventReportEngine 会查关联报告、采集变量、组装并发送 S6F11
            // 注意：命令相关的 DV（如命令名、失败原因）需要在变量提供者中实现
            _eventEngine.TriggerEvent(ceid.Value);
        }
    }
}
```

### 单测（节选）
```csharp
public class S2F41HandlerTests
{
    private static S2F41Handler CreateHandler(bool canAccept = true)
    {
        var defStore = new CommandDefinitionStore();
        defStore.RegisterStandardCommands();
        var engine = new RemoteCommandEngine(new FakeExecutor(), new ConsoleLogSink());
        return new S2F41Handler(defStore, engine, new ConsoleLogSink(), () => canAccept);
    }

    [Fact]
    public void 合法命令_ACKC10_0()
    {
        var handler = CreateHandler();
        var body = SecsItem.L(
            SecsItem.A("START"),
            SecsItem.L(
                SecsItem.L(SecsItem.A("LOTID"), SecsItem.A("LOT001")),
                SecsItem.L(SecsItem.A("RECIPE"), SecsItem.A("RCP_A"))
            )
        );
        var reply = handler.Handle(body);
        var list = (SecsList)reply;
        Assert.Equal(0, ((SecsU1)list.Items[0]).Values[0]);
    }

    [Fact]
    public void 不认识的RCMD_ACKC10_1()
    {
        var handler = CreateHandler();
        var body = SecsItem.L(SecsItem.A("UNKNOWN_CMD"), SecsItem.L());
        var reply = handler.Handle(body);
        Assert.Equal(1, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
    }

    [Fact]
    public void 缺少必填参数_ACKC10_3()
    {
        var handler = CreateHandler();
        var body = SecsItem.L(
            SecsItem.A("START"),
            SecsItem.L(SecsItem.L(SecsItem.A("LOTID"), SecsItem.A("LOT001"))) // 缺 RECIPE
        );
        var reply = handler.Handle(body);
        Assert.Equal(3, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
    }

    [Fact]
    public void OFFLINE_ACKC10_4()
    {
        var handler = CreateHandler(canAccept: false);
        var body = SecsItem.L(SecsItem.A("START"), SecsItem.L());
        var reply = handler.Handle(body);
        Assert.Equal(4, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
    }

    [Fact]
    public void 参数类型错误_ACKC10_3()
    {
        var handler = CreateHandler();
        var body = SecsItem.L(
            SecsItem.A("START"),
            SecsItem.L(
                SecsItem.L(SecsItem.A("LOTID"), SecsItem.U2(123)), // LOTID 应该是 A，给了 U2
                SecsItem.L(SecsItem.A("RECIPE"), SecsItem.A("RCP_A"))
            )
        );
        var reply = handler.Handle(body);
        Assert.Equal(3, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
    }
}
```

## 三、今日易错点
1. S2F41 body 结构记错（是 L,2[A RCMD, L,n[L,2[A CPNAME, CPVALUE]]]，参数是 L,2 不是 L,1）。
2. 校验顺序错（应先状态、再命令名、再参数、再设备状态，任何一步失败都回对应 ACKC10）。
3. 以为 ACKC10=0 表示命令执行成功（只表示已接受排队，执行结果靠 S6F11 事件）。
4. CPNAME 不认识和 CPVALUE 类型错误回不同 ACKC10（都回 3，参数错误是通用码）。
5. 命令状态变化时没触发 S6F11（需要 CommandEventBridge 桥接，且 Host 预先配置事件/报告）。
6. 命令定义表没预定义标准命令（START/STOP/PAUSE 等，应在初始化时注册）。
7. 参数类型校验用错（应比较 SecsItem 的具体类型，如 typeof(SecsA)、typeof(SecsU2)，不是比较 TypeCode）。
8. 以为 S2F42 只回 U1 ACKC10（标准实现是 L,2[U1 ACKC10, A ERRTEXT]，ERRTEXT 提供错误描述）。
