## 二、背景知识（先读，15 分钟）

### 1. S2F41 body 解析（复习）
```
S2F41 body = L,2[
  A RCMD,                      // 命令名（如 "START", "STOP"）
  L,n[                         // 参数列表（n 个参数）
    L,2[
      A CPNAME,                // 参数名（如 "LOTID", "RECIPE"）
      <CPVALUE>                // 参数值（类型由参数定义决定）
    ], ...
  ]
]
```
- 解析步骤：①取 RCMD（A 类型）；②遍历参数列表，每个参数是 L,2[A CPNAME, CPVALUE]；③校验 CPNAME 是否在命令定义中、CPVALUE 类型是否匹配。

### 2. S2F42 body（复习）
```
S2F42 body = L,2[
  U1 ACKC10,                  // 命令接受/拒绝结果（0=接受，非0=拒绝）
  A ERRTEXT                    // 错误描述（可选，部分设备实现）
]
```
- 部分设备实现为 L,2[U1 ACKC10, A ERRTEXT]，部分只回 U1 ACKC10。今天实现 L,2 版本。

### 3. 命令定义表设计
设备需要维护一个命令定义表，告诉 S2F41Handler：
- 支持哪些 RCMD（如 START、STOP、PAUSE、RESUME、ABORT）
- 每个命令有哪些参数（CPNAME）
- 每个参数的类型（如 LOTID=A, RECIPE=A, QUANTITY=U2）
- 每个参数是否必填

```
CommandDefinition {
  string Rcmd;
  Dictionary<string, Type> Parameters; // CPNAME → 参数类型
  List<string> RequiredParameters;     // 必填参数
}
```

### 4. 命令状态变化→S6F11 桥接
- RemoteCommandEngine 有 OnCommandStateChanged 事件（命令状态变化时触发）。
- EventReportEngine 有 TriggerEvent(ceid) 方法（触发事件，组装并发送 S6F11）。
- 桥接：订阅 OnCommandStateChanged，根据新状态触发对应的事件：
  - PENDING→EXECUTING → 触发"命令开始"事件（CEID=命令开始）
  - EXECUTING→COMPLETED → 触发"命令完成"事件（CEID=命令完成）
  - EXECUTING→FAILED → 触发"命令失败"事件（CEID=命令失败）
- 事件报告中可以包含命令相关的 DV（如命令名、命令 ID、失败原因）。
