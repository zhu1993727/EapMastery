## 三、综合场景流程（必背）

### 场景1：正常执行
```
Host:  建链完成（W5 流程）
Host:  S5F3 使能报警（ALED=1, 空=全部）→ S5F4 ACKC5=0
Host:  S7F3 下载配方（PPID="RCP_A", PPBODY=工艺参数）→ S7F4 ACKC7=0
Host:  S2F41 START（参数：LOTID="LOT001", RECIPE="RCP_A", QUANTITY=25）
Equip: S2F42 ACKC10=0（命令已接受，PENDING）
Equip: 命令开始执行（EXECUTING）→ 触发"命令开始"事件→ S6F11
Equip: 加载配方 RCP_A → 模拟工艺执行（25 片，每片 100ms）
Equip: 工艺执行完成 → 命令 COMPLETED → 触发"命令完成"事件→ S6F11
Host:  收到命令完成事件，回 S6F12
✓ 场景1通过
```

### 场景2：报警中断
```
Host:  建链→使能报警→下载配方 RCP_A→START（LOT001, RCP_A, 25）
Equip: 命令开始执行（EXECUTING）→ S6F11 命令开始
Equip: 执行到第 10 片时，模拟温度过高（>250°C）
Equip: 设置报警 ALID=1001（Temperature High）→ 报警状态 SET → S5F1 上报
Host:  收到 S5F1，回 S5F2，通知操作员
Equip: 报警中断命令 → 命令 FAILED（失败原因="Temperature High, interrupted"）
Equip: 触发"命令失败"事件→ S6F11（含失败原因）
Host:  收到命令失败事件，回 S6F12，记录失败
✓ 场景2通过
```

### 场景3：配方不存在
```
Host:  建链→使能报警（不下载配方，或下载其他配方）
Host:  S2F41 START（参数：LOTID="LOT002", RECIPE="NOT_EXIST", QUANTITY=10）
Equip: 校验参数→RECIPE="NOT_EXIST" 不存在→ ACKC10=3（参数错误）
Host:  收到 ACKC10=3，知道配方不存在，修正后重试
✓ 场景3通过
```

### 场景4：报警使能/禁用
```
Host:  建链→S5F3 禁用报警（ALED=0, 空=全部）→ S5F4 ACKC5=0
Equip: 触发报警 ALID=1001 → 报警状态 SET，但禁用→不发 S5F1
Host:  收不到 S5F1（正常，因为禁用了）
Host:  S5F3 使能报警（ALED=1, 空=全部）→ S5F4 ACKC5=0
Equip: 报警当前是 SET → 使能时立即触发 S5F1（通知 Host 当前有报警）
Host:  收到 S5F1，回 S5F2
✓ 场景4通过
```

## 四、FakeEquipment 设计要点
- 实现 ICommandExecutor 接口（W7 Day03 定义）。
- Execute 方法：
  1. 解析命令参数（LOTID、RECIPE、QUANTITY）。
  2. 校验 RECIPE 存在（RecipeStore.Exists）。
  3. 加载配方（RecipeStore.Upload）。
  4. 模拟工艺执行（循环 QUANTITY 次，每次 Sleep 100ms）。
  5. 可注入"报警触发点"（如执行到第 N 片时触发报警）。
  6. 报警触发时设置报警（AlarmStore.Set），返回失败。
- IsBusy：正在执行命令时返回 true。
- CanAcceptCommands：控制 ON-LINE 且无严重报警时返回 true。
