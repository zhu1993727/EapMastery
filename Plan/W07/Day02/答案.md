# W07 · Day02 答案与参考实现

## 一、自测题标准答案
1. **S5F1 是谁发的 / W位 / 对端回什么**：S5F1 是**设备主动发给 Host**的（Equipment → Host），不是 Host 发的。W 位 = 1（需要对端回 reply）。Host 收到 S5F1 后回 **S5F2**（Alarm Report Acknowledge），body = U4 ALID（确认收到的报警 ID）。S5F1 是报警上报的唯一消息，设备报警状态变化（SET/CLEAR）时主动发送，不需要 Host 请求。
2. **报警状态变化时触发 S5F1 的完整流程**：①设备内部检测到异常（如温度超过阈值）→ ②调用 AlarmStore.Set(ALID) → ③AlarmStore 检查报警存在且当前状态不是 SET → 状态变为 SET → ④检查报警已使能（Enabled=true）→ 触发 OnAlarmChanged 事件 → ⑤S5F1Sender 订阅 OnAlarmChanged 事件 → ⑥组装 S5F1 body = L,2[U4 ALID, A ALTX] → ⑦通过 HsmsConnection 发送 S5F1（W=1，SystemBytes 由连接分配）→ ⑧Host 收到 S5F1，解析 ALID/ALTX，更新本地报警状态 → ⑨Host 回 S5F2（U4 ALID）→ ⑩设备收到 S5F2，确认上报完成，清除重发定时器。清除报警（异常恢复）时流程相同，只是调用 AlarmStore.Clear(ALID)，状态从 SET→CLEAR。
3. **S5F3 body 结构 / ALED=0/=1 / 空 ALID 列表**：S5F3 body = `L,2[U1 ALED, L,n[U4 ALID, ...]]`。ALED（Alarm Enable/Disable）：**0=禁用**（禁用指定的报警，状态变化时不上报 S5F1），**1=使能**（使能指定的报警，状态变化时上报 S5F1）。ALID 列表为空（L,0）表示使能/禁用**全部**报警。设备回 S5F4 body = U1 ACKC5（0=成功，非0=失败，如 ALID 不存在）。
4. **S5F6 body 结构 / 每个报警包含哪些字段**：S5F6 body = `L,n[L,3[U4 ALID, U1 ALCD, A ALTX], ...]`。每个报警包含 3 个字段：①**ALID**（U4，报警唯一标识）；②**ALCD**（U1，报警代码，表示报警类型/严重程度，如 1=警告、2=严重、3=紧急）；③**ALTX**（A，报警描述文本，人类可读）。n 是查询到的报警数量，与 S5F5 请求的 ALID 列表对应（空列表=全部）。
5. **设备主动发消息 vs Host 发消息的处理流程区别**：①**触发方式不同**——设备主动发消息（S5F1/S6F11）由设备内部事件触发（报警状态变化、事件发生），不需要 Host 请求；Host 发消息（S5F3/S5F5/S2F33 等）由 Host 主动发起，设备被动响应。②**SystemBytes 分配不同**——Host 发消息时 SystemBytes 由 Host 分配，设备回 reply 时用相同的 SystemBytes；设备主动发消息时 SystemBytes 由设备分配，Host 回确认时用相同的 SystemBytes。③**等待确认不同**——设备主动发消息（W=1）需要等待 Host 回确认（S5F2/S6F12），有超时重发机制；Host 发消息（W=1）需要等待设备回 reply，也有超时机制。④**处理管线不同**——Host 发的消息进入设备的"请求处理管线"（Stream/Function 分发到 Handler，返回 reply）；设备主动发的消息进入"主动发送管线"（事件触发→组装→发送→等待确认）。
6. **Host 没回 S5F2 时设备怎么做**：标准做法是**超时重发**——设备发送 S5F1 后启动 T3 定时器（默认 ~45 秒），如果在 T3 时间内没收到 S5F2 确认，设备重发 S5F1（相同的 ALID 和内容）。重发次数可能有限制（如最多重发 3 次），超过后设备可能放弃并记录日志，或进入 Spool 缓存（W8 细讲）。今天实现简化版：发送后不强制等待确认，记录日志；T3 超时重发在 W8 综合实验中完善。专家实践：设备必须实现 S5F1 的超时重发，因为报警是关键通知，不能丢失；Spool 机制可以在通信中断时缓存报警，通信恢复后重发。

## 二、参考实现（EapLab.Gem/Alarm/）

### S5F1Sender.cs
```csharp
using EapLab.Secs2;
using EapLab.Transport.Connection;
using EapLab.Transport.Logging;

namespace EapLab.Gem.Alarm;

/// <summary>S5F1 报警上报发送器：订阅报警状态变化，组装并发送 S5F1。</summary>
public sealed class S5F1Sender
{
    private readonly AlarmStore _store;
    private readonly HsmsConnection _conn;
    private readonly ILogSink _log;

    public S5F1Sender(AlarmStore store, HsmsConnection conn, ILogSink log)
    {
        _store = store;
        _conn = conn;
        _log = log;
        // 订阅报警状态变化事件
        _store.OnAlarmChanged += OnAlarmChanged;
    }

    private void OnAlarmChanged(Alarm alarm, AlarmState oldState, AlarmState newState)
    {
        // 组装 S5F1 body = L,2[U4 ALID, A ALTX]
        // 扩展版可包含 ALCD: L,3[U4 ALID, U1 ALCD, A ALTX]
        var body = SecsItem.L(
            SecsItem.U4(alarm.AlId),
            SecsItem.A(alarm.AlTx)
        );

        _log.Log(LogDir.WARN, $"S5F1 send: ALID={alarm.AlId} {alarm.AlTx} state={newState}");

        // 设备主动发送 S5F1（W=1），SystemBytes 由连接分配
        // 简化版：异步发送，不等待 S5F2 确认（W8 完善超时重发）
        _conn.SendPrimaryAsync(5, 1, body);
    }

    /// <summary>处理 Host 回的 S5F2 确认。</summary>
    public void HandleS5F2(SecsItem? body)
    {
        if (body is SecsU4 alIdItem && alIdItem.Values.Length == 1)
        {
            uint alId = alIdItem.Values[0];
            _log.Log(LogDir.INFO, $"S5F2 ack received: ALID={alId}");
            // W8 完善：清除重发定时器，标记上报完成
        }
    }
}
```

### S5F3Handler.cs
```csharp
namespace EapLab.Gem.Alarm;

/// <summary>S5F3 使能/禁用报警处理器。</summary>
public sealed class S5F3Handler
{
    private readonly AlarmStore _store;
    private readonly ILogSink _log;

    public S5F3Handler(AlarmStore store, ILogSink log)
    {
        _store = store;
        _log = log;
    }

    /// <summary>处理 S5F3，返回 S5F4 body（U1 ACKC5）。</summary>
    public SecsItem Handle(SecsItem? body)
    {
        if (body is not SecsList root || root.Items.Count != 2)
            return SecsItem.U1(1); // ACKC5=1: 格式错误

        // 解析 ALED
        if (root.Items[0] is not SecsU1 aledItem || aledItem.Values.Length != 1)
            return SecsItem.U1(1);
        bool enabled = aledItem.Values[0] == 1; // 1=使能，0=禁用

        // 解析 ALID 列表
        if (root.Items[1] is not SecsList alIdList)
            return SecsItem.U1(1);
        var alIds = new List<uint>();
        foreach (var item in alIdList.Items)
        {
            if (item is SecsU4 u4 && u4.Values.Length == 1)
                alIds.Add(u4.Values[0]);
            else
                return SecsItem.U1(1);
        }

        // 使能/禁用
        byte ackc5 = _store.SetEnabled(enabled, alIds);
        _log.Log(LogDir.INFO, $"S5F3: {(enabled ? "enable" : "disable")} ALID=[{string.Join(",", alIds)}] ACKC5={ackc5}");
        return SecsItem.U1(ackc5);
    }
}
```

### S5F5Handler.cs
```csharp
namespace EapLab.Gem.Alarm;

/// <summary>S5F5 查询报警列表处理器。</summary>
public sealed class S5F5Handler
{
    private readonly AlarmStore _store;

    public S5F5Handler(AlarmStore store) => _store = store;

    /// <summary>处理 S5F5，返回 S5F6 body（L,n[L,3[U4 ALID, U1 ALCD, A ALTX]]）。</summary>
    public SecsItem Handle(SecsItem? body)
    {
        var alIds = new List<uint>();
        if (body is SecsList list)
        {
            foreach (var item in list.Items)
            {
                if (item is SecsU4 u4 && u4.Values.Length == 1)
                    alIds.Add(u4.Values[0]);
            }
        }

        var alarms = _store.Query(alIds); // 空=全部
        var items = alarms.Select(a =>
            SecsItem.L(
                SecsItem.U4(a.AlId),
                SecsItem.U1(a.AlCd),
                SecsItem.A(a.AlTx)
            )
        ).ToArray();

        return SecsItem.L(items);
    }
}
```

### S5Handler 门面（消息分发）
```csharp
namespace EapLab.Gem.Alarm;

/// <summary>S5 Stream 消息分发器。</summary>
public sealed class S5Handler
{
    private readonly S5F3Handler _f3;
    private readonly S5F5Handler _f5;
    private readonly S5F1Sender _f1Sender;

    public S5Handler(S5F3Handler f3, S5F5Handler f5, S5F1Sender f1Sender)
    {
        _f3 = f3;
        _f5 = f5;
        _f1Sender = f1Sender;
    }

    /// <summary>处理 Host 发来的 S5 primary 消息，返回 reply body（不支持返回 null，调用方回 S9）。</summary>
    public SecsItem? HandlePrimary(byte function, SecsItem? body)
    {
        return function switch
        {
            3 => _f3.Handle(body),    // S5F3 使能/禁用 → S5F4
            5 => _f5.Handle(body),    // S5F5 查询列表 → S5F6
            _ => null                  // 不支持，回 S9F5
        };
    }

    /// <summary>处理 Host 发来的 S5 reply 消息（S5F2 确认）。</summary>
    public void HandleReply(byte function, SecsItem? body)
    {
        if (function == 2)
            _f1Sender.HandleS5F2(body);
    }
}
```

### 单测（节选）
```csharp
public class S5HandlerTests
{
    private static (S5Handler, AlarmStore) CreateHandler()
    {
        var log = new ConsoleLogSink();
        var store = new AlarmStore(log);
        store.Register(1001, 2, "Temperature High");
        store.Register(1002, 1, "Pressure Low");
        var conn = new MockHsmsConnection(); // 模拟连接
        var f1Sender = new S5F1Sender(store, conn, log);
        var f3 = new S5F3Handler(store, log);
        var f5 = new S5F5Handler(store);
        return (new S5Handler(f3, f5, f1Sender), store);
    }

    [Fact]
    public void S5F3使能报警()
    {
        var (handler, store) = CreateHandler();
        var body = SecsItem.L(SecsItem.U1(1), SecsItem.L(SecsItem.U4(1001)));
        var reply = handler.HandlePrimary(3, body);
        Assert.Equal(0, ((SecsU1)reply!).Values[0]); // ACKC5=0
        Assert.True(store.Get(1001)!.Enabled);
    }

    [Fact]
    public void S5F3使能全部报警()
    {
        var (handler, store) = CreateHandler();
        var body = SecsItem.L(SecsItem.U1(1), SecsItem.L()); // 空列表=全部
        var reply = handler.HandlePrimary(3, body);
        Assert.Equal(0, ((SecsU1)reply!).Values[0]);
        Assert.True(store.Get(1001)!.Enabled);
        Assert.True(store.Get(1002)!.Enabled);
    }

    [Fact]
    public void S5F5查询全部报警()
    {
        var (handler, _) = CreateHandler();
        var reply = handler.HandlePrimary(5, SecsItem.L());
        var list = (SecsList)reply!;
        Assert.Equal(2, list.Items.Count);
    }

    [Fact]
    public void 使能后设置报警_触发S5F1()
    {
        var (handler, store) = CreateHandler();
        var conn = (MockHsmsConnection)typeof(S5Handler)
            .GetField("_f1Sender", System.Reflection.BindingFlags.NonPublic | System.Reflection.BindingFlags.Instance)!
            .GetValue(handler)!;
        // 简化：直接验证 store.Set 返回 true（表示已使能且状态变化）
        handler.HandlePrimary(3, SecsItem.L(SecsItem.U1(1), SecsItem.L(SecsItem.U4(1001))));
        bool reported = store.Set(1001);
        Assert.True(reported);
    }

    [Fact]
    public void 禁用后设置报警_不触发S5F1()
    {
        var (handler, store) = CreateHandler();
        // 默认禁用
        bool reported = store.Set(1001);
        Assert.False(reported);
    }
}
```

## 三、今日易错点
1. 以为 S5F1 是 Host 发的（是设备主动发的，W=1，Host 回 S5F2）。
2. S5F3 body 结构记错（是 L,2[U1 ALED, L,n[U4 ALID]]，不是 L,n[U4 ALID]）。
3. 以为 ALED=0 是使能（0=禁用，1=使能，不要搞反）。
4. S5F6 body 结构记错（是 L,n[L,3[U4 ALID, U1 ALCD, A ALTX]]，每个报警 3 个字段）。
5. 设备主动发消息时 SystemBytes 分配搞混（设备主动发时由设备分配，Host 回确认时用相同的 SystemBytes）。
6. 以为禁用的报警状态变化时设备内部也不记录（禁用只是不通知，内部状态机仍运行）。
7. S5F1 body 只带 ALID 和 ALTX，Host 靠维护状态表区分 SET/CLEAR（不要依赖 ALCD 或 ALTX 区分）。
8. 消息分发时把 S5F2 当 primary 处理（S5F2 是 Host 回的确认，走 HandleReply，不是 HandlePrimary）。
