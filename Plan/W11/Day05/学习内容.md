## 二、背景知识（先读，30 分钟）

### 1. 各拍超时定时器（教学定义，参数以标准/设备为准）
握手是"我置位→等你响应"，每个等待都必须有超时，不能无限等。
| 定时器 | 等待什么 | 超时典型原因 | 超时动作 |
|---|---|---|---|
| T_req | 置就绪后等 TR_REQ | 小车没来/调度取消 | 回 Idle，释放就绪 |
| T_es | TR_REQ 后等设备 ES | 设备条件不满足/故障 | 小车侧超时，撤请求并告警 |
| T_busy | ES 后等 BUSY | 小车机构未启动 | 撤许可、回 Idle、告警 |
| T_compt | BUSY 后等 COMPT | 放置/抓取动作卡住 | 急停级挂起、保持夹持、报警 |
| T_reset | COMPT 后等信号复位 | 信号残留/对方未撤 | 告警、保持安全态、人工确认 |
| T_valid | VALID 稳定/有效 | 线缆/干扰/掉电 | 立即冻结动作、安全保持 |
- 原则：越靠近物理动作的超时（T_compt）越危险，处置越保守（直接安全保持+人工），越靠空闲的超时（T_req）越轻（回 Idle 即可）。

### 2. 交接异常状态机（教学模型）
```
Idle ──TR_REQ──► WaitGrant(等ES) ──ES──► WaitBusy ──BUSY──► Transferring
  ▲                │超时/矛盾             │超时              │COMPT
  │                ▼                      ▼                 ▼
  │            RejectIdle            AbortSafe ◄──── WaitComplete
  │                                                     │复位完成
  └───────────────────────────────────────────── Idle
  任意态 ──ESTOP──► EStopHold(急停保持) ──人工复位+条件──► Idle/ManualRecover
  任意态 ──BYPS──► ManualBypass(手动) ──退出旁路──► Idle
  任意态 ──VALID丢失/断线──► SafeFreeze(安全冻结) ──恢复──► 续接或人工
```
- AbortSafe/SafeFreeze/EStopHold 都是"停止动作+保持夹持+报警"，区别在触发源和恢复路径。

### 3. 异常分类与处置矩阵
| 异常 | 现象 | 直接处置 | 是否可自动重试 |
|---|---|---|---|
| 请求超时 T_req | 就绪后无车来 | 回 Idle | 可（下次再来） |
| 许可超时 T_es | 请求后设备不许可 | 撤请求、记录原因 | 视原因，条件恢复后可 |
| 执行前矛盾 | 空口取/有盒放/方向不明 | 拒绝、告警、不动 | 否，需调度纠正 |
| VALID 丢失/抖动 | 总线信号不可信 | 立即冻结、安全保持 | 恢复后评估，多数需确认 |
| 动作超时 T_compt | BUSY 后迟迟不 COMPT | 急停级保持、禁松爪 | 否，必须人工到场 |
| 传感器不一致 | COMPT 了但在位状态不符 | 保持、不推进、报警 | 否，人工核实盒位置 |
| 机构故障 | 升降/门/夹持异常 | 急停保持 | 否，维修后人工复位 |
| 断线/掉电 | 信号全失 | 失电安全（夹持/制动） | 上电后人工确认恢复 |
| ESTOP | 急停按钮/安全回路 | 立即全停、保持 | 人工复位 |

### 4. ESTOP 急停安全流程
1. 触发（任一急停按钮/安全门/安全继电器/软件急停）→ 安全回路断电/信号动作。
2. 立即停止所有运动轴，夹持器/制动器失电保持（fail-safe 夹紧，防掉盒）。
3. 交接状态机进 EStopHold，冻结所有握手推进，记录急停时刻与各信号快照（便于复盘）。
4. 声光报警，通知现场与 Host（经 SECS 上报告警/事件，EAP 侧记录）。
5. 人工到场确认 FOUP 位置/夹持安全、排除原因、旋转/拔出急停按钮复位。
6. 复位后不自动续接，按盒实际位置选择：继续完成本次交接 / 手动取下 / 回退到安全态，全部确认后才回 Idle。

### 5. BYPS 手动旁路
- 进入：检修/调试/自动系统故障需人工操作时，切 Bypass，自动四相握手被禁用，Load Port 由现场手动操作（手动放/取 FOUP）。
- 安全要求：旁路状态必须显著上报 Host（账实要同步，Host 知道这个口在手动），手动放/取后也要人工或半自动同步 E87 载具状态，否则 MES 账目和现场实物脱节。
- 退出：手动操作完成、机构回 Home、现场确认无干涉后退出旁路，回 Idle，恢复自动交接；退出前校验物理状态（口上有无盒、盒 ID）与逻辑状态一致。

### 6. 重试与恢复策略（三类）
- **可自动重试（无物理动作发生/在空闲侧超时）**：如 T_req/T_es/T_busy 阶段尚未发生实质放/取动作，撤干净信号回 Idle，允许 AMHS 重新发起；自动重试要限次（如 ≤2 次），超限升级人工，防止死循环抖动。
- **需人工确认恢复（动作进行中被打断）**：T_compt、VALID 丢失、瞬时断电等，可能盒处于半交接位置，必须人工确认盒安全与位置后才能续接或回退，软件只提供"当前状态+建议动作"，不自动决定。
- **不可自动恢复（硬件故障/传感器矛盾/急停）**：锁定设备、报修，维修并人工复位后才解锁。
- 通用原则：**凡是不确定 FOUP 当前被谁持有的时刻，一律安全保持+人工，禁止自动重试**（掉盒风险最高）。
