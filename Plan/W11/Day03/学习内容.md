## 二、背景知识（先读，25 分钟）

### 1. Deposit 前置条件
- 设备侧：CS=ON（该 Load Port 系统就绪、无故障、非 BYPS、非 ESTOP）、Load Port 为空（没有 FOUP）、机构在 Home 位、门关闭、VALID 可建立。
- 小车侧：SS=ON（搬运系统就绪）、VR=ON（本车就绪）、车上携带 FOUP、已移动到该 Load Port 正上方/对接位。
- 双方 VALID 有效后才开始握手。

### 2. Deposit 标准节拍（教学时序，精确时序以 E84 原文为准）
```
阶段0 空闲(Idle)：双方业务信号 OFF，CS/SS 就绪
阶段1 小车就位、发起请求：
   小车到位 → VR=ON → TR_REQ=ON（请求 Deposit，配合 HO 位标记新的一拍）
   设备采样到 TR_REQ，检查：口空?CS 在?无急停非旁路?
阶段2 设备许可：
   条件满足 → Load Port 准备接收（确认空位/机构 Home）→ ES=ON（允许放置）
   小车采样到 ES=ON，确认设备已准备好承接
阶段3 小车执行放置：
   小车 BUSY=ON（开始下放 FOUP）→ 机械下降/放置到 Load Port 承接面
   设备在 BUSY 期间锁定机构、不得动作，保持承接条件
阶段4 放置完成：
   FOUP 落到 Load Port 并被夹持/坐实 → 小车松开 → COMPT=ON（放置完成）
   设备确认 FOUP 在位传感器 ON、坐实、夹持到位
阶段5 设备承接、双方复位：
   设备确认承接成功 → 按握手顺序撤销 ES
   小车撤销 COMPT、BUSY、TR_REQ（配合 HO 位翻转回空闲拍）
   设备最后撤销/回到空闲，小车离开
阶段6 转软件流程（E87/E90，W12/W14 详讲）：
   Load Port 检测 FOUP 就位 → 读取 CarrierID（RFID/条码）
   → E87 Carrier 状态迁移到 LOADED，通过 SECS 上报 Host（S16/S6F11）
   → E90 读取 SlotMap → Host 建 PJ
```

### 3. 泳道时序图结构（手绘模板）
三条泳道从上到下：**AMHS 小车 | Load Port 设备(PLC) | 设备 EAP 软件/Host**。
- 前两条泳道画 E84 电平信号随时间的 ON/OFF 阶梯线，标注置位原因。
- 第三条泳道画交接完成后才发生的 SECS 消息（E87/E90），用虚线表示"物理交接结束后才进入软件流程"。
- 互锁等待点用小竖线标注"等待 ES""等待 COMPT"。

### 4. 关键互锁原则（Deposit）
- 没看到设备 ES=ON，小车绝不下放（防止设备没准备好导致掉盒）。
- BUSY=ON 期间设备绝不能动 Load Port 机构（防止动作冲突）。
- 设备没确认 FOUP 坐实/在位传感器，不能进入承接完成、不能撤销许可。
- 任一拍等待超时或 ESTOP，立即中止并安全保持（Day05）。
- 信号撤销也要按握手顺序，不能同时全撤（HO 位翻转区分拍）。

### 5. Deposit 与 E87 的衔接边界（重要）
- E84 只负责到"FOUP 物理坐实在 Load Port、双方信号复位、小车离开"。
- "这个盒子是谁（CarrierID）、什么状态（LOADED）、里面有哪些晶圆（SlotMap）、能不能加工（预约/验证）"全部是 E87/E90 通过 SECS 与 Host 交互，E84 不传递这些信息。
- 时序上：E84 Deposit 完成是 E87 状态迁移的**物理触发源**，但二者是不同通道、不同标准。
