## 二、背景知识（先读，30 分钟）

### 1. E84 解决什么问题
- FAB 里晶圆装在 FOUP（前开式标准晶圆盒）中，由 **AMHS（Automated Material Handling System，自动物料搬运系统，常见 OHT 天车/AGV）** 在设备 Load Port（装载口）和仓储（Stocker）之间搬运。
- FOUP 放到 Load Port（Deposit/上料）或从 Load Port 取走（Pickup/下料）是**物理动作**：天车移动、机械臂放/取、Load Port 升降/开门/夹持，任何配合失误都会碰撞、掉盒、损坏晶圆，甚至伤人。
- E84 定义了 Load Port（设备侧）和搬运小车（AMHS 侧）之间的**本地并行传输接口**：一束并行数字 I/O 硬线，双方通过固定信号的电平 ON/OFF 按严格时序握手、互锁，保证"你没准备好我不动、你没拿稳我不松、任何异常立即停"。

### 2. 为什么不用 TCP/SECS 而用硬线（核心考点）
| 维度 | E84 LPT 并行硬线 | HSMS/SECS 网络报文 |
|---|---|---|
| 物理介质 | 多芯信号电缆 + 光耦 I/O | 以太网 TCP/IP |
| 信号形式 | 每根线一个电平，并行同时有效 | 串行报文，逐字节传输 |
| 实时性 | 微秒~毫秒级，确定 | 毫秒~秒级，受调度/网络/重传影响 |
| 安全等级 | 直达安全互锁回路，故障安全 | 依赖软件栈和网络，非安全级 |
| 失效行为 | 断电/断线/死机→回到安全态 | 连接断→超时，行为依赖软件恢复 |
| 用途 | 物理交接动作的硬握手/互锁 | 信息、状态、任务、数据管理 |
| 诊断 | 万用表/示波器/PLC I/O 点可量 | 抓包/日志 |
- 一句话：**动作安全靠 E84 硬线（确定、故障安全），信息管理靠 SECS（丰富、灵活）**。物理交接不允许"网络卡一下"，所以必须硬线互锁。

### 3. LPT 电气基础
- **信号电平**：工业标准常用 24V DC 数字量（ON≈有源/导通，OFF≈无源/断开），具体电压等级以设备/标准实现为准。每个逻辑信号对应一根物理信号线 + 公共回线。
- **光耦隔离（Opto-isolation）**：设备侧和搬运侧电气隔离，信号通过光耦合传递，防止地环流、干扰、高压串入损坏对方，是工业安全与抗干扰的关键。
- **Source/Sink（拉电流/灌电流，有源/无源接线）**：数字 I/O 的两种接线方式——Source（源型，输出端向外供电）与 Sink（漏型，输入端向内回流），两侧 I/O 类型必须匹配才能形成回路，接线错误信号永远不通。工程接线时必须确认双方 I/O 模块的源漏类型一致或加中继。
- **信号束与连接器**：E84 把双向多个信号集成在一根多芯电缆/连接器中（标准定义引脚分配），分"设备→搬运"和"搬运→设备"两组方向，另含电源、公共端、屏蔽层。
- **故障安全（Fail-safe）设计**：关键安全信号采用"得电有效/失电安全"或特定逻辑，使得断线、掉电、接触不良时系统进入安全态（停止动作、保持夹持、不松爪），而不是误动作。VALID 类信号用于指示整束信号有效，信号抖动/无效时不得执行动作。
- **去抖与稳定时间**：机械触点/继电器有抖动，信号必须稳定保持一定时间（debounce）才被采信；握手时序中每个信号都有最小/最大维持时间要求（W11 Day03/04 讲）。

### 4. E84 与 E87/E90/AMHS 的协作全景
```
AMHS(OHT 天车)
   │  ①E84 硬线握手：Deposit 放 FOUP / Pickup 取 FOUP（物理动作互锁）
   ▼
设备 Load Port（装载口，硬件）
   │  ②FOUP 就位/离开，Load Port 控制器产生事件
   ▼
设备 SECS/GEM/EAP 接口（软件）
   │  ③E87 载具管理：Carrier 状态机迁移(LOADED/UNLOADED)、CarrierID 绑定、上报 Host
   │  ④E90 基板跟踪：读 FOUP 内 SlotMap（哪些槽有晶圆）
   ▼
Host(EAP/MES)：⑤据载具与槽位信息创建/调度 ProcessJob（E40）、ControlJob（E94）
```
- E84 是"手"（物理交接），E87 是"账"（载具逻辑状态），E90 是"货"（晶圆位置），E40/E94 是"活"（加工任务）。W13 把 E84+E87 串成自动上料。

### 5. 关键术语先建立
- Load Port（装载口/装载台，LP）：设备上承载 FOUP 的工位，一台设备通常 2~4 个。
- FOUP（Front Opening Unified Pod）：前开式晶圆传送盒，12 英寸晶圆标准载具，内部 25 个 Slot。
- AMHS/OHT：自动物料搬运系统/架空提升搬运（天车）。
- Deposit（放货/入库到设备）、Pickup（取货/从设备出库）。
- Hand-off（交接）、Interlock（互锁）、Handshake（握手）。
