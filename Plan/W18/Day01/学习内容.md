# W18 · Day01（周一）设备资源拓扑与产能模型

> 建议时长：85 分钟。本周攻克多腔体/多机械手并发。今天先把设备建成一张"资源拓扑图"：每个腔/臂/锁/缓冲是有限容量资源，资源之间有可达路径与并行度，产能（Throughput）由资源占用时间决定。这是并发调度的物理基础。

## 一、今日目标

3. 理解并行度与瓶颈：哪些资源可并行、哪个是瓶颈资源、产能如何估算。

5. xUnit 覆盖拓扑构建、可达查询、容量与瓶颈识别。

## 二、背景知识（先读，35 分钟）

### 1. 设备资源分类
- **存放类**：LoadPort 载具槽、Buffer 暂存位（容量 1/位）。
- **搬运类**：大气机械手（EFEM Robot）、真空机械手（Vacuum Robot），通常双臂，每臂容量 1。
- **过渡类**：LoadLock（大气/真空过渡，带抽真空/破真空时间）、Aligner 对准器。
- **工艺类**：Process Module/Chamber（C1/C2/C3），单片腔容量 1（也有多片站，按实际），有工艺时长。
- 每个资源：唯一 ID、类型、容量、支持能力（工艺类/可持片）、一次占用时长、当前状态与占用者。

### 2. 资源拓扑图
- 节点=资源，有向/无向边=片可在两资源间直接搬运（机械臂可达）。
- 典型集群机（Cluster Tool）拓扑：
```
LoadPort ─ EFEM大气臂 ─ Aligner
                    │
                LoadLock(LL1/LL2, 大气↔真空)
                    │
              真空臂(Vacuum Robot, 双臂)
               ┌────┼────┐
              C1    C2    C3 (同型/异型工艺腔)
```
- 路径：片从载具槽经大气臂→对准器→LoadLock→真空臂→腔体，原路/换路返回。
- 可达性：两资源间是否存在搬运路径（W16 RouteValidator 的物理可达就来自拓扑）。

### 3. 大气侧/真空侧与 LoadLock
- 大气侧（Atmospheric）：LoadPort/EFEM 臂/Aligner，空气环境。
- 真空侧（Vacuum）：真空臂/工艺腔，真空环境。
- LoadLock 是两侧闸门：进片抽真空、出片破真空，有不可忽略的锁定时间，是典型瓶颈与互锁资源（一次只能一个方向、内部容量有限）。
- 片跨两侧必须经 LoadLock，调度要安排锁的方向与时序。

### 4. 并行度与瓶颈
- **并行度**：同型多腔可同时加工多片（C1/C2/C3 并行 3 片）；双臂可交换动作；EFEM 上片与真空侧加工可重叠（流水线）。
- **瓶颈资源**：产能由最慢/最繁忙的资源决定（约束理论 TOC）。工艺时长最长或唯一的资源（如只有一个真空臂、LoadLock 抽气慢）往往是瓶颈。
- **产能估算**：稳态下 产能≈瓶颈资源单位时间可完成片数；缩短瓶颈占用（双臂交换、并行腔）提升产能。
- 关键时间参数：Pick/Place 时间、臂移动、对准、抽/破真空、每腔工艺时长，用逻辑时钟建模（不用真线程）。

### 5. 资源占用模型（为调度器铺垫）
- 一次动作占用一组资源一段时间区间 [start,end)；调度=在满足容量/互斥/路径前提下，为每片每动作排布时间区间，最大化并行且无冲突。
- 明天实现全局资源调度器（原子占用/固定顺序防死锁），今天先把资源与拓扑、占用时间数据建好。

### 6. 与已学内容关系
- 复用 W15 ResourceTable（资源互斥）思想并升级为带拓扑和时间的全局模型；E90 位置空间的每个 InternalLocation 对应一个资源节点，容量约束一致。
