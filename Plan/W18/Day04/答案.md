# W18 · Day04 答案与参考实现

## 一、自测题标准答案
1. **Swap 省在哪 / 提升节拍**：单臂面对"腔内有完成片、还要进新片"时，必须先取旧片→送到缓冲/锁放下→空手返回→取新片→再送入，真空臂要多跑"送走旧片再回来"的往返行程；双臂 Swap 时一只手已持新片等在腔前，另一只手取出旧片后换位直接放入新片，一次驻留就完成出旧进新，旧片等新片放好后再送走。真空臂通常是整线瓶颈，Swap 直接缩短瓶颈服务每片的时间，也就缩短了稳态节拍、提升产能；同时减少腔门开关和等待。
2. **Swap 五步 / 防叠片**：前提=腔内有完成片 Old、臂 A 持新片 New、臂 B 空。①VR 移到腔前；②臂 B 伸入取出 Old 缩回（腔变空、B 持 Old）；③两臂旋转换位；④臂 A 伸入把 New 放入腔缩回（腔开始加工 New、A 空）；⑤VR 持 Old 离开送往下一目标。第②步取走 Old 后、第④步才放 New，中间通过传感器确认腔已空，保证"先出后进、腔空才放"，腔容量 1 不被突破，从而不叠片。
3. **两条安全互斥**：①腔容量互斥——必须确认旧片已取出、腔为空，才能放入新片，禁止两臂同时在腔内或未取走就放入（否则叠片）；②双臂干涉区互斥——两臂共用旋转/伸缩机构，同一时刻只能一只臂伸入或处于换位干涉区，两臂不能同时动作到干涉位置（防机械碰撞）。此外两臂各容量 1、全程守恒也是硬约束。
4. **锁循环阶段 / 为何瓶颈**：进片方向：EFEM 在大气态开大气门放入片→关大气门抽真空（Pump）→真空压力达成、VR 开真空门取走；出片方向反向：VR 放入完成片→关真空门破真空（Vent）回大气→EFEM 开大气门取走。阶段=门状态（大气门/真空门开关）、压力状态（大气/抽真空/真空/破真空）、方向（进/出）、内部有无片。Pump/Vent 需要物理抽气/充气时间，期间锁既不能被 EFEM 也不能被 VR 使用，且一次基本只服务一个方向，两侧都要在锁这里排队，所以锁成为耗时的互锁瓶颈。
5. **双锁乒乓 / 安全红线**：用 LL1、LL2 交替——当 LL1 处于抽真空/供真空侧（VR 取放）时，LL2 处于破真空/供大气侧（EFEM 取放），下一拍互换，让 EFEM 和 VR 各自总有一个处于自己可用压力状态的锁，把一个锁的抽/破真空时间重叠在另一个锁被对侧操作的时间里，从而掩盖抽气耗时、两侧不空等。安全红线是**压力互锁**：任一锁绝不能同时打开大气门和真空门（否则大气直接灌入真空腔体，严重事故）；必须压力到位、对侧门确认关闭才能开本侧门，方向与门状态由锁状态机强制，乒乓只重叠时间、绝不重叠同一锁的对侧门。
6. **锁如何解耦两侧**：没有锁时 EFEM（大气）和 VR（真空）压力环境不同、无法直接交接，会互相等对方动作；锁作为中间缓冲舱，EFEM 只与锁的大气门交互（放入/取走），VR 只与真空门交互，两侧通过"锁里有无片、锁当前压力状态"这些状态协同，而不必同步等待对方的机械动作——EFEM 把片放进锁就可以去取下一片，锁自己抽真空，VR 在真空就绪后取走；双锁乒乓进一步让两侧并行。这和 W15 用 Buffer 打破位置占用环是同一思想：缓冲边界解除双方的直接持有等待。
7. **Swap 中途断电恢复**：Swap 是复杂恢复点，断电后两臂可能各持一片（B 持取出的 Old、A 可能还持 New 或已放入），腔可能空或已放入 New。重启按 W17 物理优先：①不假设逻辑进度，用传感器读腔是否有片、两臂各持谁（读码/片在位）、各片实际位置；②重建位置空间并守恒核对（Old/New 各有唯一位置）；③判断 Swap 进行到哪一步：若 Old 已取出在 B、New 尚未放入且腔空，则从"换位放入 New"这一安全边界续做或把两片安全归位；若 New 已放入、Old 在臂，则完成送走 Old；若片身份/位置读不清，安全保持转人工。绝不在不确定腔是否为空时盲目放片（防叠片），恢复序列仍守腔容量与臂容量。

## 二、参考实现（net8.0）

### 双臂与 Swap
```csharp
namespace EapLab.E40.Sched;
public sealed class DualArm
{
    public string? BladeA { get; private set; }   // 每臂容量1
    public string? BladeB { get; private set; }
    public bool Holds(string w)=>BladeA==w||BladeB==w;
    public int Count=>(BladeA is not null?1:0)+(BladeB is not null?1:0);
    public void LoadA(string w){ if(BladeA is not null)throw new InvalidOperationException("A已持片"); BladeA=w; }
    public string? UnloadB(){ var w=BladeB; BladeB=null; return w; }
    public void RotateSwap()=> (BladeA,BladeB)=(BladeB,BladeA); // 旋转换位
}
public sealed class ChamberSlot{ public string? Wafer; public bool Empty=>Wafer is null; }
public sealed class SwapSequence
{
    // 返回每步后的(腔片,A,B), 并保证先出后进、腔空才放
    public List<(string? chamber,string? a,string? b,string note)> Run(ChamberSlot c,DualArm arm,string newWafer)
    {
        var log=new List<(string?,string?,string?,string)>();
        if(c.Empty) throw new InvalidOperationException("Swap前提:腔内有旧片");
        arm.LoadA(newWafer); log.Add((c.Wafer,arm.BladeA,arm.BladeB,"A持新片到腔前"));
        string old=c.Wafer!; c.Wafer=null; arm.BladeB=old;            // B取旧, 腔变空
        log.Add((null,arm.BladeA,arm.BladeB,"B取出旧片,腔空"));
        if(!c.Empty) throw new InvalidOperationException();          // 腔必须空
        arm.RotateSwap(); log.Add((null,arm.BladeA,arm.BladeB,"旋转换位"));
        if(!c.Empty)throw new InvalidOperationException();
        c.Wafer=arm.BladeA; arm.BladeA=null;                          // A放新片
        log.Add((c.Wafer,arm.BladeA,arm.BladeB,"A放入新片"));
        return log;
    }
}
```

### LoadLock 状态机（门/压力/方向）
```csharp
public enum LlPressure { Atmospheric, Pumping, Vacuum, Venting }
public enum LlDoor { BothClosed, AtmDoorOpen, VacDoorOpen }
public enum LlDir { Idle, Inward, Outward }
public enum LlState { EmptyAtm, LoadingAtm, Pumping, ReadyVac, UnloadingVac,
                      FillingVac, Venting, ReadyAtm, UnloadingAtm }
public sealed class LoadLockFsm
{
    public LlState State{get;private set;}=LlState.EmptyAtm;
    public LlPressure P{get;private set;}=LlPressure.Atmospheric;
    public LlDoor Door{get;private set;}=LlDoor.BothClosed;
    public string? Wafer{get;private set;}
    // 进片: EFEM放入 -> 抽真空 -> VR可取
    public void OpenAtmDoor(){ if(Door!=LlDoor.BothClosed||P==LlPressure.Vacuum)throw new InvalidOperationException("压力互锁"); Door=LlDoor.AtmDoorOpen; }
    public void PutFromAtm(string w){ if(Door!=LlDoor.AtmDoorOpen)throw new InvalidOperationException(); Wafer=w; }
    public void CloseAndPump(){ Door=LlDoor.BothClosed; State=LlState.Pumping; P=LlPressure.Pumping; }
    public void PumpDone(){ P=LlPressure.Vacuum; State=LlState.ReadyVac; }
    public void OpenVacDoor(){ if(P!=LlPressure.Vacuum)throw new InvalidOperationException("未到真空禁止开真空门"); Door=LlDoor.VacDoorOpen; }
    public string? TakeToVac(){ if(Door!=LlDoor.VacDoorOpen)throw new InvalidOperationException(); var w=Wafer;Wafer=null;return w; }
    public void CloseVac(){ Door=LlDoor.BothClosed; State=LlState.EmptyAtm; }
    // 出片反向(Vent)略, 对称实现; 关键: 两门永不同时开
}
```

public sealed class PingPong
{   // LL1供真空侧时LL2供大气侧, 交替; 返回每拍两锁角色
    public IEnumerable<(int tick,string vacSide,string atmSide)> Run(int beats)
    { for(int t=0;t<beats;t++) yield return (t, t%2==0?"LL1":"LL2", t%2==0?"LL2":"LL1"); }

## 三、Swap 与双锁（手绘参考）
```
单臂: 取旧→送旧到缓冲→空手回→取新→送入 (VR多跑往返)
双臂Swap: A持新到腔前 → B取旧(腔空) → 旋转换位 → A放新 → 持旧离开
          约束: 腔空才放(不叠片); 两臂不同时入干涉区; 各容量1; 守恒
LoadLock进: 开大气门放入→关→Pump抽真空→真空就绪→开真空门VR取
          出片反向 Vent破真空; Pump/Vent期间锁不可用=瓶颈
双锁乒乓: LL1供VR时LL2供EFEM, 下拍互换, 抽破真空与对侧动作重叠
安全红线: 同一锁大气门/真空门永不同时开, 压力到位才开本侧门
```

## 四、今日易错点
1. 以为双臂就能同时往腔里伸（干涉区互斥，一次一只臂）。
2. 旧片没取走确认腔空就放新片（叠片，必须先出后进、传感器确认）。
3. 单臂不用缓冲直接交换（单臂交换两槽/腔必须临时位，双臂才省往返）。
4. LoadLock 不建门/压力/方向状态机（压力互锁是安全红线，两门不能同开）。
5. Pump/Vent 没完成就让对侧取片（必须压力到位）。
6. 单锁硬扛两侧、不做双锁乒乓（抽破真空时间无法重叠，锁成死瓶颈）。
7. 乒乓时同一锁两侧门重叠操作（只重叠不同锁的时间，不重叠同锁对侧门）。
8. Swap 中途故障按逻辑进度盲目续（按两臂/腔实际持片物理重建，腔空才放）。
