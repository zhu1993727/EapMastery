# W18 · Day05 答案与参考实现

## 一、自测题标准答案
1. **逻辑时钟表达同时 / 不用真线程**：维护全局虚拟时钟 now，调度表给每个动作 [start,end)，执行循环按 (start, 动作ID) 全序取出动作：把时钟推到 start 执行"进入/开始"，推到 end 执行"完成/离开"。多个资源不相交的动作 start 相同，就在同一个逻辑时刻依次被处理、对外表现为"同时并行"（它们不共享资源、顺序处理结果一致）。不用真线程是因为真线程时序不确定、难复现竞争与死锁；逻辑时钟对同一调度表每次跑出完全相同的轨迹，可断言"某时刻片在哪、资源被谁占"，方便算完工时间、节拍和单测，也避免并发 bug。
2. **并发下四者职责**：调度器/选腔器是纯计算——决定每个动作用哪个腔/臂/锁、排在什么时间区间，错了可重算、无物理后果；ConcurrentExecutor 是编排——按调度表推进虚拟时钟、驱动每片阶段、发带时间戳事件，本身不直接改位置；E90 SubstrateTracker 是唯一物理位置入口——执行器的每个取放/转移都调它的原子 Move，由它守唯一/容量/守恒；PJ 状态机管 Job 单一状态（Executing/完成/暂停等），逐片 WaferProcess 记各自进度。四者分离让"计划、编排、物理一致、任务状态"互不耦合，物理安全始终由 E90 兜底。
3. **进出腔两阶段 / Process 不改位置**：Enter=片经锁、真空臂放入腔（E90 Move 到 Chamber 位置），腔资源开始占用、工艺计时开始；Process=工艺时长内片留在腔内加工，只把工艺状态从 Processing 变为 Done，**不改变位置**（W14：位置与工艺状态正交）；Exit=工艺完成后通过 Swap 用新片换出旧片，旧片经锁返回。分开是因为"片在腔里"是位置事实、"加工到什么程度"是工艺事实，二者独立，恢复/对账时要分别确认。
4. **acquire/release 与 Move 对应**：一次 Move 把片移入某资源（进臂/锁/腔）时，同时对该资源 acquire（占用，容量+1，校验不超容量）；一次 Move 把片移出该资源时 release（占用-1）。即资源占用状态完全由片的位置迁移驱动、一一对应：片在资源内=资源被该片占用，片离开=释放。这样资源调度表与 E90 实际位置始终一致，不会出现"账上占用但片不在"或"片在腔里却没占资源"的偏差，也从机制上保证不会有两片被 Move 进容量 1 的同一腔。
5. **Job 单一 Executing / 何时 Completed**：Job 状态描述的是整个任务，多片并行只是任务内部多片各自推进，任务整体仍在执行中，所以无论内部有几片在腔、几片在搬运，Job 都保持单一 Executing（不因某片完成就变状态，也不为每片建一个 Job 状态）；每片用独立 WaferProcess 记阶段。只有当完成守卫满足——所有片都 AtDestination（归位目标槽）、设备内/锁/臂全空、E90 终验通过、无异常、数据齐——才迁 Completed（W17）。
6. **并发为何每拍断言不变式更重要**：串行一次只动一片，出错面小；并发时同一时刻多片在多资源间迁移、双臂交换、锁交替，任何一步违反唯一位置/容量/守恒都可能造成叠片、两片进同腔、丢片，且并发错误隐蔽、时序复杂。每个逻辑时间步动作执行后都立即断言三不变式（一片恰在一个位置、资源容量不超、全局总数守恒），能在第一个出错动作处立刻定位，而不是等一批跑完才发现账实不符；这是把 W14 的不变式校验提升为并发循环的每拍强制检查。
7. **同 start 动作确定不冲突**：冲突在调度阶段已排除——能被排到同一 start 的动作必然占用不相交资源（Day02 区间互斥、固定顺序、all-or-nothing 保证），所以执行时即使按某个固定次序逐个处理，也不会争用同一资源、结果与处理次序无关；执行器再用 (时间, 动作ID) 的全序 tie-break 保证处理顺序唯一确定，相同输入每次相同，做到"逻辑同时、确定处理、物理不冲突"。

### 逻辑时钟并发执行器
```csharp
public sealed record TimedOp(string Wafer,string Resource,string Stage,int Start,int Dur,Action OnEnter,Action OnExit);
public sealed class ConcurrentExecutor
{
    private readonly SubstrateTracker _tracker; private readonly List<TimedOp> _ops;
    public int Now { get; private set; }
    public List<(int t,string wafer,string ev)> Trace { get; }=new();
    public ConcurrentExecutor(SubstrateTracker t,List<TimedOp> ops){_tracker=t;_ops=ops;}

    public void Run()
    {
        // 事件点: 每个动作的Start(进入)与Start+Dur(离开), 按(时间,类型,片)全序
        var events=new List<(int t,int order,TimedOp op)>();
        foreach(var o in _ops){ events.Add((o.Start,0,o)); events.Add((o.Start+o.Dur,1,o)); }
        foreach(var (t,order,op) in events.OrderBy(e=>e.t).ThenBy(e=>e.order).ThenBy(e=>e.op.Wafer,StringComparer.Ordinal))
        {
            Now=t;
            if(order==0){ op.OnEnter(); Trace.Add((t,op.Wafer,$"ENTER {op.Stage}@{op.Resource}")); }
            else        { op.OnExit();  Trace.Add((t,op.Wafer,$"EXIT  {op.Stage}@{op.Resource}")); }
            _tracker.AssertInvariants();   // 每拍强制三不变式
        }
    }
    public int Makespan()=>_ops.Max(o=>o.Start+o.Dur);
}
```

### 组装：三片并行（示意，对接 E90）
```csharp
public sealed class ClusterRuntime
{
    public static List<TimedOp> BuildOps(SubstrateTracker tracker,
        Dictionary<string,string> waferChamber, List<(string wafer,int procStart,int procDur)> schedule)
    {
        var ops=new List<TimedOp>();
        foreach(var (w,ps,pd) in schedule)
        { string ch=waferChamber[w];
          ops.Add(new TimedOp(w,ch,"Process",ps,pd,
              OnEnter:()=>tracker.Move(w,"VR:R1",InternalLocation.Chamber(ch),WaferState.InProcess), // 进腔=占用
              OnExit:()=>{ /* 片仍在腔, Swap换出时再Move; 工艺状态->Done */ }));
          // 取片/锁/对准/返回等动作同理用 TimedOp 包 E90 Move, 此处聚焦工艺并行
        }
        return ops;
    }
}
file static class InternalLocation{ public static string Chamber(string c)=>$"Internal:{c}"; }
```

## 三、并发执行结构（手绘参考）
```
Planner(时间区间) + Selector(选腔) -> 调度表(每动作[s,e))
   -> ConcurrentExecutor 逻辑时钟:
        事件点按(t, 进/出, 片ID)全序
        ENTER: E90.Move进资源(=acquire, 校验容量) / 工艺开始
        EXIT : 工艺Done(不改位置) / Swap换出时Move出(=release)
        每事件后 E90.AssertInvariants (唯一/容量/守恒)
   多片同刻不同阶段: W1在C1加工, W2在锁, W3被EFEM取 -> Job仍单一Executing
   全部AtDestination+设备内空+终验 -> Completed(W17)
   Trace带时间戳 -> 将来映射S16F1 / 算节拍 / 对账
```

## 四、今日易错点
1. 用真线程并行驱动片（逻辑时钟全序，确定可复现、可测）。
2. 执行器自己改位置（必须只经 E90 Move，守不变式）。
3. Process 完成就把片移出腔（工艺完成不改位置，Swap/取片才 Move）。
4. 资源占用与位置迁移脱节（进资源=acquire、出=release，一一对应）。
5. 每片各设一个 Job 状态（Job 单一 Executing，逐片用 WaferProcess）。
6. 某片完成就宣告 Job 完成（全部归位+终验才 Completed）。
7. 并发迁移不做每拍不变式断言（并发错误隐蔽，必须每拍查唯一/容量/守恒）。
8. 同刻动作处理顺序随机（(时间,进出,片ID) 全序 tie-break，保证确定性）。
