# W18 · Day03 答案与参考实现

## 一、自测题标准答案
1. **五依据/优先级 / 确定性**：①能力匹配（支持该工艺配方、状态可用，故障/维护/清洗中排除）；②最早可用（在满足前驱和互斥下选最早能开始的腔，即负载均衡）；③腔体亲和（同批/同配方尽量同腔，减小腔间差异、利于良率归因）；④配方切换代价（优先已就绪该配方、无需换菜单的腔，省切换时间与风险）；⑤健康/历史降权（近期报警、工艺漂移、累计片数多的腔降权）。优先级上先硬性筛"能力匹配且可用"，再在候选里按最早可用/亲和/切换/健康打分。必须确定性、可解释：相同输入选同一腔（固定 tie-break），并记录"为什么选它、其他腔为何落选"，这样调度可复现、良率问题可追溯到选腔决策、故障可复盘。
2. **均衡 vs 亲和 / 权衡**：负载均衡优点是各腔工作量均匀、等待最少、产能最大，缺点是同批片散在不同腔，腔间固有差异可能影响一致性、良率归因难；亲和优点是同批同腔、一致性好、易归因、减少配方切换，缺点是该腔忙时片要排队、产能下降。实践折中：批次内默认亲和（同批优先绑定腔），当亲和腔忙/故障/会显著拖慢时，按最早可用均衡改派到其他同型腔，并记录改派原因；即"一致性优先、产能兜底"，策略阈值可配置。
3. **流水线条件 / 资源不相交**：流水线让多片在不同阶段同时推进，成立条件=①前驱依赖满足（片必须先到 LoadLock 才能进腔、先取到才能加工）；②同时进行的动作占用**互不相交的资源集合**（片1 在 C1 加工占用 C1 时，真空臂可用且 C2 空闲，才能同时把片2 送 C2；EFEM 取片3 用大气资源，与真空侧不冲突）；③每个资源容量约束不被突破。必须资源不相交，因为同一资源（一个腔、一只臂）同一时刻只能服务一个动作，若重叠动作争用同一资源就违反容量互斥、物理上不可能同时发生；Day02 的时间区间互斥正是用来判定并安排哪些动作可以安全重叠。
4. **节拍 / Makespan 公式**：节拍（beat）是稳态下相邻两片产出的时间间隔，等于瓶颈资源服务一片所需时间（最慢环节决定多久出一片）。流水线启动时第一片要依次走完全路径（fill pipeline，时间较长），一旦所有资源都被填满进入稳态，之后每个瓶颈节拍就出一片，所以 n 片总完工时间 Makespan≈第一片走完全程的时间 +(n-1)×节拍。非流水线则约等于 n×单片全流程时间；流水线把后续每片成本从"全流程"压缩到"一个节拍"，片越多收益越大。
5. **双臂交换压缩节拍（预告）**：单臂到腔前若腔里有完成片，必须先把完成片取出（占臂）→放到安全位→再取新片送入，臂要多跑空程；双臂（或带交换位）可以一只手取着新片到腔前，用另一只手先取出腔内完成片，再把新片送入，一次到位完成"出旧进新"（swap），省掉完成片先去缓冲位再回来的往返，显著减少真空臂占用时间。而真空臂常是瓶颈，缩短它服务每片的时间就直接缩短了节拍，提升产能（明天 Day04 实现）。
6. **甘特图看瓶颈**：甘特图行是资源、列是时间，观察哪个资源的占用条几乎连续铺满整条时间轴（利用率接近 100%、没有空隙），它就是瓶颈；其他资源会出现规律性空闲（在等瓶颈）。还能看到：动作是否成功重叠（多行同一时间段都有占用）、哪里出现等待空隙及其原因（等锁/等臂）、首个节拍建立过程和稳态出片间隔。铺满的那一行对应的节拍就是整线节拍。
7. **加工中腔故障处理**：分两类。已在该腔的片：立即冻结，该片工艺中断、状态置为受影响（可能报废/需返工，不能算完成），经安全流程把片撤到安全位或保持并记录中断 Step，触发 Alarm/Fault，PJ 状态机按故障进入相应处置（W17）；等待该腔、尚未进入的片：不送入故障腔，由调度器把该腔标记不可用后重调度，按选腔策略改派到其他健康同型腔（亲和让位于可用性），已完成的其他片不受影响、不重排。即"在腔片走故障处置、未进片改派重排"。

## 二、参考实现（net8.0）

### 腔体选择
```csharp
namespace EapLab.E40.Sched;
public sealed class ChamberCandidate
{ public string Id=""; public bool Capable,Healthy,RecipeReady; public int ReadyAt; public int Load; public bool SameLotAffinity; public string? Note; }
public sealed class ChamberSelector
{
    public (string id,string reason) Choose(string lot,string recipe,List<ChamberCandidate> cs)
    {
        var ok=cs.Where(c=>c.Capable && c.Healthy).ToList();
        if(ok.Count==0) throw new InvalidOperationException("无可用同型腔");
        var pick=ok.OrderBy(c=>c.ReadyAt)                          // 最早可用
                   .ThenByDescending(c=>c.SameLotAffinity?1:0)     // 亲和优先
                   .ThenByDescending(c=>c.RecipeReady?1:0)         // 配方就绪
                   .ThenBy(c=>c.Load)                              // 负载
                   .ThenBy(c=>c.Id,StringComparer.Ordinal).First();// 确定性tie-break
        string reason=$"可用{ok.Count}; 最早{pick.ReadyAt}; 亲和={pick.SameLotAffinity}; 配方就绪={pick.RecipeReady}; 负载{pick.Load}";
        return (pick.Id,reason);
    }
}
```

### 流水线动作与编排
```csharp
public sealed record Op(string Wafer,string Resource,int Dur,string Stage,List<string> Preds);
public sealed record SchedOp(string Wafer,string Resource,int Start,int End,string Stage);
public sealed class PipelinePlanner
{
    private readonly Dictionary<string,ResourceCalendar> _cal=new();
    public PipelinePlanner(IEnumerable<Resource> rs){foreach(var r in rs)_cal[r.Id]=new(r.Id,r.Capacity);}

    public List<SchedOp> Plan(List<Op> ops)
    {
        var done=new Dictionary<string,SchedOp>(); var res=new List<SchedOp>();
        foreach(var op in ops)                                     // ops已按片序/前驱拓扑排好
        {
            int ready=op.Preds.Count==0?0:op.Preds.Max(p=>done[p].End);
            var cal=_cal[op.Resource];
            int s=cal.EarliestStart(ready,op.Dur);                 // 资源区间互斥->自动重叠/等待
            int e=s+op.Dur; var so=new SchedOp(op.Wafer,op.Resource,s,e,op.Stage);
            cal.Book(s,e); done[Key(op.Wafer,op.Stage)]=so; res.Add(so);
        }
        return res;
    }
    static string Key(string w,string st)=>$"{w}:{st}";
    public int Makespan(List<SchedOp> s)=>s.Max(x=>x.End);
    public int Beat(List<SchedOp> s,string bottleneck)            // 瓶颈资源相邻完成间隔
    { var ends=s.Where(x=>x.Resource==bottleneck).OrderBy(x=>x.End).Select(x=>x.End).ToList();
      return ends.Count<2?0:ends.Zip(ends.Skip(1),(a,b)=>b-a).Max(); }
}
```

### 文本甘特表
```csharp
public static class Gantt
{
    public static string Render(List<SchedOp> sched,int scale=1)
    {
        var sb=new StringBuilder(); int end=sched.Max(x=>x.End);
        foreach(var g in sched.GroupBy(x=>x.Resource).OrderBy(g=>g.Key,StringComparer.Ordinal))
        { sb.Append(g.Key.PadRight(5));
          var row=new char[end/scale+1]; Array.Fill(row,'.');
          foreach(var o in g) for(int t=o.Start/scale;t<o.End/scale;t++) if(t<row.Length) row[t]=o.Wafer[^1];
          sb.AppendLine(new string(row)); }
        return sb.ToString();
    }
}
```

public class PipelineTests

        new("C1",ResKind.Chamber,1,10),new("C2",ResKind.Chamber,1,10)};
        var p=new PipelinePlanner(rs);
        // W1先占C1; W2加工用C2, 与W1在C1的加工时间重叠
        var ops=new List<Op>{
            new("W1","EFEM",2,"load",new()),new("W1","C1",10,"proc",new(){"W1:load"}),
            new("W2","EFEM",2,"load",new()),new("W2","C2",10,"proc",new(){"W2:load"})};
        var s=p.Plan(ops);
        var w1c=s.First(x=>x.Wafer=="W1"&&x.Resource=="C1"); var w2c=s.First(x=>x.Wafer=="W2"&&x.Resource=="C2");
        Assert.True(w2c.Start < w1c.End);    // W2在C2加工与W1在C1加工时间重叠

      var s=p.Plan(new List<Op>{new("W1","C1",10,"p",new()),new("W2","C1",10,"p",new())});
      Assert.Equal(0,s[0].Start); Assert.Equal(10,s[1].Start); Assert.Equal(20,p.Makespan(s)); }

## 四、今日易错点
1. 选腔只看空闲不看能力/亲和/配方/健康（五依据综合，且确定性可解释）。
2. 绝对负载均衡牺牲同批一致性（批次内亲和优先、忙时才均衡改派）。
3. 让争用同一资源的动作"并行"（重叠动作必须资源不相交，区间互斥兜底）。
4. 忽略前驱依赖（没到锁不能进腔，流水线也要守拓扑顺序）。
5. 把 Makespan 当 n×单片全流程（流水线是首片+(n-1)×节拍）。
6. 不识别瓶颈，盲目给非瓶颈提速（节拍由铺满时间轴的资源决定）。
7. 腔故障时把等待片仍往故障腔送、或重排已加工片（在腔片走故障处置、未进片改派、已完成不动）。
8. 选腔 tie-break 随机导致不可复现（固定排序、记录理由）。
