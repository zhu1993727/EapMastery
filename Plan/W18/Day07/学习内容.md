## 四、W19 预热：E40 ProcessJob 综合实验周（25 分钟）
### 1. W19 定位
- W16 建 PJ 模型、W17 做状态机与恢复、W18 做多腔并发；W19 是 E40 部分的**集成验收缓冲周**，不引入大量新概念，重点是把它们连成工业级闭环并补薄弱点。

### 2. 综合主线（端到端）
```
E87 Loaded(预约/防错料) → E90注册载具与SlotMap
 → E40 建PJ(S14定义/S15创建) → 双校验 → Start
 → 多腔并发执行(W18): 选腔/流水线/双臂/双锁, 每拍守恒, S16进度事件
 → 跨载具搬运(W15): 源目映射/六道校验/终验
 → 正常完成(严格五条件) 或 Pause/Resume/Abort/故障重调度/重启恢复
 → 终验逐片ID+守恒 → UnloadGuard放行 → E87 Unload
```
