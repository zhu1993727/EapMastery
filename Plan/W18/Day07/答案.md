# W18 · Day07 答案

## 一、排障推演参考
1. **两片被调度进同一腔**：自底向上分层排查。①先看 E90 位置层是否报错（容量 1 被突破应在 Move 时直接拒绝）——若 E90 拦住了，说明是上层调度错误被正确兜底；②查全局调度器资源日程表：该腔两个动作的时间区间是否错误重叠（ResourceCalendar 容量/区间计算是否正确，是否把容量误设成 >1）；③查选腔器：是否给两片选了同一腔且时间未错开（选腔候选的 ReadyAt/占用是否没考虑在途占用）；④查并发执行器事件全序：是否两个 Enter 同刻、acquire 是否与 Move 一一对应（有无"账上没占、实际 Move 进腔"的脱节）。根因通常在②③：区间互斥失效或选腔没读最新占用。修复后加反例测试：同腔同刻两片必须被顺延或改派。
2. **真空臂成瓶颈、产能上不去**：先从甘特图确认 VR 行铺满（利用率近 100%、其他资源有空隙等它），确认瓶颈。优化手段按收益排序：①双臂 Swap 替代单臂往返，减少 VR 每片驻留（出旧进新一次到位）；②优化路径/动作时序，减少 VR 空程与等待（片提前在 LoadLock 就位、腔提前就绪）；③双 LoadLock 乒乓，让 VR 不必等抽破真空；④合理安排片顺序与选腔，缩短 VR 到各腔的平均移动；⑤若硬件允许，增加真空臂或缓冲位；⑥区分工艺瓶颈与搬运瓶颈——若优化 VR 后瓶颈转移到工艺腔，则应增加同型并行腔而非继续优化臂。核心是只优化当前瓶颈，非瓶颈优化不提升产能。

## 二、综合自测卷（8 题）标准答案
1. **拓扑图**：LP1/LP2（载具，25 槽）—EFEM 大气双臂—Aligner；EFEM—LL1/LL2（LoadLock，容量 1，大气/真空分界，抽破真空）—VR 真空双臂—C1/C2/C3（单片腔容量 1，工艺时长）；边表示可直接搬运。大气侧=LP/EFEM/Aligner，真空侧=VR/腔，LL 为分界。瓶颈候选：VR（服务所有腔的唯一共享搬运）、LL（抽破真空耗时、方向互锁）；三同型腔若是最慢工艺也可能是瓶颈。
2. **区间互斥 / 死锁**：每资源维护占用区间 [s,e)，新动作找不与已有区间冲突（容量 c 允许 c 个重叠）的最早空隙，冲突顺延，无需真锁。死锁四条件=互斥、持有并等待、不可剥夺、循环等待；设备上前三条物理难消，主要打破循环等待：所有动作按资源 ID 全局全序申请、逆序释放，等待边只从低序指向高序不成环；再配 all-or-nothing（拿不齐不持有）、分配图找环兜底、等待超时、Buffer 破位置环。
3. **选腔五依据 / 权衡**：能力匹配（支持工艺且健康可用）→最早可用（负载均衡）→腔体亲和（同批同腔一致性/良率归因）→配方切换代价（优先菜单就绪）→健康历史降权；固定 tie-break、确定性、记录理由。均衡产能最大但一致性弱，亲和一致性好但可能排队；实践批次内亲和优先、亲和腔忙或故障时按最早可用均衡改派并记录。
4. **节拍/Makespan / Swap、双锁**：节拍=瓶颈资源服务一片的时间；Makespan≈首片走完全程+(n-1)×节拍（非流水线≈n×全流程）。Swap 用双臂一次驻留完成出旧进新，省掉单臂送旧再返回的往返，直接缩短瓶颈 VR 的单片服务时间；双锁乒乓让一个锁抽/破真空时另一个锁供对侧使用，把抽破真空重叠在对侧动作里，减少 VR/EFEM 等锁时间——二者都压缩瓶颈占用从而缩短节拍。
5. **LL 安全约束 / 两门不同开**：锁有门状态（大气门/真空门/都关）、压力状态（大气/抽真空/真空/破真空）、方向（进/出）；进片先大气态开大气门放入、关门抽真空、真空到位才开真空门由 VR 取，出片反向破真空。两门绝不能同时开，否则大气直接灌入真空侧，造成严重设备/安全事故；必须对侧门确认关闭、压力到位才开本侧门，由锁状态机强制（压力互锁），乒乓只重叠不同锁的时间，不重叠同一锁对侧门。
6. **逻辑时钟并行 / acquire-release 对应 Move**：全局虚拟时钟，把每动作的进入/离开作为事件点按 (时间,进出,片ID) 全序处理，资源不相交的同刻动作即并行，结果确定可复现。片 Move 进入某资源时同时 acquire（占用+1、校验容量），Move 离开时 release（-1），资源占用与片实际位置严格一一对应；所有 Move 只经 E90，保证"片在资源=资源被占"，不会两片进容量 1 的腔。
7. **并发 Pause/Abort/故障**：Pause 用安全点栅栏，请求后任务 Pausing，等所有并发单元（在腔片到工艺边界、在臂/锁片到稳定位）都到安全点才整体 Paused，ResumeToken 含全部并发片位置、续跑不重不漏；Abort 先停调度、在途单元到安全点，再三分类（完成片不动、在途片经 E90 退源/保持、未开始留源），先撤片再释放资源、锁载具，终态不 Resume；腔故障时在腔片工艺中断走故障处置（判返工/报废、撤出/保持、Alarm），等待片排除故障腔改派健康同型腔，已完成片锁定不重排，只对未发生动作重调度。
8. **三层保障**：规划层（Scheduler/Selector）用区间互斥、固定顺序、all-or-nothing、能力匹配保证"计划上就不冲突、不死锁、资源不相交才并行"；位置层（E90）是唯一改位置入口，原子 Move+每拍断言唯一/容量/守恒，保证"物理上绝不叠片/丢片"，是最终兜底；状态层（PJ 状态机）保证 Job 单一权威状态、逐片进度、严格完成守卫、暂停/中止/恢复语义正确。规划可以重算、位置不可错、状态不混乱，三层职责分离又互相校验，所以高并行仍物理正确。

## 三、W19 预热思考题参考
1. **跨两源一目标、多腔并行的校验道数**：①E87 三个载具 Loaded 且预约/防错料通过；②E90 三载具 SlotMap 注册与初始守恒（三片集合基线）；③PJ Map 静态校验（源唯一/目标唯一/槽范围/片集合守恒，W16 六校验）；④开工前双校验（载具绑定口、ID、配方、资源）；⑤每片 AtPick 读码对源；⑥调度资源互斥（不同片同刻不撞腔/臂/锁）；⑦每拍位置不变式；⑧AtPlace CAS+放后读回对目标；⑨跨载具全局守恒（Σ载具+设备内=基线，合/拆批走集合守恒）；⑩终验逐片 ID 对目标、设备内空；⑪严格完成五条件；⑫UnloadGuard 全部门。本质是静态自洽→实时预检→动作前后→终验的多层防线。
2. **多 PJ 共享资源的调度扩展**：单 PJ 调度要提升为**全局多任务调度器**：资源日历跨所有 PJ 共享（不再只看一个 PJ 的动作）；每个动作带 PJ 标识与优先级；选腔/选臂在全局队列上统一仲裁（公平+老化防一个 PJ 饿死另一个）；增加 PJ 间依赖（一个 PJ 输出是另一个 PJ 输入时的前驱约束）与跨 PJ 片流转；死锁规避在全局资源序上做；一个 PJ Pause/Abort 只释放它占有的资源、不影响其他 PJ。这正是 E94 ControlJob 统一编排多个 ProcessJob 的雏形——W20-W22 展开。
3. **如何证明 E40 专家级可靠 / 反例测试**：用"正常+反例+故障+恢复"四类测试矩阵证明。正常：多腔并行/跨载具/合拆批的端到端正确性与产能；反例：错料/错槽/同腔冲突/死锁构造/非法状态迁移/部分完成冒充完成，都必须被对应守卫拒绝且零副作用；故障：腔/臂/锁故障、运动中掉电、通信断线，验证安全点、三分类、重调度、物理优先恢复；恢复：任意安全点 kill 后重启都能重建到一致状态或安全转人工、恢复幂等；并发：长时间随机混合负载下守恒永不被破坏。再加属性测试（随机调度下不变式恒成立）和确定性回放（同输入同轨迹）。覆盖率不是目标，"找不到能破坏不变式的反例"才是。

## 四、三张闭卷图自检要点
- 拓扑图：四类资源与容量、大气/真空分界与 LL、边=可达、VR/LL 瓶颈标注。
- 分层图：Planner/Selector（纯计划）→Scheduler 区间互斥→Executor 逻辑时钟→E90 唯一改位置并每拍断言→Job 状态机单一状态。
- Swap/双锁：Swap 先出后进、腔空才放、干涉区互斥；LL 两门不同开、压力到位、双锁乒乓角色交替。

## 五、W18 全周易错点总清单
1. 只建腔不建臂/锁资源（VR、LL 常是真瓶颈）。
2. 不区分大气/真空侧、忽略抽破真空与方向互锁。
3. 用真线程做并发（逻辑时钟确定、可复现、可算节拍）。
4. 时间区间允许容量 1 资源重叠（必须顺延/改派）。
5. 多资源不按固定全序申请、拿不齐还部分持有（循环等待/持有并等待死锁）。
6. 纯优先级无老化导致饥饿。
7. 选腔不看能力/亲和/健康、tie-break 随机不可复现。
8. 让争用同一资源的动作并行（重叠必须资源不相交）。
9. Swap 未确认腔空就放新片、双臂同时入干涉区。
10. LoadLock 两门同开/压力未到位就操作（安全红线）。
11. 执行器绕过 E90 改位置、资源占用与 Move 脱节。
12. Process 完成就移片（工艺状态与位置正交，Swap/取片才 Move）。
13. 并发 Pause 立即整体停（栅栏等全部单元到安全点）。
14. Abort 先释放资源后撤片（先撤到安全位再释放）。
15. 故障腔半成品片直接改派（在腔片走故障处置，等待片才改派，已完成锁定）。
16. 以为腔数=加速比（瓶颈在臂/锁时加速受节拍限制）。
