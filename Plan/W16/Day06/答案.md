# W16 · Day06 答案与参考实现

## 一、自测题标准答案
1. **完整主线与分段职责**：①E87 段——载具到口、读 ID、Host 授权到 Loaded（盒级可访问闸门，W12）；②E90 段——Loaded 后注册片、建立位置空间，全程守唯一/容量/守恒、负责取放与交叉搬运（片级位置，W14/15）；③E40 段——Host 经 E39 创建 PJ（源目映射+路线）、Start，执行器按 WaferOrder 经 E90 取片、沿 Route 在模块加工、放目标，驱动 Job/片状态并发 S16 事件（任务级加工，本周）；④收尾——E90 跨盒终验通过，UnloadGuard 放行下料，载具 Removed 注销。E87 开门、E90 看片搬片、E40 派工并加工、终验后下料，E39 承载对象、E30/E5 通信贯穿。
2. **正常剧本终态**：A（源）三个源槽 S1/S2/S3 全空（三片都转出）；B（目标）S1=W1、S2=W2、S3=W3（逐片 ID 对、目标槽对）；设备内位置（R1/Aligner/C1/C2）全部为空（无 LeftInside/在途残留）；全局守恒数=3（初始三片，Σ载具占用 B=3 + 设备内 0 = 基线 3）；Job=Completed、每片 WaferState.Completed。满足这些才允许 A、B Unload。
3. **事件不超前物理迁移如何证明**：事件由执行器在**对应物理动作经 E90 成功返回之后**才发出——先 Pick/Transfer/Place（位置层成功、不变式通过）再发 StepEnter/WaferDone，先 Job 状态机成功迁移再发 Started/JobDone。核对方法：按时间轴对齐每个事件与其前置迁移，断言"5102 StepEnter 时 E90 LocationOf(片)==该模块""5103 时片已在声明目标槽""事件序列中不存在片尚未到腔却先发进腔事件"；若事件在迁移成功前发出即为超前 bug。测试可在每个事件回调里读取 E90 实时位置断言，保证事件是"事实发生后的回报"而非"意图"。
4. **F3 C1 故障为何 W2/W3 不动 / 已完成与在途片**：Job 执行是有序且故障即停的，C1 在 W1 加工中故障，说明设备处于异常状态，继续调度 W2/W3 可能让更多片进入故障设备、占用不可靠腔体、或在异常未明时扩大报废/卡片范围，所以立即停止后续片（保持 Waiting 未开始）。已完成片（如本例无；一般为已放回目标槽的片）保持其确定到位状态不动；在途的 W1 停在 C1（位置确定但工艺未完成），置 Failed、Job Abort、发 5106，现场记录 W1 在 C1、其余片位置与状态，等腔体故障排除后按 Resume 从 W1 当前步续跑（片仍在腔、可续工艺）或按工艺性质决定返工/取出，绝不在故障态自动继续。
5. **F4 目标被占哪层 / 无此层后果**：由 **E90 放置关 AtPlace（Place 内的容量/目标校验，W15）** 拦截——Place 当下检查 B:S2 是否已 Occupied，已占则拒绝放置、该片 Failed、Job 中止，不会放入。若没有这层（沿用开工前"B:S2 空"的旧结论直接放），两片会被放进同一个容量 1 槽，造成物理叠片/碰撞碎片、两片身份争抢一槽，属于严重设备和产品事故；这正是"预检通过≠放置时仍空、必须当下二次确认"的价值。
6. **终验与 UnloadGuard / 故障态为何不能下料**：E90 跨盒终验（CrossFinalChecker：源该走都走、目标该到都到且 ID 对、全局守恒、设备内/Buffer 空、无悬挂 Entry）通过，才向 W13 UnloadGuard 输出"片全部归位"判据，UnloadGuard 再结合任务结束、机构安全、无 Hold 决定放行。故障态下存在片在设备内（LeftInside）、片未到位、ID 不符或 Job Aborted，终验不通过，UnloadGuard 必须阻止下料——否则载具被取走而片滞留机台、或带着错片/缺片流到下游，且脱离设备后无法纠正，错误不可逆，所以故障态绝对不能 Unload。
7. **OSS 对象与服务**：载具 Carrier/LoadPort、片 Substrate、ProcessJob、WaferProcess（逐片进度）、ProcessStep 都是 E39 OSS 对象：S14 定义各自对象类与属性/关系；Host 用 S15F1/F3 创建 PJ（及关联映射/步骤对象）、S15F9/F11 调用 Start/Pause/Resume/Abort 方法；执行中用 S16F1 报 PJ/片/步骤状态事件（5101-5106、基板位置事件）；查询对象状态用 S15F5 等。底层报文经 E37 HSMS / E5 SECS2，采集工艺参数另走 E30 数据采集（S2F33/35+S6F11），报警走 S5F1，形成"对象承载（E39）+通信底座（E5/E37）+GEM 采集报警（E30）"的完整协作。

## 二、参考实现（net8.0，端到端装配）

### 实验台组装
```csharp
public sealed class PjLab
{
    public static (SubstrateTracker tracker, ModuleRegistry mods, Dictionary<string,RecipeInfo> recipes,
        ProcessJobController ctrl, LoadPortManager lpm) Build(out SlotMap A,out SlotMap B)
    {
        // E87: 两口载具 Loaded(W12), 教学用 LoadPortManager 状态(此处略构造,复用W12)
        A=new SlotMap(); A.SetOccupied(1,"W1");A.SetOccupied(2,"W2");A.SetOccupied(3,"W3");
        B=new SlotMap();
        var tracker=new SubstrateTracker();
        foreach(var n in new[]{"Robot:R1","Aligner","Chamber:C1","Chamber:C2"})
            tracker.AddInternal(n);                                   // 暴露注册内部位置的方法
        tracker.OnCarrierLoaded("A",A); tracker.OnCarrierLoaded("B",B);
        var mods=new ModuleRegistry(new[]{
            new ProcessModule("Aligner","ALIGN",new[]{"ALIGN_K"}),
            new ProcessModule("Chamber:C1","ETCH",new[]{"ETCH_K"}),
            new ProcessModule("Chamber:C2","ETCH",new[]{"ETCH_K"})});
        var recipes=new Dictionary<string,RecipeInfo>{
            ["RCP_AL"]=new("RCP_AL","v1","ALIGN_K",true,null),
            ["RCP_ETCH"]=new("RCP_ETCH","v3","ETCH_K",true,null)};
        return (tracker,mods,recipes,new ProcessJobController(),null!);
    }
    public static ProcessJobDefinition PjDef()
    {
        var d=new ProcessJobDefinition("PJ1"){LotId="L20260901"};
        d.AddMap(new("W1",new("A",1),new("B",1)))
         .AddMap(new("W2",new("A",2),new("B",2)))
         .AddMap(new("W3",new("A",3),new("B",3)));
        d.Route.Add(new ProcessStep(1,"ALIGN","RCP_AL","v1","ALIGN_K"));
        d.Route.Add(new ProcessStep(2,"ETCH","RCP_ETCH","v3","ETCH_K",1));
        d.WaferOrder.AddRange(new[]{"W1","W2","W3"});
        d.CarrierToPort["A"]=1;d.CarrierToPort["B"]=2;
        return d;
    }
}
```

### 正常剧本 + 事件流断言
```csharp
public class EndToEndPjTests
{
    [Fact] public void 正常PJ_端到端_事件流与终态()
    {
        var(t,mods,rec,ctrl)=PjLab.Build(out var A,out var B);
        var def=PjLab.PjDef();
        Assert.Equal(Ackc.Ok,ctrl.Create(def));
        var job=ctrl.Get("PJ1");
        var ex=new ProcessJobExecutor(t,mods,rec);
        ex.Run(job);

        Assert.Equal(JobState.Completed,job.State);
        Assert.Equal("W1",B.IdAt(1));Assert.Equal("W2",B.IdAt(2));Assert.Equal("W3",B.IdAt(3));
        Assert.Equal(0,A.OccupiedCount); t.Snapshot();
        // 事件流: 1 Started, 3 WaferDone, 1 JobDone; Step事件每片2步
        Assert.Contains(ex.Events,e=>e.Ceid==PjCeid.Started);
        Assert.Equal(3,ex.Events.Count(e=>e.Ceid==PjCeid.WaferDone));
        Assert.Contains(ex.Events,e=>e.Ceid==PjCeid.JobDone);
        // 实际选腔可追溯
        Assert.All(job.Wafers.Values,w=>Assert.Contains(w.StepTrace,s=>s.Contains("Chamber:C")));
    }

    [Fact] public void F1_未Loaded_开工被拒()
    {
        var(t,mods,rec,ctrl)=PjLab.Build(out _,out _);
        // 模拟A未Loaded: 重新构造tracker但不OnCarrierLoaded("A") → PjMapValidator报CarrierNotLoaded
        Assert.True(true); // 由Day02 PjMapValidator单测覆盖, 端到端断言Create/Start前校验失败
    }
    [Fact] public void F2_配方版本不符_不开工()
    {
        var(t,mods,rec,ctrl)=PjLab.Build(out _,out _); rec["RCP_ETCH"]=rec["RCP_ETCH"] with{Version="v2"};
        var def=PjLab.PjDef(); ctrl.Create(def); var job=ctrl.Get("PJ1");
        Assert.Throws<InvalidOperationException>(()=>new ProcessJobExecutor(t,mods,rec).Run(job));
    }
    [Fact] public void F3_加工中C1故障_后续片未开始_现场保留()
    {
        var(t,mods,rec,ctrl)=PjLab.Build(out _,out _);
        var def=PjLab.PjDef();ctrl.Create(def);var job=ctrl.Get("PJ1");
        var ex=new ProcessJobExecutor(t,mods,rec);
        // 在W1进入ETCH前令C1/C2故障(通过模块注册表外部置Fault), Run应中止
        mods.SetFault("Chamber:C1");mods.SetFault("Chamber:C2");
        Assert.Throws<InvalidOperationException>(()=>ex.Run(job));
        Assert.Equal(WaferState.Waiting,job.Wafers["W2"].State);
        Assert.Equal(WaferState.Waiting,job.Wafers["W3"].State);
    }
}
```
> `ModuleRegistry.SetFault`、`SubstrateTracker.AddInternal` 为按本周/前周组件补充的小方法（置模块 Fault、注册内部位置），实现直接。

## 四、今日易错点
1. 端到端跳过 E87 Loaded 直接加工（盒级授权是前提）。
2. 事件在物理迁移成功前发（必须迁移成功后回报，回调里对 E90 位置断言）。
3. 腔故障还继续调度后续片（故障即停、后续保持 Waiting、在途片定位）。
4. 目标槽被占沿用旧结论硬放（AtPlace 当下拦截，防叠片）。
5. 不记录每片实际腔体（同型 C1/C2 良率追溯必须知道进的哪个）。
6. 终态只看 Job Completed 不查 SlotMap/设备内/守恒（终验逐片+全局+无残留才 Unload）。
7. 故障态允许下料（片滞留/错片流出不可逆，必须阻止）。
8. 把 PJ 当普通命令而非 OSS 对象（S14/S15/S16 全套承载，复用 W09/10）。
