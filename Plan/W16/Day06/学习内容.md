# W16 · Day06（周六）单 ProcessJob 端到端综合实验

> 建议时长：115 分钟。今天把 W12-W16 全部串起来跑一个完整 ProcessJob：E87 载具 Loaded → E90 位置/交叉 → E40 PJ（源目映射+多步路线+选腔+配方）→ S16 事件流 → 终验 Unload。这是从"盒进场"到"加工完下料"的第一条完整主线，并做故障演练。

## 一、今日目标
1. 搭建端到端实验台：双 LoadPort、多模块（对准+双刻蚀腔）、两载具、配方库、E87 状态门控。
2. 跑通一个多片、多步、跨盒 PJ：源 A→对准→刻蚀（C1/C2 并行）→目标 B，全程状态/位置/事件正确。
3. 验证完整事件流：5101 Started→5102 逐片逐 Step→5103 片完成→5104 Job 完成，且与位置/进度一致。
4. 故障注入 5 个：开工前载具未 Loaded、配方版本不符、加工中腔故障、目标槽被占、片失败 Job 中止与现场保留。
5. 产出端到端实验报告。

## 二、实验台与剧本（先读，30 分钟）

### 1. 实验台组成
```
LoadPort: LP1=FOUP-A(源: S1=W1,S2=W2,S3=W3), LP2=FOUP-B(目标,空), 均经E87到Loaded
设备内位置: Robot:R1, Aligner(ALIGN), ETCH腔 C1/C2(同型), (LoadLock简化)
配方库: RCP_AL(v1,ALIGN_K), RCP_ETCH(v3,ETCH_K)
组件: E87 LoadPortManager(W12) + SubstrateTracker(W14/15)
      + PjMapValidator/RouteValidator + ProcessJobController + ProcessJobExecutor
```

### 2. PJ 剧本
```
PJ1 / Lot=L20260901 / WaferOrder=W1,W2,W3
Maps: W1 A:S1→B:S1; W2 A:S2→B:S2; W3 A:S3→B:S3 (跨盒)
Route: Step1 ALIGN/RCP_AL(v1) → Step2 ETCH/RCP_ETCH(v3) (依赖Step1)
选腔: ETCH 同型 C1/C2, 逐片选可用腔(可并行)
预期:
 - 每片: A槽→R1→Aligner(对准)→C1或C2(刻蚀)→R1→B对应槽
 - Job: Started→三片依次(或步骤内并行)加工→Completed
 - B:S1=W1,B:S2=W2,B:S3=W3; A清空; 设备内空; 全局守恒3
 - 终验通过 → A、B 允许 Unload
```

### 3. 事件流核对（20min）
- 打印全部 S16 事件，断言：1 个 5101、每片 2 步的 StepEnter/Done、3 个 5103、1 个 5104。
- 每个 StepEnter 快照的实际腔体与 StepTrace 一致；5103 的目标槽与 Map 一致。
- 事件顺序与物理迁移顺序一致（不超前、不缺失）。

### 4. 故障注入（30min）
- F1 未 Loaded：A 只 Installed 就 Create+Start，PjMapValidator/门控拒绝。
- F2 配方版本不符：RCP_ETCH 实际 v2，RouteValidator/进腔前校验拦截，Job 不开始或中止。
- F3 加工中 C1 故障：W1 在 C1 时 C1 置 Fault，执行器捕获、Job Abort、W2/W3 未动、现场含每片位置。
- F4 目标槽被占：Place 前 B:S2 被占，AtPlace 拦截、该片失败、Job 中止（不叠片）。
- F5 片失败中止与现场：验证 Aborted 后 Partial 现场完整（每片实际位置/Step/事件），Resume 可续（故障解除后）。

### 5. 终验与下料（15min）
- 正常剧本结束：E90 跨盒终验（源逐片/目标逐片/全局守恒/设备内空）→ UnloadGuard 放行 A、B。
- 对照：任一故障态下 Unload 必须被阻止。

### 6. 实验报告（20min）
- 初始/最终 SlotMap、PJ 定义、每片路径与实际腔体、完整事件流、守恒快照、终验结论、5 故障证据。
