# W16 · Day02 答案与参考实现

## 一、自测题标准答案
1. **Source/Destination 声明什么 / 几个**：Source Job 声明本 PJ 从哪些载具的哪些槽取片（源载具 + 源槽集合 + 每片身份），Destination Job 声明加工后片放到哪些载具的哪些槽（目标载具 + 目标槽）。一个 PJ 可以有**多个** Source 和多个 Destination（合批多源汇入、拆批/分档分到多目标），但对每一片而言其源位置和目标位置必须唯一确定（一片一个源、一个目标）。同盒加工时 Source 与 Destination 指向同一载具，跨盒时不同。
2. **为何还要绑定 LoadPort / 前提**：PJ 声明用逻辑 CarrierID 标识载具，但设备上载具是插在具体物理 LoadPort（LP1/LP2…）上的，执行取放必须知道到哪个口动作；且要防止"声明的载具"和"口上实际的载具"不是同一个（换盒、插错口）。绑定前提：该 CarrierID 确实在某 LoadPort 上、E87 状态为 Loaded（已授权）、口上读到的载具 ID 与声明一致（W12 ID 校验），绑定关系在 PJ 生命周期内固定，执行中若该口换盒/卸载要立即判异常，防止对错误载具动作。
3. **Wafer Order / 何时严格遵从**：Wafer Order 规定 PJ 内片的加工次序（槽升序/降序、Host 指定片序、或授权的设备优化序）。它解决"多片先做谁后做谁"，影响双臂/腔体调度效率，也影响有工艺先后要求的场景。必须严格遵从 Host 顺序的情况：工艺对先后敏感（热预算、前片结果影响后片、定向分档）、Host 出于产能/良率/在制品管理指定次序、交叉布局要求按特定顺序腾挪槽位时；设备不得擅自重排，只有 Host 明确允许设备优化顺序时才可按效率调整。
4. **六项校验 / 哪些沿用哪些新增**：①源完整（源槽确有该片、ID 对、源不重复）——沿用 W15 源唯一/Preflight；②目标完整（目标不重复带载具判定、当前空、目标载具 Loaded）——沿用 W15 目标唯一/Preflight；③一一对应（每片恰一源一目标、源片集合=目标片集合守恒，合拆批按批令）——沿用 W15 守恒；④**覆盖完整（PJ 声明加工片集合=源映射片集合，不漏不多）——PJ 新增**；⑤**顺序合法（WaferOrder 引用片都在映射中、无重漏）——PJ 新增**；⑥**载具绑定一致（源/目标 CarrierID 都绑定到 Loaded 的 LoadPort、口上 ID 一致）——PJ 新增（把 E87 端口绑定纳入校验）**。前三项是 W15 CrossMap 校验在 PJ 内复用，后三项是"任务级"新增的完整性与绑定校验。
5. **覆盖完整防什么**：防止"声明要加工的片"和"映射里实际安排源目的片"不一致——漏映射（某片在加工清单里却没有源/目标，执行时被漏掉，片没加工却随盒流走，或任务卡住）、多映射（映射里出现清单外的片，被误加工/误搬运）、片集合对不上（批次构成被悄悄改变）。覆盖校验保证 PJ 说做哪些片，源目映射就恰好、且只安排这些片，每个都有确定去向，是任务完整性和批次正确的底线。
6. **OSS/SECS 承载**：PJ 及其源/目标映射都是 E39 OSS 对象：S14 定义 ProcessJob、WaferMap、Source/Destination 等对象类与属性（片 ID、载具、槽、顺序），S15F1/F3 创建 PJ 实例时把映射作为属性值带入，S16F1 在执行中报 PJ/片状态事件。SECS-II 层面映射用嵌套 List 承载，例如源侧 L,n[L,3[A waferId,A srcCarrier,U1 srcSlot]…]、目标侧同构（目标槽/目标载具），WaferOrder 用有序片 ID 列表；精确对象名与属性结构以 SEMI E40/E39 原文为准，先掌握"对象建模+结构化列表承载+事件回报"的机制。
7. **同盒 vs 跨盒结构区别**：同盒加工时，每片 Source 与 Destination 的 Carrier 相同（槽可同可不同），PJ 只绑定一个载具，源目守恒在单载具内成立（同槽则槽也相同）；跨盒时 Source 与 Destination 指向不同载具，PJ 至少绑定两个载具（源口、目标口都要 Loaded），守恒要跨载具全局成立（源减=目标增、在途计入设备内），映射结构本身统一（都是 片→源(盒,槽)、片→目标(盒,槽)），区别只在源目载具是否相同、绑定载具数量与守恒口径，这正是 W15"交叉是一般形式"在 PJ 里的体现——同一套映射模型表达两种情况。

```csharp
namespace EapLab.E40;
public sealed record WaferMap(string WaferId, SlotRef Src, SlotRef Dst);
public enum OrderMode { SlotAsc, SlotDesc, HostSpecified, DeviceOptimized }
public sealed class ProcessJobDefinition
{
    public string JobId { get; } public string LotId { get; init; }="";
    public List<WaferMap> Maps { get; }=new();
    public List<string> WaferOrder { get; }=new();   // 有序片ID
    public OrderMode OrderMode { get; init; }=OrderMode.SlotAsc;
    public Dictionary<string,int> CarrierToPort { get; }=new(); // carrierId -> loadport
    public ProcessJobDefinition(string id){JobId=id;}
    public ProcessJobDefinition AddMap(WaferMap m){Maps.Add(m);return this;}
    public IEnumerable<string> SourceCarriers => Maps.Select(m=>m.Src.Carrier).Distinct();
    public IEnumerable<string> DestCarriers => Maps.Select(m=>m.Dst.Carrier).Distinct();
}
public enum PjIssueCode { SourceMissing,SourceIdMismatch,DuplicateSource,DuplicateTarget,TargetOccupied,
    CarrierNotBound,CarrierNotLoaded,PortIdMismatch,NotOneToOne,CoverageGap,CoverageExtra,OrderInvalid,SlotRange }
public sealed record PjIssue(PjIssueCode Code,string Detail);
```

### 六项映射校验
```csharp
public sealed class PjMapValidator
{
    // 提供载具实时状态: 槽位图 / 载具是否Loaded / 口上实际载具ID
    private readonly IReadOnlyDictionary<string,SlotMap> _slot;
    private readonly Func<string,bool> _loaded;
    private readonly Func<int,string?> _carrierOnPort; // loadport -> actual carrierId
    public PjMapValidator(IReadOnlyDictionary<string,SlotMap> slot,Func<string,bool> loaded,Func<int,string?> onPort)
    {_slot=slot;_loaded=loaded;_carrierOnPort=onPort;}

    public List<PjIssue> Validate(ProcessJobDefinition pj)
    {
        var issues=new List<PjIssue>();
        var srcSeen=new Dictionary<SlotRef,string>(); var dstSeen=new Dictionary<SlotRef,string>();
        var declared=new HashSet<string>(pj.Maps.Select(m=>m.WaferId));
        foreach(var m in pj.Maps)
        {
            if(m.Src.Slot is <1 or >25||m.Dst.Slot is <1 or >25){issues.Add(new(PjIssueCode.SlotRange,m.WaferId));continue;}
            // 载具绑定(⑥)
            foreach(var c in new[]{m.Src.Carrier,m.Dst.Carrier}.Distinct())
            {
                if(!pj.CarrierToPort.TryGetValue(c,out var port)){issues.Add(new(PjIssueCode.CarrierNotBound,c));continue;}
                if(!_loaded(c)){issues.Add(new(PjIssueCode.CarrierNotLoaded,c));continue;}
                if(_carrierOnPort(port)!=c) issues.Add(new(PjIssueCode.PortIdMismatch,$"{c} 端口{port}实际载具不符"));
            }
            // 源完整(①)
            if(srcSeen.TryGetValue(m.Src,out var o)) issues.Add(new(PjIssueCode.DuplicateSource,$"{m.Src}:{o}/{m.WaferId}"));
            else srcSeen[m.Src]=m.WaferId;
            if(_slot.TryGetValue(m.Src.Carrier,out var sm))
            { if(sm.StateAt(m.Src.Slot)!=SlotState.Occupied) issues.Add(new(PjIssueCode.SourceMissing,$"{m.WaferId}@{m.Src}"));
              else if(sm.IdAt(m.Src.Slot)!=m.WaferId) issues.Add(new(PjIssueCode.SourceIdMismatch,$"{m.WaferId} 实际{sm.IdAt(m.Src.Slot)}")); }
            // 目标完整(②)
            if(dstSeen.TryGetValue(m.Dst,out var o2)) issues.Add(new(PjIssueCode.DuplicateTarget,$"{m.Dst}:{o2}/{m.WaferId}"));
            else dstSeen[m.Dst]=m.WaferId;
            if(!(m.Src==m.Dst) && _slot.TryGetValue(m.Dst.Carrier,out var dm) && dm.StateAt(m.Dst.Slot)==SlotState.Occupied)
                issues.Add(new(PjIssueCode.TargetOccupied,$"{m.WaferId} 目标{m.Dst}占用"));
        }
        // 一一对应(③): 每片唯一源目(已由遍历保证), 守恒(普通PJ源集合=目标集合,此处片ID集合天然相等,校验重复片)
        if(pj.Maps.Select(m=>m.WaferId).Distinct().Count()!=pj.Maps.Count)
            issues.Add(new(PjIssueCode.NotOneToOne,"存在同片多映射"));
        // 覆盖完整(④): WaferOrder/声明集合 与 映射集合 一致
        var mapped=new HashSet<string>(pj.Maps.Select(m=>m.WaferId));
        foreach(var d in declared.Except(mapped)) issues.Add(new(PjIssueCode.CoverageGap,d));
        // 顺序合法(⑤)
        if(pj.WaferOrder.Count>0)
        { if(new HashSet<string>(pj.WaferOrder).Count!=pj.WaferOrder.Count) issues.Add(new(PjIssueCode.OrderInvalid,"顺序有重复"));
          foreach(var w in pj.WaferOrder) if(!mapped.Contains(w)) issues.Add(new(PjIssueCode.OrderInvalid,$"顺序引用未知片 {w}"));
          if(pj.OrderMode==OrderMode.HostSpecified && pj.WaferOrder.Count!=mapped.Count)
              issues.Add(new(PjIssueCode.OrderInvalid,"Host指定顺序未覆盖全部片")); }
        return issues;
    }
}
```

```csharp
public class PjMapTests
{
    static Dictionary<string,SlotMap> TwoCarriers(out SlotMap a,out SlotMap b)
    { a=new SlotMap();a.SetOccupied(1,"W1");a.SetOccupied(3,"W3"); b=new SlotMap();
      return new(){{"A",a},{"B",b}}; }

    [Fact] public void 合法跨盒映射_通过()
    { var maps=TwoCarriers(out var a,out var b);
      var pj=new ProcessJobDefinition("PJ1"){OrderMode=OrderMode.HostSpecified}
        .AddMap(new("W1",new("A",1),new("B",1))).AddMap(new("W3",new("A",3),new("B",2)));
      pj.CarrierToPort["A"]=1;pj.CarrierToPort["B"]=2;
      pj.WaferOrder.AddRange(new[]{"W1","W3"});
      var v=new PjMapValidator(maps,c=>true,p=>p==1?"A":"B");
      Assert.Empty(v.Validate(pj));
    }
    [Fact] public void 目标重复_报DuplicateTarget()
    { var maps=TwoCarriers(out _,out _);
      var pj=new ProcessJobDefinition("PJ").AddMap(new("W1",new("A",1),new("B",1)))
            .AddMap(new("W3",new("A",3),new("B",1))); // 同目标B:1
      pj.CarrierToPort["A"]=1;pj.CarrierToPort["B"]=2;
      Assert.Contains(new PjMapValidator(maps,c=>true,p=>p==1?"A":"B").Validate(pj),i=>i.Code==PjIssueCode.DuplicateTarget);
    }
    [Fact] public void 端口载具不符_报PortIdMismatch()
    { var maps=TwoCarriers(out _,out _);
      var pj=new ProcessJobDefinition("PJ").AddMap(new("W1",new("A",1),new("B",1)));
      pj.CarrierToPort["A"]=1;pj.CarrierToPort["B"]=2;
      Assert.Contains(new PjMapValidator(maps,c=>true,p=>"X").Validate(pj),i=>i.Code==PjIssueCode.PortIdMismatch);
    }
    [Fact] public void Host顺序漏一片_报OrderInvalid()
    { var maps=TwoCarriers(out _,out _);
      var pj=new ProcessJobDefinition("PJ"){OrderMode=OrderMode.HostSpecified}
        .AddMap(new("W1",new("A",1),new("B",1))).AddMap(new("W3",new("A",3),new("B",2)));
      pj.CarrierToPort["A"]=1;pj.CarrierToPort["B"]=2; pj.WaferOrder.Add("W1"); // 漏W3
      Assert.Contains(new PjMapValidator(maps,c=>true,p=>p==1?"A":"B").Validate(pj),i=>i.Code==PjIssueCode.OrderInvalid);
    }
}
```

## 三、今日易错点
1. 认为一个 PJ 只能一个源/一个目标（可多源多目标，但每片源目唯一）。
2. 只用 CarrierID 不绑定 LoadPort（必须绑口、校验口上载具 ID 一致、生命周期固定）。
3. WaferOrder 与映射脱节（顺序引用的片必须都在、Host 序必须全覆盖）。
4. 漏掉 PJ 新增的覆盖完整/顺序合法/载具绑定校验，只做 W15 的源目守恒。
5. 目标冲突只按槽号不按（载具,槽）。
6. 同盒/跨盒写两套结构（统一映射模型，区别只在载具是否相同与守恒口径）。
7. 以为映射只是数据，不当 OSS 对象（S14 定义/S15 带值/S16 回报）。
8. 设备擅自优化 Host 指定顺序（工艺敏感时必须严格遵从）。
