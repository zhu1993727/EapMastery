# W16 · Day04 答案与参考实现

## 一、自测题标准答案
1. **整体状态与逐片进度为何分开**：二者正交、变化节奏不同。Job 整体状态（Queued/Executing/Paused/Completed…）描述整个任务的生命周期，只有一个；逐片进度描述每片走到哪个 Step、片状态、当前位置，一个 PJ 有多份且各自推进。执行中 PJ=Executing 时各片可分别处于等待/某步加工/完成（Day01 并发例）。若混存，要么无法表达"部分片完成、部分在加工"，要么整体状态被迫随每片频繁变化而失去任务级语义。分开后：整体状态由状态机统一迁移，逐片进度独立推进，PJ 是否 Completed 由"所有片都完成"这一聚合条件判定，层次清晰且支持并行。
2. **S14 元数据属性/关系**：属性至少含 JobId(A)、LotId(A)、Priority(U1/U2)、JobState(U1 枚举)、源/目标载具列表、WaferMap 集合（每片源槽/目标槽）、Route 步骤集合（步骤号/模块类型/配方与版本）、进度统计（总片数/完成片数/失败片数、当前步骤）、时间戳（创建/开始/完成）。对象关系：ProcessJob 1—N 包含 WaferProcess（逐片进度对象），Route 1—N 包含 ProcessStep 描述对象；PJ 还关联 Carrier/LoadPort 对象（源目载具）。空集合按 OSS 规则回 L,0；属性类型用 SECS2 基础类型（A/U1/U4/L 等，W03）。
3. **各操作对应 OSS 服务**：创建 PJ 实例=**S15F1/F3 Create**（带 WaferMap+Route 属性值，等价下发任务）；启动 Start、暂停 Pause、恢复 Resume、取消 Cancel、中止 Abort=**S15F9/F11 方法调用**（在 PJ 对象上调用命名方法）。S14 负责先定义这些对象类/方法/属性的元数据，S16 负责操作引发的状态事件。ACKC 沿用 W10：Create/方法调用的同步应答只表"请求是否被接受"（0 接受，类型不存在/只读/参数错/状态非法等用对应非 0 码）。
4. **S15F10 为何不代表 Start 成功 / 靠什么**：S15F10（方法调用应答 ACKC=0）只表示设备**接受并受理**了 Start 请求（请求格式合法、对象存在、方法存在），是同步受理层语义；真正"开始执行"是异步的——设备要完成前置检查、调度资源、实际启动第一片加工，之后 PJ 状态迁到 Executing 并发 **S16F1（5101 PJ Started）事件**，这才是开始的权威信号（W10"S15F10 是接受不是完成、完成靠 S16F1"口径）。若只凭 F10 就认为已启动，会在启动实际失败/延迟时误判。同理 Completed 靠 5104 事件而非命令应答。
5. **S16 事件与时机**（教学 CEID）：5101 PJ Started——Start 方法受理且实际进入 Executing；5102 Wafer Step Enter/Done——某片进入/完成某工艺 Step（带片ID/步骤/选中腔体/配方）；5103 Wafer Completed——某片走完所有 Step 并放到目标槽；5104 PJ Completed——所有片完成且归位、整体迁移到 Completed；5105 PJ Paused——暂停生效；5106 PJ Aborted/Failed——中止或故障（带原因/当前片位置）。S16F1=L,3[OBJSPEC,CEID,快照]，订阅过滤复用 W10 模型。
6. **Queued 能否直接 Complete / 谁阻止**：不能。合法生命周期必须 Queued→（Start）Executing→（全部片完成）Completed，Queued 直接到 Completed 属于非法迁移，由 **W10 泛型 StateMachine 的配置（Permit/PermitIf）**阻止：只为每个状态配置合法出边，未配置的迁移在 Fire 时被拒、零副作用（不改变状态、不发事件），并在 S15 方法层返回"状态非法"ACKC（对应码 8）。Completed 的进入还应有聚合守卫（所有 WaferProcess 都 Completed 才允许），用 PermitIf 表达，防止没加工完就标完成。
7. **WaferProcess 记录 / 与 E90 位置关系**：WaferProcess 记录每片的 WaferId、Src/Dst 槽位、当前 StepNo、片状态（Waiting/InProcess/StepDone/Completed/Failed）、当前/历史所在模块、结果量测、步骤轨迹。它描述"这片的**加工进度**"；E90 描述这片的**物理位置**（在源槽/臂/某腔/目标槽，守唯一/守恒）。二者关联但不重复：WaferProcess.当前位置应与 E90 LocationOf(片) 一致（加工步在某腔时，E90 位置也是该腔，片状态 InProcess），由执行器在每次迁移/推进时同时更新并互相印证；进度是工艺维度、位置是物理维度，正交且一致。

### ProcessJob 聚合
```csharp
public sealed class ProcessJob
{
    public ProcessJobDefinition Def { get; } public JobState State { get; private set; }=JobState.Queued;
    public Dictionary<string,WaferProcess> Wafers { get; }=new();
    public List<object> Events { get; }=new();
    private readonly StateMachine<JobState,JobMethod> _sm;
    public ProcessJob(ProcessJobDefinition def)
    {
        Def=def;
        foreach(var m in def.Maps) Wafers[m.WaferId]=new WaferProcess(m.WaferId,m.Src,m.Dst);
        _sm=new StateMachine<JobState,JobMethod>(JobState.Queued);
        _sm.Configure(JobState.Queued).Permit(JobMethod.Start,JobState.Executing).Permit(JobMethod.Cancel,JobState.Cancelled);
        _sm.Configure(JobState.Executing).Permit(JobMethod.Pause,JobState.Paused).Permit(JobMethod.Abort,JobState.Aborted)
            .PermitIf(JobMethod.Start,JobState.Completed,()=>Wafers.Values.All(w=>w.State==WaferState.Completed)); // 全片完成才Complete
        _sm.Configure(JobState.Paused).Permit(JobMethod.Resume,JobState.Executing).Permit(JobMethod.Abort,JobState.Aborted);
        _sm.StateChanged += (f,t,act)=>Events.Add(new JobStateEvent(Def.JobId,act,f,t));
    }
    public bool TryMethod(JobMethod m,out string err)
    { try{ _sm.Fire(m); err=""; return true; }
      catch(InvalidOperationException ex){ err=ex.Message; return false; } }
    public bool AllDone => Wafers.Values.All(w=>w.State==WaferState.Completed);
    public void CompleteIfAllDone(){ if(AllDone) TryMethod(JobMethod.Start,out _); /* 以Start触发守卫迁移到Completed */ }
}
public sealed record JobStateEvent(string JobId,JobMethod Method,JobState From,JobState To);
```
> 说明：用同一触发通道 + PermitIf 守卫表达"全片完成才进 Completed"；实际可定义独立 Complete 方法更直观，教学保留状态机守卫演示。

### S15 操作适配（Create + 方法调用，ACKC 沿用 W10）
```csharp
namespace EapLab.E40.S15;
public enum Ackc { Ok=0, NoSuchType=1, NoSuchInstance=2, AlreadyExists=3, NoSuchAttr=4, ReadOnly=5,
    MissingRequired=6, InvalidType=7, IllegalState=8, NoSuchMethod=9, InvalidParam=10, Internal=99 }
public sealed class ProcessJobController
{
    private readonly Dictionary<string,ProcessJob> _jobs=new();
    public Ackc Create(ProcessJobDefinition def)
    {
        if(_jobs.ContainsKey(def.JobId)) return Ackc.AlreadyExists;
        if(def.Maps.Count==0) return Ackc.MissingRequired;
        _jobs[def.JobId]=new ProcessJob(def); return Ackc.Ok;   // S15F1/F3
    }
    public (Ackc ack, ProcessJob? job) InvokeMethod(string jobId,JobMethod m)   // S15F9/F11
    {
        if(!_jobs.TryGetValue(jobId,out var job)) return (Ackc.NoSuchInstance,null);
        return job.TryMethod(m,out var err)?(Ackc.Ok,job):(Ackc.IllegalState,null);
    }
    public ProcessJob Get(string id)=>_jobs[id];
}
```

### xUnit
```csharp
public class ProcessJobModelTests
{
    static ProcessJobDefinition Def()=> new ProcessJobDefinition("PJ1")
        .AddMap(new("W1",new("A",1),new("B",1))).AddMap(new("W3",new("A",3),new("B",2)));

    [Fact] public void 正常生命周期_Queued到Executing()
    { var c=new ProcessJobController();
      Assert.Equal(Ackc.Ok,c.Create(Def()));
      var(ack,j)=c.InvokeMethod("PJ1",JobMethod.Start);
      Assert.Equal(Ackc.Ok,ack); Assert.Equal(JobState.Executing,j!.State); }

    [Fact] public void Queued直接Complete_非法()
    { var c=new ProcessJobController(); c.Create(Def());
      // 未Start且片未完成, 不存在Queued->Completed出边
      var(ack,_)=c.InvokeMethod("PJ1",JobMethod.Start); Assert.Equal(Ackc.Ok,ack); // 到Executing
      // 再次Start试图Complete但片未完成, 守卫拒绝
      var(ack2,j2)=c.InvokeMethod("PJ1",JobMethod.Start);
      Assert.Equal(Ackc.IllegalState,ack2); Assert.Equal(JobState.Executing,j2!.State); }

    [Fact] public void 重复Create_AlreadyExists()
    { var c=new ProcessJobController(); c.Create(Def());
      Assert.Equal(Ackc.AlreadyExists,c.Create(Def())); }

    [Fact] public void 暂停恢复_事件留痕()
    { var c=new ProcessJobController(); c.Create(Def()); c.InvokeMethod("PJ1",JobMethod.Start);
      c.InvokeMethod("PJ1",JobMethod.Pause); Assert.Equal(JobState.Paused,c.Get("PJ1").State);
      c.InvokeMethod("PJ1",JobMethod.Resume); Assert.Equal(JobState.Executing,c.Get("PJ1").State); }
}
```

## 三、今日易错点
1. Job 整体状态与逐片进度混存（必须正交，Completed 由"全片完成"守卫）。
2. 把 S15F10/方法应答当执行成功（受理≠执行，开始/完成以 S16 事件为准）。
3. 状态迁移不经过状态机，允许 Queued 直接 Completed（非法迁移零副作用）。
4. PJ 不当 OSS 对象、另造一套命令协议（复用 S14 定义/S15 操作/S16 事件与 ACKC）。
5. WaferProcess 重复存一份物理位置且不与 E90 对齐（进度与位置正交但须一致、互相印证）。
6. 空集合不回 L,0、属性 SECS 类型混乱。
7. Create 不校验映射/路线（应在创建或 Start 前用 Day02/03 校验器把关）。
8. 事件不带片/步骤/模块快照，后续无法关联 FDC/YMS。
