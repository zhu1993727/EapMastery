## 二、设计（先读，30 分钟）

### 1. ProcessJob 聚合结构
```
ProcessJob (聚合根, 也是OSS对象)
 ├ Identity: JobId, LotId, Priority
 ├ Definition: WaferMaps(Day02) + Route(Day03)
 ├ State: JobState(整体, 正交于片)
 ├ WaferProgress: 每片 { 当前Step, 片状态, 位置, 轨迹 }
 ├ StepProgress: 每步 { 待/执行/完成片数, 选定腔体 }
 └ 操作: Create/Start/Pause/Resume/Cancel/Abort（经S15方法）, 内部迁移由执行器驱动(Day05)
```

### 2. Job 整体状态机（本周先建模，W17 深入）
- 状态（典型）：Queued（已创建未启动）→Started/Executing（执行中）→Paused（暂停）→Completed（完成）；异常→Failed/Aborted；可在未启动时 Cancel。
- 合法迁移用 W10 泛型 StateMachine 配置 Permit/PermitIf，非法操作零副作用。
- Job 状态与每片进度正交（Day01）。

### 3. 作为 OSS 对象（复用 W09/W10）
- **S14 元数据**：为 ProcessJob 对象类定义属性：JobId(A)、LotId(A)、State(U1 枚举)、Priority、关联 WaferMap 列表、Route 步骤列表、进度统计；对象关系：PJ 包含多个 WaferProcess 对象（每片进度）。
- 空集合回复 L,0、属性类型用 W03 SECS2 类型（A/U1/U4/L）。
- **S15 操作**：
  - S15F1/F3 Create：Host 创建 PJ 实例，属性带 WaferMap+Route（等价下发任务），ACKC 语义沿用（0 接受；类型/参数错用对应码）。
  - S15F9/F11 方法调用：Start/Pause/Resume/Cancel/Abort 作为对象方法，方法前置条件=状态机合法迁移（如 Paused 才能 Resume）。
  - S15F10 只表接受，真正完成靠 S16 事件（W10 口径）。
- **S16 事件**：
  - CEID 约定（教学编号）：5101 PJ Started、5102 Wafer Step Enter/Done、5103 Wafer Completed、5104 PJ Completed、5105 PJ Paused、5106 PJ Aborted/Failed。
  - S16F1=L,3[A OBJSPEC,U4 CEID,L 快照]，快照带 JobId/片ID/Step/模块/状态。

### 4. 逐片进度对象 WaferProcess
- 每片：WaferId、Src/Dst、当前 StepNo、片状态（Waiting/InProcess/StepDone/Completed/Failed）、当前位置、结果。
- 推进由 Day05 执行器调用（EnterStep/FinishStep/Complete），每次推进发对应 S16 事件并更新聚合。

### 5. 与 W10 框架对接点
- 复用 ObjectModel（对象/属性）、S15 方法分发与 ACKC、S16 订阅与发布、泛型 StateMachine，不新造轮子。
- 命名空间 EapLab.E40.Model/.S14/.S15/.S16，保持分层一致。

### 6. 边界
- 今天只做对象与操作/事件的"模型正确性"（不真正驱动运动），Day05 接 E90 位置层与模块执行。
