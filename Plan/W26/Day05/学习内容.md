# W26 · Day05（周五）专家总验收⑤：代码资产总盘点（build + test + 架构走查）

> 建议时长：110 分钟。25 周沉淀了一套 EapLab 教学代码资产。今天把它们组织成一个可一次 build、全测试绿、依赖单向无环的解决方案，逐命名空间讲清职责与关键类，做到"闭着眼睛知道哪个问题去哪层、复用哪个件"。这是从"会写片段"到"拥有自己的 EAP 框架资产"的关键一步。

## 一、今日目标
1. 把 26 周代码按分层组织成 EapLab 解决方案（项目/文件夹、命名空间、依赖方向）。
2. 一次 `dotnet build` 通过、全部 xUnit `dotnet test` 通过，记录用例数。
3. 架构走查：依赖只能单向（Domain←各标准层←Cell/Host），无环、无跨层乱写。
4. 逐命名空间复述职责与关键复用件（StateMachine/Tracker/各 FSM/Scheduler/Orchestrator/Ept/Ram/Oee）。
5. 形成"问题→去哪层→用哪个类"的速查索引，补齐缺失/编译不过的部分。

## 二、目标解决方案结构（参考，按你实际代码调整）
```
EapLab.sln
├ src/
│  ├ EapLab.Domain            通用基元: 状态机泛型/结果/时钟/事件总线/守恒断言
│  ├ EapLab.E5                SECS2编解码 + HSMS帧/控制状态(教学实现)
│  ├ EapLab.E30               GEM控制状态/采集三层/报警/远程命令/配方/Spool
│  ├ EapLab.E39               OSS对象模型/S14元数据/S15服务/S16事件
│  ├ EapLab.E84               LPT并口信号/四相握手/fail-safe
│  ├ EapLab.E87               Carrier管理态/预约/Hold
│  ├ EapLab.E90               Substrate/SlotMap/SubstrateTracker(唯一改位)/Cross
│  ├ EapLab.E40               Model/S14/S15/S16/Fsm/Sched/Runtime/Recovery
│  ├ EapLab.E94               Oss/Flow/Aggregate/Fsm/Cascade/Recovery/Sched/Ledger/Resilience/Sim
│  ├ EapLab.Ept               EqState/Segment/TimeModel/Signals/Classifier/Collector/Report/Metrics
│  ├ EapLab.Ram               RamMetrics(MTBF/MTTR/MDT/可用度族)
│  ├ EapLab.Oee               OeeModel/Cycle/MinorStop/SlowSpeed/Quality/OeeCalculator
│  ├ EapLab.Cell              Line/Gate/Msg/LoadIn/Process/LoadOut/Recovery(全链路编排)
│  └ EapLab.Host              Host侧收发/对账/Spool消费(教学对端)
└ tests/
   └ EapLab.Tests             全部 xUnit(按命名空间分文件夹)
```
依赖方向（只能向右/向内，禁止反向与环）：
`Domain ← E5 ← E30 ← E39`；`E39 ← E87 ← E90 ← E40 ← E94`；`E84` 独立硬线、被 Cell 编排；`Ept/Ram/Oee` 只读上层投影/订阅事件、不反向写域；`Cell` 依赖各标准层做编排；`Host` 最外。

## 四、关键复用件清单（要能讲清每个的职责与被谁复用）
- Domain：泛型 `StateMachine<TState,TTrigger>`（Configure/Permit/PermitIf/OnEntry/OnExit/Fire 原子、非法零副作用、终态无出边）、单调时钟、结果类型、守恒断言。
- E90：`SubstrateTracker`（唯一改位置，LocationOf/Move/AllWaferIds/GlobalConserved/DeviceEmpty/RebuildFromPhysical）、SlotMap 位图。
- E40：`JobStateMachine`/ResumeToken/JobRebuilder、ChamberSelector、ResourceCalendar、ConcurrentExecutor。
- E94：`CjStateMachine`（聚合事件驱动）、MapCompiler、GlobalScheduler、MultiCarrierLedger、CompoundFaultResolver、DiscreteEventSim/PerfMetrics。
- Cell：FabLineOrchestrator、LayerGate、UnifiedEventEmitter、LoadIn/Process/LoadOut Pipeline、Reconciler3、SpoolQueue。
- Ept：EquipmentTimeModel、E10StateClassifier、EptCollector、EptReporting、EptMetrics。
- Ram：RamMetrics；Oee：OeeCalculator/CycleTracker/QualityTracker。
