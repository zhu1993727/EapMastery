## 二、答辩场景（闭卷，准备 20min + 讲述 15min + 追问 25min）
### 场景描述
一台双 LoadPort、双 LoadLock、四同型工艺腔、单双臂机械手的多腔设备，接入某先进 FAB：
- 经 HSMS/SECS/GEM 与 FAB EAP(Host) 通信，支持 OSS 派工；LoadPort 经 E84 连 AMHS；另需为 FDC 提供 Interface-A 高频数据（进阶，点到即可）。
- Host 一次下发一个 ControlJob，跨两个载具、含多个 ProcessJob，存在并行 Fork 与最终 Join 汇合，其中一批要求加工后量测、合格才进下一 PJ（条件流转），少量片可能 Rework。
- 生产中可能发生：某腔故障、HSMS 断线、E84 握手异常、量测结果延迟、双臂资源竞争。
- 要求：全过程片不丢不串、可安全暂停/恢复/中止、断线恢复后状态一致，并在班末产出 OEE/可靠性数据。

### 你要现场交付（讲述结构）
1. **分层与边界**（3min）：设备端 EAP vs FAB EAP vs MES/FDC/AMHS；本系统分哪些层、依赖方向、每层单一事实源。
2. **主流程时序**（4min）：从上料 E84 到下料的十阶段门控，关键 SECS 消息（S1F13/17、S2F41、S15、S6F11/S16F1、S5F1、S7）与"受理≠生效"。
3. **状态机设计**（3min）：Carrier/PJ/CJ 状态机要点、三层状态聚合、命令与事件区别。
4. **片流与守恒**（2min）：E90 唯一位置、Fork/Join/条件流转/Rework 如何保证全局 ID 集合守恒、JoinBarrier。
5. **异常与恢复**（2min）：腔故障三策略与依赖闭包、断线 P/L/H 对账与 Spool、E84 异常 fail-safe、量测延迟 Pending。
6. **资源与度量**（1min）：多腔资源全序申请/防死锁、瓶颈；E116 时间账→RAM/OEE。

### 追问清单（评委视角，逐题能答）
1. Host S2F41 下发启动，设备回 ACKC0 后立刻断线，Host 以为没启动、设备已启动，怎么对齐。
2. 双 LoadPort 同时上下料、共用双臂，如何防死锁与撞片。
3. Join 汇合时一条支路腔故障，另一条已加工完，片怎么处理不丢不重。
4. Rework 片在 E90/E40/E94/质量账里分别怎么记，片数会不会变。
5. 量测结果没回来，片能不能先放，OEE 质量怎么算。
6. 班末 OEE 三要素数据分别从哪个权威模块取，对不上怎么查。
7. FDC 要 10Hz 参数，为什么走 Interface-A 而不是 GEM S6F11。
8. 为什么设备不能自己解除 LotHold，谁能解、流程是什么。
