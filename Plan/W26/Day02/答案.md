# W26 · Day02 笔试（下）标准答案与批改要点

## A. E90 基板跟踪
1. **层级/三不变式**：E90 管**片（基板）级物理位置**，E87 管**盒（载具）级管理状态**。三不变式：①唯一位置（任一片任一时刻恰在一个位置）；②位置容量（槽/臂/腔容量，臂腔通常=1）；③总数守恒（设备内+各载具片数恒等于基线，不凭空增减）。
2. **SlotMap/位图**：三态 Empty/Occupied/Abnormal。25 槽 1-based、4 字节位图、MSB-first：槽 k→bit=k−1，bit25..31 保留清零。槽 1/16/25：字节1 bit0=0x80、字节2 bit7=0x80、字节4 bit0=0x80 → `80 80 80 00`；槽 1/3/25：字节1 bit0+bit2=0xA0、字节4 bit0=0x80 → `A0 00 80 00`。
3. **原子 Move**：要素=expectedFrom（乐观并发，校验来源确实是它）、加锁（全局位置锁）、快照（移动前位置快照）、改后断言（目标容量/唯一位置/守恒成立）、失败回滚到快照。集中为唯一改位置入口，任何取放片都走它，才能在并发下保证三不变式，杜绝多处直接改位置导致的双占/丢片。
4. **动作/异常**：Pick/Place/Transfer 改物理位置；Process 只改工艺状态（不改位置）。五类异常：Missing（应有却空）、Double（重复/双占）、Misplaced（放错位）、WrongId（读码身份不符）、LeftInside（作业结束片遗留在设备内）。
5. **交叉/守恒/Buffer**：跨载具恒等式 Σ(各载具片数)+设备内部片数=基线常量；合拆批以全局 SubstrateId 集合守恒（并集=全体、子集互斥、不新增 ID）。Buffer（缓冲位）用来打破多臂/多腔交叉取放时的占用循环等待环（避免死锁、提供临时安全位）。

## B. E40 ProcessJob
6. **三正交**：WaferMap（Source/Destination、WaferOrder、CarrierID——CarrierID 在执行时绑定到具体 LoadPort 并核对端口）、ProcessRoute（Step/Module/Recipe，串行/同型多腔步骤内并行/回流 DAG）、状态进度（运行态与前两者解耦）。三者正交：改路线不改片表、改状态不改位置。
7. **PJ 状态机**：Queued/Received→Started（过渡）→Executing；Executing→Pausing→Paused→Executing（Resume）；四终态 Completed/Cancelled/Aborted/Failed。Cancel 仅在 NothingTouched（完全没动工）时允许；Abort 在执行中强制中止并对片分类处置。
8. **命令vs事件/完成守卫/安全点**：外部 JobCommand（Host 经 S15/S2F41 下发）请求迁移，内部 JobEvent（片完成、故障等）驱动聚合；都要经合法边+Guard，不直接赋值。Completed 聚合守卫：所有 Step/片按路线完成、片全部到 Destination、无遗留、守恒成立。安全点四条件：运动机构到安全位、片在安全位置、无临界动作进行中、状态可一致快照（满足才允许暂停/中止）。
9. **多腔资源/防死锁/Swap**：四类资源=腔 Chamber、LoadLock、机械臂 Arm、端口/辅助。防死锁：资源 ID 全序申请（按固定顺序获取）、all-or-nothing、用资源分配图找环并避免。双臂 Swap：臂1取已加工片→臂2取待加工片→交换放入（先取后放、五步安全序列），减少空跑。
10. **节拍/锁**：稳态 Makespan≈首片时间+(n−1)×beat，beat 由瓶颈资源决定。LoadLock 两门（对大气门/对真空门）永不同时开、压力到位才允许开门，双 LoadLock 乒乓交替（一个抽真空加工时另一个装片）维持连续流。

## C. E94 ControlJob
11. **三层/关系**：ControlJob（E94，批次层，跨载具编排多个 PJ）→ProcessJob（E40，加工层，一条路线一组片）→Wafer/Step（片层，E90 管物理位置）。一个 CJ 1 对多 PJ；CJ 只做编排，**不改片物理位置**（位置唯一入口仍是 E90）。
12. **Definition/Runtime/六不变量**：Definition 是纯数据（可序列化、静态校验、与运行态无关），Runtime 持状态/绑口/实际位置；分离使定义可离线校验、可重放、运行态不污染定义。六不变量：至少含 1 个 PJ 且顺序唯一；每片工艺路径完整、DAG 无环；片不重复分配、输出槽唯一；片集合守恒；载具角色合法；后继来源合法（至少写 5 个）。
13. **两类依赖/片流/回流**：控制依赖=启动先后（谁先跑），片流依赖=谁的片给谁（物料流向），二者正交。四类片流：顺序、并行 Fork、汇合 Join、回流。回流=同一 PJ 的新实例+轮次标记（rework/loop 计数）并设轮次上限，靠"新实例+有限轮次"保证逻辑上不成死环、片 ID 不翻倍。
14. **状态聚合/事件**：子层状态自下而上聚合，优先级：失败中止 > Pausing > 全 Paused > Executing > 全 Completed（且片到输出）> 全 Queued。只有聚合后 **CJ 层状态真正发生变化**才发一次事件（子层抖动不冒泡成重复事件），避免事件风暴与状态抖动。
15. **故障/续跑**：三策略=局部隔离继续（Degraded，健康分支跑）、关键路径级联停（下游 Stop、上游 Hold 停供）、可恢复 PropagateHold（带超时升级）。依赖闭包：沿出边求下游（消费者）、入边求上游（供片方），无连通=无关。级联 Abort 后续跑 CJ 三原则：已发生不回退；未完成片源以 E90 实际位置为准；按已完成 PJ 裁剪、从首个未完成 PJ 重新编译（Aborted 终态不可 Resume，只能新建续跑 CJ，记谱系）。

## D. 调度/全链路
16. **日历/优先级**：GlobalResourceCalendar 以区间 [start,end)+资源+CJ/PJ、容量 c 管理，EarliestSlot/EarliestCommon，TryReserve 全资源 all-or-nothing。有效分=静态优先级+老化分 floor(wait/interval)（可封顶但须≥静态极差，保证低优先级等待有上界、无饥饿，MaxWait 告警）；再按就绪时间 FIFO、配方腔体亲和、最后用 CjId/PjId 字典序 tie-break，保证排序确定、结果可复现（同输入同调度）。非抢占+优先级继承治优先级反转；DecisionRecord 记录选中/落选原因可解释。
17. **十阶段/门控/对账**：0 通信上线（E5 HSMS/E30 S1F13-14/S1F17）→1 E84 Deposit 硬线→2 E87 Installed→3 预约 Loaded→4 E90 SourceMap 基线→5 E94 Create CJ→6 级联起首批 E40 PJ→7 多腔并发+跨 PJ 交接→8 严格完成聚合→9 UnloadGuard→Unloaded→E84 Pickup。门控次序：物理事实(E84/E90)→逻辑授权(E87 Loaded)→任务编排(E40/E94)。重连对账：HSMS→E87 三对账→E90 重建(P→L)→E40/E94 重建(L→H)→Spool 补发。

## E. E116/E10/RAM/OEE
18. **E10/E116/采集**：六状态=NonScheduled 与 Scheduled 下 Productive/Standby/Engineering（Uptime）、ScheduledDown/UnscheduledDown（Downtime）；两轴=计划轴+增值轴；控制状态(On/Off-Line、Local/Remote)与活动状态正交。状态段互斥（任一时刻一段）、完备（无缝叠、段和=总时长）、切换原子（旧 end=新 start）。两段式：事件只改信号位、Classifier 从完整信号集纯函数算唯一状态（与事件顺序无关、好处理叠加恢复）。不切段：不改变可生产性的提示类短报警、加工中必要传片/对正（仍 Productive）、重复进入同态（幂等）。
19. **RAM/OEE**：MTBF=运行时间/故障次数；MTTR=主动修复时间/故障次数；MDT=(修复+等待备件/人员/后勤)/停机次数（MTTR≤MDT）。三可用度：Inherent=MTBF/(MTBF+MTTR)（只主动修复）、Achieved（含 PM）、Operational（含等待后勤，≈OEE 的 A）。OEE：A=Run/PPT、P=IdealCT×Total/Run、Q=Good/Total(FPY)，OEE=A×P×Q=IdealCT×Good/PPT（化简式），TEEP=IdealCT×Good/日历（≤OEE）。六损失：A=故障/换型，P=小停顿/降速，Q=过程废品/启动不良。
20. **两个关键结论**：①消故障不增产 OEE 不变——化简式分子是 Good×IdealCT，单纯把停机时间变成待机（Good 不增），A 升但 Run 变大使 P 同比例降、互相抵消；只有把释放时间真正用于多产合格片 OEE 才升。②非瓶颈提效不增整线产出——整线节拍由瓶颈决定（TOC），非瓶颈设备本有空闲，再提效只多产在制品堆在瓶颈前、徒增 WIP，改善要投向约束资源。

## 四、两日笔试合并：原则性错误清零清单（C 即回炉）
1. E90 位图字节序/槽位算错、守恒恒等式写不出。
2. 多处直接改位置、绕过唯一 Move 入口。
3. PJ Cancel/Abort 条件混、Completed 不校验片到输出与守恒。
4. CJ 编排直接改片位置；三层聚合优先级反、子层抖动重复发事件。
5. 回流不设轮次上限导致逻辑成环、片 ID 翻倍。
6. 资源不按全序申请、不做 all-or-nothing 导致死锁。
7. 门控次序颠倒（未授权/未建基线就编排加工）。
8. 重连不按 P→L→H 顺序重建、Spool 命令类盲目重发。
9. 等料当故障、提示报警切段、控制状态等同活动状态。
10. MTTR/MDT 混、OEE 用日历分母、用最终良率代 FPY、以为消停机必提 OEE。
