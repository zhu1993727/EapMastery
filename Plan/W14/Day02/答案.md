# W14 · Day02 答案与参考实现

## 一、自测题标准答案
1. **25 槽位图字节数 / 槽25 位置**：1 bit 表示 1 槽，25 bit 需要 `ceil(25/8)=4` 字节（32 bit，最后一字节只用低 1 bit，其余 7 bit 保留）。槽号 1-based，槽 k 对应 bitIndex=k-1；槽 25→bitIndex=24→字节下标 24/8=2（第 3 字节，0-based）、位偏移 24%8=0，即**第 3 字节的 bit0**（若按 MSB-first 位序则是该字节最高/最低位要按约定，见第 6 点）。字节下标 0、1、2 分别覆盖槽 1-8、9-16、17-24，字节 3 覆盖槽 25（bit24）。
2. **1-based↔0-based / 常见 bug**：槽号 slot（1..25）对应数组下标 index=slot-1；反过来 index→slot=index+1。SECS 上报/Host 指令用 1..25，内部数组用 0..24，边界必须显式转换。最容易出 off-by-one：槽 1 被当成 index1（实际 index0，错位一片）、槽 25 越界、循环用 `<25` 还是 `<=25` 混乱，结果整片槽位错位、取错片。专家级做法：用 SlotNumber 值对象封装转换、只在系统边界做一次映射，内部一律用明确的槽号类型，并写槽 1/25 边界单测。
3. **三种 SECS 表达优缺点/场景**：
   - **紧凑位图 B**：4 字节，最省带宽、解析快；但只表占用有无，不带片 ID/状态，位序约定要统一。适合高频上报"哪些槽有片"。
   - **布尔数组 L,25[BOOLEAN]**：一槽一个布尔，直观、无需位运算、定长 25 项；带宽比位图大、同样不带 ID。适合调试方便、Host 按索引直读的场景。
   - **结构化 List（L,n[槽号+ID+状态]）**：只列占用槽、能带每片 SubstrateID 和状态，信息最全、支持逐片追溯和交叉取片；结构复杂、编解码开销大。适合需要逐片身份/交叉取放/结果核对的场景。实践常用"位图表占用 + 结构化列表表身份"组合。
4. **槽位三态 / Abnormal 为何不参与正常取放**：Empty 空、Occupied 有且仅有一片（可绑 ID）、Abnormal 异常（叠片/错位/未可靠就位/传感器矛盾）。Abnormal 不参与正常取放，是因为其物理状态不确定——可能两片叠放、片没坐实、传感器读数矛盾，此时机械臂按正常流程取/放会造成碎片、掉片或加重异常；必须先挂起、报警、人工/专门恢复流程确认并消除异常，转回 Empty/Occupied 后才允许自动操作，这是"状态不确定就安全冻结"原则在槽位上的体现。
5. **同槽 vs 交叉取片的源/结果差异**：
   - **同槽加工（in-place）**：片从源槽取出、加工后放回同一槽，结果图与源图占用集合完全相同、每槽 ID 相同，Diff 应为零差异（无新增/消失/ID 变化，数量一致），若有差异即异常。
   - **交叉取片（cross-carrier）**：从源盒取片加工后放到目标盒，源结果图相对源图相应槽变 Empty（消失）、目标结果图相应槽变 Occupied（新增），但两片图合起来总数守恒、片 ID 从源槽"移动"到目标槽。Diff 应精确反映这些预期的新增/消失，且源消失集合==目标新增集合（按片 ID 对应），数量差跨盒抵消；若对不上就是丢片/错放。
6. **保留 bit 26..32 处理**：4 字节共 32 bit，只用前 25 bit（bit0..24），bit25..31 为保留位。解码时只遍历 0..24 还原槽位，**显式忽略/清零保留 bit**，不把它们当成槽位；编码时保证保留 bit 写 0。否则若对端在保留位填了非 0（或脏数据），解码会算出"第 26..32 槽有片"的幻影片，破坏统计和守恒校验。健壮做法是解码后用掩码 `&` 清掉保留位。
7. **全局守恒关系**：全局基板守恒 = 各载具 SlotMap 占用数之和 + 设备内各位置（Robot/Aligner/LoadLock/Buffer/Chamber）占用数之和 = 本次上料基板总数（扣除已正常移出设备的）。SlotMap 只统计"在载具槽里"的片，设备内位置的片在全局位置表统计；两者相加才是设备当前持有的全部基板，任何时刻这个总数必须等于进入设备的总数。只看 SlotMap 会漏掉正在臂上/腔里的在途片，这正是 Day01 强调在途也要建模的原因。

## 二、参考实现（net8.0）

### SlotMap 内存模型
```csharp
namespace EapLab.E90;
public enum SlotState { Empty, Occupied, Abnormal }
public sealed class SlotMap
{
    public const int SlotCount = 25;
    private readonly SlotState[] _state = new SlotState[SlotCount];   // 0-based
    private readonly string?[] _ids = new string?[SlotCount];
    public SlotState StateAt(int slot) => Validate(slot), _state[slot-1]);
    public void SetOccupied(int slot,string? id=null)
    { var i=Index(slot); _state[i]=SlotState.Occupied; _ids[i]=id; }
    public void SetEmpty(int slot){ var i=Index(slot); _state[i]=SlotState.Empty; _ids[i]=null; }
    public void MarkAbnormal(int slot){ _state[Index(slot)]=SlotState.Abnormal; }
    public string? IdAt(int slot)=>_ids[Index(slot)];
    public int OccupiedCount => _state.Count(s=>s==SlotState.Occupied);
    public IEnumerable<int> OccupiedSlots =>
        Enumerable.Range(1,SlotCount).Where(s=>_state[s-1]==SlotState.Occupied);
    private static int Index(int slot)=> slot is <1 or >SlotCount ? throw new ArgumentOutOfRangeException(nameof(slot)) : slot-1;
}
```

### 位图 B 编解码（25 槽↔4 字节，MSB-first 位序约定）
```csharp
public static class SlotMapBitmap
{
    public static byte[] Encode(SlotMap map)
    {
        var bytes=new byte[4];
        foreach(var slot in map.OccupiedSlots)
        {
            int bit=slot-1; int by=bit/8, off=bit%8;
            bytes[by] |= (byte)(0x80 >> off);   // MSB-first: bit0→最高位
        }
        return bytes;
    }
    public static SlotMap Decode(byte[] raw)
    {
        if(raw.Length<4) throw new ArgumentException("需要4字节");
        var map=new SlotMap();
        for(int slot=1;slot<=SlotMap.SlotCount;slot++)
        {
            int bit=slot-1; int by=bit/8, off=bit%8;
            bool on=(raw[by] & (0x80>>off))!=0;
            if(on) map.SetOccupied(slot);
        }
        // bit25..31 保留位显式忽略(循环只到25,天然不读)
        return map;
    }
}
```
> 手工演算：槽 1/3/25 有片 → bit0/bit2/bit24=1。
> byte0 = 1000_0000 | 0010_0000 = 1010_0000 = 0xA0；byte1=0；byte2：bit24 在 byte2 的 bit0(MSB-first)=1000_0000=0x80；byte3=0。结果 `A0 00 80 00`。

### 源/结果图 Diff
```csharp
public enum SlotDiffKind { Added, Removed, IdChanged }
public record SlotDiff(int Slot,SlotDiffKind Kind,string? Before,string? After);
public static class SlotMapCompare
{
    public static List<SlotDiff> Diff(SlotMap src,SlotMap result)
    {
        var d=new List<SlotDiff>();
        for(int s=1;s<=SlotMap.SlotCount;s++)
        {
            bool a=src.StateAt(s)==SlotState.Occupied, b=result.StateAt(s)==SlotState.Occupied;
            if(!a&&b) d.Add(new(s,SlotDiffKind.Added,null,result.IdAt(s)));
            else if(a&&!b) d.Add(new(s,SlotDiffKind.Removed,src.IdAt(s),null));
            else if(a&&b && src.IdAt(s)!=result.IdAt(s))
                d.Add(new(s,SlotDiffKind.IdChanged,src.IdAt(s),result.IdAt(s)));
        }
        return d;
    }
}
```

### xUnit
```csharp
public class SlotMapTests
{
    [Fact] public void 位图往返一致()
    {
        var m=new SlotMap(); m.SetOccupied(1,"W1");m.SetOccupied(3,"W3");m.SetOccupied(25,"W25");
        var bytes=SlotMapBitmap.Encode(m);
        Assert.Equal(new byte[]{0xA0,0x00,0x80,0x00},bytes);
        var back=SlotMapBitmap.Decode(bytes);
        Assert.Equal(3,back.OccupiedCount);
        Assert.True(back.StateAt(25)==SlotState.Occupied);
        Assert.True(back.StateAt(2)==SlotState.Empty);
    }
    [Fact] public void 同槽加工_Diff为空()
    {
        var s=new SlotMap(); s.SetOccupied(5,"W5");
        var r=new SlotMap(); r.SetOccupied(5,"W5");
        Assert.Empty(SlotMapCompare.Diff(s,r));
    }
    [Fact] public void 交叉取片_源消失目标新增_数量守恒()
    {
        var src=new SlotMap(); src.SetOccupied(5,"W5");
        var srcAfter=new SlotMap();                       // 源盒5槽取空
        var tgtBefore=new SlotMap();
        var tgtAfter=new SlotMap(); tgtAfter.SetOccupied(7,"W5"); // 放到目标盒7槽
        var d1=SlotMapCompare.Diff(src,srcAfter); Assert.Single(d1); Assert.Equal(SlotDiffKind.Removed,d1[0].Kind);
        var d2=SlotMapCompare.Diff(tgtBefore,tgtAfter); Assert.Equal(SlotDiffKind.Added,d2[0].Kind);
        Assert.Equal(src.OccupiedCount, srcAfter.OccupiedCount+tgtAfter.OccupiedCount); // 守恒
    }
    [Fact] public void 槽号边界_1和25()
    { var m=new SlotMap(); m.SetOccupied(1);m.SetOccupied(25);
      Assert.Throws<ArgumentOutOfRangeException>(()=>m.SetOccupied(0));
      Assert.Throws<ArgumentOutOfRangeException>(()=>m.SetOccupied(26)); }
}
```

## 三、今日易错点
1. off-by-one：槽 1 当 index1、槽 25 越界（封装 SlotNumber、只在边界转换、写边界测试）。
2. 位图字节数算错（25 槽=4 字节不是 3 字节）；MSB/LSB 位序不统一导致全错。
3. 保留 bit25..31 当槽位解码（只遍历 25 槽/掩码清零）。
4. 位图以为能带 ID（只表占用，身份要配结构化 List）。
5. Abnormal 槽还参与自动取放（状态不确定必须冻结）。
6. 只看 SlotMap 算守恒，漏掉臂/腔里的在途片。
7. 交叉取片只对比单个盒（要源+目标合起来看数量守恒、按 ID 对应）。
8. 三种 SECS 表达混用、编解码往返不一致（每种都要 round-trip 测试）。
