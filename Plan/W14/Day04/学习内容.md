## 二、背景知识（先读，25 分钟）

### 1. 四类高级动作（都建立在原子 Move 上）
- **Pick(sub, carrier, slot, robotArm)**：从载具槽取片到机械手臂。前置：片在该槽、臂空、载具 Loaded；后置：片在臂、源槽空。
- **Place(sub, robotArm, carrier, slot)**：从臂放到载具槽。前置：片在臂、目标槽空、载具允许访问；后置：片在槽、臂空。
- **Transfer(sub, fromInternal, toInternal)**：设备内位置间传递（臂→对准器、臂→腔、腔→臂），前置片在源、目标空，后置相应迁移。
- **Process(sub, chamber, recipe)**：片在腔内加工，位置不变（仍在 Chamber），片状态 Processing→Processed，记录工艺/配方/起止时间。
- 每个动作=若干 Move + 前置后置校验 + 片状态迁移 + 事件，是对原子 Move 的业务封装。

### 2. 典型搬运路径（以单片同槽加工为例）
```
Slot#5 ─Pick→ Robot:R1 ─Transfer→ Aligner ─Transfer→ R1
→ LoadLock:LL1 ─Transfer→ Robot(真空侧) ─Transfer→ Chamber:C1
→ Process(recipe) [位置不变,状态Processing→Processed]
→ C1 ─Transfer→ ...原路... → R1 ─Place→ Slot#5
```
- 双腔体/双臂/交叉取片路径更复杂（W15/W18），今天先跑通单片主干。
- 路径编排器按顺序调用动作，任一动作失败（前置不满足/不变式破坏）立即中止并安全挂起。

### 3. 位置变更事件
- 每次成功动作产出 `SubstrateLocationEvent`：SubstrateId、Action(Pick/Place/Transfer/Process)、From、To、SubstrateState、Timestamp、关联 PJ/CJ ID（后续接 E40/E94）。
- 投影到线上：
  - OSS：S16F1 对象事件（Substrate 对象，CEID 如 4401 Moved/4402 Processed，W10 已建编号约定）。
  - GEM：S6F11 事件报告（CEID=基板移动/加工，报告 VID=片ID/源/目标/位置）。
- 关键事件（片进腔、片放回、异常）通常需要 Host 订阅，普通在途移动可按订阅过滤（复用 W10 订阅模型）。

### 4. 移动轨迹 Trajectory
- 每片维护有序轨迹：时间戳 + 动作 + From→To + 当时状态 +（加工时 recipe/chamber）。
- 查询能力：①该片完整路径；②某时刻片在哪（按时间回放）；③某腔体加工过哪些片（良率追溯）；④片在设备内停留时长。
- 轨迹是质量追溯和故障复盘的关键：发生异常/良率问题时，能回答"这片经过哪些位置、进过哪个腔、何时"。

### 5. 与 SlotMap/守恒联动
- Pick 后源载具 SlotMap 该槽变空，Place 后目标槽占用（Day03 Move 已同步）。
- 每个动作后不变式恒成立；路径结束时片应回到预期目标槽，结果 SlotMap 与任务声明一致（Day05 校验）。

### 6. 事件可靠上报（复用 W08 Spool）
- 位置/加工事件属关键追溯事件，断线进 Spool、重连按序重发确认后删除，保证 Host 不丢片轨迹。
