# W14 · Day01 答案

## 一、自测题标准答案
1. **E90 解决什么 / 与 E87 粒度区别**：E90（STS 基板跟踪）解决"每一片基板在载具内和设备内部的精确位置与状态可知、可校验、可追溯"，防止取放片过程中丢片、叠片、放错槽、交叉混片。粒度区别：E87 管到**载具（盒）**整体——盒在不在口、什么状态、能否访问，它不关心盒内每一片具体在哪；E90 下钻到**单颗基板（片）**——哪片在哪个盒的哪个槽、是否被取进设备、在哪个机械手/腔体、加工后放回哪个槽。一个是"盒级账本"，一个是"片级账本"，E87 Loaded 是 E90 能跟踪盒内片的前提。

2. **Location / 各举 3 个**：Location 是基板所处位置的统一抽象，用唯一 LocationId 表示，无论在盒内还是设备内都纳入同一位置空间。载具位置（Carrier 侧）：`FOUP-A:Slot1`、`FOUP-A:Slot5`、`FOUP-B:Slot25`（载具 ID+槽号）；设备内位置（Internal）：`Robot:R1`（机械手上臂）、`Aligner`（对准器）、`Chamber:C1`（工艺腔体1），还可有 LoadLock、Buffer 暂存位。每个位置带容量 Capacity，槽/臂/腔通常容量 1，Buffer 可多片。

3. **三不变式 / 各防什么事故**：
   - **唯一位置**：一片基板任一时刻必须且只能在一个位置。防止"一片同时出现在两处"（账目重复/幻影片）或"哪都不在"（丢片、片在机械手上却无记录）。
   - **位置容量**：任一位置承载数不超过容量，容量 1 的槽/臂/腔不能放两片。防止叠片/重片（两片塞进一个槽、机械臂或腔体双重装载导致物理碰撞、碎片）。
   - **守恒不丢失**：设备内基板总数守恒——上料片数=当前各载具内+设备内各位置片数之和，加工只改位置和状态不消灭片。防止片在一连串搬运后数量对不上（某片被遗漏在设备内部、下料时才发现少片）。
   三者是基板跟踪的硬约束，任何取放事务提交前都要校验，违反即拒绝并报警。

4. **在途为何也要建模**：基板从 A 位置取出到放入 B 位置之间有物理传递时间（机械臂正在搬、片在臂上），如果这段时间不建模，片就处于"已从 A 删除、还没进 B"的无归属真空——违反唯一位置和守恒不变式，一旦此刻断电/异常/查询，系统不知道片在哪，正是丢片高发点。正确做法是把传递载体本身建成位置（如 `Robot:R1`）：取片=源槽→机械手臂位（片在臂上，有明确归属），放片=臂位→目标位置，任意时刻片都恰在某个 Location（哪怕是在途的臂上），守恒始终成立，异常恢复时也能据"片在臂上"安全处置。

5. **取片更新哪两个映射 / 为何事务**：要同时维护双向映射——①基板→当前位置（`Substrate.CurrentLocation`，这片现在哪）；②位置→承载基板集合（`Location.Occupants`，这个位置现在有谁）。取片时从源位置 Occupants 移除、基板位置改为臂位、臂位 Occupants 加入；放片反向。必须放在一个事务里原子提交，因为两个映射是同一事实的正反两面，若只改一半（改了片的位置没改位置集合，或反之）就会出现"片说在 A、A 说没有"或"位置容量被突破"的不一致；事务内还要校验三不变式（目标未满、片确实在源、守恒），任一不满足整体回滚、零副作用，保证位置模型永远自洽。

6. **E90 与 E40 PJ 关系 / 没有 E90 会怎样**：E40 ProcessJob 是加工任务，它声明"从哪个源 Carrier 的哪个 Slot 取片、经过哪些腔体、放到哪个目标 Carrier 的哪个 Slot"；这些取放指令的可行性和正确性依赖 E90 提供的位置事实（源槽确实有那片、目标槽空、片当前位置与任务一致）。执行 PJ 时每次取放都驱动 E90 做位置迁移和校验。没有 E90，PJ 指定 Slot 就是盲操作：不知道源槽有没有片、是不是对的片、目标槽是否已占用，可能空取、重片、放错槽、交叉混片，且无法在过程中发现，直到下料盘点才暴露，无法追溯。E90 是 E40 取放片的"位置事实来源和安全校验层"。

7. **25 槽=25 片吗 / SlotMap**：不等于。FOUP 物理上有 25 个 Slot（槽位容量），但实际有多少片、哪些槽有片由 **SlotMap（槽位图）**描述：它是 25 个槽的占用映射，逐槽记录"空 / 有一片（及其 SubstrateID、状态）/ 异常"。一盒可能只装几片、间隔放置，SlotMap 才是真实载料情况；上料时读入源 SlotMap，加工后生成结果 SlotMap 并与预期核对（W13 Unload 守卫 AllSubstratesReturned 就靠它）。

## 二、统一位置空间图（手绘参考）
```
                    ┌──────────── 位置空间(每片任一时刻恰在一处)────────────┐
载具侧:  LP1/FOUP-A: Slot1..Slot25(每槽容量1)      LP2/FOUP-B: Slot1..Slot25
              ▲ Pick(取)                    Place(放) ▲
              │                                        │
设备侧:  Robot:R1/R2(容量1) ──► Aligner(容量1) ──► LoadLock ──► Chamber:C1/C2/C3(容量1)
                              Buffer:B1..(暂存,可多)
迁移: 源Slot →(在途:臂上)→ Aligner → ... → Chamber →(臂上)→ 目标Slot
不变式: ①唯一位置 ②位置容量 ③总数守恒; 每次取放事务内双向更新+校验
```

## 三、三不变式反例（参考）
| 不变式 | 违反事故例子 |
|---|---|
| 唯一位置 | 片从槽取出、放片记录丢失，系统既显示在原槽又显示在腔体（幻影重复）；或两边都没有（丢片） |
| 位置容量 | 目标槽已有片还往里放→叠片刮伤；机械臂双臂误判同一臂放两片→掉片 |
| 总数守恒 | 一连串搬运后上料 25 片、下料只点到 24 片，1 片遗落在某腔体/暂存位，找不回轨迹 |

## 四、费曼讲解稿（参考，3 分钟）
"一片晶圆在 FOUP-A 的 5 号槽，这是它的初始 Location。ProcessJob 要加工它：机械臂 R1 从 5 槽取片，这一刻片的位置从 Slot5 迁到 Robot:R1——注意在途也有归属，片就在臂上，不会哪都不在；臂送到 Aligner 对准，位置变 Aligner；再经 LoadLock 进 Chamber:C1 加工，位置变 C1；加工完原路经臂传回，最后放到目标槽，比如 FOUP-A 的 5 槽或另一个盒的某槽。整个过程每一步都在一个事务里同时更新'片在哪'和'位置里有谁'两张表，并检查三件事：这片任何时刻只在一个位置、每个位置不超容量、设备里片的总数守恒。只要有一步不满足——比如目标槽已有片、片不在声称的源槽——就拒绝动作并报警。这就是 E90：让每片晶圆全程位置唯一、数量守恒、轨迹可追溯，从根上防丢片、叠片和放错槽。"

## 五、今日易错点
1. 把 E87 盒级跟踪和 E90 片级跟踪混为一谈（粒度不同，E87 Loaded 是 E90 前提）。
2. 认为 25 槽=25 片（实际占用由 SlotMap 决定）。
3. 取放片只改"片的位置"不改"位置承载集合"（双向映射必须原子同改）。
4. 在途不建模，让片在取放之间无归属（违反唯一位置/守恒，是丢片高发点）。
5. 不校验目标位置容量（容量 1 放两片=叠片事故）。
6. 以为加工会改变片数（守恒：只改位置/状态，不消灭片）。
7. 把 Location 只理解成槽位（设备内臂/对准器/锁/腔/暂存都是位置，统一建模）。
8. 位置迁移不用事务、不做不变式校验（会留下自相矛盾的位置账）。
