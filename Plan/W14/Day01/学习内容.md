## 二、背景知识（先读，30 分钟）

### 1. E90 是什么
- E90 = SEMI E90 **STS Substrate Tracking Standard（基板跟踪标准）**，规定设备如何跟踪并向 Host 报告每一片基板（Wafer 晶圆、Reticle 光罩）在载具内和设备内部的位置与状态。
- 为什么需要：一片晶圆价值高、工艺步骤多，设备要从 FOUP 某槽取片、经机械手/对准器/腔体加工、再放回（本盒或另一盒）。任何"片在哪"的错误（丢片、两片叠放、放错槽、交叉混片）都是重大事故。E90 让每一片全程位置可知、可校验、可追溯。

### 2. 核心概念
- **Substrate（基板）**：最小跟踪单位，一片晶圆。可带 SubstrateID（先进 FAB 逐片刻码/读码），至少可用"载具+槽位"逻辑标识。
- **Slot（槽位）**：FOUP 内物理槽，12 寸 FOUP 标准 25 槽（编号 1..25）。每个槽状态：空、有一片（对应基板）、异常（叠片/错位）。
- **Location（位置）**：基板所处的任意位置的统一抽象，分两大类：
  - 载具位置：`Carrier/LoadPort + Slot#`（在盒内某槽）。
  - 设备内位置：Robot（机械手 R1/R2）、Aligner（对准器）、LoadLock（真空锁）、Buffer（暂存位）、ProcessChamber（工艺腔体 C1/C2）等。
- **SlotMap（槽位图）**：一个载具 25 槽的占用/基板映射，上料读入"源图"，下料生成"结果图"。
- **位置状态/迁移**：基板在位置间移动（Pick 取、Place 放、Transfer 传递、Process 加工），每次移动都是一次位置状态迁移并产生事件。

### 3. 统一位置空间模型
```
位置空间(每片基板任一时刻恰在其中一个位置):
┌─ 载具侧(External/Carrier)
│    LP1/FOUP-A : Slot1..Slot25
│    LP2/FOUP-B : Slot1..Slot25
└─ 设备侧(Internal)
     Robot-R1(上臂)/R2(下臂)
     Aligner(对准器)
     LoadLock-LL1/LL2
     Buffer-B1..(暂存)
     Chamber-C1/C2/C3(工艺腔)
每个位置有容量(Capacity): Slot/Robot/Chamber 通常容量1; Buffer可能多;
任一时刻"已放入某位置的基板数 ≤ 容量"。
```
- 用统一 LocationId 表示，如 `Carrier:FOUP-A:Slot5`、`Robot:R1`、`Chamber:C1`，基板跟踪器维护 Substrate→CurrentLocation 的映射，以及每个 Location 当前承载的基板。

### 4. 唯一位置不变式（本周灵魂）
- **不变式1（唯一位置）**：一片基板在任一时刻必须且只能在一个位置，不能同时在两处，也不能不在任何位置（除了跨位置瞬时传递，传递要建模为"源取出→在途→目标放入"，在途也要有归属，如机械手上）。
- **不变式2（位置容量）**：任一位置承载基板数不超过其容量；容量 1 的槽/臂/腔不能同时放两片（防叠片/重片）。
- **不变式3（守恒/不丢失）**：设备内基板总数守恒：上料载具内片数 = 当前载具内 + 设备内各位置片数之和（加工不消灭片，只改变位置和状态），下料前所有片必须有确定归属。
- 任何一次取/放操作都要在事务内同时更新"基板当前位置"和"位置承载集合"，并在提交前校验三个不变式，违反即拒绝并报警——这就是防丢片/重片/错位的机制。

### 5. E90 与 E87/E40/E94 关系
- E87 保证"盒可访问（Loaded）"，是 E90 能读该盒 SlotMap、跟踪其片的前提。
- E90 提供"片在哪、源槽/目标槽"的位置事实，是 E40 ProcessJob 取放片指令的数据依据。
- E40 PJ 声明"从源 Carrier/Slot 取→加工路径→放目标 Carrier/Slot"，执行时驱动 E90 位置迁移。
- E94 CJ 编排多 PJ、可跨载具（源盒→目标盒的交叉取片），更依赖 E90 逐片校验。
- 层次：E87 盒 → E90 片位置 → E40 单任务取放 → E94 多任务编排。

### 6. 先进 FAB 实践要点
- 逐片 ID（Wafer ID 读码）+ 槽位双重校验，不只靠槽位推断片身份。
- 双机械手/多腔体并行搬运时，位置模型必须支持并发迁移但仍满足不变式（加锁/事务）。
- 全程保留每片移动历史（轨迹），支持良率/异常追溯（哪片进过哪个腔、何时）。
