# W14 · Day06（周六）基板跟踪器综合实验：对接 E87 Loaded，端到端跟踪

> 建议时长：110 分钟。把本周 SlotMap、位置空间、取放迁移、轨迹、一致性校验整合成一个 `SubstrateTracker`，并对接 W12 的 E87：载具 Loaded 才注册其片、Unload 前必须 Final Check 通过。今天写一个可跑的端到端剧本，这是 W15 交叉取片和 W16 E40 的直接基座。

## 一、今日目标
1. 组装 `SubstrateTracker`：统一管理多载具 SlotMap、设备内位置、位置空间、搬运服务、轨迹、一致性校验。
2. 对接 E87 生命周期：Loaded→注册载具与片；Unloading→Final Check；Removed→注销。未 Loaded 禁止跟踪取片。
3. 跑通端到端剧本：双 LoadPort、多片、同槽加工 + 一片交叉到另一盒，全程不变式、轨迹、事件正确。
4. 注入 3 个故障（片残留臂、放错槽、下料前载具未 Loaded）验证拦截。
5. 输出一份实验报告：位置迁移序列、轨迹、Final Check 结论。

## 二、集成设计（先读，30 分钟）

### 1. SubstrateTracker 对外接口
```
OnCarrierLoaded(carrierId, sourceSlotMap):  注册载具位置+片(来自E87 Loaded)
OnCarrierRemoved(carrierId):                校验无残留后注销
Pick/Place/Transfer/Process:                委托搬运服务(内部位置空间)
RequestUnload(carrierId, plan, mapperScan): Final Check, 通过才允许(对接UnloadGuard)
GetTrajectory(id) / Snapshot() / ResultSlotMap(carrierId)
```
- 内部持有：LocationSpace、SubstrateTransferService、ConsistencyChecker、各载具 SlotMap、载具访问状态（是否 Loaded）。

### 2. 与 E87 的对接点（关键边界）
- **只有 E87 状态到 Loaded（Host 授权）才调用 OnCarrierLoaded 注册片**；Installed 未授权不注册、不能取片（呼应 W12/W13：物理在位≠逻辑可加工）。
- 载具 Unload 前 RequestUnload 做 Final Check，等价 W13 UnloadGuard 的 AllSubstratesReturned 由 E90 提供精确数据。
- 载具被 Hold 时，Tracker 拒绝其上一切取放（外部传入 Hold 状态）。
- OnCarrierRemoved 时确认该载具无"属于它但在设备内"的片，否则拒绝注销（防盒走片留）。

### 3. 端到端剧本（25 分钟搭建）
```
LP1=FOUP-A: 槽1(W1)、槽3(W3)、槽5(W5); LP2=FOUP-B: 空(目标盒),均 E87 Loaded
设备内: R1/Aligner/LL1/VR/C1/C2
JobPlan:
 W1: A:S1 → C1加工 → A:S1(同槽)
 W3: A:S3 → C2加工 → A:S3(同槽)
 W5: A:S5 → C1加工 → B:S1(交叉,源A到目标B)
逐步执行, 每步后 AssertInvariants; 打印每片轨迹
Final Check: A 剩 W1/W3 原位, B:S1=W5, 设备内全空, 数量守恒(3)
RequestUnload(A)、RequestUnload(B) 均通过
```

### 4. 故障注入（20 分钟）
- F1 片残留：W3 加工完停在 R1 不放回，RequestUnload(A) 必须报 LeftInside 并拒绝。
- F2 放错槽：W1 放到槽2，Final Check 报 Misplaced（槽2 计划外 + 槽1 缺失/错位）。
- F3 未授权取片：载具只 Installed 未 Loaded 就 Pick，必须被 Tracker 拒绝。
- 每个故障验证：动作被拦或 Final Check 失败、Hold/拒绝 Unload、告警内容含期望与实际。

### 5. 事件与上报（15 分钟）
- 汇总位置事件，按 W10 订阅过滤关键事件（进腔/加工完成/放回/异常），打印其 S16F1/S6F11 投影结构。
- 断线场景：关键事件进 Spool（复用 W08）占位，说明轨迹本地不丢、线上补发。

### 6. 实验报告（20 分钟）
- 记录：初始 SlotMap、每步位置迁移表、三片轨迹、结果 SlotMap、Final Check 结果、故障拦截证据。
