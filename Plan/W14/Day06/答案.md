# W14 · Day06 答案与参考实现

## 一、自测题标准答案
1. **三个对接点 / 为何 Loaded 才注册**：对接点①**Loaded→注册片**：E87 载具到 Loaded（Host 授权）才 OnCarrierLoaded，把源 SlotMap 的片注册进位置空间、建立载具槽位 Location；Installed 只是物理在位、未授权，不注册。②**Unload 前→Final Check**：E87 要 Unload 时先经 Tracker RequestUnload 做四方一致性校验，通过才允许（对应 W13 AllSubstratesReturned）。③**Removed→注销**：载具物理移除前确认没有属于它的片滞留在设备内，才 OnCarrierRemoved 注销位置。必须 Loaded 才注册片，因为 Installed≠可加工（W12 核心）：盒刚放上去还没读 ID/校验/授权，此时若就把片纳入可调度账本并允许取片，可能对错料、未授权盒、问题盒操作；Loaded 代表身份校验和 Host 授权都完成，片才"合法进入"可加工位置空间，这是把 E87 的盒级授权传导到 E90 片级操作的闸门。
2. **RequestUnload 与 UnloadGuard 关系 / E90 提供什么**：W13 UnloadGuard 是下料总守卫（任务结束、片归位、机构安全、无 Hold 四条件），其中"片归位 AllSubstratesReturned"这一条的**精确判定数据由 E90 RequestUnload/Final Check 提供**。E90 负责回答：是否每片都在计划目标槽、设备内有无残留、结果图与计划/Mapper 是否一致、有无丢重错；E90 校验通过是 UnloadGuard 放行的必要条件之一。即 UnloadGuard 是决策编排者，E90 是片级事实与校验的提供者，二者组合才构成完整下料许可。
3. **交叉片 W5 如何确认到 B:S1**：Final Check 四方核对——JobPlan 声明 W5 目标为 B:S1；LivePositions 显示 W5.CurrentLocation==CarrierLocation(B,S1)；结果图 ResultMap(B) 的 S1 占用且 IdAt(S1)=="W5"，ResultMap(A) 的 S5 为空；数量上 A 结果图（W1/W3 两片）+B 结果图（W5 一片）=3=计划总数，守恒；B:S1 的 ExpectedId（JobPlan.ExpectedIdAt(B,1)）=="W5"与实际一致；设备内无残留。全部满足才确认 W5 正确从 A 交叉移动到 B:S1，任一不符（如还在设备内、放到 B 别的槽、ID 错）即 Misplaced/WrongId/LeftInside。
4. **Removed 前查"属于该载具却在设备内"的片**：载具一旦物理移除，其槽位位置随之消失，若此时还有原本来自该载具的片在机械臂/腔体/暂存位，就会出现"片的归属载具已不在、片滞留机台"的严重局面——后续无法把片放回原盒、位置空间里载具槽位已注销、守恒基线错乱，甚至误把残留当丢片。所以 OnCarrierRemoved 前必须检查：该载具注册的所有片，当前要么随它在其槽内、要么已明确转移到另一仍在场载具，绝不能有片孤悬在设备内位置；有则拒绝注销并报警取回，确保"盒走片清、账随物走"。
5. **三故障由哪层拦截**：
   - F1 片残留臂上：由 **E90 Final Check（LeftInside 检测）+ UnloadGuard** 拦截——动作本身合法，但下料前扫描设备内位置发现 R1 非空，RequestUnload 返回 LeftInside、拒绝 Unload。
   - F2 放错槽：由 **E90 Post-check/Final Check（Misplaced）** 拦截——数量守恒、容量没破，但逐片比对 JobPlan 目标槽发现 W1 不在 S1、S2 出现计划外片，判 Misplaced，Hold 并阻止下料。
   - F3 未 Loaded 就取片：由 **E87 授权门控（Tracker 访问状态检查）** 在最外层拦截——载具只 Installed 未 Loaded，Tracker 直接拒绝 Pick，根本不进入位置迁移，属于"逻辑未授权不动物理"，比位置校验更早一层。
   三层分别对应：授权门（能不能动这个盒）、动作/不变式（动得对不对）、总验收（结束是否全部归位）。
6. **本地轨迹 vs 线上上报 / 断线**：本地 Trajectory 记录**全量**位置事件（含高频在途 Transfer），始终完整保存在设备端，供任意时刻查询、回放、追溯，不依赖连接；线上只按 Host 订阅上报**关键事件**（进腔/加工完成/放回/异常）以省带宽。断线时关键上线事件进 W08 Spool 缓存、重连按序重发、Host 确认后删除；即使线上暂时中断，本地轨迹不丢，恢复后还能用全量对账补齐 Host 视图。即"本地全量留痕、线上按需订阅、Spool 保关键事件不丢、对账补全量"。
7. **一句话讲协作**：E87 决定"哪个盒被授权可以进出和访问（盒级闸门）"，E90 在盒被 Loaded 后精确跟踪"盒里每一片在设备内的位置、轨迹和归位（片级账本与校验）"，E40 则依据 E90 的位置事实下达"把哪片从哪取、经哪加工、放回到哪（加工任务）"——E87 开门、E90 记账看片、E40 派活，三者层层依赖。

## 二、参考实现（net8.0，整合本周组件）

### SubstrateTracker
```csharp
namespace EapLab.E90;
public sealed class SubstrateTracker
{
    private readonly LocationSpace _space=new();
    private readonly Dictionary<string,SlotMap> _carrierMaps=new();
    private readonly HashSet<string> _loaded=new();
    private readonly HashSet<string> _hold=new();
    private readonly Dictionary<string,List<string>> _carrierWafers=new();
    public SubstrateTransferService Transfer { get; }
    public ConsistencyChecker Checker { get; }
    public SubstrateTracker(){ Transfer=new SubstrateTransferService(_space); Checker=new ConsistencyChecker(_space);
        foreach(var n in new[]{"Robot:R1","Aligner","LoadLock:LL1","Robot:VR","Chamber:C1","Chamber:C2"})
            _space.AddLocation(new Location(new InternalLocation(n))); }

    // E87对接①: Loaded才注册
    public void OnCarrierLoaded(string carrier,SlotMap source)
    {
        _carrierMaps[carrier]=source; _loaded.Add(carrier);
        _space.RegisterCarrier(carrier,source);
        _carrierWafers[carrier]=source.OccupiedSlots.Select(s=>source.IdAt(s)??$"{carrier}-S{s}").ToList();
    }
    private void EnsureAccessible(string carrier)
    {
        if(!_loaded.Contains(carrier)) throw new InvalidOperationException($"{carrier} 未Loaded,禁止取片");
        if(_hold.Contains(carrier)) throw new InvalidOperationException($"{carrier} 处于Hold");
    }
    public void SetHold(string carrier,bool on){ if(on)_hold.Add(carrier); else _hold.Remove(carrier); }

    public void Pick(string id,string carrier,int slot,string arm){ EnsureAccessible(carrier);
        Transfer.Pick(id,new CarrierLocation(carrier,slot),new InternalLocation(arm)); }
    public void Place(string id,string arm,string carrier,int slot,SubstrateState st=SubstrateState.Processed){ EnsureAccessible(carrier);
        Transfer.Place(id,new InternalLocation(arm),new CarrierLocation(carrier,slot),st); }
    public void TransferInternal(string id,string from,string to)=>Transfer.Transfer(id,new InternalLocation(from),new InternalLocation(to));
    public void Process(string id,string chamber,string recipe,string? pj=null)=>Transfer.Process(id,new InternalLocation(chamber),recipe,pj);

    // E87对接②: Unload前Final Check
    public IReadOnlyList<Issue> RequestUnload(JobPlan plan,string? mapperCarrier=null,SlotMap? mapper=null)
    {
        var issues=Checker.FinalCheck(plan,_carrierMaps,mapper,mapperCarrier);
        return issues; // 空才允许Unload
    }
    // E87对接③: Removed前确认无本载具片残留设备内
    public void OnCarrierRemoved(string carrier)
    {
        foreach(var id in _carrierWafers.GetValueOrDefault(carrier,new()))
        { var loc=_space.LocationOf(id);
            if(loc is InternalLocation) throw new InvalidOperationException($"{id} 仍在设备内{loc.Key},禁止移除{carrier}"); }
        _loaded.Remove(carrier);
    }
    public SlotMap ResultSlotMap(string c)=>_carrierMaps[c];
    public Trajectory Trajectory(string id)=>Transfer.Trajectories[id];
    public void Snapshot()=>_space.AssertInvariants();
}
```

### 端到端剧本
```csharp
public static class EndToEndDemo
{
    public static void Run()
    {
        var t=new SubstrateTracker();
        var A=new SlotMap(); A.SetOccupied(1,"W1");A.SetOccupied(3,"W3");A.SetOccupied(5,"W5");
        var B=new SlotMap();
        t.OnCarrierLoaded("A",A); t.OnCarrierLoaded("B",B);

        var plan=new JobPlan();
        plan.Wafers.Add(new("W1","A",1,"A",1));
        plan.Wafers.Add(new("W3","A",3,"A",3));
        plan.Wafers.Add(new("W5","A",5,"B",1)); // 交叉

        // W1 同槽 C1
        t.Pick("W1","A",1,"Robot:R1"); t.TransferInternal("W1","Robot:R1","Chamber:C1");
        t.Process("W1","Chamber:C1","RCP1","PJ1"); t.TransferInternal("W1","Chamber:C1","Robot:R1");
        t.Place("W1","Robot:R1","A",1);
        // W3 同槽 C2(路径简化)
        t.Pick("W3","A",3,"Robot:R1"); t.TransferInternal("W3","Robot:R1","Chamber:C2");
        t.Process("W3","Chamber:C2","RCP2","PJ2"); t.TransferInternal("W3","Chamber:C2","Robot:R1");
        t.Place("W3","Robot:R1","A",3);
        // W5 交叉 A:S5 -> C1 -> B:S1
        t.Pick("W5","A",5,"Robot:R1"); t.TransferInternal("W5","Robot:R1","Chamber:C1");
        t.Process("W5","Chamber:C1","RCP1","PJ3"); t.TransferInternal("W5","Chamber:C1","Robot:R1");
        t.Place("W5","Robot:R1","B",1);

        t.Snapshot(); // 不变式
        var issues=t.RequestUnload(plan);
        Console.WriteLine(issues.Count==0?"Final Check 通过, 允许Unload":"存在异常");
        Console.WriteLine($"A: {string.Join(",",t.ResultSlotMap("A").OccupiedSlots)} (应1,3)");
        Console.WriteLine($"B:S1 = {t.ResultSlotMap("B").IdAt(1)} (应W5)");
        t.OnCarrierRemoved("A"); t.OnCarrierRemoved("B");
    }
}
```

### 故障注入 xUnit
```csharp
public class TrackerFaultTests
{
    static SubstrateTracker LoadedWithW3(out SlotMap A)
    { var t=new SubstrateTracker(); A=new SlotMap();A.SetOccupied(3,"W3");t.OnCarrierLoaded("A",A); return t; }

    [Fact] public void F1_片残留臂_RequestUnload报LeftInside()
    { var t=LoadedWithW3(out _); var plan=new JobPlan();plan.Wafers.Add(new("W3","A",3,"A",3));
      t.Pick("W3","A",3,"Robot:R1"); // 不Place, 停在臂
      var issues=t.RequestUnload(plan);
      Assert.Contains(issues,i=>i.Kind==ConsistencyIssue.LeftInside);
      Assert.Throws<InvalidOperationException>(()=>t.OnCarrierRemoved("A")); }

    [Fact] public void F2_放错槽_Misplaced()
    { var t=LoadedWithW3(out _); var plan=new JobPlan();plan.Wafers.Add(new("W3","A",3,"A",3));
      t.Pick("W3","A",3,"Robot:R1"); t.Place("W3","Robot:R1","A",7); // 错放到7
      var issues=t.RequestUnload(plan);
      Assert.Contains(issues,i=>i.Kind==ConsistencyIssue.Misplaced); }

    [Fact] public void F3_未Loaded取片被拒()
    { var t=new SubstrateTracker(); var map=new SlotMap();map.SetOccupied(1,"W1"); // 只建不Loaded
      Assert.Throws<InvalidOperationException>(()=>t.Pick("W1","A",1,"Robot:R1")); }

    [Fact] public void Hold中取片被拒()
    { var t=LoadedWithW3(out _); t.SetHold("A",true);
      Assert.Throws<InvalidOperationException>(()=>t.Pick("W3","A",3,"Robot:R1")); }
}
```

## 三、实验报告模板
```
1 初始SlotMap: A{S1=W1,S3=W3,S5=W5}, B空; 两载具均E87 Loaded
2 位置迁移序列(逐片From→To, 附事件): 见Trajectory输出
3 三片轨迹: W1 A1→C1→A1; W3 A3→C2→A3; W5 A5→C1→B1
4 结果SlotMap: A{S1=W1,S3=W3}, B{S1=W5}; 总数3守恒; 设备内全空
5 Final Check: 0 issue → RequestUnload通过 → OnCarrierRemoved
6 故障: F1 LeftInside拦Unload; F2 Misplaced; F3 未Loaded拒Pick; 均符合预期
7 事件: 进腔/加工完成/放回/异常 经订阅投影S16F1/S6F11; 本地Trajectory全量
```

## 四、今日易错点
1. Installed 就注册片/允许取片（必须 Loaded 授权闸门）。
2. Unload 只看任务结束不查片归位（E90 Final Check 是 AllSubstratesReturned 的数据来源）。
3. 交叉片只看单个载具结果图（要源+目标合起来看守恒与 ID 对应）。
4. 载具移除不查设备内残留片（盒走片留、无法归位）。
5. Hold 状态没传导到 Tracker 取片门控。
6. 本地轨迹和线上上报混为一谈（本地全量、线上订阅、Spool 补关键）。
7. 故障注入只验证"抛异常"，不验证 Unload 是否被阻止、告警是否含期望/实际。
8. 交叉放片后忘了目标载具也要 Loaded/可访问（目标盒同样要授权）。
