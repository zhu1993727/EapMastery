# W14 · Day03 答案与参考实现

## 一、自测题标准答案
1. **为何双向映射 / 单向问题**：两类查询都高频且方向相反——"这片现在哪"需要 片→位置（Substrate→Location），"这个位置有谁/是否已满"需要 位置→片集合（Location→Occupants）。只存单方向，另一类查询就得全表扫描甚至无法回答：只存片→位置，判断目标槽是否已有片要遍历所有片，且容量校验、SlotMap 生成都低效易错；只存位置→片，查单片轨迹困难。双向映射是同一事实的正反索引，必须在唯一写入口 Move 内原子同改以保持镜像一致，查询 O(1) 且互相印证（两个方向对不上本身就能检测出 bug）。
2. **expectedFrom 防什么**：Move 要求调用方声明"我认为这片当前在 expectedFrom"，提交前比对片的真实 CurrentLocation，不一致就拒绝。它防止基于**过期认知的误操作**：多个任务/双臂并发或上一步异常后，调用方以为片还在源槽 5，实际已被移到机械臂或别处，若不校验就会从错误位置"取片"、把片放错或覆盖，造成丢片/重片。这是乐观并发控制思想——不长期加锁，但每次修改都验证前提未被他人改变，类似 CAS。真实 EAP 里 ProcessJob 指令都带源槽，跟踪器据此核对片确实在那才执行。
3. **Move 事务步骤 / 快照与断言时机**：①加锁；②校验片存在、CurrentLocation==expectedFrom、目标存在、目标未满、源≠目标（前置校验，不满足直接拒绝、零改动）；③对双向映射和相关 SlotMap 做回滚快照；④执行变更：源 Occupants 移除（源是载具槽则 SlotMap 置空）、片 CurrentLocation 改为目标、目标 Occupants 加入（目标是载具槽则 SlotMap 置占用并绑 ID）；⑤提交后立即跑三不变式增量/全量断言，若失败用快照回滚并抛异常；⑥成功则记移动历史、发位置变更事件后解锁。快照在第③步（改动前），不变式断言在第⑤步（改动后、对外生效前），保证任何破坏不变式的改动都不会留下。
4. **三不变式实现 / 守恒基线**：①唯一位置：遍历每片 CurrentLocation 非空，且对每个位置反查 Occupants，正反映像一致（片登记在 loc 当且仅当 loc.Occupants 含该片），无片同时属两位置、无片无位置；②容量：遍历所有位置断言 Occupants.Count≤Capacity，载具槽/臂/腔容量 1 即不能有两片；③守恒：维护"进入设备基线总数"（上料时按源 SlotMap 占用数累加、正常移出时扣减），任何时刻 TotalInside=所有载具 SlotMap 占用数+所有设备内位置占用数，必须==当前应在总数。基线来自上料时刻的源 SlotMap 与 Host 任务声明（进多少、出多少），是守恒校验的参照。
5. **片状态与位置为何正交**：位置回答"物理在哪"（Slot5/RobotR1/ChamberC1），片状态回答"工艺进行到哪一步"（OnCarrier 在盒、InTransfer 在途、Processing 加工中、Processed 已加工、Done 完成）。二者独立变化、组合才有完整含义：同在 ChamberC1，可能正 Processing 也可能已 Processed 待取出；同在载具槽，可能未加工也可能加工完放回。若混成一个字段会产生笛卡尔积状态爆炸且语义混乱。正交建模：位置由 Move 迁移，工艺状态由加工流程迁移，互不替代，查询/追溯时组合两者（这正是 W12 正交状态机同一思想）。
6. **目标满在哪步拦截**：在第②步前置校验阶段就拦截——Move 先查目标 Location.Occupants.Count 是否==Capacity（或目标载具槽是否 Occupied），已满直接抛 LocationFull/DoublePlace，不做任何改动（零副作用），不会进入第④步修改。即使并发，靠加锁保证"检查容量+放入"原子，避免两个迁移同时通过检查导致双重放置。上层捕获后转告警并安全挂起该取放任务。
7. **槽位占用为何与 SlotMap 同步、不能各存一份**：载具槽位的占用本质是同一件事——LocationSpace 里 CarrierLocation 的 Occupants 和 SlotMap 的槽状态是同一物理事实的两种视图。各存一份且不原子同步，就会出现"位置空间说槽空、SlotMap 说有片"的双账本不一致，Unload 守卫、源/结果图对比、SECS 上报会互相矛盾。正确做法是以 LocationSpace 为权威，在 Move 同一事务内同步更新对应 SlotMap（或让 SlotMap 直接从 CarrierLocation 占用派生），保证单一事实源、绝不维护两份可能漂移的独立副本。

### 值对象

```csharp
namespace EapLab.E90;
public abstract record LocationId(string Key);
public sealed record CarrierLocation(string CarrierId,int Slot) : LocationId($"Carrier:{CarrierId}:S{Slot}");
public sealed record InternalLocation(string Name) : LocationId($"Internal:{Name}");

public enum SubstrateState { OnCarrier, InTransfer, Processing, Processed, Done }
public sealed class Substrate
{
    public string Id { get; }
    public LocationId Location { get; internal set; }
    public SubstrateState State { get; internal set; }=SubstrateState.OnCarrier;
    public List<string> History { get; }=new();
    public Substrate(string id,LocationId loc){Id=id;Location=loc;}
}
public sealed class Location
{
    public LocationId Id { get; } public int Capacity { get; }
    public HashSet<string> Occupants { get; }=new();
    public bool IsFull => Occupants.Count>=Capacity;
    public Location(LocationId id,int capacity=1){Id=id;Capacity=capacity;}
}
public enum TrackErrorCode { NotAtExpectedLocation, LocationFull, SubstrateMissing, DoublePlace, ConservationBroken, LocationMissing }
public sealed class SubstrateTrackingException : Exception
{ public TrackErrorCode Code { get; }
  public SubstrateTrackingException(TrackErrorCode c,string msg):base(msg){Code=c;} }
```

### 位置空间（双向映射 + 原子 Move + 不变式）
```csharp
public sealed class LocationSpace
{
    private readonly Dictionary<string,Substrate> _sub=new();
    private readonly Dictionary<string,Location> _loc=new();
    private readonly Dictionary<string,SlotMap> _carrierSlotMap=new();
    private int _baselineTotal;   // 守恒基线(应在设备内总数)
    public List<string> Events { get; }=new();
    public event Action<string,LocationId,LocationId>? Moved;

    public void AddLocation(Location l)=>_loc[l.Id.Key]=l;
    public void RegisterCarrier(string carrierId,SlotMap source)
    { for(int s=1;s<=SlotMap.SlotCount;s++) AddLocation(new Location(new CarrierLocation(carrierId,s),1));
      _carrierSlotMap[carrierId]=source; _baselineTotal+=source.OccupiedCount;
      foreach(var s in source.OccupiedSlots){ var id=source.IdAt(s)??$"{carrierId}-S{s}";
        var sub=new Substrate(id,new CarrierLocation(carrierId,s)); _sub[id]=sub;
        _loc[sub.Location.Key].Occupants.Add(id); } }
    public LocationId LocationOf(string id)=>_sub.TryGetValue(id,out var s)?s.Location:throw new SubstrateTrackingException(TrackErrorCode.SubstrateMissing,id);

    public void Move(string id, LocationId expectedFrom, LocationId to, SubstrateState? stateDuring=null)
    {
        lock(this)
        {
            if(!_sub.TryGetValue(id,out var sub)) throw new SubstrateTrackingException(TrackErrorCode.SubstrateMissing,id);
            if(!_loc.TryGetValue(to.Key,out var target)) throw new SubstrateTrackingException(TrackErrorCode.LocationMissing,to.Key);
            if(sub.Location.Key!=expectedFrom.Key)
                throw new SubstrateTrackingException(TrackErrorCode.NotAtExpectedLocation,$"{id} 实际在{sub.Location.Key}, 声称从{expectedFrom.Key}");
            if(target.IsFull) throw new SubstrateTrackingException(TrackErrorCode.LocationFull,$"目标已满 {to.Key}");
            if(sub.Location.Key==to.Key) throw new SubstrateTrackingException(TrackErrorCode.DoublePlace,$"原地重复放置 {to.Key}");
            var from=_loc[sub.Location.Key];
            // 快照(教学用关键字段,真实可深拷贝)
            var fromSet=new HashSet<string>(from.Occupants); var toSet=new HashSet<string>(target.Occupants);
            var oldLoc=sub.Location;
            try
            {
                // 变更: 源移除
                from.Occupants.Remove(id); SyncCarrierSlot(oldLoc,null,id);
                // 目标加入
                target.Occupants.Add(id); sub.Location=to; SyncCarrierSlot(to,id,id);
                if(stateDuring is { } st) sub.State=st;
                sub.History.Add($"{oldLoc.Key}->{to.Key}");
                AssertInvariants();   // 提交后断言
            }
            catch
            {   // 回滚
                from.Occupants.Clear(); foreach(var x in fromSet)from.Occupants.Add(x);
                target.Occupants.Clear(); foreach(var x in toSet)target.Occupants.Add(x);
                sub.Location=oldLoc; throw;
            }
            var ev=$"{id}:{oldLoc.Key}->{to.Key}"; Events.Add(ev); Moved?.Invoke(id,oldLoc,to);
        }
    }
    private void SyncCarrierSlot(LocationId loc,string? add,string? remove)
    {
        if(loc is CarrierLocation c)
        { var map=_carrierSlotMap[c.CarrierId];
          if(remove is not null) map.SetEmpty(c.Slot);
          if(add is not null) map.SetOccupied(c.Slot,add); }
    }
    public int TotalInside => _loc.Values.Sum(l=>l.Occupants.Count(id=>_sub[id].Location.Key==l.Id.Key));
    public void AssertInvariants()
    {
        // 容量 + 正反映像
        foreach(var loc in _loc.Values)
        {
            if(loc.Occupants.Count>loc.Capacity) throw new SubstrateTrackingException(TrackErrorCode.DoublePlace,$"容量突破 {loc.Id.Key}");
            foreach(var id in loc.Occupants) if(_sub[id].Location.Key!=loc.Id.Key)
                throw new SubstrateTrackingException(TrackErrorCode.ConservationBroken,$"镜像不一致 {id}");
        }
        foreach(var s in _sub.Values) if(!_loc.ContainsKey(s.Location.Key))
            throw new SubstrateTrackingException(TrackErrorCode.ConservationBroken,$"{s.Id}无有效位置");
        if(TotalInside!=_baselineTotal)
            throw new SubstrateTrackingException(TrackErrorCode.ConservationBroken,$"守恒破坏 total={TotalInside} base={_baselineTotal}");
    }
    public void SubstrateState(string id,SubstrateState st){_sub[id].State=st;}
}
```

```csharp
public class LocationSpaceTests
{
    LocationSpace Build(out SlotMap map)
    { var space=new LocationSpace(); map=new SlotMap(); map.SetOccupied(5,"W5");
      space.AddLocation(new Location(new InternalLocation("R1")));
      space.AddLocation(new Location(new InternalLocation("C1")));

    [Fact] public void 正常迁移_槽到臂到腔()
    { var s=Build(out _);
      s.Move("W5",new CarrierLocation("FOUP-A",5),new InternalLocation("R1"),SubstrateState.InTransfer);
      Assert.Equal("Internal:R1",s.LocationOf("W5").Key);
      s.Move("W5",new InternalLocation("R1"),new InternalLocation("C1"),SubstrateState.Processing);
    }
    [Fact] public void 过期源位置_拒绝()
    { var s=Build(out _); s.Move("W5",new CarrierLocation("FOUP-A",5),new InternalLocation("R1"));
      Assert.Throws<SubstrateTrackingException>(()=>
        s.Move("W5",new CarrierLocation("FOUP-A",5),new InternalLocation("C1"))); // 已不在槽5
    }
    [Fact] public void 目标满_双重放置拒绝()
    { var s=Build(out var m); m.SetOccupied(6,"W6");
      // 重新注册以含W6(教学), 让两片都想去容量1的R1
      var s2=new LocationSpace(); var map=new SlotMap();map.SetOccupied(5,"W5");map.SetOccupied(6,"W6");

      s2.Move("W5",new CarrierLocation("A",5),new InternalLocation("R1"));

    { var s=Build(out _); s.AssertInvariants();
      s.Move("W5",new CarrierLocation("FOUP-A",5),new InternalLocation("R1"));s.AssertInvariants();

      Assert.Equal(1,s.TotalInside);
    }
```

## 三、今日易错点
1. 双向映射只改一边（正反映像不一致，必须 Move 内原子同改）。
2. Move 不带 expectedFrom（基于过期位置误操作，要乐观并发校验）。
3. 先改后校验、失败不回滚（先快照、改后断言、失败整体回滚零副作用）。
4. 容量检查和放入不原子（并发下双重放置，要加锁）。
5. 片状态和位置混成一个字段（正交：位置 Move 迁移、工艺状态单独迁移）。
6. SlotMap 与位置空间各存一份独立副本（单一事实源，Move 内同步/派生）。
7. 守恒基线忘记随上料/移出更新（进加出减，否则恒等式永远对不上）。
8. 在途片不在任何位置（臂也是容量 1 的位置，保证唯一归属）。
