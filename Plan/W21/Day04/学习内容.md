# W21 · Day04（周四）多 PJ 级联暂停/恢复与交接位重核

> 建议时长：90 分钟。今天聚焦 CJ 级联 Pause/Resume 的完整正确性：多个 PJ 同时到安全点的栅栏、CJ 级恢复点（含每个 PJ 恢复点与跨 PJ 交接位）、Resume 时对交接位片的重新核对，保证整批暂停后续跑不重片、不漏片、不串片。

## 一、今日目标
1. 实现 CJ 级联暂停栅栏：跨多 PJ、多并发单元全部到安全点才整体 Paused。
2. 构建 CjResumeToken：聚合各 PJ 恢复点 + 跨 PJ 交接位快照 + 全局守恒。
3. Resume 时重核交接位：交接片身份/位置/清单一致才续，不一致转人工。
4. 处理暂停期间的保护：锁载具、冻结调度、未启动 PJ 的挂起标记不被拉起。
5. xUnit 覆盖栅栏汇聚、恢复点聚合、交接位重核通过/拒绝、不重不漏。

## 二、背景知识（先读，30 分钟）

### 1. 从单 PJ 暂停到 CJ 级联暂停
- 单 PJ：自己的在途片到安全点→Paused（W17）。
- CJ：含多个 PJ，可能多个 PJ 同时在多腔并行（W18）；级联 Pause 要等**所有活动 PJ 都 Paused**，且每个 PJ 内所有并发单元都到安全点，是一个"两层栅栏"（PJ 内栅栏 + CJ 跨 PJ 栅栏）。

### 2. 两层栅栏
```
PJ内栅栏(W17/W18): 一个PJ的所有并发单元(腔/臂/锁)到安全点 → 该PJ Paused
CJ跨PJ栅栏(本周): 所有活动PJ都Paused(Completed保持, Queued挂起) → CJ Paused
```
- 任一层未满足，CJ 保持 Pausing；已 Paused 的 PJ 等待其余 PJ。

### 3. CJ 级恢复点 CjResumeToken
- 聚合每个 PJ 的 ResumeToken（进度游标、每片位置、已完成集合、载具快照，W17）。
- 额外记录**跨 PJ 交接位**：哪些片停在前驱输出/后继输入的交接位置、交接进行到哪一步（是否已从前驱取出、是否已被后继取走）。
- 全局守恒快照：所有载具+设备内+交接位的片 ID 集合=基线。
- CJ 状态、被 SuspendPending 的未启动 PJ 列表、暂停原因/时间。

### 4. Resume 交接位重核（核心）
- 暂停期间现场可能变化（人工干预、抖动），Resume 不能只信 Token：
  1. 逐 PJ 恢复点与 E90 实际位置核对（W17 现场一致性）。
  2. **重点重核跨 PJ 交接位**：交接中的片，其实际位置/身份是否与 Token 记录的交接阶段一致——
     - 片还在前驱输出位且未被后继取：后继从该位取；
     - 片已在后继（已完成交接）：后继按已接收继续，前驱不重发；
     - 位置/身份对不上：交接状态不明，转人工，禁止猜。
  3. 全局集合守恒复核通过后，才逐 PJ Resume，解除未启动 PJ 挂起。
- 目标：跨 PJ 边界不出现"前驱重发一片、后继已收一片"的重片，或"两边都以为对方拿了"的漏片。

### 5. 暂停期间保护
- 锁定 CJ 相关输入/输出/中间载具（防止卸载取走交接片）。
- 冻结全局调度（不启动新动作、不拉起 SuspendPending 的 PJ）。
- 必要工艺保持（真空等按能力），记录保持状态。

### 6. 不重不漏的层级保证
- PJ 内：已完成步/片跳过、当前从安全边界续（W17）。
- 跨 PJ：以交接位实际状态决定"谁该拿这片"，交接是幂等动作（带预期片 ID，取走即标记，重复交接被识别）。
- CJ：唯一片集合守恒贯穿，Resume 后最终输出与无暂停基线一致。
