# W21 · Day04 答案与参考实现

## 一、自测题标准答案
1. **两层栅栏 / 为何两层**：内层 PJ 栅栏——一个 PJ 内多个并发单元（多腔/臂/锁上的片）都到安全点，该 PJ 才 Paused（W17/W18）；外层 CJ 栅栏——所有活动 PJ 都 Paused（Completed 保持、Queued 挂起），CJ 才 Paused。需要两层是因为暂停一个含多 PJ、且每 PJ 又多腔并行的 CJ，安全点条件是分层的：单个 PJ 内部先收敛（它自己的片安全），多个 PJ 之间再收敛（没有任何 PJ 还在动）。只做一层会出现"某 PJ 自己停了但别的 PJ 还在加工"或"PJ 声称停了但它腔内反应未到边界"，都不是整体安全态。
2. **CjResumeToken 多了什么 / 为何**：除聚合每个 PJ 各自的 ResumeToken（进度游标、每片位置、已完成集合、载具快照）外，必须额外记录①跨 PJ 交接位状态——哪些片停在前驱输出/后继输入的交接点、交接进行到哪一步（前驱是否已交出、后继是否已取走）；②全局片 ID 集合守恒快照（所有载具+设备内+交接位=基线）；③被 SuspendPending 的未启动 PJ 列表；④CJ 整体状态与暂停原因。因为单 PJ 恢复点只覆盖一个 PJ 内部，而 CJ 的最大风险在 PJ 之间的责任缝隙（交接片归谁、续跑时谁取），不记录交接阶段就无法在 Resume 时判断该由前驱重发还是后继续收，会重片/漏片。
3. **为何重点重核交接位**：暂停期间现场可能被改变（人工动片、抖动、机构状态变化），PJ 内部有 W17 的现场一致性校验，而跨 PJ 交接位是两个执行单元的边界、最容易出现"前驱以为交了、后继以为没收到"或片被移动的情况，且 Token 记录的交接阶段可能已过时。Resume 时若只信 Token 不看实际，可能前驱再发一片（重复）或两边都不取（漏片）。因此必须用 E90 实际位置+读码核对交接片到底处于"仍在前驱输出位"还是"已到后继"，身份一致才按实际续，状态不明转人工。
4. **交接片两种确定状态 / 如何续**：①片仍在前驱输出交接位、尚未被后继取走——Resume 后由后继从该交接位按预期 ID 取片，继续后继流程，前驱不重复产出；②片已被后继取走、交接已完成（片在后继内/后继输入位）——后继按"已接收"继续其加工，前驱不再重发该片。判定依据是 E90 实际位置+交接标记+读码，二者必居其一且身份一致才安全；若片既不在前驱输出也不在后继、或读码不符，属于第三种"不明状态"，安全保持转人工。
5. **交接幂等 / 防重收重发**：给每次跨 PJ 交接赋唯一交接标识（源 PJ、目标 PJ、片 ID、交接序号），交接动作带"预期片 ID + 期望当前位置"，执行时先检查交接状态：若该片已被目标 PJ 接收（有接收标记/已在目标侧），再次请求直接返回"已交接"而不重复取放；前驱侧交出后标记"已交出"，不会因 Resume 重新产出。即交接是带幂等键的状态转移（Pending→HandedOver→Received），重复执行结果相同、只推进一次，配合 E90 位置核对，从机制上杜绝前驱重发、后继重复收。
6. **Paused 期间保护 / 不做的后果**：①锁定相关输入/输出/中间载具，禁止卸载——否则交接片/在途片失去归属载具，Resume 无位可归；②冻结全局调度，不启动新动作、不拉起 SuspendPending 的未启动 PJ——否则"暂停"期间仍有片流动，违背暂停语义、现场被进一步改变；③必要工艺保持（真空/温度按设备能力）并记录——否则在腔片工艺环境丧失可能报废；④保持现场快照与资源占用记录。不做这些，Resume 时现场已不可恢复地改变，只能人工，甚至造成丢片/报废。
7. **级联 Resume 不重不漏**：分三层保证。PJ 内：按各自 ResumeToken，已完成步/片跳过、当前片从安全边界续、未开始按序（W17 不重不漏）；跨 PJ：以交接位实际状态+幂等交接决定每片归谁续（未取由后继取、已取不重发），消除责任缝隙；CJ 层：用全局唯一 ID 集合守恒复核（载具+设备内+交接位=基线），解除未启动 PJ 挂起、按依赖顺序恢复。三层一致且守恒通过才整体回 Executing，最终输出片集合/位置与"没有暂停过"的基线完全一致，即整批不重不漏。

## 二、参考实现（net8.0）

### 两层栅栏
```csharp
namespace EapLab.E94.Cascade;
// 内层: 单PJ并发单元栅栏(复用W18 ConcurrentPauseBarrier)
// 外层: 跨PJ栅栏
public sealed class CjPauseBarrier
{
    private readonly HashSet<string> _activePjs;   // 活动PJ(执行中)
    public CjPauseBarrier(IEnumerable<string> activePjs){_activePjs=new(activePjs);}
    public void PjPaused(string pj){_activePjs.Remove(pj);}
    public bool AllPaused=>_activePjs.Count==0;
}
```

### 交接状态与幂等
```csharp
public enum HandoverState{Pending,HandedOver,Received}
public sealed class CjHandover
{
    public string Wafer="",FromPj="",ToPj=""; public HandoverState State;
    public string StageLocation="";   // 交接位
}
public sealed class HandoverTable
{
    private readonly Dictionary<string,CjHandover> _byWafer=new();
    public void Declare(string w,string from,string to,string loc)
    { if(!_byWafer.ContainsKey(w))_byWafer[w]=new(){Wafer=w,FromPj=from,ToPj=To,StageLocation=loc,State=HandoverState.Pending}; }
    public void HandedOver(string w){_byWafer[w].State=HandoverState.HandedOver;}
    // 幂等接收: 已Received则不再取
    public bool TryReceive(string w,Func<string,string> actualLocation,Func<string,string?> readId,out string reason)
    { var h=_byWafer[w]; reason="";
      if(h.State==HandoverState.Received){reason="已交接,幂等返回";return true;}
      var loc=actualLocation(w); var id=readId(w);
      if(id!=w){reason="交接身份不符";return false;}
      if(loc!=h.StageLocation){reason="交接片不在预期交接位";return false;}
      h.State=HandoverState.Received; return true; }
}
```

### CJ 恢复点与 Resume 重核
```csharp
public sealed class CjResumeToken
{
    public string CjId=""; public Dictionary<string,ResumeToken> PjTokens=new();
    public List<CjHandover> Handovers=new(); public HashSet<string> SuspendedPjs=new();
    public HashSet<string> GlobalIdSnapshot=new();
}
public sealed class CjResumeService
{
    private readonly SubstrateTracker _t; private readonly HandoverTable _ht;
    public CjResumeService(SubstrateTracker t,HandoverTable ht){_t=t;_ht=ht;}

    // 逐PJ恢复 + 交接位重核; 返回是否可整体Resume
    public (bool ok,List<string> problems) Resume(CjResumeToken tok)
    { var prob=new List<string>();
      // 1 全局集合守恒
      if(!new HashSet<string>(_t.AllWaferIds()).SetEquals(tok.GlobalIdSnapshot))prob.Add("全局片集合与恢复点不符");
      // 2 交接位重核: 每片按实际位置决定续法
      foreach(var h in tok.Handovers)
      { var loc=_t.LocationOf(h.Wafer).Key;
        if(h.State==HandoverState.HandedOver && loc==h.StageLocation){/*仍在交接位: 后继取*/}
        else if(h.State==HandoverState.Received){/*已到后继: 不重发*/}
        else prob.Add($"交接状态不明:{h.Wafer}@{loc}"); }
      // 3 各PJ现场一致性(复用W17, 教学略)
      return (prob.Count==0,prob); }
}
```

## 三、级联暂停/恢复（手绘参考）
```
Pause(CJ) → 级联各活动PJ →
  内层栅栏: 每PJ的腔/臂/锁到安全点 → 该PJ Paused
  外层栅栏: 所有活动PJ Paused(Completed保持/Queued挂起SuspendPending) → CJ Paused
落 CjResumeToken: 各PJ恢复点 + 交接位状态(Pending/HandedOver/Received) + 全局ID集合
暂停期: 锁载具/冻结调度/不拉起挂起PJ/必要工艺保持
Resume: 全局守恒核对 → 交接位按实际重核(仍在交接位→后继取; 已接收→不重发; 不明→人工)
       → 各PJ不重不漏 → 解挂起按依赖恢复 → Executing; 输出==无暂停基线
交接幂等键(源PJ,目标PJ,片ID,序号): Pending→HandedOver→Received, 重复执行只推进一次
```

## 四、今日易错点
1. 只做一层栅栏（PJ 内安全点 + 跨 PJ 全部 Paused 两层都要）。
2. CJ 恢复点不记跨 PJ 交接位状态（责任缝隙无法续，重漏片）。
3. Resume 只信 Token 不核对交接位实际位置/读码（现场可能变）。
4. 交接非幂等，Resume 导致前驱重发、后继重复收（用状态机+幂等键）。
5. 分不清 HandedOver 与 Received（前者片仍在交接位待后继取，后者已到后继）。
6. Paused 期间不锁载具/不冻结调度，挂起 PJ 被偷偷拉起。
7. 全局集合守恒不复核（跨 PJ 漏片在 CJ 层才看得全）。
8. 交接状态不明还猜着续（身份/位置不明必须安全保持人工）。
