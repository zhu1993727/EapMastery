# W21 · Day02 答案与参考实现

## 一、自测题标准答案
1. **为何不能无脑广播**：子 PJ 处于不同状态（Completed/Executing/Pausing/Paused/Queued），同一命令对不同状态合法性不同——对已 Completed 的 PJ 下 Pause/Start 无意义甚至非法，对 Queued 的 PJ 下"到安全点暂停"无从谈起（它还没开始），对 Paused 的 PJ 再下 Pause 是重复操作。无脑广播会产生非法命令、重复副作用或错误状态。必须按每个 PJ 的当前状态分类决定"下发/忽略/挂起/取消"，才能让一个 CJ 命令在异构子状态上语义正确。
2. **Pause 对五类子 PJ**：Completed——不动，保持完成终态（成果不回退）；Executing——下发 Pause，该 PJ 进入 Pausing，让在途片到安全点后 Paused；Pausing——幂等，它已在暂停过程中，不重复下发；Paused——幂等，已是目标态；Queued（未启动）——加 SuspendPending 标记，即使之后依赖满足也不自动启动，直到 CJ Resume。即"活动者去安全点、完成者不动、未启动者挂起、已在过程/目标态者幂等"。
3. **为何幂等 / 实现**：级联命令可能因重试、重复事件、网络重发而多次到达，若不幂等，重复 Pause 会重置安全点过程、重复 Abort 触发二次错误处理。实现：下发前先看子 PJ 当前状态，若已处于该命令导致的过程/目标态（Pausing/Paused 之于 Pause、已 Aborted 之于 Abort），直接返回"已在该态"而不再次调用其状态机；命令本身设计为"转到目标态"而非"叠加一次动作"，多次调用结果相同。
4. **Cancel(CJ) 前提 / 有 PJ 动工**：前提是**所有**子 PJ 都未动工（每个都 Queued、没有任何片离开源槽，即 CJ 范围的 NothingTouched），此时可整体干净撤回、释放全部预留、Cancelled 终态。只要有一个 PJ 已动工（Started/Executing，有片在途/加工），物理现实已改变，无法回到"什么都没发生"，Cancel 必须拒绝（零副作用）并提示应使用 Abort（对活动 PJ 中止、对未动工 PJ 取消、三分类处置片）。
5. **CJ 何时真 Paused / 汇聚机制**：Pause(CJ) 后 CJ 先进入 Pausing，向活动 PJ 下发 Pause；每个活动 PJ 都让自己的在途片到安全点并 Paused，Completed 的保持、Queued 的挂起。当聚合发现"所有活动 PJ 都 Paused（无 Executing/Pausing 残留、无运动中片）"即 AllChildrenPaused 且栅栏 Guard 通过，才驱动 CJ-FSM 迁移到 Paused。靠的是 W20/W21 的安全点栅栏 + 聚合事件：子 PJ 逐个到达→重算→全部到达才迁移，未到齐前一直 Pausing。
6. **SuspendPending / 解决问题**：这是给尚未启动（Queued）的子 PJ 的"暂停挂起"标记。CJ Pause 时它还没运行、谈不上到安全点，但如果不标记，等它的依赖稍后满足时编排器会按正常逻辑自动启动它，违背"整批已暂停"的意图。加标记后，即使依赖就绪、片就位也不启动；CJ Resume 时清除标记，被挂起的 PJ 才恢复可启动。它解决"暂停时未启动的子作业在暂停期间被意外拉起"的问题，保证 Paused 的 CJ 不会有 PJ 偷偷开始。
7. **部分拒绝如何不状态失真**：先做可执行性预判——对于要求"全部子 PJ 到达某态"的命令（Cancel、最终 Paused/Aborted），先判断是否存在无法到达目标态的 PJ，若存在则整体判定不可行，不做半吊子下发（all-or-nothing），CJ 不迁移、返回原因。对于本来就允许渐进的命令（Pause 需各 PJ 逐步到安全点），先下发、CJ 停在 Pausing 由栅栏汇聚，只有全部到位才迁移；若中途某 PJ 明确拒绝且导致永远无法到齐，则 CJ 不进 Paused，转异常处理并报告是哪个 PJ 阻塞。核心原则：CJ 状态必须如实反映子 PJ 集合，绝不在"部分暂停/部分中止"时宣称整体已到目标态。

## 二、参考实现（net8.0）

### 级联结果与分类下发
```csharp
namespace EapLab.E94.Fsm;
public enum CascadeResult { Accepted, Ignored, Rejected }
public sealed class CascadeOutcome
{ public Dictionary<string,CascadeResult> PerPj=new(); public bool All(Func<CascadeResult,bool> f)=>PerPj.Values.All(f); }

public sealed class CjCommandCascade
{
    private readonly Dictionary<string,ProcessJob> _pjs;
    private readonly HashSet<string> _suspendPending=new();   // 未启动PJ的暂停挂起标记
    public CjCommandCascade(Dictionary<string,ProcessJob> pjs){_pjs=pjs;}
    public IReadOnlySet<string> SuspendPending=>_suspendPending;

    public CascadeOutcome Dispatch(CjCommand cmd)
    {
        var o=new CascadeOutcome();
        foreach(var (id,pj) in _pjs)
            o.PerPj[id]=cmd switch
            {
                CjCommand.Start  => ToStart(id,pj),
                CjCommand.Pause  => ToPause(id,pj),
                CjCommand.Resume => ToResume(id,pj),
                CjCommand.Cancel => ToCancel(id,pj),
                CjCommand.Abort  => ToAbort(id,pj),
                _=>CascadeResult.Rejected
            };
        return o;
    }

    CascadeResult ToStart(string id,ProcessJob pj)=>pj.State switch
    { JState.Queued => pj.Try(JobCommand.Start)?CascadeResult.Accepted:CascadeResult.Rejected,
      _=>CascadeResult.Ignored };                                  // 已开始/完成: 忽略

    CascadeResult ToPause(string id,ProcessJob pj)=>pj.State switch
    { JState.Completed => CascadeResult.Ignored,                  // 完成不动
      JState.Executing => pj.Try(JobCommand.Pause)?CascadeResult.Accepted:CascadeResult.Rejected,
      JState.Pausing or JState.Paused => CascadeResult.Ignored,   // 幂等
      JState.Queued => { _suspendPending.Add(id); return CascadeResult.Accepted; }, // 挂起
      _=>CascadeResult.Rejected };

    CascadeResult ToResume(string id,ProcessJob pj)
    { if(_suspendPending.Remove(id))return CascadeResult.Accepted; // 解除挂起
      return pj.State switch
      { JState.Paused => pj.Try(JobCommand.Resume)?CascadeResult.Accepted:CascadeResult.Rejected,
        JState.Completed => CascadeResult.Ignored,
        _=>CascadeResult.Ignored }; }

    CascadeResult ToCancel(string id,ProcessJob pj)=>pj.State switch
    { JState.Queued => CascadeResult.Accepted,                    // 仅未动工可取消
      _=>CascadeResult.Rejected };                                // 有动工→拒绝(应Abort)

    CascadeResult ToAbort(string id,ProcessJob pj)=>pj.State switch
    { JState.Completed => CascadeResult.Ignored,
      JState.Queued => CascadeResult.Accepted,                    // 未开始直接取消
      _=> pj.Try(JobCommand.Abort)?CascadeResult.Accepted:CascadeResult.Rejected };

    public bool AllUntouched()=>_pjs.Values.All(p=>p.State==JState.Queued);
}
```

### 级联 + CJ-FSM 联动
```csharp
public sealed class CjCascadeCoordinator
{
    private readonly CjStateMachine _cj; private readonly CjCommandCascade _cas;
    public CjCascadeCoordinator(CjStateMachine cj,CjCommandCascade cas){_cj=cj;_cas=cas;}

    public bool Pause()
    { if(_cj.State!=CjState.Executing)return false;
      var o=_cas.Dispatch(CjCommand.Pause);
      if(o.PerPj.Values.Any(r=>r==CascadeResult.Rejected))return false; // 有拒绝不迁移
      return _cj.TryCommand(CjCommand.Pause); }                         // 进Pausing, 等栅栏

    public bool Cancel()
    { if(!_cas.AllUntouched())return false;                             // 有动工拒绝
      _cas.Dispatch(CjCommand.Cancel); return _cj.TryCommand(CjCommand.Cancel); }

    // 子PJ逐步到安全点后调用, 全部活动Paused则驱动CJ
    public void Reevaluate(IReadOnlyList<JState> children)
    { if(_cj.State==CjState.Pausing && children.All(s=>s is JState.Paused or JState.Completed))
        _cj.TryAggregate(CjAggEvent.AllChildrenPaused);
      if(_cj.State==CjState.Executing && children.All(s=>s==JState.Completed))
        _cj.TryAggregate(CjAggEvent.AllChildrenDone); }
}
```

```csharp
public class CascadeTests
{
    [Fact] public void Pause_按态分类_完成忽略_执行下发_排队挂起_幂等()
    { var pjs=new Dictionary<string,ProcessJob>
      { ["A"]=PjAt(JState.Completed),["B"]=PjAt(JState.Executing),["C"]=PjAt(JState.Queued) };
      var cas=new CjCommandCascade(pjs);
      var o=cas.Dispatch(CjCommand.Pause);
      Assert.Equal(CascadeResult.Ignored,o.PerPj["A"]);
      Assert.Equal(CascadeResult.Accepted,o.PerPj["B"]);
      Assert.Equal(CascadeResult.Accepted,o.PerPj["C"]);
      Assert.Contains("C",cas.SuspendPending);
      var o2=cas.Dispatch(CjCommand.Pause);                  // 重复: B已Pausing幂等
      Assert.Equal(CascadeResult.Ignored,o2.PerPj["B"]); }

    { var pjs=new(){["A"]=PjAt(JState.Queued),["B"]=PjAt(JState.Executing)};
      var cj=new CjStateMachine(); var cas=new CjCommandCascade(pjs);
      var co=new CjCascadeCoordinator(cj,cas);
      Assert.False(co.Cancel()); Assert.NotEqual(CjState.Cancelled,cj.State); }

      var cj=new CjStateMachine(); ToStarted(cj);
      var co=new CjCascadeCoordinator(cj,new CjCommandCascade(pjs));
      Assert.True(co.Cancel()); Assert.Equal(CjState.Cancelled,cj.State); }
    [Fact] public void Pause栅栏_全部Paused才CJ_Paused()

      var cj=new CjStateMachine(); ToExecuting(cj);
      var co=new CjCascadeCoordinator(cj,new CjCommandCascade(pjs));
      co.Pause();
      co.Reevaluate(new[]{JState.Paused,JState.Executing}); Assert.Equal(CjState.Pausing,cj.State);
      co.Reevaluate(new[]{JState.Paused,JState.Paused});    Assert.Equal(CjState.Paused,cj.State); }

      var cas=new CjCommandCascade(pjs); cas.Dispatch(CjCommand.Pause);
      var o=cas.Dispatch(CjCommand.Resume);
      Assert.DoesNotContain("B",cas.SuspendPending);
      Assert.Equal(CascadeResult.Accepted,o.PerPj["A"]); }

    static void ToStarted(CjStateMachine f){f.TryCommand(CjCommand.Start);}
```

## 三、命令级联规则表（手绘参考）
```
          Completed   Executing     Pausing/Paused   Queued
Start     忽略        -             -                依赖就绪则启动
Pause     忽略        下发→Pausing  幂等             SuspendPending挂起
Resume    忽略        -             Paused→恢复      清除挂起标记
Cancel    拒绝(已完成) 拒绝(动工)    拒绝             仅全Queued才整体Cancel
Abort     忽略(保成果) 下发Abort    下发Abort        取消
汇聚: Pause→全部活动Paused(栅栏)才CJ Paused
      Abort→全部活动到终态才CJ Aborted
原则: 幂等/按态分类/all-or-nothing预判/级联动作与CJ-FSM迁移分离
```

## 四、今日易错点
1. 命令无脑广播给所有 PJ（必须按子状态分类：忽略/下发/幂等/挂起/取消）。
2. 级联命令不幂等，重复下发产生副作用。
3. 有 PJ 动工还允许整体 Cancel（必须全 Queued，否则改 Abort）。
4. Pause 后不等全部活动 PJ 到安全点就把 CJ 设 Paused（栅栏汇聚）。
5. 不给 Queued PJ 加 SuspendPending，导致暂停期间它依赖满足后被偷偷启动。
6. Resume 只恢复 Paused 的 PJ，忘了清除未启动 PJ 的挂起标记。
7. 部分 PJ 拒绝还强行迁移 CJ（状态失真，应不迁移并报告阻塞者）。
8. 把级联下发和 CJ 自身状态迁移耦合在一起（级联下命令、FSM 凭聚合事件迁移，分离才好测）。
