## 二、背景知识（先读，30 分钟）

### 1. CJ-FSM 与 PJ-FSM 的异同
- 同：状态集同构（Queued/Started/Executing、Pausing/Paused、四终态），都复用泛型状态机、Guard、非法零副作用、终态无出边、先迁移后发事件。
- 异：PJ 由自身执行事件驱动（片完成、到安全点）；CJ 由**一组子 PJ 的状态聚合**驱动——子 PJ 一变，CJ 重算"如果现在迁移应到哪个态"，与当前态不同且 Guard 满足才迁移。

### 2. CJ 的两类触发器
- **外部命令 CjCommand**：Host 经 S15 下发 Start/Pause/Resume/Cancel/Abort（W20 Day03）。
- **内部聚合事件 CjAggEvent**：由子 PJ 状态变化计算而来，如
  - ChildStarted（有 PJ 开始）
  - ChildStateChanged（任一子 PJ 状态变化，触发重算）
  - AllChildrenDone（所有 PJ 完成，且片到输出、终验过→可 Completed）
  - ChildFaulted（某 PJ 故障，按级联策略）
  - AllChildrenPaused（活动 PJ 全 Paused→CJ Paused）
- CJ-FSM 同时接受命令与聚合事件（同 PJ-FSM 用 object 统一承载命令/事件的写法）。

### 3. 聚合驱动回路
```
子PJ状态变化事件 → CjStateAggregator 计算期望CJ态
   → 若期望态≠当前态 且 对应Guard通过 → CJ-FSM迁移 → 发CJ事件
   → 若Guard不通过(如片未全到输出) → 保持当前态(如Executing), 不迁移
```
- 关键点：聚合"期望态"只是建议，真正迁移仍由 FSM 的合法边与 Guard 裁决，保证不会绕过状态机直接改状态。

### 4. CJ 迁移 Guard
- StartGuard：所有输入/输出载具 Loaded、绑口 ID 对、PJ 定义齐、资源可用、无 Hold（W20）。
- PauseBarrierGuard：所有活动 PJ 已 Paused（Completed 保持），无运动中片（W20 栅栏）。
- CompleteGuard：所有 PJ Completed + 每片在 CJ 输出槽 + 设备内空 + 终验守恒 + 数据全（PJ 严格完成在 CJ 的放大）。
- NothingTouched（Cancel）：所有 PJ 未动工、无片离源。
- Guard 为假：零副作用、保持当前态、记录原因。

### 5. 状态集与边（今天实现）
- Queued --Start(Guard)→ Started --ChildStarted→ Executing
- Executing --Pause→ Pausing --AllChildrenPaused(Guard)→ Paused --Resume→ Executing
- Executing/Pausing/Paused --Abort→ Aborted；Queued/Started --Cancel(NothingTouched)→ Cancelled
- Executing --AllChildrenDone(CompleteGuard)→ Completed；--ChildFaulted(策略)→ Failed/保持
- 四终态无出边；其余非法组合拒绝。

### 6. 与级联的边界（今天只做 CJ 自身，命令如何下发到 PJ 是 Day02）
- 今天 CJ-FSM 只负责"自己的状态怎么变"；外部命令到达后如何逐个作用到子 PJ（级联动作）在 Day02 实现，二者分开便于单测。
