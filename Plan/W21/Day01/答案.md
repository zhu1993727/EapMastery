# W21 · Day01 答案与参考实现

## 一、自测题标准答案
1. **触发最大不同**：PJ-FSM 由"外部命令 + 自身执行事件（片就绪/到安全点/本片全完成/自身故障）"驱动，这些事件来自它自己的执行过程；CJ-FSM 没有自己的加工动作，它除外部命令外，迁移主要由**一组子 PJ 的状态变化经聚合后产生的内部事件**驱动——子 PJ 一变化，CJ 重算自己应处的状态。即 PJ 是"自己执行驱动自己"，CJ 是"下层子状态聚合驱动自己"，CJ-FSM 本质上是一组子 FSM 状态的聚合状态机。
2. **内部聚合事件 / 产生时机**：ChildStarted（首个/某 PJ 启动，CJ 应进入执行）；ChildStateChanged（任一子 PJ 状态变化，触发 CJ 重新聚合，最通用）；AllChildrenPaused（所有活动 PJ 都到安全点 Paused，满足级联暂停栅栏）；AllChildrenDone（所有 PJ Completed，且片到输出、终验通过，满足完成守卫）；ChildFaulted（某 PJ Failed/Aborted，按故障级联策略决定 CJ 走向）。它们都不是 Host 直接发的，而是 CJ 监听到子 PJ 的 S16/状态变化后由聚合器计算产生。
3. **期望态为何还要 FSM/Guard 裁决**：聚合期望态是"按子状态推断的理想态"，但状态迁移还必须满足合法性（当前态是否允许到目标态、有没有这条边）和 Guard（物理/任务条件是否具备）。例如子 PJ 全完成（期望 Completed）但有片还在 Buffer，CompleteGuard 不过，就不能迁移；若直接给 State 赋值，就绕过了状态机的合法性与条件检查，可能出现"跳到无此边的状态""条件不满足却完成"。经 FSM 裁决保证：只有合法边且 Guard 通过才迁移，否则保持现状、零副作用，这是单一状态写入口的要求。
4. **状态集与主要边**：Queued --Start(StartGuard)→ Started --ChildStarted→ Executing；Executing --Pause→ Pausing --AllChildrenPaused(PauseBarrierGuard)→ Paused --Resume→ Executing；Queued/Started --Cancel(NothingTouched)→ Cancelled(终)；Executing/Pausing/Paused --Abort→ Aborted(终)；Executing --AllChildrenDone(CompleteGuard)→ Completed(终)；Executing --ChildFaulted(关键路径策略)→ Failed(终)，可隔离策略则保持 Executing 并标记 Degraded。四终态 Cancelled/Aborted/Completed/Failed 无出边；其余组合非法、零副作用拒绝。
5. **CompleteGuard 比 PJ 完成守卫多的条件**：单 PJ 完成要求自己的片走完步骤、归到该 PJ 的目标、自身终验。CJ 的 CompleteGuard 是跨多 PJ 的放大：①**所有**子 PJ 都 Completed（不是一个）；②每片到达 **CJ 声明的最终输出载具槽**（中间 PJ 完成、片在交接位不算）；③跨 PJ/跨载具全局片 ID 集合守恒（顺序/汇合不重不漏）；④设备内/臂/锁/Buffer 全空（无 LeftInside）；⑤跨 PJ 交接全部闭合无悬挂；⑥无 Failed 子作业/Degraded 未闭环、无阻断 Hold；⑦各 PJ 数据齐全。即把 PJ 的"片归位+终验"提升到"整批料出 CJ"的范围。
6. **片在 Buffer 的 CJ 态**：仍是 Executing（或处于完成尝试中但迁移不成功）。因为所有 PJ 虽 Completed，但该片没到 CJ 最终输出槽、设备内非空（LeftInside），CompleteGuard 为假，AllChildrenDone 无法迁移到 Completed，FSM 保持 Executing 并提示有片滞留设备内，直到把 Buffer 中的片归位输出、设备清空、终验通过才 Completed。这与 W17"片在机械臂不能完成"是同一原则在 CJ 层的体现。
7. **Pausing 收到子完成会回 Executing 吗**：不会。Pausing 表示已收到暂停请求、正在等所有活动单元到安全点，这是一个有明确目标（去 Paused）的过渡态；此时某子 PJ 完成只是暂停过程中的正常进展，CJ 不会因此撤销暂停意图回到 Executing，而是继续等 AllChildrenPaused（其余活动 PJ 也 Paused）后迁移 Paused。状态迁移意图一旦确立（暂停中），中途的子完成事件不改变"要去 Paused"这个方向，避免在 Pausing/Executing 间抖动；要取消暂停需显式走相应命令（通常先到 Paused 再 Resume）。

## 二、参考实现（net8.0）

### 状态/命令/聚合事件
```csharp
namespace EapLab.E94.Fsm;
public enum CjState{Queued,Started,Executing,Pausing,Paused,Completed,Cancelled,Aborted,Failed}
public enum CjCommand{Start,Pause,Resume,Cancel,Abort}
public enum CjAggEvent{ChildStarted,ChildStateChanged,AllChildrenPaused,AllChildrenDone,ChildFaulted}
public enum CjTriggerKind{Command,Aggregate}
public sealed record CjTrigger(CjTriggerKind Kind,CjCommand? Cmd,CjAggEvent? Ev);
```

### CJ 状态机（复用 W10 泛型 StateMachine 思路）
```csharp
public sealed class CjStateMachine
{
    public CjState State{get;private set;}=CjState.Queued;
    public bool Degraded{get;private set;}
    // Guard 注入
    public Func<bool> StartGuard=()=>true;
    public Func<bool> PauseBarrier=()=>true;
    public Func<bool> CompleteGuard=()=>true;
    public Func<bool> NothingTouched=()=>true;
    public Func<bool> FaultStopsWhole=()=>true;
    private readonly List<string> _log=new(); public IReadOnlyList<string> Log=>_log;

    public bool TryCommand(CjCommand c)=>Try(new CjTrigger(CjTriggerKind.Command,c,null));
    public bool TryAggregate(CjAggEvent e)=>Try(new CjTrigger(CjTriggerKind.Aggregate,null,e));

    public bool Try(CjTrigger t)
    {
        var s=State;
        switch(s)
        {
          case CjState.Queued:
            if(t.Is(CjCommand.Start)&&StartGuard()){Goto(CjState.Started);return true;}
            if(t.Is(CjCommand.Cancel)&&NothingTouched()){Goto(CjState.Cancelled);return true;}
            break;
          case CjState.Started:
            if(t.Is(CjAggEvent.ChildStarted)){Goto(CjState.Executing);return true;}
            if(t.Is(CjCommand.Cancel)&&NothingTouched()){Goto(CjState.Cancelled);return true;}
            if(t.Is(CjCommand.Abort)){Goto(CjState.Aborted);return true;}
            break;
          case CjState.Executing:
            if(t.Is(CjCommand.Pause)){Goto(CjState.Pausing);return true;}
            if(t.Is(CjCommand.Abort)){Goto(CjState.Aborted);return true;}
            if(t.Is(CjAggEvent.AllChildrenDone)&&CompleteGuard()){Goto(CjState.Completed);return true;}
            if(t.Is(CjAggEvent.ChildFaulted))
            { if(FaultStopsWhole()){Goto(CjState.Failed);return true;} Degraded=true; return true; } // 可隔离: 保持执行
            break;
          case CjState.Pausing:
            if(t.Is(CjAggEvent.AllChildrenPaused)&&PauseBarrier()){Goto(CjState.Paused);return true;}
            if(t.Is(CjCommand.Abort)){Goto(CjState.Aborted);return true;}
            // 子完成/子变化不改变去Paused的方向
            break;
          case CjState.Paused:
            if(t.Is(CjCommand.Resume)){Goto(CjState.Executing);return true;}
            if(t.Is(CjCommand.Abort)){Goto(CjState.Aborted);return true;}
            break;
        }
        _log.Add($"非法迁移 {s}<-{t}"); return false; // 零副作用
    }
    void Goto(CjState n){_log.Add($"{State}->{n}");State=n;}
    public bool IsTerminal=>State is CjState.Completed or CjState.Cancelled or CjState.Aborted or CjState.Failed;
}
internal static class CjTrigExt{ public static bool Is(this CjTrigger t,CjCommand c)=>t.Kind==CjTriggerKind.Command&&t.Cmd==c;
    public static bool Is(this CjTrigger t,CjAggEvent e)=>t.Kind==CjTriggerKind.Aggregate&&t.Ev==e; }
```

### 聚合驱动回路
```csharp
public sealed class CjAggregationDriver
{
    private readonly CjStateMachine _fsm; private readonly CjStateAggregator _agg=new();
    public CjAggregationDriver(CjStateMachine fsm){_fsm=fsm;}
    // 子PJ状态变化时调用: 先算期望态, 再投递对应聚合事件由FSM裁决
    public void OnChildrenChanged(IReadOnlyList<JState> children,bool allAtOutput,bool barrier)
    {
        if(children.All(x=>x==JState.Completed))
            _fsm.TryAggregate(allAtOutput?CjAggEvent.AllChildrenDone:CjAggEvent.ChildStateChanged);
        else if(children.All(x=>x is JState.Paused or JState.Completed)&&children.Any(x=>x==JState.Paused))
            _fsm.TryAggregate(barrier?CjAggEvent.AllChildrenPaused:CjAggEvent.ChildStateChanged);
        else _fsm.TryAggregate(CjAggEvent.ChildStateChanged);
    }
}
```

### xUnit
```csharp
public class CjFsmTests
{
    [Fact] public void 正常启动到执行()
    { var f=new CjStateMachine();
      Assert.True(f.TryCommand(CjCommand.Start)); Assert.Equal(CjState.Started,f.State);
      Assert.True(f.TryAggregate(CjAggEvent.ChildStarted)); Assert.Equal(CjState.Executing,f.State); }
    [Fact] public void 全完成但片未到输出_不Completed()
    { var f=new CjStateMachine(); ToExecuting(f);
      f.CompleteGuard=()=>false;   // 片在Buffer, 守卫假
      Assert.False(f.TryAggregate(CjAggEvent.AllChildrenDone));
      Assert.Equal(CjState.Executing,f.State); }
    [Fact] public void 全完成且守卫过_Completed终态无出边()
    { var f=new CjStateMachine(); ToExecuting(f);
      Assert.True(f.TryAggregate(CjAggEvent.AllChildrenDone)); Assert.Equal(CjState.Completed,f.State);
      Assert.False(f.TryCommand(CjCommand.Start)); Assert.False(f.TryCommand(CjCommand.Resume)); }
    [Fact] public void 暂停栅栏_全活动Paused才Paused_中途完成不回执行()
    { var f=new CjStateMachine(); ToExecuting(f);
      f.PauseBarrier=()=>true;
      f.TryCommand(CjCommand.Pause); Assert.Equal(CjState.Pausing,f.State);
      f.TryAggregate(CjAggEvent.ChildStateChanged); Assert.Equal(CjState.Pausing,f.State); // 子完成不改方向
      Assert.True(f.TryAggregate(CjAggEvent.AllChildrenPaused)); Assert.Equal(CjState.Paused,f.State); }
    [Fact] public void 子故障_关键路径Failed_可隔离保持执行()
    { var a=new CjStateMachine(); ToExecuting(a); a.FaultStopsWhole=()=>true;
      Assert.True(a.TryAggregate(CjAggEvent.ChildFaulted)); Assert.Equal(CjState.Failed,a.State);
      var b=new CjStateMachine(); ToExecuting(b); b.FaultStopsWhole=()=>false;
      Assert.True(b.TryAggregate(CjAggEvent.ChildFaulted)); Assert.Equal(CjState.Executing,b.State);
      Assert.True(b.Degraded); }
    [Fact] public void Cancel需无片受影响()
    { var f=new CjStateMachine(); f.NothingTouched=()=>false;
      Assert.False(f.TryCommand(CjCommand.Cancel)); Assert.Equal(CjState.Queued,f.State); }
    static void ToExecuting(CjStateMachine f){f.TryCommand(CjCommand.Start);f.TryAggregate(CjAggEvent.ChildStarted);}
}
```

## 三、聚合驱动回路（手绘参考）
```
子PJ状态变 → 聚合器算期望态
   → 投递聚合事件(ChildStarted/AllChildrenPaused/AllChildrenDone/ChildFaulted)
   → CjStateMachine 查合法边+Guard裁决:
        过→迁移→发CJ事件; 不过→保持当前态零副作用
外部命令(Start/Pause/Resume/Cancel/Abort)走同一FSM
边: Queued→Started→Executing ⇄ Pausing→Paused ; 终态 Completed/Cancelled/Aborted/Failed
特殊: Pausing中子完成不回Executing(暂停方向不抖动); 故障按策略Failed或保持+Degraded
```

## 四、今日易错点
1. 让聚合器直接给 CJ State 赋值（必须投递事件经 FSM 合法边+Guard 裁决）。
2. 分不清外部命令与内部聚合事件两类触发。
3. PJ 全完成就迁 Completed（必须片到 CJ 输出、设备空、跨 PJ 守恒、CompleteGuard 过）。
4. Pausing 中因子完成抖动回 Executing（暂停方向确定，继续等 AllChildrenPaused）。
5. 子故障一律 Failed（可隔离策略保持 Executing+Degraded，关键路径才 Failed）。
6. 终态还允许迁移（四终态无出边）。
7. Guard 为假仍迁移（零副作用保持现状并记原因）。
8. 把命令级联到 PJ 的动作塞进 CJ-FSM（今天只管自身状态，级联 Day02）。
