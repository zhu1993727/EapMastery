# W21 · Day06 答案与参考实现

## 一、自测题标准答案
1. **Pause 时 A/B/C**：A 已 Completed——保持终态不动（成果不回退）；B 在 Executing——收到级联 Pause 进 Pausing，让在腔片到安全点后 Paused；C 还 Queued——加 SuspendPending 标记，即使稍后依赖满足也不启动。CJ 进入 Pausing，等 B（唯一活动 PJ）到 Paused、无运动中片，外层栅栏满足后 CJ 才 Paused，落含 A→B 交接位与全局集合的 CjResumeToken。
2. **B 不可恢复后 A/C/CJ**：A 已完成保持 Completed、其已产出片安全保持为有效在制品；C 是 B 的下游（需要 B 输出），输入缺失，按故障传播到安全点 Stop（不再启动、已取到的片保护）；B 自身三分类处置片后进 Failed/Aborted；没有与故障无关的并行分支。因 B 在唯一关键路径、不可替代，CJ 转 Failed（不是 Degraded 继续，也不是静默完成），冻结现场供续跑。
3. **两类片进入点差异**：已过 A、卡在 B 的片（A 确定完成、片在 B 输入/交接位）——续跑首个 PJ=B、源=该片实际位置、不重做 A；B 反应中途的片（B 这一步没走完、工艺存疑）——首个 PJ 也是 B，但要标记 ReworkCurrent，从 B 的起点**返工重做 B**（不能从 B 中断处假定已完成）。两者都跳过 A，区别在 B 是"正常接着做"还是"从头返工"。
4. **X 可恢复时 Y 继续 / D Hold**：Y 与 X 是并行分支、不依赖 X 的输出，故障影响闭包不含 Y，所以 Y 局部隔离继续（CJ 标 Degraded 但不 Failed）；D 需要 X、Y 两路汇合，缺 X 一路无法完成，但故障判定为可恢复且在等待超时内，所以 D 进入 Propagate Hold 挂起等待、而不是立即 Failed——给 X 恢复机会，超时未恢复才升级 Stop/Failed。这是"影响最小、不轻易整批失败"的策略。
5. **Y 先到、X 没好 / 不丢不提前**：Y 的片到达汇合点后由 JoinBarrier 登记"Y 路已到"，片安全保存在汇合等待位/Buffer（有确定位置、计入 E90 守恒，不会丢）；JoinBarrier 记录缺 X 路，CanJoin=false，D 不启动汇合（不提前消费）。等 X 的片也到、AllArrived 才允许 D 取两路片汇合。即汇合以"所有分支齐"为门，已到分支有位可等、账目可查。
6. **X 不可恢复为何不能先汇合一半**：D 的工艺定义要求 X、Y 两路配对（每片/每批需要两条分支结果），只用 Y 一路"汇合一半"产出的是缺工序的不合格品，且会让 X 路片与 Y 路片的配对账目错乱（谁和谁是一组对不上），破坏汇合的闭合与守恒。正确做法是 D 缺路 Stop、Y 片安全保持，CJ Failed 或授权 Partial（明确标注缺 X、Y 片为待处理半成品），绝不能制造"看似完成"的半工序产品。
7. **任意时刻三类不变式**：①物理位置三不变式（E90）——每片唯一位置、位置容量不超限、全局片 ID 集合守恒；②任务状态一致性——CJ 状态是子 PJ 状态的合法聚合（不自封、不违背聚合优先级），PJ 状态迁移合法、终态无出边；③片流/账目闭合——每片有完整输入到输出路径、交接幂等且状态明确（无既未交出也未接收的悬挂）、汇合分支齐才闭合、唯一片 ID 计数不翻倍。三类分别守住物理、任务、账目，任一被破坏即 fail-safe 停止转人工。

## 二、参考实现（net8.0，剧本骨架）

### 剧本 A：顺序链暂停恢复 + 故障续跑
```csharp
namespace EapLab.E94.Lab;
public class ScenarioA_Chain
{
    [Fact] public void Run()
    {
        // 1 建依赖图与CJ: A->B->C, 6片
        var graph=new PjDepGraph().Edge("A","B").Edge("B","C");
        var tracker=TrackerFactory.SixWafers("IN");
        var pjs=PjFactory.Chain("A","B","C");
        var cj=new CjStateMachine();
        var cascade=new CjCommandCascade(pjs);
        var co=new CjCascadeCoordinator(cj,cascade);

        // Start
        Assert.True(cj.TryCommand(CjCommand.Start));
        pjs["A"].Force(JState.Executing); cj.TryAggregate(CjAggEvent.ChildStarted);
        Assert.Equal(CjState.Executing,cj.State);

        // A完成,B启动后 Pause
        pjs["A"].Force(JState.Completed); pjs["B"].Force(JState.Executing);
        Assert.True(co.Pause()); Assert.Equal(CjState.Pausing,cj.State);
        pjs["B"].Force(JState.Paused);
        co.Reevaluate(new[]{JState.Completed,JState.Paused,JState.Queued});
        Assert.Equal(CjState.Paused,cj.State);
        Assert.Contains("C",cascade.SuspendPending);

        // Resume(交接位重核略, Day04已测)
        Assert.True(cj.TryCommand(CjCommand.Resume));
        pjs["B"].Force(JState.Executing);
        Assert.Equal(CjState.Executing,cj.State);

        // B不可恢复故障
        var fp=new FaultPropagation(graph);
        var dec=fp.Analyze("B",FaultMode.Irrecoverable,new(){"A","B","C"},_=>false,false);
        Assert.Contains(dec,x=>x.Pj=="A"&&x.Action==FaultAction.Hold);
        Assert.Contains(dec,x=>x.Pj=="C"&&x.Action==FaultAction.Stop);
        Assert.Equal(CjState.Failed,fp.CjTarget(dec,FaultMode.Irrecoverable,false));
        cj.TryAggregate(CjAggEvent.ChildFaulted); Assert.Equal(CjState.Failed,cj.State);

        // 中止快照 + 续跑
        var snap=new CjCascadeAbort().Abort("CJ1",pjs.Values,tracker,new HandoverTable());
        Assert.True(snap.Conserved(tracker));
        var orig=DefFactory.ChainRoute(new[]{"A","B","C"});
        var(plan,problems)=new ResumeCjBuilder().Build(snap,orig);
        Assert.Empty(problems);
        var resumeCj=new ResumeCjBuilder().NewCj("CJ1-R","CJ1",plan,orig); // 内部重过六不变量
        Assert.True(ResumeBalance.Check(new HashSet<string>(Enumerable.Range(1,6).Select(i=>$"W{i}")),
                                        FinishedToOut(snap),plan));
    }
    static HashSet<string> FinishedToOut(CjAbortSnapshot s)=>
        new(s.Wafers.Where(w=>w.Class==WaferAbortClass.Completed).Select(w=>w.Wafer));
}
```

### 剧本 B：并行分支隔离 + 汇合
```csharp
public class ScenarioB_ForkJoin
{
    [Fact] public void 可恢复_另一支继续_汇合等待后补齐()
    {
        var g=new PjDepGraph().Edge("S","X").Edge("S","Y").Edge("X","D").Edge("Y","D");
        var fp=new FaultPropagation(g,holdTimeout:30);
        var dec=fp.Analyze("X",FaultMode.Recoverable,new(){"S","X","Y","D"},_=>false,false,waited:10);
        Assert.Contains(dec,x=>x.Pj=="Y"&&x.Action==FaultAction.Continue);
        Assert.Contains(dec,x=>x.Pj=="D"&&x.Action==FaultAction.Hold);
        Assert.Equal(CjState.Executing,fp.CjTarget(dec,FaultMode.Recoverable,false));

        var join=new JoinBarrier(new[]{"X","Y"});
        join.Arrive("Y","Y1"); join.Arrive("Y","Y2"); join.Arrive("Y","Y3");
        Assert.False(join.CanJoin); Assert.Equal(new[]{"X"},join.Missing); // Y片等待不丢

        join.Arrive("X","X1");join.Arrive("X","X2");join.Arrive("X","X3");
        Assert.True(join.CanJoin);                                       // 齐了才汇合
    }
    [Fact] public void 不可恢复_缺路不汇合_CJ失败_Y片安全保持()
    {
        var g=new PjDepGraph().Edge("X","D").Edge("Y","D");
        var fp=new FaultPropagation(g);
        var dec=fp.Analyze("X",FaultMode.Irrecoverable,new(){"X","Y","D"},_=>false,false);
        Assert.Contains(dec,x=>x.Pj=="D"&&x.Action==FaultAction.Stop);
        Assert.Equal(CjState.Failed,fp.CjTarget(dec,FaultMode.Irrecoverable,false));
        var join=new JoinBarrier(new[]{"X","Y"}); join.Arrive("Y","Y1");
        Assert.False(join.CanJoin);   // 绝不"先汇合一半"
    }
}
```

## 四、两剧本状态轨迹（手绘参考）
```
A: Queued→Executing→Completed(保持)
B: Queued→Executing→Pausing→Paused→Executing→Failed
C: Queued(SuspendPending)→(Resume解挂)→(B故障)Stop
CJ:Queued→Started→Executing→Pausing→Paused→Executing→Failed →[续跑新CJ]→Completed
并行: X:Executing→(故障Hold)→恢复→Executing→Completed
      Y:Executing→Completed(片在JoinBarrier等)
      D: Hold(缺X) → X齐→Executing→Completed ; 若X不可恢复→Stop, CJ Failed
```

## 五、今日易错点
1. 级联 Pause 漏给 Queued 的 C 加 SuspendPending（Resume 前被拉起）。
2. 故障后把已完成的 A 也停掉/重做（成果保持）。
3. 关键路径故障只停 B、放任下游 C 空转等输入（应传播 Stop/Hold）。
4. 续跑把 B 中途片当 B 完成（要返工）。
5. 并行分支 X 故障误停无关的 Y（应局部继续）。
6. 汇合点一支先到就提前 D 汇合（必须分支齐，已到片安全等待）。
7. 不可恢复还"汇合一半"造半工序品（缺路 Stop/Partial，不假完成）。
8. 续跑不校验"原输入=成品∪续跑"守恒、不重新编译新 CJ。
9. 断言只看 CJ 终态，不查中间每时刻的 E90 三不变式与事件序列。
