# W21 · Day05 答案与参考实现

## 一、自测题标准答案
1. **级联 Abort 过程 / 为何不能 Resume**：Abort(CJ) 经级联器对所有活动 PJ 下发 Abort，每个 PJ 让在途片先到安全点、按三分类处置（已完成保持、在途退到源/Buffer/安全保持、未开始留源），释放各自资源；CJ 汇聚所有 PJ 的中止结果，冻结跨 PJ 现场，待全部活动 PJ 到终态、资源释放、相关载具锁定后，CJ 进 Aborted/Failed。Aborted 是终态、不能 Resume，因为中止时工艺链已被打断、片已被重新处置到各处、资源已释放、原执行上下文已销毁，"原地继续"不再成立；正确做法是基于冻结现场新建一个续跑 ControlJob，从当前现实重新派工。
2. **CjAbortSnapshot 跨 PJ 信息**：①每片：ID、分类（Completed/InFlight/NotStarted/Failed）、中止时所在 PJ 与 StepNo、E90 实际位置、工艺进度（哪几道 PJ/Step 已做、是否需返工）、所处交接状态；②跨 PJ 交接位：哪些片在 PJ 之间、交接到 Pending/HandedOver/Received 哪一步；③全局守恒：所有载具+设备内+交接位片集合=基线；④各 PJ 结果、资源释放与载具锁定状态；⑤原因码、命令/事件时间线。快照在处置前冻结，作为续跑与追溯的唯一依据，不被后续动作污染。
3. **续跑 CJ 三原则**：①已发生不回退——已到 CJ 输出的成品、已完成的 PJ/Step 不重做；②未发生按新现实重算——未完成片以**当前实际位置**为新源（源载具/中间载具/Buffer/交接位），而不是用旧定义里的原始源；③按片裁剪工艺路径——根据每片已完成的 PJ，决定它在续跑 CJ 中从下一个未完成 PJ 进入，重建 ControlJobMap 并重新通过六不变量与片流编译。本质：续跑 CJ 是一个全新对象（新 CjId、引用原 CJ Id），走正常校验派工，而不是复活旧终态。
4. **过 A 卡 B 的片 / 进入点与源**：该片 PJ_A 已合格完成，续跑时不重做 A；它在续跑 CJ 中的首个 PJ 就是 PJ_B（从 B 开始，跳过 A），源=该片中止时的**实际位置**——若已在 B 的输入交接位/Buffer 就以该位为源，若在 A 输出位就以 A 输出位为源（续跑时先完成 A→B 交接）。即"进入点=第一个未完成 PJ（B），源=E90 实际所在位"，绝不是从原始输入载具、从 A 头再来一遍。
5. **交接中（HandedOver 未 Received）片**：先看实际位置与交接状态做幂等处理：若片确实在交接位、身份一致，则续跑时由后继 PJ（B）幂等完成"接收"这一步（标记 Received），再从 B 继续，前驱不重发；若实际已退回前驱输出位，则把源设为前驱输出位、重做这一次交接；若位置/身份不明，安全保持转人工，不猜。关键是交接是带幂等键的状态转移，续跑只把它从实际所处阶段推进到完成，不重复搬运。
6. **为何不能假定 B 步已完成 / 如何标记**：反应中途被中止时，工艺步可能只进行了一部分（气体/等离子/时间未走完），无法保证达到 B 的工艺结果，假定完成会让一片实际没做完 B 的片带着"已完成 B"的错误账目进入后道，造成质量事故。应标记为"B 未完成/工艺存疑，需返工（rework）"，续跑时从 B 的起点重做该步（必要时回退到可返工状态）；只有明确走完 B 并通过验证的片才记 B 完成。宁可重做，不可把不确定当完成。
7. **集合等式 / 谱系用途**：不重不漏用集合等式证明——原 CJ 输入片集合 = 已完成成品集合（到输出、不再进续跑）+ 续跑 CJ 输入集合（所有未完成片，按实际位置），两侧 SetEquals 且无交集，即没有片被漏掉、也没有片既算成品又进续跑（重片）；续跑完成后，成品并集再等于原输入。工艺谱系（genealogy）记录每片经过的原 CJ/续跑 CJ、各 PJ/Step 完成情况与中止继承关系，用于良率追溯：当后道发现缺陷，能回溯这片在哪个 CJ、哪次中止、哪个腔体/配方做过，是 FDC/YMS 分析与质量追责的基础。

```csharp
namespace EapLab.E94.Recovery;
public enum WaferAbortClass{Completed,InFlight,NotStarted,Failed}
public sealed record WaferAbortRec(string Wafer,WaferAbortClass Class,string Pj,int StepNo,
    string ActualLocation,IReadOnlyList<string> DonePjs,bool BUncertain,HandoverState Ho);
public sealed class CjAbortSnapshot
{
    public string OrigCjId=""; public List<WaferAbortRec> Wafers=new();
    public HashSet<string> GlobalIds=new();
    public bool Conserved(SubstrateTracker t)=>new HashSet<string>(t.AllWaferIds()).SetEquals(GlobalIds);
}
```

### 级联中止汇聚
```csharp
public sealed class CjCascadeAbort
{
    public CjAbortSnapshot Abort(string origId,IEnumerable<ProcessJob> pjs,SubstrateTracker t,HandoverTable ht)
    {
        var snap=new CjAbortSnapshot{OrigCjId=origId,GlobalIds=new(t.AllWaferIds())};
        foreach(var pj in pjs)
        {
            pj.Try(JobCommand.Abort);                    // 各PJ三分类处置(W17)
            foreach(var w in pj.Wafers)
            { var cls=Classify(pj,w);
              var done=pj.DonePjsOf(w);
              var bUnc=cls==WaferAbortClass.InFlight && pj.IsMidStep(w); // 反应中途→B存疑
              snap.Wafers.Add(new WaferAbortRec(w,cls,pj.Id,pj.StepOf(w),
                  t.LocationOf(w).Key,done,bUnc,ht.StateOf(w))); }
        }
        return snap;
    }
    static WaferAbortClass Classify(ProcessJob pj,string w)=>pj.WaferClassAtAbort(w);
}
```

### 续跑 CJ 生成
```csharp
public sealed record ResumeWafer(string Wafer,string SourceLocation,string FirstPj,bool ReworkCurrent);
public sealed class ResumeCjBuilder
{
    // 返回续跑CJ每片: 新源=实际位置, 首个未完成PJ; 成品排除; 不明返回问题
    public (List<ResumeWafer> plan,List<string> problems) Build(CjAbortSnapshot snap,ControlJobDefinition orig)
    {
        var plan=new List<ResumeWafer>(); var prob=new List<string>();
        foreach(var w in snap.Wafers)
        {
            if(w.Class==WaferAbortClass.Completed) continue;          // 成品不进续跑
            if(w.ActualLocation is "UNKNOWN" or ""){prob.Add($"{w.Wafer}位置不明,人工");continue;}
            var route=orig.RouteOf(w.Wafer);                           // 原工艺路径(PJ序列)
            var first=route.FirstOrDefault(p=>!w.DonePjs.Contains(p)); // 第一个未完成PJ
            if(first is null){prob.Add($"{w.Wafer}无剩余PJ却未完成,矛盾");continue;}
            bool rework=w.BUncertain;                                  // B中途→该PJ返工
            plan.Add(new ResumeWafer(w.Wafer,w.ActualLocation,first,rework));
        }
        return (plan,prob);
    }
    public ControlJobDefinition NewCj(string newId,string origId,List<ResumeWafer> plan,ControlJobDefinition orig)
    {
        var cj=new ControlJobDefinition{CjId=newId,DerivedFrom=origId};
        foreach(var p in plan) cj.AddSource(p.Wafer,p.SourceLocation,p.FirstPj,p.ReworkCurrent);
        cj.Validate();   // 重新过六不变量+片流编译(W20), 不过则抛
        return cj;
    }
}
```

### 守恒校验
```csharp
public static class ResumeBalance
{
    public static bool Check(HashSet<string> origInput,HashSet<string> finished,List<ResumeWafer> resume)
    { var union=new HashSet<string>(finished); union.UnionWith(resume.Select(x=>x.Wafer));
        return union.SetEquals(origInput) && !finished.Intersect(resume.Select(x=>x.Wafer)).Any(); }
}
```

```csharp
public class ResumeCjTests
{
    [Fact] public void 过A卡B_续跑从B进_源为实际位_不重做A()
```

## 三、中止→续跑（手绘参考）
```
Abort(CJ) → 各活动PJ三分类处置 → 汇聚冻结CjAbortSnapshot(每片实际位置/已做PJ/交接态/全局守恒)
         → 资源释放/载具锁定 → CJ Aborted(终态,不可Resume)
续跑: 成品(到输出)排除; 未完成片新源=E90实际位置; 首个未完成PJ=原路径中第一个没做完的
      B中途→标记返工从B头; 交接中→幂等推进或退回; 位置/工艺不明→人工
      重建ControlJobMap→重新六不变量/片流编译→新CjId(引用原CJ)→正常派工
守恒: 原输入 == 成品 ∪ 续跑输入(不相交); 谱系记录每片CJ/PJ/Step/中止继承
```

## 四、今日易错点
1. 试图 Resume 一个 Aborted 的 CJ（终态不可续，只能新建续跑 CJ）。
2. 续跑用旧定义的原始源（必须用中止时 E90 实际位置）。
3. 重做已完成 PJ/片（已发生不回退，按 DonePjs 裁剪进入点）。
4. 假定反应中途的 B 步已完成（必须标返工，宁可重做）。
5. 交接中片不做幂等处理，续跑重复交接或漏交接。
6. 快照在处置后才取、被污染（处置前冻结）。
7. 续跑 CJ 不重新过六不变量/片流编译（新计划必须独立合法）。
8. 不做"原输入=成品∪续跑输入"守恒，漏片/重片；不记谱系无法良率追溯。
9. 位置/工艺不明的片硬塞进续跑（必须安全保持人工）。
