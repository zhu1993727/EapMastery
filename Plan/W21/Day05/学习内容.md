# W21 · Day05（周五）CJ 中止现场汇总与续跑 ControlJob 生成

> 建议时长：90 分钟。今天处理 CJ 级联 Abort/Failed 后的"善后与重建"：汇总跨多 PJ 的中止现场（每片分类、实际位置、跨 PJ 交接状态），并据此生成一个只含未完成片、源为当前实际位置的续跑 ControlJob。这是异常恢复闭环的最后一块。

## 一、今日目标
1. 实现 CJ 级联中止：向所有活动 PJ 下发 Abort、汇聚各自三分类结果。
2. 构建 CjAbortSnapshot：跨 PJ 汇总每片分类/实际位置/当前 PJ 与 Step/交接状态。
3. 掌握续跑 CJ 生成：排除已完成片，未完成片源改为当前实际位置，重建片流与依赖。
4. 处理跨 PJ 半成品：前道完成待后道的片如何在续跑 CJ 中从正确 PJ 进入。
5. xUnit 覆盖现场汇总分类、续跑 CJ 只含未完成、源为实际位置、守恒。

## 二、背景知识（先读，30 分钟）

### 1. CJ 级联中止过程
- Abort(CJ)：级联器对活动 PJ 下发 Abort（W21 Day02），每个 PJ 按 W17 三分类处置自己的片（完成不动、在途退/保持、未开始留源）。
- 汇聚：CJ 收集所有 PJ 的中止快照，形成 CJ 级现场；所有活动 PJ 到终态、资源释放、载具锁定后，CJ 进 Aborted/Failed。
- 与暂停区别：Aborted 是终态，不能 Resume；只能基于现场新建续跑 CJ（同单 PJ 的 W17 Day04，范围扩到多 PJ）。

### 2. CjAbortSnapshot 内容
- 每片：ID、分类（Completed/InFlight/NotStarted/Failed）、中止时所在 PJ、StepNo、**实际位置**（E90）、工艺状态（哪几道已做、是否需返工）、所处交接状态。
- 跨 PJ 交接位：哪些片在 PJ 之间、交接进行到哪步（W21 Day04）。
- 全局守恒：Σ载具+设备内+交接位=基线；各 PJ 结果汇总；资源与载具锁定状态；原因码/时间线。
- 快照在处置前冻结，不随后续动作污染。

### 3. 续跑 CJ 生成（核心）
- 原则（W17/W19 一致）：已发生不回退、未发生按新现实重算。
- 排除所有 Completed 片（已到 CJ 输出的成品不动）。
- 对每个未完成片，以其**当前实际位置**为新源（可能在源载具、中间载具、Buffer、交接位）。
- 根据该片已完成的 PJ/Step，决定它在续跑 CJ 中**从哪个 PJ 进入**（前道已做的 PJ 跳过，从下一个未做 PJ 开始）——即按片裁剪工艺路径。
- 重建 ControlJobMap：新源→剩余 PJ→最终输出；重新做六不变量与片流编译（W20）。
- 续跑 CJ 是新对象（新 CjId），引用原 CJ Id 以便追溯，经正常校验/派工流程启动。

### 4. 跨 PJ 半成品的进入点
- 片已过 PJ_A、卡在 PJ_B 中止：续跑时不重做 A，直接把 B 作为它的首个 PJ（源=B 的输入交接位/当前位）。
- 片在 A→B 交接中（HandedOver 未 Received）：续跑时先幂等完成交接（B 接收）再继续，或退回 A 输出位重来该交接，按实际位置定。
- 片工艺状态不明（B 反应中途被中止）：标记需返工，可能从 B 头重做（不假定 B 已完成）。

### 5. 与 Rollback/人工的选择
- 能确定位置与工艺进度→生成续跑 CJ；需要退回原始源→经 E90 Rollback；身份/工艺不明→安全保持人工。判据同前：不猜测身份与工艺完成度。

### 6. 守恒与追溯
- 续跑前后片集合守恒：原 CJ 输入集合=已完成成品集合 + 续跑 CJ 输入集合（不重不漏）。
- 续跑 CJ 记录来源原 CJ、每片继承的已完成 PJ/Step，形成完整工艺谱系（genealogy），供良率追溯。
