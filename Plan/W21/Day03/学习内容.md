# W21 · Day03（周三）故障级联策略：局部隔离、关键路径与依赖传播

> 建议时长：95 分钟。一个子 PJ 故障，整个 CJ 怎么办？今天建立故障在 PJ 依赖图上的传播规则：哪些能局部隔离继续生产、哪些必须级联停、上游供片和下游消费分别如何处置，做到故障影响范围最小且不失控。

## 一、今日目标

2. 掌握三种级联策略：局部隔离继续、关键路径级联停、依赖传播挂起/取消。
3. 区分上游（供片方）与下游（消费方）对故障的不同处置。

## 二、背景知识（先读，30 分钟）

### 1. 故障不是"全停"就是"最优"
- 先进 FAB 追求高可用：一个非关键 PJ/资源故障，若其他 PJ 不依赖它、可绕开或改派，应隔离故障、让健康部分继续，减少产能损失。
- 但如果故障在关键路径（其他 PJ 依赖其输出、或共用唯一资源/安全系统），就必须级联停止相关 PJ，否则它们会等不到输入或进入危险状态。
- 策略选择由依赖关系 + 工艺/Host 配置决定，不能拍脑袋。

### 2. 用依赖图算影响范围
- 节点=PJ，边=控制/片流依赖（A→B 表示 B 需要 A）。
- **下游影响（沿出边）**：故障 PJ 的直接/间接消费者会拿不到输入，需要挂起等待或取消。
- **上游影响（沿入边）**：给故障 PJ 供片的 PJ，其产出无处可去，需要停止供片（否则片堆积在交接位）。
- 与故障 PJ 无依赖连通关系的 PJ（独立并行分支）不受影响，可继续。

### 3. 三种级联策略
- **局部隔离（Isolate/Continue）**：故障 PJ 可被替代（同型资源改派、可重试），或它属于独立可降级分支；标记故障 PJ、隔离其资源，其余 PJ 继续，CJ 保持 Executing 并标记 Degraded，最终可能 Partial（需授权）。
- **关键路径级联停（Cascade Stop）**：故障 PJ 在关键路径、其输出被依赖且不可替代；级联让下游到安全点停、上游停止供片，CJ→Failed/Aborted。
- **依赖传播挂起（Propagate Hold）**：下游不立即失败，而是挂起等待故障恢复（若预计可恢复），设超时，超时转级联停；用于短暂可恢复故障。

### 4. 上游/下游处置细化
- 下游（消费故障 PJ 输出）：输入缺失→不能启动/继续，挂起；若已取到部分片，保护这些在制片。
- 上游（向故障 PJ 供片）：停止向故障路径供片，已产出的半成品停在交接位/Buffer 安全保持；若其输出还有别的去向（分叉），可改道。
- 已完成 PJ：保持终态不动（成果有效）。
- 故障 PJ 内：按 W17 三分类处置片（完成/在途/未开始）。

### 5. 菱形/汇合结构的特殊处理
- A→B、A→C、B+C→D（菱形）：若 B 故障，D 需要 B 和 C 两路输入，缺 B 则 D 无法完成；C 可继续加工但其产出要在汇合点等待 B（或等 B 恢复/改道），不能让 C 的片丢失。
- 汇合点要记录"已到分支/缺哪路"，等齐或按策略降级。

### 6. 策略判定输入
- 依赖图、故障 PJ、故障可恢复性/可替代性、Host 策略（是否允许 Partial、等待超时）、当前各 PJ 状态与片位置。输出=每个 PJ 的动作（Continue/Hold/Stop/Isolate）+ CJ 目标态。
