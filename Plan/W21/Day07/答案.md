# W21 · Day07 答案

## 一、排障推演参考
1. **CJ 卡 Pausing 不进 Paused**：按两层栅栏从外到内定位。①外层：列出所有活动 PJ，找还不是 Paused 的（Completed 不算活动、Queued 应已 SuspendPending）；②锁定某个仍 Executing/Pausing 的 PJ，进它的内层栅栏：列出它所有并发单元（各腔/臂/LoadLock 上的片），找没到安全点的那个——常见：某腔反应步不可中断还没到步边界、某片在臂上运动中未到安全位、某 LoadLock 正在 Pump/Vent 循环没走完；③再查是不是安全点判定条件没满足（位置确定/工艺可续/资源自洽/账目一致之一为假）；④最后查事件链：子 PJ 其实已 Paused 但状态变化事件没送到 CJ 聚合器（订阅/回调断），导致栅栏计数没更新。顺序：活动 PJ 清单→PJ 内并发单元→安全点四条件→事件上报链路。
2. **续跑后重片最可能错处**：重片=同一片被两个环节各处理/计数一次，按续跑流程倒查。①最常见：交接中片处理错误——片其实已被后继 Received，续跑却按"仍在前驱输出"又让后继取一次（没做交接位实际重核或交接非幂等）；②续跑源与成品划分错误：某片已到输出算成品却又被纳入续跑输入（没保证"原输入=成品∪续跑"且两者不相交）；③已做 PJ 裁剪错误：B 实际完成却没记进 DonePjs，续跑从 B 重做一遍；④快照不是处置前冻结、被后续动作污染，导致据错误现场生成计划。定位：对重片 ID 查它在快照里的分类/实际位置/交接态/DonePjs，再查续跑计划给它的源和首个 PJ，哪一层让它被重复纳入即根因。

## 二、综合自测卷（8 题）参考答案
1. **两类触发器/边/四 Guard**：外部命令 CjCommand（Start/Pause/Resume/Cancel/Abort，Host 经 S15）与内部聚合事件 CjAggEvent（ChildStarted/ChildStateChanged/AllChildrenPaused/AllChildrenDone/ChildFaulted，子 PJ 状态变化聚合产生）。主要边：Queued→Started→Executing、Executing→Pausing→Paused→Executing、Queued/Started→Cancelled、执行系→Aborted、Executing→Completed/Failed，四终态无出边。四 Guard：StartGuard（载具 Loaded/绑口/资源/无 Hold）、PauseBarrier（全部活动 PJ 到安全点）、CompleteGuard（所有 PJ 完成+片到 CJ 输出+设备空+跨 PJ 守恒+数据全）、NothingTouched（所有 PJ 未动工才可 Cancel）。期望态仍须经合法边+Guard 裁决，不直接赋值。
2. **五命令×五子状态 / 幂等挂起**：Start——Queued 且依赖就绪启动，余忽略；Pause——Completed 不动、Executing 下发去安全点、Pausing/Paused 幂等、Queued 加 SuspendPending；Resume——Paused 恢复、清 Queued 挂起标记、Completed 不动；Cancel——仅全部 Queued（未动工）可整体取消，有动工拒绝改 Abort；Abort——Completed 保持、活动者下发中止三分类、Queued 取消。幂等=重复下发对已在目标过程/态者无副作用；SuspendPending 保证暂停期未启动 PJ 依赖满足也不被拉起。
3. **三策略/判定/上下游**：局部隔离继续（可替代或独立无关分支、无共同安全风险，CJ 保持 Executing 标 Degraded）、关键路径级联停（不可替代且输出被依赖，下游到安全点停、上游停供，CJ Failed）、可恢复挂起（Recoverable 且超时内，下游 Hold 等待，恢复续、超时升级停）。在依赖图上沿出边求下游闭包（消费者）、沿入边求上游闭包（供片方）、无连通路径者为无关可继续。
4. **两层栅栏/恢复点/交接三态**：内层 PJ 栅栏（一个 PJ 内多腔/臂/锁全到安全点才该 PJ Paused）、外层 CJ 栅栏（所有活动 PJ Paused 才 CJ Paused）。CjResumeToken=各 PJ ResumeToken（进度/片位置/已完成集）+跨 PJ 交接位状态+全局 ID 集合快照+挂起 PJ 列表。交接三态 Pending→HandedOver（前驱已交出、片在交接位待取）→Received（后继已收）；Resume 按 E90 实际位置重核：仍在交接位由后继幂等取、已接收不重发、位置/身份不明转人工。
5. **级联 Abort/续跑三原则/守恒**：级联 Abort 对活动 PJ 下发中止、各自三分类、汇聚冻结 CjAbortSnapshot（每片分类/实际位置/PJ/Step/交接态/全局守恒），资源释放载具锁定后 CJ 终态。续跑三原则：已发生不回退（成品/已做 PJ 不重做）、未完成片源=中止时 E90 实际位置、按每片已做 PJ 裁剪首个未完成 PJ 并重新编译；B 反应中途标返工。守恒：原输入集合=成品集合∪续跑输入集合且不相交，续跑完成后并集=原输入。
6. **为何状态不自封/故障不一刀切**：CJ 没有自己的加工动作，它的真实状态就是子 PJ 状态的聚合，自封状态会与下层脱节（CJ 说完成、PJ 还在跑）；只有由子状态按固定优先级聚合、经 FSM 裁决，上层才永远是下层事实的真实投影。故障不一刀切：一律全停误伤无关健康分支损失产能，一律继续会让缺输入的下游空转、上游继续供片堆积或带险运行；按依赖闭包精确决定隔离/停/挂起，才能影响最小又不失控。两者本质都是"让决定来自真实下层与真实依赖，而不是上层主观断言"。
7. **菱形缺路正确/错误**：正确：健康分支继续加工，产出在汇合点 JoinBarrier 安全等待（有确定位置、计入守恒、登记已到分支与缺失分支），故障分支恢复/改道补齐后才汇合，不可恢复则 D 缺路 Stop、健康片转安全保持、CJ Failed 或授权 Partial。错误：让 D 只用健康分支"先汇合一半"产出缺工序品、或把健康分支片丢弃、或假装两分支齐了假完成——都会造成半工序不合格品与配对/守恒账目错乱。
8. **W22 全链路主干**：E84 AMHS 送盒握手 Deposit→E87 Installed→预约/Loaded（S15）→E90 注册基线 SourceMap→E94 下 CJ（S15 Create/Start）→级联起首批 E40 PJ→选腔多腔并发（位置唯一走 E90）→全程 S6F11/S16F1 事件、S5F1 报警、S2F41 远程命令、VID/CEID 采集→PJ 严格完成→E94 跨 PJ 交接→CJ 全完成、E90 ResultMap 终验→E87 UnloadGuard→Unloaded→E84 Pickup 取盒。每段标注对应标准与门控，W22 逐段打通。

## 三、W22 预热思考题参考
1. **空设备到第一片进腔的门控链**：E84 送盒四相握手成功、载具在位（Deposit）→E87 载具 Installed（物理在位去抖）→Host 预约匹配、下发 Load→Loaded（逻辑授权，唯一 Loaded 才能自动取片）→E90 读盒注册基线 SourceMap（知道每槽片 ID）→E94 Create/Start CJ（校验载具 Loaded、绑口 ID、六不变量）→级联起首个 E40 PJ（开工双校验、配方版本）→PJ 选腔、E90 原子 Move 取片进腔。缺步被挡：没 Deposit/Installed 无法 Load；没 Loaded 不能 Create/Start CJ（E87 门控）；没注册基线 E90 拒绝取片（无账）；CJ 没过校验不起 PJ；配方/资源/ Hold 不满足不起步。每一层都由对应标准的状态做前置门。
2. **四层唯一权威 / 跨层怎么问**：载具状态唯一权威是 E87（盒级）、片物理位置唯一权威是 E90（片级，改位置唯一入口）、PJ 任务状态权威是 E40-FSM、CJ 状态权威是 E94 聚合。跨层不复制对方状态，只通过公开方法查询或订阅事件：要知道盒能不能动问 E87、要知道片在哪问 E90、要知道任务到哪问对应 FSM；上层持有的下层信息只是只读投影/缓存，以被问方实时返回为准（W19 三单一事实源）。这样避免同一事实多处可写导致不一致。
3. **断线重连对账 / Spool 补什么**：HSMS 重连后先恢复通信控制态（S1F13/14 交换、S1F17 上线），再逐层对账：E87 核对载具在位/管理态（物理在位 vs 设备账 vs Host 镜像）、E90 用当前实际 SlotMap/位置重建片账（P-L-H 三对账）、E40 各 PJ 与 E94 CJ 从事件溯源/快照重建并与物理核对（W17/W19）。Spool 补的是断线期间"已发生但未被 Host 确认"的上报类消息——S6F11 事件、S5F1 报警、S16F1 对象事件，按序重发、对端按序号去重、ACK 后删除；它不补"需要双向握手的命令"，命令类要在状态对账后由权威状态决定是否重下，避免重复起作业。

## 五、W21 全周易错点总清单
1. 让聚合器直接给 CJ State 赋值（必须投聚合事件经 FSM+Guard）。
2. 混淆外部命令与内部聚合事件两类触发。
3. PJ 全完成就 Completed（必须片到 CJ 输出、设备空、跨 PJ 守恒）。
4. Pausing 中子完成导致回 Executing 抖动（暂停方向不撤销）。
5. 命令无脑广播、不幂等、重复下发副作用。
6. 有 PJ 动工还整体 Cancel（必须全 Queued，否则 Abort）。
7. 不给 Queued PJ 加 SuspendPending，暂停期被偷偷拉起；Resume 忘清标记。
8. 部分 PJ 拒绝还迁移 CJ（状态失真）。
9. 故障一刀切全停或一律继续（按依赖闭包分隔离/停/挂起）。
10. 不分上下游（上游停供、下游挂起/停）；菱形缺路丢健康片或半汇合。
11. 只做一层暂停栅栏（PJ 内 + 跨 PJ 两层）。
12. CJ 恢复点不记交接位、Resume 不重核实际、交接非幂等→重漏片。
13. 试图 Resume 终态 Aborted（只能新建续跑 CJ）。
14. 续跑用原始源/重做已完成 PJ/假定中途步完成（源=实际位、裁剪、返工）。
15. 续跑不重新编译、不做"原输入=成品∪续跑"守恒、不记谱系。
