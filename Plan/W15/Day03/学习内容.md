# W15 · Day03（周三）交叉调度：Buffer 暂存、双臂时序与槽位交换

> 建议时长：90 分钟。交叉取片真正难在"调度"：机械臂容量有限、目标槽可能被占、两槽交换需要暂存、双臂可并行但要防冲突。今天掌握设备内搬运调度的约束与算法，并用代码实现单臂/双臂的安全搬运序列。

## 一、今日目标
1. 理解设备内搬运的资源约束：机械臂/对准器/腔体/Buffer 都是有限容量位置。
2. 掌握 Buffer（暂存位）的作用：打破循环依赖、槽位交换、解耦取放节奏。
3. 掌握单臂交换算法（两槽互换需暂存）与双臂并行调度的时序与互锁。
4. 实现一个最小调度器：给定 CrossMap，产出安全的 Pick/Transfer/Place 动作序列。
5. xUnit 覆盖两槽交换、目标占用暂存、双臂不冲突、死锁规避。

## 二、背景知识（先读，30 分钟）

### 1. 资源约束视角
- 设备内每个位置都有容量：单臂 Robot 容量 1（一次持一片），双臂 R1/R2 各容量 1，Buffer 可多片，腔体容量通常 1。
- 一次搬运占用"臂"这一稀缺资源；取片后必须先放到某位置才能取下一片（除非双臂各持一片）。
- 调度本质：在容量约束和位置不变式下，为每片找到一条 源→（设备内路径）→目标 的无冲突动作序列。

### 2. Buffer 暂存位的作用
- **打破循环依赖（槽位交换）**：要交换 S1、S3 的片，单臂容量 1：
  ```
  W1:S1→Buffer; W3:S3→S1; W1:Buffer→S3   (Buffer 当"临时变量")
  ```
  没有 Buffer 就无法完成（臂持 W1 时无法把 W3 放进被占逻辑的 S1 腾挪）。
- **解耦取/放节奏**：源片已取出但目标槽暂不可用（被占/目标盒未就位），先放 Buffer 安全等待，不长期占用臂。
- **双臂交接**：大气臂与真空臂之间常借 LoadLock/Buffer 交接。
- Buffer 也是受不变式约束的位置：有容量、片在 Buffer 有明确归属、计入守恒和轨迹。

### 3. 单臂调度算法（最小可行）
- 维护：臂当前持有（空/某片）、Buffer 占用表、待完成 CrossEntry。
- 对每条 Entry：
  1. 若目标槽空且臂空：直接 源→臂→目标。
  2. 若目标槽被另一片 P 占据（且 P 也要移动）：先把 P 移到 Buffer 腾出目标，再搬当前片，再处理 P（递归/队列，注意终止，防环）。
  3. 若臂已持片：先把手上片放到其目标或 Buffer，再取新片。
- 环检测：移动依赖构成图（谁的目标被谁占），出现环必须用 Buffer 打破，否则死锁。

### 4. 双臂并行调度
- 双臂（R1 上、R2 下）可各持一片，形成"交换臂"高效动作：一只臂放片同时另一只取片（swap move），减少空跑。
- 互锁约束：两臂不能同时访问同一位置（同槽/同腔/同 Buffer 位）；物理干涉区（同一轴/同一 LoadLock）要串行。
- 时序：为动作标注占用的资源与时间段，资源冲突的动作必须串行，不冲突的可并行；用资源锁集合保证同一时刻一个资源只被一个动作占用。
- 教学用逻辑时钟：每个动作声明 lockResources，调度器检查资源空闲才推进，模拟并行而不用真线程（同 W11 模拟器思路）。

### 5. 死锁与饥饿规避
- 死锁条件：多个搬运互相持有对方需要的位置/资源且都不释放。用 Buffer 打破"位置占用环"，用统一资源申请顺序（如按 LocationId 排序加锁）打破"资源等待环"。
- 饥饿：某片一直被插队，用条目顺序/公平队列保证每片最终被调度。
- 任何调度产出的序列，逐步执行后必须满足 W14 三不变式（调度器输出要可被 LocationSpace 验证）。

### 6. 与 E40 的关系（印象）
- E40 ProcessJob 会规定片在设备内的加工路径与顺序，调度器是其"搬运执行层"；本周先做位置安全调度，工艺顺序在 W16+ 引入。
