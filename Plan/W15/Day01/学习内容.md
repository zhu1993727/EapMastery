# W15 · Day01（周一）交叉取片基础：源/目标载具、CrossMap 与工艺场景

> 建议时长：75 分钟。本周专攻交叉取片（Cross-Carrier/Cross-Slot Transfer）——片从一个载具取出、加工后放到另一个载具（或同盒不同槽）。这是 E90 最容易出错、也是 E40/E94 ProcessJob/ControlJob 的核心场景。今天先把概念、场景和映射模型吃透。

## 一、今日目标
1. 准确区分同槽加工、同盒换槽、跨盒交叉三类取放模式。
2. 掌握交叉取片在真实 FAB 的工艺场景（重布片、分档、合批/拆批、返工）。
3. 建立 CrossMap（逐片源→目标映射）模型，理解它与 JobPlan、SlotMap 的关系。
4. 说清交叉取片为何风险更高、错误如何同时影响两批 lot。
5. 闭卷手绘"源盒—设备—目标盒"交叉流向图。

## 二、背景知识（先读，30 分钟）

### 1. 三类取放模式
- **同槽加工 In-place**：源(盒A,槽s)取→加工→放回(盒A,槽s)，源=目标，SlotMap 不变（W14 已学）。
- **同盒换槽 Intra-carrier**：源(A,s1)取→加工/不加工→放回(A,s2)，同一载具内槽位变化，源槽空、目标槽占，盒内总数不变。
- **跨盒交叉 Cross-carrier**：源(A,s1)取→加工→放到(B,t1)，源载具减少、目标载具增加，全局守恒。
- 交叉是一般形式：令"源位置"和"目标位置"可独立指定，同槽/同盒都是其特例。

### 2. 真实 FAB 为什么需要交叉
- **重布片 Rearrange/Slot Map Remap**：把稀疏放置的片紧凑排列、或按标准槽位图重排，便于下游。
- **分档 Sorting/Binning**：按量测/工艺结果把片分到不同目标盒（合格/不合格/不同等级），目标盒由结果动态决定。
- **合批/拆批 Merge/Split**：多个小批合成一盒加工，或一批拆到多盒；批量管理需要。
- **返工 Rework**：问题片从原批取出进入返工盒/返工流。
- **载具更换/FOUP Swap**：前道载具与后道载具不同，片跨载具流转。
- 这些都要求设备精确知道"每片从哪来、到哪去"。

### 3. CrossMap 映射模型
- **CrossMap**：逐片的源→目标声明，是交叉取片的"路线表"。
  ```
  CrossEntry: SubstrateId | Src(Carrier,Slot) | Dst(Carrier,Slot) | 工艺路径/Recipe | 状态
  ```
- 与 W14 JobPlan 同源（JobPlan 是其雏形），本周强化为支持多载具、状态跟踪、可行性预检。
- 一张 CrossMap 必须满足**内部一致性**：
  - 源唯一：两片不能声明从同一源槽取（源槽只有一片）。
  - 目标唯一：两片不能放到同一目标槽（容量 1，防叠片）。
  - 全局守恒：所有 CrossEntry 的源片集合 = 目标片集合（同一批片，只是换位置），除非是明确的合/拆批（需额外批令）。
  - 源/目标槽在对应载具 1..25 范围内。

### 4. CrossMap 与 SlotMap、位置空间关系
- 源 SlotMap：决定"声明的源槽是否真有该片"（交叉前核对）。
- 目标 SlotMap：决定"目标槽是否为空、可放"（放置前核对）。
- 位置空间：执行交叉时片在 源槽→设备内→目标槽 间迁移，全程三不变式（W14）。
- CrossMap 是"计划"，SlotMap/LivePositions 是"现实"，执行中持续比对计划与现实。

### 5. 为什么交叉风险高（专家视角）
- 涉及两个载具、可能两个 lot，一片放错会同时污染源批和目标批，追溯范围翻倍。
- 源减目标增，单盒视角会"看起来丢片/多片"，必须跨盒全局守恒。
- 多片交叉时目标槽分配、暂存、双臂并行使顺序约束复杂，存在循环依赖（两槽交换需暂存，Day03 讲）。
- 目标盒可能在交叉途中被 Hold/满载/取走，需要安全中止与在途片处置。
- 先进 FAB 用逐片读码 + CrossMap 双重确认，放置前再核目标槽，杜绝"想当然"。

### 6. 与 E40/E94 的衔接（先建立印象）
- E40 ProcessJob 会显式声明 SourceJob（源载具/槽位映射）与 DestinationJob（目标载具/槽位映射），CrossMap 正是其数据内核，W16 起正式展开。
- E94 ControlJob 编排多个 ProcessJob，可跨多载具做复杂交叉，本周把最小交叉做扎实。
