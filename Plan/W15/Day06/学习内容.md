# W15 · Day06（周六）交叉取片综合大实验：分档、合/拆批与故障演练

> 建议时长：115 分钟。用昨天的编排器跑三个贴近真实 FAB 的综合场景（同槽+跨盒混合、按结果分档、合批），并注入 5 个故障验证全链路防护，产出实验报告。做完本周交叉取片就真正落地了。

## 一、今日目标
1. 场景一：混合交叉——一个源盒中部分同槽加工、部分跨盒到目标盒，逐片正确、守恒。
2. 场景二：分档 Sorting——按"量测结果"动态决定目标盒（合格盒/返工盒），CrossMap 动态生成。
3. 场景三：合批 Merge——两个源盒片合入一个目标盒（显式批令授权、全局片集合守恒）。
4. 故障注入 5 个：源 ID 不符、预检后目标被占、在途目标 Hold、双臂争腔、部分完成 Rollback。
5. 产出完整实验报告：CrossMap、动作序列、守恒快照、终验、故障证据。

## 二、场景设计（先读，30 分钟）

### 场景一 混合交叉（25min）
```
源盒 A: S1=W1,S2=W2,S3=W3,S4=W4; 目标盒 B 空
CrossMap:
 W1 A:S1→A:S1 同槽加工C1
 W2 A:S2→B:S1 跨盒
 W3 A:S3→A:S3 同槽加工C2
 W4 A:S4→B:S2 跨盒
预期: A 最终 S1=W1,S3=W3; B S1=W2,S2=W4; 总数4守恒; 设备内空
```
- 验证编排器对同槽/跨盒混合的统一处理、源盒"留片"与"转出片"逐槽正确。

### 场景二 分档 Sorting（25min）
- 先加工得到每片"量测结果"（用可注入的 `IMetrologySource` 模拟 Pass/Fail/Grade）。
- 按结果动态生成 CrossMap：Pass→Good 盒指定槽，Fail→Rework 盒指定槽。
- 关键点：目标在加工后才确定，动态分配目标槽时仍要满足目标唯一、目标空、目标盒 Loaded。
- 验证结果驱动的目标分配、不同目标盒、逐片 ID 正确。

### 场景三 合批 Merge（20min）
```
源 A: S1=W1,S2=W2; 源 C: S1=U1,S2=U2; 目标 G 空(合批盒)
批令授权 MergeSplitAuthorized=true
CrossMap: W1 A:S1→G:S1, W2 A:S2→G:S2, U1 C:S1→G:S3, U2 C:S2→G:S4
预期: G 收4片, A/C 清空, 全局片集合{W1,W2,U1,U2}守恒
```
- 验证合批的全局片集合守恒（非逐盒相等）、必须显式批令、多源单目标目标唯一。

### 故障注入（25min）
- F1 源 ID 不符：A:S1 实际是 WX，Preflight/AtPick 拦截，不下发。
- F2 预检后目标被占：Preflight 通过后、Place 前并行让 B:S1 被占，AtPlace 二次确认拦截→暂存/挂起。
- F3 在途目标 Hold：W2 已取、B 突然 Hold，片安全退回 A:S2/Buffer，Partial，恢复后续跑。
- F4 双臂争腔：R1/R2 同时要用 C1，资源表串行化，不并行、无碰撞。
- F5 部分完成 Rollback：完成一半中断，Rollback 全部回源、布局复原、守恒。

### 实验报告（10min）
- 每场景：初始/最终 SlotMap、CrossMap、动作序列、守恒快照序列、终验结论；故障：触发点、拦截层、处置、结果。
