# W29 · Day06（周六）综合演练：作业链控制 + 高频采集并行，故障注入互不影响

> 建议时长：110 分钟。今天做一次贴近现场的综合演练：GEM 走完整作业链（E87 上料→E94 CJ/PJ→加工状态迁移→S6F11 事件），同时 EDA 向 FDC/YMS 高频推 trace 与事件；再注入两类故障（EDA 慢/断客户端、GEM 报警 Hold），验证双通道互不影响、数据可按统一时间线重建。这是 W27–W29 的收官实战。

## 一、今日目标
1. 编排一个完整批次场景：载具 Installed/Loaded→建 CJ/PJ→加工中 EDA 高频采、Step 切换双通道同源事件→完成卸载。
2. 用统一单调时间线把 GEM S6F11 稀疏事件与 EDA 连续 trace 对齐（事件 marker 落在波形正确位置）。

5. 集成测试断言作业终态正确、EDA 数据完整度符合预期、故障隔离成立。

## 二、背景知识（先读，25 分钟）

### 1. 场景与你已有资产的对应
- 作业链复用 W22 全链路十阶段、W20 E94 CJ 聚合、W14 E90 位置；控制消息复用 GEM（S2F41 受理≠生效、S6F11 迁移后事件）。
- 数据面复用 W28 运行时/引擎、W29 Day01–05 的宿主/编码/扇出/双通道。
- 今天不引入新标准，重点是"并行 + 对齐 + 隔离"的系统能力。

### 2. 统一时间线对齐（专家能力）
- GEM 事件稀疏但权威地标记工艺节点（JobStart/StepChanged/JobComplete/Hold）；EDA trace 连续记录物理量。两者用同一单调时钟（+UTC），把事件作为 marker 投到 EDA 时间窗（W28 Day04），就能在波形上精确标出"哪段是 Step1、何时 Hold"，这是 FDC 归因和 VM 特征切片的基础（W30/W32 要用）。
- 对齐校验：每个 GEM 事件时刻，EDA 最近采样点时间差应在一个采样周期内。

### 3. 故障注入矩阵
- A 数据面故障：FDC 慢消费（通道 DropOldest 丢点/Gap）、FDC 断连（判死级联撤订阅）。断言：YMS 与 GEM 不受影响、作业终态 Completed、仅 FDC 数据有 Gap。
- B 控制面故障：加工中触发 Alarm（S5F1 通知）+ 决策 Hold（S2F41/设备自身），设备 FSM 迁移到 Hold、EDA 继续只读采到 Hold 现场。断言：Hold 由控制面执行、EDA 无写动作、Hold 时刻 EDA 快照可读。
- 交叉断言：数据面再乱，控制状态机结果确定；控制面 Hold，数据面不断（用于归因）。

### 4. 现场意义（长鑫/中芯/台积电类 FAB）
- FDC 就是在连续 trace 上结合作业事件做实时规则判定；设备端要保证"控制绝对可靠优先、数据尽量连续可对齐、两者故障域隔离"。今天把这句话变成可执行测试。
