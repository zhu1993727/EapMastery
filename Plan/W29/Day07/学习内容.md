## 三、本周知识地图（先默写再对照）
```
宿主(D1): 最小API四端点(metadata/sessions/plans/callback); DI内核单例;
  BackgroundService(PeriodicTimer+CT)采样/flush; 优雅启停(先建内核后监听,停监听→停采样→级联);
  错误码401/403/404/422/429/204; 端口EDA5100与HSMS5000分离

  ISO8601 UTC/InvariantCulture; IHttpClientFactory; 超时<flush; 抓包对比HSMS二进制

  gRPC server streaming持续推, HTTP2多路复用/HPACK, CT取消; 体积远小于XML; E164公共proto; II/III并存
并发(D4): 有界Channel扇出, TryWrite不await慢者; 周期DropOldest+Gap, 事件独立优先不丢;
  backlog涨→降频→切除; 断连判死级联, 重连从当前续传不补历史(历史归EDC); 全局水位; 压测P50/95/99丢点
双通道(D5): 唯一FSM+Bus, GEM可控视图/EDA只读视图(IReadOnlyDataBus编译期只读);
  同源事件出口同快照同戳; 控制唯一经GEM(R2R经RMS/EAP→GEM); 线程端口隔离控制优先; GEM不依赖EDA发送
综合(D6): 作业链稀疏事件marker对齐连续trace(误差≤1周期); FDC慢断不影响CJ Completed;
  Hold由控制面执行EDA只读采现场; 控制可靠优先数据尽量连续; 交叉断言故障域隔离
```
