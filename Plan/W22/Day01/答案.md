# W22 · Day01 答案与参考实现

## 一、自测题标准答案
1. **十阶段与标准**：0 通信上线（E5 HSMS/E30 GEM，S1F13/14、S1F17）；1 AMHS 送盒（E84 硬线四相握手 Deposit）；2 载具在位 Installed（E87）；3 Host 预约+授权 Loaded（E87/E39，S15/S16）；4 读盒注册片基线（E90 SourceMap/SlotMap）；5 下 ControlJob（E94/E39，S15 Create/Start）；6 CJ 级联起首批 PJ（E40，选腔）；7 多腔并发加工与跨 PJ 交接（E40/E90/W18，S6F11/S16、采集）；8 PJ 严格完成、CJ 聚合完成（E40/E94，ResultMap 终验）；9 下料门 Unload+取盒（E87 UnloadGuard/E84 Pickup）。
2. **没 Loaded 不能取片/下 CJ / 门控类型**：Installed 只是物理在位（盒子在口上），Loaded 才是 Host 完成预约核对、授权这批料可以在这台设备加工的"逻辑授权"，且全设备只有 Loaded 载具能自动取片（E87 防错料核心）。没 Loaded 就取片/下 CJ，可能加工错料/未派工料/未核对料。这属于"物理事实→逻辑授权→任务编排"中的逻辑授权门控：物理在位(E84/Installed)不等于被授权生产(Loaded)，任务层(E94)必须以逻辑授权为前置。
3. **E90 基线阶段与作用**：第 4 阶段（Loaded 后、下 CJ/取片前）。它读盒内每槽片 ID、建立 SourceMap 与 SlotMap 基线，回答"这批料每片是谁、初始在哪槽"，为后续所有搬运/加工提供唯一片账：取片时按基线核对、跨载具/跨 PJ 用全局 ID 集合守恒、终验用 SourceMap 对 ResultMap。没有基线，E90 无法判断 Missing/Double/Misplaced/WrongId，等于无账生产。
4. **三纵贯线 / 为何分开**：状态纵贯研究 E87 盒态、E90 片位、E40 PJ 态、E94 CJ 态如何互为前置、谁是唯一权威（解决"状态一致性与门控"）；消息纵贯研究一个现场动作触发哪些 SECS 消息、方向与同源关系（解决"设备与 Host 怎么交换信息、受理≠生效"）；异常纵贯研究掉线、Hold、片异常、作业故障如何跨层传播恢复（解决"非正常路径的鲁棒性"）。分开看是因为它们是同一主干的三个正交切面：状态是"内部事实"、消息是"对外通信"、异常是"偏离主线时的行为"，混在一起会理不清每层职责，也无法分别做验证。
5. **设备端承担 / 不直连 MES**：设备端执行 E84 硬线交接，维护 E87 载具、E90 片位置、E40 PJ、E94 CJ 等对象与状态机，保证物理安全与守恒，向 FAB EAP 上报事件/采集数据、接收并执行其命令（S15/S2F41）。它只与 FAB 端 EAP/Host 一对一通信，不直接对接 MES——MES 的派工/批次/工艺令通过 FAB EAP 翻译为设备能执行的 CJ/预约/RCMD；这样解耦使设备不依赖 MES 厂商差异、职责清晰、安全边界明确（高频数据另走 EDA Interface-A 到 FDC/YMS，也不是直连 MES）。
6. **为何禁跳阶段 / 事故举例**：每个阶段是下一阶段的前置事实或授权，跳阶段等于在前提不成立时动作，状态机会进入现实不支持的危险/错误态。例：跳过 Loaded 直接下 CJ 取片，可能取到刚被 AMHS 放错、未预约核对的错料盒，造成整批错料加工；或跳过 E90 基线直接加工，终验时无法核对片 ID，混片无法追溯；或片未全到输出就跳 Unload 取盒，把还在设备内/臂上的片连同盒子取走，发生撞机/碎片。阶段机用 Guard 保证前提成立才推进，从结构上杜绝。
7. **放盒到第一片进腔的门**：E84 四相握手 Deposit 成功（硬线安全交接、在位去抖）→E87 Installed（物理在位）→Host 预约核对一致并 Load（Installed→Loaded 逻辑授权、无 Hold）→E90 读盒注册 SourceMap 基线→E94 Create CJ 过六不变量、Start 过开工校验（绑口 ID/配方/资源/无 Hold）→级联起首个 PJ（配方版本复核、选腔）→E90 原子 Move 把第一片从槽位移出、经机械手/LoadLock 到腔（每步容量/唯一位置/守恒），到位才"进腔"。任一不过即被对应层挡下。

## 二、参考实现（net8.0）：全链路阶段机骨架

```csharp
namespace EapLab.Cell.Line;
public enum LineStage
{ Idle, Linked, Deposited, Installed, Loaded, BaselineRegistered,
  CjCreated, CjStarted, Processing, CjCompleted, Unloaded, PickedUp }

public sealed class FabLineContext
{   // 各模块公开状态(只读投影), 真实权威在各自模块
    public bool HsmsSelected; public bool OnlineRemote;
    public bool E84DepositOk; public bool CarrierInstalled; public bool CarrierLoaded;
    public bool BaselineRegistered; public bool CjCreated; public bool CjStarted;
    public bool AllPjsFinished; public bool AllWafersAtOutput; public bool UnloadGuardOk;
    public bool CarrierUnloaded; public bool E84PickupOk;
}

public sealed class FabLineOrchestrator
{
    public LineStage Stage{get;private set;}=LineStage.Idle;
    private readonly List<string> _trace=new(); public IReadOnlyList<string> Trace=>_trace;

    public bool Go(LineStage target,FabLineContext c)
    {
        if(!CanEnter(target,c)){_trace.Add($"拒绝进入 {target}: 前置不满足(当前{Stage})");return false;}
        _trace.Add($"{Stage}->{target}"); Stage=target; return true;
    }

    bool CanEnter(LineStage t,FabLineContext c)=>t switch
    {
      LineStage.Linked=>Stage==LineStage.Idle && c.HsmsSelected && c.OnlineRemote,
      LineStage.Deposited=>Stage==LineStage.Linked && c.E84DepositOk,
      LineStage.Installed=>Stage==LineStage.Deposited && c.CarrierInstalled,
      LineStage.Loaded=>Stage==LineStage.Installed && c.CarrierLoaded,
      LineStage.BaselineRegistered=>Stage==LineStage.Loaded && c.BaselineRegistered,
      LineStage.CjCreated=>Stage==LineStage.BaselineRegistered && c.CjCreated,
      LineStage.CjStarted=>Stage==LineStage.CjCreated && c.CjStarted,
      LineStage.Processing=>Stage==LineStage.CjStarted,
      LineStage.CjCompleted=>Stage==LineStage.Processing && c.AllPjsFinished && c.AllWafersAtOutput,
      LineStage.Unloaded=>Stage==LineStage.CjCompleted && c.UnloadGuardOk && c.CarrierUnloaded,
      LineStage.PickedUp=>Stage==LineStage.Unloaded && c.E84PickupOk,
      _=>false
    };
    public bool IsDone=>Stage==LineStage.PickedUp;
}
```

### xUnit
```csharp
public class FabLineTests
{
    [Fact] public void 正常主干_顺序推进到取盒()
    { var o=new FabLineOrchestrator(); var c=FullOk();
      foreach(var s in new[]{LineStage.Linked,LineStage.Deposited,LineStage.Installed,LineStage.Loaded,
        LineStage.BaselineRegistered,LineStage.CjCreated,LineStage.CjStarted,LineStage.Processing,
        LineStage.CjCompleted,LineStage.Unloaded,LineStage.PickedUp})
        Assert.True(o.Go(s,c));
      Assert.True(o.IsDone); }
    [Fact] public void 未Loaded不能建CJ()
    { var o=new FabLineOrchestrator(); var c=FullOk();
      o.Go(LineStage.Linked,c);o.Go(LineStage.Deposited,c);o.Go(LineStage.Installed,c); // 停在Installed
      Assert.False(o.Go(LineStage.CjCreated,c)); }
    [Fact] public void 片未全到输出不能完成()
    { var o=new FabLineOrchestrator(); var c=FullOk(); ToProcessing(o,c);
      c.AllWafersAtOutput=false;
      Assert.False(o.Go(LineStage.CjCompleted,c)); Assert.Equal(LineStage.Processing,o.Stage); }
    [Fact] public void 未过下料门不能Unload()
    { var o=new FabLineOrchestrator(); var c=FullOk(); ToProcessing(o,c);
      o.Go(LineStage.CjCompleted,c); c.UnloadGuardOk=false;
      Assert.False(o.Go(LineStage.Unloaded,c)); }
    static FabLineContext FullOk()=>new(){HsmsSelected=true,OnlineRemote=true,E84DepositOk=true,
      CarrierInstalled=true,CarrierLoaded=true,BaselineRegistered=true,CjCreated=true,CjStarted=true,
      AllPjsFinished=true,AllWafersAtOutput=true,UnloadGuardOk=true,CarrierUnloaded=true,E84PickupOk=true};
    static void ToProcessing(FabLineOrchestrator o,FabLineContext c)
    { foreach(var s in new[]{LineStage.Linked,LineStage.Deposited,LineStage.Installed,LineStage.Loaded,
        LineStage.BaselineRegistered,LineStage.CjCreated,LineStage.CjStarted,LineStage.Processing})o.Go(s,c); }
}
```

## 三、全链路主干（手绘参考）
```
[Idle] --HSMS SELECTED+ONLINE/REMOTE(S1F13/14,S1F17)--> [Linked]
 --E84 Deposit四相握手(硬线)--> [Deposited]
 --E87 Installed(物理在位)--> [Installed]
 --E87 预约/Load(S15) --> [Loaded=逻辑授权, 唯一可自动取片]
 --E90 SourceMap基线 --> [BaselineRegistered]
 --E94 Create CJ(六不变量,S15) --> [CjCreated]
 --Start(开工校验,级联首批PJ,E40) --> [CjStarted→Processing]
    多腔并发(E40/W18) + 位置唯一(E90) + 跨PJ交接(E94) + 事件S6F11/S16/采集
 --PJ全完成+片到输出+ResultMap终验 --> [CjCompleted]
 --E87 UnloadGuard --> [Unloaded] --E84 Pickup硬线 --> [PickedUp]
门控次序: 物理事实(E84/E90) → 逻辑授权(E87) → 任务编排(E40/E94)
```

## 四、今日易错点
1. 把 Installed 当 Loaded（物理在位≠逻辑授权，唯一 Loaded 能自动取片）。
2. 跳过 E90 基线直接加工（无账，终验无法核对、异常无法判）。
3. 阶段顺序记成"先下 CJ 再 Loaded"（必须先授权再派工）。
4. 以为设备端直连 MES（设备只对 FAB EAP，MES 经 EAP 翻译）。
5. 把状态/消息/异常三切面混讲（本周要正交分开、分别验证）。
6. 阶段机允许跳阶段（必须每阶段 Guard 前置、不可跳）。
7. 完成只看 PJ 完成、不看片到输出（CjCompleted 要 AllWafersAtOutput）。
8. 忽略通信上线阶段 0（HSMS 未 SELECTED/未 ONLINE REMOTE，一切自动流程不成立）。
