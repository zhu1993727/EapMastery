# W22 · Day03（周三）消息纵贯：一次现场动作的完整消息链与同源原则

> 建议时长：90 分钟。今天从"消息视角"贯通全链路：一个物理动作（送盒、授权、取片、加工、事件、完成、下料）分别触发哪些 SECS 消息、谁发谁收、同步应答与异步事件如何区分，并落实两条铁律——受理≠生效、S16F1 与 S6F11 同权威状态同源现取。

## 一、今日目标
1. 按全链路十阶段列出每阶段的消息清单（方向、流/功能、同步/异步、含义）。
2. 区分请求-应答（SxF0/SxF1 对）、命令受理（ACKC）、异步事件上报（S6F11/S16F1/S5F1）。
3. 实现 MessageTracer：给定一个现场动作，产出有序消息链并校验方向/配对。
4. 落实同源：状态迁移成功后，从同一权威状态现取数据生成 S16F1 与 S6F11，禁止两份不一致。
5. xUnit 覆盖消息配对、受理≠生效、同源一致、断线 Spool 顺序。

## 二、背景知识（先读，30 分钟）

### 1. 消息大类
- **握手/控制**：HSMS Select（控制消息 SType）、S1F13/14 建立通信、S1F17/18 请求在线/应答。
- **请求-应答（主-从）**：Host 发 SxFn、设备回 SxF(n+1)，如 S2F41/42 远程命令、S15F1/2 创建对象、S2F33/34 定义报告、S7F1/2 取配方。
- **主动上报（设备→Host，异步）**：S6F11 事件报告、S16F1 OSS 事件、S5F1 报警、S9 系列错误。
- **同步应答只代表"收到/受理"**：如 S2F42 ACKC10=0、S15F2 ACKC=0，都是受理，真正完成看后续异步事件。

### 2. 十阶段消息链（主干）
| 阶段 | 消息（方向 H=Host E=Equipment） |
|---|---|
| 0 上线 | HSMS Select；E→H S1F13(MDLN/SOFTREV)←H S1F14；E→H S1F17 请求在线←S1F18 |
| 1 送盒 | E84 硬线（非 SECS 消息，数字 I/O 四相握手） |
| 2 Installed | 状态迁移后 E→H S16F1（Carrier 对象 Installed 事件）/ 或 S6F11 CEID |
| 3 预约/Loaded | H→E S15F1 建预约/载具对象←S15F2；H→E S15F9 方法 Load←F10 受理；迁移后 E→H S16F1 Loaded |
| 4 基线 | E 读盒后 E→H S16F1/S6F11（载具内容/SourceMap 就绪） |
| 5 下 CJ | H→E S15F1 建 CJ←F2；H→E S15F9 Start←F10(受理) |
| 6 起 PJ | CJ 级联：E 内部建 PJ，迁移后 E→H S16F1（CJ Started、PJ Started） |
| 7 加工 | 采集 E→H S6F11（按 CEID 关联 VID/RPT）；报警 E→H S5F1；远程命令 H→E S2F41←S2F42 |
| 8 完成 | 迁移成功后 E→H S16F1（PJ Completed、CJ Completed）+ 对应 S6F11 |
| 9 下料 | H→E S15F9 Unload←F10；E→H S16F1 Unloaded；E84 Pickup 硬线 |

### 3. 受理≠生效（全链路一致）
- S2F42/S15F2/F10 的 ACKC=0：语法/前置通过、我接收了，**不代表动作已完成**。
- 生效以状态机迁移成功后的异步事件（S16F1/S6F11）为准。
- 若受理后校验失败/Guard 不过：不迁移、补发失败事件或错误码，绝不能让 Host 以为已生效。

### 4. 同源原则（重点）
- 一次状态迁移（如 PJ Executing→Completed）可能既要发 OSS 事件 S16F1，又要发 GEM 事件 S6F11。
- 两者必须在迁移成功后、从**同一个权威状态对象现取**同一批数据（状态、时间戳、关键属性），由统一出口组装，保证内容一致。
- 禁止：S16 用一套内存数据、S6F11 用另一套缓存/各自查询拼装，导致"OSS 说 Completed、GEM 说 Executing"。

### 5. 采集三层与事件的关系（回顾）
- VID→RPTID→CEID（S2F33 定义、S2F35 关联），S6F11 携带 CEID + 关联报告快照；S16F1 携带 OBJSPEC+CEID+对象属性快照。两者数据都来自同一时刻权威状态的快照。

### 6. 断线与 Spool（消息链的可靠性）
- 上报类（S6F11/S5F1/S16F1）在断线时入 Spool，按序重发、对端按序去重、ACK 后删；命令类不盲目重发，重连对账后由权威状态决定（W21 Day07）。
