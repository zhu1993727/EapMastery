# W22 · Day05 答案与参考实现

## 一、自测题标准答案
1. **完整调用链**：自顶向下编排——Host S15 Start CJ→CjStateMachine 迁移 Started/Executing→对依赖就绪（前驱完成）、片就位、资源可用的首批 PJ 级联 Create/Start（E40）→PJ 经 ModuleRegistry 选腔→逐片经 E90 原子 Move 源槽→臂→LoadLock→腔，Process 只改工艺状态，加工完 Move 腔→…→PJ 目标位→PJ 严格完成发 S16/S6F11→跨 PJ 交接（片到交接位、后继取片）→启动后继 PJ→直到全部 PJ 完成。自底向上聚合——片完成更新 PJ 进度→PJ 满足严格完成迁移 Completed→CjStateAggregator 收子 PJ 事件重算→所有 PJ 完成且片到 CJ 输出、设备空、守恒→CJ 迁移 Completed，同源上报。编排向下、事实与状态向上。
2. **编排不改位置 / 加工不改位置**：编排不改位置——CJ/PJ 是任务逻辑，只决定"哪片、经哪条路线、到哪个目标、做什么配方"，它不直接修改片的物理坐标，所有位置变化必须且只能调用 E90 的原子 Move（否则任务层和物理层各有一份位置、必然不一致）。加工不改位置——Process（工艺反应）进行时片仍停在腔内同一位置，它只把片的工艺状态从"待加工→加工中→已加工"推进，不产生位移；位移只发生在进出腔/臂/锁的 Move 动作。这样"位置"只有 E90 一个写入口、"工艺状态"归作业、"任务状态"归 FSM，三者正交不互相越权。
3. **源槽到腔的 E90 动作 / Process 改什么**：典型序列 Move(源槽→机械手)、Move(机械手→Aligner 对正再回臂，视布局)、Move(臂→LoadLock 大气侧)、锁抽真空后 Move(LoadLock 真空侧→腔)，每一步都是带 expectedFrom 的原子转移（加锁、快照、容量校验、改后断言、失败回滚）。进腔后 Process：把该片工艺状态置为加工中→计时/工艺→已加工（可记录工艺数据/overlay 结果），**不改变 Location**；加工完再 Move(腔→锁→臂→目标位)。即移动全是 Move、工艺只改工艺状态。
4. **选腔依据 / 并发重叠前提**：选腔五依据——能力匹配（该腔能做这道工序/配方）→最早可用（资源日历上空闲最早）→腔体亲和（同片/同批尽量同腔减少差异）→配方切换代价（减少换配方/换气）→健康降权（有报警/性能差的腔降权），选择确定可解释。并发（流水线）重叠的前提是**资源不相交**：两片/两步骤同一时刻不申请同一腔/臂/锁（容量为 1 的资源），重叠才安全；争用同一资源必须在资源日历上串行（区间互斥），并按全序申请防死锁。
5. **交接四校验 / 幂等**：四校验=清单一致（前驱输出集合与后继输入约定一致）、读码身份一致（交接位实际片 ID=预期）、交接位置稳定可用、全局 ID 集合守恒。幂等是因为交接可能因暂停恢复、重发、重试被多次触发，必须设计成 Pending→HandedOver→Received 的状态转移，重复请求只返回当前阶段、不重复取放；否则前驱重发、后继重复收会重片，或两边都等对方造成漏片。
6. **CJ 凭什么 Completed / 为何不最后 PJ 完成立刻完成**：最后一个 PJ 完成只是必要条件，CJ Completed 还要每片确实到达 CJ 声明的最终输出载具槽（不是停在中间 PJ/交接位/Buffer）、设备内（臂/锁/腔）全空、跨 PJ/跨载具全局片集合守恒、SourceMap 对 ResultMap 终验通过、无故障子作业未闭环、数据齐全，LayerGate.CanCompleteCj 全过才迁移。不能最后 PJ 一完成就完成，因为 PJ 完成只代表它那道工序结束，片可能还在交接/搬运途中、或某片在中间位置没出 CJ，账面完成而物理未归位会导致提前下料撞机/丢片。
7. **顺序链 vs 并行汇合的启动/汇合时机**：顺序链——前驱 PJ 完成且其输出片到达与后继约定的交接位、交接四校验过，才启动后继 PJ 取片（严格串行、片流依赖决定先后）。并行汇合——多个分支 PJ 可并行启动（资源不相交），但汇合点 PJ 必须等**所有**输入分支都到齐（JoinBarrier AllArrived）才启动汇合，某分支先到则其片在汇合等待位安全等待、计入守恒，缺任一分支不汇合。前者是"前完后启"的点到点触发，后者是"多路齐了才启"的栅栏触发。

## 二、参考实现（net8.0）：加工管线

```csharp
namespace EapLab.Cell.Process;
public sealed class ProcessPipeline
{
    private readonly CjStateMachine _cj; private readonly PjFactory _pjf;
    private readonly ChamberSelector _selector; private readonly SubstrateTransferService _move;
    private readonly HandoverTable _handover; private readonly LayerGate _gate;
    public ProcessPipeline(CjStateMachine cj,PjFactory pjf,ChamberSelector sel,
        SubstrateTransferService mv,HandoverTable ho,LayerGate gate)
    {_cj=cj;_pjf=pjf;_selector=sel;_move=mv;_handover=ho;_gate=gate;}

    // 启动当前可启动PJ(依赖就绪+片就位+资源)
    public void TryStartReadyPjs(ControlJobRuntime cj)
    { foreach(var pj in cj.ReadyProcessJobs())
      { var(ok,_)=_gate.CanStartPj(pj,cj); if(!ok)continue;
        pj.Try(JobCommand.Start); }
        if(_cj.State==CjState.Started)_cj.TryAggregate(CjAggEvent.ChildStarted);
    }

    // 执行一片: 只通过E90移动; Process不改位置
    public void ProcessOneWafer(ProcessJob pj,string wafer,List<ResId> pathToChamber,ResId chamber,List<ResId> pathToTarget,string target)
    { foreach(var step in pathToChamber) _move.Transfer(wafer,step.From,step.To); // 源→腔
      pj.BeginProcess(wafer,chamber);      // 工艺状态: 加工中(位置不变)
      pj.FinishProcess(wafer);             // 工艺状态: 已加工(位置不变)
      foreach(var step in pathToTarget) _move.Transfer(wafer,step.From,step.To);  // 腔→目标
      pj.MarkWaferDone(wafer,target);
    }

    // 跨PJ交接后启动后继
    public void HandoverAndStartNext(ProcessJob prev,ProcessJob next)
    { foreach(var w in prev.OutputWafers)
        if(!_handover.TryReceive(w,id=>prev.OutputLocOf(id),id=>id,out _)) throw new InvalidOperationException($"交接失败{w}");
      if(next.InputsReady(_move.Tracker)) next.Try(JobCommand.Start);
    }

    // 每步后尝试完成聚合
    public bool TryComplete(ControlJobRuntime cj)
    { foreach(var pj in cj.Pjs) if(pj.CanStrictlyComplete) pj.Try(JobEvent.WaferAllDone);
      var(ok,_)=_gate.CanCompleteCj(cj); if(ok)_cj.TryAggregate(CjAggEvent.AllChildrenDone);
      return _cj.State==CjState.Completed; }
}
```

### xUnit（顺序链 + 并行汇合）
```csharp
public class ProcessPipelineTests
{
    [Fact] public void 顺序链_A完交接_B启_最终CJ完成_片到输出()
    { var env=LabEnv.Build(); var pipe=env.Pipeline; var cj=env.ChainCj("A","B"); // A->B
        env.Cj.TryCommand(CjCommand.Start);
        pipe.TryStartReadyPjs(cj);
        var a=cj.Pj("A");
        foreach(var w in a.Wafers) pipe.ProcessOneWafer(a,w,env.ToChamber(),env.CH1,env.ToTarget(),env.MidLoc);
        Assert.True(pipe.TryComplete(cj)==false);           // A完但B没完, CJ不完成
        var b=cj.Pj("B"); pipe.HandoverAndStartNext(a,b);
        Assert.Equal(JState.Executing,b.State);
        foreach(var w in b.Wafers) pipe.ProcessOneWafer(b,w,env.ToChamber(),env.CH1,env.ToTarget(),env.OutLoc);
        Assert.True(pipe.TryComplete(cj));
        Assert.Equal(CjState.Completed,env.Cj.State);
        Assert.True(env.Tracker.AllAt(cj.OutputCarrierId,cj.ExpectedOutputSlots));
        Assert.True(env.Tracker.DeviceEmpty); }
    [Fact] public void 并行汇合_分支齐才Join_唯一片计数()
    { var env=LabEnv.Build(); var cj=env.ForkJoinCj("X","Y","D");
        env.Cj.TryCommand(CjCommand.Start); env.Pipeline.TryStartReadyPjs(cj);
        env.RunPj(cj.Pj("X")); env.RunPj(cj.Pj("Y"));
        Assert.False(cj.Pj("D").State==JState.Executing);    // 汇合点等(此处X/Y到JoinBarrier)
        env.ArriveJoin("X"); Assert.False(env.Join.CanJoin);
        env.ArriveJoin("Y"); Assert.True(env.Join.CanJoin);
        env.Pipeline.TryStartReadyPjs(cj); Assert.Equal(JState.Executing,cj.Pj("D").State);
        env.RunPj(cj.Pj("D"));
        Assert.True(env.Pipeline.TryComplete(cj));
        Assert.Equal(6,cj.OutputWafers.Distinct().Count()); } // 不翻倍
    [Fact] public void Process不改位置()
    { var env=LabEnv.Build(); var pj=env.SinglePj("A");
        env.Move.Transfer("W1","IN:S1","CH1"); var before=env.Tracker.LocationOf("W1").Key;
        pj.BeginProcess("W1",ResId.Ch("CH1"));pj.FinishProcess("W1");
        Assert.Equal(before,env.Tracker.LocationOf("W1").Key); }
}
```

## 三、加工链路（手绘参考）
```
Start CJ ─► 依赖就绪? ─是─► 起首批PJ ─► 选腔(能力/最早/亲和/切换/健康)
   │                                   └─► 每片: E90 Move 源→臂→锁→腔(原子/expectedFrom/回滚)
   │                                              Process只改工艺状态(位置不变)
   │                                              Move 腔→锁→臂→PJ目标
   │                                   └─► PJ严格完成(归位+终验) ─► S16/S6F11同源
   ├─ 顺序: 前驱完成+片在交接位+四校验 ─► 后继启动(交接幂等)
   ├─ 并行: 分支并行, JoinBarrier齐了才汇合(先到片安全等)
   └─ 全PJ完成 + 每片到CJ输出 + 设备空 + 守恒 ─► LayerGate过 ─► CJ Completed
三边界: 编排不改位置 / Process不改位置 / 状态只向上聚合; 位置唯一写入口=E90
```

## 四、今日易错点
1. CJ/PJ 直接改片位置（必须唯一经 E90 原子 Move）。
2. Process 里改 Location（工艺反应只改工艺状态，位移只在 Move）。
3. 最后一个 PJ 完成就宣布 CJ 完成（必须片到 CJ 输出、设备空、守恒、门控过）。
4. 选腔只看空闲不看能力/亲和/健康；并发重叠不检查资源是否相交。
5. 跨 PJ 交接不做四校验、不幂等（重片/漏片）。
6. 并行汇合一支先到就启动汇合点（必须分支齐，先到安全等待）。
7. 片计数按加工次数（顺序/汇合翻倍），应按唯一 ID、完成以出 CJ 为准。
8. 事件不同源、或在迁移成功前报完成。
9. 资源争用不进全局日历、不按全序申请（死锁风险，W18）。
