## 二、背景知识（先读，30 分钟）

### 1. 加工段调用链（自顶向下编排，自底向上聚合）
```
Host S15 Start CJ → CjStateMachine Started/Executing
  → 依赖就绪+片就位+资源可用 → 级联创建/启动首批 PJ(E40)
    → PJ 选腔(ModuleRegistry, W18) → 逐片:
        E90 原子Move 源槽→臂→锁→腔(唯一改位置入口)
        Process 只改工艺状态不改位置; 完成后 腔→...→PJ目标位
      → PJ 严格完成(片归位+终验) → S16/S6F11
  → 跨PJ交接(清单+读码+位置+守恒, W20) → 后继PJ启动
  → 所有PJ完成+片到CJ输出 → CjStateAggregator → CJ Completed
```

### 2. 三条边界（必须守住）
- **编排不改位置**：CJ/PJ 只决定"哪片去哪、做什么"，真正的位置变化只由 E90 SubstrateTransferService 的原子 Move 完成（expectedFrom、加锁、快照、改后断言、失败回滚）。
- **加工不改位置**：Process 只改片的工艺状态（加工中/完成），片仍在腔内；进出腔才是 Move。
- **状态向上聚合**：片完成→PJ 进度→PJ 完成→CJ 聚合，上层不自称完成。

### 3. 选腔与并发（W18 落地）
- 同型多腔按能力→最早可用→亲和→切换代价→健康选腔，进全局资源日历（区间互斥、防死锁、容量）。
- 多片流水线重叠的前提是资源不相交；双臂 Swap、LoadLock 乒乓按 W18 时序。
- 每个进/出资源动作与 E90 Move 一一对应，逻辑时钟可复现。

### 4. 跨 PJ 交接（W20/W21 落地）
- 前驱输出集合==后继输入约定；交接幂等（Pending→HandedOver→Received）；交接位实际位置+读码核对；全局 ID 集合守恒。
- 顺序链：前驱完成且片在交接位→后继启动取片；并行汇合：分支齐才 Join。

### 5. 完成聚合
- PJ 严格完成（W17）：全片走完、归 PJ 目标、终验、数据全。
- CJ 完成（W20/W21）：所有 PJ Completed + 每片到 CJ 最终输出槽 + 设备内空 + 跨 PJ 守恒，LayerGate.CanCompleteCj 通过才迁移，同源发 S16/S6F11。

### 6. 加工段与采集/控制的耦合点
- 关键工艺/状态点触发 CEID 采集（S6F11）、异常触发 S5F1；R2R overlay 在进腔前随 recipe 参数下发（不改主档，本周末尾标注接口位置即可）。
- 加工中 Hold/Pause/故障的完整异常在 Day06 集中注入，今天先跑通正常链。
