## 二、背景知识（先读，30 分钟）

### 1. 上料段三步衔接
- **E84 Deposit（物理交接）**：OHT 小车与 LoadPort 四相握手（VALID 门控、HO 翻转防丢拍、COMPT），完成后载具物理在位 ON。E84 是硬线，独立于 SECS。
- **E87 Installed（物理事实）**：在位信号经去抖确认稳定→载具 NotInstalled→Installed，读 CarrierID（条码/RFID），发对象事件。Installed 只表示"盒子确实在口上"。
- **预约与 Loaded（逻辑授权）**：Host 已下发预约（期望 CarrierID/批次/口），设备核对在位载具 ID 与预约一致、无 Hold，执行 Load→Loaded。Loaded 是唯一可自动取片状态。
- **E90 基线（建账）**：Loaded 后逐槽读片（读码/映射），生成 SourceMap（25 槽谁是谁）、SlotMap 位图、Substrate 台账，作为后续一切搬运/守恒的基准。

### 2. 两个关键映射点
- 物理→逻辑（W13 PhysicalToLogicalBridge）：E84 在位是电平事实，要去抖+稳定确认才提升为 E87 Installed，防瞬时抖动误判。
- 盒→片（E87→E90）：载具 Loaded 后才有资格读片建账；SourceMap 的 CarrierID 必须与 Loaded 的载具一致（绑口），防止错盒建错账。

### 3. 门控（接 Day02 LayerGate）
- Installed 前不接受 Load；预约不匹配拒 Load 并报警（防错料）；CarrierHold 阻断 Load。
- 基线未注册，后续 CJ/PJ 无法取片（Day02 已建）。

### 4. 上料段异常与处置
- E84 握手中断/VALID 抖动：fail-safe，不确认在位，退回等 AMHS 重交，归属不确定禁自动重试。
- 在位但读不到 CarrierID：Installed 挂起、人工/重读，不进入预约匹配。
- 预约不符（ID/批次/口错）：拒绝 Load、上 CarrierHold/报警，等 Host 处理（绝不将错就错加工）。
- 读槽异常：Missing（槽应有片却空）、Double（双片）、Misplaced（错位）、读码失败 Unknown——标 Abnormal、登记、按 Host 策略（Hold/继续），基线要如实反映而非忽略。
- 上料全程事件经 Day03 同源出口上报。

### 5. 多口情况
- 多个 LoadPort 各自独立走这条管线，互不阻塞（一个口异常不影响另一个口正常上料），但都进同一 E90 全局台账（片 ID 全局唯一、跨口守恒）。
