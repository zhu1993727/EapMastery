# W22 · Day04 答案与参考实现

## 一、自测题标准答案
1. **四步含义与先后**：①E84 Deposit——OHT 小车与 LoadPort 经并行硬线四相握手把盒子物理放下、在位信号 ON（纯物理交接，走数字 I/O 不走 SECS）；②E87 Installed——在位经去抖稳定确认、读到 CarrierID，载具 NotInstalled→Installed，表示"盒子确实在口上"的物理事实；③Loaded——Host 预约与在位载具核对一致、无 Hold，执行 Load，Installed→Loaded，是"授权这批料在此加工"的逻辑状态；④E90 基线——Loaded 后逐槽读片建 SourceMap/SlotMap/片台账。先后不可乱：物理交接→确认在位→逻辑授权→建立片账。
2. **为何去抖才 Installed**：E84 在位是硬件电平，小车放盒过程中会有接触抖动、瞬时通断、未放稳时的短暂信号，若一见 ON 就判 Installed，可能在盒子没放稳/握手没完成时误认在位，后续读 ID/Load 全错。要在 VALID 门控下要求在位信号持续稳定一段时间（去抖窗口）且四相握手 COMPT 正常，才把电平事实提升为 Installed 逻辑事实；抖动/握手中断则 fail-safe 不确认、等重交。
3. **Installed vs Loaded / 谁能取片**：Installed 是物理事实（盒子在口上、读到 ID），但不代表 Host 已安排它生产；Loaded 是逻辑授权（预约核对通过、Host 允许、无 Hold）。全设备只有 Loaded 载具允许自动取片——这是 E87 防错料的核心：口上物理放着盒子(Installed)但没被授权(未 Loaded)，设备不会动它。
4. **SourceMap 为何绑口一致**：SourceMap 记录"某载具每槽片 ID"，后续取片、跨载具转移、终验都要按 CarrierID+口找账。若建账时的载具和当前 Loaded 载具不一致（错盒、换盒、绑错口），就会给错误的盒子建立片账，导致取错料、终验对不上、良率谱系全错。因此读片建 SourceMap 前必须核对它属于当前该口 Loaded 的那个 CarrierID（绑口一致性），不一致拒绝建账并报警。
5. **预约不符怎么办 / 为何不先加工**：设备必须拒绝 Load、保持在 Installed（不进入 Loaded），置 CarrierHold/报警并把"期望 ID/批次/口 vs 实际 ID"上报 Host，等 Host 裁决（换盒/改预约/取走）。不能先加工，因为预约承载了"这盒料该走哪个工艺路线/批次/客户"的 MES 指令，预约不符意味着可能是错料、错工艺、错流向，一旦加工就造成整批工艺错误甚至报废且难以追溯，防错料(load verify)是 GEM300 不可逾越的安全门。
6. **读片异常基线如何处理**：基线必须如实反映物理现实，绝不忽略或"补全"：Missing（计划/映射应有片但槽空）记该槽异常并在台账标缺片；Double（一槽叠双片）标 Abnormal、禁止从该槽取片；Misplaced（片在非预期槽）按实际槽登记并标错位；读码失败标 Unknown 身份待确认。这些异常槽在 SlotMap 标 Abnormal、登记事件上报，按 Host 策略决定整盒 Hold 还是跳过异常槽继续；带着异常也必须如实入账，保证后续守恒能发现问题，而不是假装每槽正常。
7. **多口是否阻塞 / 全局台账**：各 LoadPort 的上料管线相互独立、并行不阻塞——一个口握手失败或预约不符只影响该口（该口 fail-safe/Hold），其他口可正常 Deposit→Installed→Loaded→建账。但所有口的片都进入同一个 E90 全局片台账：片 ID 全局唯一、跨口转移时全局集合守恒，口的独立是流程调度层面的独立，片账是全局统一的（这样跨载具交叉取片才守得住守恒）。

## 二、参考实现（net8.0）：上料管线

```csharp
namespace EapLab.Cell.LoadIn;
public enum LoadStage{Empty,SignalDebounce,Installed,Loaded,Baselined,Held}
public sealed class SlotRead{public int Slot;public string? WaferId;public SlotIssue Issue;}
public enum SlotIssue{Ok,Missing,Double,Misplaced,UnknownId}

public sealed class LoadInPipeline
{
    private readonly CarrierManager _carrier; private readonly SubstrateTracker _tracker;
    private readonly LayerGate _gate; private readonly UnifiedEventEmitter _emitter;
    public LoadStage Stage{get;private set;}=LoadStage.Empty;
    private bool _signalStable; private string? _readCarrierId;
    public LoadInPipeline(CarrierManager c,SubstrateTracker t,LayerGate g,UnifiedEventEmitter e)
    {_carrier=c;_tracker=t;_gate=g;_emitter=e;}

    // E84 Deposit 完成, 在位信号去抖稳定
    public (bool ok,string why) OnDeposit(bool signalStable)
    { if(Stage!=LoadStage.Empty)return(false,"非空口"); _signalStable=signalStable;
      if(!signalStable){return(false,"在位未稳定,不确认Installed");}
      Stage=LoadStage.SignalDebounce; return(true,""); }

    public (bool ok,string why) ConfirmInstalled(string carrierId)
    { if(Stage!=LoadStage.SignalDebounce)return(false,"阶段错");
      if(string.IsNullOrWhiteSpace(carrierId)){Stage=LoadStage.Held;return(false,"读不到CarrierID");}
      _readCarrierId=carrierId; _carrier.Install("LP1",carrierId); Stage=LoadStage.Installed;
      return(true,""); }

    public (bool ok,string why) Load(string expectedId)
    { if(Stage!=LoadStage.Installed)return(false,"未Installed");
      var(ok,why)=_gate.CanLoad("LP1",_readCarrierId!);
      if(!ok || _readCarrierId!=expectedId){Stage=LoadStage.Held;return(false,$"预约不符/门控:{why} 期望{expectedId} 实际{_readCarrierId}");}
      _carrier.Load("LP1",_readCarrierId!); Stage=LoadStage.Loaded; return(true,""); }

    public (bool ok,List<SlotIssue> issues) RegisterBaseline(List<SlotRead> slots)
    { if(Stage!=LoadStage.Loaded)return(false,new());
      var issues=new List<SlotIssue>();
      foreach(var s in slots)
      { if(s.Issue!=SlotIssue.Ok){issues.Add(s.Issue); _tracker.MarkAbnormal(_readCarrierId!,s.Slot,s.Issue);}
        else _tracker.Register(_readCarrierId!,s.Slot,s.WaferId!); }
      _tracker.FreezeBaseline(_readCarrierId!);
      Stage=issues.Any(i=>i is SlotIssue.Double)?LoadStage.Held:LoadStage.Baselined; // 双片等严重异常Hold
      return(Stage==LoadStage.Baselined,issues); }
}
```

### xUnit
```csharp
public class LoadInTests
{
    [Fact] public void 正常上料_到基线()
    { var(c,t,g,e)=Ctx(); var p=new LoadInPipeline(c,t,g,e);
      Assert.True(p.OnDeposit(true).ok);
      Assert.True(p.ConfirmInstalled("CASS-A").ok);
      Assert.True(p.Load("CASS-A").ok);
      var(ok,_)=p.RegisterBaseline(NormalSlots(25));
      Assert.True(ok); Assert.Equal(LoadStage.Baselined,p.Stage); }
    [Fact] public void 在位抖动_不Installed()
    { var(c,t,g,e)=Ctx(); var p=new LoadInPipeline(c,t,g,e);
      Assert.False(p.OnDeposit(false).ok); Assert.Equal(LoadStage.Empty,p.Stage); }
    [Fact] public void 预约不符_Held不Loaded()
    { var(c,t,g,e)=Ctx(); var p=new LoadInPipeline(c,t,g,e);
      p.OnDeposit(true);p.ConfirmInstalled("CASS-A");
      var r=p.Load("CASS-X"); Assert.False(r.ok); Assert.Equal(LoadStage.Held,p.Stage); }
    [Fact] public void 双片异常_基线后Hold()
    { var(c,t,g,e)=Ctx(); var p=new LoadInPipeline(c,t,g,e);
      p.OnDeposit(true);p.ConfirmInstalled("CASS-A");p.Load("CASS-A");
      var slots=NormalSlots(25); slots[4]=new SlotRead{Slot=5,Issue=SlotIssue.Double};

    { var(c,t,g,e)=Ctx(); var p=new LoadInPipeline(c,t,g,e);

      Assert.False(p.RegisterBaseline(NormalSlots(25)).ok); }
}
```

## 三、上料链路（手绘参考）
```
OHT → E84四相握手(VALID门控/HO翻转/COMPT) → 在位ON
   → 去抖稳定 → E87 Installed(读CarrierID, 物理事实)
   → 预约匹配(期望ID/批次/口)+无CarrierHold → Load → Loaded(逻辑授权,唯一可自动取片)
   → 逐槽读片 → SourceMap/SlotMap位图/Substrate台账(与Loaded载具绑口) → Baselined
异常: 抖动/握手中断→不确认重交; 读不到ID→挂起; 预约不符→拒Load+Hold+报;
      Missing/Double/Misplaced/Unknown→如实标Abnormal, 严重(Double)Hold
多口: 各口管线独立不阻塞; 片账进同一E90全局台账, ID全局唯一/跨口守恒
```

## 四、今日易错点
1. 在位信号一 ON 就 Installed（必须去抖稳定+握手 COMPT）。
2. 把 Installed 当 Loaded（物理在位≠授权，唯一 Loaded 能取片）。
3. 不做预约匹配就 Load（错料/错工艺，load verify 不可逾越）。
4. SourceMap 不核对绑口载具（错盒建错账）。
5. 读片异常被忽略或"自动补全"（必须如实标 Abnormal，Double 等严重异常 Hold）。
6. 上料异常就整台设备停（应只影响该口，其他口独立继续）。
7. 多口各建各的片账、不做全局 ID 唯一与守恒（必须统一 E90 台账）。
8. 上料事件不走同源出口、或在状态迁移前就报"Loaded"。
