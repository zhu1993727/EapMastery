# W22 · Day06 答案与参考实现

## 一、自测题标准答案
1. **UnloadGuard 五条件防什么**：①所有作业完成——防止还有 PJ/CJ 在跑就取盒造成运动中干涉/在制品丢失；②所有片回输出载具——防止片还在臂/腔/锁/Buffer 时取走盒子，片掉在设备内（LeftInside）；③机械手 Home——防止机械手仍伸在盒/腔里，取盒发生机械碰撞；④LoadPort 门关闭锁紧——防止开门状态取盒、碎片/污染/安全事故；⑤无相关 Hold——CarrierHold/EquipmentHold 未解除说明问题未闭环，不能下料。五条共同保证"盒被取走的一刻，设备内无片、无运动、无未决问题"。
2. **账面先于物理取盒 / 归属不确定**：下料是先在逻辑上完成 Unload（载具 Loaded→Unloaded、账面上解除该盒授权与占用、准备交接），再由 E84 硬线四相握手让 OHT 物理把盒取走、在位变 OFF；逻辑先准备好、物理交接才安全有序。若物理取盒中途信号异常、盒子处于"小车还夹着还是口上还留着"归属不确定状态，禁止自动重试取/放（重试可能重复抓取或撞盒），保持 fail-safe、报警转人工确认归属后再继续。
3. **断线瞬间加工 / 重连对账顺序**：断线不影响设备本地安全执行——正在腔里不可中断的工艺步继续走到安全点，本地状态机/位置照常推进（设备不依赖连接才能安全动作），同时该上报的事件入 Spool，涉及需要 Host 授权才能继续的动作则安全挂起。重连后顺序：①HSMS Select、S1F13/14 重建通信、S1F17 回到 ONLINE/REMOTE；②E87 载具三对账（物理在位 vs 设备账 vs Host 镜像）；③E90 用当前实际 SlotMap/位置重建片账（P-L 先收敛）；④E40/E94 从事件溯源/快照重建 PJ/CJ 状态并与物理核对（L-H 同步）；⑤权威状态确定后按序补发 Spool 上报。
4. **Spool 只补上报 / 命令怎么办**：S6F11/S5F1/S16F1 是"已发生事实的通知"，断线期间发生了就是发生了，重连后必须让 Host 知道，所以缓存按序补发、对端去重、ACK 后删。命令类（S2F41/S15F9 Start 等）是"要求做动作"，断线时设备可能已经执行只是应答丢失，盲目重发会重复创建/启动/加工；因此命令不进重发队列，重连先对账出权威当前状态，再判断目标状态是否已达成，未达成且安全才幂等重下一次（命令带幂等键，重复调用结果相同）。
5. **LotHold 时在腔片与排队片**：LotHold 阻断该批次"向前推进"，但不强行中断不可中断工艺。正在腔反应的片继续走到本步安全点后停止（不进下一步、不出片继续加工）；已完成的片保持成果；正在排队/未启动的 PJ/片不再启动（类似 SuspendPending 挂起）；整批停在安全一致状态并上报，等质量/工艺方授权解除 LotHold 后从安全点续跑，已完成不重做。EquipmentHold 范围更宽（整机）、CarrierHold 针对盒，处置方向相同：到安全点、停推进、保成果。
6. **Missing 为何封锁搬运 / 三对账定位**：Missing 意味着"账上该有片的位置实际没有"，全局守恒已被破坏，此时继续自动搬运可能把错误扩大（误取邻槽、叠片、把异常传播到下游），所以立即封锁与该载具/区域相关的自动取放、保持现场、报警。三对账定位：P（物理实测，重新扫描/读槽/读码）对 L（设备 E90 台账）先收敛，判断是物理丢片、错位还是读码错；再 L 对 H（Host 镜像/预约与历史事件），看是上料就缺、搬运中遗落还是上报不一致；收敛后区分真丢片（人工/安全流程）、错位（Misplaced 修正）、账错（修正台账），身份/位置存疑一律人工，不猜。
7. **三条红线**：①物理红线——E90 三不变式任何异常下都成立：每片唯一位置、位置容量不超限（槽/臂/腔容量 1）、全局片 ID 集合守恒，不允许异常处理本身制造重片/丢片；②状态红线——所有状态机只走合法迁移、终态无出边、Guard 不过不迁移，绝无"账面完成/暂停而物理在跑"的状态失真；③事实红线——完成必须以物理归位+守恒为准，恢复后输出集合等于基线，做不到就显式 Partial（需授权、带每片明细）或安全保持转人工，绝不静默假完成、假恢复。

## 二、参考实现（net8.0）：下料 + 异常注入

### 下料管线
```csharp
namespace EapLab.Cell.LoadOut;
public sealed class LoadOutPipeline
{
    private readonly CarrierManager _carrier; private readonly LayerGate _gate;
    private readonly E84Port _e84;
    public LoadOutPipeline(CarrierManager c,LayerGate g,E84Port e){_carrier=c;_gate=g;_e84=e;}
    public (bool ok,string why) Unload(string port,ControlJobRuntime cj)
    { var(ok,why)=_gate.CanUnload(port,cj); if(!ok)return(false,why);     // 五条件
        _carrier.Unload(port); return(true,""); }
    public (bool ok,string why) Pickup(string port)
    { if(_carrier.StateOf(port)!=CarrierState.Unloaded)return(false,"未Unloaded,不能Pickup");
        return _e84.Pickup(port); }   // 四相握手, 归属不确定返回false不重试
}
```

### 断线重连对账 + Spool
```csharp
namespace EapLab.Cell.Recovery;
public sealed class ReconnectRecovery
{
    public List<string> Steps{get;}=new();
    public void Recover(CarrierManager c,SubstrateTracker t,JobRebuilder jobs,SpoolQueue spool)
    { Steps.Add("HSMS Select/S1F13-14/S1F17 ONLINE");
      Steps.Add("E87 三对账(物理/设备账/Host镜像)"); c.Reconcile();
      Steps.Add("E90 实际SlotMap重建片账 P->L"); t.RebuildFromPhysical();
      Steps.Add("E40/E94 快照重建并与物理核对 L->H"); jobs.Rebuild();
      Steps.Add("权威确定后Spool按序补发上报"); spool.FlushInOrder(); }
}
public sealed class SpoolQueue
{
    private readonly Queue<SecsMessage> _q=new();
    public void Enqueue(SecsMessage m)=>_q.Enqueue(m);
    public List<SecsMessage> FlushInOrder(){var r=new List<SecsMessage>();while(_q.Count>0)r.Add(_q.Dequeue());return r;}
}
```

## 三、全链路异常矩阵（手绘参考）
```
通信断: 本地到安全点继续/需授权则挂起 + 上报入Spool → 重连: 通信→E87对账→E90重建→PJ/CJ重建→补Spool
Hold:   EQ(整机)/CARRIER(盒)/LOT(批); 在腔到安全点停, 排队不启动, 成果不回退, 授权解后续
片异常: Missing/Double/Misplaced → 封锁相关搬运+报警 → P-L-H三对账 → 真丢/错位/账错分流, 存疑人工
PJ故障: W21 隔离继续/关键路径停/可恢复Hold; CJ Abort三分类→快照→续跑CJ
下料:   UnloadGuard五条件任一不过拒Unload; 账面Unload先于E84物理Pickup; 归属不确定不重试
六步: 停危险→片安全位→定状态→冻快照→守恒→恢复; 兜底fail-safe人工
红线: E90三不变式 / 状态合法不失真 / 输出==基线(否则授权Partial带明细)
```

## 四、今日易错点
1. Unload 不查五条件（片在内/臂未 Home/门未关都会事故）。
2. 物理取盒先于账面 Unload、归属不确定还自动重试（fail-safe 人工）。
3. 断线就停掉本地一切（不可中断工艺应到安全点，本地不依赖连接）。
4. 重连不按层对账、直接用旧内存状态（先 E87→E90→PJ/CJ 重建权威）。
5. 命令类也进 Spool 重发（重复创建/启动，应对账后幂等决定）。
6. Hold 时硬切在腔工艺或回退已完成片（到安全点停、保成果）。
7. Missing 还继续搬运扩大错误（立即封锁、三对账、存疑人工）。
8. 异常处理破坏守恒/非法迁移/假完成（三条红线不可破，做不到显式 Partial/人工）。
