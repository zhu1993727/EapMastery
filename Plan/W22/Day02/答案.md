# W22 · Day02 答案与参考实现

## 一、自测题标准答案
1. **五层状态/粒度/权威**：E30 设备控制态（整机，ONLINE/OFF-LINE、LOCAL/REMOTE，权威=GEM 控制态模块）；E87 载具态（盒，NotInstalled/Installed/Loaded/Unloaded 及 Hold，权威=CarrierManager）；E90 片位置（片，每片 Location+SlotMap Empty/Occupied/Abnormal，权威=SubstrateTracker，改位置唯一入口）；E40 PJ 态（作业，Queued/Started/Executing/Pausing/Paused/Completed/Cancelled/Aborted/Failed，权威=JobStateMachine）；E94 CJ 态（批次，九态由子 PJ 聚合，权威=CjStateMachine）。每层状态只由本层模块写。
2. **为何不能复制对方状态为可写字段**：一旦把别的层状态复制成自己的可写副本，同一事实就有两个可写来源，对方状态变化时副本未必同步，必然漂移，导致基于过期副本做决策（如自己记着载具 Loaded、实际已被 Unload 还继续取片）。正确做法是跨层只调对方公开方法实时查询、或订阅事件维护**只读**投影（明确标注是缓存、以权威方为准）。单一事实源保证"一个事实只有一个可写权威"，从根上消除多份状态不一致。
3. **E94 Start CJ 的跨层前提**：E30 层=ONLINE 且 REMOTE（自动+可受 Host 控制）、无 EquipmentHold；E87 层=该 CJ 涉及的输入/输出载具都 Loaded、LoadPort 绑定的载具 ID 与计划一致、无 CarrierHold；E90 层=输入载具已注册 SourceMap 基线、片 ID 与计划匹配、无片异常；批次层=无 LotHold；自身=CJ 定义过六不变量、配方/资源可用。任一不满足 Start 拒绝、停留 Queued、零副作用。
4. **CJ Completed 跨层前置 / 为何 E90 参与**：E40 层所有子 PJ 都 Completed；E90 层每片实际位于 CJ 声明的最终输出槽、设备内（臂/锁/腔/Buffer）全空、SourceMap 与 ResultMap 全局集合守恒、无 Missing/Double/Misplaced/WrongId/LeftInside；E87 层输出载具仍 Loaded 在口；自身聚合条件与数据完整。必须 E90 参与是因为"完成"最终是物理事实——PJ 账面上做完不等于片真的到了输出位，只有 E90 是片位置的唯一权威，由它确认片全部归位、设备清空，才能保证不是账面完成、没有片滞留。
5. **三类 Hold 阻断 / 能否自解**：EquipmentHold 整机级，阻断所有自动作业的启动与推进（最宽）；CarrierHold 只阻断与该载具有关的取/放片；LotHold 阻断该批次（对应 CJ/PJ）的加工。Hold 只阻止"向前"的迁移，不回退已完成状态。设备端不能自行解除任何 Hold（防错/防违规），必须由设置方（Host/MES/工艺/质量）授权解除，设备只如实上报 Hold 状态与原因。
6. **自底向上供事实、自顶向下受约束**：下层（E84 硬线、E90 位置）产生不可违背的物理事实，中层 E87 据此给逻辑授权，上层 E40/E94 在这些事实/授权成立的前提下编排任务——即底层为上层提供前置条件（底→上传事实）。反过来，上层的任务指令不能命令底层破坏其不变式（顶→下受约束）：CJ 再怎么编排也不能让 E90 把两片放同一槽、不能让 E87 在未 Installed 时 Loaded。门控就是把这种"上层动作必须先查下层事实且不违背底层约束"的关系集中判定。
7. **UnloadGuard 机械手 Home/门关闭 / 属哪层**：Unload 是让 AMHS 把整盒取走，若机械手还伸在载具/腔室里、LoadPort 门还开着，取盒会发生机械干涉、碎片或安全事故，所以要求所有作业结束、所有片回输出盒、机械手回到 Home 安全位、LoadPort 门关闭锁紧、无运动、无 Hold 才允许 Unload。机械手位置/门状态属于设备物理执行层事实（与 E90 位置、设备机构状态同源的物理层），UnloadGuard 汇总 E94（作业完成）、E90（片归位、设备空）、物理机构（Home/门关）多层前提，是典型跨层门控。

## 二、参考实现（net8.0）：只读跨层门控

```csharp
namespace EapLab.Cell.Gate;
public enum EquipCtrl{ OffLine, OnlineLocal, OnlineRemote }
public sealed class LayerGate
{
    private readonly Func<EquipCtrl> _ctrl;
    private readonly CarrierManager _carrier; private readonly SubstrateTracker _tracker;
    private readonly HashSet<string> _eqHold=new(),_carrierHold=new(),_lotHold=new();
    public LayerGate(Func<EquipCtrl> ctrl,CarrierManager carrier,SubstrateTracker tracker)
    {_ctrl=ctrl;_carrier=carrier;_tracker=tracker;}
    public void SetHold(string kind,string key){Set(kind,key,true);}
    public void ClearHold(string kind,string key){Set(kind,key,false);}
    void Set(string k,string key,bool on)
    { var s=k switch{"EQ"=>_eqHold,"CARRIER"=>_carrierHold,"LOT"=>_lotHold,_=>throw new ArgumentException(k)};
      if(on)s.Add(key);else s.Remove(key); }

    // 总前提: 在线+远程+无整机Hold
    public bool AutoEnabled()=>_ctrl()==EquipCtrl.OnlineRemote && _eqHold.Count==0;

    public (bool ok,string why) CanLoad(string port,string carrierId)
    { if(_carrier.StateOf(port)!=CarrierState.Installed)return(false,"未Installed");
      if(_carrierHold.Contains(carrierId))return(false,"CarrierHold");
      if(!_carrier.ReservationMatches(port,carrierId))return(false,"预约不匹配");
      return(true,""); }

    public (bool ok,string why) CanStartCj(ControlJobDefinition cj)
    { if(!AutoEnabled())return(false,"非ONLINE/REMOTE或EquipmentHold");
      if(_lotHold.Contains(cj.LotId))return(false,"LotHold");
      foreach(var cr in cj.Carriers)
      { if(_carrier.StateOf(cr.Port)!=CarrierState.Loaded)return(false,$"{cr.Port}未Loaded");
        if(_carrier.CarrierIdAt(cr.Port)!=cr.ExpectedId)return(false,$"{cr.Port}绑口ID不符");
        if(_carrierHold.Contains(cr.ExpectedId))return(false,$"{cr.ExpectedId} CarrierHold"); }
      if(!_tracker.BaselineRegistered(cj.InputCarrierId))return(false,"E90基线未注册");
      return(true,""); }

    public (bool ok,string why) CanStartPj(ProcessJob pj,ControlJobRuntime cj)
    { if(cj.State is not (CjState.Started or CjState.Executing))return(false,"CJ未启动");
      if(!AutoEnabled()||_lotHold.Contains(cj.LotId))return(false,"控制态/Hold阻断");
      if(!pj.InputsReady(_tracker))return(false,"输入片未就位");
      if(!pj.ResourceAvailable())return(false,"资源不可用");
      if(!pj.RecipeVerified())return(false,"配方未校验");
      return(true,""); }

    public (bool ok,string why) CanCompleteCj(ControlJobRuntime cj)
    { if(!cj.AllChildrenCompleted)return(false,"存在未完成PJ");
      if(!_tracker.AllAt(cj.OutputCarrierId,cj.ExpectedOutputSlots))return(false,"片未全到输出");
      if(!_tracker.DeviceEmpty)return(false,"设备内非空(LeftInside)");
      if(!_tracker.GlobalConserved)return(false,"全局片集合不守恒");
      return(true,""); }

    public (bool ok,string why) CanUnload(string port,ControlJobRuntime cj)
    { var(c,_)=CanCompleteCj(cj); if(!c)return(false,"CJ未达完成条件");
      if(!RobotHome)return(false,"机械手未Home"); if(!DoorClosed)return(false,"门未关闭");
      if(_carrierHold.Contains(_carrier.CarrierIdAt(port)))return(false,"CarrierHold");
      return(true,""); }

    public bool RobotHome{get;set;}=true; public bool DoorClosed{get;set;}=true;
}
```

```csharp
public class LayerGateTests
{
    [Fact] public void 未Loaded不能起CJ()
    { var(carrier,tracker)=Ctx(); var g=Gate(carrier,tracker);
      carrier.ForceState("LP1",CarrierState.Installed);
      var r=g.CanStartCj(CjWith("LP1")); Assert.False(r.ok); Assert.Contains("Loaded",r.why); }
    [Fact] public void 全部满足才能起CJ()
    { var(carrier,tracker)=Ctx(); var g=Gate(carrier,tracker);
      carrier.ForceState("LP1",CarrierState.Loaded); carrier.SetIdAt("LP1","CASS-A");
      tracker.RegisterBaseline("CASS-A");
      Assert.True(g.CanStartCj(CjWith("LP1","CASS-A")).ok); }
    [Fact] public void EquipmentHold阻断自动()
    { var(c,t)=Ctx(); var g=Gate(c,t); g.SetHold("EQ","EQ1");
      Assert.False(g.AutoEnabled()); }
    [Fact] public void 片未到输出_CJ不能完成()
    { var(c,t)=Ctx(); var g=Gate(c,t); var cj=RuntimeAllPjDone();
      t.SetAllAtOutput(false);
      Assert.False(g.CanCompleteCj(cj).ok); }
    [Fact] public void 机械手未Home_不能Unload()
    { var(c,t)=Ctx(); var g=Gate(c,t){RobotHome=false}; var cj=RuntimeReady();
```

## 三、状态门控矩阵（手绘参考）
```
目标迁移 \ 需要的层:
 Load载具(E87)      : Installed + 预约匹配 + 无CarrierHold
 Start CJ(E94)      : E30 ONLINE/REMOTE + 载具Loaded绑口 + E90基线 + 无EQ/Lot Hold + 六不变量
 Start PJ(E40)      : CJ Started + E90输入片就位 + 资源 + 配方 + 无Hold
 自动取片(E90)      : 载具Loaded + PJ授权 + 目标容量允许
 PJ Completed       : 本片走完 + E90归到PJ目标 + 自身终验
 CJ Completed       : 全PJ Completed + E90每片到CJ输出+设备空+守恒
 Unload(E87)        : CJ完成 + E90片回盒 + 机械手Home + 门关 + 无Hold
方向: 底层供事实(E84/E90)→E87授权→E40/E94编排; 上层不得令底层违背不变式
权威: 每层只写自己状态; 跨层只读查询/订阅只读投影(LayerGate只判不写)
```

## 四、今日易错点
1. 跨层复制对方状态为可写副本（必然漂移，只读查询/只读投影）。
2. 把 E30 LOCAL/OFF-LINE 也当成能自动加工（自动流程要 ONLINE+REMOTE）。
3. 起 CJ 只看 CJ 自己，不查载具 Loaded/绑口/E90 基线/Hold。
4. CJ 完成只看子 PJ 完成（必须 E90 确认到输出、设备空、守恒）。
5. 混淆三类 Hold 的阻断范围；以为设备能自解 Hold（必须授权方解除）。
6. 门控条件散落在各处业务代码（集中到 LayerGate 才好评审/测试）。
7. Unload 不查机械手 Home/门关（物理干涉风险）。
8. LayerGate 里直接改其他层状态（它是只读协调者，只判定不写入）。
