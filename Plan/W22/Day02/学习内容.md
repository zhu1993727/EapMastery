# W22 · Day02（周二）状态纵贯：四层状态门控矩阵与单一事实源

> 建议时长：90 分钟。全链路中同时存在四层状态：E87 载具态、E90 片位置、E40 PJ 态、E94 CJ 态（外加 E30 设备控制态）。今天把它们之间"谁是谁的前置、谁能挡住谁、谁是唯一权威"做成一张门控矩阵，并实现跨层只读查询而不复制状态。

## 一、今日目标
1. 梳理五层状态（E30 控制态/E87 载具/E90 片位/E40 PJ/E94 CJ）的取值与权威归属。
2. 建立状态门控矩阵：某层要迁移到某态，需要其他层处于什么态。
3. 实现跨层门控检查器 LayerGate，集中表达前置条件，禁止跨层写状态。
4. 掌握"只读投影 + 公开方法查询/订阅事件"的单一事实源模式。
5. xUnit 覆盖关键门控（未 Loaded 不起 CJ、片未归位不完成、Hold 阻断等）。

## 二、背景知识（先读，30 分钟）

### 1. 五层状态与唯一权威
| 层 | 状态 | 唯一权威模块 | 粒度 |
|---|---|---|---|
| E30 设备控制 | ONLINE/OFF-LINE、LOCAL/REMOTE、控制状态机 | GEM 控制态 | 整机 |
| E87 载具 | NotInstalled/Installed/Loaded/Unloaded + Hold | CarrierManager | 盒 |
| E90 片位置 | 每片 Location + SlotMap 三态 | SubstrateTracker | 片 |
| E40 PJ | Queued/Started/Executing/Pausing/Paused/终态 | JobStateMachine | 作业 |
| E94 CJ | 同构九态（子 PJ 聚合） | CjStateMachine | 批次 |
- 每层状态只由自己的模块写；其他层只读、不缓存可写副本。

### 2. 关键门控（前置条件）
- 自动流程总前提：E30 ONLINE + REMOTE（LOCAL 只受本机、OFF-LINE 不接受 Host 控制）。
- E87 Loaded 前置：Installed + 预约匹配 + 无 CarrierHold。
- E94 Create/Start CJ 前置：相关载具 Loaded（绑口 ID 对）+ E90 基线已注册 + E30 REMOTE + 无 Lot/Equipment Hold。
- E40 Start PJ 前置：所属 CJ Started、输入片就位（E90）、资源可用、配方校验。
- E90 自动取片前置：载具 Loaded（唯一）、PJ 授权、目标位置容量允许。
- PJ Completed 前置：自己片走完 + E90 归到 PJ 目标 + 自身终验。
- CJ Completed 前置：所有 PJ Completed + 每片到 CJ 输出 + 设备内空 + 跨 PJ 守恒。
- E87 Unload 前置（UnloadGuard）：CJ Completed、所有片回输出载具、机械手 Home、门关闭、无 Hold。

### 3. Hold 的跨层阻断
- EquipmentHold：整机级，阻断一切自动作业起停（设备不能自解，需 Host）。
- CarrierHold：该载具相关取放阻断。
- LotHold：该批次（CJ/PJ）加工阻断。
- Hold 不回退已完成状态，只阻止"继续向前"的迁移；解除需授权方。

### 4. 门控方向（自底向上提供事实，自顶向下受约束）
- 底层向上层提供事实前提：E84/E90 物理事实→E87 授权→E40/E94 任务。
- 上层不能命令底层违背不变式：CJ 不能让 E90 把两片放同一槽。
- 门控是"查询各权威层当前态 + 布尔判定"，集中在 LayerGate，不散落在业务代码里。

### 5. 单一事实源的代码形态
- 跨层需要信息时调对方公开方法（如 `tracker.LocationOf(id)`、`carrierMgr.StateOf(port)`），或订阅其状态变更事件维护**只读**投影。
- 禁止把对方状态复制成自己的可写字段再据此决策（会产生两份可写事实、必然漂移）。
- LayerGate 是只读协调者：注入各模块，只做前置判定，不改任何层状态。
