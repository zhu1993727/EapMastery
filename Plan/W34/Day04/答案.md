# W34 · Day04 答案与参考实现

## 一、自测题标准答案
1. **五种质量码/举例**：Good=正常可信（传感器在量程内、按时到达、通过校验）；Bad=确认无效，如传感器断线、超物理量程、NaN、采集硬件错、解码失败，不能用于计算；Uncertain=可疑未确认，如与冗余传感器/相邻点严重背离、由插值得到、上下文刚切换不稳，需降权谨慎用；Stale=值长期不更新/卡死（通信挂起、传感器冻结），表面有数但已过期；Gap=按采集计划本应到却缺失的时间缺口（丢包、flush 失败、EDA 会话断/有界队列丢点）。五者随样本全链路携带，区别"坏、疑、旧、缺"。
2. **来源层/为何标来源**：源端（传感器故障/超量程/标定过期/设备未提供）、采集层（ADC/DCM 计划漏配、采样线程抖动、设备负载漏采）、传输层（丢包、断连、队列 Dropped、延迟超限）、平台层（解码失败、上下文 Unbound、时钟异常）。标来源是为了快速定位与正确整改：源端问题要修传感器/设备，传输问题要查网络/会话配额，采集问题改计划/频率，平台问题改对齐逻辑；若不标来源，看到坏值分不清是设备真异常还是链路丢点，会误判工艺或白跑维修。
3. **Stale vs Gap/识别**：Gap 是"该有的点没有"，表现为时间栅格上的空缺区间（无值）；Stale 是"有值但不再变化/不刷新"，表现为最新值时间戳超 N 个周期未更新，或连续 M 点数值完全相同（值在但过期）。识别：按计划频率建预期时间栅格，缺位置标 Gap 区间（记录起止）；Stale 用"最后更新时间超时"或"连续等值检测"（与 FDC stuck 规则同源，W30 Day03），结合状态字判断是真稳定还是冻结。二者都不能当 Good。
4. **窗口含 Bad 的聚合质量**：聚合质量由成员质量决定、只降不升。若窗口内存在 Bad 点：坏点比例超阈值（或关键输入为 Bad）则聚合结果判 Bad；少量 Bad 但剔除后样本仍足够，结果至少降为 Uncertain 并记录剔除比例；含 Gap 时跨缺口不能直接算变化率/积分（窗口被缺口截断分段，W30）；两通道相关/回归任一通道有 Bad/Gap，结果不可信应降级。绝不能无视坏点照常输出"看起来正常"的 Good 聚合。
5. **只降不升/能否洗白**：质量只降不升是指输出结果的可信度不可能高于其输入与计算过程——输入 Uncertain 或计算本身依赖插值/跨缺口，结果最多是 Uncertain，不能因为后续平均、平滑或模型输出一个确定数值就标成 Good。Uncertain 不能被"洗"成 Good：要恢复 Good 必须有新的可靠观测来源（如冗余传感器确认、实测校准、重采），而不是靠算法掩盖。否则下游会把不可信数据当确定事实，风险被层层放大。
6. **下游各自处理**：FDC——Good 正常判规则，Uncertain 降权/仅提示，Bad/Gap 不判工艺、规则窗口跨缺口重置，长期 Bad 单列数据质量告警（W30）；VM——关键 Step 特征必须 Good 且齐全才出高置信预测，含坏点/缺口则降置信或不出预测、等实测（W32）；R2R——量测可靠才更新 EWMA 状态，Bad/缺失不更新、hold-last-good，连续无有效反馈则停自动（W31）；SPC——坏点不入控制图、缺口显式标注，避免把数据缺失误判成工艺异常或正常。共同原则：宁可少动作/不出结论，也不基于坏数据决策，且每次"因质量不动作"都记数据质量事件。
7. **长期 Bad 为何告警/与工艺报警关系**：数据是 FDC/R2R/VM/SPC 的"眼睛"，长期 Bad/Gap 等于监控失明：此时真正的工艺异常无法被检测，可能在无人知晓下持续产出坏片，风险极高，因此数据质量本身要告警、推动尽快修复并评估失明期间产品。它与工艺报警区别：工艺报警是"测得工艺坏了"（值越限/异常模式），数据质量告警是"看不清/测不了"（链路或传感器问题）；前者针对产品/过程，后者针对测量系统，但数据问题可能掩盖工艺问题，二者都要上报告警、联动处置（数据失明期必要时按风险暂停自动控制/加严人工确认）。

## 二、参考实现（net8.0）：质量码与质量传播

```csharp
namespace EapLab.Edc.Quality;
public enum Q{ Good,Uncertain,Bad,Stale,Gap }
public sealed record QSample(DateTime T,double? V,Q Q);
public static class QRank{ public static int Level(Q q)=>q switch{Q.Good=>0,Q.Uncertain=>1,Q.Stale=>2,Q.Gap=>3,Q.Bad=>4,_=>9}; }
public sealed record Agg(double? Mean,Q Quality,double GoodRatio);
public sealed class QualityPropagator
{
    readonly double _badTol;public QualityPropagator(double badTol=0.1){_badTol=badTol;}
    // 聚合质量只降不升: 有关键Bad→Bad; 坏比例超阈→Bad; 有Uncertain/Stale/Gap→降级
    public Agg Aggregate(IEnumerable<QSample> w)
    { var a=w.ToList();var good=a.Where(x=>x.Q==Q.Good&&x.V is not null).ToList();
        double ratio=(double)good.Count/a.Count;
        Q worst=a.Max(x=>QRank.Level(x.Q))switch{0=>Q.Good,1=>Q.Uncertain,2=>Q.Stale,3=>Q.Gap,_=>Q.Bad};
        double badRatio=(double)a.Count(x=>x.Q is Q.Bad or Q.Gap)/a.Count;
        Q outq=worst==Q.Bad||badRatio>_badTol?Q.Bad:worst==Q.Good?Q.Good:Q.Uncertain;
        double? mean=good.Count==0?null:good.Average(x=>x.V!.Value);
        return new Agg(mean,outq,ratio); }
    // 下游门控
    public bool FdcMayJudge(Q windowQ)=>windowQ==Q.Good;
    public bool VmHighConfidence(IEnumerable<Q> featureQs)=>featureQs.All(x=>x==Q.Good);
    public bool R2rMayUpdate(Q measureQ)=>measureQ==Q.Good;
    public bool SpcMayPlot(Q q)=>q==Q.Good;
    // 缺口检测: 周期栅格上缺失区间
    public List<(DateTime s,DateTime e)> FindGaps(IEnumerable<QSample> s,TimeSpan period)
    { var x=s.OrderBy(t=>t.T).ToList();var gaps=new List<(DateTime,DateTime)>();
        for(int i=1;i<x.Count;i++){var d=x[i].T-x[i-1].T;if(d>period*1.5)gaps.Add((x[i-1].T,x[i].T));}
        return gaps; }
}
```

### xUnit
```csharp
public class QualityTests
{
    static QSample G(DateTime t,double v,Q q=Q.Good)=>new(t,v,q);
    [Fact] public void 全Good聚合Good()
    { var p=new QualityPropagator();var t=DateTime.UtcNow;
      var a=p.Aggregate(new[]{G(t,1),G(t.AddSeconds(1),2),G(t.AddSeconds(2),3)});
      Assert.Equal(Q.Good,a.Quality);Assert.Equal(2,a.Mean); }
    [Fact] public void 含一个Bad_比例低降Uncertain_比例高判Bad()
    { var p=new QualityPropagator(0.1);var t=DateTime.UtcNow;
      var low=p.Aggregate(new[]{G(t,1),G(t.AddSeconds(1),2,Q.Bad),G(t.AddSeconds(2),3),G(t.AddSeconds(3),4),G(t.AddSeconds(4),5),G(t.AddSeconds(5),6)});
      Assert.Equal(Q.Uncertain,low.Quality);
      var high=p.Aggregate(new[]{G(t,1,Q.Bad),G(t.AddSeconds(1),2,Q.Bad),G(t.AddSeconds(2),3)});
      Assert.Equal(Q.High is Q?Q.Bad:Q.Bad,high.Quality); }
    [Fact] public void Uncertain不能被聚合洗白成Good()
    { var p=new QualityPropagator();var t=DateTime.UtcNow;
      Assert.Equal(Q.Uncertain,p.Aggregate(new[]{G(t,1),G(t.AddSeconds(1),2,Q.Uncertain)}).Quality); }
    [Fact] public void 下游门控_非Good都不放行()
    { var p=new QualityPropagator();Assert.False(p.FdcMayJudge(Q.Bad));Assert.False(p.R2rMayUpdate(Q.Stale));
      Assert.False(p.VmHighConfidence(new[]{Q.Good,Q.Uncertain}));Assert.False(p.SpcMayPlot(Q.Gap)); }
    [Fact] public void 缺口区间被识别()
    { var p=new QualityPropagator();var t=DateTime.UtcNow;
      var gaps=p.FindGaps(new[]{G(t,1),G(t.AddSeconds(1),2),G(t.AddSeconds(5),3)},TimeSpan.FromSeconds(1));
      Assert.Single(gaps); }
}
```

## 三、质量流转（手绘参考）
```
源端(传感器/量程/标定) → 采集(DCM计划/漏采) → 传输(丢包/断连/Dropped/延迟) → 平台(解码/上下文/时钟)
   每层给样本打质量码+来源: Good / Bad坏 / Uncertain疑 / Stale旧 / Gap缺(缺口区间)
聚合/特征: 质量只降不升(窗口含Bad→Bad/Uncertain, 跨Gap截断, 相关任一端坏即不可信)
   ↓
下游门控: FDC仅Good判工艺(跨缺口重置) / VM关键特征全Good才高置信 / R2R可靠才更新否则hold / SPC坏点不入图
"因质量不动作"必须记数据质量事件(不静默); 长期Bad=监控失明→告警并评估失明期产品
治理: Good率/Bad/Gap/Stale/Dropped统计看板(ADC SLA) → 驱动传感器/频率/网络/会话配额整改
区分: 数据质量告警="看不清" vs 工艺报警="工艺坏", 前者可能掩盖后者
```

## 四、今日易错点
1. 只有值没有质量码，坏数据被当 Good 用。
2. 分不清 Bad/Uncertain/Stale/Gap，一律按缺失删或一律照常算。
3. 不标质量来源层，坏值误当工艺异常。
4. Gap 只删行不显式记录缺口区间，跨缺口误算变化率/积分。
5. 聚合时让 Uncertain/Bad 被平均"洗白"成 Good（质量只降不升）。
6. FDC/VM/R2R/SPC 对坏数据照常出结论/控制。
7. 因质量不动作却不记事件，静默失明无人知。
8. 长期 Bad 不告警，忽视"监控失明会掩盖工艺事故"。
