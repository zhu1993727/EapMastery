## 二、背景知识（先读，20 分钟）

### 1. GEM 能力（Capabilities）
GEM 标准定义了很多功能，但不是所有设备都支持全部功能。设备通过**能力列表**告知 Host 它支持哪些 GEM 功能：
- **事件报告能力**：是否支持 S2F33 定义报告、S2F35 关联事件、S6F11 上报。
- **报警能力**：是否支持 S5F1 报警上报、S5F3 使能/禁用报警。
- **远程命令能力**：支持哪些 RCMD（START/STOP/PAUSE 等），每个命令有哪些参数。
- **配方能力**：是否支持 S7 配方上传/下载/删除，配方最大大小。
- **数据变量能力**：支持哪些 SV（状态变量）、DV（数据变量）、VID。
- **时钟能力**：是否支持 S2F17 设置时间、S2F31 查询时间。
- **Spool 能力**：通信中断时是否支持事件/报警缓存（W8 细讲）。

Host 通常在建链后查询设备能力，根据能力决定后续交互方式。

### 2. 状态-消息允许矩阵（核心）
设备在不同状态下，对不同消息的处理方式不同。矩阵如下：

| 消息类型 | 通信 OFF-LINE | 通信 ON-LINE + 控制 OFF-LINE | 通信 ON-LINE + 控制 ON-LINE |
|---|---|---|---|
| S1F1/F2 (Are You There) | ✓ | ✓ | ✓ |
| S1F13/F14 (Establish Comm) | ✓ | ✓ | ✓ |
| S1F15/F16 (Request Off-line) | ✓ | ✓ | ✓ |
| S1F17/F18 (Request On-line) | ✓ | ✓ | ✓ |
| S2F17/F18 (Set Time) | ✗ | ✓ | ✓ |
| S2F31/F32 (Query Time) | ✗ | ✓ | ✓ |
| S2F33/F34 (Define Report) | ✗ | ✓ | ✓ |
| S2F35/F36 (Link Event) | ✗ | ✓ | ✓ |
| S2F37/F38 (Unlink Event) | ✗ | ✓ | ✓ |
| S2F41/F42 (Remote Command) | ✗ | ✗(ACKC10=4) | ✓ |
| S5F1/F2 (Alarm Report) | ✓(设备主动) | ✓(设备主动) | ✓(设备主动) |
| S5F3/F4 (Enable/Disable Alarm) | ✗ | ✓ | ✓ |
| S5F5/F6 (List Alarms) | ✗ | ✓ | ✓ |
| S6F11/F12 (Event Report) | ✓(设备主动) | ✓(设备主动) | ✓(设备主动) |
| S6F15/F16 (Event Request) | ✗ | ✓ | ✓ |
| S7F1-F6 (PP 管理) | ✗ | ✓ | ✓ |
| S7F17/F18 (Delete PP) | ✗ | ✓ | ✓ |
| S9Fx (Error) | ✓ | ✓ | ✓ |

> 具体以 E30 原文及设备实现为准；核心规律：**通信 OFF-LINE 只允许 S1 通信相关消息；控制 OFF-LINE 拒绝 S2F41 远程命令；ON-LINE+ON-LINE 允许全部。**

### 3. 拒绝消息的处理方式
设备收到不允许的消息时，有两种处理方式：
- **回 S9 错误**：消息完全不支持（如 Stream 不认识、Function 不支持），回 S9F3/F5。
- **回 ACKC 非 0**：消息支持但当前状态不允许（如 OFF-LINE 时发 S2F41），回对应 reply 带 ACKC 非 0（如 S2F42 ACKC10=4）。
- 关键区分：**S9 是"消息本身不支持"，ACKC 非 0 是"消息支持但当前条件不满足"**。

### 4. S1F1/F2 扩展能力列表
部分设备在 S1F2（Are You There Response）中除了返回 MDLN/SOFTREV，还返回扩展能力列表（如果 Host 在 S1F1 中请求了扩展信息）。扩展能力列表通常包含：
- 支持的 GEM 功能标志位（事件/报警/远程命令/配方/Spool 等）。
- 支持的 Stream/Function 列表。
- 设备特定能力。
- 具体格式以设备实现为准，标准 S1F2 只要求 MDLN/SOFTREV，扩展是可选的。

### 5. 能力查询的标准流程
```
建链完成后：
1. Host 发 S1F1 → 设备回 S1F2（MDLN/SOFTREV，可选扩展能力）
2. Host 发 S2F31 → 设备回 S2F32（当前时间）
3. Host 发 S1F13（如果还没建立通信）→ 设备回 S1F14
4. Host 查询 SV（S1F3/S1F11 或 S2F1?）获取支持的变量/事件/报警/远程命令列表
5. Host 根据能力配置报告/事件/报警
```
