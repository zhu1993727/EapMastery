# W05 · Day04 答案与参考实现

## 一、自测题标准答案
1. **通信 OFF-LINE 时能否收 S2F41**：能收到消息（HSMS 通道是通的，如果 SELECTED），但设备**拒绝处理**。通信 OFF-LINE 时设备只接受 S1 通信相关消息，S2F41 属于控制类消息，设备会回 S2F42 带 ACKC10 非 0（如 4="设备 OFF-LINE"），或直接不处理。Host 必须先完成 S1F13 建立通信 + S1F17 请求在线，才能发 S2F41。
2. **ON-LINE + 控制 OFF-LINE 时 S2F33/S2F41**：S2F33（定义报告）**可以**——定义报告是数据采集配置，不直接控制设备，控制 OFF-LINE 时通常允许；S2F41（远程命令）**不可以**——远程命令直接控制设备运行，控制 OFF-LINE 时会被拒绝（ACKC10=4）。关键区别：S2F33 是"配置/监控"类，S2F41 是"控制/执行"类。
3. **S9 错误 vs ACKC 非 0**：**S9 错误**表示"消息本身不支持/无法处理"——Stream 不认识(S9F3)、Function 不支持(S9F5)、数据格式非法(S9F7)、数据太长(S9F11)，设备无法理解这条消息，回 S9 通知对端；**ACKC 非 0**表示"消息支持但当前条件不满足"——设备理解这条消息，但因为状态不对(O FF-LINE)、参数错、设备忙等原因拒绝执行，回对应 reply 带 ACKC 非 0。简单说：S9="我听不懂你说什么"，ACKC 非 0="我听懂了但现在不能做"。
4. **GEM 能力列表大类 / Host 为何查询**：7 大类——①事件报告能力、②报警能力、③远程命令能力、④配方能力、⑤数据变量能力(SV/DV/VID)、⑥时钟能力、⑦Spool 能力。Host 查询设备能力是为了**知道设备能做什么、不能做什么**，从而决定后续交互方式——比如设备不支持某远程命令，Host 就不应发；设备不支持 Spool，Host 就知道通信中断时事件会丢；设备支持哪些 SV，Host 才能定义报告采集哪些变量。不查能力就盲目发消息，会大量收到拒绝/错误。
5. **通信 OFF-LINE 时能否主动发 S6F11**：**通常不能**，或即使发了 Host 也不应依赖。通信 OFF-LINE 意味着设备未与 Host 建立业务通信关系，设备的事件报告通常只在通信 ON-LINE 且已定义报告/关联事件后才会上报。OFF-LINE 时设备可能缓存事件(如果支持 Spool)，等 ON-LINE 后再上传；也可能直接丢弃。标准实践是：通信 ON-LINE 后 Host 才配置报告/事件，设备才开始上报。
6. **S1F18 ACKC1=1 拒绝的原因 / Host 怎么做**：ACKC1=1 表示设备拒绝进入 ON-LINE，可能原因：①设备有急停/严重报警未清除；②设备正在运行，不允许切换到远程模式；③设备配置为不允许 Host 控制（本地锁定）；④操作员正在本地操作。Host 应该：记日志告警，通知操作员检查设备状态（急停、报警、本地/远程开关），等设备条件满足后再重试 S1F17；不应盲目死循环重发。

## 二、参考实现（GemStateMachine.IsMessageAllowed）

```csharp
using EapLab.Gem.State;

namespace EapLab.Gem.State;

public enum MessageAllowance
{
    Allowed,               // 允许
    RejectedOffline,       // 通信 OFF-LINE 拒绝
    RejectedControlOffline,// 控制 OFF-LINE 拒绝（S2F41）
    RejectedNotSupported   // 不支持（回 S9）
}

public sealed class GemStateMachine
{
    public GemCommState CommState { get; private set; } = GemCommState.Offline;
    public GemControlState ControlState { get; private set; } = GemControlState.EquipmentOffline;

    /// <summary>判断当前状态下是否允许某条消息，返回允许/拒绝原因。</summary>
    public MessageAllowance IsMessageAllowed(byte stream, byte function)
    {
        // S1 通信相关消息：任何状态都允许
        if (stream == 1) return MessageAllowance.Allowed;

        // S9 错误消息：任何状态都允许
        if (stream == 9) return MessageAllowance.Allowed;

        // 通信 OFF-LINE：只允许 S1/S9，其他拒绝
        if (CommState == GemCommState.Offline)
            return MessageAllowance.RejectedOffline;

        // 通信 ON-LINE：S2F41 远程命令需要控制 ON-LINE
        if (stream == 2 && function == 41)
        {
            if (ControlState == GemControlState.EquipmentOffline)
                return MessageAllowance.RejectedControlOffline;
        }

        // 其他消息（S2F33/S2F35/S5/S6/S7 等）：通信 ON-LINE 即允许
        return MessageAllowance.Allowed;
    }

    /// <summary>接收管线调用：根据允许结果决定处理方式。</summary>
    public (bool handle, byte? ackc, byte? s9Function) CheckAndDecide(byte s, byte f)
    {
        var allowance = IsMessageAllowed(s, f);
        return allowance switch
        {
            MessageAllowance.Allowed => (true, null, null),
            MessageAllowance.RejectedOffline => (false, 4, null),        // 回 ACKC=4（设备 OFF-LINE）
            MessageAllowance.RejectedControlOffline => (false, 4, null),  // 回 ACKC10=4
            MessageAllowance.RejectedNotSupported => (false, null, 5),     // 回 S9F5（Unknown Function）
            _ => (false, 1, null)
        };
    }

    // 状态切换方法（Day05 完整实现）
    public bool RequestOnline() { CommState = GemCommState.Online; return true; }
    public bool RequestOffline() { CommState = GemCommState.Offline; ControlState = GemControlState.EquipmentOffline; return true; }
    public void SetControlOnline() => ControlState = GemControlState.EquipmentOnline;
    public void SetControlOffline() => ControlState = GemControlState.EquipmentOffline;
}
```

### 单测
```csharp
public class GemStateMachineTests
{
    [Fact]
    public void 通信OFFLINE时S1消息允许_S2消息拒绝()
    {
        var gem = new GemStateMachine(); // 默认 OFFLINE
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(1, 13));
        Assert.Equal(MessageAllowance.RejectedOffline, gem.IsMessageAllowed(2, 41));
        Assert.Equal(MessageAllowance.RejectedOffline, gem.IsMessageAllowed(6, 11));
    }

    [Fact]
    public void 通信ONLINE控制OFFLINE时S2F41拒绝_其他允许()
    {
        var gem = new GemStateMachine();
        gem.RequestOnline();          // 通信 ON-LINE，控制默认 OFF-LINE
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(2, 33));  // 定义报告允许
        Assert.Equal(MessageAllowance.RejectedControlOffline, gem.IsMessageAllowed(2, 41)); // 远程命令拒绝
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(5, 1));   // 报警允许
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(7, 3));   // 配方允许
    }

    [Fact]
    public void 通信ONLINE控制ONLINE时全部允许()
    {
        var gem = new GemStateMachine();
        gem.RequestOnline();
        gem.SetControlOnline();
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(2, 41));
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(6, 11));
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(7, 1));
    }

    [Fact]
    public void S9消息任何状态都允许()
    {
        var gem = new GemStateMachine(); // OFFLINE
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(9, 3));
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(9, 7));
    }
}
```

## 四、GEM 能力 7 大类速查卡
| 能力 | 说明 | 查询方式 |
|---|---|---|
| 事件报告 | 支持 S2F33/S2F35/S6F11，有哪些 CEID/RPTID/VID | S2F33 定义、S1F3 查询 SV |
| 报警 | 支持 S5F1/S5F3，有哪些 ALID | S5F5 List Alarms |

| Spool | 通信中断时缓存事件/报警 | S1F3 查询 Spool 状态 |

## 五、今日易错点
1. 以为通信 OFF-LINE 时设备不能收任何消息（S1/S9 仍允许）。
2. 以为控制 OFF-LINE 时 S2F33 也被拒绝（S2F33 是配置类，允许；只有 S2F41 控制类被拒绝）。
3. 混淆 S9 错误和 ACKC 非 0（S9=不支持消息，ACKC=支持但条件不满足）。
4. 以为 OFF-LINE 时设备主动上报的 S6F11 一定能收到（可能缓存或丢弃）。
5. 不查设备能力就盲目发消息（大量拒绝/错误）。
6. S1F17 被拒绝后死循环重发（应检查设备状态，等条件满足再重试）。
7. 状态-消息矩阵不随设备实现调整（不同设备可能有差异，以设备手册为准）。
