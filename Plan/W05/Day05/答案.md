# W05 · Day05 答案与参考实现

## 一、自测题标准答案
1. **为何通信状态机和控制状态机分开**：两者是独立的维度——通信状态表示"设备是否与 Host 建立业务通信"，控制状态表示"Host 是否有权限控制设备运行"。分开实现有三个好处：①职责单一，每个状态机只管理自己的状态和转换；②可以独立变化——通信 ON-LINE 后控制状态可以在 OFF-LINE/ON-LINE 之间切换，不影响通信；③可以独立测试和复用。合成一个状态机会导致状态爆炸（2×2=4 种组合，每种组合的转换规则复杂）。
2. **通信 ON-LINE→OFF-LINE 时控制状态怎么变 / 为什么**：控制状态应**自动回 EQUIPMENT OFF-LINE**。因为控制状态 EQUIPMENT ON-LINE 的前提是通信 ON-LINE——Host 不可能控制一个未建链的设备。如果通信断了但控制状态还停在 ON-LINE，会导致状态不一致（Host 以为还能控制设备，实际通道已断）。所以通信 OFF-LINE 时必须联动控制状态回 OFF-LINE。
3. **Host 能直接切换控制状态吗**：**不能**。控制状态是设备的本地状态，由设备的本地操作（操作员按本地/远程按钮）、设备配置（上电默认远程模式）、或设备内部逻辑（急停/故障）决定。Host 只能通过 S2F41 发远程命令，设备根据当前控制状态决定接受或拒绝；Host 不能发一条消息让设备从 EQUIPMENT OFF-LINE 切到 ON-LINE。这是安全设计——设备的控制权必须由本地操作员确认，不能被远程强制切换。
4. **合法边校验 vs 业务逻辑校验 / S2F41 例子**：合法边校验是状态机层面的——"当前状态是否允许这个转换"，如"EQUIPMENT OFF-LINE 时不允许接受 S2F41"；业务逻辑校验是业务层面的——"命令名是否认识、参数是否正确、设备是否忙"，如"START 命令是否带了 LOTID 参数、RECIPE 是否存在"。S2F41 的完整校验流程：①状态机校验（控制是否 ON-LINE）→ ②命令名校验（是否认识 RCMD）→ ③参数校验（CPNAME/CPVALUE 是否正确）→ ④设备状态校验（是否忙、是否有报警）→ ⑤接受并排队。任何一步失败都回 ACKC10 非 0，但原因不同。
5. **设备急停时通信/控制状态怎么变 / S2F42 怎么回**：急停时，控制状态**立即回 EQUIPMENT OFF-LINE**（设备进入安全状态，拒绝远程命令）；通信状态**通常保持 ON-LINE**（急停不影响通信通道，Host 仍能收事件/报警、查询状态），除非设备配置为急停时也断通信。此时如果 Host 正在等 S2F42，设备会回 S2F42 ACKC10 非 0（如"设备急停，命令被拒绝"），或命令已接受但执行被中断（通过 S6F11 事件通知执行失败）。
6. **为何状态机不做业务逻辑 / 业务逻辑放哪里**：状态机只管理"在什么状态下允许什么转换"，保持简单、可验证、可复用；业务逻辑（命令执行、参数校验、设备动作）复杂且多变，放在状态机外部的事件处理器或业务服务中。这样状态机可以独立测试（只测状态转换），业务逻辑可以独立修改（不影响状态机），符合单一职责原则。业务逻辑通过监听状态机的状态转换事件来触发，或在消息处理器中调用状态机检查状态后执行。

## 二、参考实现（EapLab.Gem/State/）

### GemCommStateMachine.cs
```csharp
using EapLab.Transport.Connection;
using EapLab.Transport.Logging;

namespace EapLab.Gem.State;

public enum GemCommState { Offline, Online }

public sealed class GemCommStateMachine : StateMachineBase<GemCommState>
{
    public event Action? OnOnline;
    public event Action? OnOffline;

    public GemCommStateMachine(ILogSink log) : base(GemCommState.Offline, log) { }

    protected override bool CanTransition(GemCommState f, GemCommState t) => (f, t) switch
    {
        (GemCommState.Offline, GemCommState.Online) => true,   // S1F17 接受
        (GemCommState.Online, GemCommState.Offline) => true,   // S1F15 接受 / 设备主动
        _ => false
    };

    public bool RequestOnline()
    {
        if (!ChangeState(GemCommState.Online, "S1F17 accepted")) return false;
        OnOnline?.Invoke();
        return true;
    }

    public bool RequestOffline()
    {
        if (!ChangeState(GemCommState.Offline, "S1F15 accepted")) return false;
        OnOffline?.Invoke();
        return true;
    }

    public void EquipmentInitiatedOffline(string reason)
    {
        if (Current == GemCommState.Online)
        {
            ChangeState(GemCommState.Offline, $"Equipment initiated: {reason}");
            OnOffline?.Invoke();
        }
    }
}
```

### GemControlStateMachine.cs
```csharp
namespace EapLab.Gem.State;

public enum GemControlState { EquipmentOffline, EquipmentOnline }

public sealed class GemControlStateMachine : StateMachineBase<GemControlState>
{
    public event Action? OnControlOnline;
    public event Action? OnControlOffline;

    public GemControlStateMachine(ILogSink log) : base(GemControlState.EquipmentOffline, log) { }

    protected override bool CanTransition(GemControlState f, GemControlState t) => (f, t) switch
    {
        (GemControlState.EquipmentOffline, GemControlState.EquipmentOnline) => true,  // 本地切远程
        (GemControlState.EquipmentOnline, GemControlState.EquipmentOffline) => true,  // 本地切本地/急停
        _ => false
    };

    // 注意：控制状态转换由设备本地触发，Host 不能直接调用
    public void LocalSwitchToOnline()   // 操作员按"远程"按钮
    {
        if (ChangeState(GemControlState.EquipmentOnline, "Local switch to REMOTE"))
            OnControlOnline?.Invoke();
    }

    public void LocalSwitchToOffline()  // 操作员按"本地"按钮
    {
        if (ChangeState(GemControlState.EquipmentOffline, "Local switch to LOCAL"))
            OnControlOffline?.Invoke();
    }

    public void EmergencyStop()          // 急停
    {
        if (Current == GemControlState.EquipmentOnline)
        {
            ChangeState(GemControlState.EquipmentOffline, "Emergency stop");
            OnControlOffline?.Invoke();
        }
    }
}
```

### GemStateMachine 门面类（组合+联动+IsMessageAllowed）
```csharp
namespace EapLab.Gem.State;

public enum MessageAllowance { Allowed, RejectedOffline, RejectedControlOffline, RejectedNotSupported }

public sealed class GemStateMachine
{
    private readonly GemCommStateMachine _comm;
    private readonly GemControlStateMachine _control;
    private readonly ILogSink _log;

    public GemCommState CommState => _comm.Current;
    public GemControlState ControlState => _control.Current;
    public bool CommEstablished { get; private set; }

    // 状态变化事件（上层订阅）
    public event Action? OnOnline => _comm.OnOnline;
    public event Action? OnOffline => _comm.OnOffline;
    public event Action? OnControlOnline => _control.OnControlOnline;
    public event Action? OnControlOffline => _control.OnControlOffline;

    public GemStateMachine(ILogSink log)
    {
        _log = log;
        _comm = new GemCommStateMachine(log);
        _control = new GemControlStateMachine(log);
        // 联动：通信 OFF-LINE 时，控制状态自动回 OFF-LINE
        _comm.OnOffline += () =>
        {
            if (_control.Current == GemControlState.EquipmentOnline)
                _control.LocalSwitchToOffline();  // 联动回 OFF-LINE
        };
    }

    public void OnCommEstablished() => CommEstablished = true;

    public bool RequestOnline() => _comm.RequestOnline();
    public bool RequestOffline() => _comm.RequestOffline();
    public void EquipmentInitiatedOffline(string reason) => _comm.EquipmentInitiatedOffline(reason);
    public void LocalSwitchToOnline() => _control.LocalSwitchToOnline();
    public void LocalSwitchToOffline() => _control.LocalSwitchToOffline();
    public void EmergencyStop() => _control.EmergencyStop();

    public MessageAllowance IsMessageAllowed(byte stream, byte function)
    {
        if (stream == 1 || stream == 9) return MessageAllowance.Allowed;
        if (_comm.Current == GemCommState.Offline)
            return MessageAllowance.RejectedOffline;
        if (stream == 2 && function == 41 &&
            _control.Current == GemControlState.EquipmentOffline)
            return MessageAllowance.RejectedControlOffline;
        return MessageAllowance.Allowed;
    }
}
```

### 消息处理管线集成（在 HsmsConnection 接收侧）
```csharp
private void DispatchGemMessage(HsmsHeader h, SecsItem? body)
{
    var allowance = _gem.IsMessageAllowed(h.Stream, h.Function);
    switch (allowance)
    {
        case MessageAllowance.RejectedOffline:
            _log.Log(LogDir.ERR, $"消息 S{h.Stream}F{h.Function} 在 OFF-LINE 状态被拒绝");
            SendReply(h, BuildAckReply(4, "Equipment OFF-LINE"));  // ACKC=4
            return;
        case MessageAllowance.RejectedControlOffline:
            _log.Log(LogDir.ERR, $"S2F41 在控制 OFF-LINE 状态被拒绝");
            SendReply(h, BuildAckReply(4, "Control OFF-LINE"));
            return;
        case MessageAllowance.RejectedNotSupported:
            _s9.UnknownFunction(h.Encode(0));  // 回 S9F5
            return;
    }

    // 状态允许，继续业务处理
    switch (h.Stream)
    {
        case 1:
            var s1Reply = _s1Handler.HandlePrimary(h.Function, body);
            if (h.Function == 17 && s1Reply != null) _gem.RequestOnline();   // S1F17 接受后转 ONLINE
            if (h.Function == 15 && s1Reply != null) _gem.RequestOffline();  // S1F15 接受后转 OFFLINE
            SendReply(h, s1Reply);
            break;
        case 2 when h.Function == 41:
            var cmdReply = _rcmdHandler.HandleS2F41(body);
            SendReply(h, cmdReply);
            break;
        // ... 其他 Stream
    }
}
```

### 单测
```csharp
public class GemStateMachineTests
{
    [Fact]
    public void 建链流程_OFFLINE→ONLINE()
    {
        var gem = new GemStateMachine(new ConsoleLogSink());
        Assert.Equal(GemCommState.Offline, gem.CommState);
        Assert.True(gem.RequestOnline());     // S1F17 接受
        Assert.Equal(GemCommState.Online, gem.CommState);
    }

    [Fact]
    public void OFFLINE时S2F41被拒绝()
    {
        var gem = new GemStateMachine(new ConsoleLogSink());
        Assert.Equal(MessageAllowance.RejectedOffline, gem.IsMessageAllowed(2, 41));
    }

    [Fact]
    public void 通信ONLINE控制OFFLINE时S2F41被拒绝_其他允许()
    {
        var gem = new GemStateMachine(new ConsoleLogSink());
        gem.RequestOnline();
        Assert.Equal(MessageAllowance.RejectedControlOffline, gem.IsMessageAllowed(2, 41));
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(2, 33));  // 定义报告允许
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(6, 11));  // 事件允许
    }

    [Fact]
    public void 通信ONLINE控制ONLINE时S2F41允许()
    {
        var gem = new GemStateMachine(new ConsoleLogSink());
        gem.RequestOnline();
        gem.LocalSwitchToOnline();  // 操作员切远程
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(2, 41));
    }

    [Fact]
    public void 设备主动OFFLINE时控制状态联动回OFFLINE()
    {
        var gem = new GemStateMachine(new ConsoleLogSink());
        gem.RequestOnline();
        gem.LocalSwitchToOnline();
        Assert.Equal(GemControlState.EquipmentOnline, gem.ControlState);

        gem.EquipmentInitiatedOffline("急停");  // 设备主动断通信
        Assert.Equal(GemCommState.Offline, gem.CommState);
        Assert.Equal(GemControlState.EquipmentOffline, gem.ControlState);  // 联动回 OFF-LINE
    }

    [Fact]
    public void S1和S9消息任何状态都允许()
    {
        var gem = new GemStateMachine(new ConsoleLogSink());  // OFFLINE
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(1, 13));
        Assert.Equal(MessageAllowance.Allowed, gem.IsMessageAllowed(9, 3));
    }
}
```

## 三、今日易错点
1. 把通信状态和控制状态合成一个状态机（状态爆炸，应分开）。
2. 通信 OFF-LINE 时控制状态没联动回 OFF-LINE（状态不一致）。
3. Host 直接调用控制状态转换（控制状态由设备本地触发，Host 不能直接切）。
4. 状态机里写业务逻辑（状态机只管状态转换，业务逻辑放外部）。
5. S2F41 在控制 OFF-LINE 时回 S9 而不是 ACKC10=4（消息支持但状态不允许，应回 ACKC 非 0）。
6. 急停时通信状态也断（急停通常只断控制状态，通信保持，除非设备配置为急停断通信）。
7. 状态转换事件没触发或重复触发（ChangeState 唯一入口，事件在转换成功后触发）。
