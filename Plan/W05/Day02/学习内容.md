## 二、背景知识（先读，25 分钟）

### 1. 完整建链时序（必背）
```
Host(上位机)                              Equipment(设备)
  │── TCP Connect ───────────────────────►│
  │── HSMS Select.req ───────────────────►│
  │◄─ HSMS Select.rsp(Status=0) ──────────│  SELECTED
  │                                          │
  │── S1F13 Establish Comm(MDLN,SOFTREV) ─►│  交换身份
  │◄─ S1F14 (MDLN,SOFTREV) ───────────────│  通信建立
  │                                          │
  │── S1F17 Request On-line ───────────────►│  请求在线
  │◄─ S1F18 ACKC1=0(接受) ────────────────│  → GEM ON-LINE
  │                                          │
  │   ════════ 业务交互（S2/S5/S6/S7）════════ │
```
- HSMS Select 是传输层选通，S1F13 是业务层身份交换，S1F17 是业务层在线授权。
- 三步缺一不可：Select 保证通道通，S1F13 保证双方身份确认，S1F17 保证设备接受 Host 控制。

### 2. S1F13/F14（Establish Communications）
- **方向**：Host→设备（S1F13 primary），设备→Host（S1F14 reply）。
- **W 位**：S1F13 W=1（要求回复），S1F14 W=0。
- **body 结构**：
  - S1F13：`L,2[A MDLN, A SOFTREV]`——Host 的型号和软件版本。
  - S1F14：`L,2[A MDLN, A SOFTREV]`——设备的型号和软件版本。
- **状态转换**：S1F13/F14 成功后，双方交换身份，通信建立。但设备**不一定**立即进入 ON-LINE——S1F13 只是"建立通信"，ON-LINE 还需要 S1F17。
- **MDLN（Model Number）**：设备/Host 型号标识。
- **SOFTREV（Software Revision）**：软件版本号。

### 3. S1F17/F18（Request On-line）
- **方向**：Host→设备（S1F17 primary），设备→Host（S1F18 reply）。
- **W 位**：S1F17 W=1，S1F18 W=0。
- **body 结构**：
  - S1F17：**空 body**（无数据，只是请求）。
  - S1F18：`L,2[U1 ACKC1, A ERRMSG?]`——确认码 + 可选错误信息。
- **状态转换**：设备接受（ACKC1=0）后，GEM 通信状态从 OFF-LINE → ON-LINE。
- **ACKC1 常见值**：0=接受在线；1=拒绝在线（设备不允许）；2=不支持此命令；其他=各种设备特定原因。

### 4. S1F15/F16（Request Off-line）
- **方向**：Host→设备（S1F15 primary），设备→Host（S1F16 reply）。
- **W 位**：S1F15 W=1，S1F16 W=0。
- **body 结构**：
  - S1F15：**空 body**。
  - S1F16：`L,2[U1 ACKC1, A ERRMSG?]`。
- **状态转换**：设备接受（ACKC1=0）后，GEM 通信状态从 ON-LINE → OFF-LINE。
- 设备也可以**主动 OFF-LINE**（如急停、故障），此时不需要 S1F15，设备直接切换状态并通过事件上报通知 Host。

### 5. S1F1/F2（Are You There）
- **方向**：任一方→对方（通常 Host→设备），对方回。
- **W 位**：S1F1 W=1，S1F2 W=0。
- **body**：S1F1 空；S1F2 `L,2[A MDLN, A SOFTREV]`。
- **用途**：轻量级探测，确认对方在线，不改变 GEM 状态。可在任何状态（OFF-LINE/ON-LINE）使用。
