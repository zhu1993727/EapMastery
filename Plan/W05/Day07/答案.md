## 三、现场排障方法论（专家必会，费曼重点）

### "能 ping 通、能 Select，但 Host 发命令设备没反应"排查
1. **看 S1F13**：建立通信成功了吗？S1F14 回了吗？MDLN/SOFTREV 交换了吗？
2. **看 S1F17**：请求在线成功了吗？S1F18 的 ACKC1=0 还是非0？
   - ACKC1=1（拒绝）→ 设备有急停/严重报警/本地锁定，通知操作员检查。
3. **看控制状态**：设备在 EQUIPMENT ON-LINE 吗？
   - 控制 OFF-LINE（本地模式）→ S2F41 会被拒绝（ACKC10=4），通知操作员切远程。
   - 控制状态变化事件定义了吗？Host 知道设备何时切远程吗？
4. **看 S2F42**：设备回了吗？ACKC10 是多少？
   - 没回 → T3 超时，可能设备忙或通信问题。
   - ACKC10=2（参数错）→ 检查 RCMD/CPNAME/CPVALUE。
   - ACKC10=3（设备忙）→ 等待后重试。
5. **看 S6F11**：命令执行完成/失败事件上报了吗？
   - 没上报 → 命令可能还在执行，或完成事件没定义/关联。

### "回了 ACKC10=0，但命令没执行"排查
1. **ACKC10=0 只表示命令已接受并排队**，不表示已执行完成。
2. **看设备是否在执行**：查询状态变量(SV)，看设备运行状态。
3. **看执行条件**：设备是否满足执行条件（门关、气路通、配方已加载、无报警）？命令可能排队等待条件。
4. **看完成事件**：命令完成事件(CEID)定义了吗？关联了吗？Host 监听了吗？
   - 没定义 → Host 不知道命令完成，以为没执行。
5. **看设备日志**：设备端是否收到命令、是否开始执行、是否报错。
6. **看是否被中断**：急停/故障可能中断了正在执行的命令，通过 S6F11 失败事件通知。

## 四、费曼参考脚本（对照录音）
"Host 发一条 S2F41 START 命令，前提是建链完成——TCP 连接、HSMS Select、S1F13 交换身份、S1F17 请求在线（通信 ON-LINE）、操作员切远程（控制 ONLINE）。Host 构造 S2F41 body：L,2[A RCMD='START', L,n 参数]，W=1，发出去。设备收到后先过状态闸门——通信 ON-LINE、控制 ON-LINE，然后校验命令名、参数、设备状态，都通过后回 S2F42 ACKC10=0（命令已接受并排队）。注意这只是接受，不是完成。设备异步执行命令，可能几秒到几分钟，执行完后触发'命令完成'事件(CEID)，通过 S6F11 上报，Host 回 S6F12 确认。如果通信 OFF-LINE，设备回 ACKC10=4 拒绝；如果控制 OFF-LINE（本地模式），也回 ACKC10=4；如果急停，控制状态立即回 OFF-LINE，正在执行的命令被中断，通过 S6F11 失败事件通知。整个过程的核心是：状态决定权限，ACKC 只表示接受，执行结果靠事件。"

## 五、W6(E30 数据采集) 三问思考方向（先自己想，W6 揭晓）
1. **SV/DV/VID 区别**：SV（Status Variable，状态变量）是设备当前状态的只读变量（如温度、压力、运行状态），Host 可随时查询；DV（Data Variable，数据变量）是事件触发时采集的变量（如事件发生时的温度），随 S6F11 上报；VID（Variable ID，变量 ID）是变量的唯一标识，SV 和 DV 都有 VID，用于定义报告时引用。简单说：SV 是"随时可查的状态"，DV 是"事件发生时采集的数据"，VID 是"变量的身份证号"。
2. **S2F33 vs S2F35 关系 / 为何分两步**：S2F33（Define Report）定义"报告里包含哪些变量(VID)"，即报告的内容模板；S2F35（Link Event Report）把"事件(CEID)"和"报告(RPTID)"关联起来，即"当这个事件发生时，上报这些报告"。分两步是因为：一个报告可以被多个事件关联（复用报告模板），一个事件也可以关联多个报告（一次事件触发多份报告），解耦后更灵活。这和 W3 中学的"先定义报告内容，再关联事件"是同一个思路。
3. **S6F11 body 结构**：`L,3[U4 DATAID, U2 CEID, L,n[L,2[U2 RPTID, L,m[变量值...]]]]`。DATAID 是数据收集定义 ID（标识这套报告-变量关联关系是哪次 S2F33 定义的）；CEID 是触发本次上报的事件 ID；报告列表是 n 个报告，每个报告是 L,2[RPTID, 变量值列表]，变量值按 S2F33 定义的顺序排列。这就是 W3 Day05/06 中反复练习的 S6F11 结构。
