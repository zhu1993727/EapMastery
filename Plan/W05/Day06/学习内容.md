## 三、完整建链流程（必背）
```
Host(上位机)                              Equipment(设备)
  │── TCP Connect ───────────────────────►│
  │── HSMS Select.req ───────────────────►│
  │◄─ HSMS Select.rsp(Status=0) ──────────│  SELECTED
  │                                          │
  │── S1F13 Establish Comm(MDLN,SOFTREV) ─►│  交换身份
  │◄─ S1F14 (MDLN,SOFTREV) ───────────────│  通信建立
  │                                          │
  │── S1F17 Request On-line ───────────────►│  请求在线
  │◄─ S1F18 ACKC1=0(接受) ────────────────│  → 通信 ON-LINE
  │                                          │
  │          操作员在设备上切"远程"模式       │
  │◄─ S6F11 事件(控制状态变化: ONLINE) ─────│  → 控制 ONLINE
  │── S6F12 ACK ───────────────────────────►│
  │                                          │
  │   ════════ GEM 完全在线，可发远程命令 ════ │
```

## 四、4 个场景的验收标准

### 场景1：正常建链 + 远程命令
- Host 完成 Select→S1F13→S1F17，设备通信 ON-LINE。
- 操作员切远程，设备控制 ONLINE，通过 S6F11 事件通知 Host。
- Host 发 S2F41 START 命令（带 LOTID/RECIPE/QUANTITY）。
- 设备回 S2F42 ACKC10=0（命令已接受）。
- 设备异步执行命令，完成后发 S6F11 事件（CEID=命令完成）。
- Host 回 S6F12 确认。
- 抓包：完整流程所有消息的 hex 与预期一致。

### 场景2：OFF-LINE 发 S2F41
- Host 和设备 SELECTED，但通信 OFF-LINE（没发 S1F17 或 S1F17 被拒）。
- Host 发 S2F41 START。
- 设备回 S2F42 ACKC10=4（设备 OFF-LINE，拒绝）。
- Host 收到拒绝，记日志，不执行命令。
- 验证：设备状态保持 OFF-LINE，命令未排队。

### 场景3：控制 OFF-LINE → 切远程 → 接受
- 通信 ON-LINE，但控制 EQUIPMENT OFF-LINE（设备在本地模式）。
- Host 发 S2F41 START。
- 设备回 S2F42 ACKC10=4（控制 OFF-LINE，拒绝）。
- 操作员在设备上按"远程"按钮，控制状态切 ONLINE。
- 设备发 S6F11 事件（控制状态变化）通知 Host。
- Host 再次发 S2F41 START。
- 设备回 S2F42 ACKC10=0（接受）。
- 验证：控制状态切换后命令被接受。

### 场景4：急停联动
- 通信 ON-LINE，控制 ONLINE，Host 发 S2F41 START，设备接受并开始执行。
- 操作员按急停按钮。
- 设备控制状态立即回 EQUIPMENT OFF-LINE。
- 正在执行的命令被中断，设备发 S6F11 事件（命令失败，原因=急停）。
- Host 收到事件，记日志，命令标记为失败。
- 验证：急停后控制状态 OFF-LINE，后续 S2F41 被拒绝（ACKC10=4）。
