# W20 · Day01 答案

## 一、自测题标准答案
1. **E94 解决什么 / 没有它会怎样**：E94 解决"一批料的完整加工流程如何作为一个整体被派工和追踪"的问题——一批料常跨多个源/目标载具、包含多个工艺段（多条工艺路线/配方），过程作业之间有先后或并行依赖。ControlJob 用一个上层对象统一声明输入载具、要经过的若干 ProcessJob、输出载具与整体状态。没有它，Host 只能逐个下发孤立 PJ，还要自己维护 PJ 先后顺序、载具衔接（上一个 PJ 输出当下一个输入）、跨载具片流向、整体进度与成败，逻辑复杂、各 PJ 状态分散、极易不一致；设备侧也没有一个对象对整批料负责。E94 把这些编排职责标准化，让 Host 以批次为单位一次派工，设备内部拆解执行并向上汇总。
2. **三层及核心问题**：ControlJob（E94，业务/批次层）回答"这批料从哪几个盒来、经过哪些加工、到哪几个盒去、整体什么状态"；ProcessJob（E40，加工层）回答"某组片按哪条工艺路线、什么配方、在哪些模块/腔加工"；Wafer/Step（片/步骤层）回答"每一片当前在哪个 Step、哪个物理位置、什么工艺状态"，物理位置由 E90 唯一管理。三层自上而下编排、自下而上汇聚状态，职责不重叠。
3. **基数关系**：正常情况下一个 ControlJob 包含一个或多个 ProcessJob（CJ 1 对多 PJ）；一个 ProcessJob 在其生命周期内属于且仅属于一个 CJ（同一时刻不会被两个 CJ 共享编排，避免同一组片/资源被两个上层作业同时主张导致冲突）。PJ 完成后其产出片可作为后续 PJ 输入，但这是 CJ 内部的片流衔接，不是 PJ 被多个 CJ 共有。单 CJ 单 PJ 是最简退化形态。
4. **依赖各标准什么能力**：依赖 E39 OSS——CJ/PJ 都是对象，需要 S14 元数据、S15 创建/方法、S16 事件这套对象服务来定义、创建、控制和上报；依赖 E40——CJ 编排的执行单元是 PJ，需要 PJ 的模型/状态机/多腔执行能力，没有 PJ 就没有可编排内容；依赖 E90——片在跨 PJ、跨载具流动时的位置、SlotMap、守恒、交叉搬运都由 E90 保证；依赖 E87——CJ 声明的输入/输出载具必须正确 Installed/Loaded、预约授权、绑定口；依赖 E30/E5——通信连接、控制状态机、事件报告、远程命令、采集等底座。正因为 CJ 位于这些能力之上，所以必须最后学、集大成。
5. **CJ 改不改物理位置**：不改。物理位置的唯一写入口是 E90 位置层（W14 起的铁律）。CJ 只做编排（决定哪些片经哪个 PJ、流向哪个输出载具）和状态汇总，PJ 执行器在真正取放时调用 E90 的原子 Move 改位置。CJ/PJ 是"计划与任务状态"的持有者，E90 是"物理事实"的持有者；若 CJ 直接改位置，就会出现多个位置写入口、破坏单一事实源，并发/恢复时无法保证一致。
6. **单 CJ 多顺序 PJ、跨两载具例子**：输入载具 A（未加工片 W1-W3）装在 LP1，输出载具 B 在 LP2。建一个 CJ，含两个顺序 PJ：PJ-1=蚀刻（片从 A 取出，经 C1/C2 蚀刻，蚀刻后暂存到中间位置/或直接交下一 PJ），PJ-2=清洗（以 PJ-1 输出为输入，经清洗模块，最终把成品放到 B 的对应槽）。片流向：A 槽→PJ-1 蚀刻（E90 移入腔加工移出）→PJ-2 清洗（以前者输出位置为源）→B 槽。CJ 完成要求 PJ-1、PJ-2 都 Completed、三片都在 B 的声明目标槽、PJ-1 输出集合==PJ-2 输入集合（无丢漏）、全局守恒。
7. **为何以 CJ 派工**：MES/Host 的管理粒度是批次/料（一批从未加工载具到成品载具的完整流程），CJ 正好对应这一业务粒度，一次派工就说清源载具、工艺序列、目标载具与整体要求；设备内部再拆成 PJ 调度。若以 PJ 派工，Host 要承担本可标准化的编排职责（PJ 顺序、载具衔接、跨 PJ 守恒、整体成败聚合），且 Host 看到的是碎片化执行单元而非完整批次，不利于批次追踪、异常时整体决策（暂停/中止整批）和在制管理。CJ 派工实现"业务层一次下发、执行层内部分解、状态逐层汇总"。

## 四、四种 CJ 形态与真实例子（参考）
1. 单 CJ 单 PJ：一批片只做一道等离子蚀刻，一条路线、同型三腔——CJ 是 PJ 的薄封装（最常见的简单批次）。
2. 单 CJ 多顺序 PJ：先蚀刻（PJ1）→去胶清洗（PJ2）→沉积（PJ3），前道产出是后道输入，同一设备集群内串联多工艺段。
3. 单 CJ 多并行 PJ：一批片按量测/类型分两组，一组走路线甲、一组走路线乙并行加工，之后汇合到输出载具。
4. 多载具合批/分档：两个源载具合批加工，或加工后按 Good/Recheck 分档到多个输出载具（W19 复杂布局在 CJ 层的标准表达）。

## 五、今日易错点
1. 把 CJ 和 PJ 当同一层（CJ 编排批次、PJ 执行一条工艺路线，是两层）。
2. 以为 CJ 直接搬片（物理位置唯一入口是 E90，CJ 只编排）。
3. 脱离 E40/E90 硬学 E94（CJ 是集大成上层，下层不懂就是黑盒）。
4. 认为一个 PJ 可同时属于多个 CJ（正常唯一归属，避免双重主张）。
5. 把"Host 派 PJ"当常态（Host 以 CJ 批次派工，设备拆 PJ）。
6. 忽略 CJ 也要依赖 E87 载具 Loaded/授权与 E39 对象服务。
7. 单 CJ 单 PJ 时误以为没有 CJ（退化形态仍有 CJ 层负责整体状态与源目载具）。
8. 画三层图时漏掉"状态自下而上汇聚、编排自上而下分解"的方向。
