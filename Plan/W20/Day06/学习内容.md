# W20 · Day06（周六）实验：ControlJob 端到端建模（顺序链 + 并行分支）

> 建议时长：105 分钟。实验日。把本周 CJ 对象模型、OSS 派工、片流编译、状态聚合组装起来，跑两个端到端剧本：两 PJ 顺序链（蚀刻→清洗、跨两载具）、并行分支汇合（分两路加工再合到输出），验证三层状态、片流守恒与级联启动。

## 一、今日目标
1. 组装 EapLab.E94 总装：CjHostService + MapCompiler + 状态聚合 + 级联 PJ（复用 E40/E90/E87）。
2. 剧本一：单 CJ、两顺序 PJ、源 A→输出 B，验证级联启动、PJ 交接、CJ 最终完成与守恒。
3. 剧本二：单 CJ、两并行 PJ 分支→汇合到输出，验证并行启动、分支片流、汇合不重不漏。
4. 验证三层状态聚合随执行正确变化、CJ 事件只在状态变化时发。
5. xUnit 覆盖两剧本全链路与守恒/终态断言。

## 二、实验准备（10 分钟）
- 复用 W19 VirtualClusterTool 作为 PJ 执行底座（E87/E90/E40 多腔）。
- 在其上加 E94 层：CjHostService（Day03）、FlowGraph/MapCompiler（Day04）、CjStateAggregator/CjProgress（Day05）。
- 参数：源 A 6 片；剧本一 PJ_ETCH→PJ_CLEAN 顺序，输出 B；剧本二 6 片分两组并行 PJ_X/PJ_Y 后汇合 B。

## 三、实验步骤（80 分钟）

### 实验1 顺序链端到端（30min）
1. A/B Loaded、E90 注册基线 6。
2. 建 CJ（含 PJ_ETCH、PJ_CLEAN，控制依赖+片流 A→ETCH→CLEAN→B），静态六校验+片流编译通过。
3. Start CJ：断言只启动 PJ_ETCH，PJ_CLEAN 等待；CJ=Executing。
4. PJ_ETCH 完成：交接校验（ETCH 输出==CLEAN 输入、读码、守恒），级联启动 PJ_CLEAN。
5. PJ_CLEAN 完成、6 片全到 B：聚合判 CJ Completed；终验全局集合守恒、设备内空。
- 记录：级联启动时点、交接清单、各时点 CJ/PJ 状态、最终布局。

### 实验2 并行分支汇合（30min）
1. 片流：A 的 W1-W3 走 PJ_X、W4-W6 走 PJ_Y（分支选择条件），两 PJ 无依赖、Start 时并行启动。
2. 两 PJ 输出汇合到 B 的不同槽（输出槽唯一）。
3. 过程中 CJ 始终 Executing（任一 PJ 在跑）；一个 PJ 先完成时 CJ 不完成，等另一个。
4. 两 PJ 都完成、6 片全到 B、汇合守恒（X 输出∪Y 输出==输入 6 片、无重叠）→CJ Completed。
- 记录：并行启动、先完成分支的状态、汇合点片集合、去重计数（6 非 12）。

### 实验3 状态聚合与事件（20min）
1. 在两剧本中记录每次子 PJ 状态变化后的 CJ 聚合结果，验证优先级规则。
2. 统计 CJ 事件次数：仅 CJ 层状态变化才发（Executing→Completed 一次），PJ 内部高频事件不引发 CJ 事件。
3. 反例：顺序链中 PJ_ETCH Failed，验证 CJ 不完成、按策略整体 Failed 并带失败片。

## 四、验收标准
- [ ] 顺序链：级联启动/交接/最终完成正确，全局集合守恒、设备内空
- [ ] 并行分支：并行启动、汇合不重不漏、唯一片计数、全部完成才 CJ Completed
- [ ] 三层状态聚合符合优先级，CJ 事件仅在状态变化时发
- [ ] 子 PJ 失败时 CJ 不假完成、带失败信息
- [ ] xUnit 全绿
