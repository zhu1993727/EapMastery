# W20 · Day07 答案

## 一、排障推演参考
1. **CJ 一直 Executing 不变 Completed**：按聚合条件从下往上查。①查子 PJ 是否全部 Completed（可能某个 PJ 卡住没完成，CJ 聚合要求所有 PJ 完成）；②PJ 都完成了但片没全到输出载具声明槽——查 E90 是否有片 LeftInside（在臂/锁/腔/Buffer 未归位），聚合规则里"PJ 全完成但片未全到输出"仍是 Executing；③查终验/守恒是否没过（Missing/Double/WrongId）；④查是否有 PJ Failed/Aborted 被标记 Degraded 导致不能走正常完成；⑤查状态聚合事件是否没被触发（子 PJ 完成事件没上送到 CJ 聚合器，订阅/回调断了）。顺序：先看每个 PJ 状态→再看每片物理位置→再看终验守恒→最后看事件链路。
2. **两 PJ 交接处缺一片**：沿责任缝隙定位。①取交接清单：前驱输出集合、后继输入集合，差集就是缺的片 ID；②查该 ID 在 E90 的最后位置轨迹（Trajectory）：是前驱没产出（前驱漏加工/片还在前驱内）、还是产出了但没到约定交接位（在中间 Buffer/臂上）、还是交接时读码不符被拦下；③查全局守恒：该片是否还在设备内（LeftInside）还是已丢失（Missing，守恒破坏）；④核对前驱 WaferMap 输出与后继输入定义是否一致（映射写错导致"账面上不需要这片"）。处置：片在设备内且身份明确→补交接；身份/位置存疑→安全保持人工；守恒破坏→封锁下料、按 Missing 排查，绝不让缺片的 CJ 完成。

## 二、综合自测卷（8 题）参考答案
1. **三层模型与五依赖**：CJ（批次编排）→PJ（一条工艺路线加工）→Wafer/Step（片/步，物理位置 E90 唯一管）。五依赖：E39 OSS（CJ/PJ 是对象，S14/S15/S16）、E40（PJ 执行单元）、E90（片位置/守恒/交叉）、E87（输入输出载具 Loaded/授权/绑口）、E30/E5（通信/控制状态/事件/远程命令底座）。
2. **七类属性/六不变量/分离原因**：七类=标识、状态、载具、片流、PJ 编排、进度结果、时间审计。六不变量=至少一个 PJ 且顺序唯一、每片有完整输入到输出路径且依赖 DAG 无环、片不重复分配且输出槽唯一、片集合守恒、载具角色合法、后继来源合法。Definition/Runtime 分离：计划是可序列化纯数据、能独立静态校验，运行态持状态机/进度/实际绑口位置，分离才好校验、重启重建、重复测试。
3. **Create/Start 校验与级联 / ACKC**：Create 过 OSS 通用校验+跨 PJ 六不变量才 Queued；Start 受理后做开工校验（载具 Loaded 绑口 ID、配方、资源、无 Hold），通过才 Executing 并级联启动无依赖首批 PJ，后继等前驱完成+片就位+资源。ACKC0 只是同步受理，真正 Executing/首个 PJ Started 以迁移后的 S16 事件为准，校验失败回非 0、停留 Queued、零副作用。
4. **两类依赖/四结构/编译器**：控制依赖管 PJ 启动先后，片流依赖管谁的片给谁，正交。四结构=顺序、并行 Fork、汇合 Join、回流（同 PJ 新实例+轮次上限+退出条件）。MapCompiler 为每片产出工艺路径（PJ 序列）与物理路径（输入槽→输出槽）及每 PJ 期望输入输出；静态可查断头、空 PJ、来源缺失、输出槽冲突、集合不守恒、分支未闭合。
5. **交接四校验 / 责任缝隙**：清单一致（前驱输出==后继输入或约定子集）、读码身份一致、交接位置稳定可用、全局守恒。跨 PJ 是责任缝隙：前驱以为交出、后继以为没轮到，最易让片掉在两者之间（无主/重复/丢失），所以要像跨载具一样显式清单+读码+守恒。
6. **聚合优先级/混合态/栅栏**：失败中止>Pausing>全 Paused>Executing>全完成（且片到输出）>全 Queued，固定优先级保证唯一。一 Completed 一 Executing=Executing；PJ 全完成但片未到输出仍 Executing。级联 Pause 栅栏：所有活动 PJ 都到安全点 Paused（Completed 保持），CJ 才 Paused。
7. **计数口径/事件时机**：CJ 片数按唯一 ID（顺序/汇合不翻倍，6 片经两 PJ 仍是 6，加工工作量是 12 次）；完成以片到 CJ 最终输出槽为准。每次子变化都重算聚合，但仅当 CJ 层状态/活动 PJ/进度阈值变化才发 CJ 事件，避免 PJ 高频事件刷屏。
8. **编排不搬片+状态向上聚合如何避免不一致**：CJ/PJ 只做编排与任务状态，物理位置唯一由 E90 改（不存在多个位置写入口，从根上杜绝"上层说在这、物理在那"）；CJ 状态不自封，而是子 PJ/片状态按固定规则聚合的纯函数，下层一变就重算，上层永远是下层事实的真实投影（不会"CJ 说完成、PJ 还在跑"）。两条合起来：物理事实单点权威、任务状态向上投影，跨层一致性由结构保证而非靠约定。

## 三、W21 预热思考题参考
1. **Pause(CJ) 时三种 PJ**：已 Completed 的 PJ 保持终态不动（成果不回退）；在腔反应的活动 PJ 进入 Pausing，等当前不可中断工艺步到安全点后 Paused（不硬切）；Queued 未启动的 PJ 保持未启动/标记被级联暂停、不开始。CJ 用栅栏等待：当在腔 PJ 也 Paused、其余活动单元都到安全点、无运动中片时，CJ 才整体 Paused，并落包含全部 PJ 与片位置的恢复点。
2. **顺序链中间 PJ Aborted 的上下游**：上游（前驱）若已完成，其产出片停在交接位/中间载具，保持并登记为"前道合格在制品"，不回退；若上游还在跑，停止向故障 PJ 供片（级联阻断，避免再送片进来卡住）。下游（后继 PJ）因输入来自故障 PJ、输入缺失且无法满足，不能启动，按依赖传播挂起/级联取消其未开始部分。故障 PJ 内片三分类处置、冻结现场，CJ 转 Failed/Aborted；恢复时基于现场为未完成片新建 CJ/PJ（源=当前实际位置），前道合格片不重做。
3. **CJ-FSM 与 PJ-FSM 最大不同**：PJ-FSM 的迁移主要由外部命令和自身执行事件（就绪/到安全点/片全完成/故障）触发；CJ-FSM 除外部命令外，其迁移**主要由子 PJ 的状态变化事件聚合驱动**——它没有自己的"加工动作"，状态是多个子状态按规则聚合的结果（子完成→重算、全部完成才迁移 Completed，子故障→按级联策略迁移）。即 PJ 是"自己执行驱动自己"，CJ 是"下层聚合驱动自己"，CJ-FSM 要订阅并聚合一组子 FSM，这是它最特殊之处。

## 四、四张闭卷图自检要点
- 三层模型：CJ→PJ→Wafer 方向（编排向下、聚合向上）、五个下层依赖标注。
- 对象树：载具角色、有序 PJ+依赖、ControlJobMap 片流、双向导航、Definition/Runtime 分界。
- 派工时序：Loaded→Create(六校验)→Start(开工校验/级联首批 PJ)→子事件聚合→全完成到输出→Unload，标注 ACKC=受理、S16=生效。
- 四结构：顺序/并行 Fork/汇合 Join/回流（轮次上限），标注交集空、并集全等、输出槽唯一。

## 五、W20 全周易错点总清单
1. 把 CJ 当 PJ 同一层、或让 CJ 直接搬片（CJ 编排，位置唯一入口 E90）。
2. 脱离 E40/E90 硬学 E94、以为一个 PJ 可属多个 CJ。
3. Definition 与 Runtime 混在一起，无法独立校验/重建。
4. Create CJ 漏跨 PJ 六不变量（断头/成环/重复分配/串片）。
5. 把 Start 的 ACKC0 当 Executing；一次性启动所有后继 PJ。
6. 控制依赖与片流依赖混淆；回流无轮次上限成死循环；分支不闭合。
7. PJ 交接不做清单/读码/位置/守恒，片掉在责任缝隙。
8. 状态聚合无固定优先级、上层自封状态、一个 PJ 完成就 CJ 完成。
9. 级联 Pause 不等全部活动 PJ 到安全点。
10. 顺序/汇合按加工次数计片（唯一 ID 计数、完成以最终出 CJ 为准）。
11. 每个子事件都发 CJ 事件（仅 CJ 层状态变化才发）。
12. 子 PJ 失败时 CJ 假装完成（必须显式失败/Degraded/Partial 并带片明细）。
