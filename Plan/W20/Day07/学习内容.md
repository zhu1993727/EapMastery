## 四、W21 预热：CJ 状态机与级联（25 分钟）
### 1. CJ 自己的状态机
- 本周已用聚合规则推导 CJ 状态，W21 正式把它做成与 PJ 同构的状态机（复用 W10 泛型 StateMachine）：Queued→Started→Executing、Pausing→Paused、四终态 Completed/Cancelled/Aborted/Failed。
- 区别：CJ 状态迁移的触发不仅来自外部命令，还来自**子 PJ 状态变化事件**（聚合驱动），这是 CJ-FSM 的特殊点。

### 2. 命令级联（CJ 命令如何作用到 PJ）
- Start(CJ)：级联启动当前可启动 PJ（本周已做）。
- Pause(CJ)：向所有活动 PJ 下发 Pause，全部到安全点 Paused 后 CJ 才 Paused（栅栏，本周已聚合）。
- Resume(CJ)：恢复所有被级联暂停的 PJ（现场一致才恢复，不重不漏）。
- Cancel(CJ)：只有所有 PJ 都未动工（无片受影响）才允许，否则改 Abort。
- Abort(CJ)：级联中止所有活动 PJ，各自三分类处置片，CJ 汇总现场。

### 3. 故障级联策略（W21 重点难点）
- **局部隔离**：一个 PJ 故障，若其他 PJ 不依赖它，可继续，CJ 标记 Degraded，最终 Partial（需授权）。
- **关键路径级联停**：故障 PJ 在关键路径（顺序链唯一环节、其输出被依赖），级联让下游到安全点、上游停止供片，CJ→Failed/Aborted。
- **依赖传播**：一个 PJ Aborted，依赖它的后继 PJ 因输入缺失无法执行，如何级联挂起/取消，W21 建规则。
- 级联方向：上游（供片）与下游（消费）动作不同，要分别定义。

### 4. CJ 级联与恢复
- CJ 级联 Pause 后的 Resume：多个 PJ 各自从恢复点续，交接位的片要重新核对。
- CJ 重启恢复：重建 CJ + 所有 PJ 状态（W17/W19 Day04 方法在 CJ 层的嵌套应用），物理优先、逐层聚合。
