# W20 · Day04（周四）ControlJobMap 深入：片流路径、PJ 依赖 DAG 与 PJ 间交接

> 建议时长：95 分钟。今天专攻 CJ 最核心、也最容易出错的部分——ControlJobMap：如何用一张图描述片在多个 PJ 之间的顺序、并行、分支、汇合，以及片在 PJ 之间交接时的位置、守恒与校验。这是 CJ 编排能力的内核。

## 一、今日目标
1. 用片流图（Flow Graph）精确表达顺序、并行分支、汇合、回流四类结构。
2. 掌握 PJ 依赖 DAG 与片流的关系：控制依赖（谁先启动）与数据依赖（谁的片给谁）。
3. 实现 PJ 间交接：前驱输出位置→后继输入，片身份核对、守恒、不断片。
4. 实现 ControlJobMap 编译器：把片流图展开为每片的"工艺路径 + 物理路径"。
5. xUnit 覆盖四类结构、PJ 间交接、路径展开与守恒、非法图拒绝。

## 二、背景知识（先读，35 分钟）

### 1. 两类依赖要分清
- **控制依赖（Control/Start Dependency）**：决定 PJ 启动先后——B DependsOn A，则 A 完成（或到达某阶段）后 B 才能启动。回答"什么时候能开始"。
- **数据/片流依赖（Material/Flow Dependency）**：决定片从谁流向谁——B 加工的某些片来自 A 的输出。回答"加工的是哪片、从哪取"。
- 二者相关但不等价：两个 PJ 可并行（无控制依赖）却各自从输入载具取片；也可 B 在 A 后启动（控制依赖）且接收 A 的输出（片流依赖）。ControlJobMap 同时表达二者。

### 2. 四种片流结构
1. **顺序（Sequential）**：A→B→C，A 输出全部交 B，B 输出交 C（蚀刻→清洗→沉积）。
2. **并行分支（Parallel/Fork）**：片分组，组1走 A、组2走 B，同时进行（不同工艺/不同腔群）。
3. **汇合（Join/Merge）**：A、B 的输出汇到同一个后继 C 或同一输出载具（合批，W19）。
4. **回流（Rework Loop）**：片经 A 后按结果可能回到 A（或前道）重做——注意 DAG 对"控制流"无环，但回流是同一 PJ 的新一轮（用轮次/实例区分），不能造成定义死循环，需显式最大返工次数与退出条件。

### 3. 片流图建模
- 节点：输入载具槽（Source）、PJ、输出载具槽（Sink）。
- 有向边：片沿边流动，边上可带"片选择条件"（哪些片/哪一档走这条边，分档时用）。
- 每片从 Source 到 Sink 有确定路径（分支条件在运行时按量测确定，但候选路径在定义时闭合、无未知节点）。

### 4. PJ 间交接（关键，容易丢片）
- 前驱 PJ 完成后，片停在其输出位置（中间载具/Buffer/指定槽）；后继 PJ 启动时从这些位置取片。
- 交接校验：①交接清单一致（前驱输出片集合==后继输入片集合，除非是分支/汇合的显式子集）；②片身份核对（读码=预期 ID）；③位置确定且 Loaded/可用；④守恒（交接前后全局片集合不变）。
- 交接点是"跨 PJ 边界"，要像跨载具一样做 AtPick/AtPlace 核对（复用 W15 六道关思想）。
- 中间缓冲：若前驱快、后继慢，片在中间 Buffer/载具排队，受容量约束（W18 资源调度）。

### 5. ControlJobMap 编译器
- 输入：片流图 + 输入片清单；输出：每片的有序 PJ 序列（工艺路径）与最终输出槽（物理路径），以及每个 PJ 的期望输入/输出片集合。
- 编译期可查：未使用的片、无片的 PJ、到不了 Sink 的片（断头）、汇合冲突、输出槽多片、回流无出口。
- 运行期按编译结果驱动 PJ 级联与交接，片身份全程携带。

### 6. 与下层关系
- 每个 PJ 内部仍由 E40 WaferMap/Route、E90 位置、W18 调度负责；ControlJobMap 只管"跨 PJ 的边"，不重复管 PJ 内部。
- 全局守恒以 CJ 为范围：输入片集合==各 PJ 处理集合==输出片集合（跨 PJ、跨载具）。
