# W20 · Day05（周五）三层状态聚合：CJ 状态如何由 PJ / 片状态汇聚

> 建议时长：90 分钟。今天解决"上层状态从哪来"：ControlJob 不自己拍脑袋设状态，而是由其下所有 PJ 状态、每片状态按确定规则聚合而来。掌握聚合规则、进度汇总与状态投影，为 W21 的 CJ 状态机与级联打基础。

## 一、今日目标
1. 建立三层状态投影：Wafer 状态→PJ 状态→CJ 状态的聚合方向与规则。
2. 实现 CJ 状态聚合器：由子 PJ 状态集合确定 CJ 应处状态（含混合态处理）。
3. 实现 CJ 进度汇总：总片数、各态计数、完成率、当前活动 PJ、在制分布。
4. 处理混合态：部分 PJ 完成、部分执行、一个失败/暂停时 CJ 是什么态。
5. xUnit 覆盖各种子状态组合下的 CJ 聚合结果与进度计算。

## 二、背景知识（先读，30 分钟）

### 1. 状态只能自下而上聚合（单一事实源）
- 片的真实状态来自执行（E90 位置+工艺），PJ 状态由其片状态与自身状态机决定（W17），CJ 状态由所有 PJ 状态聚合。
- 上层不"命令"下层变成某状态来配合自己；而是下层变化→触发上层重新计算（投影）。这保证上层状态永远是下层事实的真实汇总，不会出现"CJ 说完成、PJ 还在跑"。

### 2. CJ 聚合状态集合（与 PJ 对齐）
- Queued：所有 PJ 都未启动（Queued/未创建）。
- Executing：至少一个 PJ 在执行（Started/Executing/Pausing），且没有需要整体停下的条件。
- Paused：活动 PJ 都到安全点并 Paused（CJ 级联暂停完成，W21）。
- Completed：**所有** PJ Completed 且片全部到输出载具、终验守恒（严格，W17 完成条件在 CJ 层的放大）。
- Aborted/Failed/Cancelled：按级联策略与子状态聚合（W21 细讲，今天先做聚合判定）。

### 3. 混合态聚合规则（核心）
- 全部 Completed → CJ Completed（还要位置/终验）。
- 任一在 Executing/Started，其余 Completed/Queued → CJ Executing（并行/顺序推进中的正常混合）。
- 收到 Pause：活动者进入 Pausing，**全部活动 PJ 都 Paused** 后 CJ 才 Paused（类似 W18 并发栅栏）。
- 任一 PJ Failed/Aborted：CJ 不会假装完成；按策略——可隔离则其余 PJ 继续、CJ 仍 Executing 但标记 Degraded/有失败子作业；需整体停则 CJ 走向 Aborted/Failed（W21 决策）。
- 规则要**确定、无歧义**：给定子状态集合，CJ 状态唯一（固定优先级：终态失败 > 暂停中 > 执行中 > 全完成）。

### 4. 进度汇总
- 片维度：CJ 总片数=各 PJ 去重后的片集合（注意顺序 PJ 是同一片流经多个 PJ，不能重复计数）。
- 完成口径：以"片到达 CJ 最终输出槽"为 CJ 完成片（中间 PJ 完成不等于 CJ 完成该片）。
- 完成率=已到最终输出片数/总片数；另统计在制（在设备内/中间位）、未开始、失败。
- 当前活动 PJ 集合、每片当前所在 PJ/Step/位置（向下钻取）。

### 5. 避免重复计数（顺序 PJ 的关键坑）
- 同一片顺序经过 PJ_A、PJ_B：在 PJ 维度它被两个 PJ 各加工一次（PJ 步骤计数可累加），但在 CJ 片维度它始终是 1 片，CJ 总片数按唯一片 ID 计，完成以最终出 CJ 为准。
- 并行分支汇合时同理，汇合后仍是同一片，不翻倍。

### 6. 聚合触发时机
- 任一子 PJ/片状态变化事件 → CJ 重新聚合（事件驱动，W20 Day03 的事件上送）；聚合结果若改变 CJ 状态，才迁移并发 CJ 事件（状态变化才发事件，避免抖动刷屏）。
