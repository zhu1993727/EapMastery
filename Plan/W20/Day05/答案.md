# W20 · Day05 答案与参考实现

## 一、自测题标准答案
1. **为何自下而上聚合**：片状态、PJ 状态是执行中真实发生的事实，CJ 是对这些事实的整体概括。若上层可以直接设定自己的状态，就可能与下层事实脱节（CJ 说 Executing 但所有 PJ 都没跑，或 CJ 说 Completed 但某 PJ 还在加工），上层状态失去可信度，Host 据此决策会出错。自下而上聚合保证：下层一变、上层按确定规则重算投影，CJ 状态永远是子 PJ/片事实的真实函数，单一事实源在下层，上层只读汇总、不臆造，这和"位置只问 E90、任务状态只问状态机"是同一原则在 CJ 层的延伸。
2. **聚合优先级 / 理由**：给定子状态集合，CJ 状态需唯一，用固定优先级：**失败/中止类终态 > 暂停流程中(Pausing) > 已整体 Paused > 执行中(Executing) > 全完成(Completed) > 全 Queued**。理由：安全/异常最优先（有子作业失败必须先体现，不能被"其他在跑"掩盖）；暂停过渡态要可见（正在走向暂停，尚未到位）；其次才是正常执行；全部完成是最"好"也最靠后的判定（必须没有任何执行/暂停/失败子项才成立）。固定优先级保证任意混合组合结果唯一、可复现、无歧义。
3. **一 Completed 一 Executing 的 CJ 态**：CJ=Executing。因为整个控制作业尚未全部完成，仍有一个 PJ 在加工，属于顺序/并行推进中的正常混合态（前一个 PJ 完工、后一个正在跑，正是顺序流程的常态）。只有所有 PJ 都 Completed 且片到输出、终验通过才 Completed；一个子 PJ 完成只是中间进展，不能让 CJ 提前完成。
4. **级联 Pause 栅栏**：CJ Pause 会把暂停请求下发给所有活动 PJ，每个 PJ 都要让自己的在途片到安全点后才 Paused（W17/W18）。只要还有一个活动 PJ 处于 Executing/Pausing（片在反应中/运动中），整批料就没进入安全可保持状态，此时 CJ 若先 Paused 会造成"上层说停了、下层还在动"的不一致，也无法安全开罩/干预。必须用栅栏等全部活动 PJ 都 Paused、已完成 PJ 保持终态，CJ 才聚合为 Paused（与 W18 并发安全点栅栏同理，范围扩到 PJ）。
5. **一子 PJ Failed，CJ 是否一定 Failed**：不一定，取决于故障范围与级联策略。①可隔离策略：若失败 PJ 的工作可由其他同型资源/重试替代，或该分支失败不影响其他独立分支（并行分支），则其他 PJ 可继续，CJ 保持 Executing 但标记 Degraded/带失败子作业记录，最终可能 Partial；②整体停止策略：若失败 PJ 在关键路径（顺序流程的唯一环节、共用真空/安全系统）、其他 PJ 依赖其输出无法继续，则级联让相关 PJ 到安全点，CJ 转 Failed/Aborted。策略由工艺/Host 决定，但无论哪种，CJ 都绝不能假装 Completed，必须显式携带失败信息与受影响片，最终结局按 W17 三结局严格判定。
6. **顺序/汇合不重复计片**：CJ 片维度按**唯一片 ID**计数，同一片即使顺序经过 PJ_A、PJ_B（被加工两次、PJ 步骤数可累加），在 CJ 总片数里只算 1 片；并行分支汇合后也是同一片、不翻倍。完成口径以"片到达 CJ 最终输出载具声明槽"为准——它在中间 PJ 完成只算"该 PJ 完成、对 CJ 仍是在制"，直到出了 CJ 最后一个环节到 Sink 才计为 CJ 完成片。完成率=到达最终输出的唯一片数/CJ 唯一总片数；在制=在设备内/中间位置的片，未开始=仍在输入载具未动的片。
7. **何时发 CJ 事件 / 不每次都发**：子 PJ/片事件会高频到达（每步、每片都有），若每次都发 CJ 事件会大量重复、Host 被刷屏且多数没带来 CJ 层变化。正确做法是每次子变化触发**重新聚合**，但只有聚合结果（CJ 状态、或 CJ 层进度跨越阈值/当前活动 PJ 切换）真正改变时才迁移并发一个 CJ 事件；纯内部 PJ 细节由 PJ 层事件承载。即"每次都重算、仅变化才上报"，既保证 CJ 状态及时准确，又避免冗余事件，事件仍在状态迁移成功后发、序号单调。

## 二、参考实现（net8.0）

### CJ 状态聚合器
```csharp
namespace EapLab.E94.Aggregate;
public sealed class CjStateAggregator
{
    private readonly bool _failStopsWhole; public CjStateAggregator(bool failStopsWhole=true){_failStopsWhole=failStopsWhole;}

    public CjState Aggregate(IReadOnlyList<JState> pjs,bool allWafersAtOutput,bool degraded=false)
    {
        if(pjs.Count==0)return CjState.Queued;
        // 优先级: 失败/中止 > 暂停过渡 > 全暂停 > 执行 > 全完成 > 全排队
        if(_failStopsWhole && pjs.Any(s=>s is JState.Aborted or JState.Failed))return CjState.Failed;
        if(pjs.Any(s=>s==JState.Pausing))return CjState.Pausing;
        if(pjs.All(s=>s is JState.Paused or JState.Completed)) {
            if(pjs.Any(s=>s==JState.Paused))return CjState.Paused;
        }
        if(pjs.Any(s=>s is JState.Started or JState.Executing or JState.Pausing))
            return degraded?CjState.Executing:CjState.Executing;
        if(pjs.All(s=>s==JState.Completed))
            return allWafersAtOutput?CjState.Completed:CjState.Executing; // PJ全完但片未全到输出, 不算完成
        if(pjs.All(s=>s is JState.Queued))return CjState.Queued;
        return degraded?CjState.Executing:CjState.Executing;
    }
    // 级联暂停栅栏: 所有"活动PJ"都Paused(Completed保持)才算整体Paused
    public bool AllPaused(IReadOnlyList<JState> pjs)=>
        pjs.All(s=>s is JState.Paused or JState.Completed) && pjs.Any(s=>s==JState.Paused);
}
```

### CJ 进度汇总（按唯一片 ID）
```csharp
public sealed class CjProgress
{
    public int TotalUnique,AtOutput,InProcess,NotStarted,Failed;
    public List<string> ActivePjs=new();
    public double Rate=>TotalUnique==0?0:Math.Round(100.0*AtOutput/TotalUnique,1);
    public bool ConservedUnique=>AtOutput+InProcess+NotStarted+Failed==TotalUnique;
}
public sealed class CjProgressCalculator
{
    private readonly SubstrateTracker _t; public CjProgressCalculator(SubstrateTracker t){_t=t;}
    public CjProgress Calc(ControlJobRuntime cj)
    {
        var p=new CjProgress();
        var unique=cj.Def.InputWaferIds;                       // 唯一片ID集合(顺序/汇合不翻倍)
        p.TotalUnique=unique.Count;
        foreach(var w in unique)
        { var loc=_t.LocationOf(w).Key;
          if(IsCjOutput(cj,w,loc))p.AtOutput++;
          else if(IsInputUntouched(cj,w,loc))p.NotStarted++;
          else if(cj.PjOf(w)?.Wafers[w].State==WaferState.Failed)p.Failed++;
          else p.InProcess++; }
        p.ActivePjs=cj.PjRuntime.Where(x=>x.Value.State==JState.Executing).Select(x=>x.Key).ToList();
        return p;
    }
    bool IsCjOutput(ControlJobRuntime cj,string w,string loc)=>cj.IsDeclaredOutput(w,loc);
    bool IsInputUntouched(ControlJobRuntime cj,string w,string loc)=>cj.IsStillAtInput(w,loc);
}
```

### 状态变化才发事件
```csharp
public sealed class CjProjection
{
    private readonly CjStateAggregator _agg=new(); private CjState _last=CjState.Queued;
    public event Action<CjState,CjState>? OnChanged;
    public CjState Recompute(ControlJobRuntime cj,bool allAtOutput)
    { var now=_agg.Aggregate(cj.PjRuntime.Values.Select(p=>p.State).ToList(),allAtOutput,cj.Degraded);
      if(now!=_last){ var old=_last;_last=now;OnChanged?.Invoke(old,now); }   // 仅变化才发
      return now; }
}
```

```csharp
public class CjAggregateTests
{
    static JState[] P(params JState[] s)=>s;
    [Fact] public void 一完成一执行_CJ执行中()
    { var a=new CjStateAggregator();
      Assert.Equal(CjState.Executing,a.Aggregate(P(JState.Completed,JState.Executing),false)); }

      Assert.Equal(CjState.Executing,a.Aggregate(P(JState.Completed,JState.Completed),allWafersAtOutput:false));
      Assert.Equal(CjState.Completed,a.Aggregate(P(JState.Completed,JState.Completed),true)); }

    { var a=new CjStateAggregator();

      Assert.True(a.AllPaused(P(JState.Paused,JState.Completed))); }
```

## 三、三层状态投影（手绘参考）
```
Wafer(位置E90+工艺) ─聚合→ PJ状态(W17状态机, 片全完成+归位才PJ完成)
   多个PJ状态 ─聚合(固定优先级)→ CJ状态
优先级: 失败/中止 > Pausing > 全Paused > Executing > 全Completed(且片到输出) > 全Queued
混合: 一Completed一Executing=Executing; 级联Pause栅栏=全部活动Paused才CJ Paused
失败: 可隔离→继续+Degraded/Partial; 关键路径→整体Failed/Aborted(绝不假完成)
进度: 唯一片ID计数(顺序/汇合不翻倍); 完成=到CJ最终输出; 每次重算仅状态变才发事件
```

## 四、今日易错点
1. 上层直接设定 CJ 状态（必须由 PJ/片事实聚合，单一事实源在下层）。
2. 聚合无固定优先级，混合态结果不确定（失败>暂停>执行>完成，唯一可复现）。
3. 一个 PJ 完成就宣告 CJ 完成（要所有 PJ 完成且片到输出、终验）。
4. 级联 Pause 不等全部活动 PJ 到 Paused（栅栏，否则上层停了下层还在动）。
5. 任一 PJ 失败就机械判 CJ 失败（看故障范围与策略，可隔离则继续+标记，关键路径才整体停）。
6. 顺序/汇合重复计片（按唯一 ID，完成以最终出 CJ 为准）。
7. 每个子事件都发 CJ 事件（每次重算、仅 CJ 层状态变化才上报）。
8. PJ 全完成但片还在中间位就判完成（必须到声明输出槽、设备内空、守恒）。
