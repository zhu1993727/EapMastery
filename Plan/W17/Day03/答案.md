# W17 · Day03 答案与参考实现

## 一、自测题标准答案
1. **三层暂停区别 / 共同点**：任务级=整个 PJ 停下，不再开始新片，当前片走到安全点后全任务停；片级=把当前正在做的这片做完放回（或到该片安全边界），后续片等待，即"做完这片停"；步骤级=当前正在执行的 Step 走到其可停边界再停（不可中断的 Step 必须整步做完）。区别是**停止粒度/停在哪个边界**（当前步、当前片、整个任务）。共同点：都不是"立即冻结物理动作"，而是"发出暂停请求后，把当前不可中断的最小单元推进到最近安全点再真正 Paused"，都要保存恢复点、都要求片处于确定稳定可恢复位置、Resume 都从该边界确定性续跑。
2. **安全点条件 / 举例**：条件①位置确定稳定（片在槽内、臂持片稳定位、模块内安全位，不在运动半程）；②工艺可续（处于可停止且可续/可重做的边界，非不可中断反应过程中）；③资源自洽（不长期占有无法保持的临界资源，或设备有保持能力）；④账目一致（E90 位置与进度一致、守恒成立）。安全点：片间（前片已放回目标槽、后片未取，最干净）、步骤边界（一步完整结束、下一步未开始）。非安全点：机械臂正在两位置间运动、工艺气体/等离子反应进行到一半、阀门/LoadLock 切换半程。
3. **腔中化学反应中为何不是安全点**：化学反应/等离子工艺是连续且对时间-条件敏感的过程，中途停止会破坏工艺结果（参数曲线中断、膜层/刻蚀停在非预期状态、片可能报废），很多过程一旦中断无法从中间精确续做（无法知道"反应到一半"如何接续），还可能因中断气体/温度/真空过程损伤片或腔体。因此这类 Step 必须整体完成到工艺边界才算安全点；暂停请求到达时只能让该 Step 跑完（或按工艺允许的安全中止流程），不能在反应中途冻结并声称可续。
4. **ResumeToken 保存内容 / 为何**：至少含①任务标识与状态（JobId、暂停时 Job 状态）；②进度游标——WaferOrder 中当前片索引、该片当前 StepNo、片内步骤阶段（决定从哪续）；③每片当前实际位置与片状态（与 E90 对齐，Resume 时核对）；④各载具 SlotMap 快照与绑定（防换盒）；⑤资源占用（持片臂、模块、Buffer 暂存片）；⑥已完成片/步骤集合（保证不重做）、未开始队列（保证不漏）；⑦配方与版本、选中腔体、必要工艺上下文；⑧时间戳与暂停原因。因为 Resume 是在新的执行上下文里无缝接续，必须靠这些信息精确重建"做到哪、每片在哪、哪些做过了"，否则会重片、漏片或从错误步骤续。
5. **Resume 如何不重不漏**：以 ResumeToken 的进度游标和已完成集合为准，配合 E90 实际位置：已 Completed 的片/已完成 Step 标记跳过（不重做）；当前未完成片从其记录的安全边界（当前 Step 起点或下一步）继续；未开始片按 WaferOrder 从游标处依次执行；续跑前用 E90 逐片核对位置与 Token 一致（该在槽的在槽、在模块的在模块），并校验总数守恒。这样"做过的不重复、没做的都补上"，即不重片不漏片；本质是幂等的进度恢复——进度以"完成记录+物理位置"双确认，而非简单从头跑。
6. **何时拒绝自动 Resume / 之后**：现场与恢复点不一致时拒绝：载具被更换/卸载（CarrierID 或绑定口对不上）、片被人工动过导致 E90 实际位置与 Token 不符、资源/配方状态变化（模块故障、配方版本被换）、新增 Hold/Alarm、守恒对不上、片归属不明。拒绝后：保持安全状态、不自动续跑，转入对账（W13 P/L/H、W15 Partial 思路）与人工核查，由操作员/工程师确认物理现场、重建一致状态后，再选择 Resume（现场可对齐时）、Rollback（退回源）或按异常流程处理；绝不在现场存疑时凭 Token 想当然续跑。
7. **Paused 为何保护载具不被卸载**：暂停时可能有片已从载具取出、在设备内（臂/模块/Buffer），若此时源或目标载具被卸载取走，这些在途片就失去归属载具——无法放回原槽/目标槽、位置空间的载具位置失效、ResumeToken 与现场脱节，恢复时无槽可归，造成片滞留甚至丢片。因此 Paused 期间要锁定相关载具（禁止 Unload），保证片的来源/去向始终在场，Resume 才能闭环；这与 W14/W15"载具移除前确认无属于它的片在设备内"一致，暂停态尤其要防止现场被外部改变。

## 二、参考实现（net8.0）

### 暂停层级与安全点
```csharp
namespace EapLab.E40.Fsm;
public enum PauseGranularity { JobLevel, WaferLevel, StepLevel }
public enum UnitPhase { BetweenWafers, BetweenSteps, Moving, InModuleProcess, AtStableSlot }
public sealed class SafePointJudge
{
    // 是否安全点: 稳定位置 + 不在运动/反应中
    public bool IsSafePoint(UnitPhase phase) => phase is UnitPhase.BetweenWafers or UnitPhase.BetweenSteps or UnitPhase.AtStableSlot;
    // 给定暂停粒度, 当前单元做完到哪个边界才算到安全点
    public UnitPhase RequiredBoundary(PauseGranularity g)=>g switch
    {
        PauseGranularity.JobLevel=>UnitPhase.BetweenWafers,
        PauseGranularity.WaferLevel=>UnitPhase.BetweenWafers,
        PauseGranularity.StepLevel=>UnitPhase.BetweenSteps,
        _=>UnitPhase.BetweenWafers
    };
}
```

### 暂停/恢复控制器
```csharp
public sealed class PauseResumeController
{
    private readonly JobStateMachine _fsm; private readonly SafePointJudge _judge=new();
    private readonly SubstrateTracker _tracker;
    public PauseRequest? Pending { get; private set; }
    public ResumeToken? Token { get; private set; }
    public PauseResumeController(JobStateMachine fsm,SubstrateTracker t){_fsm=fsm;_tracker=t;}

    // 收到暂停请求: 进Pausing, 记录粒度, 不立即停
    public void RequestPause(PauseGranularity g,string reason)
    { if(_fsm.Try(JobCommand.Pause)) Pending=new PauseRequest(g,reason); }

    // 执行器每到一个单元边界调用: 若满足暂停请求所需边界, 则真正Paused并落Token
    public bool TryReachSafePoint(UnitPhase phase, ResumeProgressView view)
    {
        if(Pending is null) return false;
        if(!_judge.IsSafePoint(phase)) return false;
        var need=_judge.RequiredBoundary(Pending.Granularity);
        bool reached = need==UnitPhase.BetweenSteps ? phase==UnitPhase.BetweenSteps || phase==UnitPhase.BetweenWafers
                                                    : phase==UnitPhase.BetweenWafers;
        if(!reached) return false;
        Token=view.BuildToken(Pending.Reason);
        _fsm.Try(JobEvent.ReachedSafePoint); Pending=null; return true;
    }
    public bool CanResume(ResumeToken tk, Func<ResumeToken,bool> siteConsistent)=>siteConsistent(tk);
    public void Resume(ResumeToken tk,Func<ResumeToken,bool> siteConsistent)
    {
        if(!CanResume(tk,siteConsistent)) throw new InvalidOperationException("现场与恢复点不一致,拒绝自动Resume,转对账/人工");
        if(!_fsm.Try(JobCommand.Resume)) throw new InvalidOperationException("当前非Paused");
        Token=null;
    }
}
public sealed record PauseRequest(PauseGranularity Granularity,string Reason);
```
> `ResumeProgressView.BuildToken` 由执行器提供：汇总当前片游标、每片 E90 实际位置、已完成片/步集合、载具快照，生成 ResumeToken。

### xUnit
```csharp
public class PauseResumeTests
{
    [Fact] public void 运动中请求Pause_到片间才Paused()
    { var f=new JobStateMachine(); var h=new JobCommandHandler(f);
      h.Accept(JobCommand.Start); f.Try(JobEvent.ReadyToExecute);
      var pr=new PauseResumeController(f,null!);
      pr.RequestPause(PauseGranularity.JobLevel,"host");
      Assert.Equal(JState.Pausing,f.State);                 // 运动中先Pausing
      Assert.False(pr.TryReachSafePoint(UnitPhase.InModuleProcess, null!)); // 反应中不是安全点
      Assert.Equal(JState.Pausing,f.State);
      // 到片间安全点
      var ok=pr.TryReachSafePoint(UnitPhase.BetweenWafers,new FakeView());
      Assert.True(ok); Assert.Equal(JState.Paused,f.State); Assert.NotNull(pr.Token);
    }
    [Fact] public void 步骤级暂停_步骤边界即停()
    { var judge=new SafePointJudge();
      Assert.Equal(UnitPhase.BetweenSteps,judge.RequiredBoundary(PauseGranularity.StepLevel));
      Assert.True(judge.IsSafePoint(UnitPhase.BetweenSteps));
      Assert.False(judge.IsSafePoint(UnitPhase.Moving));
    }
    [Fact] public void 现场不一致_拒绝Resume()
    { var f=new JobStateMachine();
      var pr=new PauseResumeController(f,null!);
      var tk=new ResumeToken("PJ",1,1,new(),new(),new(),new(),"r",0);
      Assert.Throws<InvalidOperationException>(()=>pr.Resume(tk,_=>false)); // 现场核对失败
    }
    [Fact] public void 恢复游标_不重不漏()
    { // DoneWafers跳过, 当前片从CurStepNo续, 未开始按序; 断言执行计划=未完成集合
      var tk=new ResumeToken("PJ",curWaferIndex:1,curStepNo:2,
        new(),new HashSet<string>{"W1"},new HashSet<int>{1},new(),"",0);
      var todo=ResumePlan.Build(tk,waferOrder:new[]{"W1","W2","W3"});
      Assert.DoesNotContain("W1",todo.Wafers);              // W1已完成不重做
      Assert.Equal(new[]{"W2","W3"},todo.Wafers);           // 未完成依次
      Assert.Equal(2,todo.CurStartStepOf("W2"));            // 当前片从Step2续
    }
}
```

## 三、暂停/恢复时序（手绘参考）
```
Pause命令 → Executing→Pausing(记粒度) → 继续推进当前不可中断单元
        → 到目标安全点(片间/步边界, 位置确定+工艺可续+账目一致)
        → 落 ResumeToken(游标/每片位置/已完成集合/载具快照) → Paused(5105)
Paused: 锁载具防卸载, 拒新动作, 可查询, 必要工艺保持
Resume → 核对现场(载具/位置/资源/配方/守恒)
        一致: →Executing, 已完成跳过, 当前从边界续, 未开始按序(不重不漏)
        不一致: 拒绝→对账/人工
```

## 四、今日易错点
1. 收到 Pause 立即 Paused（必须到安全点，运动/反应中先 Pausing）。
2. 不区分三层暂停粒度（停在当前步/当前片/任务边界不同）。
3. 把反应中途当安全点（不可中断工艺必须整步到边界）。
4. ResumeToken 不存物理位置/已完成集合（无法不重不漏、无法核对现场）。
5. Resume 从头重跑（要按游标+完成记录+物理位置幂等续跑）。
6. 现场变了还自动 Resume（载具/位置/资源/配方不一致必须拒绝转人工）。
7. Paused 允许卸载载具（在途片会失去归属，必须锁载具）。
8. 暂停期间还接受新取放/加工（除安全恢复外应拒绝）。
