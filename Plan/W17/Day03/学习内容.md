# W17 · Day03（周三）Pause/Resume 深入：暂停层级、安全点与恢复点

> 建议时长：90 分钟。暂停/恢复是 PJ 状态机最容易出错的地方。今天讲清任务级/片级/步骤级暂停的区别、什么是安全点、如何决定"停在哪、从哪续"，并用代码实现 Pausing→安全点→Paused→Resume 的确定性逻辑。

## 一、今日目标
1. 区分三个层级的暂停：任务级、片级（当前片）、步骤级（当前 Step）。
2. 掌握安全点（Safe Point）定义与判定：哪些位置/边界可安全暂停与恢复。
3. 实现 Pausing 过程：记录暂停请求、走到最近安全点、保存恢复点（Resume Token）。
4. 实现 Resume：校验现场一致、从恢复点确定性续跑（不重片、不漏片）。
5. xUnit 覆盖运动中暂停到安全点、片间/步骤边界暂停、Resume 不重不漏、暂停期间保护。

## 二、背景知识（先读，30 分钟）

### 1. 三个暂停层级
- **任务级（Job Pause）**：请求整个 PJ 暂停——不再开始新片，当前片走到安全点后停。
- **片级（Wafer Pause）**：当前片完成到安全点、后续片等待；常用于"做完这片停"。
- **步骤级（Step Pause）**：当前 Step 走到可停边界再停（某些工艺 Step 不可中断，必须整步完成）。
- 本质都是"请求在某个粒度的安全边界停下"，区别是停在当前步、当前片还是整个任务的哪个边界。

### 2. 什么是安全点（Safe Point）
- 安全点=片处于**确定、稳定、可恢复**的位置与工艺边界，满足：
  - 位置确定：片稳定停在槽/臂持片稳定位/模块内安全位，不在运动半程。
  - 工艺可续：当前工艺处于可停止且可续/可重做的边界（不可中途断电的化学反应步骤不能停在中间）。
  - 资源自洽：不持有无法长期保持的资源（如真空/温度临界过程），或设备具备保持能力。
  - 账目一致：E90 位置与进度一致、守恒成立。
- 典型安全点：**片间**（前片已 Place 回槽、后片未 Pick，最干净）、**步骤边界**（一步完整结束、片在稳定位、下一步未开始）。
- 非安全点：机械臂运动中、阀门开关半程、腔体工艺反应进行中。

### 3. Pausing 过程（请求→生效）
```
收到Pause → 状态 Executing→Pausing, 记录暂停请求与目标粒度
执行器继续把"当前不可中断单元"推进到最近安全点:
  Step级: 当前Step做完; 片级: 当前片做完放回; 任务级: 当前安全边界
到达安全点 → 触发 ReachedSafePoint → Paused
保存恢复点 ResumeToken: 当前片序号/当前StepNo/每片位置与状态/资源占用/未开始队列
```

### 4. Resume 恢复
- 前置：现场仍一致（载具未被换、片位置与恢复点一致、资源/配方仍可用、无新增 Hold/故障）。
- 从恢复点确定性续跑：未完成的当前片/步从其安全边界继续，已完成的不重做，未开始的按序进行——**不重片、不漏片**。
- 现场不一致（载具换了、片被动过、位置对不上）→ 拒绝自动 Resume，转对账/人工（W13/W15 原则）。

### 5. 暂停期间的保护
- Paused 时：拒绝新的取放/加工（除安全恢复动作）、保持片当前稳定状态、载具受保护（防止被卸载导致片无归属）、维持必要工艺保持（如真空/温度，按设备能力）。
- 暂停期间 Host 可查询状态/进度（S15F5），但不能越过状态机直接改进度。

### 6. 与 Abort 的边界
- Pause 是"可恢复的停止"，现场保持、还要继续；Abort 是"不再继续"，要走在途片处置。Paused 可被 Abort（Day04）。
- 暂停超时（长期 Paused 导致工艺不可续，如片在腔超时）要转异常处理。
