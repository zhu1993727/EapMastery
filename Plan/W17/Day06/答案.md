# W17 · Day06 答案与参考实现

## 一、自测题标准答案
1. **为何持久化 / 只读物理够不够**：物理位置只告诉你"片现在哪"，无法告诉你"这片做到哪个 Step、是否已加工、用的什么配方版本、哪些片已完成、Job 处于什么阶段"——工艺进度是逻辑信息，传感器读不出来。若不持久化，重启后只能看到片在某槽/腔，却不知它做过没有，整片重做对很多工艺不可逆（重复加工报废），漏做又流向下游。所以必须持久化逻辑进度，再与重启后读到的物理位置交叉对齐：物理回答"在哪"，持久化回答"做到哪"，二者结合才能安全恢复。
2. **事件溯源 / 快照 / 为何结合**：事件溯源只追加不可变状态事件，当前状态=从初始态顺序回放事件的结果，优点是完整审计、可重建任意时刻状态、没有"只存当前态导致中间过程丢失"的问题，但事件很多时从头回放慢；快照在安全点保存聚合的当前状态，恢复时从最近快照开始、只回放其后少量事件，显著加快启动。结合使用：快照解决回放效率、事件保证完整与可追溯，缺一不可（只靠快照丢失两次快照间细节，只靠事件恢复慢且长日志难管理）。
3. **落盘时机 / 原因**：在**状态迁移成功、且到达不可逆点时**先持久化（WAL/先写日志原则）——例如片真正完成一个 Step、片完成归位、Job 状态迁移成功后立即落盘事件/更新快照，保证"已发生的不可逆事实（已加工、已放片）"在掉电后不丢；顺序上先可靠写入进度日志再让流程继续，避免"物理已加工、日志没写"导致重启重复加工。对不能重复的工艺步骤，"加工完成"事实必须在进入下一步前持久化。落盘要原子（追加日志/临时文件替换），防止写一半掉电损坏。
4. **重启五步 / 物理优先**：①加载持久化（最近快照+其后事件）重建逻辑状态与预期进度；②E87 重新扫描 LoadPort 确认载具身份/状态；③E90 用传感器/Mapper/读码重建物理位置空间（每片实际在哪）；④三方比对（逻辑进度位置 vs 物理实际、载具绑定 vs 实际、守恒）分一致/可自动对账/存疑三分支；⑤恢复后重新校验配方模块资源、由 Host 确认续/退/停。"物理优先重建逻辑"是因为掉电期间物理世界可能被改变（人工取片、载具更换），逻辑记录可能过时，而物理片位置是客观事实，逻辑状态必须向可确认的物理现实对齐，而不是让物理迁就内存记忆——与 W13 对账"物理是最终基准"一致。
5. **Executing 为何不直接自动跑 / 正确做法**：重启前 Executing 时片可能停在任意位置（运动中途被断电、片在臂/腔/锁、某 Step 加工到未知程度），这些状态是否安全、工艺能否续做并不确定，直接恢复 Executing 自动跑可能在未知位置取放、重复不可续工艺、碰撞。正确：先进入"恢复挂起（Recovery Pending）"安全态，不自动动作；逐片用 E90 确认实际位置、判断是否在安全点、该 Step 是完成/需重做/可续，现场一致且都在安全边界后，再经显式 Resume 从恢复点续跑；不确定则安全保持人工。
6. **可自动对账 vs 必须人工 / 判据**：可自动对账（以物理刷新逻辑）限于**有无/位置类、身份明确**的差异：逻辑记某片在臂、物理读在某槽且读码身份一致（可补登/修正位置）；载具在位状态、数量类偏差且片 ID 明确。必须人工：**身份或归属存疑**——片 ID 读不到/与记录不符（可能混片）、一片对不上记录、守恒破坏找不到去向、载具被换导致源目无法对应、工艺 Step 是否完成无法判定（可能已反应一半）。判据=能否在不猜测的前提下确定"这片是谁、它确定处于什么可续状态"，能则自动对齐，涉及身份/工艺完整性猜测则人工，绝不自动改身份或假设工艺完成。
7. **Spool / 持久化 / 对账分工**：Spool（W08）管**通信上报**——断线时缓存待发的 S6F11/S5F1/S16F1 报文，重连按序补发确认后删，保证 Host 不丢事件；状态持久化管**设备任务**——Job/片/步进度与恢复点落盘，重启后重建任务状态，保证本机不丢加工进度；重连对账（W13 P/L/H）管**视图一致**——重连后用全量事实校正 Host 镜像账与设备账差异。三者层次不同：Spool 保报文不丢、快照保任务可恢复、对账保 Host 与设备最终一致，互补构成"通信-任务-账"三层可靠。

```csharp
namespace EapLab.E40.Recovery;
public sealed record JobEvent(long Seq,string Kind,string? Wafer,int? Step,JState State,long Ts);
public sealed class JobSnapshot
{
    public string JobId=""; public JState State; public long LastEventSeq;
    public Dictionary<string,(WaferState ws,int step,string loc)> Wafers=new();
    public long Ts;
}
public sealed class EventStore
{
    private readonly List<JobEvent> _log=new(); private long _seq;
    public void Append(string kind,JState st,string? w=null,int? step=null)
    { _log.Add(new JobEvent(++_seq,kind,w,step,st,DateTimeOffset.UtcNow.ToUnixTimeMilliseconds())); } // 先落日志(WAL)
    public IReadOnlyList<JobEvent> After(long seq)=>_log.Where(e=>e.Seq>seq).ToList();
    public IReadOnlyList<JobEvent> All=>_log;
}
```

### 事件溯源回放
```csharp
public sealed class JobRebuilder
{
    // 快照 + 其后事件 重建
    public JobSnapshot Rebuild(JobSnapshot snap,IEnumerable<JobEvent> tail)
    {
        var s=new JobSnapshot{JobId=snap.JobId,State=snap.State,LastEventSeq=snap.LastEventSeq,
            Wafers=new(snap.Wafers),Ts=snap.Ts};
        foreach(var e in tail.OrderBy(e=>e.Seq))
        {
            s.State=e.State; s.LastEventSeq=e.Seq; s.Ts=e.Ts;
            if(e.Wafer is not null)
            {
                var prev=s.Wafers.GetValueOrDefault(e.Wafer,(WaferState.Waiting,0,""));
                var ws = e.Kind switch{"WaferDone"=>WaferState.Completed,"StepEnter"=>WaferState.InProcess,_=>prev.ws};
                s.Wafers[e.Wafer]=(ws,e.Step??prev.step,prev.loc);
            }
        }
        return s;
    }
}
```

### 重启恢复器（物理优先三分支）
```csharp
public enum RecoveryDecision { ResumeState, ReconcileThenResume, SafeHoldForManual }
public sealed record PhysicalView(Dictionary<string,string> WaferLocation,Dictionary<int,string> CarrierOnPort);
public sealed record RecoveryResult(RecoveryDecision Decision,JState RecoveredState,List<string> Notes);

public sealed class RestartRecovery
{
    public RecoveryResult Recover(JobSnapshot logical, PhysicalView physical,
        Func<(string wafer,string logicalLoc,string physicalLoc),bool> identityOk)
    {
        var notes=new List<string>();
        // 终态不复活
        if(logical.State is JState.Completed or JState.Cancelled or JState.Aborted or JState.Failed)
            return new(RecoveryDecision.ResumeState,logical.State,new(){"终态保持,不自动复活"});

        bool needManual=false, reconcile=false;
        foreach(var (w,prog) in logical.Wafers)
        {
            if(!physical.WaferLocation.TryGetValue(w,out var phys))
            { notes.Add($"{w} 物理找不到"); needManual=true; continue; }
            if(prog.loc!=phys)
            {   // 位置不一致: 身份明确可对账, 身份存疑人工
                if(identityOk((w,prog.loc,phys))) { notes.Add($"{w} 位置以物理为准 {prog.loc}->{phys}"); reconcile=true; }
                else { notes.Add($"{w} 身份/归属存疑"); needManual=true; }
            }
        }
        if(needManual) return new(RecoveryDecision.SafeHoldForManual,JState.Paused,notes); // 安全保持
        // Executing 不自动跑, 进入安全挂起待显式Resume; Paused 保持
        var state = logical.State==JState.Executing ? JState.Paused : logical.State; // 恢复挂起用Paused表达待续
        return new(reconcile?RecoveryDecision.ReconcileThenResume:RecoveryDecision.ResumeState,state,notes);
    }
}
```

### xUnit
```csharp
public class RecoveryTests
{
    static JobSnapshot Snap(JState st,params (string,WaferState,int,string)[] w)=>new(){
        JobId="PJ",State=st,
        Wafers=w.ToDictionary(x=>x.Item1,x=>(x.Item2,x.Item3,x.Item4))};
    static PhysicalView Phys(params (string,string)[] w)=>new(w.ToDictionary(x=>x.Item1,x=>x.Item2),new());

    [Fact] public void 快照加事件_重建到最新()
    { var snap=Snap(JState.Executing,("W1",WaferState.InProcess,1,"Internal:Chamber:C1"));
      var tail=new List<JobEvent>{new(2,"StepEnter",  "W1",2,JState.Executing,2),
                                  new(3,"WaferDone",  "W1",2,JState.Executing,3)};
      var r=new JobRebuilder().Rebuild(snap,tail);
      Assert.Equal(WaferState.Completed,r.Wafers["W1"].ws); Assert.Equal(2,r.LastEventSeq); }

    [Fact] public void 一致现场_Executing恢复为安全挂起_不自动跑()
    { var s=Snap(JState.Executing,("W1",WaferState.InProcess,1,"Internal:Robot:R1"));
      var p=Phys(("W1","Internal:Robot:R1"));
      var r=new RestartRecovery().Recover(s,p,_=>true);
      Assert.Equal(RecoveryDecision.ResumeState,r.Decision);
      Assert.Equal(JState.Paused,r.RecoveredState); }   // 待显式Resume

    [Fact] public void 位置不符身份明确_对账后续跑()
    { var s=Snap(JState.Paused,("W1",WaferState.StepDone,1,"Internal:Robot:R1"));
      var p=Phys(("W1","Carrier:A:S1"));
      var r=new RestartRecovery().Recover(s,p,_=>true);
      Assert.Equal(RecoveryDecision.ReconcileThenResume,r.Decision);
      Assert.Contains(r.Notes,n=>n.Contains("以物理为准")); }

    [Fact] public void 身份存疑_安全保持人工()
    { var s=Snap(JState.Paused,("W1",WaferState.InProcess,1,"Internal:Chamber:C1"));
      var p=Phys(("W1","Carrier:B:S9"));
      var r=new RestartRecovery().Recover(s,p,_=>false);
      Assert.Equal(RecoveryDecision.SafeHoldForManual,r.Decision); }

    [Fact] public void Completed终态_不复活()
    { var s=Snap(JState.Completed); var p=Phys();
      var r=new RestartRecovery().Recover(s,p,_=>true);
      Assert.Equal(JState.Completed,r.RecoveredState); }

    [Fact] public void 恢复幂等_多次结果一致()
    { var s=Snap(JState.Paused,("W1",WaferState.StepDone,1,"Carrier:A:S1"));
      var p=Phys(("W1","Carrier:A:S1")); var rec=new RestartRecovery();
      var a=rec.Recover(s,p,_=>true); var b=rec.Recover(s,p,_=>true);
      Assert.Equal(a.Decision,b.Decision); Assert.Equal(a.RecoveredState,b.RecoveredState); }
}
```

## 三、重启恢复流程（手绘参考）
```
掉电/重启
 →加载 快照+事件日志 重建逻辑(做到哪)
 →E87扫口确认载具 / E90传感器+Mapper+读码重建物理(片在哪)
 →三方比对:
    一致: Completed保持终态不重做; Paused保持; Executing→安全挂起待显式Resume
    位置类差异且身份明确: 以物理为准对账后续跑
    身份/工艺完整性存疑: 安全保持+人工(不猜身份/不假定工艺完成)
 →重校配方/模块/资源 → Host确认 续跑(新PJ/Resume)/Rollback/停
配套: WAL先落进度日志; 快照加速; Spool补上报; 重连全量对账; 全程审计
```

## 四、今日易错点
1. 以为读物理位置就知道进度（物理只知"在哪"，持久化才知"做到哪"，两者结合）。
2. 只存当前态不用事件溯源（丢失过程、无法审计与任意时刻重建）。
3. 有事件不做快照（长日志回放慢，要快照+尾部事件）。
4. 落盘晚于不可逆动作（已加工没记日志会重做，要 WAL 先记）。
5. 重启把 Executing 直接自动跑（片可能在非安全点，先安全挂起、确认再 Resume）。
6. 身份存疑还自动改账续跑（身份/工艺不确定必须人工）。
7. 终态任务重启被"复活"（Completed/Aborted 等保持终态）。
8. 混淆 Spool（报文）/持久化（任务进度）/对账（Host 视图）三层职责。
9. 恢复不幂等、无审计（多次恢复必须同结果、全程留痕）。
