# W17 · Day07 答案

## 一、排障推演参考
1. **Host 发了 Pause 设备还在加工**：这通常不是 bug，而是"受理≠生效/安全点"机制。排查：①确认设备是否先进入 Pausing（已受理、正在走到安全点）而非直接 Paused——当前片可能正在不可中断的腔体工艺中，必须等该 Step 到边界才停，期间仍在加工是预期行为；②查当前片所处阶段是否为反应中途（非安全点），到步骤边界/片间才会 ReachedSafePoint→Paused；③若长时间停在 Pausing，查安全点是否永远到不了（Step 完成信号丢失、机械臂卡住），这才是故障。向 Host 解释：Pause 应答只表受理，真正 Paused 以 5105 状态事件为准。若要求"立即停"，那是 Abort/安全停止语义，且仍需让当前工艺到可安全中止点，不能硬切反应。
2. **重启后 PJ 状态与现场对不上**：走重启恢复流程定位。①加载快照+事件重建逻辑进度；②E87 重新确认口上载具是否被换、E90 用传感器/Mapper/读码重建每片物理位置；③逐片比对逻辑进度位置与物理实际：位置类差异且身份明确→以物理为准对账；身份读不到/不符、守恒破坏、工艺步是否完成不明→安全保持转人工，不猜；④常见根因：掉电期间人工动过片/换过盒、上次进度日志没在不可逆点落盘（WAL 缺失）、快照过旧且事件丢失。处置：能自动对齐则重建到安全挂起态由 Host 决定续/退，存疑则人工核对物理片刻码与工艺状态后再恢复，绝不用内存记忆覆盖物理事实。

## 二、综合自测卷（8 题）标准答案
1. **完整状态机与 Guard**：Queued —Start(外部命令，开工双校验 Guard)→ Started —ReadyToExecute(内部事件)→ Executing；Executing —Pause(命令)→ Pausing —ReachedSafePoint(内部事件)→ Paused —Resume(命令)→ Executing；Executing —WaferAllDone(内部事件，聚合 Guard：全片完成+归位+终验+无异常+数据全)→ Completed(终)；Queued/Started —Cancel(命令，Guard 无片受影响)→ Cancelled(终)；Executing/Pausing/Paused —Abort→ Aborted(终)；Executing —Fault→ Failed(终)；四终态无出边；其余组合非法、零副作用拒绝回 IllegalState。
2. **F10 不代表生效 / Pause、Completed 例**：S15F10 只表请求被受理，状态真正改变要等 Guard 与内部事实。Pause：受理后先进 Pausing，要等当前不可中断单元走到安全点、产生 ReachedSafePoint 才 Paused（发 5105），受理时仍可能在加工。Completed：不存在"完成命令"直接生效，必须等最后一片归位、终验通过产生 WaferAllDone 且聚合 Guard 满足才迁 Completed（5104），片没归位即使流程走完也不完成。两者最终状态都以迁移后的 S16 事件为准。
3. **安全点四条件 / Resume 不重不漏与拒绝条件**：安全点=位置确定稳定、工艺可续（在可停可续边界）、资源自洽、账目（位置与进度）一致。Resume 靠 ResumeToken 的进度游标+已完成片/步集合，配合 E90 实际位置：已完成跳过、当前片从当前 Step 安全边界续、未开始按序，续前逐片核对位置与守恒，做到不重不漏。拒绝条件：载具被换/卸载、片被动过致位置不符、模块故障/配方被换、新增 Hold/Alarm、守恒或身份存疑——拒绝自动续，转对账/人工。
4. **Cancel vs Abort / 三分类片**：Cancel 前提=无片受影响（都还 Waiting、没离槽），后果=干净撤回、释放预留、Cancelled 终态、无需善后；Abort 用于执行中，后果=停调度、当前单元到安全点、分类处置在途片、释放可释放资源、Aborted 终态。三分类：已完成片保持不动（有效成果）；在途/在腔片先到安全点再退回源/Buffer/安全保持并记实际位置；未开始片原地不动；全程经 E90 守守恒。Aborted 不能 Resume，只能新建续跑 PJ/Rollback/人工。
5. **Completed 五条件 / 片在臂上 / Partial**：五条件=每片走完所有 Step、每片在声明目标槽且设备内空、E90 终验逐片 ID 对且守恒、无 Failed/阻断 Hold/Alarm、数据完整。片在机械臂上不满足"物理归位+设备内无残留（LeftInside）"，聚合 Guard 为假，不能 Completed，必须放回目标槽。Partial 要结构化列 CompletedList/InFlightList/FailedList 且每片带实际位置与当前 Step、分类守恒，结局显式标 PartialCompleted（需授权）或随 Aborted/Failed，绝不能标 Completed 隐藏缺口，并把缺口报给 MES。
6. **事件溯源+快照 / WAL 时机**：只追加不可变状态事件，当前状态由初始回放事件得到（完整可审计、可重建任意时刻）；快照在安全点存聚合当前态，恢复用"最近快照+其后事件"快速重建。落盘采用 WAL 先行：在状态迁移成功、尤其片完成不可重复工艺步/归位等不可逆点，先可靠追加进度日志再继续后续动作，保证掉电后"已加工"事实不丢、不会重启重做；原子写入防半截损坏。
7. **重启三分支 / Executing 先挂起**：一致→恢复相应状态（Completed 终态保持、Paused 保持待续）；位置类差异且身份明确→以物理为准自动对账后续跑；身份/归属/工艺完整性存疑→安全保持人工。Executing 重启后片可能停在运动中途/腔/臂等非安全点、工艺步完成程度未知，直接自动跑会在未知位置动作或重做不可续工艺，所以先进入恢复挂起（安全态、不自动动作），逐片确认实际位置与安全边界、现场一致后再显式 Resume。
8. **多腔并行新要求**：资源调度上，把每腔/臂/锁/缓冲建成有限容量资源，动作原子占用、冲突串行、固定申请顺序防死锁，并做腔体分配/负载均衡/流水线重叠；完成守卫上，Job 单一 Executing 但多片并发独立推进，Completed 必须等**所有并发片**都完成归位（不能只等某条流水线）；Pause/Abort 上，要让所有正在并发的执行单元（各腔各臂上的片）都到达各自安全点/完成三分类处置后才整体 Paused/Aborted，不能只停一个而让其他并发片继续；不变式上并发每步仍守唯一/容量/守恒，资源层保证不把两片送进同一腔。

## 三、W18 预热思考题参考
1. **两片谁进 C1/C2**：依据=腔体可用性（未故障、空闲、能力匹配）优先，其次负载均衡（选排队少/最早空闲的腔）、腔体亲和（同批/同配方尽量同腔以减少配方切换、保证一致性）、腔体健康/匹配历史（问题腔降权），并保证确定性（同条件同结果，便于复现）；都忙则在逻辑时钟队列等待，资源表原子分配，避免两片争同一腔。
2. **流水线重叠要额外保证什么**：搬运与加工重叠时，状态机仍要保证片位置唯一（一片任一时刻只在一个资源上）、资源容量（一腔一次一片、臂不冲突）、全局守恒；资源占用/释放原子且固定顺序防死锁；"片在腔加工"和"臂给另一腔上片"资源不相交才允许同拍并行；每片进度独立、事件在各自迁移成功后发、顺序可追溯；完成守卫统计全部并发片。即并行只发生在资源不相交的动作之间，位置不变式与单一状态权威不因并行放松。
3. **并发 Pause 等哪些单元**：要等当前所有正在执行的并发单元分别到安全点——各机械臂完成当前取放到稳定位、各腔里的片走到其 Step 可停边界（不可中断工艺步跑完）、LoadLock/Buffer 里的片到稳定状态；当且仅当所有在途并发片都处于安全点、资源处于可保持状态、位置与进度账目一致，才整体进入 Paused 并落包含全部并发片位置的 ResumeToken。任一单元未到安全点，任务保持 Pausing。

## 五、W17 全周易错点总清单
1. 收到 Pause 立即 Paused（经 Pausing 到安全点才生效，受理≠生效）。
2. 以 S15F10 当状态（以迁移后 S16 为准，先迁移后事件）。
3. 外部命令与内部事件不分离（无法表达异步生效）。
4. Guard 为假仍迁移（零副作用拒绝、回 IllegalState）。
5. Cancel/Abort 混用，已加工还 Cancel（Cancel 要求无片受影响）。
6. 硬切反应中途（先到安全点/工艺安全中止边界）。
7. Abort 不分类、绕过 E90 善后（三分类、位置层守守恒）。
8. Aborted 直接 Resume（终态，新建 PJ/Rollback/人工）。
9. 循环跑完即 Completed（严格五条件，片在臂上也不行）。
10. Partial 冒充 Completed、不带实际位置（显式缺口+每片位置+守恒，报 MES）。
11. 只存当前态、落盘晚于不可逆动作（事件溯源+快照、WAL 先行）。
12. 重启 Executing 直接自动跑（先安全挂起、物理优先、身份存疑人工、终态不复活）。
