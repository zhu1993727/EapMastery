# W17 · Day04 答案与参考实现

## 一、自测题标准答案
1. **本质区别 / 可触发状态**：本质区别在"物理世界是否已被改变、任务是否还要继续"。Cancel 是**未加工的干净撤回**——没有任何片被取动/加工，现场等同未下发，只释放预留资源即可，可从 Queued（或 Started 但无片离槽）触发；Abort 是**执行中不再继续**——已有片被取走/加工/在途，必须面对和处置这些片，可从 Executing/Pausing/Paused 触发。Cancel 后无需恢复（本来就没做），Abort 后要处理在途片并以新任务/回退/人工恢复，二者触发前提、后果、恢复路径完全不同。
2. **有片 InProcess 发 Cancel 的响应**：状态机 Cancel Guard（NothingTouched）为假，**拒绝 Cancel**（回 IllegalState，状态不变、零副作用），并明确提示 Host：任务已开始加工、不能取消，如需停止应发 Abort。因为片已离开源槽/在加工，物理现实已改变，无法回到"什么都没发生"，强行按 Cancel 处理会留下无主片和账实不符。这是用 Guard 从机制上阻止错误停止方式。
3. **Abort 三分类处置 / 完成片为何不回退**：①已完成片（已放目标槽、位置确定、工艺有效）——保持不动，登记为有效成果；②在途/在腔片（在臂/模块/Buffer，未归位）——先把当前不可中断单元走到安全点，再按策略退回源槽、移到安全 Buffer 或安全保持，逐片记录实际位置与进度；③未开始片（仍在源槽 Waiting）——原地不动。已完成片默认不回退，因为它们已经完整走完工艺、质量有效，回退是无意义的额外搬运，还增加风险；只有当工艺要求"整批同进同出、部分完成即整批废弃/返工"时才按专门策略回退，这属于显式工艺决策而非默认动作。
4. **反应中途为何不硬切 / 当前 Step 处理**：化学反应/等离子等工艺对连续过程敏感，硬切（立即断工艺/动作）会让片停在不可知、不可续的中间状态，可能报废片、损伤腔体，也无法确定片当前工艺进度。Abort 流程对当前 Step 的处理是：**不硬切，先让当前不可中断单元走到最近安全点**（该步完整结束或工艺允许的安全中止边界），片到稳定位置后再中止后续调度；若工艺本身支持安全中止（可受控停下并标记该步状态），则按其安全中止流程，同时记录该步是"完成/部分/需返工"，供恢复决策。
5. **Aborted 为何终态 / 想继续怎么办**：Abort 意味着原任务的执行上下文和正常序列已被打破（部分片完成、部分在途、资源已释放），不再具备"沿原任务无缝继续"的一致前提，若允许直接 Resume 回 Executing，会在一个已经被打乱的现场按旧计划继续，极易重片/漏片/错放。所以设为终态。想继续：①**新建续跑 PJ**——以 Abort 现场快照为依据，把未完成片的源改成其当前实际位置、排除已完成片，经正常校验后作为新任务执行；②**Rollback**——把已搬动的片经 E90 安全退回原始源槽、恢复布局后重做；③现场不确定则人工。三种都基于真实现场重新建立一致前提，而不是在终态上硬续。
6. **Abort 现场快照内容**：①每片分类（完成/在途/未开始）及其**实际位置**（与 E90 对齐）、当前 StepNo 与工艺状态、是否需返工；②各载具当前 SlotMap 与源目映射、载具绑定口；③设备内位置占用（臂/模块/Buffer 里有谁）；④全局守恒数与基线；⑤已发事件/轨迹、暂停或中止原因码、时间戳；⑥资源占用（哪些模块/臂被占、哪些已释放）、必要工艺保持状态。快照是新建续跑 PJ、Rollback、人工处置和追溯的唯一依据，必须在中止处置前冻结、不随后续动作污染。
7. **Pause vs Abort 对比**：意图上 Pause 是暂时停、还要继续，Abort 是不再继续本任务；现场上 Pause 完整保持（含资源预约、锁载具），Abort 冻结后还要分类处置在途片、释放可释放资源；后续上 Paused 可 Resume 直接回 Executing 从恢复点续，Aborted 是终态、只能新建 PJ/Rollback/人工；资源上 Pause 保持预约，Abort 释放可释放资源（仅保留必要安全保持）；状态上 Paused 非终态、Aborted 终态。一句话：Pause 是"暂停键、可播放"，Abort 是"终止键、要善后"。

### Abort 处理器
```csharp
public sealed class AbortHandler
{
    private readonly SubstrateTracker _tracker;
    public AbortHandler(SubstrateTracker t){_tracker=t;}

    public AbortSnapshot Abort(ProcessJob job,string reason,
        Func<string,SlotRef?> chooseSafeReturn)   // 在途片: 返回退回目标槽(源),null=安全保持/Buffer
    {
        // 1 立即停止后续调度由调用方(执行器主循环)检查 job.Aborted 跳出; 此处做现场与处置
        var snap=new AbortSnapshot{Reason=reason};
        foreach(var wp in job.Wafers.Values)
        {
            var loc=_tracker.LocationOf(wp.WaferId).Key;
            WaferClassAtAbort cls = wp.State switch
            {
                WaferState.Completed => WaferClassAtAbort.Completed,
                WaferState.Waiting   => WaferClassAtAbort.NotStarted,
                _                    => WaferClassAtAbort.InFlight
            };
            if(cls==WaferClassAtAbort.InFlight)
            {   // 2 当前单元已由执行器走到安全点后才进入这里; 3 处置在途片
                var back=chooseSafeReturn(wp.WaferId);
                if(back is not null && loc.StartsWith("Internal:Robot"))
                {   // 从臂安全退回源槽(经E90,守不变式)
                    _tracker.Place(wp.WaferId,"Robot:R1",back.Carrier,back.Slot,WaferState.Waiting);
                    loc=_tracker.LocationOf(wp.WaferId).Key;
                }
                // 否则安全保持在当前稳定位/Buffer, 交人工/续跑PJ
            }
            // Completed/NotStarted 保持不动
            snap.Wafers.Add((wp.WaferId,cls,loc,wp.CurStepNo));
        }
        _tracker.Snapshot(); // 处置后守恒断言
        return snap;
    }

    // 基于快照新建续跑PJ(示意): 仅未完成片, 源改为当前实际位置(若是载具槽)
    public ProcessJobDefinition BuildResumePj(AbortSnapshot snap,ProcessJobDefinition old,string newJobId)
    {
        var nd=new ProcessJobDefinition(newJobId){LotId=old.LotId};
        foreach(var (w,c,loc,step) in snap.Wafers)
        { if(c==WaferClassAtAbort.Completed) continue;       // 已完成不重做
          var oldMap=old.Maps.First(m=>m.WaferId==w);
          // 若当前在载具槽则以其为新源, 在内部位置则需先取回(由执行器安全序列处理)
          nd.AddMap(new WaferMap(w,ParseCarrierSlot(loc),oldMap.Dst)); }
        return nd;
    }
    static SlotRef ParseCarrierSlot(string loc)=> /* 解析 "Carrier:A:S3" → new SlotRef("A",3) */ new("A",1);
}
```

### Cancel Guard（沿用 Day02 状态机）
```csharp
// NothingTouched = 所有片仍Waiting(无片离槽)
bool NothingTouched(ProcessJob j)=>j.Wafers.Values.All(w=>w.State==WaferState.Waiting);
// 状态机: Queued/Started --Cancel(Guard NothingTouched)--> Cancelled(终态)
//        Executing/...   --Abort--> Aborted(终态, 走AbortHandler)
```

### xUnit
```csharp
public class CancelAbortTests
{
    [Fact] public void 未动工_Cancel成功_终态()
    { var f=StartedJob(out _); f.NothingTouched=()=>true;
      Assert.True(f.Try(JobCommand.Cancel)); Assert.Equal(JState.Cancelled,f.State);
      Assert.False(f.Try(JobCommand.Start)); // 终态不可再Start
    }
    [Fact] public void 已加工_Cancel被拒_应Abort()
    { var f=StartedJob(out _); f.NothingTouched=()=>false;
      Assert.False(f.Try(JobCommand.Cancel)); Assert.Equal(JState.Executing,f.State);
      Assert.True(f.Try(JobCommand.Abort)); Assert.Equal(JState.Aborted,f.State);
    }
    [Fact] public void Abort_三类片分类_在途退回_守恒()
    { var(t,job)=RunningJob();   // W1已完成到B:S1, W2在臂(InFlight), W3未开始
      var handler=new AbortHandler(t);
      var snap=handler.Abort(job,"host stop",w=>job.Wafers[w].Src); // 在途退回源
      Assert.Contains(snap.Wafers,x=>x.Class==WaferClassAtAbort.Completed);
      var inflight=snap.Wafers.First(x=>x.Wafer=="W2");
      Assert.DoesNotContain("Robot",inflight.Location);   // 已退回源槽
      t.Snapshot();                                       // 守恒
    }
    [Fact] public void Aborted终态_不能Resume_需新PJ()
    { var f=StartedJob(out _); f.Try(JobCommand.Abort);
      Assert.False(f.Try(JobCommand.Resume)); Assert.Equal(JState.Aborted,f.State); }
    static JobStateMachine StartedJob(out object _){var f=new JobStateMachine();f.Try(JobCommand.Start);f.Try(JobEvent.ReadyToExecute);_=null!;return f;}
    // RunningJob 构造: 复用W16实验台让W1完成/W2在臂, 略
}
```

## 三、Abort 流程（手绘参考）
```
Abort命令/不可继续 → 停调度(不开始新片/新Step)
  → 当前不可中断Step走到安全点(不硬切反应)
  → 冻结现场快照(每片分类+实际位置+Step+SlotMap+守恒+轨迹+原因)
  → 在途片: 能退源→经E90退回; 不能→Buffer/安全保持; 完成片/未开始片不动
  → 每步守恒断言 → 释放可释放资源/保留必要保持 → 锁载具
  → Aborted终态 + 5106(原因+现场摘要)
恢复(非Resume): 新建续跑PJ(未完成片源=当前实际位置) / Rollback退回 / 人工
```

## 四、今日易错点
1. Cancel/Abort 混用，已加工还允许 Cancel（Guard 阻止，应 Abort）。
2. Abort 硬切化学反应/运动（要先到安全点，片到稳定位）。
3. 中止时不分类，把已完成片也退回或把在途片当未开始（三类分别处置）。
4. Abort 过程绕过 E90 直接改位置（必须经位置层守守恒，防止善后中再制造丢叠片）。
5. 让 Aborted 能直接 Resume（终态，只能新建 PJ/Rollback/人工）。
6. 不冻结现场快照就处置（后续续跑/追溯失去依据）。
7. 中止后释放载具锁（在途片可能未归位，必须锁载具）。
8. 分不清 Pause（可续、保持预约）与 Abort（终止、释放资源、要善后）。
