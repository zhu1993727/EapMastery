## 二、背景知识（先读，30 分钟）

### 1. Cancel（取消）精确语义
- 仅允许在**没有任何片被加工影响**时：Queued，或 Started 但尚无片离开源槽（无 InProcess）。
- 后果：释放预留资源（模块/臂预约）、任务进 Cancelled 终态、现场等同未执行、无在途片需要处置。
- Guard：NothingTouched（Day02）；一旦有片 InProcess，Cancel 被拒，应改用 Abort。
- Cancelled 是终态，不能再 Start/Resume。

### 2. Abort（中止）精确语义
- 用于执行中（Executing/Pausing/Paused）需要**不再继续**的场景：Host 主动中止、或判断无法安全继续。
- 与 Failed 区别：Abort 偏主动决定停止；Failed 偏故障导致无法继续（很多实现合并为"异常终止"，但原因码区分）。
- Abort 是终态，**不能像 Pause 那样 Resume 回 Executing**；要继续需新建 PJ 或走专门恢复流程（这是与 Pause 的关键区别）。

### 3. Abort 时三类片分类处置（核心）
- **已完成片（Completed）**：已放到目标槽、位置确定——保持不动，登记其已完成状态与位置（它们是有效成果，不回退，除非工艺要求整批废弃）。
- **在途/在腔片（InProcess/StepDone 未归位）**：位置在臂/模块/Buffer——
  - 优先安全完成当前不可中断单元到安全点（不强行中断化学反应）；
  - 然后按策略：退回源槽（源在场且安全）、移到安全 Buffer/等待位、或安全保持在当前稳定位；
  - 逐片记录实际位置与工艺进度，交后续恢复/人工。
- **未开始片（Waiting）**：仍在源槽未动——保持在源槽不动。
- 处置后保证三不变式（唯一/容量/守恒），绝不在 Abort 过程中制造丢片/叠片。

### 4. Abort 标准流程
```
1 状态机迁 Aborting(内部过渡)/Aborted, 立即停止调度新片/新Step
2 当前不可中断单元走到安全点(不硬切工艺)
3 冻结现场快照: 每片分类(完成/在途/未开始)+实际位置+Step+事件轨迹+SlotMap+守恒
4 在途片按策略处置(退源/Buffer/安全保持), 每步经E90并守恒
5 释放可释放资源(臂/模块预约), 保留必要保持(真空等,按能力)
6 进入 Aborted 终态, 发5106(带原因码与现场摘要), 锁相关载具待处理
```

### 5. 中止后的恢复路径（区别于 Pause.Resume）
- Aborted 是终态，不直接续跑；恢复方式：
  - **新建续跑 PJ**：基于现场快照，为未完成片生成新 PJ（源位置改为其当前实际位置），经正常校验后执行。
  - **Rollback**：把已搬片退回原始源槽，恢复布局（经 E90、守恒）。
  - **人工处置**：归属/工艺不确定时安全保持、交现场。
- 选择条件同 W15：位置确定且可安全动→自动退/续；不确定→人工。

### 6. 与 Pause 的本质对比（务必讲清）
| | Pause | Abort |
|---|---|---|
| 意图 | 暂时停、还要继续 | 不再继续本任务 |
| 现场 | 完整保持、锁载具 | 冻结+分类处置在途片 |
| 后续 | Resume 回 Executing | 终态；新建PJ/Rollback/人工 |
| 资源 | 保持预约 | 释放可释放资源 |
| 状态 | Paused（非终态） | Aborted（终态） |
