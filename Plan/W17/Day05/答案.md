# W17 · Day05 答案与参考实现

## 一、自测题标准答案
1. **五充要条件 / 循环跑完不算完成**：①片进度——WaferMap 每片都 Completed（走完所有 Step）；②物理归位——每片 E90 实际位置==声明目标槽，设备内/Buffer 全空；③终验通过——逐片 ID 对、全局守恒、无 Missing/Double/Misplaced/WrongId；④无未决异常——无 Failed 片、无阻断 Hold/未确认 Alarm；⑤数据完整——每片每步事件与采集数据、配方版本记录齐全。"循环跑完"只代表执行器把动作序列走了一遍，是过程行为；任务完成是**结果状态**，可能循环走完却有片没归位、终验不过、数据缺失，所以必须由聚合守卫按结果判定，不能以"最后一个动作执行过"作为完成依据，否则就是假完成。
2. **片在臂上没放回能 Completed 吗**：不能。被条件②物理归位和③终验（LeftInside 检测）拦住——该片 WaferState 即便工艺做完，E90 位置在 Internal:Robot 而非目标槽、设备内位置非空，AllDoneGuard 为假，WaferAllDone 事件无法把 Job 迁到 Completed，Job 保持 Executing 挂起并提示有片滞留设备内，直到把片放回目标槽、设备内清空、终验通过才完成。这正是 W14"守恒没丢≠归位"在任务级的体现。
3. **三维统计 / 各回答什么**：①Wafer 维度（Total/Completed/InProcess/Waiting/Failed 数量与占比）回答"多少片做完/在做/没做/失败，整体进度百分比"；②Step 维度（片×步骤总实例数、完成数、完成率）回答"工艺步骤推进到什么程度、卡在哪个 Step"；③位置维度（在目标槽数、设备内数、仍在源槽数）回答"片物理上都在哪、多少已归位、多少还在设备内/未动"。片维度看任务进度、步维度看工艺进度、位置维度看物理归位，三者交叉才能完整刻画"完成度"，任一维度都不足以单独判定。
4. **Partial 清单 / 为何带实际位置**：CompletedList（成功片+最终目标槽，有效成果）、InFlight/PendingList（未完成片+当前 Step）、FailedList（失败片+错误码），并且每一类都要带**每片实际位置**，最后做守恒核对（完成+在途+未开始+失败=总数）。必须带实际位置，因为部分完成后要续跑/回退/人工，必须知道每片物理上到底在哪（目标槽/源槽/臂/腔/Buffer）才能安全决定下一步；只报"成功/失败"而无位置，恢复时无法取片、无法核对、可能重复加工或找不到片。
5. **Partial 为何不能静默 Completed / 默认策略**：标 Completed 等于向 Host/MES 宣告"这批片全部按要求加工并归位"，而 Partial 实际有片未完成/失败/未归位，静默标完成会让 MES 误判整批完工、让未加工或不合格片流入下游，造成质量事故且难以追溯。默认策略是**不允许静默部分完成**：必须显式区分结局（Aborted/Failed 带 Partial 明细，或经 Host 明确策略授权才走"部分完成"终态并显式列出缺口），把"哪些成了、哪些没成、缺口片在哪"如实上报，由 Host 决定后续。
6. **三结局 / 为何集中评估**：AllCompleted（五条件全满足→Completed 正常终态）；PartialCompleted（Host 策略明确允许部分交付时，以部分完成结束并显式列未完成片，否则不走此结局）；Aborted/Failed（中止/故障结束，带完整现场和 Partial 明细，供新 PJ/Rollback/人工）。要集中在一个结果评估器统一判定，因为完成/部分/失败的口径涉及片进度、位置、终验、异常、数据多方面，分散在执行流程各处判断容易口径不一致（一处认为完成、一处发现没归位），集中评估保证同一时刻用同一套规则得出唯一结局，且便于测试和审计。
7. **MES 为何要知道缺口**：MES 管理批次流转与在制品，它要据此决定：哪些片已完工可流入下道工序、哪些未完成要重新派工/续跑、哪些失败要返工或隔离、整批是否可关闭、库存/在制数量如何更新。若不知道 Partial 缺口，MES 会按整批完工推进，导致未加工/不合格片混入下游、批次账目与实物不符、漏做工艺；显式缺口让 MES 能精确跟踪每片去向、安排补救，保证批次级账实一致。

### 完成度统计
```csharp
namespace EapLab.E40.Fsm;
public sealed class Progress
{
    public int Total, Completed, InProcess, Waiting, Failed;
    public int StepTotal, StepDone;
    public int AtDestination, InsideDevice, StillAtSource;
    public double WaferRate=>Total==0?0:Math.Round(100.0*Completed/Total,1);
    public double StepRate=>StepTotal==0?0:Math.Round(100.0*StepDone/StepTotal,1);
    public bool CountsConserved => Completed+InProcess+Waiting+Failed==Total;
}
public sealed class ProgressCalculator
{
    private readonly SubstrateTracker _t; public ProgressCalculator(SubstrateTracker t){_t=t;}
    public Progress Calc(ProcessJob job)
    {
        var p=new Progress{Total=job.Wafers.Count};
        foreach(var wp in job.Wafers.Values)
            switch(wp.State)
            { case WaferState.Completed:p.Completed++;break;
              case WaferState.Waiting:p.Waiting++;break;
              case WaferState.Failed:p.Failed++;break;
              default:p.InProcess++;break; }
        // 位置维度: 对比实际位置与目标
        foreach(var wp in job.Wafers.Values)
        { var loc=_t.LocationOf(wp.WaferId).Key; var dst=new CarrierLocation(wp.Dst.Carrier,wp.Dst.Slot).Key;
          if(loc==dst)p.AtDestination++; else if(loc.StartsWith("Internal"))p.InsideDevice++; else p.StillAtSource++; }
        // 步骤维度(教学): 每片Route步数累加
        p.StepTotal=job.Total*job.Def.Route.Steps.Count;
        p.StepDone=job.Wafers.Values.Sum(w=>w.CurStepNo); // 简化
        return p;
    }
}
```

### 严格完成守卫
```csharp
public sealed class CompletionGuard
{
    private readonly SubstrateTracker _t; private readonly ProgressCalculator _pc;
    public CompletionGuard(SubstrateTracker t){_t=t;_pc=new ProgressCalculator(t);}

    public (bool ok,List<string> reasons) Evaluate(ProcessJob job,bool dataComplete,bool noBlockingIssue)
    {
        var reasons=new List<string>(); var pg=_pc.Calc(job);
        if(job.Wafers.Values.Any(w=>w.State!=WaferState.Completed)) reasons.Add("存在未完成片");
        if(pg.InsideDevice>0) reasons.Add($"设备内残留{pg.InsideDevice}片未归位");
        foreach(var wp in job.Wafers.Values)
        { var loc=_t.LocationOf(wp.WaferId).Key; var dst=new CarrierLocation(wp.Dst.Carrier,wp.Dst.Slot).Key;
          if(wp.State==WaferState.Completed && loc!=dst) reasons.Add($"{wp.WaferId}完成但不在目标槽({loc})"); }
        if(job.Wafers.Values.Any(w=>w.State==WaferState.Failed)) reasons.Add("存在Failed片");
        if(!noBlockingIssue) reasons.Add("存在阻断Hold/Alarm");
        if(!dataComplete) reasons.Add("采集/事件数据不完整");
        if(!pg.CountsConserved) reasons.Add("片分类不守恒");
        // E90终验(跨盒逐片/守恒)由CrossFinalChecker结果并入, 略
        return (reasons.Count==0,reasons);
    }
    public bool CanComplete(ProcessJob job,bool dataComplete,bool noBlock)=>Evaluate(job,dataComplete,noBlock).ok;
}
```

### Partial 结果与三结局
```csharp
public enum JobOutcome { AllCompleted, PartialCompleted, Aborted, Failed }
public sealed class WaferResult{ public string Id=""; public WaferState State; public string ActualLocation=""; public int CurStep; public string? Err; }
public sealed class JobResult
{
    public JobOutcome Outcome; public List<WaferResult> Wafers=new(); public List<string> Notes=new();
    public bool Conserved;
}
public sealed class OutcomeEvaluator
{
    private readonly CompletionGuard _guard; public OutcomeEvaluator(CompletionGuard g){_guard=g;}
    public JobResult Evaluate(ProcessJob job,bool allowPartial,bool dataComplete,bool noBlock,bool aborted)
    {
        var r=new JobResult{Outcome=JobOutcome.AllCompleted};
        foreach(var wp in job.Wafers.Values)
            r.Wafers.Add(new(){Id=wp.WaferId,State=wp.State,ActualLocation="",CurStep=wp.CurStepNo});
        var (ok,_)=_guard.Evaluate(job,dataComplete,noBlock);
        if(ok){ r.Outcome=JobOutcome.AllCompleted; }
        else if(aborted){ r.Outcome=JobOutcome.Aborted; r.Notes.Add("中止,带Partial现场"); }
        else if(allowPartial && r.Wafers.All(w=>w.State!=WaferState.Failed))
        { r.Outcome=JobOutcome.PartialCompleted; r.Notes.Add("经授权部分完成,显式列缺口"); }
        else r.Outcome=JobOutcome.Failed;
        r.Conserved = r.Wafers.Count==job.Wafers.Count; // 分类守恒
        if(r.Outcome!=JobOutcome.AllCompleted)
            r.Notes.AddRange(r.Wafers.Where(w=>w.State!=WaferState.Completed).Select(w=>$"缺口:{w.Id}@{w.State}"));
        return r;
    }
}
```

## 三、完成判定流程（手绘参考）
```
执行循环结束 ─► CompletionGuard 五条件:
   每片Completed? 每片AtDestination且设备内空? E90终验过? 无Failed/Hold? 数据完整?
   ├ 全满足 → AllCompleted(Completed终态,5104)
   ├ 不满足+中止 → Aborted + Partial明细(完成/在途/失败+实际位置)
   ├ 不满足+Host授权部分交付 → PartialCompleted(显式缺口,绝不标Completed)
   └ 否则 → Failed/保持Executing挂起
 三维Progress(片/步/位置)实时可查; 分类之和=总数守恒; 结果供MES区分完工/缺口
```

## 四、今日易错点
1. 把"动作循环跑完"当 Completed（必须按结果五条件聚合判定）。
2. 片工艺完成但没归位也标完成（物理归位+设备内清空是硬条件）。
3. 只看片进度不看位置/终验/数据完整（五条件缺一不可）。
4. Partial 静默标 Completed（必须显式结局+缺口，默认不允许部分冒充全完成）。
5. Partial 不带每片实际位置（恢复/取片/核对无依据）。
6. 完成判定散落在多处、口径不一（集中 OutcomeEvaluator）。
7. 统计分类不守恒（完成+在途+等待+失败必须=总数）。
8. 不向 MES 报缺口（未完成/失败片会被当完工流入下游）。
