## 二、背景知识（先读，10 分钟）

### 1. CIM 是"统称"，不是一个软件
- **CIM = Computer Integrated Manufacturing（计算机集成制造）**，是工厂级自动化的**伞形概念/范畴**。它由多个子系统拼装组成，且这些子系统常来自不同厂商：
  - **MES**（制造执行，含 DFS/RTD 派工、工单/批次/在制/报工）
  - **APC 家族**：FDC 故障检测分类、R2R 逐批调参、VM 虚拟量测、SPC 统计过程控制
  - **RMS** 配方管理、**YMS** 良率管理、**ADC** 缺陷自动分类、**ECN** 变更管理
  - **EDA/Interface-A** 高频数据采集、**iEMS/CMMS** 设备维护、**RCM** 远程集中控制
  - **MCS/AMHS** 物料搬运（OHT/Stocker）
  - **EAP（设备接入层，你在这里）**
- 单一厂商的产品只叫它自己的名字（MES/EAP/RMS…），只有提供"全栈集成方案"时才叫"CIM 平台"。

### 2. 设备端 EAP 对外有"两条通道、两类客人"
- **SECS/GEM 控制通道**（E4/E5/E37/E30/GEM300）：中低频，命令/事件/报警/报告。设备端接口 ↔ **FAB 端 EAP（Host/Cell Controller）一对一**，MES/RMS 等不直连设备，经 FAB EAP 中转。
- **EDA/Interface-A 数据通道**（E120/E125/E128/E132/E134/E164，Freeze 3）：**高频 trace、订阅式、多客户端直连设备**，FDC/R2R/VM/YMS 采集侧用，不绕 FAB EAP。
- 另有 **E84 并口硬线**：AMHS 与 Load Port 直接握手，不走 SECS 报文。
- 术语：设备端准确叫 **Equipment SECS/GEM Interface（被管端）**；FAB 端叫 **EAP/Host（管理端）**。

### 3. SEMI 标准分层（自底向上，学习顺序）
```
L5 作业/物流：E94 CJM(编排PJ+物料路由) / E40 PJM(一次recipe运行) / E90 STS(片级位置) / E87 CMS(载具) / E84 LPT(并口交接) / E116 EPT(效率)
L4 对象语言：E39 OSS（对象-属性-服务，S14/S15/S16）
L3 设备行为：E30 GEM（通信/控制状态机、采集、报警、远程命令）
L2 报文语法：E5 SECS-II（Stream/Function、数据项编码）
L1 传输：    E37 HSMS（TCP/IP、连接状态机、T超时）；E4 SECS-I（RS-232，了解即可）
```
**依赖铁律**：上层全部建立在下层之上。E94 依赖 E40/E87/E39/E30/E5；不先打 L1~L4，直接看 E94 全是黑盒。

### 4. 最新版本意识（专家铁律）
一律按最新修订版学习：E87-0225、E40-0226、E94-0226、E134-1224、EDA Freeze 3；E5/E30 有 2026 修订提案。未标注版本的标准，购原文前去 SEMI 官网核对当日最新版。
