# W01 · Day01 答案与标准参考（做完自测再看）

## 一、自测题标准答案

### 题1：各标准一句话 + 层级关系
- **E37 HSMS（L1 传输）**：基于 TCP/IP 的传输层，含连接控制状态机与 T3/T5/T6/T7/T8 超时参数。
- **E5 SECS-II（L2 语法）**：定义消息内容怎么编码——Stream/Function、W-bit、10 字节消息头、数据项类型。
- **E30 GEM（L3 行为）**：设备通用行为模型——通信/控制状态机、数据采集、报警、远程命令、PP 管理。
- **E39 OSS（L4 对象语言）**：把设备资源抽象成"对象-属性-服务"，用 S14/S15/S16 统一操作，是 GEM300 的通用语言。
- **E84 LPT（L5 物流）**：载具上下设备时，运输系统与 Load Port 之间的并口硬件互锁握手（VALID/HANDSHAKE/CS0/CS1）。
- **E87 CMS（L5 物流）**：FOUP/Carrier 的对象生命周期（NotInstalled/Installed/Mounted）、ID 校验、SlotMap。
- **E90 STS（L5 跟踪）**：每片晶圆在设备内的精确位置与加工状态（片级追溯、防混片）。
- **E40 PJM（L5 作业）**：一次 recipe 运行 = 一个 Process Job，含加工步骤、片清单、状态机。
- **E94 CJM（L5 作业编排）**：一个 Control Job 编排一组有序 PJ，并决定加工后物料去向（路由）。
- **E116 EPT（L5 横向）**：基于 E10 RAM 采集设备状态时长、计算效率/OEE。
- 关系：L1→L5 单向依赖；E94 在最顶（依赖 E40/E87/E39/E30/E5），E37/E5 在最底。

### 题2：CIM 与 MES 的关系
- **不是一回事**。CIM 是工厂级"计算机集成制造"的**统称/范畴**（抽象概念，不卖不装）；MES 是 CIM 里**一个具体子系统**（管工单/批次/在制/报工/派工）。
- 一座 FAB 的 CIM 由 MES、APC(FDC/R2R/VM/SPC)、RMS、YMS、EDA、iEMS、MCS/AMHS、EAP 等**多厂商系统拼装**，所以单独一家只卖 MES 就该叫 MES，不该叫 CIM。
- **例外**：当某厂商提供"全栈集成方案"（把 MES+EAP+RMS+APC 打包），对外可叫"CIM 平台/解决方案"，这是产品包意义上的 CIM。判断口诀：卖全套集成→可叫 CIM 平台；只卖单个系统→叫具体名字。

### 题3：两类客人、两条通道；FDC 为何不绕 FAB EAP
- 两类客人：①**FAB 端 EAP（Host）**——走 SECS/GEM，一对一，管作业/事件/报警/命令；②**EDA 客户端（FDC/R2R/VM/YMS 采集侧）**——走 Interface-A，多客户端订阅式直连。
- 两条通道：SECS/GEM（E4/E5/E37/E30/GEM300，中低频）与 EDA/Interface-A（E120/E125/E128/E132/E134/E164，高频）。
- **FDC 不绕 FAB EAP 的原因**：FDC 要毫秒~秒级高频 trace（关键参数可达 100Hz、recipe step 边界至少 10Hz，日数据量几十 GB 级），SECS/GEM 是秒~分钟级、且多一层 EAP 转发，带不动也增加延迟；Interface-A 天生为高频、多客户端订阅、自描述设计，所以直连设备。

### 题4：为什么 300mm 要在 GEM 之上搞 GEM300
- 200mm 时代以人工/半自动物流为主，GEM(E30) 管通用行为即可；**300mm（12 寸）厂追求全自动、大重量 FOUP 人工搬不动、片级追溯与设备综合效率要求极高**，于是在 GEM 之上补充：
  - 全自动物流：E84（硬件交接）+ E87（载具对象管理）；
  - 片级追溯：E90（每片位置）；
  - 作业标准化：E40（PJ）+ E94（CJ 编排+路由）；
  - 效率量化：E116/E10；
  - 统一对象语言：E39（让上述业务对象同构、可发现、可操作）。
- 一句话：GEM 解决"设备怎么和主机说话"，GEM300 进一步解决"全自动厂里料怎么流、片怎么追、作业怎么编排、效率怎么算"。

### 题5：同时要 SECS/GEM 和 Interface-A 时做几套接口
- **两套独立对外接口**：
  1. SECS/GEM 接口：E37+E5+E30(+GEM300)，对 FAB EAP；
  2. EDA/Interface-A 接口：E120/E125/E128/E132/E134/E164（SOAP/XML、自描述模型、订阅采集），对 FDC/YMS 等 EDA 客户端。
- 两者**共享同一套内部数据源**（设备变量表/事件表/状态机），但传输栈、会话管理、数据频率、客户端模型完全不同，不能用一套顶替另一套。

## 三、今日易错点（红笔重点）
1. 把 CIM 等同于 MES（错：CIM 是范畴，MES 是成员）。
2. 以为设备只对一个 Host（漏了 Interface-A 直连的多客户端与 E84 硬线）。
3. 学习顺序从 E94 硬啃（错：必须自底向上，E94 放 W20 收编）。
4. 忽略标准版本（专家必须用最新修订版，E87-0225/E40/E94-0226/EDA Freeze3）。
