## 三、W2 三个预习问题的"思考方向"（先自己想，W2 揭晓完整答案）
1. **TCP 连上为何还要 Select**：思考方向——TCP 只保证"两个网络进程通了"，但不确认"对方是不是 HSMS 实体、用哪个 Session、是否已被别的 Host 占用"。Select 是 HSMS 层的"会话选通/排他确认"。
2. **Linktest 防什么**：思考方向——TCP 可靠是"有数据传时可靠"，但对端断电/拔线不会通知你（半开连接）。空闲时主动探测才能发现"静默死亡"。
3. **T 参数分工**：思考方向——按"管哪段时间"记：T3 管数据回复、T6 管单次控制握手应答、T8 管空闲保活、T5 管双 Active 冲突、T7 管 Select 间隔。W2 会做一张超时参数总表并写进代码。

## 四、今日自测参考答案
1. **一句话解释设备端 EAP**："它是设备对外的统一接口软件，把设备内部状态/事件/数据按 SEMI 标准（SECS/GEM，必要时加 Interface-A）提供给工厂各系统，并把主机命令翻译成设备动作，是设备与 CIM 之间的双向翻译官和守门人。"
2. **哪些 W2 直接演进 / 哪些长期复用**：FrameReader/Writer、TcpConnState、StateMachineBase、HexDump、ILogSink 都是长期地基；W2 直接把 TcpConnState 升级为 HSMS 控制状态机、把长度帧补上 10B 头与控制消息。
3. **为何不能跳过底座学 E94**：E94 的每条命令都靠 E5 编码、靠 E37 传输、受 E30 控制状态约束、用 E39 对象表达、引用 E40/E87/E90 的对象；跳过后只会"听过名词"，无法实现也无法排障，达不到 L4。
4. **疑问排期示例**：T 参数细节→W2；数据项编码→W3；GEM 状态机→W5；对象服务 S14/15/16→W9；CJ 级联→W21。把问题挂到对应周，避免堆积。
