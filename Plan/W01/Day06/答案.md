# W01 · Day06 答案与参考实现

## 一、自测题标准答案
1. **为何早写 HexDump**：SECS/HSMS 排障的日常就是"对着十六进制还原报文"，BitConverter 输出无偏移、无 ASCII、无换行，长报文无法阅读。固定三列排版后，W2/W3 抓任何报文都能直接读；它也是你以后做"本地日志分析工具"的基础组件。
2. **Closed→Connected 为何非法**：连接必须有过程。Passive 要先 Listening 才能 Accept 到 Connected；Active 要先 Connecting（发起握手）才能 Connected。跳过中间态意味着状态机没记录"正在监听/正在连接"，会丢失重连、并发 Accept、重复连接等判断依据。
3. **S6F11 从应用到网线的封装流（自顶向下）**：
   - 应用层：事件触发，取出 CEID 关联报告里的各 VID 现值（E30）；
   - E5 SECS-II：把 CEID+报告+值编码成数据项树（List/各类型），形成 SECS-II body，并定 S=6,F=11,W=1；
   - E37 HSMS：加 10 字节消息头（SessionID、W+Stream=6、Function=11、PType、SType=0 数据消息、SystemBytes），再在最前加 4 字节大端长度；
   - TCP：按 MSS 分段（Segment），保证可靠有序；
   - IP：封包路由到对端；链路层成帧上物理网络。
   - 接收端正相反：去 IP/TCP → 按长度切帧 → 读 10B 头知道是 S6F11 → E5 解码数据树 → E30 还原成事件。
4. **Passive/Active 状态机差异**：差异在"进入 Connected 之前"那一步——Passive 是 Closed→**Listening**（等 Accept）；Active 是 Closed→**Connecting**（主动 Connect）。Connected 之后收发/关闭逻辑一致。
5. **按周归档的原因**：26 周是长期工程，按周/标准分目录能让"某张图、某次实验"可回溯、可对照前后进步；堆一个文件夹会在 W10 后彻底失控，也不利于 W26 总验收时按图索骥。

## 二、参考实现

### Hex.cs（HexDump，放 EapLab.Transport/Text/）
```csharp
namespace EapLab.Transport.Text;

public static class Hex
{
    public static string Dump(byte[] data, int bytesPerLine = 16)
    {
        if (data.Length == 0) return "<empty>";
        var sb = new System.Text.StringBuilder();
        for (int off = 0; off < data.Length; off += bytesPerLine)
        {
            int n = Math.Min(bytesPerLine, data.Length - off);
            sb.Append(off.ToString("X8"));
            sb.Append("  ");
            for (int i = 0; i < bytesPerLine; i++)
            {
                if (i < n) sb.Append(data[off + i].ToString("X2") + " ");
                else sb.Append("   ");
                if (i == 7) sb.Append(' '); // 中缝
            }
            sb.Append(' ');
            for (int i = 0; i < n; i++)
            {
                byte b = data[off + i];
                sb.Append(b >= 0x20 && b < 0x7F ? (char)b : '.');
            }
            sb.AppendLine();
        }
        return sb.ToString().TrimEnd();
    }
}
```

### TcpConnState 状态机（连接雏形）
```csharp
using EapLab.Transport.Connection;
using EapLab.Transport.Logging;

public enum TcpConnState { Closed, Listening, Connecting, Connected }

public sealed class TcpConnStateMachine : StateMachineBase<TcpConnState>
{
    public bool IsPassive { get; }
    public TcpConnStateMachine(bool isPassive, ILogSink log)
        : base(TcpConnState.Closed, log) => IsPassive = isPassive;

    protected override bool CanTransition(TcpConnState from, TcpConnState to) =>
        (IsPassive, from, to) switch
        {
            (true,  TcpConnState.Closed,     TcpConnState.Listening)  => true, // 开始监听
            (true,  TcpConnState.Listening,  TcpConnState.Connected)  => true, // Accept 成功
            (false, TcpConnState.Closed,     TcpConnState.Connecting) => true, // 发起连接
            (false, TcpConnState.Connecting, TcpConnState.Connected)  => true, // 握手成功
            (_,     TcpConnState.Connected,  TcpConnState.Closed)     => true, // 正常/异常关闭
            (_,     TcpConnState.Listening,  TcpConnState.Closed)     => true,
            (_,     TcpConnState.Connecting, TcpConnState.Closed)     => true,
            _ => false
        };
}
```
> W2 把它替换/升级为 HSMS 控制状态机（NotConnected→NotSelected→Selected，含 Select/Linktest/Separate 与 T 参数），方法完全一样，只是状态和合法边更多。

### 单测示例
```csharp
[Fact]
public void Passive不能从Closed直接Connected()
{
    var sm = new TcpConnStateMachine(true, new ConsoleLogSink());
    Assert.False(sm.TryChange(TcpConnState.Connected, "bad")); // 内部调 ChangeState
    Assert.Equal(TcpConnState.Closed, sm.Current);
}
```
（在 StateMachineBase 上把 ChangeState 包一层 public TryChange 即可测试。）

## 五、易错点
1. HexDump 偏移用十进制（应十六进制）、中缝缺失导致难读。
2. 状态机允许"跳态"（失去过程记录）。
3. 只画"发送方向"不画接收方向（专家要能双向讲剥离过程）。
