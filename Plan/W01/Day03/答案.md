# W01 · Day03 答案与参考实现

## 一、自测题标准答案
1. **Transport 不能引用 Gem 的原因**：依赖方向必须与协议栈方向一致（上层依赖下层）。若下层反向引用上层，会形成**循环依赖**（编译不过或被迫下沉接口）、下层无法独立复用/单测、且传输层被业务污染。正确做法是下层定义抽象、上层注入实现（依赖倒置）。
2. **状态迁移唯一入口的价值**：状态机 bug 90% 来自"状态在多处被悄悄改"。统一走 `ChangeState()`，就能在**唯一位置**打日志、做合法转换校验、断点抓"非法跳转"。W2/W5 的 HSMS、GEM 状态机都沿用这个模式，排查时一条迁移日志就能还原现场。
3. **Passive/Active 对应**：EquipSim=**Passive**（监听端口、等连接、回 Select.rsp）；HostSim=**Active**（发起 TCP、发 Select.req）。设备通常做 Passive，因为设备固定在位、长期监听，由可移动/可冗余的主机主动发起与重连，多主机场景角色清晰、故障恢复由 Host 侧统一调度。
4. **扩展 EDA 第二通道**：新增 `EapLab.Eda`（SOAP/XML、EqSD、DCM/CAM）项目，与 SECS 栈**平级**，共同复用一个"设备数据源"（变量/事件/状态的只读供给接口）；EquipSim 同时挂载 Secs 通道与 Eda 通道。绝不让 Eda 依赖 Secs2 的二进制编码（两者传输不同）。
5. **TX/RX/EVT 三方向**：TX=本端发出的报文、RX=收到的报文、EVT=内部状态/事件迁移。分开后能一眼区分"线上收发"与"内部状态变化"，排障时先看 EVT 定位状态、再对照 TX/RX 看报文因果。

### 2. 日志抽象（放 EapLab.Transport/Logging/ILogSink.cs）
```csharp
namespace EapLab.Transport.Logging;

public enum LogDir { TX, RX, EVT, ERR }

public interface ILogSink
{
    void Log(LogDir dir, string message);
}

public sealed class ConsoleLogSink : ILogSink
{
    public void Log(LogDir dir, string message)
    {
        Console.WriteLine($"{DateTime.Now:HH:mm:ss.fff} | {Environment.CurrentManagedThreadId:D2} | {dir,-3} | {message}");
    }
}
```

### 3. 状态唯一入口（放 EapLab.Transport/Connection/StateMachineBase.cs）
```csharp
using EapLab.Transport.Logging;

namespace EapLab.Transport.Connection;

public enum ConnState { Disconnected, Listening, Connecting, Connected }

public abstract class StateMachineBase<TState> where TState : struct, Enum
{
    private TState _state;
    private readonly ILogSink _log;
    protected StateMachineBase(TState initial, ILogSink log) { _state = initial; _log = log; }

    public TState Current => _state;

    /// <summary>唯一状态迁移入口：校验合法转换 + 打日志，子类用 CanTransition 定义规则。</summary>
    protected bool ChangeState(TState next, string reason = "")
    {
        if (EqualityComparer<TState>.Default.Equals(_state, next)) return false;
        if (!CanTransition(_state, next))
        {
            _log.Log(LogDir.ERR, $"非法状态迁移 {_state} -> {next} ({reason})");
            return false;
        }
        var prev = _state; _state = next;
        _log.Log(LogDir.EVT, $"状态迁移 {prev} -> {next} ({reason})");
        OnChanged(prev, next);
        return true;
    }

    protected abstract bool CanTransition(TState from, TState to);
    protected virtual void OnChanged(TState from, TState to) { }
}
```
> W2 做 HSMS 控制状态机时，继承它并在 `CanTransition` 里写死 NotConnected→NotSelected→Selected 的合法边即可，非法跳转会被自动拦截并打日志。
