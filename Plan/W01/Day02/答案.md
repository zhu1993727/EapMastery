# W01 · Day02 答案与标准参考

## 一、自测题标准答案

### 题1：E94-0226 与 E94.1-0226
- `E94-0226`：SEMI E94《控制作业管理规范(CJM)》主标准，**2026 年 2 月技术修订版**；定义对象、属性、状态机、服务语义（"要做什么、状态怎么迁"）。
- `E94.1-0226`：其 **SECS-II 协议绑定分册**，规定每个服务具体用哪条 S/F、参数排列、数据类型、ACK 码、事务时序（"用什么报文落地"）。
- **成对看的原因**：只看主标准懂业务却写不出/看不懂报文；只看 .1 会拼消息却不懂状态约束（如 Paused 态为何拒绝 Start）。两者结合才打通"状态机语义 ↔ 报文实现"，这是 L1 与 L4 的分水岭。

### 题2：五个标识
- **CEID（Collection Event ID，E30）**：采集事件编号，标识"某个值得上报的时刻"；触发时按链接关系组 S6F11。
- **SVID（Status Variable ID，E30）**：状态变量编号，设备的只读实时状态值（如温度、计数）。
- **ECID（Equipment Constant ID，E30）**：设备常量编号，可配置参数（可读、部分可写）。
- **ALID（Alarm ID，E30）**：报警编号，配合 ALCD（报警代码，含 set/clear 位与类别）、ALTX（报警文本）走 S5F1。
- **RCMD（Remote Command，E30）**：远程命令，Host 经 S2F41 下发（带 CPNAME/CPVAL 参数），设备校验后执行并回 HCACK/CPACK。

### 题3：CIM 系统职责与数据通道
- **FDC**：实时监控 trace/事件，检测并分类故障，可联动 hold。
- **R2R**：按上一批结果算下一批工艺参数偏移（不改 recipe 主档，只叠加 overlay）。
- **VM**：用过程数据 AI 预测量测结果，替代部分实测。
- **SPC**：对量测/过程数据做统计控制（控制限、异常模式）。
- **RMS**：recipe 版本/审批/下发（S7 上下载、版本比对）。
- **YMS**：设备数据+量测/缺陷做良率关联分析。
- **主要走 Interface-A 拿高频数据的**：FDC、VM、YMS（以及 R2R 的高频采集侧）；RMS 的 PP 上下传多走 SECS/GEM 的 S7；SPC 两者皆可。

### 题4：异名同物
- **Host / EAP / Cell Controller（Station Controller）**：都指 FAB 侧"管设备的那一端"。Host 是 SECS 标准里的正式角色名；EAP 是工厂里的系统名（设备自动化程序）；Cell/Station Controller 是按区域管理设备时的架构叫法。设备端正式名是 **Equipment SECS/GEM Interface（被管端）**。
- **Carrier / FOUP / Cassette**：Carrier 是标准正式名（载具，E87 对象）；FOUP 是 300mm 前道光刻级密闭盒的具体形态；Cassette 是 200mm/传统开放式片盒的叫法。标准文档用 Carrier 统称。

### 题5：Spooling 与 EDA 高频采集的区别
- **Spooling（E30 GEM）**：链路 NOT COMMUNICATING 期间，把 S6F11 事件/S5F1 报警等"流水"按发生顺序持久化，恢复后 FIFO 补传；解决的是"**断链不丢事件、保序**"，是中低频控制通道的容错机制。
- **EDA 高频采集（Interface-A）**：解决的是"**正常连接下，多客户端以毫秒级订阅海量 trace**"，是独立第二通道。
- 两者不是一回事：一个是断链补传（SECS/GEM），一个是高频订阅（Interface-A）。

## 三、今日易错点
1. 术语卡只写中文不写全称/归属（专家要能中英互译并指出标准出处）。
2. 把 .1 分册当附录略过（.1 是报文落地，必须成对）。
3. 把 Spooling 当高频采集（一个是断链补传，一个是订阅采集）。
4. 拿到旧版标准不核对修订年份。
