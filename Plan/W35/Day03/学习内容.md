# W35 · Day03（周三）下行指令链：MES→EAP→设备 的事务性下发与回告

## 二、背景知识（先读，40 分钟）

### 1. 下行链总时序（默写级）
1. MES 派工：指定 Lot、目标工序、PPID/版本、片/槽范围、优先级。
2. Carrier 到位与身份校验：E84 上料、E87 Load 绑定 Carrier↔Lot、E90 SlotMap 与 MES 期望逐片核对（三不变式，W14-15）。
3. 配方就绪：RMS 确认设备上 PPID/版本存在且 hash 一致（W33），否则先分发。
4. 远程命令/建作业：EAP 用 S2F41 下 RCMD，按 E40 创建 Process Job（哪些槽、哪个 PPID、哪些腔、顺序），按 E94 建 Control Job 组织调度（W16-23）。
5. PP-Select：加工前在安全点选配方并回读当前 PPID/版本一致（W33）。
6. Start：五门前置满足（Remote、安全点非加工、本地一致、版本合工单、无 Hold）后启动 CJ/PJ，设备迁移 Started/Executing 并发事件。

### 2. 每步门控（复用前序，串联）
- 通信门：HSMS SELECTED、设备在线 Remote（W02/W05）。
- 物料门：E87 Loaded、E90 SlotMap 与 MES 期望一致、无错片/缺片冲突。
- 配方门：PPID/版本合工单、设备副本一致、Selected 成功（W33）。
- 作业门：E40 PJ 合法（槽/腔/recipe 正交）、E94 CJ 栅栏与顺序正确（W20-23）。
- 状态门：设备非 Hold/Down、处于可启动安全点、无未解除联锁。
- 任一门不过：不进入下一步，返回明确原因，已建部分回滚/取消。

### 3. 事务性、幂等、回滚
- 一次派工开工是一个跨多消息的"事务"：要么走到开工，要么干净回到未开始/可重试态，不留半截作业。
- 幂等：每条命令带唯一 ReqId/JobId，重发同一指令设备识别为重复、不重复建 Job/不叠加（W31 overlay、W22 对账同思想）。
- 失败回滚：建了 PJ 但 Start 失败→取消 PJ、释放预约、回告 MES 派工未执行及原因；配方下发失败不允许用旧版/本地版"将就加工"。

### 4. 上行回告层级（受理≠生效，贯穿）
- 受理层：S2F42/远程命令 ACKC10=0、S7F4=0、E40 命令 ACK 只代表"收到且格式合法"，不代表已执行/生效。
- 生效层：必须等设备状态机真正迁移并发出对应 S6F11 事件（JobStarted/StepStarted…）、回读一致，才算生效（W05/W22/W31）。
- 进度层：CJ/PJ 状态、片/Step 进度、消耗（E10/E116）实时上行。
- 完工层：JobCompleted/片结果/量测触发，EAP 汇总成 Lot/工序完工回告 MES（Day04）。
- 异常层：Hold/Alarm/Abort/Fail 事件即时上行，MES 据此冻结 WIP/派工（谁设谁解，决策≠执行）。

### 5. MES↔EAP 接口语义
- MES 侧通常是服务调用/消息（派工、取消、改派、Hold/Release、配方指定），EAP 负责把它编排成设备时序并把设备事件回译为 MES 事务；EAP 要屏蔽设备差异，对 MES 呈现稳定的制造语义（开工/完工/异常），而不是裸 SECS 报文。

### 6. 典型异常分支
- 上料片与 MES 期望不符→拒开工并告警（防串批）。
- 配方版本不符→触发 RMS 分发，分发失败则不加工。
- Start 后设备异常 Abort→作业转终态、回告 MES、WIP 停在当前工序并 Hold 待处理。
- 通信中断→重连对账（W22）恢复作业状态后再决定续做/取消（Day05）。
