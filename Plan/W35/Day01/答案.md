# W35 · Day01 答案与参考实现

## 一、自测题标准答案
1. **位置/不直连设备**：CIM 是工厂自动化的统称，MES 是其中的制造执行核心子系统，管"生产什么、走哪条工艺路线、在哪道工序/哪台设备做、用哪版配方、当前做到哪、结果与谱系"，面向工单/批次/在制品。它不直接连设备，是因为 MES 面向业务与制造对象（工单、Lot、路线、WIP），而设备侧是异构实时的 SECS/GEM、EDA、E84/E87/E90/E40/E94 世界，协议、时序、状态机完全不同；中间由 EAP 承担协议适配、实时控制与设备状态管理，MES↔EAP 走工厂级服务/消息，EAP↔设备走 SECS/GEM/EDA，这样 MES 不必为每种设备写驱动、设备侧实时性也不被业务系统拖累。
2. **对象链/数量关系**：Work Order（工单，产品/数量/路线/交期）1—n Lot（批次，现场基本流转单位，常 25 片，可分 Sublot）；Lot 1—n Wafer（片，最小产品单位，有 slot/单片状态/量测/良率）；某一时刻 Lot n—1 Carrier（装在一个 FOUP 里，可换载）；Route 1—n Operation（工序，对应一类设备），Operation 内部对应设备 recipe Step / CJ；在某道工序，Carrier 上设备后 EAP 按 Lot/片创建 E40 Process Job / E94 Control Job，Job 与 Wafer/Slot 多对多、按腔调度。即工单→批次→片，片盒物理承载批次，工艺路线定义工序，Job 是设备侧执行单元。
3. **Carrier 与 Lot 关系/绑定解绑**：Carrier（FOUP）是物理容器，Lot 是逻辑生产批次，二者是"装载"关系而非等同：一个 FOUP 在某时刻装载一个 Lot（其 wafer 按 slot 摆放，E90 SlotMap），在 Carrier 被 Load 到设备/存储位、扫码确认时完成 CarrierID↔Lot 绑定（E87 Load 流程，W12-13），绑定后该盒内片才被认作该 Lot；解绑发生在 Unload、Lot 换盒/分合批时。绑定关系由 MES 记录、EAP/设备执行校验，防止"盒里装的不是 MES 认为的 Lot"导致串批。
4. **Route/Operation/Step 对应**：Route 是跨设备的工序序列（刻蚀→薄膜→CMP…），每个 Operation 对应一类工艺设备/一道厂内工序；设备内 recipe 由多个工艺 Step 组成（升温/沉积/稳定…），E94 Control Job 组织一次加工、其下 PJ 对应对一批片用某 recipe 的执行，recipe Step 与 CJ/PJ 的执行阶段对应。映射关系：MES Operation→选定某台设备→RMS 选对应 recipe（含其 Step）→EAP 建 PJ/CJ→设备按 recipe Step 加工并以 Step 事件回告（S6F11），EDC 用这些 Step marker 给数据分段（W34）。即厂级工序、设备作业、配方工步三层逐级落地。
5. **WIP/Lot 状态**：WIP（Work In Process，在制品）是厂内尚未完工的 Lot/片及其工序位置与状态的"账"。Lot 大致流转：Created（建批）→Released/Dispatched（派工放行）→Queue/在工序间等待移动→At Equipment（片盒上设备、绑定）→Processing（加工中）→（片完）Move 到下一工序（过账 transaction），期间可被 Hold（质量/工程冻结，谁设谁解），最终 Complete（完工入库）或 Scrap（报废）。每次移动/状态变更加工/检验结果都回写 MES 形成 WIP 账，追求账实一致（MES 认为的位置/状态=现场实际）。
6. **系统分工**：MES 决定"做什么、走什么路线、在哪做、该用哪个 PPID/版本、目标规格"（制造对象与调度）；RMS 保证配方内容正确、版本受控、设备副本一致（W33，管配方本身）；APC 中 FDC 实时保安全、R2R 逐批补偿漂移、VM/SPC 估测与判稳（过程优化与质量，W30-32）；EDC 汇聚治理过程/量测数据并提供实时/历史服务（W34，管数据底座）；EAP 负责把 MES 指令翻译成设备 SECS/GEM 动作并把设备事件结果回译给 MES（适配与实时控制）。MES 面向业务编排，其余各司其职、经 EAP/EDC 协同。
7. **对象映射/错的后果**：EAP 要做的映射：CarrierID↔Lot（E87 装载绑定）、Wafer↔Slot（E90 SlotMap 逐片对应）、MES 工序/指定 PPID 版本↔设备 recipe 选择（W33 PP-Select）、派工要求↔E40 PJ/E94 CJ（哪些片、哪些腔、什么顺序）、设备作业/片级事件与结果↔Lot/Wafer 回告（进度/消耗/质量/完工），并保证每个上行数据带 Lot/Wafer/Step 谱系键（W34）。映射错误后果：串批（把 A Lot 片当 B Lot 加工/记账）、跑错配方版本、SlotMap 错位导致片级张冠李戴、WIP 账实不符、谱系断裂无法追溯良率，属严重质量/合规事故。

## 二、参考实现（net8.0）：制造对象模型

```csharp
namespace EapLab.Mes;
public enum LotState{ Created,Released,Queued,AtEquipment,Processing,OnHold,Completed,Scrapped }
public sealed class Wafer
{ public string Id{get;}public int Slot{get;}public string? Result{get;set;}
    public Wafer(string id,int slot){Id=id;Slot=slot;} }
public sealed class Lot
{ public string Id{get;}public string Product{get;}public List<string> Route{get;}public List<Wafer> Wafers{get;}=new();
    public LotState State{get;set;}=LotState.Created;public string? CarrierId{get;set;}public int OpIndex{get;set;}
    public Lot(string id,string product,IEnumerable<string> route){Id=id;Product=product;Route=route.ToList();}
    public string? CurrentOp=>OpIndex<Route.Count?Route[OpIndex]:null;
    public void BindCarrier(string c){CarrierId=c;}public void Unbind(){CarrierId=null;} }
public sealed class WorkOrder
{ public string Id{get;}public string Product{get;}public int Qty{get;}public List<Lot> Lots{get;}=new();
    public WorkOrder(string id,string product,int qty){Id=id;Product=product;Qty=qty;}
    public Lot ReleaseLot(string lotId,IEnumerable<string> route)
    { var l=new Lot(lotId,Product,route){State=LotState.Released};Lots.Add(l);return l; } }
public sealed class Carrier
{ public string Id{get;}public string? LotId{get;private set;}public Carrier(string id){Id=id;}
    public void Load(Lot l){if(LotId is not null)throw new InvalidOperationException("occupied");LotId=l.Id;l.BindCarrier(Id);}
    public void Unload(Lot l){LotId=null;l.Unbind();} }
// 设备侧执行单元(与E40/E94对应, 教学模型)
public sealed record ExecJob(string JobId,string LotId,string Ppid,List<int> Slots,string Chamber);
```

## 三、制造对象链（手绘参考）
```
Work Order(产品/数量/路线) 1—n Lot(批次,常25片, WIP状态机) 1—n Wafer(slot/单片结果)
                                   │ 某时刻 n—1 装载
                                Carrier/FOUP(E87扫码绑定 CarrierID↔Lot, E90 SlotMap逐片)
Route(厂级工序序列) → Operation(一道工序/一类设备) → 上设备
   MES指定PPID版本 → RMS保证配方对(W33) → EAP建 E40 PJ / E94 CJ(哪些片/哪些腔/顺序)
   → 设备按recipe Step加工, S6F11 Step事件 → EDC分段(W34) → APC(FDC/R2R/VM/SPC)
对象映射(EAP, 错=串批/跑错版本/账实不符): Carrier↔Lot, Wafer↔Slot, 工序↔recipe版本, 派工↔PJ/CJ, 事件↔Lot/Wafer回告
Lot状态: Created→Released→Queued→AtEquipment→Processing→Move下一工序 ; Hold(谁设谁解) ; Complete/Scrap
边界: MES编排制造对象(不直连设备) / EAP实时适配控制 / RMS配方 / APC过程优化 / EDC数据底座
谱系: wafer→Lot/工单→各工序设备腔/recipe版本/overlay→过程数据/量测/良率 全程可反查
```

## 四、今日易错点
1. 把 CIM 当单一系统/单一产品（CIM 是统称，MES 是其子系统）。
2. 让 MES 直接走 SECS 连设备（应经 EAP）。
3. 混淆 Lot（逻辑批次）与 Carrier（物理容器），不做装载绑定校验导致串批。
4. 分不清 Route/Operation 与 recipe Step/CJ 的层级对应。
5. WIP 只在 MES 记账、不与设备实际状态核对，账实不符。
6. 混淆 MES（做什么/在哪做）与 RMS（配方内容）、APC（过程控制）、EDC（数据）。
7. 上行事件不带 Lot/Wafer/Step 谱系键，谱系断裂。
8. 设备侧不做 Slot↔Wafer、PPID 版本映射校验，片级张冠李戴/跑错版本。
