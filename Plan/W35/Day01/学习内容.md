## 二、背景知识（先读，40 分钟）

### 1. MES 在 CIM 中的位置（回扣早期澄清）
- CIM 是工厂自动化的**统称**，由 MES、EAP、RMS、APC(FDC/R2R/VM/SPC)、YMS、EDC、AMHS/E84 等多个子系统组成；单一厂商产品不应叫"CIM"。
- MES 是制造执行核心：管"生产什么、走什么路线、在哪道工序/哪台设备做、用什么配方、做到什么状态、结果与谱系"，面向订单/批次/工艺路线与在制品。
- MES **不直接连设备**：它面向业务/制造对象，设备侧的 SECS/GEM、EDA、E84/E87/E90/E40/E94 对接由 EAP 承担；MES↔EAP 之间是工厂级接口（消息/服务/数据库），EAP↔设备是 SECS/GEM/EDA。

### 2. 核心制造对象模型（必须清晰）
- **Work Order（工单/生产订单）**：要生产什么产品、数量、工艺路线、交期；是生产任务源头。
- **Lot（批次）**：工单下达到现场的基本生产/流转单位，通常一批 25 片 wafer（可分 Sublot 子批）；带产品、工艺路线、当前工序、状态、规格/目标。
- **Wafer（片）**：最小物理产品单位，有 slot 位置、单片状态/量测/良率，经 E90 SlotMap 跟踪。
- **Carrier/FOUP（片盒，E87）**：物理承载 Lot 的容器，Carrier ID 与 Lot 绑定（Load 时关联），在 AMHS/设备间搬运。
- **Route / Operation / Step（工艺路线/工序/工步）**：Route 是产品要经过的工序序列（如刻蚀→薄膜→CMP），Operation 是一道工序（对应某类设备），Step 是设备内工艺步骤（对应 recipe step / CJ）。
- **Job（作业）**：设备上一次可执行任务——E40 Process Job（PJ，对哪些片用什么 recipe 怎么加工）、E94 Control Job（CJ，调度/顺序控制）；Job 是 MES 生产要求在设备侧的落地（W16-23 已学）。

### 3. 对象链全景（默写级）
- Work Order 1—n Lot；Lot 1—n Wafer；Lot n—1 Carrier（某时刻装载在某 FOUP，可换载）；Route 1—n Operation；在某 Operation，Lot 的片经 Carrier 上设备→EAP 据此创建 PJ/CJ（Job n—n Wafer/Slot，按腔调度）。
- 谱系（genealogy）：任意 wafer 可反查属于哪个 Lot/工单、经过哪些设备/腔/工序、用了哪版 recipe/overlay、过程数据与量测/良率（依赖 W34 EDC 数据与 W33 RMS 版本）。

### 4. WIP 与状态流转
- WIP（Work In Process，在制品）：当前在厂内未完工的 Lot/片及其工序位置与状态；MES 维护 WIP 账（在哪、在等/加工/待检/Hold）。
- Lot 状态：Created→Released(派工)→在工序间 Move/Queue→At Equipment（上设备）→Processing→完工件 Move 到下一工序→Hold（质量/工程冻结，谁设谁解）→Complete/Scrap。
- 每次移动（transaction/movement）更新 MES 账并留痕，保证账实一致。

### 5. MES 与周边系统边界
- MES↔RMS：MES 指定该用的 PPID/版本，RMS 保证配方内容与一致（W33）。
- MES↔APC：MES 提供产品/目标/工序上下文，FDC 保安全、R2R 做控制、VM/SPC 反馈质量，结果回写 MES/EDC。
- MES↔EDC：MES 提供制造对象/谱系键，EDC 提供过程/量测数据（W34），二者 join 形成完整制造数据。
- MES↔EAP↔设备：派工/预约/启动指令下行，设备状态/作业事件/结果上行（Day03-05 细讲）。
- MES↔AMHS/E84：片盒搬运与上下料协同（W11）。

### 6. 设备端 EAP 视角（你的岗位）
- 你不实现 MES，但要把 MES 的制造对象正确映射到设备对象：Carrier Load 时绑定 Lot（E87）、SlotMap 对片（E90）、按派工建 PJ/CJ（E40/E94）、选对 MES 指定的 recipe 版本（W33）、把作业/片级事件与结果按 Lot/片回告，供 MES 记账与谱系。映射错=账实不符/跑错工艺。
