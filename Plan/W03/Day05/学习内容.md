## 二、背景知识（先读，20 分钟）

### 1. 解码单 Item 算法（递归）
```
1) 读 formatByte：typeCode = b>>2；lenBytes = (b&0x03)+1
2) 读 lenBytes 大端整数 = length
3) 按类型：
   - L：循环 length 次，每次递归解码一个子 Item，offset 随子项推进
   - 原子：value 区长度 = length × 单元素宽度(A/B 按 length 字节)，整块读出
4) 返回 Item 与"本 Item 消耗的总字节"，供父级/下一项推进
```

### 2. 必须防的异常报文
- 声明长度 > 剩余字节（截断/粘包残留）→ 抛 TruncatedException；
- 长度字段声称 3 字节但值 >0xFFFFFF、或类型码未知 → 抛格式异常；
- List 子项递归深度过大 → 限深保护；
- 原子值长度不是单元素宽度整数倍（如 U2 长度=3）→ 对齐异常。

### 3. SML（SECS Message Language）文本表示
便于日志/讲解，例：
```
S6F11 W
L,3
  U4 1
  U2 2001
  L,1
    L,2
      U2 1
      L,1 U1 1
.
```
今天实现一个 `ToSml(indent)`，这是你以后给同事讲报文、做日志分析工具的基础。

### 4. 与 HSMS 衔接点
W2 的 `OnDataMessage(header, body)`：body 就是 SECS-II 字节；调用 `SecsItem.Decode(body, out used)` 得到树根，校验 used==body.Length（防止尾巴脏字节），再按 header.SxFy 分发。
