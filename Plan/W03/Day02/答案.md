# W03 · Day02 答案与参考实现

## 一、自测题标准答案
1. **格式字节基值（长度1B）**：U2=0xA8，F4=0x84，I1=0x64，Boolean=0x28，A=0x40，L=0x20。
2. **300 个 U1 元素的长度字段**：元素个数 300 > 255，长度需 **2 字节**；格式字节低 2 位=1，U1 基值 0xA4 → **0xA5**，随后长度大端 `01 2C`。
3. **I2=-2**：+2=`00 02`，取反加一：`FF FE`。完整 `68 01 FF FE`（I2 基值 0x68，长度1元素）。
4. **U4=300 为何长度仍 1B**：长度字段记录的是**元素个数=1**（不是值大小），1<256 用 1 字节；每个 U4 元素固定占 4 字节，所以值 `00 00 01 2C` 占 4 字节。两回事，别混。
5. **Boolean 宽度 / 空 A**：Boolean 每元素 **1 字节**（不是 1 bit，值 0/1）；空 A 编码为 `40 00`（格式字节 + 长度0，无 value）。
6. **U2=258 大端**：258=0x0102，高位在前 → `01 02`。

## 二、参考实现（EapLab.Secs2/Coding/）

### SecsFormatExtensions.cs
```csharp
using System.Buffers.Binary;

namespace EapLab.Secs2.Coding;

public static class SecsFormatExtensions
{
    /// <summary>单元素字节宽度；L 返回 0（不定），A/B 返回 0（按字节长度）。</summary>
    public static int AtomWidth(this SecsFormat f) => f switch
    {
        SecsFormat.Boolean or SecsFormat.Binary or SecsFormat.I1 or SecsFormat.U1 or SecsFormat.Ascii => 1,
        SecsFormat.I2 or SecsFormat.U2 => 2,
        SecsFormat.I4 or SecsFormat.U4 or SecsFormat.F4 => 4,
        SecsFormat.I8 or SecsFormat.U8 or SecsFormat.F8 => 8,
        _ => 0
    };

    /// <summary>长度需要几个字节：1/2/3。</summary>
    public static int LengthByteCount(int length)
    {
        if (length < 0) throw new ArgumentOutOfRangeException(nameof(length));
        if (length <= 0xFF) return 1;
        if (length <= 0xFFFF) return 2;
        if (length <= 0xFFFFFF) return 3;
        throw new ArgumentException("SECS-II 长度最大 0xFFFFFF");
    }

    /// <summary>生成格式字节：(类型码<<2)|(长度字节数-1)。</summary>
    public static byte FormatByte(this SecsFormat f, int length)
        => (byte)((int)f << 2 | (LengthByteCount(length) - 1));

    /// <summary>写格式字节 + 大端长度，返回"头部"字节。</summary>
    public static byte[] WriteHeader(this SecsFormat f, int length)
    {
        int n = LengthByteCount(length);
        var head = new byte[1 + n];
        head[0] = f.FormatByte(length);
        var lenBytes = new byte[3];
        BinaryPrimitives.WriteUInt32BigEndian(new byte[]{0,0,0,0}.AsSpan(), 0); // no-op 示意
        // 大端写长度到末尾 n 字节
        Span<byte> tmp = stackalloc byte[4];
        BinaryPrimitives.WriteInt32BigEndian(tmp, length);
        tmp.Slice(4 - n).CopyTo(head.AsSpan(1));
        return head;
    }
}
```

### 整数大端写入（各原子类型编码器 Day04 用）
```csharp
public static class BigEndian
{
    public static byte[] U1(params byte[] v) => v;
    public static byte[] U2(params ushort[] v) { var b=new byte[v.Length*2]; for(int i=0;i<v.Length;i++) BinaryPrimitives.WriteUInt16BigEndian(b.AsSpan(i*2), v[i]); return b; }
    public static byte[] U4(params uint[] v)   { var b=new byte[v.Length*4]; for(int i=0;i<v.Length;i++) BinaryPrimitives.WriteUInt32BigEndian(b.AsSpan(i*4), v[i]); return b; }
    public static byte[] I2(params short[] v)  { var b=new byte[v.Length*2]; for(int i=0;i<v.Length;i++) BinaryPrimitives.WriteInt16BigEndian (b.AsSpan(i*2), v[i]); return b; }
    public static byte[] I4(params int[] v)    { var b=new byte[v.Length*4]; for(int i=0;i<v.Length;i++) BinaryPrimitives.WriteInt32BigEndian (b.AsSpan(i*4), v[i]); return b; }
}
```

## 三、手算卡答案示例（抽查）
- U2[1,2] → `A8 02 00 01 00 02`
- A"Hi" → `40 02 48 69`
- Boolean[true,false] → `28 02 01 00`

- 空 List → `20 00`

## 四、今日易错点
1. 把"元素个数"和"值字节宽度"混进同一个长度（长度只数个数/字符字节）。
2. 300 个元素忘了长度要升 2 字节、格式字节低 2 位要 +1。
3. 有符号负数用绝对值编码（应用补码）。
4. 多字节整数用主机小端（SECS 一律大端）。
5. Boolean 按 bit 打包（实际每元素 1 字节）。
