## 四、W29 预热：真实 HTTP/gRPC 双通道实战（25 分钟）
### 1. W29 七天预告
- Day01 ASP.NET Core 最小 Web API 承载 EDA：把内存 ITransport 换成真实 HTTP 端点（自描述获取、会话、采集计划 CRUD、数据回报）。
- Day02 Freeze II 回报：XML/SOAP 风格端点与客户端回调，Wireshark 抓 HTTP 报文对照。
- Day03 Freeze III：Protocol Buffers(.proto)+gRPC server streaming 高频流，对比 XML/PB 报文体积与 CPU。
- Day04 背压与并发实战：多客户端真实连接、慢消费者、断连重连、取消订阅、资源水位压测。
- Day05 GEM+EDA 同源双通道实战：同一设备同时跑 HSMS GEM 控制与 HTTP EDA 采集，验证同源同值、端口/线程隔离、EDA 不控。
- Day06 综合演练：GEM 走作业链(E87/E94)同时 EDA 高频出数+事件，故障注入下双通道互不影响。
- Day07 复盘 + W30（APC/FDC）预热。

### 2. 技术准备
- 复习 ASP.NET Core 最小 API、依赖注入、BackgroundService（采样/上报后台服务）、gRPC 与 protobuf-net/Grpc.AspNetCore。
- 准备 Wireshark 抓 loopback HTTP（W02 已装 Npcap）。
- 复用本周全部 EapLab.Eda 类型，只新增 Hosting/Transport 适配层。

### 3. 思考题（带进 W29）
1. 真实 HTTP 下一个采样后台服务如何与请求线程协作、优雅启停。

3. GEM 控制与 EDA 采集同进程时如何做到资源隔离、谁都不能拖垮谁。
