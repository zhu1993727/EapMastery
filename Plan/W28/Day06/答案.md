# W28 · Day06 答案与参考实现（端到端集成）

## 一、自测题标准答案
1. **采样点全链路**：硬件/驱动值→写入唯一数据源 EquipmentDataBus（权威值）→集中采样调度器基础 tick 到期、从数据源只读快照取值并打单调时间戳/质量码→写入该计划 RingBuffer→上报 flush 时 Drain 成中性 Packet（序号/时间窗/质量/Gap）→ReportService 按会话协商选 XML/protobuf 编码→进该会话独立发送队列→ITransport（II 回调 / III 流）推送到 FDC 收件。经过：数据源→采样调度→环形缓冲→运行时打包→编码→会话发送队列→传输→客户端。
2. **周期/事件各走通道**：FDC 周期订阅注册到采样调度器，由基础节拍按 EveryTicks 驱动、点进可覆盖环形缓冲、定时/凑点批量出 Packet；YMS 事件订阅不进周期循环，而是向 FSM 同源事件出口注册，StepChanged 发生时即时取 ECV 快照进独立不可丢队列、可配置事件即报。二者驱动源、缓冲、上报策略都不同，运行时按计划 Trigger 分流，互不阻塞、互不丢对方数据。
3. **慢/断隔离分层动作**：采集层——环形缓冲有界，慢消费覆盖最旧周期点并计 Overwritten→Gap，事件队列独立不被覆盖；运行时层——发送堵塞时丢最旧周期包、保事件包并计数；上报层——每会话独立发送队列与发送循环，YMS 堵只堆 YMS 队列，FDC 链路独立照常；会话层——连续失败判死，级联撤销 YMS 全部计划、退订事件、释放队列与配额。四层共同把故障限制在单个客户端。
4. **如何证明同源/不一致排查**：让 GEM 侧（GemOutlet）与 EDA 采样在同一时刻从同一个 EquipmentDataBus 读同一变量，断言值相等、时间戳一致即可证明同源。若不一致，最可能：①存在第二份数据源/缓存（EDA 自己存了一份而非读权威源）；②时间戳不同源（各用各的时钟/采样时刻错位导致看似值不同）；③单位换算不一致（一侧 SI 一侧工程单位）；④读到更新前后不同版本（缺锁/快照不一致）。根因几乎都是违反"唯一数据源、同一时钟、同一单位基准"。
5. **会话 ID 贯穿组件/作用**：贯穿 EdaSessionManager（认证授权、配额、可见域）、CollectionRuntime（sessionId→plans 映射、计划归属）、ReportService（每会话编码协商与发送队列）、级联撤销（按会话找计划与队列清理）。作用：把"谁订的、能看什么、用什么编码、发给谁、断了清什么"全部串到同一身份上，是授权隔离、数据路由、生命周期级联清理的钥匙；没有会话 ID 就无法做多客户端隔离与僵尸资源回收。
6. **易出问题接缝/测试锁定**：①注册授权接缝——计划是否真的过了可见域/频率闸门（越权用例锁定）；②事件退订接缝——会话关闭后 FSM 回调是否还在触发（关闭后注入事件断言无包）；③Drain 与覆盖接缝——计数 Gap 是否准确（写满覆盖后断言 Overwritten/Gap）；④编码协商接缝——II/III 是否选对编码器（双客户端断言载荷形态）；⑤级联接缝——关闭会话后计划数/队列数是否归零；⑥同源接缝——GEM/EDA 同刻值相等。用端到端集成测试把这些接缝各写一条断言，重构时即可防回归。
7. **换真实 HTTP 动哪里**：只动 ITransport 的实现（把 InMemoryTransport 换成 ASP.NET Core 的 HTTP(S) 回调客户端 / gRPC(HTTP2) 流发送），以及 onboard 时建立真实连接与内容协商；建模、自描述、授权、采样调度、环形缓冲、运行时打包、编码选择、生命周期与级联逻辑全部不动。这就是内核-传输分离的回报：业务逻辑与 xUnit 测试保持有效，只替换最外层传输适配。

## 二、参考实现（net8.0）：EdaServer 门面 + 端到端

```csharp
namespace EapLab.Eda.Server;
public sealed class EdaServer
{
    public EquipmentDataBus Bus{get;}=new();
    public CemObject Model{get;}public WknRegistry Wkn{get;}=new();
    public EdaSessionManager Sessions{get;}=new(8,1000);
    public SampleScheduler Scheduler{get;}
    public CollectionRuntime Runtime{get;}public ReportService Reports{get;}
    readonly InMemoryTransport _trans=new();
    public EdaServer()
    { Model=TypicalToolTree.Build();AssertLint();
      Scheduler=new SampleScheduler(Bus);
      Runtime=new CollectionRuntime(Sessions,Bus);
      Reports=new ReportService(_trans); }
    void AssertLint(){var iss=new CemModelLint().Check(Model);if(iss.Count>0)throw new InvalidOperationException("model lint fail");}

    public string? Connect(string sess,ClientCred cred,string role,Freeze f,Func<string,Grant> grant)
    { var(_,s,err)=Sessions.Open(cred,grant,0);if(err!="")return err;
        Reports.Onboard(new ClientEndpoint(sess,f));return null; }
    public string? Subscribe(string sess,string planId,Trigger t,string[] tags,double hz)
    =>Runtime.Create(sess,planId,t,tags,hz);
    public void Tick(double at)=>Scheduler.Tick(at,_=>Quality.Good);
    public void StepEvent(string planId,double at,double v)=>Runtime.OnEvent(planId,at,v);
    public Packet? Flush(string id)=>Runtime.Flush(id);
    public void Push(string sess,Packet p)=>Reports.Publish(sess,p,x=>"<p/>",x=>new byte[]{9});
    public int Received(string sess)=>_trans.Inbox.GetValueOrDefault(sess)?.Count??0;
    public void DisconnectTransport(){_trans.Disconnected=true;}
}
```

### 端到端 xUnit（三场景）
```csharp
public class EndToEndTests
{
    static Grant G(string r)=>new(){VisiblePrefix=new(){"/Equipment"},MaxHz=r=="FDC"?50:10,MaxTags=9999};
    [Fact] public void 场景A_FDC周期_YMS事件_各取所需()
    { var s=new EdaServer();
      Assert.Null(s.Connect("fdc",new("fdc","tok-fdc","FDC"),"FDC",Freeze.III_PB,G));
      Assert.Null(s.Connect("yms",new("yms","tok-yms","YMS"),"YMS",Freeze.II_XML,G));
      Assert.Null(s.Subscribe("fdc","cyc",Trigger.Periodic,new[]{"/Equipment/PM1/T"},50));
      Assert.Null(s.Subscribe("yms","ev",Trigger.OnEvent,new[]{"/Equipment/Step"},1));
      for(int i=0;i<100;i++){s.Bus.Publish("/Equipment/PM1/T",200+i%5);s.Tick(i*0.01);if(i==50)s.StepEvent("ev",0.5,1);}
      var cyc=s.Flush("cyc")!;var ev=s.Flush("ev")!;
      Assert.NotEmpty(cyc.Rows);Assert.Single(ev.Events); }
    [Fact] public void 场景B_越权超频被拒()
    { var s=new EdaServer();s.Connect("fdc",new("fdc","tok-fdc","FDC"),"FDC",Freeze.II_XML,
        r=>new Grant{VisiblePrefix=new(){"/Equipment/ProcessModule"},MaxHz=50,MaxTags=100});
      Assert.Equal("out of scope",s.Subscribe("fdc","x",Trigger.Periodic,new[]{"/Equipment/Recipe"},10));
      Assert.Equal("hz over grant",s.Subscribe("fdc","y",Trigger.Periodic,new[]{"/Equipment/ProcessModule/t"},1000)); }
    [Fact] public void 场景B_断连级联撤销_配额释放()
    { var s=new EdaServer();s.Connect("yms",new("yms","tok-yms","YMS"),"YMS",Freeze.II_XML,G);
      s.Subscribe("yms","a",Trigger.OnEvent,new[]{"/Equipment/s"},1);s.Subscribe("yms","b",Trigger.Periodic,new[]{"/Equipment/t"},10);
      Assert.Equal(2,s.Runtime.TeardownSession("yms"));Assert.Equal(0,s.Runtime.PlanCount);
      s.Reports.Cancel("yms"); }

      var eda=s.Bus.Read("/Equipment/PM1/T");var gem=s.Bus.Read("/Equipment/PM1/T");
      Assert.Equal(gem,eda); }
}
```

## 三、端到端总图（手绘参考，要求能默画）
```
CEM树─Lint校验─WKN映射─MetaGenerator→EqSD自描述
客户端 ─认证授权(Session, 可见域/Hz配额, 协商II/III)─▶ 提交计划(过授权闸门)
   ├ 周期计划→SampleScheduler(基础tick分级, 读唯一Bus, 单调时间戳)→RingBuffer(覆盖+Gap)
   └ 事件计划→FSM同源事件出口→ECV/EXV独立队列(不丢)
CollectionRuntime flush→Packet(序号/时间窗/质量/Gap)
ReportService 按会话编码(XML/PB)→每会话独立队列→ITransport(II回调/III流)→客户端
保护: 越权超频拒; 慢客户端四层隔离; 连续失败判死→按Session级联撤计划退订清队列; 关闭零残留
同源: GemOutlet 与 EDA 同读 EquipmentDataBus, 同刻同值同戳
换真实HTTP: 仅替换ITransport, 内核与测试不动
```

## 四、今日易错点（集成接缝）
1. 模型未 Lint 就上线（结构/单位/同型一致性问题带到联调）。
2. 计划绕过授权闸门直接注册。
3. 事件订阅在会话关闭后未退订，仍产生快照。
4. Gap/Overwritten 计数在 Drain 后算错，质量码丢失。
5. II/III 编码协商错，老客户端收到 protobuf 无法解析。
6. 断连只关传输、不级联撤计划，僵尸订阅残留。
7. EDA 缓存了一份值导致与 GEM 不同源。
8. 业务逻辑和传输耦合，换 HTTP 要重写且无法单测。
