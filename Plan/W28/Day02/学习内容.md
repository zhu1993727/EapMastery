## 二、背景知识（先读，35 分钟）

### 1. WKN 映射四步
1. **识别通用量**：从成员清单挑出跨设备通用的物理量/状态（腔体温度/压力、RF 功率/反射功率、MFC 流量、真空度、阀门状态、作业/载具/片状态、计数）。
2. **选标准 WKN**：按 E164 语义（标准名+量纲+类型+方向）匹配，不能只看名字像，要看物理语义与量纲。
3. **绑定私有路径**：私有 CEM 路径 ↔ WKN，一对一本设备内唯一；记录映射表（随自描述下发）。
4. **校验一致**：量纲、类型、取值方向（越大越…）、枚举语义与 WKN 定义一致，不一致不许映射。

### 2. 单位与量纲治理（专家级重点）
- 以 **SI 为内部基准**存储（K、Pa、W、sccm/slm、s、比例用 0–1），展示/上报可带工程单位，但必须明确单位字段。
- 常见换算：压力 Pa↔mTorr↔Torr（1 Torr=133.322Pa，1 mTorr=0.133322Pa）；温度 ℃↔K（+273.15）↔℉；功率 W；流量 sccm↔slm(÷1000)。
- **量纲一致性**：映射到"压力 WKN"的必须是压力量纲，流量不能错映压力；温度类不能映成温差（量纲同但语义不同）。
- 枚举语义对齐：状态 WKN 的枚举值顺序/含义要对齐标准（如 0=未知/1=运行…），不能各厂自定编号。

### 3. 覆盖率与未映射量
- 覆盖率=已映射通用量 / 应映射通用量；目标通用量接近全覆盖，否则跨设备规则有缺口。
- 厂商专有/工艺特有量无对应 WKN：保留私有路径、标注 `vendor-specific` 与说明，不硬凑 WKN（硬映错语义比不映更糟）。
- 映射缺失、量纲不符、重复映射（一个 WKN 映到多个不同语义私有量）都要在校验中暴露。

### 4. 命名/映射评审机制
- 评审清单：通用量是否识别全、WKN 选择是否量纲语义一致、单位是否 SI 化、枚举是否对齐、专有量是否标注、路径是否稳定。
- 评审时机：新机型建模后、软件版本变更点表后；冻结后映射表纳入模型版本管理，变更走 ECN（工程变更，后续 W33/W34 会再遇到）。
- 与 FDC/YMS 使用者会签：他们是 WKN 规则的消费者，确认取到的标准量够用。

### 5. 与 GEM 变量命名的关系
- GEM VID 名往往厂商化、面向单 Host；EDA WKN 是跨厂商标准语义层。同一底层量可同时有 GEM VID、私有 CEM 路径、标准 WKN 三个名字，EDA 自描述里同时携带，客户端按需要用（标准分析用 WKN、深度诊断用私有名）。
