# W25 · Day07 答案

## 一、排障推演参考
1. **三要素不低但乘积≠化简式**：这是口径不一致的典型，逐要素对同一权威数据核。①RunTime 口径：A 的分母 RunTime 与 P 的分母 RunTime 是否同一值（P 是否用了净理想时间、A 是否把 Standby 也扣成停机，导致两个 RunTime 不等，约分失败）；②Total 口径：P 的 TotalCount 与 Q 的分母 Total/Decided 是否同一批片（一个含返工、一个不含，或一个按投入一个按产出）；③Good 口径：Q 的 Good 是否就是化简式里的一次合格 Good（是否误用最终良率救回片）；④理想节拍/单位：IdealCT 与时间单位是否统一；⑤Pending：Q 是否把待定片算入。定位方法：令 A×P 展开，看它等不等于 IdealCT×Total/PPT，若不等是 RunTime 口径问题；再乘 Q 看等不等于 IdealCT×Good/PPT，若不等是 Total/Good 口径问题，一层一层锁定。
2. **两班同机型 OEE 差 10 点：真实 vs 口径**：先排口径再比实绩。①时间口径：两班 PPT 是否同（排产/休息/NonScheduled 扣除是否一致）、ScheduledDown 是否同口径扣减、班次时长是否同；②节拍口径：理想节拍是否同一配方同一标准（换了产品却用同一 IdealCT 会假性降速）、cycle 测量点是否同；③质量口径：都用 FPY 还是一个用最终良率、Pending 处理是否同、返工计数是否同；④小停顿/停机阈值：两班 MinorStopLimit 是否一致（阈值不同会把同一事件在 A/P 间挪）；⑤数据同源：是否都用 EPT 状态段+同一时钟、有无手工补录。把两班全部口径拉齐重算，若仍有差异才是真实效率差异，再用损失瀑布对比是哪一层（故障/换型/降速/良率）拉开的，按原因码下钻。跨班/跨机比较的前提是口径完全一致，否则差异可能全是定义差异。

## 二、综合自测卷（8 题）参考答案
1. **MTBF/MTTR/MDT/可用度**：MTBF=运行时间 T_op/故障次数（平均故障间隔，只用运行时间）；MTTR=主动修复时间/故障次数；MDT=(修复+等待备件/人员/后勤)/停机次数（MTTR≤MDT）。Inherent A_i=MTBF/(MTBF+MTTR) 只含主动修复；Achieved 再纳入 PM；Operational=运行/(运行+非计划停+等待后勤)，口径最宽≈OEE 的 A。分母含什么必须声明，PM 不是故障、不计 N_f。
2. **OEE/化简/TEEP**：PPT=日历−NonScheduled；A=RunTime/PPT；P=IdealCT×Total/RunTime；Q=Good/Total(FPY)；OEE=A×P×Q=IdealCT×Good/PPT（化简金标准，用于自洽校验）；TEEP=IdealCT×Good/日历，分母含未排产故 TEEP≤OEE。OEE 看安排生产时效率，TEEP 看全时资产利用。
3. **六损失/小停顿边界/降速**：A 损失=故障、换型；P 损失=小停顿、降速；Q 损失=过程废品、启动不良。小停顿=运行态、无产出、时长在[去抖,停机阈值)且自动恢复（归 P）；达阈值或需维修介入=停机（归 A），阈值固定。降速=实际节拍/理想节拍在滑窗内连续 N 周期超 SlowRatio（或超控制限），单点抖动不算。
4. **FPY vs 最终良率/返工守恒**：FPY=一次合格/总片（OEE 用，因返工占用额外产能）；最终良率含返工救回、≥FPY。返工同一物理片不增片（全局片 ID 集合守恒）、reworkCount 累加、额外占用 RunTime 由 P 承担、不在 Q 里再折时间；量测未回 Pending 挂起不判废；启动损失与过程废品分开。
5. **时间改善须转化为产出**：OEE 化简式=IdealCT×Good/PPT，单纯减少停机/追回时间若不增加 Good（释放时间变待机），分子不变 OEE 不变——表现为 A 升、P 因 RunTime 变大而同比例降，互相抵消。只有把释放/追回时间真正用于多生产合格片（Total、Good 增加），OEE 才升。良率提升不占时间、直接增 Good，在 Q 有空间时杠杆高。
6. **计算器一致性断言**：时间守恒（状态段和=Calendar、Run=PPT−Down）抓重叠/漏记；片 ID 集合守恒（质量账=加工账）抓漏采/重计/返工翻倍；自洽（A×P×Q=化简式）抓 RunTime/Total/Good 口径不一致；要素范围与 TEEP≤OEE 抓分母分子错；Performance>1 告警抓理想节拍偏小/RunTime 少计/Total 多计；Pending>0 提示质量未闭环。任一不过不输出"精确实则错"的 OEE。
7. **非瓶颈提效不增整线产出（TOC）**：整线节拍由瓶颈资源决定，非瓶颈设备本就有空闲/缓冲，把它 OEE 提到最高只会更快地产出在制品堆在瓶颈前，整线产出节奏不变、反增 WIP 与等待浪费。局部 OEE 最大化≠系统最优；改善应优先投向瓶颈（瓶颈的可用率/性能提升才直接放大整线产出），非瓶颈以配合瓶颈、平顺流为目标。设备 OEE 必须结合 W23 资源利用率/瓶颈定位解读。
8. **三模块闭环**：同一批领域事件、同一单调时钟驱动——EPT(E116) 产出互斥完备状态段（时间账）；RAM 从故障段/运行段算 MTBF/MTTR/MDT 与可用度（可靠性视角）；OEE 以时间账定 A、以逐片节拍定 P、以质量结果定 Q，并用化简式与片 ID 守恒把时间账、作业账、质量账锁成一致。三模块共享 EquipmentTimeModel、片 ID 主键与 Cj/Pj 上下文：时间回答"时间花在哪"、RAM 回答"多可靠/多快修复"、OEE 回答"多少变成了有效良品"，层层用同一原料、口径一致，形成从原始事件到管理指标的可追溯闭环，任何指标都能下钻到具体状态段/片/原因码。

## 三、三个费曼讲解要点（口述提纲）
- **消故障不增产 OEE 不变**：OEE 本质是"良品理想时间/计划时间"。修好故障只是把时间从停机挪到运行，若这段时间没多做出良品，分子没增；账面上 A 变好看但 P 被摊薄，乘积不变。所以可靠性改善要和排产/上料配套，让释放的时间真的出片。
- **OEE 为何用 FPY**：OEE 衡量有效利用，返工件第一次没做好、又占了一遍设备，是真实损耗；最终良率把它"洗白"成合格，掩盖返工成本。FPY 让一次没做对暴露出来，和精益"一次做对"一致。
- **非瓶颈提效**：产线像串联水管，流量由最细的管决定；把粗管再加粗，出水不会变多，只会在细管前积水。先找瓶颈（资源利用率≈100%、前面积压），钱和改善花在瓶颈上。

## 五、W25 全周易错点总清单
1. MTTR/MDT 混，等备件等人员误进 MTTR。
2. 用日历时间当 T_op，MTBF 虚高；PM 当故障。
3. 三种可用度不声明分母、混用不可比。
4. OEE 用日历分母（那是 TEEP）；换型漏扣或重复扣。
5. Performance 直接填 100%、忽略小停顿/降速。
6. 理想节拍不按配方、不用稳态 beat、含首片换型。
7. 小停顿阈值不固定，在 A/P 间乱归类；单点抖动误判降速。
8. 只看平均节拍，漏高频小停顿与 P95 长尾。
9. 用最终良率当 Q；返工重复计片；返工时间在 P、Q 双扣。
10. Pending 误判废/合格；质量账不与 E90 片 ID 守恒。
11. A×P×Q 不做化简式自洽；P>1 不告警。
12. 以为消停机就提 OEE（不增产则 A 升 P 降抵消）。
13. 局部 OEE 最大化忽视 TOC，非瓶颈提效不增整线产出。
14. 跨班/跨机不先对齐口径就比较，把定义差异当实绩差异。
