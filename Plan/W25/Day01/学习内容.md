## 二、背景知识（先读，30 分钟）

### 1. 故障的严格定义与计数
- failure（故障/失效）：设备丧失规定功能、不能生产合格产品的事件或状态。要和"提示报警但仍正常生产""外部等料"区分（W24 已建）。
- 计数规则：一次从"可生产→不可生产（Unscheduled Down）"的进入算一次故障事件；同一根因未修复期间的反复报警不重复计数；修复恢复后再次故障算新的一次。
- 关联代码：故障段（UnscheduledDown）段数=故障次数，按原因码/子系统分类统计。

### 2. 时间切分（RAM 口径，比 E10 更细）
- **Uptime/Operating Time（T_op）**：设备可运行（含 Productive 与短暂可用待机，RAM 公式里以"能工作"为准，具体口径显式声明）。
- **Corrective Maintenance Time（T_cm，修复时间）**：实际动手修复的时间。
- **Waiting/Logistics/Administrative Time**：等备件、等人员、等批准——设备没在修也没运行。
- **Preventive Maintenance Time（T_pm）**：预防性维护（计划）。
- **MDT（Mean Down Time / 平均不能工作时间）**：一次停机从发生到恢复可用的平均总时长，含修复+等待/后勤（口径比 MTTR 宽）。
- MTTR 严格指平均"修复"时间；MDT 指平均"停机"时间，现场常混用，必须按口径区分。

### 3. 核心公式
- MTBF（可修复设备，平均故障间隔）= T_op / N_f（两次故障间的平均运行时间，含修复后继续）。
- MTTF（不可修复/到失效平均时间）= 总运行时间/失效数（偏零件寿命）。
- MTTR = T_cm / N_f（平均修复时间）。
- MDT = 总停机时间 / N_停（含修复+等待后勤）。
- 故障频率/失败率 λ=N_f/T_op；MTBF≈1/λ（指数分布假设下，了解即可）。

### 4. 可用度公式族（Availability，分母是关键）
- **Inherent Availability A_i = MTBF/(MTBF+MTTR)**：只看主动修复，理想维护、无等待/后勤/计划停，反映固有设计可靠性。
- **Achieved Availability A_a = MTBM/(MTBM+M̄)**：MTBM 平均维修间隔（含预防+纠正维修）、M̄ 平均维修时间，纳入 PM。
- **Operational/Achieved（运行可用度）= Uptime/(Uptime+Unscheduled Down+等待后勤...)**：按实际日历、含等待后勤，口径最宽，最贴近 OEE 的 Availability。
- 计划停机（PM/换型/未排产）是否进分母决定口径，必须显式声明（W24 已强调，今天公式化）。

### 5. 与 W24/E116 的衔接
- 所有时间从 EPT 状态段与原因码取：UnscheduledDown 段给故障次数与停机时长，段内再细分"修复中/等备件/等人员"子原因，才能分别算 MTTR 与 MDT；Uptime 段给 T_op。
- 数据不足（没细分等待时间）时只能算 MTTR≈MDT，要注明口径限制，不臆造数字。

### 6. 典型陷阱
- 把 PM 当故障拉低 MTBF；把等备件算进 MTTR（应进 MDT）；重复计数同一故障；用日历时间当运行时间算 MTBF（分母虚大）。
