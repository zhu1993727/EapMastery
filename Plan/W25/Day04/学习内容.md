## 二、背景知识（先读，30 分钟）

### 1. Quality 口径
- Quality=Good Count/Total Count（总产出中一次合格的比例，经典 OEE 用 First Pass 口径）。
- **FPY（First Pass Yield，一次通过率）**：第一次通过就合格、不需返工的比例；经典 OEE Quality 通常对应 FPY，因为返工件占用了额外产能。
- **最终良率（Final Yield）**：经过返工修复后最终合格的比例，会高于 FPY，但掩盖了返工消耗的产能。
- OEE 用 FPY 才能把返工损失体现出来；若用最终良率，返工"白用"的设备时间被忽略。

### 2. 质量结果分类（设备/检测端）
- Good 合格；Scrap 报废（不可修复）；Rework 可返工（重新过某工艺）；Startup-loss 启动/暖机/换型后首批不良（可归 Scrap 或专门标记，用于区分稳态过程缺陷）。
- 数据来自量测/检测结果与分档（W23 Binning：量测后、放置前定档），设备 EAP 采集每片结果与缺陷代码、关联 Cj/Pj/Step。

### 3. 返工与片数守恒（关键，接 W14/W23）
- 返工是同一物理片重新加工：**不增加片数**（全局 SubstrateId 集合守恒），但加工次数/占用设备时间累加（reworkCount、MaxRework）。
- 返工片第一次产出时不是 Good（计入 Total 但非 Good，拉低 FPY）；返工后合格计入最终良率，但其额外占用的 Run Time 已体现在 Performance/Availability 时间里。
- 避免双重计算：质量上按一次通过算 FPY；时间上返工多花的时间自然落在 RunTime（产出间隔变大→Performance），不要在 Quality 里再折算一遍时间。

### 4. 启动损失 Startup/Reduced Yield
- 开机、换型、PM 后暖机阶段，工艺未稳定产生的不良：六大损失第⑥项（Quality）。
- 与稳态过程废品（第⑤项）分开统计，因为改善手段不同：启动损失靠标准化暖机/首件确认/recipe 管理，过程废品靠工艺控制（接 FDC/SPC）。
- 用"换型/开工后前 N 片"窗口标记，便于量化启动良率。

### 5. Quality 与设备端责任边界
- 设备端负责如实采集每片结果与时间/作业上下文、保证计数与 E90 位置/片数守恒一致；缺陷判定本身可能来自外部量测（YMS/检测设备），EAP 做关联落账，不自行篡改结果。

### 6. 典型陷阱
- 用最终良率当 OEE Quality（掩盖返工）；返工片重复计入 Total（片数翻倍）；Scrap 与 Startup 混在一起无法定位；质量计数与 E90 片数对不上；把外部量测延迟导致的"暂无结果"误算废品。
