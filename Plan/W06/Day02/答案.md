# W06 · Day02 答案与参考实现

## 一、自测题标准答案
1. **S2F33 body 结构 / RPTID 和 VID 列表含义**：`L,2[U2 RPTID, L,n[U2 VID, U2 VID, ...]]`。RPTID（Report ID）是要定义/覆盖的报告的唯一标识；VID 列表是该报告包含的变量 ID 集合（n 个，每个是 U2 类型的 VID，可以是 SV 或 DV 的 VID）。S2F33 的作用是"定义报告里包含哪些变量"，即报告的内容模板。
2. **ACKC5=0 / =3 含义 / Host 收到 =3 怎么做**：ACKC5=0=**成功**，报告已定义/覆盖；ACKC5=3=**变量 ID 不存在**，VID 列表中有设备不支持的 VID，整个报告定义失败。Host 收到 =3 后：检查 VID 列表，对比 S1F4（SV 列表）确认哪些 VID 不存在，修正后重新发送 S2F33；不应盲目重发原消息（会一直失败）。
3. **RPTID 已存在再发 S2F33 会怎样 / 已关联事件受影响吗**：会**覆盖**原报告——用新的 VID 列表替换旧的 VID 列表，RPTID 不变。已关联的事件**不受影响**——事件与报告的关联关系（S2F35 定义的 CEID-RPTID 映射）保持不变，但报告内容变了，后续事件触发时按新的 VID 列表采集变量。这是解耦的好处：改报告内容不需要重新关联事件。
4. **空 VID 列表（L,0）表示什么**：表示**删除该报告**（或定义一个空报告，具体以设备实现为准）。标准实践是用空 VID 列表删除报告——Host 发 S2F33(RPTID=X, VID=[])，设备删除 RPTID=X 的报告定义。如果该报告已被事件关联，删除后事件关联关系可能失效（设备可能自动取消关联，或在事件触发时忽略不存在的报告），具体以设备实现为准。
5. **报告里能否混合 SV 和 DV / 事件触发时怎么采集**：**可以混合**。报告的 VID 列表中可以同时包含 SV 的 VID 和 DV 的 VID。事件触发时，设备对报告中的每个 VID 采集值——SV 取事件触发时刻的当前值（因为 SV 是状态变量，随时可查），DV 取事件触发时刻的瞬时值（因为 DV 是事件采集变量，只在事件发生时有效）。两者都按 S2F33 定义的 VID 顺序排列，组装成 S6F11 的报告内容。
6. **设备重启后已定义的报告还在吗 / Host 怎么做**：**通常不在**。报告定义存储在设备的内存中，设备重启后丢失（除非设备支持持久化存储，如写入 Flash/配置文件，但这不是标准要求）。Host 应该在每次建链完成后（S1F13/S1F17 之后）重新定义报告和关联事件——这是标准的 GEM 初始化流程。Host 也可以通过 S1F7 查询报告列表确认设备是否还有报告定义，如果为空就重新定义。

## 二、手算 S2F33 hex（对照 W3 编码器）

### 例1：RPTID=1, VID=[100,101]
```
body = L,2[
  U2=1,          // RPTID
  L,2[           // VID 列表
    U2=100,
    U2=101
  ]
]
```
编码：
- L,2 = `20 02`
- U2=1 = `68 02 00 01`（类型码 27<<2=0x6C？不对，U2 类型码是 42，42<<2=0xA8）
  - 修正：U2 类型码=42，42<<2=0xA8，长度字节数=2，低2位=2-1=1 → 0xA8 | 1 = 0xA9？不对。
  - 格式字节 = 类型码(高6位)<<2 | (长度字节数-1)(低2位)。U2 类型码=42，42<<2=168=0xA8；长度字节数=2，2-1=1；0xA8 | 1 = 0xA9。
  - 所以 U2=1 = `A9 00 01`（格式字节 A9，值 00 01）。
- L,2 = `20 02`
- U2=100 = `A9 00 64`（100=0x64）
- U2=101 = `A9 00 65`（101=0x65）

完整 body hex：`20 02 A9 00 01 20 02 A9 00 64 A9 00 65`

### 例2：RPTID=2, VID=[200]
```
body = L,2[U2=2, L,1[U2=200]]
```
编码：`20 02 A9 00 02 20 01 A9 00 C8`（200=0xC8）

> 注意：格式字节计算要仔细，U2 的格式字节是 0xA9（不是 0xA8），因为长度字节数-1=1。对照 W3 Day02 的格式字节表验证。

## 三、参考实现（EapLab.Gem/DataCollection/）

### ReportDefinition.cs
```csharp
namespace EapLab.Gem.DataCollection;

/// <summary>报告定义：RPTID + 包含的 VID 列表。</summary>
public sealed class ReportDefinition
{
    public ushort RptId { get; }
    public List<ushort> VidList { get; }
    public DateTime CreatedAt { get; set; }

    public ReportDefinition(ushort rptId, IEnumerable<ushort> vidList)
    {
        RptId = rptId;
        VidList = vidList.ToList();
        CreatedAt = DateTime.Now;
    }

    public bool IsEmpty => VidList.Count == 0;
}
```

### ReportStore.cs
```csharp
using System.Collections.Concurrent;

namespace EapLab.Gem.DataCollection;

/// <summary>报告存储：Dictionary<RPTID, ReportDefinition>，线程安全。</summary>
public sealed class ReportStore
{
    private readonly ConcurrentDictionary<ushort, ReportDefinition> _reports = new();
    private readonly ISet<ushort> _supportedVids; // 设备支持的 VID 集合（从 S1F4 加载）

    public ReportStore(IEnumerable<ushort> supportedVids)
    {
        _supportedVids = new HashSet<ushort>(supportedVids);
    }

    /// <summary>定义/覆盖报告。返回 ACKC5（0=成功，3=VID不存在）。</summary>
    public byte Define(ushort rptId, IEnumerable<ushort> vidList)
    {
        var vids = vidList.ToList();

        // 校验：所有 VID 必须是设备支持的（空列表除外，空列表=删除）
        if (vids.Count > 0)
        {
            foreach (var vid in vids)
            {
                if (!_supportedVids.Contains(vid))
                    return 3; // ACKC5=3: 变量 ID 不存在
            }
        }

        if (vids.Count == 0)
        {
            // 空列表 = 删除报告
            _reports.TryRemove(rptId, out _);
        }
        else
        {
            // 定义/覆盖
            _reports[rptId] = new ReportDefinition(rptId, vids);
        }
        return 0; // ACKC5=0: 成功
    }

    public bool TryGet(ushort rptId, out ReportDefinition? report)
        => _reports.TryGetValue(rptId, out report);

    public IReadOnlyList<ushort> GetAllRptIds() => _reports.Keys.OrderBy(k => k).ToList();

    public void Clear() => _reports.Clear(); // 设备重启/建链时清空
}
```

### S2F33Handler.cs
```csharp
using EapLab.Secs2;
using EapLab.Transport.Logging;

namespace EapLab.Gem.DataCollection;

/// <summary>S2F33 Define Report 处理器。</summary>
public sealed class S2F33Handler
{
    private readonly ReportStore _store;
    private readonly ILogSink _log;

    public S2F33Handler(ReportStore store, ILogSink log)
    {
        _store = store;
        _log = log;
    }

    /// <summary>处理 S2F33，返回 S2F34 body。</summary>
    public SecsItem Handle(SecsItem? body)
    {
        if (body is not SecsList root || root.Items.Count != 2)
            return BuildReply(4, 0); // ACKC5=4: 格式错误

        // 解析 RPTID
        if (root.Items[0] is not SecsU2 rptIdItem || rptIdItem.Values.Length != 1)
            return BuildReply(4, 0);
        ushort rptId = rptIdItem.Values[0];

        // 解析 VID 列表
        if (root.Items[1] is not SecsList vidList)
            return BuildReply(4, rptId);
        var vids = new List<ushort>();
        foreach (var item in vidList.Items)
        {
            if (item is SecsU2 u2 && u2.Values.Length == 1)
                vids.Add(u2.Values[0]);
            else
                return BuildReply(4, rptId); // 格式错误
        }

        // 定义/覆盖报告
        byte ackc5 = _store.Define(rptId, vids);
        _log.Log(LogDir.INFO, $"S2F33 Define Report RPTID={rptId} VID=[{string.Join(",", vids)}] ACKC5={ackc5}");

        return BuildReply(ackc5, rptId);
    }

    /// <summary>S2F34 body = L,2[U1 ACKC5, U2 RPTID]</summary>
    private static SecsItem BuildReply(byte ackc5, ushort rptId)
        => SecsItem.L(SecsItem.U1(ackc5), SecsItem.U2(rptId));
}
```

### 单测
```csharp
public class S2F33HandlerTests
{
    private static S2F33Handler CreateHandler(params ushort[] supportedVids)
    {
        var store = new ReportStore(supportedVids);
        return new S2F33Handler(store, new ConsoleLogSink());
    }

    [Fact]
    public void 成功定义报告()
    {
        var handler = CreateHandler(100, 101, 102);
        var body = SecsItem.L(SecsItem.U2(1), SecsItem.L(SecsItem.U2(100), SecsItem.U2(101)));
        var reply = handler.Handle(body);
        var list = (SecsList)reply;
        Assert.Equal(0, ((SecsU1)list.Items[0]).Values[0]); // ACKC5=0
        Assert.Equal(1, ((SecsU2)list.Items[1]).Values[0]);  // RPTID=1
    }

    [Fact]
    public void 覆盖已有报告()
    {
        var handler = CreateHandler(100, 101, 200);
        // 第一次定义
        handler.Handle(SecsItem.L(SecsItem.U2(1), SecsItem.L(SecsItem.U2(100))));
        // 第二次覆盖
        var reply = handler.Handle(SecsItem.L(SecsItem.U2(1), SecsItem.L(SecsItem.U2(200))));
        var list = (SecsList)reply;
        Assert.Equal(0, ((SecsU1)list.Items[0]).Values[0]); // 覆盖成功
    }

    [Fact]
    public void VID不存在返回ACKC5_3()
    {
        var handler = CreateHandler(100, 101);
        var body = SecsItem.L(SecsItem.U2(1), SecsItem.L(SecsItem.U2(999))); // 999 不存在
        var reply = handler.Handle(body);
        var list = (SecsList)reply;
        Assert.Equal(3, ((SecsU1)list.Items[0]).Values[0]); // ACKC5=3
    }

    [Fact]
    public void 空VID列表删除报告()
    {
        var handler = CreateHandler(100);
        handler.Handle(SecsItem.L(SecsItem.U2(1), SecsItem.L(SecsItem.U2(100))));
        // 删除
        var reply = handler.Handle(SecsItem.L(SecsItem.U2(1), SecsItem.L())); // 空列表
        var list = (SecsList)reply;
        Assert.Equal(0, ((SecsU1)list.Items[0]).Values[0]); // 删除成功
    }
}
```

## 四、今日易错点
1. S2F33 body 结构记错（是 L,2[U2 RPTID, L,n[U2 VID]]，不是 L,n[U2 RPTID, U2 VID]）。
2. U2 格式字节算错（U2 格式字节是 0xA9，不是 0xA8，因为长度字节数-1=1）。
3. 以为 RPTID 已存在再定义会报错（会覆盖，不是报错）。
4. 以为空 VID 列表是"定义空报告"（标准实践是删除报告）。
5. VID 列表中有不存在的 VID 时以为部分成功（整个报告定义失败，回 ACKC5=3）。
6. 以为报告定义在设备重启后还在（通常丢失，Host 每次建链后重新定义）。
7. 混淆 RPTID 和 VID（RPTID 是报告 ID，VID 是变量 ID，报告包含变量）。
8. 以为报告里只能放 SV 或只能放 DV（可以混合）。
