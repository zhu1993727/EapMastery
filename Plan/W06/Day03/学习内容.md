## 二、背景知识（先读，25 分钟）

### 1. S2F35 body 结构（必背）
```
S2F35 Link Event Report (Host → Equipment, W=1)
body = L,2[
  U2 CEID,              // 事件 ID（要关联的事件）
  L,n[                  // 该事件关联的报告 ID 列表（n 个 RPTID）
    U2 RPTID,
    U2 RPTID,
    ...
  ]
]
```
- CEID：U2 类型，事件的唯一标识。Host 指定要关联的事件。
- RPTID 列表：L,n[U2]，该事件触发时要上报哪些报告。n 可以为 0（空列表，表示取消该事件的所有关联，等价于 S2F37）。
- 注意：RPTID 必须是已通过 S2F33 定义的报告。如果 RPTID 未定义，设备回 ACKC6 非 0。

### 2. S2F36 body 结构（必背）
```
S2F36 Link Event Report Acknowledge (Equipment → Host, W=0)
body = L,2[
  U1 ACKC6,              // 关联结果（0=成功，非0=失败）
  U2 CEID                // 对应的事件 ID
]
```
- ACKC6 常见值：
  - **0 = 成功**（事件-报告关联已建立）
  - **1 = 拒绝**（设备不允许关联，如通信 OFF-LINE）
  - **2 = 事件 ID 不存在**（CEID 设备不支持）
  - **3 = 报告 ID 不存在**（RPTID 未通过 S2F33 定义）
  - **4 = 其他错误**
- 具体值以设备实现为准，核心是 0=成功，非0=各种失败。

### 3. 关联规则
1. **CEID 必须存在**：CEID 必须是设备支持的事件（可通过 S1F5 查询）。如果 CEID 不存在，设备回 ACKC6=2。
2. **RPTID 必须已定义**：RPTID 列表中的每个 RPTID 必须是已通过 S2F33 定义的报告。如果 RPTID 未定义，设备回 ACKC6=3。
3. **一个事件可关联多个报告**：CEID 关联的 RPTID 列表可以有多个。事件触发时，设备同时采集所有关联报告的变量，一起在 S6F11 中上报（报告列表里有多个报告）。
4. **一个报告可被多个事件关联**：同一个 RPTID 可以出现在多个 CEID 的关联列表中。不同事件触发时都上报同一份报告模板，但采集的变量值不同（事件时刻不同）。
5. **重新关联覆盖**：如果 CEID 已有关联，再发 S2F35 关联同一个 CEID，会**覆盖**原关联（用新的 RPTID 列表替换旧的）。
6. **空 RPTID 列表取消关联**：如果 RPTID 列表为空（L,0），表示取消该事件的所有报告关联（等价于 S2F37）。

### 4. S2F37 Unlink Event Report（取消关联）
```
S2F37 Unlink Event Report (Host → Equipment, W=1)
body = L,2[
  U2 CEID,              // 事件 ID
  L,n[                  // 要取消关联的报告 ID 列表
    U2 RPTID,
    ...
  ]
]
```
- S2F37 用于取消事件与报告的关联。
- 如果 RPTID 列表为空（L,0），表示取消该事件的**所有**报告关联。
- 如果指定了 RPTID 列表，只取消列表中的报告关联，其他关联保留。
- S2F38 是确认，body = L,2[U1 ACKC7, U2 CEID]，ACKC7=0 表示成功。

### 5. 事件-报告关联的存储
- 设备维护一个关联表：`Dictionary<CEID, List<RPTID>>`。
- 事件触发时，设备查关联表，获取该 CEID 关联的所有 RPTID，然后对每个 RPTID 查报告定义表获取 VID 列表，采集变量值，组装 S6F11。
- 关联表和报告定义表配合使用：报告定义表存"报告包含哪些变量"，关联表存"事件触发哪些报告"。

### 6. 数据采集配置完整流程（S2F33 + S2F35）
```
1. Host 查询能力：S1F3(SV列表)、S1F5(CEID列表)
2. Host 定义报告：
   S2F33(RPTID=1, VID=[100,101]) → S2F34 ACKC5=0
   S2F33(RPTID=2, VID=[200,201]) → S2F34 ACKC5=0
3. Host 关联事件：
   S2F35(CEID=3001, RPTID=[1,2]) → S2F36 ACKC6=0  (事件3001关联报告1和2)
   S2F35(CEID=3002, RPTID=[1])   → S2F36 ACKC6=0  (事件3002关联报告1)
4. 事件触发：
   CEID=3001 发生 → 采集报告1(VID 100,101) + 报告2(VID 200,201) → S6F11 上报
   CEID=3002 发生 → 采集报告1(VID 100,101) → S6F11 上报
```
