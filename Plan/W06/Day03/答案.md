# W06 · Day03 答案与参考实现

## 一、自测题标准答案
1. **S2F35 body 结构 / CEID 和 RPTID 列表含义**：`L,2[U2 CEID, L,n[U2 RPTID, U2 RPTID, ...]]`。CEID（Collection Event ID）是要关联的事件的唯一标识（数据采集触发器）；RPTID 列表是该事件触发时要上报的报告 ID 集合（n 个，每个是已通过 S2F33 定义的报告）。S2F35 的作用是"定义事件触发时上报哪些报告"，即把"什么时候采集"和"采集什么"关联起来。
2. **ACKC6=0/=2/=3 含义**：ACKC6=0=**成功**，事件-报告关联已建立；ACKC6=2=**事件 ID 不存在**，CEID 设备不支持；ACKC6=3=**报告 ID 不存在**，RPTID 未通过 S2F33 定义。Host 收到 =2 时检查 CEID 是否正确（对比 S1F6 事件列表）；收到 =3 时先确认报告是否已定义（S2F33 是否成功），修正后重新发送。
3. **CEID 已有关联再发 S2F35 会怎样**：会**覆盖**原关联——用新的 RPTID 列表替换旧的 RPTID 列表，CEID 不变。这和 S2F33 覆盖报告是同一个设计思路：重新定义即覆盖。如果要保留原有关联并新增报告，Host 需要在 S2F35 中包含原有的 RPTID + 新增的 RPTID（即完整的新列表），而不是只发新增的。
4. **一个事件能否关联多个报告 / 事件触发时怎么上报**：**可以**。一个 CEID 可以关联多个 RPTID，事件触发时，设备同时采集所有关联报告的变量，然后在一条 S6F11 中一起上报——S6F11 的报告列表（L,n）里有多个报告，每个报告是 L,2[RPTID, 变量值列表]。Host 收到一条 S6F11 就能拿到该事件触发的所有报告数据。
5. **空 RPTID 列表在 S2F35 中表示什么 / 和 S2F37 的关系**：空 RPTID 列表（L,0）表示**取消该事件的所有报告关联**——等价于 S2F37(CEID, 空列表)。这是一种便捷写法：Host 不想用 S2F37，直接发 S2F35(CEID, 空列表) 就能取消该事件的所有关联。S2F37 更灵活，可以指定取消部分报告关联（保留其他），而 S2F35 空列表只能取消全部。
6. **S2F37 指定 RPTID 列表时取消所有还是部分**：**只取消列表中的报告关联**，其他关联保留。例如 CEID=3001 关联了 RPTID=[1,2,3]，Host 发 S2F37(CEID=3001, RPTID=[2])，则取消报告2的关联，保留报告1和3，最终关联变为 RPTID=[1,3]。如果 RPTID 列表为空（L,0），则取消该事件的**所有**关联。这是 S2F37 和 S2F35 空列表的区别：S2F37 可以部分取消，S2F35 空列表只能全部取消。

## 二、手算 S2F35 hex

### 例1：CEID=3001, RPTID=[1,2]
```
body = L,2[U2=3001, L,2[U2=1, U2=2]]
```
编码：
- L,2 = `20 02`
- U2=3001 = `A9 0B B9`（3001=0x0BB9）
- L,2 = `20 02`
- U2=1 = `A9 00 01`
- U2=2 = `A9 00 02`

完整 body hex：`20 02 A9 0B B9 20 02 A9 00 01 A9 00 02`

### 例2：CEID=3002, RPTID=[1]
```
body = L,2[U2=3002, L,1[U2=1]]
```
编码：`20 02 A9 0B BA 20 01 A9 00 01`（3002=0x0BBA）

## 三、参考实现（EapLab.Gem/DataCollection/）

### EventReportLinkStore.cs
```csharp
using System.Collections.Concurrent;

namespace EapLab.Gem.DataCollection;

/// <summary>事件-报告关联存储：Dictionary<CEID, List<RPTID>>。</summary>
public sealed class EventReportLinkStore
{
    private readonly ConcurrentDictionary<ushort, List<ushort>> _links = new();
    private readonly ISet<ushort> _supportedCeids;
    private readonly ReportStore _reportStore;

    public EventReportLinkStore(IEnumerable<ushort> supportedCeids, ReportStore reportStore)
    {
        _supportedCeids = new HashSet<ushort>(supportedCeids);
        _reportStore = reportStore;
    }

    /// <summary>关联事件-报告。返回 ACKC6（0=成功，2=CEID不存在，3=RPTID不存在）。</summary>
    public byte Link(ushort ceid, IEnumerable<ushort> rptIds)
    {
        var rpts = rptIds.ToList();

        // 校验 CEID 存在（空列表取消关联时也需要 CEID 存在）
        if (!_supportedCeids.Contains(ceid))
            return 2; // ACKC6=2: 事件 ID 不存在

        // 校验 RPTID 已定义（空列表除外）
        if (rpts.Count > 0)
        {
            foreach (var rptId in rpts)
            {
                if (!_reportStore.TryGet(rptId, out _))
                    return 3; // ACKC6=3: 报告 ID 不存在
            }
            _links[ceid] = rpts; // 覆盖
        }
        else
        {
            // 空列表 = 取消所有关联
            _links.TryRemove(ceid, out _);
        }
        return 0;
    }

    /// <summary>取消事件-报告关联。返回 ACKC7（0=成功，2=CEID不存在）。</summary>
    public byte Unlink(ushort ceid, IEnumerable<ushort> rptIds)
    {
        if (!_supportedCeids.Contains(ceid))
            return 2;

        var rpts = rptIds.ToList();
        if (rpts.Count == 0)
        {
            // 空列表 = 取消所有关联
            _links.TryRemove(ceid, out _);
        }
        else if (_links.TryGetValue(ceid, out var existing))
        {
            // 只取消列表中的报告关联
            foreach (var rptId in rpts)
                existing.Remove(rptId);
            if (existing.Count == 0)
                _links.TryRemove(ceid, out _);
        }
        return 0;
    }

    public IReadOnlyList<ushort> GetLinkedReports(ushort ceid)
        => _links.TryGetValue(ceid, out var rpts) ? rpts.ToList() : new List<ushort>();

    public void Clear() => _links.Clear();
}
```

### S2F35Handler.cs
```csharp
using EapLab.Secs2;
using EapLab.Transport.Logging;

namespace EapLab.Gem.DataCollection;

public sealed class S2F35Handler
{
    private readonly EventReportLinkStore _store;
    private readonly ILogSink _log;

    public S2F35Handler(EventReportLinkStore store, ILogSink log)
    {
        _store = store;
        _log = log;
    }

    public SecsItem Handle(SecsItem? body)
    {
        if (body is not SecsList root || root.Items.Count != 2)
            return BuildReply(4, 0);

        if (root.Items[0] is not SecsU2 ceidItem || ceidItem.Values.Length != 1)
            return BuildReply(4, 0);
        ushort ceid = ceidItem.Values[0];

        if (root.Items[1] is not SecsList rptList)
            return BuildReply(4, ceid);
        var rpts = new List<ushort>();
        foreach (var item in rptList.Items)
        {
            if (item is SecsU2 u2 && u2.Values.Length == 1)
                rpts.Add(u2.Values[0]);
            else
                return BuildReply(4, ceid);
        }

        byte ackc6 = _store.Link(ceid, rpts);
        _log.Log(LogDir.INFO, $"S2F35 Link CEID={ceid} RPTID=[{string.Join(",", rpts)}] ACKC6={ackc6}");
        return BuildReply(ackc6, ceid);
    }

    private static SecsItem BuildReply(byte ackc6, ushort ceid)
        => SecsItem.L(SecsItem.U1(ackc6), SecsItem.U2(ceid));
}
```

### 单测（节选）
```csharp
public class S2F35HandlerTests
{
    private static (S2F35Handler, ReportStore) CreateHandler()
    {
        var reportStore = new ReportStore(new[] { 100, 101, 200 });
        reportStore.Define(1, new[] { 100, 101 });
        reportStore.Define(2, new[] { 200 });
        var linkStore = new EventReportLinkStore(new[] { 3001, 3002 }, reportStore);
        return (new S2F35Handler(linkStore, new ConsoleLogSink()), reportStore);
    }

    [Fact]
    public void 成功关联()
    {
        var (handler, _) = CreateHandler();
        var body = SecsItem.L(SecsItem.U2(3001), SecsItem.L(SecsItem.U2(1), SecsItem.U2(2)));
        var reply = handler.Handle(body);
        var list = (SecsList)reply;
        Assert.Equal(0, ((SecsU1)list.Items[0]).Values[0]);
    }

    [Fact]
    public void CEID不存在返回ACKC6_2()
    {
        var (handler, _) = CreateHandler();
        var body = SecsItem.L(SecsItem.U2(9999), SecsItem.L(SecsItem.U2(1)));
        var reply = handler.Handle(body);
        Assert.Equal(2, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
    }

    [Fact]
    public void RPTID不存在返回ACKC6_3()
    {
        var (handler, _) = CreateHandler();
        var body = SecsItem.L(SecsItem.U2(3001), SecsItem.L(SecsItem.U2(999)));
        var reply = handler.Handle(body);
        Assert.Equal(3, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
    }

    [Fact]
    public void 空列表取消关联()
    {
        var (handler, _) = CreateHandler();
        handler.Handle(SecsItem.L(SecsItem.U2(3001), SecsItem.L(SecsItem.U2(1))));
        var reply = handler.Handle(SecsItem.L(SecsItem.U2(3001), SecsItem.L())); // 空列表
        Assert.Equal(0, ((SecsU1)((SecsList)reply).Items[0]).Values[0]);
    }
}
```

## 四、今日易错点
1. S2F35 body 结构记错（是 L,2[U2 CEID, L,n[U2 RPTID]]，不是 L,n[U2 CEID, U2 RPTID]）。
2. 以为 CEID 已有关联再发 S2F35 会追加（会覆盖，不是追加）。
3. 以为 S2F35 空列表和 S2F37 完全一样（S2F35 空列表=取消全部，S2F37 可以部分取消）。
4. RPTID 未通过 S2F33 定义就发 S2F35（会回 ACKC6=3，必须先定义报告）。
5. 以为一个事件只能关联一个报告（可以关联多个，S6F11 报告列表里有多个）。
6. 混淆 ACKC5（S2F34）和 ACKC6（S2F36）和 ACKC7（S2F38）——分别是定义报告、关联事件、取消关联的确认码。
7. 取消关联后以为报告定义也被删除（S2F37 只取消关联，报告定义还在，可重新关联）。
