```

  │                                          │
  │── 1. S1F3(空) 查询SV列表 ─────────────►│
  │◄─ S1F4 (VID+名称列表) ─────────────────│
  │── 2. S1F5(空) 查询事件列表 ────────────►│
  │◄─ S1F6 (CEID+名称列表) ────────────────│
  │── 3. S1F7(空) 查询报告列表 ────────────►│
  │◄─ S1F8 (空，重启后无报告) ──────────────│
  │                                          │
  │── 4. S2F33 Define Report(RPTID=1,VID=[100,101]) ►│
  │◄─ S2F34 ACKC5=0 ───────────────────────│  DATAID=1
  │── 5. S2F35 Link Event(CEID=3001,RPTID=[1]) ►│
  │◄─ S2F36 ACKC6=0 ───────────────────────│
  │                                          │
  │          6. 设备事件发生(CEID=3001)      │
  │          7. 查关联→RPTID=[1]→查报告→VID=[100,101] │
  │          8. 采集 VID=100(当前温度), VID=101(当前压力) │
  │          9. 组装 S6F11(DATAID=1, CEID=3001, 报告1=[25.5,100]) │
  │◄─ 10. S6F11 Event Report Send(W=1) ─────│
  │── 11. S6F12 ACK(DATAID=1) ─────────────►│
  │                                          │
  │── 12. S1F11(VID=[100,101]) 轮询当前值 ─►│
  │◄─ S1F12 ([25.6, 101]) ─────────────────│
```

## 四、4 个场景的验收标准

### 场景1：正常采集全链路
- Host 完成建链（W5 的完整流程）。
- Host 发 S1F3/S1F5/S1F7，获取 SV 列表、事件列表、报告列表（空）。
- Host 发 S2F33 定义报告1（RPTID=1, VID=[100,101]），设备回 ACKC5=0。
- Host 发 S2F35 关联事件1（CEID=3001, RPTID=[1]），设备回 ACKC6=0。
- 设备触发事件1（模拟 Lot Start），设备发 S6F11（DATAID=1, CEID=3001, 报告1=[温度值,压力值]）。
- Host 收 S6F11，解析正确，回 S6F12。
- Host 发 S1F11 轮询 VID=100,101，设备回当前值。
- 抓包：所有消息 hex 与预期一致。

### 场景2：多报告多事件
- 定义报告1（RPTID=1, VID=[100]）、报告2（RPTID=2, VID=[101,102]）。
- 关联事件1（CEID=3001, RPTID=[1,2]）、事件2（CEID=3002, RPTID=[2]）。
- 触发事件1：S6F11 报告列表有 2 个报告（报告1+报告2）。
- 触发事件2：S6F11 报告列表有 1 个报告（报告2）。
- 验证：每个报告的变量值正确，顺序正确。

### 场景3：重新配置报告（DATAID 变化）
- 初始：报告1（RPTID=1, VID=[100,101]），DATAID=1。
- 触发事件1：S6F11 带 DATAID=1，报告1有 2 个变量。
- Host 重新定义报告1（S2F33, RPTID=1, VID=[100,101,102]），覆盖原报告。
- DATAID 递增为 2。
- 触发事件1：S6F11 带 DATAID=2，报告1有 3 个变量（新增 102）。
- 验证：Host 能通过 DATAID 判断报告是按新配置采集的。

### 场景4：未关联事件不上报
- 定义报告1，关联事件1（CEID=3001）。
- 触发事件2（CEID=3002，未关联报告）。
- 验证：设备不发 S6F11（事件2无关联，跳过）。
- 触发事件1：设备发 S6F11。
- 验证：只有关联了报告的事件才上报。
