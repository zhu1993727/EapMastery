# W06 · Day04 答案与参考实现

## 一、自测题标准答案
1. **S6F11 body 结构 / DATAID/CEID/报告列表含义**：`L,3[U4 DATAID, U2 CEID, L,n[L,2[U2 RPTID, L,m[变量值...]]]]`。DATAID（Data Collection Definition ID）是数据收集定义 ID，标识当前这套"报告定义+事件关联"的配置版本；CEID（Collection Event ID）是触发本次上报的事件 ID；报告列表是 n 个报告，每个报告包含 RPTID 和该报告的变量值列表（按 S2F33 定义的 VID 顺序排列）。S6F11 是设备主动发给 Host 的事件报告，W=1，需要 Host 回 S6F12。
2. **变量值类型由什么决定 / Host 怎么知道类型**：变量值的**类型**由 VID 对应的变量类型决定——VID=100 如果在 S1F4（SV 列表）中定义为 F4（温度），则 S6F11 中该位置就是 F4 类型的值。Host 通过 S1F3/S1F4 查询设备支持的 SV 列表时，获取每个 VID 的名称和类型，建立 VID→类型的映射表，解析 S6F11 时按位置和类型映射表解析每个变量值。S6F11 中**不带 VID**，只带值，所以 Host 必须知道报告定义（RPTID→VID 列表）和 VID→类型映射才能正确解析。
3. **S6F12 body / 回 S6F12 表示什么**：S6F12 body = `U4 DATAID`（与 S6F11 中的 DATAID 相同）。Host 回 S6F12 表示"我收到了这份事件报告"，是确认消息，不是数据。S6F12 是 W=0（不需要设备再回）。如果 Host 不回 S6F12，设备可能重发 S6F11（取决于设备实现和 Spool 配置，W8 细讲）。
4. **事件无关联时设备会发 S6F11 吗 / 为什么**：**不会**。只有被 Host 通过 S2F35 关联了报告的事件，触发时才会采集变量并发 S6F11。未关联的事件只在设备内部记录（设备日志），不发给 Host。这是为了减少通信量——Host 只关心它关联的事件，其他事件不需要上报。设备触发事件时先查 EventReportLinkStore，如果该 CEID 没有关联的 RPTID，直接跳过，不组装也不发送。
5. **DATAID 什么时候变化 / Host 为什么需要知道**：DATAID 在 Host 每次重新配置数据采集时变化——S2F33 定义/覆盖报告、S2F35 关联/覆盖事件、S2F37 取消关联，都会导致设备递增 DATAID。Host 需要知道 DATAID 是为了**确认报告是按哪套配置采集的**——如果 Host 刚改了报告定义（如新增了一个变量），但收到的 S6F11 还带旧 DATAID，说明设备还在用旧配置，报告里没有新增的变量，Host 可以判断数据是否符合预期。DATAID 也用于 S6F12 确认（Host 回 DATAID 表示收到了哪套配置的报告）。
6. **一个事件关联 3 个报告时 S6F11 报告列表有几个 / 变量值怎么排列**：S6F11 的报告列表（L,n）里有 **3 个报告**，n=3。每个报告是 L,2[U2 RPTID, L,m[变量值...]]，变量值按该报告 S2F33 定义的 VID 顺序排列。3 个报告在 S6F11 中按 S2F35 关联时的 RPTID 顺序排列（Host 发 S2F35 时 RPTID 列表的顺序）。Host 解析时先按报告位置找到 RPTID，再查该报告的 VID 列表，按位置和 VID→类型映射解析每个变量值。

## 二、手算 S6F11 hex

### 例：DATAID=1, CEID=3001, 报告1(RPTID=1, 变量=[F4=25.5, U2=100])
```
body = L,3[
  U4=1,                          // DATAID
  U2=3001,                       // CEID
  L,1[                           // 报告列表（1个报告）
    L,2[
      U2=1,                      // RPTID
      L,2[                       // 变量值列表（2个值）
        F4=25.5,                 // 第一个变量（F4温度）
        U2=100                   // 第二个变量（U2计数）
      ]
    ]
  ]
]
```
编码：
- L,3 = `20 03`
- U4=1 = `AC 04 00 00 00 01`（U4 格式字节：类型码43<<2=0xAC，长度4，4-1=3 → 0xAC|3=0xAF？不对）
  - 修正：U4 类型码=43，43<<2=172=0xAC；长度字节数=4，4-1=3；0xAC | 3 = 0xAF。
  - 所以 U4=1 = `AF 00 00 00 01`（格式字节 AF，4字节值 00 00 00 01）。
- U2=3001 = `A9 0B B9`
- L,1 = `20 01`
- L,2 = `20 02`
- U2=1 = `A9 00 01`
- L,2 = `20 02`
- F4=25.5：F4 类型码=33，33<<2=0x84；长度字节数=4，4-1=3；0x84|3=0x87。25.5 的 IEEE754 单精度 = 0x41CC0000。所以 F4=25.5 = `87 41 CC 00 00`。
- U2=100 = `A9 00 64`

完整 body hex：`20 03 AF 00 00 00 01 A9 0B B9 20 01 20 02 A9 00 01 20 02 87 41 CC 00 00 A9 00 64`

> 注意：U4 格式字节是 0xAF（不是 0xAC），F4 格式字节是 0x87（不是 0x84），因为长度字节数-1 要和类型码<<2 做或运算。对照 W3 Day02 格式字节表验证。

### EventReportEngine.cs
```csharp
using EapLab.Secs2;
using EapLab.Transport.Logging;

namespace EapLab.Gem.DataCollection;

/// <summary>事件报告引擎：事件触发→查关联→采集变量→组装 S6F11→发送。</summary>
public sealed class EventReportEngine
{
    private readonly EventReportLinkStore _linkStore;
    private readonly ReportStore _reportStore;
    private readonly IVariableProvider _variableProvider;
    private readonly ILogSink _log;
    private uint _dataId = 0;

    public uint CurrentDataId => _dataId;

    public EventReportEngine(EventReportLinkStore linkStore, ReportStore reportStore,
                              IVariableProvider variableProvider, ILogSink log)
    {
        _linkStore = linkStore;
        _reportStore = reportStore;
        _variableProvider = variableProvider;
        _log = log;
    }

    /// <summary>配置变更时调用，递增 DATAID。</summary>
    public void OnConfigurationChanged() => Interlocked.Increment(ref _dataId);

    /// <summary>触发事件，返回组装好的 S6F11 body（无关联返回 null）。</summary>
    public SecsItem? TriggerEvent(ushort ceid)
    {
        // 1. 查关联：该 CEID 关联了哪些 RPTID？
        var rptIds = _linkStore.GetLinkedReports(ceid);
        if (rptIds.Count == 0)
        {
            _log.Log(LogDir.INFO, $"Event CEID={ceid} triggered, no linked reports, skip");
            return null; // 无关联，不上报
        }

        // 2. 对每个 RPTID，查报告定义，采集变量
        var reports = new List<SecsItem>();
        foreach (var rptId in rptIds)
        {
            if (!_reportStore.TryGet(rptId, out var report) || report == null)
            {
                _log.Log(LogDir.ERR, $"Event CEID={ceid}: RPTID={rptId} not defined, skip");
                continue;
            }

            // 采集报告中每个 VID 的当前值
            var values = new List<SecsItem>();
            foreach (var vid in report.VidList)
            {
                var value = _variableProvider.GetValue(vid);
                values.Add(value ?? SecsItem.A("")); // 采集失败用空字符串占位
            }

            // 组装报告：L,2[U2 RPTID, L,m[变量值...]]
            reports.Add(SecsItem.L(SecsItem.U2(rptId), SecsItem.L(values.ToArray())));
        }

        if (reports.Count == 0) return null;

        // 3. 组装 S6F11 body：L,3[U4 DATAID, U2 CEID, L,n[报告...]]
        var body = SecsItem.L(
            SecsItem.U4(_dataId),
            SecsItem.U2(ceid),
            SecsItem.L(reports.ToArray())
        );

        _log.Log(LogDir.INFO, $"Event CEID={ceid} triggered, S6F11 assembled, DATAID={_dataId}, reports={reports.Count}");
        return body;
    }
}
```

### S6F11Parser.cs（Host 端解析器）
```csharp
namespace EapLab.Gem.DataCollection;

/// <summary>S6F11 解析结果。</summary>
public sealed class EventReport
{
    public uint DataId { get; init; }
    public ushort Ceid { get; init; }
    public List<ReportData> Reports { get; } = new();
}

public sealed class ReportData
{
    public ushort RptId { get; init; }
    public List<SecsItem> Values { get; } = new();
}

/// <summary>S6F11 解析器（Host 端）。</summary>
public static class S6F11Parser
{
    public static EventReport? Parse(SecsItem? body)
    {
        if (body is not SecsList root || root.Items.Count != 3) return null;

        if (root.Items[0] is not SecsU4 dataIdItem || dataIdItem.Values.Length != 1) return null;
        if (root.Items[1] is not SecsU2 ceidItem || ceidItem.Values.Length != 1) return null;
        if (root.Items[2] is not SecsList reportList) return null;

        var result = new EventReport { DataId = dataIdItem.Values[0], Ceid = ceidItem.Values[0] };

        foreach (var item in reportList.Items)
        {
            if (item is not SecsList rpt || rpt.Items.Count != 2) continue;
            if (rpt.Items[0] is not SecsU2 rptIdItem || rptIdItem.Values.Length != 1) continue;
            if (rpt.Items[1] is not SecsList valueList) continue;

            var report = new ReportData { RptId = rptIdItem.Values[0] };
            foreach (var v in valueList.Items)
                report.Values.Add(v);
            result.Reports.Add(report);
        }

        return result;
    }
}
```

### 单测（节选）
```csharp
public class EventReportEngineTests
{
    private class FakeVariableProvider : IVariableProvider
    {
        private readonly Dictionary<ushort, SecsItem> _data;
        public FakeVariableProvider(Dictionary<ushort, SecsItem> data) => _data = data;
        public SecsItem? GetValue(ushort vid) => _data.TryGetValue(vid, out var v) ? v : null;
    }

    [Fact]
    public void 事件有关联时组装S6F11()
    {
        var reportStore = new ReportStore(new[] { 100, 101 });
        reportStore.Define(1, new[] { 100, 101 });
        var linkStore = new EventReportLinkStore(new[] { 3001 }, reportStore);
        linkStore.Link(3001, new[] { 1 });
        var varProvider = new FakeVariableProvider(new() { [100] = SecsItem.F4(25.5f), [101] = SecsItem.U2(100) });
        var engine = new EventReportEngine(linkStore, reportStore, varProvider, new ConsoleLogSink());

        var body = engine.TriggerEvent(3001);

        Assert.NotNull(body);
        var parsed = S6F11Parser.Parse(body);
        Assert.NotNull(parsed);
        Assert.Equal(3001u, parsed.Ceid);  // 注意类型
        Assert.Single(parsed.Reports);
        Assert.Equal(1, parsed.Reports[0].RptId);
        Assert.Equal(2, parsed.Reports[0].Values.Count);
    }

    [Fact]
    public void 事件无关联时返回null()
    {
        var reportStore = new ReportStore(Array.Empty<ushort>());
        var linkStore = new EventReportLinkStore(new[] { 3001 }, reportStore);
        var engine = new EventReportEngine(linkStore, reportStore, new FakeVariableProvider(new()), new ConsoleLogSink());

        var body = engine.TriggerEvent(3001); // 无关联

        Assert.Null(body);
    }

    [Fact]
    public void 多报告时S6F11报告列表有多个()
    {
        var reportStore = new ReportStore(new[] { 100, 200 });
        reportStore.Define(1, new[] { 100 });
        reportStore.Define(2, new[] { 200 });
        var linkStore = new EventReportLinkStore(new[] { 3001 }, reportStore);
        linkStore.Link(3001, new[] { 1, 2 }); // 关联2个报告
        var varProvider = new FakeVariableProvider(new() { [100] = SecsItem.U2(1), [200] = SecsItem.U2(2) });
        var engine = new EventReportEngine(linkStore, reportStore, varProvider, new ConsoleLogSink());

        var body = engine.TriggerEvent(3001);
        var parsed = S6F11Parser.Parse(body);

        Assert.Equal(2, parsed.Reports.Count);
        Assert.Equal(1, parsed.Reports[0].RptId);
        Assert.Equal(2, parsed.Reports[1].RptId);
    }
}
```

## 四、今日易错点
1. S6F11 body 结构记错（是 L,3[U4 DATAID, U2 CEID, L,n[L,2[U2 RPTID, L,m[值]]]]，不是 L,2 或 L,4）。
2. U4/F4 格式字节算错（U4=0xAF，F4=0x87，因为长度字节数-1 要或运算）。
3. 以为 S6F11 中带 VID（只带值，不带 VID，Host 按位置和报告定义解析）。
4. 以为所有事件触发都会发 S6F11（只有关联了报告的事件才发）。
5. 变量值顺序乱序（必须严格按 S2F33 定义的 VID 顺序，Host 按位置解析）。
6. 混淆 DATAID 和 CEID（DATAID 是配置版本，CEID 是事件 ID）。
7. 以为 S6F12 带数据（只带 U4 DATAID，是确认）。
8. 配置变更后没递增 DATAID（每次 S2F33/S2F35/S2F37 后都要递增）。
