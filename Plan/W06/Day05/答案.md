# W06 · Day05 答案与参考实现

## 一、自测题标准答案
1. **S1F3 vs S1F11 区别 / 场景**：S1F3（Status Variable Namelist Request）是查询 SV 的**列表和名称**——Host 发 VID 列表（或空列表查全部），设备回 S1F4，返回每个 VID 的名称，作用是"知道设备支持哪些 SV、叫什么名字"；S1F11（Status Variable Data Request）是查询 SV 的**当前值**——Host 发 VID 列表，设备回 S1F12，返回每个 VID 的当前值，作用是"知道设备现在是什么状态"。场景：建链后用 S1F3 发现设备能力（有哪些 SV），运行中用 S1F11 轮询关键 SV 的当前值（如温度、压力）。
2. **S1F4 返回名称和类型吗 / Host 怎么知道类型**：S1F4 只返回 VID 和**名称**（SVNAME），**不返回变量类型**。标准 S1F4 的 body 是 L,n[L,2[U2 VID, A SVNAME]]，没有类型字段。Host 知道变量类型的方式：①从设备文档/手册获取（最可靠，设备商提供 VID→类型映射表）；②通过 S1F11 查询值时看返回值的 SECS-II 类型（如返回 F4 就是浮点，返回 U2 就是无符号短整数）；③部分设备在 S1F4 中扩展返回类型（非标准，以设备实现为准）。专家实践：建链后用 S1F11 查一次所有 SV 的值，建立 VID→类型映射，后续解析 S6F11 时用这个映射。
3. **建链后 S1F7 通常返回什么 / 为什么**：通常返回**空列表**（L,0）。因为报告定义（S2F33 定义的 RPTID+VID 列表）存储在设备的内存中，设备重启后丢失（除非设备支持持久化）。Host 每次建链后需要重新定义报告和关联事件。所以建链后查 S1F7 通常为空，Host 据此知道需要重新配置数据采集。如果设备支持持久化（如写入 Flash），S1F7 可能返回上次定义的报告，但这不是标准要求，以设备实现为准。
4. **S1F9/F10 作用 / Host 为何需要查询报告包含哪些 VID**：S1F9（Report Variable Request）查询某个报告包含哪些 VID，设备回 S1F10，返回每个 RPTID 对应的 VID 列表。Host 需要这个信息是为了**解析 S6F11**——S6F11 中只带变量值，不带 VID，Host 按位置解析。要知道每个位置对应哪个 VID，Host 必须知道报告定义（RPTID→VID 列表）。Host 可以通过 S1F9 查询设备上的报告定义，也可以自己维护报告定义（因为是 Host 自己通过 S2F33 定义的）。S1F9 主要用于 Host 不确定报告定义时（如设备重启后报告还在，但 Host 忘了定义了什么）查询确认。
5. **能力发现完整流程 / 哪步知道支持什么 / 哪步配置采集什么**：完整流程：建链完成→S1F3 查 SV 列表→S1F5 查事件列表→S1F7 查报告列表（通常空）→Host 根据业务需求选择 SV/DV 和事件→S2F33 定义报告→S2F35 关联事件→事件触发→S6F11 上报→S6F12 确认。其中**S1F3/S1F5/S1F7 是"知道设备支持什么"**（能力发现），**S2F33/S2F35 是"配置采集什么"**（数据采集配置）。能力发现是配置的前提——Host 必须先知道设备支持哪些 VID/CEID，才能定义报告和关联事件，否则会引用不存在的 VID/CEID 导致失败。
6. **S1F12 返回值顺序 / Host 怎么知道每个值对应哪个 VID**：S1F12 返回的变量值按 S1F11 请求的 VID 顺序排列，一一对应。例如 Host 发 S1F11 body=L,3[U2=100, U2=101, U2=102]，设备回 S1F12 body=L,3[值1, 值2, 值3]，其中值1对应 VID=100，值2对应 VID=101，值3对应 VID=102。Host 按位置解析，不需要在 S1F12 中带 VID（因为请求时 Host 自己知道顺序）。这和 S6F11 的设计一致——值按定义顺序排列，不带 ID，节省带宽。

## 二、S1 系列查询消息速查表
| 消息 | 方向 | Request body | Reply body | 作用 |
|---|---|---|---|---|
| S1F1/F2 | H→E | 空/扩展 | L,2[A MDLN, A SOFTREV] | 心跳/身份确认 |
| S1F3/F4 | H→E | L,n[U2 VID]（空=全部）| L,n[L,2[U2 VID, A SVNAME]] | 查询 SV 列表/名称 |
| S1F5/F6 | H→E | L,n[U2 CEID]（空=全部）| L,n[L,2[U2 CEID, A CENAME]] | 查询事件列表/名称 |
| S1F7/F8 | H→E | L,n[U2 RPTID]（空=全部）| L,n[U2 RPTID] | 查询已定义报告列表 |
| S1F9/F10 | H→E | L,n[U2 RPTID] | L,n[L,2[U2 RPTID, L,m[U2 VID]]] | 查询报告包含的 VID |
| S1F11/F12 | H→E | L,n[U2 VID] | L,n[变量值...] | 查询 SV 当前值 |
| S1F13/F14 | H→E | L,2[A MDLN, A SOFTREV] | L,2[A MDLN, A SOFTREV] | 建立通信 |
| S1F15/F16 | H→E | 空 | L,2[U1 ACKC1, U2 ERRCODE] | 请求离线 |
| S1F17/F18 | H→E | 空 | L,2[U1 ACKC1, U2 ERRCODE] | 请求在线 |

## 三、参考实现（EapLab.Gem/DataCollection/S1QueryHandler.cs）

```csharp
using EapLab.Secs2;
using EapLab.Transport.Logging;

namespace EapLab.Gem.DataCollection;

/// <summary>S1 系列查询处理器（设备端）。</summary>
public sealed class S1QueryHandler
{
    private readonly IReadOnlyDictionary<ushort, string> _svNames;   // VID→SV名称
    private readonly IReadOnlyDictionary<ushort, string> _eventNames; // CEID→事件名称
    private readonly ReportStore _reportStore;
    private readonly IVariableProvider _variableProvider;
    private readonly ILogSink _log;

    public S1QueryHandler(
        IReadOnlyDictionary<ushort, string> svNames,
        IReadOnlyDictionary<ushort, string> eventNames,
        ReportStore reportStore,
        IVariableProvider variableProvider,
        ILogSink log)
    {
        _svNames = svNames;
        _eventNames = eventNames;
        _reportStore = reportStore;
        _variableProvider = variableProvider;
        _log = log;
    }

    /// <summary>分发 S1 primary 消息，返回 reply body（不支持返回 null，调用方回 S9）。</summary>
    public SecsItem? Handle(byte function, SecsItem? body)
    {
        return function switch
        {
            3 => HandleS1F3(body),    // 查询 SV 列表
            5 => HandleS1F5(body),    // 查询事件列表
            7 => HandleS1F7(body),    // 查询报告列表
            9 => HandleS1F9(body),    // 查询报告变量列表
            11 => HandleS1F11(body),  // 查询 SV 值
            _ => null
        };
    }

    /// <summary>S1F3: 查询 SV 列表。body=L,n[U2 VID]（空=全部），回 S1F4。</summary>
    private SecsItem HandleS1F3(SecsItem? body)
    {
        var vids = ParseU2List(body);
        if (vids.Count == 0) vids = _svNames.Keys.OrderBy(k => k).ToList(); // 空=全部

        var items = new List<SecsItem>();
        foreach (var vid in vids)
        {
            var name = _svNames.TryGetValue(vid, out var n) ? n : "UNKNOWN";
            items.Add(SecsItem.L(SecsItem.U2(vid), SecsItem.A(name)));
        }
        return SecsItem.L(items.ToArray());
    }

    /// <summary>S1F5: 查询事件列表。回 S1F6。</summary>
    private SecsItem HandleS1F5(SecsItem? body)
    {
        var ceids = ParseU2List(body);
        if (ceids.Count == 0) ceids = _eventNames.Keys.OrderBy(k => k).ToList();

        var items = new List<SecsItem>();
        foreach (var ceid in ceids)
        {
            var name = _eventNames.TryGetValue(ceid, out var n) ? n : "UNKNOWN";
            items.Add(SecsItem.L(SecsItem.U2(ceid), SecsItem.A(name)));
        }
        return SecsItem.L(items.ToArray());
    }

    /// <summary>S1F7: 查询已定义报告列表。回 S1F8。</summary>
    private SecsItem HandleS1F7(SecsItem? body)
    {
        var requested = ParseU2List(body);
        var all = _reportStore.GetAllRptIds();
        var result = requested.Count == 0 ? all : all.Intersect(requested).ToList();
        return SecsItem.L(result.Select(r => SecsItem.U2(r)).ToArray());
    }

    /// <summary>S1F9: 查询报告包含的 VID 列表。回 S1F10。</summary>
    private SecsItem HandleS1F9(SecsItem? body)
    {
        var rptIds = ParseU2List(body);
        var items = new List<SecsItem>();
        foreach (var rptId in rptIds)
        {
            if (_reportStore.TryGet(rptId, out var report) && report != null)
            {
                var vids = report.VidList.Select(v => SecsItem.U2(v)).ToArray();
                items.Add(SecsItem.L(SecsItem.U2(rptId), SecsItem.L(vids)));
            }
        }
        return SecsItem.L(items.ToArray());
    }

    /// <summary>S1F11: 查询 SV 当前值。回 S1F12。</summary>
    private SecsItem HandleS1F11(SecsItem? body)
    {
        var vids = ParseU2List(body);
        var values = new List<SecsItem>();
        foreach (var vid in vids)
        {
            var value = _variableProvider.GetValue(vid);
            values.Add(value ?? SecsItem.A("")); // 采集失败用空字符串占位
        }
        return SecsItem.L(values.ToArray());
    }

    /// <summary>解析 L,n[U2] 列表。</summary>
    private static List<ushort> ParseU2List(SecsItem? body)
    {
        var result = new List<ushort>();
        if (body is SecsList list)
        {
            foreach (var item in list.Items)
            {
                if (item is SecsU2 u2 && u2.Values.Length == 1)
                    result.Add(u2.Values[0]);
            }
        }
        return result;
    }
}
```

### Host 端查询封装（EapLab.Gem/Host/HostQueryClient.cs）
```csharp
namespace EapLab.Gem.Host;

/// <summary>Host 端查询封装（简化版，实际通过 HsmsConnection 发送）。</summary>
public sealed class HostQueryClient
{
    private readonly HsmsConnection _conn;

    public HostQueryClient(HsmsConnection conn) => _conn = conn;

    /// <summary>查询 SV 列表（空=全部）。返回 VID→名称映射。</summary>
    public async Task<Dictionary<ushort, string>> QuerySvListAsync(params ushort[] vids)
    {
        var reqBody = SecsItem.L(vids.Select(v => SecsItem.U2(v)).ToArray());
        var reply = await _conn.SendAndWaitAsync(1, 3, reqBody); // S1F3→S1F4
        var result = new Dictionary<ushort, string>();
        if (reply is SecsList list)
        {
            foreach (var item in list.Items)
            {
                if (item is SecsList pair && pair.Items.Count == 2 &&
                    pair.Items[0] is SecsU2 vid && pair.Items[1] is SecsA name)
                    result[vid.Values[0]] = name.Value;
            }
        }
        return result;
    }

    /// <summary>查询 SV 当前值。返回 VID→值映射。</summary>
    public async Task<Dictionary<ushort, SecsItem>> QuerySvValuesAsync(params ushort[] vids)
    {
        var reqBody = SecsItem.L(vids.Select(v => SecsItem.U2(v)).ToArray());
        var reply = await _conn.SendAndWaitAsync(1, 11, reqBody); // S1F11→S1F12
        var result = new Dictionary<ushort, SecsItem>();
        if (reply is SecsList list)
        {
            for (int i = 0; i < vids.Length && i < list.Items.Count; i++)
                result[vids[i]] = list.Items[i];
        }
        return result;
    }

    // QueryEventListAsync / QueryReportListAsync / QueryReportVariablesAsync 类似，省略
}
```

### 单测（节选）
```csharp
public class S1QueryHandlerTests
{
    private static S1QueryHandler CreateHandler()
    {
        var svNames = new Dictionary<ushort, string> { [100] = "Temperature", [101] = "Pressure" };
        var eventNames = new Dictionary<ushort, string> { [3001] = "LotStart", [3002] = "LotEnd" };
        var reportStore = new ReportStore(new[] { 100, 101 });
        reportStore.Define(1, new[] { 100, 101 });
        var varProvider = new FakeVariableProvider(new() { [100] = SecsItem.F4(25.5f), [101] = SecsItem.U2(100) });
        return new S1QueryHandler(svNames, eventNames, reportStore, varProvider, new ConsoleLogSink());
    }

    [Fact]
    public void S1F3查询全部SV()
    {
        var handler = CreateHandler();
        var reply = handler.Handle(3, SecsItem.L()); // 空列表=全部
        var list = (SecsList)reply;
        Assert.Equal(2, list.Items.Count);
    }

    [Fact]
    public void S1F11查询SV值()
    {
        var handler = CreateHandler();
        var reply = handler.Handle(11, SecsItem.L(SecsItem.U2(100), SecsItem.U2(101)));
        var list = (SecsList)reply;
        Assert.Equal(2, list.Items.Count);
        Assert.IsType<SecsF4>(list.Items[0]); // VID=100 是 F4
        Assert.IsType<SecsU2>(list.Items[1]); // VID=101 是 U2
    }

    [Fact]
    public void S1F7查询报告列表()
    {
        var handler = CreateHandler();
        var reply = handler.Handle(7, SecsItem.L());
        var list = (SecsList)reply;
        Assert.Single(list.Items);
        Assert.Equal(1, ((SecsU2)list.Items[0]).Values[0]);
    }

    [Fact]
    public void S1F9查询报告变量列表()
    {
        var handler = CreateHandler();
        var reply = handler.Handle(9, SecsItem.L(SecsItem.U2(1)));
        var list = (SecsList)reply;
        var pair = (SecsList)list.Items[0];
        Assert.Equal(1, ((SecsU2)pair.Items[0]).Values[0]);
        var vidList = (SecsList)pair.Items[1];
        Assert.Equal(2, vidList.Items.Count);
    }
}
```

## 四、今日易错点
1. 混淆 S1F3（查列表/名称）和 S1F11（查当前值）。
2. 以为 S1F4 返回变量类型（只返回名称，类型从文档或 S1F11 推断）。
3. 以为建链后 S1F7 返回上次定义的报告（通常为空，重启后丢失）。
4. S1F12 返回值顺序乱序（必须按 S1F11 请求的 VID 顺序，一一对应）。
5. 以为 S1F9 是查询 SV 列表（S1F9 是查询报告包含哪些 VID，S1F3 才是查询 SV 列表）。
6. 能力发现时不查 S1F3/S1F5 就直接 S2F33/S2F35（可能引用不存在的 VID/CEID）。
7. 混淆 S1F7（查报告列表）和 S1F9（查报告变量列表）。
8. S1F3 空列表以为是错误（空列表=查询全部，是标准用法）。
