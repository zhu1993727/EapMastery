## 一、今日目标

## 二、背景知识（先读，25 分钟）

### 1. 变量体系（Variables）
GEM 定义了设备的可观测数据，按用途分为：

| 类型 | 全称 | 含义 | 用途 | 查询方式 |
|---|---|---|---|---|
| SV | Status Variable | 状态变量：设备当前状态的只读变量 | Host 随时查询设备当前状态（温度、压力、运行状态、配方名等）| S1F3（请求 SV 列表）、S1F11（请求 SV 值）|
| DV | Data Variable | 数据变量：事件触发时采集的变量 | 事件发生时的瞬时数据（事件发生时的温度、计数、结果等），随 S6F11 上报 | 不能单独查询，只能在事件报告中获取 |
| VID | Variable ID | 变量 ID：变量的唯一标识 | SV 和 DV 都有 VID，用于定义报告时引用 | — |
| ECID | Equipment Constant ID | 设备常量 ID：设备的可配置参数 | Host 可读取/修改的设备配置参数（如通信超时、Spool 配置等）| S2F13/F14（查询/修改设备常量）|

- **SV 是"现在是什么"**：随时可查，反映设备当前状态。
- **DV 是"事件发生时是什么"**：只在事件触发时采集，反映事件时刻的瞬时值。
- 同一个物理量（如温度）可以同时是 SV（随时可查当前温度）和 DV（事件发生时的温度），但 VID 不同。

### 2. 事件体系（Collection Events / CEID）
- **CEID（Collection Event ID）**：集合事件 ID，设备发生的可被 Host 感知的事件。
- 事件是数据采集的**触发器**：当某个事件发生时，设备采集关联的变量，组装报告，通过 S6F11 上报给 Host。
- 常见事件：
  - 状态变化事件（设备从 IDLE→RUN、控制状态变化等）
  - 作业开始/结束事件（Lot Start/Lot End、Wafer Start/End）
  - 报警设置/清除事件
  - 远程命令开始/完成/失败事件
  - 设备自定义事件（工艺相关）
- 每个 CEID 有唯一 ID 和名称（ALTXT），Host 可通过 S1F5/S1F7 查询事件列表。

### 3. 报告体系（Reports / RPTID）
- **RPTID（Report ID）**：报告 ID，报告的唯一标识。
- 报告是**一组变量的集合**：定义报告时，Host 指定 RPTID 和该报告包含哪些 VID（变量）。
- 报告是**可复用的模板**：一个报告可以被多个事件关联，一个事件也可以关联多个报告。
- 报告的内容在事件触发时填充：设备采集报告中每个 VID 的当前值，按定义顺序排列，组装成 S6F11 的 body。

### 4. 三者关系（必背）
```
变量(VID) ──被包含于──► 报告(RPTID) ──被关联于──► 事件(CEID)
  │                        │                          │
  │  SV: 随时可查          │  一组变量的模板          │  数据采集触发器
  │  DV: 事件时采集        │  可被多事件复用          │  触发时采集关联报告的变量
  ▼                        ▼                          ▼
S1F11 查询            S2F33 定义报告              S2F35 关联事件
```
- **变量是原子**：最小的数据单元。
- **报告是变量的容器**：定义"要采集哪些变量"。
- **事件是触发器**：定义"什么时候采集"。
- 三者解耦：Host 可以灵活组合——同一个温度变量(SV/DV)可以放进多个报告，同一个报告可以关联多个事件。

### 5. 数据采集完整流程（必背）
```
1. Host 查询设备能力：S1F3(SV列表)、S1F5(CEID列表)、S1F7(报告列表，初始为空)
2. Host 定义报告：S2F33 Define Report → 指定 RPTID + 包含的 VID 列表
   设备回 S2F34 ACKC5（0=成功，非0=失败，如 VID 不存在）
3. Host 关联事件：S2F35 Link Event Report → 指定 CEID + 关联的 RPTID 列表
   设备回 S2F36 ACKC6（0=成功，非0=失败，如 CEID/RPTID 不存在）
4. 设备事件发生：触发 CEID
5. 设备采集：对关联的每个报告，采集报告中每个 VID 的当前值
6. 设备组装：按 S6F11 body 结构组装（DATAID + CEID + 报告列表）
7. 设备上报：S6F11 Event Report Send（W=1）
8. Host 确认：S6F12 Event Report Acknowledge（回 DATAID）
```
- 可以取消关联：S2F37 Unlink Event Report（取消某事件与某报告的关联）。
- 可以删除报告：S2F33 重新定义同名 RPTID（覆盖），或通过特定流程删除。
- DATAID：数据收集定义 ID，标识这套"报告定义+事件关联"的配置版本，Host 每次重新配置后 DATAID 变化，设备在 S6F11 中带回 DATAID，Host 据此知道报告是按哪套配置采集的。
