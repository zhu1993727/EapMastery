# W13 · Day02 答案与参考实现

## 一、自测题标准答案
1. **为何加桥接层 / 单一职责**：E84 原始信号是电平世界，有机械抖动、切换中间态、握手未完成、SafeHold/EStop 异常中止，直接让 E87 读原始信号会把"瞬时毛刺/没交接成功/半放半悬"误当成"盒已就位"而建错账。桥接层负责唯一职责——把原始物理信号净化、判定为**可信的"物理有无"业务事件**（Placed/Removed）：去抖滤毛刺、只在 E84 正常完成时产出、识别方向、边沿幂等。它不做 ID 校验、授权、状态机迁移（那些归 E87/Host），职责单一才可独立穷举测试、可复用、出问题好定位。这是"传感器原始量→工艺事件"的标准工业抽象。
2. **去抖实现 / 抖动回退为何重置**：记录传感器每次跳变的时刻与当前原始电平，逻辑时钟每拍检查：若当前电平已连续稳定保持 ≥ DebounceMs，才把"稳定态"更新为该电平；未达时长则稳定态不变。抖动中途回退（刚 ON 几十 ms 又 OFF）必须重置计时，是因为这一段 ON 根本没达到"持续稳定"的判据，说明它是毛刺而非真实就位；若不重置、把前后两段 ON 时间累加，就会错误地把断续抖动凑够时长当成稳定 ON，去抖失效。核心是"必须从最后一次跳变起连续稳定"，任何反向跳变都重新计时。
3. **E84 正常完成的代码判定 / 排除状态**：条件=本次 E84 交接状态机**正常回到 Idle**（等价握手四相走完、无异常）且本次方向==Deposit，同时去抖后在位稳定态为 ON，三者齐备才产出 Placed。要排除的 E84 状态：SafeHold/AbortSafe（安全保持）、EStopHold（急停）、Rejected（方向矛盾被拒）、WaitGrant/WaitBusy/Transferring/WaitComplete（还在握手途中，没走完）、ManualBypass（手动旁路，走手动登记而非自动桥接）。这些状态下即便传感器瞬时 ON 也不产出 Placed，改为产告警/不建账。
4. **边沿检测 / 为何边沿 / 幂等**：边沿检测是对比"上一次稳定态 last"和"本次稳定态 current"：OFF→ON 是上升沿（盒来，Placed）、ON→OFF 是下降沿（盒走，Removed），电平不变（持续 ON/持续 OFF）不产事件。用边沿而非电平，是因为业务要的是"状态发生变化的那一刻"触发一次迁移；若用电平触发，只要盒在口上、每次时钟 Tick 都会重复触发，造成重复建 Carrier、重复 Installed 事件。幂等做法：只在 last≠current 的变化边沿产出事件并更新 last，持续电平不再产出，保证同一物理事实恰好触发一次逻辑迁移。
5. **方向与边沿矛盾处理**：E84 报告本次是 Deposit（预期盒来、应对应 OFF→ON 上升沿），桥接层却检测到 ON→OFF 下降沿，说明物理事实和交接方向对不上（可能传感器故障、盒没放稳又掉出、状态错报）。不能将错就错产出事件，应：①不产出 Placed；②产"方向/边沿矛盾"告警事件（带口位、E84 方向、实际边沿、传感器快照）；③保持/进入安全态，交 E87/Host 与现场核查。反之 Pickup 却见上升沿同理。原则：跨层信息互相印证，矛盾即视为不可信，安全保守、宁停勿错。
6. **异常时产出什么 / 为何不忽略**：不产出 Placed/Removed 业务事件，但要产出**诊断/告警事件**（异常类型、E84 状态、传感器原始与稳定态、时刻、口位），并计数。不能简单忽略，因为：①现场需要可观测性——一次被拦下的异常交接可能预示传感器老化、线缆松动、天车定位偏差，忽略后问题反复发生却无日志可查；②Host 需要知道"有一次交接尝试没成功建账"，否则它以为盒该到了却迟迟没收到 Installed，无法区分"盒还在路上"还是"到了但被桥接层拦了"；③安全与审计要求所有偏离正常流程的情况留痕。即"不建账"不等于"悄无声息"。
7. **数据流**：见下方架构图与代码。

### 物理事件与 E84 结果抽象
```csharp
namespace EapLab.E84E87;
public abstract record PhysicalEvent(string LoadPortId);
public sealed record Placed(string Lp) : PhysicalEvent(Lp);
public sealed record Removed(string Lp) : PhysicalEvent(Lp);
public sealed record PhysicalFault(string Lp, string Reason, string Detail) : PhysicalEvent(Lp);

public enum HandshakeOutcome { None, DepositCompleted, PickupCompleted, Aborted, EStop, Rejected, Manual }
public sealed class E84Snapshot
{
    public HandshakeOutcome Outcome { get; init; } = HandshakeOutcome.None;
    public bool FsmIdle { get; init; }
}
public interface IE84Provider
{   // 提供某口当前 E84 交接结果快照
    E84Snapshot GetSnapshot(string lpId);
    bool PresentRaw(string lpId);   // 在位传感器原始电平
}
```

### 去抖 + 边沿跟踪器（每口一个）
```csharp
public sealed class DebounceEdgeTracker
{
    private bool _raw; private bool _stable; private bool _lastStable;
    private long _lastChangeAt = -1;
    public int DebounceMs { get; init; } = 50;
    public bool? DetectEdge(long now, bool rawOn, out bool stableNow)
    {
        if (rawOn != _raw) { _raw = rawOn; _lastChangeAt = now; }   // 跳变重置计时
        stableNow = _stable;
        if (_lastChangeAt >= 0 && now - _lastChangeAt >= DebounceMs)
            _stable = _raw;                                          // 连续稳定才更新稳定态
        if (_stable != _lastStable)
        {
            bool rising = _stable && !_lastStable;                   // OFF->ON 上升沿
            _lastStable = _stable; stableNow = _stable;
            return rising;   // true=上升沿(Placed), false=下降沿(Removed)
        }
        stableNow = _stable;
        return null;        // 无沿
    }
    public void Reset(){ _raw=_stable=_lastStable=false; _lastChangeAt=-1; }
}
```

### 物理→逻辑桥接层（对接点1，兼留对接点2）
```csharp
public sealed class PhysicalToLogicalBridge
{
    private readonly IE84Provider _e84;
    private readonly Dictionary<string,DebounceEdgeTracker> _tr = new();
    private long _now;
    public List<PhysicalEvent> Output { get; } = new();
    public PhysicalToLogicalBridge(IE84Provider e84, IEnumerable<string> lpIds, int debounceMs=50)
    { _e84=e84; foreach(var lp in lpIds) _tr[lp]=new DebounceEdgeTracker{DebounceMs=debounceMs}; }

    public void Tick(long deltaMs)
    {
        _now += deltaMs;
        foreach (var (lp, tracker) in _tr)
        {
            bool raw = _e84.PresentRaw(lp);
            var edge = tracker.DetectEdge(_now, raw, out bool stable);
            if (edge is null) continue;                  // 无沿: 幂等, 不重复产出
            bool rising = edge.Value;
            var snap = _e84.GetSnapshot(lp);

            if (rising) // OFF->ON: 期望 Deposit 正常完成
            {
                bool ok = snap.Outcome==HandshakeOutcome.DepositCompleted && snap.FsmIdle && stable;
                if (ok) Output.Add(new Placed(lp));
                else Output.Add(new PhysicalFault(lp,"就位但E84未正常完成",
                    $"outcome={snap.Outcome},stable={stable}"));
            }
            else        // ON->OFF: 期望 Pickup 正常完成
            {
                bool ok = snap.Outcome==HandshakeOutcome.PickupCompleted && snap.FsmIdle;
                if (ok) Output.Add(new Removed(lp));
                else Output.Add(new PhysicalFault(lp,"移除但E84未正常完成",
                    $"outcome={snap.Outcome}"));
            }
        }
    }
    public void DrainTo(E87.LoadPortManager mgr)
    {
        foreach(var ev in Output)
            switch(ev)
            {
                case Placed p: mgr.OnPhysicalPlaced(p.Lp); break;
                case Removed r: mgr.OnPhysicalRemoved(r.Lp); break;
                case PhysicalFault f: mgr.Port(f.LoadPortId).Alarms.Add($"{f.Reason}:{f.Detail}"); break;
            }
        Output.Clear();
    }
}
```

### xUnit
```csharp
public class BridgeTests
{
    sealed class FakeE84 : IE84Provider
    { public Dictionary<string,bool> Raw=new(); public Dictionary<string,E84Snapshot> Snap=new();
      public E84Snapshot GetSnapshot(string lp)=>Snap.GetValueOrDefault(lp,new());
      public bool PresentRaw(string lp)=>Raw.GetValueOrDefault(lp); }

    [Fact] public void 正常Deposit_稳定后产出一次Placed()
    {
        var e=new FakeE84(); var b=new PhysicalToLogicalBridge(e,new[]{"LP1"},50);
        // E84 正常完成
        e.Snap["LP1"]=new E84Snapshot{Outcome=HandshakeOutcome.DepositCompleted,FsmIdle=true};
        e.Raw["LP1"]=true;
        for(int i=0;i<6;i++) b.Tick(10);          // 60ms > 50 去抖
        Assert.Single(b.Output.OfType<Placed>());
        b.Tick(10);                                // 持续ON,无新沿
        Assert.Single(b.Output);                   // 幂等:不重复
    }
    [Fact] public void 抖动短ON_不产出()
    {
        var e=new FakeE84(); var b=new PhysicalToLogicalBridge(e,new[]{"LP1"},50);
        e.Snap["LP1"]=new E84Snapshot{Outcome=HandshakeOutcome.DepositCompleted,FsmIdle=true};
        e.Raw["LP1"]=true; b.Tick(20);             // 只稳20ms
        e.Raw["LP1"]=false; b.Tick(20);            // 抖动回退,重置
        Assert.Empty(b.Output);
    }
    [Fact] public void E84急停_即使ON也不建账()
    {
        var e=new FakeE84(); var b=new PhysicalToLogicalBridge(e,new[]{"LP1"},10);
        e.Snap["LP1"]=new E84Snapshot{Outcome=HandshakeOutcome.EStop,FsmIdle=false};
        e.Raw["LP1"]=true; for(int i=0;i<3;i++) b.Tick(10);
        Assert.Empty(b.Output.OfType<Placed>());
        Assert.Single(b.Output.OfType<PhysicalFault>());
    }
    [Fact] public void Deposit却下降沿_矛盾告警()
    {
        var e=new FakeE84(); var b=new PhysicalToLogicalBridge(e,new[]{"LP1"},10);
        // 先置 ON 稳定
        e.Snap["LP1"]=new E84Snapshot{Outcome=HandshakeOutcome.DepositCompleted,FsmIdle=true};
        e.Raw["LP1"]=true; for(int i=0;i<2;i++) b.Tick(10); b.Output.Clear();
        // 再变 OFF, 但 E84 仍报 Deposit(矛盾)
        e.Raw["LP1"]=false; b.Tick(10);
        Assert.Empty(b.Output.OfType<Removed>());
        Assert.Single(b.Output.OfType<PhysicalFault>());
    }
}
```

## 三、数据流图（手绘参考）
```
 E84握手FSM ┐(Outcome/Idle?)
            ├─► PhysicalToLogicalBridge ──去抖(连续稳定)──边沿(OFF→ON/ON→OFF)
 在位传感器 ┘(Raw电平)                      │            └─正常完成判定(Idle+方向)
                                          ├─正常─► Placed/Removed ─► E87 Manager
                                          └─异常─► PhysicalFault(留痕,不建账)
 单一职责: 桥只输出"可信物理有无"; ID校验/授权/迁移归 E87/Host
```

## 四、今日易错点
1. E87 直接读原始传感器（必须经桥接层去抖+正常完成判定）。
2. 去抖把断续 ON 累加计时（反向跳变必须重置，从最后跳变连续稳定）。
3. E84 还在握手途中/异常态就产出 Placed（只认正常回 Idle+方向匹配）。
4. 用电平触发导致持续 ON 每拍重复建账（必须边沿触发、幂等一次）。
5. 方向与边沿矛盾还硬产出事件（矛盾即不可信，告警安全挂起）。
6. 异常时静默忽略（要产 PhysicalFault 留痕、计数、可观测）。
7. 桥接层里顺手做 ID 校验/授权（越界，单一职责，归 E87/Host）。
8. 忘记 Pickup 的 OFF 也要去抖（瞬时掉线会误判移除）。
