# W13 · Day06（周六，整块 3.5h）综合大演练：多 LoadPort 并行自动上下料 + 故障注入

> 本周毕业实验。把 W11（E84）、W12（E87）、本周（桥接/编排/双模式/对账）全部模块组装成一个多装载口的自动物料系统仿真：3 个 LoadPort 并行跑上料-加工-下料，中途注入 6 类故障，验证系统"正常流自动闭环、异常流安全拦截且账实一致"。这是进入 E90 前对"手+盒"体系的总验收。

## 一、今日目标
1. 组装 3 LoadPort 并行仿真系统：每口独立 E84/E87/桥接，共享一个 Host 决策器，统一逻辑时钟驱动。
2. 跑通混合场景：LP1 正常料、LP2 错料被退回、LP3 RFID 失败转人工，三口交错推进互不阻塞。
3. 注入 6 类故障并验证处置：E84 急停、传感器抖动、ID 不匹配、Loaded 非正常移除、Pickup 失败、断线重连对账。
4. 全程时间线可追溯，最终做一次全系统账实对账，全部一致才算通过。
5. 闭卷手绘"多口并行系统架构图 + 故障处置地图"。

## 二、实验剧本（先读，20 分钟）

### 阶段0 初始化（t0）
- 建 LP1/LP2/LP3，各自 E84 FSM、桥接（去抖 30ms）、E87 CarrierFsm；共享 MockHost、统一时钟。
- Host 预约：LP1 期望 A、LP2 期望 B、LP3 期望 C。

### 阶段1 三口交错上料（正常+错料+读失败）
- LP1：E84 Deposit 正常、RFID=A → Installed → Host 授权 → Loaded（正常）。
- LP2：E84 Deposit 正常、RFID=X（≠B）→ Installed、Mismatch、Host 不授权 → 反向调度 Pickup 退回 → 回 Empty。
- LP3：E84 Deposit 正常、RFID 读失败 → Installed、Unreadable、Hold → 模拟人工核对后手动输入 C、留痕 → 授权 Loaded。
- 断言：最终 LP1 Loaded(A)、LP2 Empty、LP3 Loaded(C)，互不串扰。

### 阶段2 加工（模拟，为 E40 占位）
- LP1/LP3 模拟 ProcessJob 跑完（AllJobsFinished=true、片归位），保持 Loaded。

### 阶段3 下料与故障注入
- LP1 正常 Unload→Pickup→Removed→Empty。
- 故障①：LP3 在 Unloaded 后 E84 Pickup 失败（T_compt），验证 E87 保持 Unloaded、口仍 Occupied、重试后成功移除。
- 故障②：（重开一轮）让某口在 Loaded 时在位突丢，验证非正常移除高危、停 PJ、告警、锁口。

### 阶段4 物理层故障注入
- 故障③：某口 Deposit 途中 E84 EStop，验证桥接不建账、E87 保持 Empty。
- 故障④：在位信号 20ms 抖动（<去抖阈值），验证不产生 Placed。

### 阶段5 断线重连对账
- 故障⑤：模拟通信断线期间"手动在 LP2 放一盒 D"（本地物理变化、Host 镜像不知），重连后 Reconciler 发现 P有H无（L 补登）→ 补建账并刷新 Host。
- 故障⑥：模拟 Host 镜像错以为 LP1 还有盒（实际已空），对账发现 P无L/H有→按移除销账、刷新镜像。

### 阶段6 全系统对账收口
- 对所有口跑 Reconciler，P/L/H 三方完全一致、无未处理告警、时间线完整，实验通过。
