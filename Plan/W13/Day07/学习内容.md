## 四、W14 预热：E90 Substrate Tracking（30 分钟）

### 1. E90 是什么 / 解决什么问题
- E90 = SEMI E90 **STS Substrate Tracking Standard（基板跟踪标准）**，管理"每一片基板（晶圆 Wafer/Reticle）在设备内的位置与状态"。
- E87 管到"载具（盒）"这一粒度，E90 下钻到"盒内每一片、设备内每个位置"这一粒度：哪片在哪个 FOUP 的哪个 Slot、是否被取进设备、在哪个腔体/机械手、加工后放回哪个 Slot。
- 价值：防丢片、防混片、交叉取片验证、精确追溯每片晶圆的设备内轨迹，是 E40 ProcessJob 指定"从哪取、放哪去"的数据基础。

### 2. 核心概念先建立
- **Substrate（基板）**：一片晶圆/光罩，有 SubstrateID（可选，先进 FAB 逐片 ID）。
- **Slot（槽位）**：FOUP 内 25 个槽（1..25），SlotMap 描述每个槽"有/无片、片 ID、状态"。
- **Location（位置）**：基板可在载具槽位（Carrier:Slot）、设备内部位置（机械手/腔体/暂存位 Buffer/对准器 Aligner）。
- **Slot Map（槽位图）**：载具级的占用矩阵，上料时读入、下料前核对。
- **Substrate Location State（基板位置状态）**：在载具上 / 在设备内（哪个位置）/ 已移出等。

### 3. E90 的位置模型（教学框架，W14 详讲）
```
基板位置空间:
 外部: Carrier:LP1/FOUP-A/Slot#5  (在某载具某槽)
 设备内:
   Robot(机械手臂位 R1/R2)、Aligner(对准器)、Buffer(暂存)、
   Chamber(工艺腔体 C1/C2...)、LoadLock(真空锁)
 每片基板在任一时刻恰在一个位置(唯一位置不变式),移动=位置状态迁移
```
- **唯一位置不变式**：一片基板同一时刻只能在一个确定位置，不能同时在两处，也不能"消失"（除非正常移出设备）。这是基板跟踪的核心约束，违反即丢片/重片事故。

### 4. SlotMap 表示与校验
- 25 槽可用布尔数组/位图/B 类型表示占用，配合每槽 SubstrateID/状态。
- 上料读入"源 SlotMap"，ProcessJob 声明"源槽→目标槽"映射，加工过程逐片迁移位置，下料前生成"结果 SlotMap"与预期核对（这正是 W13 Unload 守卫 AllSubstratesReturned 的数据来源）。

### 5. E90 与 E87/E40/E94 的关系
```
E87: Carrier 载具状态(盒能不能访问) —— 提供"盒在口上、Loaded"前提
E90: 盒内/设备内每片基板位置 —— 提供"片在哪、源目槽"数据
E40 ProcessJob: 声明并执行"从源槽取片→加工→放目标槽"(W16+)
E94 ControlJob: 编排多个 PJ、跨载具(源盒→目标盒)(W20+)
交叉取片: 从源 Carrier 取、加工后放到另一个目标 Carrier,必须 E90 逐片校验
```
- E90 是 E40/E94 取放片的"位置事实来源"，没有精确基板跟踪，ProcessJob 的 Slot 指定就是盲操作。
