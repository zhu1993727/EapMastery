## 二、背景知识（先读，30 分钟）

### 1. 三个系统边界
- **AMHS（天车/OHT）**：负责物理搬运，执行 E84 硬握手，受 Host 调度（去哪、送/取哪个 CarrierID）。不管工艺、不管载具逻辑状态。
- **设备端（你开发的 EAP 接口所在）**：内含 E84 Load Port 控制器（硬线交接）和 E87 载具管理（SECS 软件），向 Host 上报物理/载具事件、执行 Host 授权/卸载命令，向上对接 E90/E40/E94。
- **Host（FAB EAP/MES）**：派工、预约、ID 校验决策、授权、建任务、调度 AMHS。掌握工艺计划，是"逻辑决策"中心。
- 关键认知：设备端是 AMHS 与 Host 之间的枢纽——向下用 E84 和天车握手，向上用 SECS 和 Host 对话，把物理世界翻译成逻辑世界。

### 2. 端到端 13 步（本周集成主线）
```
[Host 决策层]
1 MES 生成工艺计划,Host 对设备 LP1 下预约(预期 CarrierID=A) ——E87 S15F9
2 Host 调度 AMHS 送 A 到 LP1
[物理交接层 E84]
3 天车到达,E84 Deposit 硬握手(CS/ES/TR_REQ/BUSY/COMPT)放盒
4 E84 正常完成,在位传感器稳定 ON
[对接点1: 物理→逻辑]
5 设备读 RFID=A,创建 Carrier,E87 NotInstalled→Installed,S16F1 上报
[Host 决策层]
6 Host 比对预约 A==A,校验通过,S15F9 AuthorizeLoad
[载具逻辑层 E87]
7 E87 Installed→Loaded(守卫:Verified∧无Hold∧口正常),开放访问
[基板/任务层 E90/E40/E94]
8 E90 读 SlotMap;Host 建 ProcessJob/ControlJob
9 Loaded 期间自动取放片加工
[载具逻辑层 E87]
10 加工完,Host S15F9 Unload(守卫:PJ全结束/片归位/门关)→Unloaded
[Host 决策层]
11 Host 调度 AMHS 来取
[物理交接层 E84]
12 E84 Pickup 硬握手取盒,在位稳定 OFF
[对接点2: 逻辑→物理完成]
13 E87 Unloaded→NotInstalled,S16F1 Removed;Host 更新流向,口空接单
```

### 3. 跨层状态时序总图（三条泳道并行）
```
时间→  1预约  2调度   3 E84 Deposit     5安装   6授权  7 Loaded  8-9加工  10 Unload  12 E84 Pickup  13移除
AMHS:       来 ──► [Deposit硬握手: TR_REQ→等ES→BUSY→COMPT→复位] 离                来 ►[Pickup硬握手] 离
E84状态: Idle → WaitGrant→WaitBusy→Transfer→Complete→Idle                    Idle→...Pickup...→Idle
E87状态: (空,Reserved)                    NotInstalled→Installed ──授权──►Loaded(加工)→Unloaded ──►NotInstalled
Host:   预约/校验决策────────────────►比对ID✓→AuthorizeLoad   建PJ/CJ   Unload决策   调度取走   更新流向
对接点:                                 ▲对接点1(在位ON触发安装)                                  ▲对接点2(在位OFF触发移除)
```

### 4. 两个对接点（跨层集成核心）
- **对接点1（物理→逻辑）**：唯一由"E84 正常完成 + 在位稳定 ON"触发 E87 OnPhysicalPlaced。E84 SafeHold/EStop/未完成绝不触发；传感器需去抖稳定。
- **对接点2（逻辑→物理完成）**：由"E84 Pickup 正常完成 + 在位稳定 OFF"触发 E87 OnPhysicalRemoved；若 E87 还 Loaded 就丢盒=非正常移除高危。

### 5. 四个"互为前提"约束（时序不可乱）
1. 先有 Host 预约，盒到了才能校验通过（无预约=准入异常）。
2. 先 E84 Deposit 物理成功，E87 才能 Installed（物理是逻辑前提）。
3. 先 E87 Loaded 授权，E90/PJ 才能取片加工（授权是加工前提）。
4. 先 E87 Unload（加工结束），E84 才能正常 Pickup 取走（逻辑放行是物理取走前提）。
- 形成闭环：预约→物理进→逻辑授权→加工→逻辑放行→物理出。

### 6. 全链路的状态一致性目标
- 任何时刻，AMHS 以为的盒位置、设备 E87 状态、Host 账目三者必须一致。
- 任一环节中断（断线、异常、重启），都能靠"物理传感器 + 状态查询对账"恢复到一致（W13 Day05 做 reconciliation）。
