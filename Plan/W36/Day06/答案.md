# W36 · Day06 答案（综合闭卷笔试参考答案 + 能力画像）

## A. 概念填空/判断
1. NOT CONNECTED、NOT SELECTED、SELECTED；T3 用于控制/数据消息的回复超时（重发/判定超时）。
2. U1：U 系列基值 40（0x28=40），U1 长度字节数=1，类型码=(40)<<2 |(1-1)=160=0xA0（U2=0xB1）；多字节大端（big-endian）。
3. VID→RPT(S2F33 定义报告)→CEID(S2F35 关联事件)→S6F11。
4. Loaded（唯一自动取片状态）；谁设 Hold 谁解（谁设谁解）。
5. 三态=该槽有片/空/不可用（SlotMap 三态）；1-based 起始；4 字节 MSB-first（大端）。
6. SVDV（周期采样）、ECV（事件上下文值）、EXV（异常触发值）；Protocol Buffers（Freeze III）。
7. a_t=λ(y−b·u)+(1−λ)·a；u=(T−a)/b。
8. Cpk=min(Cpu,Cpl)=min((USL−μ)/3σ,(μ−LSL)/3σ)；Cp 只看离散宽度=(USL−LSL)/6σ 不看是否对中，Cpk 同时反映对中程度（R2R 主要提 Cpk，提 Cp 靠降本征 σ）。
9. hash（内容校验，如 SHA-256）。
10. Bad、Uncertain、Stale、Gap（连同 Good）。

## B. 辨析
11. **受理 vs 生效**：ACKC10=0/S7F4=0/命令 ACK 只表示设备收到、格式合法、愿意受理（传输/语法层）；生效以设备 FSM 实际迁移到目标状态 + 主动发对应 S6F11 事件 + 回读一致为判据。受理后设备仍可能拒绝/延迟/失败，故上位必须等生效事件再更新制造账，不能把 ACK 当完成。
12. **FDC/R2R/SPC**：FDC 秒/亚秒实时检测与分类，给报警/建议，执行 Hold 的是设备 FSM（不直接控）；R2R 逐片/逐批（run 间）补偿慢漂移，产 overlay 经 RMS/GEM 下发，run 内不调；SPC 跨批（小时~月）判稳与过程能力，不控制单批，异常驱动工程动作（重整定/保养）。三者都不绕过 EAP/GEM 直接写设备。
13. **CIM/MES/EAP**：CIM 是工厂自动化统称（由 MES/EAP/RMS/APC/EDC/YMS/AMHS 等组成，单一产品不叫 CIM）；MES 是制造执行子系统（工单/Lot/派工/WIP/谱系，业务事实源），不直连设备；EAP 是设备适配与实时控制层。设备端 EAP/SECS 接口只与 FAB 端 EAP(Host) 直连，其他系统经其汇聚。
14. **实时不补/历史可修不矛盾**：二者目标不同——实时层为当下控制求确定及时，水位关窗即结论、迟到不回改（避免控制/告警抖动）；历史层为分析追溯求完整准确，迟到/补传写入后可重算并版本化。同一份原始数据分别进两层，实时近似、批量准确，各司其职，因此不矛盾（W34 Day05）。

## C. 计算
**15. Xbar-R（n=5，X̄̄=100，Rbar=4.2，A2=0.577，D4=2.114，D3=0）**
- Xbar 控制限：UCL_X = X̄̄ + A2·Rbar = 100 + 0.577×4.2 = **102.4234**；LCL_X = 100 − 2.4234 = **97.5766**。
- R 控制限：UCL_R = D4·Rbar = 2.114×4.2 = **8.8788**；LCL_R = D3·Rbar = 0（n=5 时 D3=0）。
- 点 103.5 > UCL_X 102.4234，**越上限，判异（R1 越 3σ 类特殊原因）**，需查因，不能当普通波动。

**16. EWMA（T=50，b=2，a=49，λ=0.3，本 run y=53，上次 u=2）**
- 新状态 a_t = λ(y−b·u)+(1−λ)a = 0.3×(53−2×2)+0.7×49 = 0.3×49 + 34.3 = 14.7+34.3 = **49**。
- 下一步控制 u = (T−a_t)/b = (50−49)/2 = **0.5**。
- 解读：本 run 偏差被 EWMA 平滑后 a 仍为 49（目标略偏低 1），故把控制量从 2 调到 0.5 向目标对中；实际还要经步长限幅/死区/控制限检查并走 overlay 握手。

## D. 设计题 17 评分要点
- 通道：下行控制一条竖线 MES→EAP→GEM→设备；上行两股（EDA→EDC 高频、GEM 事件→EAP→MES）；EDA 只读、IReadOnlyDataBus 隔离。
- 五门：通信门（HSMS SELECTED/Remote）、物料门（E84/E87 绑定、E90 三不变式）、配方门（RMS PPID 版本+hash+回读）、作业门（E40 PJ 三正交、E94 CJ 级联）、状态门（E10 可生产/非 Hold/安全点）。
- 生效点：ACK 仅受理，Start 以 S6F11 JobStarted+回读为生效；完工以预期片销账+PJ/CJ 终态双条件。
- 数据去向：trace→EDC 实时给 FDC、历史给 VM/SPC/YMS；结果/消耗/谱系回 MES，数据放 EDC 引用。
- 异常分支：断线→重连先 W22+MES 对账、对账前禁下行（防脑裂）；片不符→E90 拒开工、核对实物防串批；FDC 报警→设备 FSM Hold、MES 冻结、工程师 Release。
- 评分：结构完整（分层+泳道）、方向/门控/生效/异常齐全、能边画边讲为满分。

## E. 排故题参考
**18. CD 系统偏大 + SPC 连续 9 同侧 + overlay 逼近控制限**
- 止损：连续 9 同侧已是特殊原因判异（R2），且 overlay 撞限风险高，先对该设备/腔 Hold、冻结相关 Lot 过账、where-used 圈定同腔同时间窗片待复检。
- 证据/时间线：EDC 拉源时间 trace、量测/VM、R2R 每次 Δu 与残差、配方/overlay 版本、FDC 报警、保养换件记录。
- 根因假设排序：①设备慢漂移且 R2R 一阶 EWMA 追不上（线性漂移，应上 dEWMA 估斜率）——证据是 overlay 单调增大仍压不住、残差同向；②某硬件劣化（靶材/气体 MFC/温控/腔体老化）导致本征工作点移动；③量测系统偏置（量测本身漂移，误导 R2R）；④配方/主档或来料变化；⑤数据质量问题（Stale/错单位）先排除。
- 处置：区分是可控漂移（整定 dEWMA/重置状态、限幅内补偿）还是设备问题（保养/换件/ECN）；撞限即停自动转手动，受影响片复检/返工判废；量测先做 MSA/校准排除假信号。
- 预防：SPC 同时监控 Δu/残差趋势做设备劣化预警（撞限前保养）、控制限与死区整定、模型作用域与版本管理、横向排查同型号腔。

**19. EDA 丢点/延迟抖动但 GEM 正常（提纲）**
- 分层：设备采样侧（采样线程负载/最高频率与点数是否超 DCM/会话配额 MaxHz/MaxTags）→编码（Freeze 版本/序列化开销）→网络（带宽/拥塞/MTU/loopback 与网卡）→EDC 接入（有界队列是否 Dropped、消费速度、GC/内存压力、线程调度）→客户端（订阅过多/处理慢反压）。
- 关键：GEM 正常说明 HSMS 控制通道与设备本体正常，问题集中在高频数据面；查质量码 Gap/Dropped 统计、watermark 推进、P95/P99 延迟、CPU/GC、订阅是否重复多点（应一次采集多客户端共享 fan-out，W29）。
- 根因方向：超配额/采样过密、客户端慢导致反压丢点、队列太小、GC pause/线程抢占、网络抖动。
- 整改：按需求反推合理频率（W34 Day06）、多客户端共享采集、调队列与背压、对象池化降 GC（呼应内存池）、必要时分会话/降频/Freeze III 提效，并以完整率/延迟 SLA 复验。

## 二、参考实现（net8.0）：能力画像评估器

```csharp
namespace EapLab.Arch;
public sealed record Dim(string Name,int Score,double Weight);
public sealed class CompetencyProfile
{ readonly List<Dim> _d=new();
    public CompetencyProfile Add(Dim d){_d.Add(d);return this;}
    public double WeightedScore=>_d.Sum(x=>x.Score*x.Weight)/_d.Sum(x=>x.Weight); // 1-5
    public IEnumerable<Dim> Weakest(int n)=>_d.OrderBy(x=>x.Score).Take(n);
    public string Level=>WeightedScore switch{>=4.5=>"expert",>=3.5=>"senior",>=2.5=>"intermediate",_=>"junior"};
    public List<string> Plan()
    =>Weakest(2).Select(x=>x.Name switch
        { "EDA/EDC 数据通道与治理"=>"专题: FreezeIII抓包+EDC水位线/质量码实验",
          "APC(FDC/R2R/VM/SPC)"=>"专题: dEWMA/VM特征/SPC手算与判异强化",
          "表达与排故"=>"每周白板讲1题+写1篇事故复盘",
          _=>$"强化 {x.Name}: 读SEMI原文+故障注入" }).ToList();
}
```
