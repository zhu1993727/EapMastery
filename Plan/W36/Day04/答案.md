# W36 · Day04 答案与参考实现

## 一、自测题标准答案
1. **14 图三类归类**：A 协议与 GEM300（9 张）——①HSMS 连接状态机、②SECS-II 报文与类型编码、③GEM 采集三层（VID→RPT→CEID→S6F11）、④GEM 控制状态机（在线离线/Spool）、⑤E84 并行 I/O 握手、⑥E87 Carrier 状态机、⑦E90 SlotMap 三态三不变式、⑧E40 PJ/E94 CJ 状态机与级联栅栏、⑨重连对账链；B EDA/APC/数据（4 张）——⑩GEM+EDA 双通道、⑪EDA 采集栈（CEM→DCM→调度→编码→订阅）、⑫APC 家族与三时间尺度/EWMA 闭环、⑬EDC 数据旅程（上下文+时间+质量→实时/历史两层）；C CIM/流程（1 组）——⑭CIM 交互矩阵+五泳道 12 阶段全链路+单片谱系时间轴。
2. **HSMS 图必标**：状态 NOT CONNECTED→NOT SELECTED→SELECTED（含 TCP 已连但未 Select 的区别）；迁移消息 SType：Select.req/sec(1/2)、Linktest.req/sec(3/4)、Separate(5)、Reject(7)；控制消息 vs 数据消息（SType vs W/R+Stream/Function）；定时器 T3（回复超时，典型 ~45s 量级，具体以标准/实现为准）、T8（Select 超时）、连接断开回退路径；还要标主动/被动方与重连。少了 Select 阶段或定时器就不算过关。
3. **E40/E94 图必标**：E40 PJ 状态 Queued/Received→Started→Executing，暂停子状态 Executing⇄Pausing⇄Paused（Pausing 是过渡、Paused 是稳定态、Resume 回 Executing），终态 Completed/Cancelled/Aborted/Failed；三正交（片槽×配方×腔/顺序）；E94 CJ→PJ→Wafer/Step 层级与级联两层栅栏（CjResumeToken 幂等、全序 all-or-nothing、多腔故障域隔离）；并标注受理（ACK）与生效（迁移事件+回读）的区别、异常终态分支。缺暂停子状态或终态/级联关系即为不完整。
4. **双通道四要点**：①职责对比——GEM/HSMS 一对一、面向控制与稀疏作业事件；EDA/Interface-A 多客户端订阅、高频连续只读；②共享同一事实源（设备数据总线），GEM 拿可写视图、EDA 只拿 `IReadOnlyDataBus` 只读视图，编译期封死写；③通道隔离、故障互不影响（EDA 高频拥塞不阻塞 GEM 控制，GEM 重连不影响 EDA 订阅恢复机制）；④协议代际 Freeze I/II=SOAP/XML over HTTP、Freeze III=Protocol Buffers（近 gRPC server streaming），下行控制永远只走 GEM。四者缺一就没讲透双通道。
5. **EDC 旅程图必含**：入口分 EDA 高频/GEM 事件；治理三环——事件驱动上下文绑定（Lot/Wafer/Job/Step/腔，缺片标 Unbound）、源时间戳+时钟同步+有序缓冲+水位线迟到处理、质量码（Good/Bad/Uncertain/Stale/Gap）只降不升与下游门控；之后分两层服务——实时层（水位关窗即结论、迟到不回溯）与历史层（全量落盘、可补传重算），下接热/温/冷分层存储与 TSDB/数据湖；还要标需求反推（消费方→ADC 计划）与数据契约、血缘。少了"两层语义差异"或"质量只降不升"就是关键遗漏。
6. **矩阵/全链路易懂标准**：节点按层分区（决策业务层 MES/YMS、使能层 EAP/RMS/APC、数据层 EDC、执行层设备/AMHS）；每条连线标注五要素——内容、通道（GEM/EDA/E84/服务）、方向、控制还是数据、同步/异步；用颜色或线型明确区分"唯一下行控制竖线（MES/APC→EAP→GEM→设备）"与"两股上行（EDA→EDC、GEM→EAP→MES）"；标出事实源与关键门控/生效点。别人不看你讲解，仅看图就能回答"谁能命令谁、数据从哪来到哪去、谁是事实源、异常怎么走"，才算达标；五泳道图则要能沿一片 Lot 走通 12 阶段且每阶段标到标准/消息。
7. **训练法/过关标准**：四遍法——①凭记忆闭卷默画（不看任何资料）；②对照标准答案图红笔标出所有漏节点、错方向、缺异常分支；③擦掉重画到一次成型、无红笔修改；④边画边费曼讲解（每个状态为何存在、每条箭头由什么触发、异常分支去哪、对应哪条工程铁律）。一张图真正过关的标准：一次成型无遗漏、能脱稿讲清每个元素与"为什么"、能现场回答追问的异常场景（断连/乱序/丢点/拒绝/重复）而不卡壳；对高频图还要能在 3–5 分钟内画完。过不了关的图记入待重画清单，次日先重默再学新内容。

## 二、参考实现（net8.0）：图表要素自检清单

```csharp
namespace EapLab.Arch;
public sealed record DiagramItem(string Name,bool Required,string[] MustHave);
public sealed class DiagramChecklist
{
    readonly Dictionary<string,HashSet<string>> _checked=new();
    readonly Dictionary<string,DiagramItem> _items=new();
    public DiagramChecklist Add(DiagramItem d){_items[d.Name]=d;_checked[d.Name]=new();return this;}
    public void Tick(string diagram,string element){_checked[diagram].Add(element);}
    public IEnumerable<string> Missing(string diagram)
    =>_items[diagram].MustHave.Where(e=>!_checked[diagram].Contains(e));
    public bool Passed(string diagram)=>!Missing(diagram).Any();
    public double Completion(string diagram)
    { var t=_items[diagram].MustHave.Length;return t==0?1:_checked[diagram].Count/(double)t; }
    // 高频图必须一次成型(无缺失)才算过关
    public IEnumerable<string> NotReady(IEnumerable<string> highFreq)=>highFreq.Where(d=>!Passed(d));
}
```

### xUnit
```csharp
public class ChecklistTests
{
    DiagramChecklist Book()=>new DiagramChecklist()
        .Add(new("HSMS",true,new[]{"states","select/linktest","timers","fallback"}))
        .Add(new("DualChannel",true,new[]{"1:1 vs multi","readonly view","isolation","freeze3"}));
    [Fact] public void 全要素勾选才通过()
    { var c=Book();foreach(var e in new[]{"states","select/linktest","timers","fallback"})c.Tick("HSMS",e);
      Assert.True(c.Passed("HSMS"));Assert.Empty(c.Missing("HSMS")); }
    [Fact] public void 缺要素能列出且不通过()
    { var c=Book();c.Tick("HSMS","states");
      Assert.False(c.Passed("HSMS"));Assert.Equal(3,c.Missing("HSMS").Count()); }
    [Fact] public void 高频图未达标被挑出()
    { var c=Book();c.Tick("DualChannel","1:1 vs multi");
      Assert.Contains("DualChannel",c.NotReady(new[]{"HSMS","DualChannel"})); }
    [Fact] public void 完成度计算()
    { var c=Book();c.Tick("HSMS","states");c.Tick("HSMS","timers");
      Assert.Equal(0.5,c.Completion("HSMS"),2); }
}
```

## 四、今日易错点
1. 只"看懂图"不默画，上场画不出（必须闭卷四遍法）。
2. HSMS 漏 Select 阶段或定时器。
3. E40 状态机漏 Pausing 过渡态、终态或 E94 级联栅栏。
4. 双通道图只画两条线，没表达只读隔离、共享事实源、故障隔离。
5. EDC 旅程漏质量只降不升或实时/历史语义差异。
6. CIM 图不标通道/方向/控制数据，别人看不懂谁命令谁。
7. 能画不能讲，讲不清"为什么有这个状态/异常箭头去哪"。
8. 不做一次成型训练，依赖涂改，答辩时逻辑混乱。
