# W10 · Day02 答案与参考实现

## 一、自测题标准答案
1. **列举场景 / 与 S15F11 区别**：典型场景：①重连状态同步——Host 重连后列举设备现有全部 Job/Carrier，重建本地实例缓存（防止断连期间对象被设备/操作员增删导致漂移）；②EAP 界面刷新——展示设备当前任务列表和状态；③调度决策——MES 派工前列举 ProcessJob 判断忙闲、列举 Carrier 判断载具占用；④对账——周期性比对 Host 缓存与设备实际对象集合。与 S15F11 的区别：方向相反、粒度不同——S15F11 是"**给定**一批 OBJSPEC，回答每个**是否存在**"（Host 已知对象，做存在性校验，输入是 OBJSPEC 列表，输出是布尔结果）；列举是"**不指定或只指定类型/父**，回答设备上**到底有哪些**对象"（Host 不知道有哪些，输出是 OBJSPEC 列表）。重连时通常先列举拿全集，再对全集批量查询属性详情。
2. **为什么分页 / 参数和返回 / 怎么翻页**：对象数量可能很大（一台设备数百片 Substrate、多个 Lot），单条 SECS 消息受最大长度限制（设备能力协商，超长会触发 S9F9），一次全量返回会撑爆消息、增大延迟和内存峰值，所以分页。分页参数：StartIndex（起始索引/游标，从 0 开始）、Count（本页请求数量，如 50）、可选过滤条件（类型、父路径、状态）。返回字段：本页实例列表、TotalCount（满足条件的总数，可选）、HasMore（是否还有下一页）、NextCursor（下一页起始游标=本次 StartIndex+本页实际条数）。Host 翻页：从 StartIndex=0 开始，每次用返回的 NextCursor 作为下一次 StartIndex，直到 HasMore=false；翻页期间对象集合可能变化（新增/删除），工程上可带快照版本号或接受最终一致。
3. **批量查询矩阵 / 对象不存在怎么处理**：请求=L,2[L,n 个 OBJSPEC, L,m 个统一 AttrId]；返回=L,2[ACKC, L,n 行，每行=L,2[OBJSPEC, L,m 个值（与请求属性同序）]]，即 N 对象×M 属性矩阵，Host 用 (对象下标,属性下标) 定位值。某个对象不存在或某属性取不到：**批量查询允许部分失败**（读操作无副作用，不应因一个坏点让整批失败），该对象行的值列表对应位置放空值/错误标记（如该位置用空 List 或带错误码的子结构），行级或单元级标注错误，其他对象正常返回；Host 据此知道哪个对象失效（可从重连同步中剔除）。
4. **批量读 vs 批量写原子性 / 为什么不同**：批量读（列举/批量查询）**无副作用**，不改变设备状态，允许部分成功——某对象查不到不影响其他对象返回，逐项标注结果即可，可用性优先。批量写（批量创建/设置/删除）**有副作用**，改变对象状态，推荐"请求内原子"——先整批校验全部通过再统一提交，任一非法整批拒绝、设备状态完全不变。原因：写操作部分成功会产生不一致（创建了 CJ 但 PJ 创建失败、设置了上限没设下限），Host 难以补偿，工艺对象属性间有耦合，半更新危害大；读操作只是观察，部分失败可重试、无一致性风险。跨对象强一致（CJ+PJ 同时建）用显式事务或强制按依赖顺序创建并在失败时回滚已建对象。
5. **子树列举实现 / 防环路重复**：从给定父 OBJSPEC 出发，用 W10 Day01 的 ObjectTree.GetChildren 取直接子，对每个子递归（深度优先 DFS 或广度优先 BFS），收集所有子孙，可选择是否包含父自身。防环路：对象树是包含关系、每个子只有唯一父（Day01 AddChild 已强制），结构上不可能成环；但实现上仍加 visited 集合（HashSet<spec>）防御性去重，进入节点前检查是否已访问，已访问则跳过，避免异常数据导致无限递归；同时限制最大深度/节点数作为安全阀。分页在"收集完全部子孙后"或"流式遍历"时按游标切片。
6. **列举要不要带属性快照 / 带多少**：可以带"轻量摘要"，不宜带全部属性。列举的首要目的是拿到对象标识集合（OBJSPEC），若每个对象只返回 OBJSPEC，Host 还要对每个对象发批量查询，往返多；因此可在列举时为每个对象带少量**关键摘要属性**（如状态 ProcessState、LotID），一次拿到列表+核心状态，供界面列表和调度快速使用。但不宜带全部属性——会让消息膨胀、抵消分页意义，且很多详情属性列表场景用不到。最佳实践：列举带固定的"摘要属性集"（类型定义中标记为 summary 的属性，如状态/ID/时间），详情按需用批量查询 S15F15 拉取。

## 二、参考实现

### S15F13 列举处理器（类型/子树 + 分页）
```csharp
using EapLab.Oss.ObjectModel;
using EapLab.Oss.Tree;
using EapLab.Secs2;

namespace EapLab.Oss.S15;

public sealed class ListQuery
{
    public string? TypeFilter { get; init; }
    public string? ParentSpec { get; init; }   // 非空=列子树
    public int StartIndex { get; init; }
    public int Count { get; init; } = 50;
    public string[] SummaryAttrs { get; init; } = Array.Empty<string>();
}

public sealed class S15F13Handler
{
    private readonly ObjectRegistry _registry;
    private readonly ObjectTree _tree;
    public S15F13Handler(ObjectRegistry registry, ObjectTree tree)
    { _registry = registry; _tree = tree; }

    public SecsItem Handle(SecsItem? body) => SafeHandler.Run(() =>
    {
        var q = Parse(body);
        // 1. 收集候选集合
        List<ObjectInstance> all;
        if (q.ParentSpec != null)
        {
            all = CollectSubtree(q.ParentSpec); // 子树 DFS
        }
        else
        {
            all = _registry.ListInstances(q.TypeFilter).ToList();
        }
        // 2. 稳定排序（按 OBJSPEC，保证分页顺序确定）
        all = all.OrderBy(i => i.ObjSpec).ToList();

        int total = all.Count;
        // 3. 分页切片
        var page = all.Skip(q.StartIndex).Take(q.Count).ToList();
        bool hasMore = q.StartIndex + page.Count < total;
        int nextCursor = q.StartIndex + page.Count;

        // 4. 组装（OBJSPEC + 摘要属性）
        var rows = page.Select(inst =>
        {
            var rowItems = new List<SecsItem> { SecsItem.A(inst.ObjSpec) };
            if (q.SummaryAttrs.Length > 0)
            {
                var sums = q.SummaryAttrs
                    .Select(a => inst.GetAttribute(a) ?? SecsItem.L(Array.Empty<SecsItem>()))
                    .ToArray();
                rowItems.Add(SecsItem.L(sums));
            }
            return SecsItem.L(rowItems.ToArray());
        }).ToArray();

        // 返回：L,4[ACKC, L,n 行, U4 total, L,2[Boolean hasMore, U4 nextCursor]]
        return SecsItem.L(
            SecsItem.U1(0),
            SecsItem.L(rows),
            SecsItem.U4((uint)total),
            SecsItem.L(SecsItem.Boolean(hasMore), SecsItem.U4((uint)nextCursor)));
    },
    code => SecsItem.L(SecsItem.U1((byte)code), SecsItem.L(Array.Empty<SecsItem>()),
                        SecsItem.U4(0), SecsItem.L(SecsItem.Boolean(false), SecsItem.U4(0))));

    private List<ObjectInstance> CollectSubtree(string parentSpec)
    {
        var result = new List<ObjectInstance>();
        var visited = new HashSet<string>();           // 防御性去重
        void Dfs(string spec, int depth)
        {
            if (depth > 64 || !visited.Add(spec)) return; // 深度/环路安全阀
            foreach (var child in _tree.GetChildren(spec))
            {
                result.Add(_registry.GetInstance(child));
                Dfs(child, depth + 1);
            }
        }
        Dfs(parentSpec, 0);
        return result;
    }

    private static ListQuery Parse(SecsItem? body)
    {
        // 教学解析：L,4[类型A?, 父A?, L,2[start,count], L,n 摘要属性]
        if (body is not SecsList l) return new ListQuery();
        string? type = l.Items.Count > 0 && l.Items[0] is SecsAscii ta ? ta.Value : null;
        string? parent = l.Items.Count > 1 && l.Items[1] is SecsAscii pa ? pa.Value : null;
        int start = 0, count = 50;
        if (l.Items.Count > 2 && l.Items[2] is SecsList pg)
        {
            if (pg.Items.Count > 0 && pg.Items[0] is SecsU4 s) start = (int)s.Values[0];
            if (pg.Items.Count > 1 && pg.Items[1] is SecsU4 c) count = (int)c.Values[0];
        }
        return new ListQuery { TypeFilter = type, ParentSpec = parent, StartIndex = start, Count = count };
    }
}
```

### S15F15 批量查询（N×M 矩阵，部分失败容错）
```csharp
public sealed class S15F15Handler
{
    private readonly ObjectRegistry _registry;
    public S15F15Handler(ObjectRegistry registry) => _registry = registry;

    public SecsItem Handle(SecsItem? body) => SafeHandler.Run(() =>
    {
        var l = (SecsList)body!;
        var specs = ((SecsList)l.Items[0]).Items.Cast<SecsAscii>().Select(a => a.Value).ToList();
        var attrIds = ((SecsList)l.Items[1]).Items.Cast<SecsAscii>().Select(a => a.Value).ToList();

        var rows = new List<SecsItem>();
        foreach (var spec in specs)
        {
            ObjectInstance? inst = null;
            try { inst = _registry.GetInstance(spec); } catch (OssCodedException) { /* 对象失效 */ }

            var values = new List<SecsItem>();
            if (inst == null)
            {
                // 对象不存在：每个位置放空标记，行级错误码 2
                for (int i = 0; i < attrIds.Count; i++)
                    values.Add(SecsItem.L(Array.Empty<SecsItem>())); // 空=取不到
                rows.Add(SecsItem.L(SecsItem.A(spec), SecsItem.U1(2), SecsItem.L(values.ToArray())));
                continue;
            }

            foreach (var attrId in attrIds)
            {
                var v = inst.GetAttribute(attrId);
                values.Add(v ?? SecsItem.L(Array.Empty<SecsItem>())); // 属性缺失放空
            }
            rows.Add(SecsItem.L(SecsItem.A(spec), SecsItem.U1(0), SecsItem.L(values.ToArray())));
        }
        return SecsItem.L(SecsItem.U1(0), SecsItem.L(rows.ToArray()));
    },
    code => SecsItem.L(SecsItem.U1((byte)code), SecsItem.L(Array.Empty<SecsItem>())));
}
```

### 批量设置（跨对象整批原子）
```csharp
public sealed class BatchSetHandler
{
    private readonly ObjectRegistry _registry;
    public BatchSetHandler(ObjectRegistry registry) => _registry = registry;

    public SecsItem Handle(SecsItem? body) => SafeHandler.Run(() =>
    {
        var l = (SecsList)body!;
        var updates = ((SecsList)l.Items[0]).Items.Cast<SecsList>().Select(req =>
        {
            var spec = ((SecsAscii)req.Items[0]).Value;
            var pairs = S15F1Handler.ParseAttrValues((SecsList)req.Items[1]);
            return (spec, pairs);
        }).ToList();

        // 阶段1：跨对象整批校验（不写入）
        foreach (var (spec, pairs) in updates)
        {
            var inst = _registry.GetInstance(spec);
            foreach (var kv in pairs)
            {
                var def = inst.Type.GetAttribute(kv.Key)
                    ?? throw new OssCodedException(OssErrorCode.AttrNotFound, $"{spec}.{kv.Key}");
                if (def.Access == AccessMode.ReadOnly)
                    throw new OssCodedException(OssErrorCode.ReadOnlyAttr, $"{spec}.{kv.Key}");
            }
        }
        // 阶段2：全部通过才提交
        foreach (var (spec, pairs) in updates)
        {
            var inst = _registry.GetInstance(spec);
            foreach (var kv in pairs) inst.SetAttribute(kv.Key, kv.Value);
        }
        return SecsItem.L(SecsItem.U1(0));
    },
    code => SecsItem.L(SecsItem.U1((byte)code)));
}
```

### 单元测试（节选）
```csharp
public class ListAndBatchTests
{
    [Fact]
    public void 分页列举_120个对象每页50_共3页()
    {
        var reg = new ObjectRegistry();
        reg.RegisterType(new ObjectType("Substrate"));
        for (int i = 0; i < 120; i++)
            reg.CreateInstance("Substrate", $"W{i:D3}", new());
        var tree = new ObjectTree(reg, new CompositionRule());
        var h = new S15F13Handler(reg, tree);

        var p1 = (SecsList)h.Handle(MakeListBody(null, null, 0, 50));
        Assert.Equal(50, ((SecsList)p1.Items[1]).Items.Count);
        Assert.Equal(120u, ((SecsU4)p1.Items[2]).Values[0]);
        Assert.True(((SecsBoolean)((SecsList)p1.Items[3]).Items[0]).Values[0]); // hasMore

        var p3 = (SecsList)h.Handle(MakeListBody(null, null, 100, 50));
        Assert.Equal(20, ((SecsList)p3.Items[1]).Items.Count);  // 最后一页 20
        Assert.False(((SecsBoolean)((SecsList)p3.Items[3]).Items[0]).Values[0]);
    }

    [Fact]
    public void 批量查询_含不存在对象_其他正常返回()
    {
        var reg = new ObjectRegistry();
        reg.RegisterType(new ObjectType("ProcessJob")
            .AddAttribute(new("LotID", "批次", SecsDataType.A, AccessMode.ReadWrite)));
        reg.CreateInstance("ProcessJob", "P1", new() { ["LotID"] = SecsItem.A("L1") });
        var h = new S15F15Handler(reg);
        var body = SecsItem.L(
            SecsItem.L(SecsItem.A("ProcessJob:P1"), SecsItem.A("ProcessJob:PX")),
            SecsItem.L(SecsItem.A("LotID")));
        var reply = (SecsList)h.Handle(body);
        var rows = (SecsList)reply.Items[1];
        Assert.Equal(2, rows.Items.Count);
        // P1 行 ACKC=0，PX 行 ACKC=2
        Assert.Equal(0u, ((SecsU1)((SecsList)rows.Items[0]).Items[1]).Values[0]);
        Assert.Equal(2u, ((SecsU1)((SecsList)rows.Items[1]).Items[1]).Values[0]);
    }
}
```

## 三、今日易错点
1. 列举不分页，一次返回几百对象撑爆消息（必须分页，带 HasMore/NextCursor）。
2. 分页不排序导致翻页重复/遗漏（列举结果要稳定排序，如按 OBJSPEC）。
3. 批量查询因一个对象不存在让整批失败（读操作允许部分失败，单元/行级标注）。
4. 批量写边校验边写（跨对象也要两阶段原子，整批校验后统一提交）。
5. 子树列举不防环路/不限制深度（加 visited 和深度安全阀，虽然唯一父结构上无环）。
6. 列举带全部属性导致消息膨胀（只带摘要属性，详情用批量查询）。
7. 翻页期间对象增删导致索引漂移（用快照版本或游标，接受最终一致，工程上知悉即可）。
8. 混淆列举（设备有哪些）和存在性查询（给定对象在不在）。
