## 二、完整 FAB 场景（必背，毕业考试题目）

### 阶段1：连接与建链（W2/W5）
```
1. Host TCP 连接设备 → 连接成功
2. Host 发 HSMS Select.req → 设备回 Select.rsp(Status=0) → SELECTED
3. Host 发 S1F13(MDLN="MES_HOST", SOFTREV="3.1") → 设备回 S1F14(MDLN="ETCHER_01", SOFTREV="2.5") → 通信建立
4. Host 发 S1F17(Request On-line) → 设备回 S1F18(ACKC1=0) → 通信 ON-LINE
5. 操作员切远程 → 控制 ON-LINE → 设备发 S6F11(控制状态变化事件) → Host 回 S6F12
```

### 阶段2：能力发现与配置（W6/W7）
```
6. Host 发 S1F3(空) → 设备回 S1F4(SV列表：温度=100, 压力=101, 运行状态=102, 通信状态=103, 控制状态=104)
7. Host 发 S1F5(空) → 设备回 S1F6(事件列表：LotStart=3001, WaferStart=3002, WaferEnd=3003, LotEnd=3004, CmdStart=3101, CmdComplete=3102, CmdFail=3103, AlarmSet=3201, AlarmClear=3202)
8. Host 发 S5F5(空) → 设备回 S5F6(报警列表：温度过高=1001(ALCD=3), 压力过低=1002(ALCD=2), 门未关=1003(ALCD=1))
9. Host 发 S1F7(空) → 设备回 S1F8(报告列表：空)
10. Host 发 S2F33(RPTID=1, VID=[100,101]) → 设备回 S2F34(ACKC5=0) → 定义"工艺数据报告"
11. Host 发 S2F33(RPTID=2, VID=[102]) → 设备回 S2F34(ACKC5=0) → 定义"状态报告"
12. Host 发 S2F35(CEID=3001, RPTID=[1]) → 设备回 S2F36(ACKC6=0) → LotStart 关联工艺数据
13. Host 发 S2F35(CEID=3004, RPTID=[1,2]) → 设备回 S2F36(ACKC6=0) → LotEnd 关联工艺数据+状态
14. Host 发 S2F35(CEID=3102, RPTID=[2]) → 设备回 S2F36(ACKC6=0) → 命令完成关联状态
15. Host 发 S2F35(CEID=3103, RPTID=[2]) → 设备回 S2F36(ACKC6=0) → 命令失败关联状态
16. Host 发 S5F3(ALED=1, 空=全部) → 设备回 S5F4(ACKC5=0) → 使能所有报警
17. Host 发 S7F3(PPID="RCP_A", PPBODY=工艺参数) → 设备回 S7F4(ACKC7=0) → 下载配方
```

### 阶段3：正常生产（W5/W6/W7）
```
18. Host 发 S2F41(START, LOTID="LOT001", RECIPE="RCP_A", QUANTITY=25)
    → 设备回 S2F42(ACKC10=0) → 命令接受(PENDING)
19. 设备开始执行(EXECUTING) → 发 S6F11(CmdStart=3101, 状态报告) → Host 回 S6F12
20. 设备加载配方 RCP_A → 开始工艺执行
21. Lot 开始 → 发 S6F11(LotStart=3001, 工艺数据报告：温度=200.5°C, 压力=1.5Pa) → Host 回 S6F12
22. 每片 Wafer 开始/结束 → 发 S6F11(WaferStart=3002 / WaferEnd=3003) → Host 回 S6F12
23. 执行到第 15 片时，温度过高(>250°C) → 设置报警(ALID=1001, SET)
    → 发 S5F1(ALID=1001, "Temperature High") → Host 回 S5F2
    → 严重报警中断命令 → 命令 FAILED(失败原因="Temperature High, interrupted at wafer 15")
    → 发 S6F11(CmdFail=3103, 状态报告：失败原因) → Host 回 S6F12
24. Host 收到报警和命令失败 → 通知操作员，暂停派工
```

### 阶段4：通信断开与 Spool（W8）
```
25. 操作员处理报警时，网络故障 → TCP 断开 → HSMS Select 丢失
26. 设备检测到通信断开 → 通信 OFF-LINE → 触发 Spool 模式
27. 操作员清除报警(温度恢复) → 报警 CLEAR → 设备内部记录，但不发 S5F1(Spool 缓存)
28. 操作员重新启动生产 → Lot 结束(第15片后停止，实际完成14片) → 设备内部触发 LotEnd 事件 → Spool 缓存 S6F11
29. Host 重启 → 网络恢复
```

### 阶段5：重连恢复与补收数据（W5/W8）
```
30. Host TCP 重连 → HSMS Select → SELECTED
31. Host 发 S1F13 → 设备回 S1F14 → 通信建立
32. Host 发 S1F17 → 设备回 S1F18(ACKC1=0) → 通信 ON-LINE
33. 设备检测到通信恢复 → 开始重发 Spool 缓存
34. 设备重发 S5F1(报警清除, ALID=1001) → Host 回 S5F2 → 设备从缓存删除
35. 设备重发 S6F11(LotEnd=3004, 工艺数据+状态报告) → Host 回 S6F12 → 设备从缓存删除
36. Spool 清空 → 设备切回 Normal 模式
37. Host 发 S2F43(查询 Spool 状态) → 设备回 S2F44(记录数=0, 容量=10000, 模式=Normal)
38. Host 重新配置数据采集(报告/事件关联，因为设备重启后配置丢失)
39. Host 重新使能报警(S5F3)
```

### 阶段6：继续生产与优雅断开（W5/W6/W7）
```
40. Host 发 S2F41(START, LOTID="LOT002", RECIPE="RCP_A", QUANTITY=10)
    → 设备回 S2F42(ACKC10=0) → 命令接受
41. 设备执行 → LotStart → WaferStart/End ×10 → LotEnd → CmdComplete
    → 所有 S6F11 正常上报，Host 回 S6F12
42. Host 发 S1F11(VID=[100,101,102]) → 设备回 S1F12(温度=200.0, 压力=1.5, 状态=IDLE)
43. Host 发 S1F15(Request Off-line) → 设备回 S1F16(ACKC1=0) → 通信 OFF-LINE
44. Host 发 HSMS Deselect.req → 设备回 Deselect.rsp → NOT SELECTED
45. Host TCP 断开 → 连接关闭
```
