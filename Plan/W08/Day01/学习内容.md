## 三、完整业务流程演练（必背，40 分钟）

### 场景：Host 连接设备，生产一个 Lot（25 片），然后断开

```
阶段1：连接与建链（W2/W5）
  1. Host TCP 连接设备 → 连接成功
  2. Host 发 HSMS Select.req → 设备回 Select.rsp(Status=0) → SELECTED
  3. Host 发 S1F13(MDLN="HOST", SOFTREV="2.0") → 设备回 S1F14(MDLN="EAP-SIM", SOFTREV="1.0") → 通信建立
  4. Host 发 S1F17(Request On-line) → 设备回 S1F18(ACKC1=0) → 通信 ON-LINE
  5. 操作员切远程 → 控制 ON-LINE（设备发 S6F11 控制状态变化事件，如果配置了）

阶段2：能力发现（W6/W7）
  6. Host 发 S1F3(空) → 设备回 S1F4（所有 SV 的 VID+名称，如温度=100、压力=101、运行状态=102）
  7. Host 发 S1F5(空) → 设备回 S1F6（所有事件的 CEID+名称，如 LotStart=3001、WaferStart=3002、WaferEnd=3003、LotEnd=3004、CmdStart=3101、CmdComplete=3102、CmdFail=3103）
  8. Host 发 S5F5(空) → 设备回 S5F6（所有报警的 ALID+ALCD+ALTX，如温度过高=1001、压力过低=1002）
  9. Host 发 S1F7(空) → 设备回 S1F8（已定义报告列表，通常为空）

阶段3：配置数据采集（W6）
  10. Host 发 S2F33(RPTID=1, VID=[100,101]) → 设备回 S2F34(ACKC5=0) → 定义"工艺数据报告"（温度+压力）
  11. Host 发 S2F33(RPTID=2, VID=[102]) → 设备回 S2F34(ACKC5=0) → 定义"状态报告"（运行状态）
  12. Host 发 S2F35(CEID=3001, RPTID=[1]) → 设备回 S2F36(ACKC6=0) → LotStart 关联工艺数据报告
  13. Host 发 S2F35(CEID=3004, RPTID=[1,2]) → 设备回 S2F36(ACKC6=0) → LotEnd 关联工艺数据+状态报告
  14. Host 发 S2F35(CEID=3102, RPTID=[2]) → 设备回 S2F36(ACKC6=0) → 命令完成关联状态报告
  15. Host 发 S2F35(CEID=3103, RPTID=[2]) → 设备回 S2F36(ACKC6=0) → 命令失败关联状态报告

阶段4：使能报警 + 下载配方（W7）
  16. Host 发 S5F3(ALED=1, 空=全部) → 设备回 S5F4(ACKC5=0) → 使能所有报警
  17. Host 发 S7F3(PPID="RCP_A", PPBODY=工艺参数) → 设备回 S7F4(ACKC7=0) → 下载配方

阶段5：生产执行（W5/W6/W7）
  18. Host 发 S2F41(RCMD="START", 参数：LOTID="LOT001", RECIPE="RCP_A", QUANTITY=25)
      → 设备回 S2F42(ACKC10=0) → 命令已接受（PENDING）
  19. 设备开始执行命令（EXECUTING）→ 触发 CmdStart 事件(CEID=3102) → 发 S6F11（状态报告）→ Host 回 S6F12
  20. 设备加载配方 RCP_A → 开始工艺执行
  21. Lot 开始 → 触发 LotStart 事件(CEID=3001) → 发 S6F11（工艺数据报告：温度=25.5, 压力=100）→ Host 回 S6F12
  22. 每片 Wafer 开始/结束 → 触发 WaferStart/WaferEnd 事件（如果配置了）→ 发 S6F11
  23. 25 片全部完成 → Lot 结束 → 触发 LotEnd 事件(CEID=3004) → 发 S6F11（工艺数据+状态报告）→ Host 回 S6F12
  24. 命令执行完成（COMPLETED）→ 触发 CmdComplete 事件(CEID=3102) → 发 S6F11（状态报告）→ Host 回 S6F12

阶段6：查询结果与断开（W5/W6）
  25. Host 发 S1F11(VID=[100,101,102]) → 设备回 S1F12（当前温度、压力、运行状态）
  26. Host 发 S1F15(Request Off-line) → 设备回 S1F16(ACKC1=0) → 通信 OFF-LINE
  27. Host 发 HSMS Deselect.req → 设备回 Deselect.rsp → NOT SELECTED
  28. Host TCP 断开 → 连接关闭
```
