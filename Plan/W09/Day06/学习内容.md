## 二、背景知识（先读，20 分钟）

### 1. S15 处理器的统一处理模式
每个 S15 处理器都遵循同一模式：
```
解析请求 body（提取 OBJSPEC / 属性 / 方法 / 参数）
 → 调用 ObjectRegistry / ObjectInstance
 → 成功：组装 reply（ACKC=0 + 数据）
 → 捕获 OssException：映射为对应 ACKC 非 0 + 空数据
 → 未知异常：ACKC=99 + 日志（不崩溃，W8 Day05 原则）
```
建议抽一个基类或辅助方法 `SafeHandle(Func<SecsItem>)`，统一 try/catch 和错误码映射，避免六个处理器重复写异常处理。

### 2. ACKC 错误码映射（Day05 表的代码化）
定义 OssErrorCode 枚举和异常到错误码的映射：
- 未知类型→1、实例不存在→2、已存在→3、属性不存在→4、只读→5、缺必填→6、类型不匹配→7、状态非法→8、方法不存在→9、参数错误→10、内部错误→99。
- 建议在 OssException 上携带错误码字段（如 OssException(code, message)），ObjectRegistry/ObjectInstance 抛异常时就带上精确错误码，处理器直接读取，避免靠异常消息文本匹配。

### 3. S15F5/F6 查询属性的顺序对应实现
- 请求解析出 List<string> attrIds（空=全部）。
- 非空：严格按 attrIds 顺序，逐个 instance.GetAttribute，组装 L,2[A AttrId, 值]；属性取不到时该项带错误标记但不影响其他项（或整批回错误，取决于规范，教学版逐项返回）。
- 空列表：取 type.Attributes 的注册顺序，返回全部属性。

### 4. S15F7/F8 整批原子设置实现
- 先解析出 List<(attrId, value)>。
- **第一阶段校验（不写入）**：逐个校验属性存在、非只读、状态允许、类型匹配；任一失败立即回错误码，不做任何写入。
- **第二阶段提交**：全部校验通过后，循环 SetAttribute 真正写入。
- 两阶段保证原子性：校验阶段对象状态不变。

### 5. S15F9/F10 方法调用实现
- 解析 OBJSPEC、METHODID、输入参数字典。
- GetInstance 定位对象 → instance.InvokeMethod（内部做 RequiredState 校验，非法抛状态异常→ACKC=8）。
- 方法执行器（executor）是设备端注入的委托：真正驱动状态机转换（如 Start 委托里调用 instance.TransitionTo("EXECUTING", canTransition)）。
- TransitionTo 触发 EventRaised → ObjectEventService 发 S16F1（异步于 S15F10 应答）。
- S15F10 立即回 ACKC=0（接受），S16F1 在状态转换时发出。

### 6. S16F1/F2 对象事件服务
- ObjectEventService 在创建实例时订阅 instance.EventRaised（删除实例时取消订阅，防止泄漏）。
- 事件回调里组装 S16F1 body：
  ```
  L,3
    [0] A OBJSPEC
    [1] U4 CEID
    [2] L,n[ L,2[A AttrId, 值] ]   // 事件定义的 LinkedAttributes 快照
  ```
- 通过 HsmsConnection.SendPrimaryAsync(16,1,body) 发送；通信中断时走 SpoolManager.SendOrSpool（复用 W8 的 Spool，S16F1 和 S6F11 一样是需要缓存的事件消息）。
- S16F2 是 Host 回的确认（L,1[U1 ACKC]），收到后走和 S6F12 相同的确认机制（Spool 待确认删除）。
- S16Router 处理 Host 主动发的 S16 消息（如订阅管理 S16F3/F4，教学版先实现 F2 确认处理）。

### 7. 订阅生命周期管理（防内存泄漏）
- 对象创建（S15F1）成功后，ObjectEventService.Subscribe(instance)。
- 对象删除（S15F3）前，ObjectEventService.Unsubscribe(instance)。
- 若设备内部也创建对象（非 Host 创建），同样要订阅。
- 用 WeakReference 或显式注销，避免删除对象后事件委托仍持有实例导致 GC 无法回收。
