# W09 · Day02 答案与参考实现

## 一、自测题标准答案
1. **为什么分元数据层和实例层 / 代码怎么体现**：因为"类型定义"是静态的、全设备共享一份（ProcessJob 类型只有一个定义，所有 PJ 实例都遵循它），而"实例数据"是动态的、每个对象一份（PJ001/PJ002/PJ003 状态各不相同）。混在一起会导致：类型定义被实例数据污染、无法在没有实例时查询类型（S14 需要在创建实例前就回答"你支持什么类型"）、新增实例时重复存储类型定义浪费内存。代码体现：定义两套类——元数据层 ObjectType + AttributeDefinition/MethodDefinition/EventDefinition（注册一次，只读），实例层 ObjectInstance（持有 OBJSPEC 和运行时属性值字典，引用对应 ObjectType）；ObjectRegistry 分两个字典 TypeRegistry（类型名→ObjectType）和 InstanceStore（OBJSPEC→ObjectInstance）。S14 查 TypeRegistry，S15/S16 操作 InstanceStore。
2. **AccessMode 有哪几种 / 为什么大部分属性 ReadOnly**：三种——ReadOnly（只读，Host 只能用 S15F5 查询）、ReadWrite（可读写，Host 可用 S15F7 设置）、WriteOnly（只写，少见，如某些控制指令型属性）。大部分属性是 ReadOnly 的原因：对象属性反映的是**设备内部真实状态**（如 ProcessState、StartTime、WaferCount），这些状态由设备内部逻辑和工艺执行决定，Host 不能直接改写，否则会造成"Host 以为的状态"和"设备真实状态"不一致，破坏状态权威性（设备是状态的权威来源）。只有少量"配置型"属性（如 LotID、OperatorID、优先级 Priority）允许 Host 在对象创建前/特定状态下写入，而且通常只允许在对象未开始执行（如 QUEUED/READY 状态）时写，执行中锁定。
3. **RequiredState 是什么 / 错误状态调用怎么处理**：RequiredState 是方法定义中声明的"允许调用该方法的前置对象状态"集合。例如 ProcessJob.Start 只允许在 QUEUED/READY/PAUSED 状态调用（PAUSED 时 Start 等价 Resume），在 EXECUTING 状态调 Start 非法（已经在跑），在 COMPLETED/ABORTED 终态调 Start 也非法（已结束）。错误状态下调用的处理：①设备端 ObjectInstance.InvokeMethod 先查当前状态是否在 RequiredState 集合内；②不在则拒绝执行，S15F10 返回错误码（方法状态非法，类似 ACKC 非 0），不改变对象状态；③记录日志（OBJSPEC、METHODID、当前状态、允许状态）；④这和 GEM 状态机非法转换拦截是同一原则——状态机是唯一管理者，方法调用必须经过状态校验。
4. **事件触发到 S16F1 的调用链**：①设备内部逻辑导致对象状态变化（如 ProcessJob 状态机转到 EXECUTING）；②ObjectInstance 检测到状态变化，查 ObjectType 中该状态对应的 EventDefinition（如 Started）；③ObjectInstance 按 EventDefinition.LinkedAttributes 从自己属性字典中快照属性值；④ObjectInstance 触发 OnEventRaised 事件（C# event，携带 OBJSPEC+CEID+属性快照）；⑤上层 ObjectEventService 订阅该事件，组装 S16F1 body（OBJSPEC、CEID、属性快照列表）；⑥ObjectEventService 调用 HsmsConnection.SendPrimaryAsync(16,1,body) 发给 Host；⑦Host 回 S16F2 确认（若走 Spool，通信中断时此消息进 Spool 缓存，和 S6F11 同一机制）。链路：状态机转换→查事件定义→快照属性→C# event→EventService 组包→HSMS 发送。
5. **CreateInstance 需要做哪些校验**：①类型存在性——typeName 必须在 TypeRegistry 注册过，未注册类型拒绝（S15F2 返回"未知对象类型"）；②OBJSPEC 唯一性——同 OBJSPEC 实例不能已存在（重复创建拒绝，返回"对象已存在"）；③ID 合法性——实例 ID 非空、长度/字符集符合设备约定；④必填属性——AttributeDefinition.Required=true 的属性必须在 initialAttributes 中提供，缺失拒绝（返回"缺少必填属性 xxx"）；⑤属性合法性——提供的属性必须是该类型定义过的 ATTRID，未知属性拒绝（或忽略+告警，取决于策略）；⑥属性类型——初始值类型必须和 AttributeDefinition.DataType 匹配；⑦只读属性初始值——ReadOnly 属性允许创建时给初值，但之后不可 S15F7 修改；⑧数量上限——该类型实例数不超过设备支持上限（如最多 16 个 ProcessJob）；⑨状态合法性——部分类型要求前置对象存在（如创建 ProcessJob 前要求对应 Carrier 已 Loaded）。
6. **并发创建相同 OBJSPEC 的问题 / 怎么避免**：问题：两个 Host 操作线程（或 Host 线程与设备内部线程）同时 CreateInstance 相同 OBJSPEC，若"检查存在性"和"加入字典"不是原子操作，两个线程都通过检查后都加入字典，导致后一个覆盖前一个（或字典异常）、产生两个逻辑实例、状态错乱。避免方法：①对 InstanceStore 的写操作加锁（lock 同一对象），把"检查重复+创建+入字典"放在一个锁内成为原子操作；②或用 ConcurrentDictionary.GetOrAdd 但要注意工厂函数可能被多次调用，需配合 Lazy 或先构造对象再 TryAdd，TryAdd 失败说明已存在；③全局为 OBJSPEC 创建分配加锁，保证同一 OBJSPEC 串行化创建；④删除/查询也要考虑并发（查询时对象可能正被另一线程删除），返回实例引用后操作期间要保证对象不被释放（引用计数或锁）。

```csharp
namespace EapLab.Oss.ObjectModel;

public enum AccessMode { ReadOnly, ReadWrite, WriteOnly }

{

    private readonly Dictionary<string, AttributeDefinition> _attributes = new();
    private readonly Dictionary<string, MethodDefinition> _methods = new();
    private readonly Dictionary<uint, EventDefinition> _events = new();

    public ObjectType(string typeName) => TypeName = typeName;

    public ObjectType AddAttribute(AttributeDefinition def) { _attributes[def.AttrId] = def; return this; }
    public ObjectType AddMethod(MethodDefinition def) { _methods[def.MethodId] = def; return this; }
    public ObjectType AddEvent(EventDefinition def) { _events[def.Ceid] = def; return this; }

    public AttributeDefinition? GetAttribute(string attrId) => _attributes.GetValueOrDefault(attrId);
    public MethodDefinition? GetMethod(string methodId) => _methods.GetValueOrDefault(methodId);
    public EventDefinition? GetEvent(uint ceid) => _events.GetValueOrDefault(ceid);
    public IEnumerable<AttributeDefinition> Attributes => _attributes.Values;
    public IEnumerable<MethodDefinition> Methods => _methods.Values;
    public IEnumerable<EventDefinition> Events => _events.Values;
}
```

### 实例层
```csharp
namespace EapLab.Oss.ObjectModel;

/// <summary>对象实例（实例层，动态创建/删除）。</summary>
public sealed class ObjectInstance
{
    public string ObjSpec { get; }           // "Type:ID"
    public string TypeName { get; }
    public ObjectType Type { get; }
    private readonly Dictionary<string, SecsItem> _attrValues = new();
    private readonly object _lock = new();
    private string _state;

    /// <summary>对象事件触发回调（上层订阅后发 S16F1）。参数：OBJSPEC, CEID, 属性快照。</summary>
    public event Action<string, uint, Dictionary<string, SecsItem>>? EventRaised;

    public ObjectInstance(ObjectType type, string id, string initialState,
                          Dictionary<string, SecsItem> initialValues)
    {
        TypeName = type.TypeName;
        Type = type;
        ObjSpec = $"{type.TypeName}:{id}";
        _state = initialState;

        // 先填默认值，再用初始值覆盖
        foreach (var attr in type.Attributes)
            if (attr.DefaultValue != null) _attrValues[attr.AttrId] = attr.DefaultValue;
        foreach (var kv in initialValues) _attrValues[kv.Key] = kv.Value;
    }

    public string State { lock (_lock) return _state; }

    public SecsItem? GetAttribute(string attrId)
    {
        lock (_lock) return _attrValues.GetValueOrDefault(attrId);
    }

    public void SetAttribute(string attrId, SecsItem value)
    {
        var def = Type.GetAttribute(attrId) ?? throw new OssException($"Unknown attribute: {attrId}");
        if (def.Access == AccessMode.ReadOnly)
            throw new OssException($"Attribute {attrId} is read-only");
        // 类型校验、枚举校验略
        lock (_lock) _attrValues[attrId] = value;
    }

    /// <summary>状态转换（内部逻辑调用），转换成功后触发绑定事件。</summary>
    public void TransitionTo(string newState, Func<string, string, bool> canTransition)
    {
        uint? ceidToRaise = null;
        lock (_lock)
        {
            if (!canTransition(_state, newState))
                throw new OssException($"Illegal transition {_state}->{newState} on {ObjSpec}");
            _state = newState;
            // 查找该目标状态绑定的事件
            foreach (var ev in Type.Events)
                if (ev.TriggerState == newState) ceidToRaise = ev.Ceid;
        }
        if (ceidToRaise.HasValue) RaiseEvent(ceidToRaise.Value);
    }

    /// <summary>调用对象方法。</summary>
    public Dictionary<string, SecsItem> InvokeMethod(string methodId,
        Dictionary<string, SecsItem> inputs,
        Func<ObjectInstance, string, Dictionary<string, SecsItem>, Dictionary<string, SecsItem>> executor)
    {
        var def = Type.GetMethod(methodId) ?? throw new OssException($"Unknown method: {methodId}");
        lock (_lock)
        {
            if (!def.RequiredStates.Contains(_state))
                throw new OssException($"Method {methodId} not allowed in state {_state} (need {string.Join("/", def.RequiredStates)})");
        }
        // 必填参数校验略
        return executor(this, methodId, inputs);
    }

    /// <summary>触发事件：快照关联属性值，抛给上层。</summary>
    public void RaiseEvent(uint ceid)
    {
        var def = Type.GetEvent(ceid) ?? throw new OssException($"Unknown event: {ceid}");
        Dictionary<string, SecsItem> snapshot;
        lock (_lock)
        {
            snapshot = def.LinkedAttributes
                .Where(a => _attrValues.ContainsKey(a))
                .ToDictionary(a => a, a => _attrValues[a]);
        }
        EventRaised?.Invoke(ObjSpec, ceid, snapshot);
    }
}

public sealed class OssException : Exception
{
    public OssException(string msg) : base(msg) { }
}
```

### ObjectRegistry
```csharp
namespace EapLab.Oss.ObjectModel;

/// <summary>对象注册表：类型注册 + 实例 CRUD（线程安全）。</summary>
public sealed class ObjectRegistry
{
    private readonly Dictionary<string, ObjectType> _types = new();
    private readonly Dictionary<string, ObjectInstance> _instances = new();
    private readonly object _typeLock = new();
    private readonly object _instanceLock = new();

    // ---- 类型注册 ----
    public void RegisterType(ObjectType type)
    {
        lock (_typeLock)
        {
            if (!_types.TryAdd(type.TypeName, type))
                throw new OssException($"Type already registered: {type.TypeName}");
        }
    }

    public ObjectType GetType(string typeName)
    {
        lock (_typeLock)
            return _types.GetValueOrDefault(typeName) ?? throw new OssException($"Unknown type: {typeName}");
    }

    public IReadOnlyList<string> ListTypes() { lock (_typeLock) return _types.Keys.ToList(); }

    // ---- 实例 CRUD ----
    public ObjectInstance CreateInstance(string typeName, string id,
        Dictionary<string, SecsItem> initialValues, string initialState = "CREATED")
    {
        ObjectType type;
        lock (_typeLock)
            type = _types.GetValueOrDefault(typeName) ?? throw new OssException($"Unknown type: {typeName}");

        // 必填属性 + 未知属性 + 类型校验
        foreach (var attrDef in type.Attributes)
        {
            if (attrDef.Required && !initialValues.ContainsKey(attrDef.AttrId) && attrDef.DefaultValue == null)
                throw new OssException($"Missing required attribute: {attrDef.AttrId}");
        }
        foreach (var key in initialValues.Keys)
            if (type.GetAttribute(key) == null)
                throw new OssException($"Unknown attribute {key} for type {typeName}");

        // 原子地"检查重复 + 创建 + 入字典"
        lock (_instanceLock)
        {
            string spec = $"{typeName}:{id}";
            if (_instances.ContainsKey(spec))
                throw new OssException($"Object already exists: {spec}");
            var instance = new ObjectInstance(type, id, initialState, initialValues);
            _instances[spec] = instance;
            return instance;
        }
    }

    public void DeleteInstance(string objSpec)
    {
        lock (_instanceLock)
        {
            if (!_instances.Remove(objSpec))
                throw new OssException($"Object not found: {objSpec}");
        }
    }

    public ObjectInstance GetInstance(string objSpec)
    {
        lock (_instanceLock)
            return _instances.GetValueOrDefault(objSpec) ?? throw new OssException($"Object not found: {objSpec}");
    }

    public bool Exists(string objSpec) { lock (_instanceLock) return _instances.ContainsKey(objSpec); }

    public IReadOnlyList<ObjectInstance> ListInstances(string? typeName = null)
    {
        lock (_instanceLock)
        {
            var q = _instances.Values.AsEnumerable();
            if (typeName != null) q = q.Where(i => i.TypeName == typeName);
            return q.ToList();
        }
    }
}
```

```csharp
public class OssObjectModelTests
{
    private static ObjectType BuildProcessJobType() => new ObjectType("ProcessJob")
        .AddAttribute(new("ProcessState", "状态", SecsDataType.U1))
        .AddAttribute(new("LotID", "批次", SecsDataType.A, AccessMode.ReadWrite, required: true))
        .AddAttribute(new("WaferCount", "片数", SecsDataType.U2, defaultValue: SecsItem.U2(0)))
        .AddMethod(new("Start", "开始",
            new[] { new ParameterDefinition("Mode", SecsDataType.U1, required: false) },
            Array.Empty<ParameterDefinition>(),
            new HashSet<string> { "QUEUED", "PAUSED" }))
        .AddEvent(new(4101, "Started", new[] { "ProcessState", "LotID" }, triggerState: "EXECUTING"));

    [Fact]
    public void 注册类型_创建实例_读写属性_调方法_删除_完整流程()
    {
        var reg = new ObjectRegistry();
        reg.RegisterType(BuildProcessJobType());

        var pj = reg.CreateInstance("ProcessJob", "PJ001",
            new() { ["LotID"] = SecsItem.A("LOT001") }, initialState: "QUEUED");

        Assert.Equal("ProcessJob:PJ001", pj.ObjSpec);
        Assert.Equal("LOT001", ((SecsAscii)pj.GetAttribute("LotID")!).Value);
        Assert.Equal(0u, ((SecsU2)pj.GetAttribute("WaferCount")!).Values[0]); // 默认值

        pj.SetAttribute("LotID", SecsItem.A("LOT002")); // 可写属性
        Assert.Equal("LOT002", ((SecsAscii)pj.GetAttribute("LotID")!).Value);

        Assert.True(reg.Exists("ProcessJob:PJ001"));
        reg.DeleteInstance("ProcessJob:PJ001");
        Assert.False(reg.Exists("ProcessJob:PJ001"));
    }

    [Fact]
    public void 只读属性写入_抛异常()
    {
        var reg = new ObjectRegistry();
        reg.RegisterType(BuildProcessJobType());
        var pj = reg.CreateInstance("ProcessJob", "PJ001", new() { ["LotID"] = SecsItem.A("L1") });
        Assert.Throws<OssException>(() => pj.SetAttribute("ProcessState", SecsItem.U1(3)));
    }

    [Fact]
    public void 缺少必填属性_创建失败()
    {
        var reg = new ObjectRegistry();
        reg.RegisterType(BuildProcessJobType());
        Assert.Throws<OssException>(() => reg.CreateInstance("ProcessJob", "PJ001", new()));
    }

    [Fact]
    public void 重复创建相同OBJSPEC_失败()
    {
        var reg = new ObjectRegistry();
        reg.RegisterType(BuildProcessJobType());
        reg.CreateInstance("ProcessJob", "PJ001", new() { ["LotID"] = SecsItem.A("L1") });
        Assert.Throws<OssException>(() =>
            reg.CreateInstance("ProcessJob", "PJ001", new() { ["LotID"] = SecsItem.A("L2") }));
    }

    [Fact]
    public void 错误状态调用方法_被拒绝()
    {
        var reg = new ObjectRegistry();
        reg.RegisterType(BuildProcessJobType());
        var pj = reg.CreateInstance("ProcessJob", "PJ001",
            new() { ["LotID"] = SecsItem.A("L1") }, initialState: "EXECUTING"); // 已在执行
        Assert.Throws<OssException>(() =>
            pj.InvokeMethod("Start", new(), (_, _, _) => new()));
    }
```

## 三、今日易错点
1. 类型定义和实例数据混在一个类里（应分元数据层 ObjectType 和实例层 ObjectInstance）。
2. OBJSPEC 只存 ID 不存 Type（标准格式是 "Type:ID"，S15/S16 都靠它定位）。
3. 允许 Host 写只读状态属性（状态由设备内部状态机决定，Host 不能直接改）。
4. 方法调用不做前置状态校验（应检查 RequiredState，非法状态拒绝并回错误码）。
5. CreateInstance 的"查重+入字典"不加锁（并发下重复创建，必须原子化）。
6. 创建实例时不校验必填属性和未知属性（应在创建时就拒绝，避免产生残缺对象）。
7. 事件触发不快照属性值（应在状态转换瞬间快照 LinkedAttributes，异步发送时值可能已变）。
8. 对象删除后仍被其他线程持有引用并操作（删除后操作应报"对象不存在"，必要时引用计数）。
9. 默认值不填充（未提供且非必填的属性应填 DefaultValue，否则 S15F5 查询返回空）。
