# W23 · Day03（周三）多载具上下料重叠与多盒全局台账

> 建议时长：90 分钟。真实设备多个 LoadPort 并行周转：前一批在加工，后一批已上料、甚至第三批在等下料。今天实现多载具重叠上下料的状态协同，以及按全局唯一片 ID、带批次归属的多盒台账，保证高周转下不混批、不混账。

## 一、今日目标
1. 实现多 LoadPort 并行的上料/加工/下料重叠流水线（端口状态独立、调度统一）。
2. 建立 MultiCarrierLedger：多盒并存时每片带 CjId/Lot 归属，全局与分批次守恒。
3. 掌握端口周转时序：输入口、输出口、InOut 口在重叠期的占用与释放。
4. 处理重叠期冲突：同一口不能同时上下、输出盒未取走阻塞、跨批片不可混。
5. xUnit 覆盖前批未下后批已上、跨批守恒、口占用冲突、InOut 复用。

## 二、背景知识（先读，30 分钟）

### 1. 为什么要重叠上下料
- 若一批完全下料后才上后一批，LoadPort/E84 交接时间成为设备空闲，拉低利用率。先进 FAB 让多口并行：AMHS 提前把下一盒送到空闲口、完成预约/Loaded，前批一结束即可无缝加工。
- 前提是端口状态独立推进、加工调度全局统一（Day01）。

### 2. 端口与载具角色（回顾 W20）
- Input 口：只进原料；Output 口：只出成品；InOut 口：先卸成品再上原料（复用，时序不能撞）。
- 每口独立走 E84→E87→E90 上料链（W22 Day04），互不阻塞，但共用机械手/EFEM（进全局资源日历）。

### 3. 多盒全局台账（核心）
- 单盒台账（W14）只看一个 CarrierID；多盒并存时必须以**全局唯一片 ID** 为主键：
  - 每片记录 SubstrateId、所属 Lot/CjId、来源载具/槽、当前位置、目标载具/槽、工艺状态。
- 两级守恒：
  - 全局守恒：所有在口载具 + 设备内 = 全部已上料片集合（跨盒总量不变）。
  - 分批守恒：每个 CJ/Lot 的片集合各自守恒、不同 CJ 片集合交集为空（不混批）。
- 片在盒间转移（跨载具交叉取片 W15）时，同时更新全局与两盒的分账。

### 4. 重叠期端口/批次状态协同
- 前批 CJ 仍 Executing，后批可 Installed→Loaded→建基线，但其 CJ 因资源/前批顺序进入就绪等待（Day01/02 调度）。
- 输出盒角色：成品陆续进入输出盒，盒满或批次完成触发 Unload；输出盒未被 AMHS 取走前，不能把需要该口的新成品/新盒安排冲突。
- InOut 口：必须先完成前批 Unload（取走）才能 Deposit 后批，口状态机串行化。

### 5. 防混批硬规则
- 片的目标输出由其 CJ 定义决定；调度/搬运任何时候按片 ID 查归属，禁止"按槽就近"把 A 批片放进 B 批输出盒。
- 分档/合批（Day04）也必须显式带授权与目标批，不允许隐式混批。

### 6. 与 AMHS 的协同信号
- 口空闲/需要上料/请求取盒通过 E84/E87 状态与事件告知 FAB 物流；设备端只如实暴露口状态，AMHS 派车由上层决定（设备不直接调度小车）。
