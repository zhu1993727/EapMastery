# W32 · Day04 答案与参考实现

## 一、自测题标准答案
1. **两类变异/对待**：普通原因变异是过程稳定运行时固有的随机波动，由大量小因素累积、分布稳定、单个不可归因，过程处于统计受控、可预测，要降低它只能改进系统（换设备/优化工艺）；特殊原因变异是非固有的、可归因的异常（故障、装夹错、来料批次、操作失误），会让均值偏移、方差增大或出现趋势，在控制图上表现为越界或非随机模式，应及时识别、定位根因并消除。SPC 的核心就是把两者区分开：对普通原因波动不要乱动，对特殊原因信号要干预。
2. **tampering 危害**：tampering（过度干预/乱调）是把普通原因的随机波动误判为特殊原因，每看到一个随机高低点就去调设备/设定。由于随机波动本就会自行回到均值，这种"追着噪声调"等于把额外的调节方差叠加进过程，著名的漏斗实验表明它反而会让输出波动**变大**、过程更不稳定。正确做法是：只有控制图出现统计上显著的信号（越界/判异规则）才判定特殊原因并干预，受控状态下的起伏不调（这与 R2R 死区、不被噪声带着走的思想一致）。
3. **为何 ±3σ/由谁决定**：受控时统计量近似正态，落在均值±3σ 内概率约 99.73%，界外只有约 0.27%，是极小概率；若一点落界外，就有统计理由认为过程可能不再受控（出现特殊原因），同时把虚警率压得很低，兼顾灵敏度与误报。控制限由**过程自身的历史数据**估计（均值与由组内变异估的 σ），不是目标值也不是客户规格，过程改进或重新基线化后按受控数据重估。
4. **图型选型**：Xbar-R（均值-极差）用于计量型数据、能合理分成小子组（n=2–5，如同腔短时连续几片），Xbar 盯中心、R 盯组内离散，最常用；子组大时用 Xbar-S；I-MR（单值-移动极差）用于每次只有一个观测、无法分组（每批一个值、破坏性测量、测量很慢）时，用相邻差估变异；p/np 图用于不合格品率/数（合格-不合格二分类），c/u 图用于缺陷数/单位缺陷数（计数型）。小偏移慢漂移可用 EWMA/CUSUM 图（更灵敏，与 R2R EWMA 同源）。
5. **控制限公式**：先求每组均值与极差 R，得 Rbar=平均极差、Xbarbar=各组均值的平均，σ̂=Rbar/d2（d2 为随子组 n 的常数）。均值图：UCL_X=Xbarbar+A2·Rbar、LCL_X=Xbarbar−A2·Rbar；极差图：UCL_R=D4·Rbar、LCL_R=D3·Rbar（n≤6 时 D3=0，故 LCL_R=0）。A2/D3/D4 是标准控制图常数（n=5 时 A2=0.577、D3=0、D4=2.114）。
6. **受控≠合格**：统计受控只说明过程输出分布稳定、只有普通原因波动、结果可预测；产品合格要求输出落在规格限 USL/LSL 内。一个过程可以非常稳定（点全在控制限内）但均值偏离目标或固有方差太大，导致稳定地产出超规格品——这是"过程能力不足"（Cpk 低，Day05），需要系统改进把均值对中、减小变异，而不是靠 SPC 报警（它不会报，因为没有特殊原因）。所以受控是"稳不稳"，合格是"对不对、够不够精"，两件事。
7. **SPC 处置 vs R2R 补偿**：SPC 发现特殊原因信号时，走"识别→隔离受影响产品→查根因→纠正/消除特殊原因→确认恢复受控"的工程处置，是离散的、针对异常事件的干预，SPC 本身不自动改设定；R2R 是在过程**受控**前提下，对可预期的慢漂移做连续、自动、小幅的设定补偿，把均值维持在目标。一个处理"突发/非随机异常（special cause）"，一个处理"正常工况下的缓慢趋势（common drift）"；若过程已失控（存在特殊原因），应暂停 R2R 自动调节，先排除特殊原因，否则会把异常当漂移错误补偿（呼应 W31 Hold/异常期暂停下发）。

## 二、参考实现（net8.0）：Xbar-R 控制图

```csharp
namespace EapLab.Spc;
// 控制图常数(常用子组大小)
public static class ChartConst
{ static readonly Dictionary<int,(double A2,double D3,double D4,double d2)> T=new()
  { {2,(1.880,0,3.267,1.128)},{3,(1.023,0,2.574,1.693)},{4,(0.729,0,2.282,2.059)},
    {5,(0.577,0,2.114,2.326)},{6,(0.483,0,2.004,2.534)},{7,(0.419,0.076,1.924,2.704)} };
    public static bool TryGet(int n,out(double A2,double D3,double D4,double d2)v)=>T.TryGetValue(n,out v); }
public sealed record Limits(double Cl,double Ucl,double Lcl);
public sealed class XbarRChart
{
    public Limits Xbar{get;}public Limits Range{get;}public int N{get;}
    public XbarRChart(double[][] groups)
    { N=groups[0].Length;if(!ChartConst.TryGet(N,out var c))throw new ArgumentException("n 2..7");
        var means=groups.Select(g=>g.Average()).ToArray();
        var ranges=groups.Select(g=>g.Max()-g.Min()).ToArray();
        double xbb=means.Average(),rb=ranges.Average();
        Xbar=new Limits(xbb,xbb+c.A2*rb,xbb-c.A2*rb);
        Range=new Limits(rb,c.D4*rb,c.D3*rb); }
    // Day04先判越界(Day05补模式规则)
    public bool XbarOutOfLimits(double xbar)=>xbar>Xbar.Ucl||xbar<Xbar.Lcl;
    public bool RangeOutOfLimits(double r)=>r>Range.Ucl||r<Range.Lcl;
    public double SigmaHat( ){ChartConst.TryGet(N,out var c);double rb=Range.Cl;return rb/c.d2;}
}
```

## 三、Xbar-R 控制图（手绘参考）
```
均值图 Xbar                              极差图 R
UCL=X̄̄+A2·Rbar ─────                   UCL=D4·Rbar ─────
CL =X̄̄(过程均值) ───── 打点随时间       CL =Rbar    ─────
LCL=X̄̄-A2·Rbar ─────                   LCL=D3·Rbar(=0,n≤6) ─────
点越界/非随机模式 → 特殊原因(查因/隔离/纠正/确认) ; 界内随机起伏=普通原因, 不调(tampering会增大波动)
σ̂=Rbar/d2 ; 系数随n: n5→A2 .577 D3 0 D4 2.114
控制限=过程声音(数据算, 稳不稳) ≠ 规格限USL/LSL=客户声音(合不合格); 受控但Cpk低=稳定地产不良, 要系统改进
选型: 子组Xbar-R / 单值I-MR / 计数p,np,c,u / 小偏移EWMA,CUSUM
定位: SPC监控判稳不直接控; R2R在受控下自动补慢漂移; 失控先排特殊原因再恢复R2R
```

## 四、今日易错点
1. 把普通原因随机波动当异常乱调（tampering，越调越差）。
2. 把控制限当规格限、把受控当合格。
3. 控制限按目标值/客户要求画（应由过程数据估计）。
4. 不会按数据形态选图（单值硬套 Xbar-R）。
5. 记错 A2/D3/D4 或直接用样本标准差代替 Rbar/d2。
6. 过程已失控还让 R2R 继续自动补偿（应先排特殊原因）。
7. 子组划分不合理（把差异大的时间/腔混进同一子组，掩盖变异）。
8. 认为 SPC 会自动改设定（它只监控判稳，控制归 R2R/GEM）。
