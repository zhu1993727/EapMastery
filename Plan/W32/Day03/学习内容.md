## 二、背景知识（先读，40 分钟）

### 1. 端到端管线（本周主线落地）
1. EDA 采高频 trace + GEM Step marker（W27-29）。
2. 片结束按 Step 提特征（Day01）。
3. VM 推理出 ŷ、PI、OOD/置信度（Day02）。
4. **质量门控**：数据 Good、非 OOD、置信度达标、作用域匹配才放行。
5. 进入量测融合（W31 Day04）：有实测用实测，否则用合格 VM（保守权重）。
6. EWMA/dEWMA 更新→控制律→限幅→overlay（W31 Day02/03）。
7. RMS/GEM 下发并确认生效（W31 Day05）。

### 2. 逐片全检的价值与风险
- 价值：抽检下未测片失控无人知；VM 全检使每片都有质量估计，异常片当片预警、R2R 反馈从"每几批一次"变"每片一次"，控制更及时、方差更小；并为良率提供逐片过程画像。
- 风险：VM 有误差，若把预测当精确真值直接判废/强控会误伤；必须带 PI 与置信度、以实测抽检校准、关键决策（判废/放行）保留实测或人工。

### 3. 规格限 USL/LSL 与预测区间结合
- 规格限（来自规格/客户，USL 上规格限、LSL 下规格限）是合格范围，区别于 SPC 控制限（过程自身统计界，Day04）。
- 用整个预测区间判：PI 完全在规格内→安全；PI 跨规格线→不确定有风险→复测/降级；点预测超规格且高置信→高风险预警。区间越宽越保守，避免误判。

### 4. VM 质量门控（进入闭环的硬条件，汇总）
- 输入数据质量：关键 Step 特征齐全、trace 无 Bad/Gap（或已按规则处理）。
- 模型可信：非 OOD、置信度≥阈值、PI 宽度在限内。
- 作用域：recipe/腔/模型版本匹配。
- 时效：预测在片结束后、下一 run 决策前及时产出（迟到则不用于本次控制）。
- 不满足：不进 R2R，保持上一设定等实测（W31 Day04），并计数据/模型质量事件。

### 5. 实测回灌的双轨闭环
- 抽检实测回来：以实测为准更新 R2R、校正 VM 偏差（Day02）、核对当时 VM 预测准确性（监控模型）；若实测与当时 VM 严重不符，回溯该时段用 VM 做的控制决策、评估风险片。

### 6. 设备端 EAP 视角
- 保证 trace 与 marker 完整对齐、片-腔绑定正确、VM/决策所需上下文齐全；VM 多在上位/EDC 侧运行，设备端负责"供数准、下发稳、生效可确认"。
