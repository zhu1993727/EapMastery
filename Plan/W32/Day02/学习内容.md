## 二、背景知识（先读，45 分钟）

### 1. 常用模型与选择
- **多元线性回归/PLS**：过程变量高度相关（共线性），PLS 通过潜变量同时利用 X 与 y 的协方差，稳健、可解释、小样本表现好，是半导体 VM 经典方法。
- 岭回归/Lasso 处理共线与特征选择；非线性工艺用随机梯度提升、随机森林、神经网络，但需更多数据、可解释性弱、更易漂移。
- 现场偏好：先简单可解释模型，特征/模型版本化；模型要能说明"哪些过程特征主导了本次预测"。

### 2. 评估指标
- RMSE（均方根误差，放大较大误差）、MAE（平均绝对误差，直观）、R²（解释方差比例）、MAPE。
- **预测区间覆盖率**：真实值落入 PI 的比例是否接近标称（如 95%），校准不好的区间无意义。
- bias（平均预测-实测偏差）：系统性偏高/偏低，用于在线校正。
- 必须在独立测试集/按时间留出的 Lot 上评估，防泄漏。

### 3. 置信度量化（重点）
- **来源 A 模型残差不确定性**：用验证集残差标准差 σ，给点预测加区间 ŷ±z·σ（z=1.96 对应 95%）；残差越大、区间越宽、置信越低。
- **来源 B 分布外程度 OOD**：若本次特征与训练数据差异大（新工况/异常/传感器漂移），即使模型"自信"也不可信。用马氏距离（Mahalanobis，考虑特征相关与尺度）或到训练集中心的标准化距离衡量；距离越大置信度越低，超阈值判 OOD、不用于闭环。
- 综合置信度 = f(残差区间宽度, OOD 距离, 输入数据质量)；W31 Day04 的融合据此决定是否采用 VM。

### 4. 实测双轨在线校正
- VM 会有缓慢系统偏差（设备状态变化），实测陆续回来后，维护偏差项 `b_t=λ·(real−vm)+(1−λ)·b_{t-1}`（EWMA），校正输出 `ŷ'=ŷ+b_t`，和 R2R 同思想。
- 实测是真值：有实测的片以实测为准，并作为新样本监控/触发重训；校正只修短期偏差，长期漂移靠重训。
- 校正项异常变大也是模型漂移信号。

### 5. 模型版本与治理
- 特征清单、模型参数、训练数据范围（recipe/腔/时间）、σ 与分布参数、版本号一起固化；换 recipe/大保养/新腔用对应模型或重训，不跨工况滥用（作用域思想同 overlay）。

### 6. 与 R2R 的接口（衔接 W31）
- VM 输出 (ŷ', PI, confidence, source)；R2R 融合器只在 confidence≥阈值且非 OOD 时采用，否则等实测（W31 Day04 已实现门控，今天产出合格的 VM 供其使用）。
