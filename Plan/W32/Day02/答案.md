# W32 · Day02 答案与参考实现

## 一、自测题标准答案
1. **为何 PLS**：半导体过程变量（温度/压力/功率/各气路流量…）彼此高度相关（共线性），普通多元线性回归在共线下系数不稳定、方差大、对噪声敏感、甚至矩阵不可逆。PLS（偏最小二乘）把高维相关 X 投影到少数潜变量，且投影方向同时考虑 X 方差与 X-y 协方差，用少量正交成分稳健建模，小样本下表现好、可解释（能看各过程段贡献）、抗共线，因此成为半导体 VM 经典；岭回归/Lasso 是另一条正则化路线，非线性再考虑树/神经网络。
2. **指标含义**：RMSE 预测误差均方根，对大误差敏感、量纲与 y 相同；MAE 平均绝对误差，直观稳健、不放大离群；bias=平均(预测−实测)，衡量系统性偏高/偏低（可校正）；R² 衡量模型解释输出方差的比例；PI 覆盖率=真实值落入预测区间的实际比例，检验区间是否校准（标称 95% 就应覆盖约 95%），覆盖率不足说明置信区间不可信。它们要在按时间/Lot 留出的独立集上算，防同 Lot 泄漏高估。
3. **置信度两来源/残差小也不可信**：来源 A 是**模型内不确定性**——验证集残差大小决定预测区间宽度（σ 越大越不确定）；来源 B 是**分布外程度 OOD**——本次输入特征与训练分布的距离。残差小只说明模型在训练分布内拟合得好，若本次样本落在训练分布之外（新工况、异常波形、传感器漂移、新腔），模型是在外推，训练时的小残差不能保证外推正确，可能"自信地错"。所以必须同时看 OOD：内插可信、外推降置信甚至不用。
4. **马氏距离优点**：欧氏距离把各特征等权、忽略量纲与相关性；过程特征量纲差异大（℃、Pa、W）且高度相关，欧氏距离会被大量纲主导、并把相关特征重复计权。马氏距离 `D²=(x−μ)ᵀΣ⁻¹(x−μ)` 用协方差矩阵的逆做白化，自动归一各特征尺度并扣除特征间相关性，衡量的是"考虑相关结构后，该点离训练中心有多远"，多变量下判断 OOD 更合理（与 FDC PCA T² 同源思想）。教学可用对角协方差（按各特征标准差归一）近似。
5. **在线校正/与重训分工**：实测陆续回来后维护 EWMA 偏差项 `b_t=λ(real−vm)+(1−λ)b_{t-1}`，输出校正为 `ŷ'=ŷ+b_t`，快速消除缓慢系统偏差，实测片以实测为准。校正解决的是**短期、小幅、慢变的系统偏差**，不动模型本体；当偏差持续增大、残差结构改变、recipe/硬件变化时，靠**重训**更新模型系数/分布参数（用新实测样本），这是长期适应。校正项本身的异常增大正是触发重训/报警的信号；二者是"临时微调"与"重新建模"的关系。
6. **作用域版本/乱套后果**：VM 模型学到的是特定 recipe/腔/工艺窗口下"过程特征→输出"的关系，不同 recipe、不同腔特性、大保养后关系会变。因此特征清单、系数、残差 σ、训练分布参数、适用 recipe/腔与版本要一起固化（作用域思想同 overlay）。跨 recipe/跨腔直接套用等于在不同物理关系上外推，预测系统性失准且 OOD 未必能完全识别，导致错误反馈进 R2R、错误判废。正确做法是按作用域选对应模型，不匹配则不用 VM、等实测或重训。
7. **R2R 采用条件**：VM 输出需同时满足：①置信度≥融合阈值（残差区间不过宽）；②非 OOD（到训练分布距离在限内）；③输入过程数据质量 Good（无 Bad/Gap、关键 Step 特征完整，W28/W30 质量码）；④模型作用域匹配（recipe/腔/版本对得上）。任一不满足则不用于闭环、保持上一设定等实测（W31 Day04）；采用时也按低于实测的保守权重参与，并在实测回来后以实测校正。

## 二、参考实现（net8.0）：教学版多元线性 VM + PI + OOD + 偏差校正

```csharp
namespace EapLab.Vm;
// 教学: 多元线性回归 y=b0+Σbi*xi (最小二乘, 正规方程), 残差PI, 对角马氏OOD, EWMA偏差校正
public sealed class LinearVm
{
    double[] _beta=Array.Empty<double>();double[] _mu=Array.Empty<double>();double[] _sd=Array.Empty<double>();
    double _sigma;public string Version{get;}
    public LinearVm(string ver){Version=ver;}

    public void Fit(double[][] X,double[] y)
    { int n=X.Length,d=X[0].Length;_mu=new double[d];_sd=new double[d];
        for(int j=0;j<d;j++){_mu[j]=X.Average(r=>r[j]);_sd[j]=Math.Sqrt(X.Sum(r=>Math.Pow(r[j]-_mu[j],2))/n)+1e-9;}
        var Z=X.Select(r=>Standard(r)).ToArray();           // 标准化
        // 增广一列1求截距; 教学用正规方程 (A'A)^-1 A'y
        var A=Z.Select(z=>new[]{1.0}.Concat(z).ToArray()).ToArray();
        _beta=NormalEquation(A,y);
        var res=y.Zip(A,(yi,row)=>yi-Dot(_beta,row)).Select(e=>e*e);
        _sigma=Math.Sqrt(res.Sum()/(n-d-1)); }              // 残差标准差

    public record Pred(double Yhat,double Lo,double Hi,double Ood,double Confidence,bool OutOfDist);
    public Pred Predict(double[] x,double z95=1.96)
    { var z=Standard(x);double yhat=Dot(_beta,new[]{1.0}.Concat(z).ToArray());
        double ood=Math.Sqrt(z.Select((v,j)=>v*v).Sum());  // 对角马氏(标准化空间欧氏)
        double conf=Math.Exp(-ood/(2*Math.Sqrt(x.Length))); // 教学: 距离越远置信越低
        bool oodFlag=ood>2.5*Math.Sqrt(x.Length);
        return new Pred(yhat,yhat-z95*_sigma,yhat+z95*_sigma,ood,conf,oodFlag); }

    double _bias;public double Correct(double vm,double? real,double lam=0.3)
    { if(real is double r){_bias=lam*(r-vm)+(1-lam)*_bias;} // 实测回来EWMA校正
        return vm+_bias; }
    double[] Standard(double[] r)=>r.Select((v,j)=>(v-_mu[j])/_sd[j]).ToArray();
    static double Dot(double[]a,double[]b){double s=0;for(int i=0;i<a.Length;i++)s+=a[i]*b[i];return s;}
    static double[] NormalEquation(double[][]A,double[]y) // (A'A)^-1 A'y, 高斯消元求逆(教学规模)
    { int m=A[0].Length;var ata=new double[m,m];var aty=new double[m];
        for(int i=0;i<A.Length;i++)for(int r=0;r<m;r++){aty[r]+=A[i][r]*y[i];
            for(int c=0;c<m;c++)ata[r,c]+=A[i][r]*A[i][c];}
        return Solve(ata,aty); }
    static double[] Solve(double[][]M,double[]b) // 封装成矩阵高斯消元
    { int n=b.Length;var aug=new double[n][];
        for(int i=0;i<n;i++){aug[i]=new double[n+1];for(int j=0;j<n;j++)aug[i][j]=M[i,j];aug[i][n]=b[i];}
        for(int col=0;col<n;col++){int piv=col;for(int r=col+1;r<n;r++)if(Math.Abs(aug[r][col])>Math.Abs(aug[piv][col]))piv=r;
            (aug[col],aug[piv])=(aug[piv],aug[col]);double d=aug[col][col];for(int j=col;j<=n;j++)aug[col][j]/=d;
            for(int r=0;r<n;r++)if(r!=col){double f=aug[r][col];for(int j=col;j<=n;j++)aug[r][j]-=f*aug[col][j];}}
        return aug.Select(r=>r[n]).ToArray(); }
}
```

## 三、训练-预测-校正流（手绘参考）
```
离线: 历史特征X(按Step,WKN) ↔ 实测y(按片对齐) → 标准化(μ,σ) → PLS/线性(抗共线)
      → 独立集评估 RMSE/MAE/bias/R²/PI覆盖率 → 固化(系数,残差σ,分布μ/Σ,作用域recipe/腔,版本)
在线: 新片特征x → 标准化 → ŷ ; 残差σ→PI(ŷ±1.96σ) ; 马氏距离D²→OOD与置信
      → 合格(置信高/非OOD/数据Good/作用域匹配)才送R2R(保守权重), 否则等实测
双轨: 实测回来→以实测为准 + EWMA偏差b修正后续VM + 残差监控; 偏差变大/换recipe/保养→重训
要点: 内插可信外推降权; VM只预测不控制; 模型带作用域与版本, 不跨工况滥用
```

## 四、今日易错点
1. 共线过程变量直接用普通多元回归，系数不稳。
2. 只看点预测、不算 PI 与 OOD，外推时"自信地错"。
3. 用欧氏距离判 OOD，被量纲/相关性误导（应用马氏/白化）。
4. 同 Lot 数据同时进训练和测试，虚高准确率。
5. 把短期偏差校正当万能，模型真漂移却不重训。
6. 模型不带作用域/版本，跨 recipe/跨腔/保养后乱套。
7. 输入有 Bad/Gap 或关键 Step 缺失仍出预测并闭环。
8. 让 VM 直接控制设备（只预测，控制归 R2R/GEM）。
