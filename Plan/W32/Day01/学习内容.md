## 二、背景知识（先读，40 分钟）

### 1. 为什么需要 VM
- 物理量测（膜厚/CD/overlay/刻蚀深度）依赖量测机，慢、贵、多为抽检，结果滞后若干批；等量测发现偏差，已经产出一批问题片。
- VM 用加工过程中**已经采到**的过程数据（传感器 trace）建模，片一加工完立即"虚拟量"出结果，可逐片、零额外量测成本，把抽检补成全检（呼应 W31 Day04 融合）。

### 2. VM 输入：过程 trace + 上下文
- 过程 trace：EDA/Interface-A 高频采集的温度/压力/功率/气体流量/阻抗/端点信号等时间序列（W27-29 通道）。
- Step marker/上下文：作业/Step 事件（S6F11：JobStart/StepChanged/Complete，recipe 版本、腔、Lot、Wafer、产品），用来把连续 trace 正确切到每个工艺段；没有 marker，trace 无法与工艺步骤对齐，特征就是错的。
- 设备状态/耗材信息（RF 小时数、保养记录、腔体 id）也可作特征（解释腔间差/老化）。

### 3. 特征工程（VM 成败关键）
- 原始高频点太多且片间时长有波动，不能直接喂模型；要**按 Step 分段**，把每段 trace 压缩成稳健统计特征：
  - 集中趋势：均值、中位数；离散：标准差、极差、IQR；
  - 趋势：线性拟合斜率、首尾差；累积：积分/均值×时长（能量/剂量类）；
  - 极值：max/min 及出现位置；段时长、稳态建立时间、超调；
  - 相关性：两通道相关系数（如功率-压力关系，呼应 FDC 多变量）。
- 对齐：以 Step 起止 marker 对齐，用相对时间/归一化时间消除片间时长差异；异常段（FDC 报警/Bad 点）标记或剔除。
- 特征要带 WKN/单位（W28 WKN 治理），保证跨设备/跨腔一致可比。

### 4. VM 输出：点预测 + 置信度
- 输出预测值 ŷ，更重要的是**置信度/预测区间 PI**（如 ŷ±区间，置信水平 95%）：模型对本次预测有多大把握。
- 置信度来源：该样本与训练分布的距离（外推则低置信）、模型残差、输入数据质量；低置信预测不能直接用于 R2R 闭环（W31 Day04 已用）。

### 5. 建模与运维流程
1. 数据准备：历史"过程特征 X ↔ 实测标签 y"按片对齐（必须有实测做监督）。
2. 训练/验证：划分训练/验证/测试，交叉验证评估 RMSE/MAE、PI 覆盖率，防过拟合。
3. 部署：片结束实时算特征→模型推理→ŷ+置信度，供 R2R/FDC/良率分析。
4. 监控与重训：模型会因设备老化/recipe 变更漂移，用实测-预测残差监控（Day02），超阈值或换 recipe/大保养后重训；模型/特征版本化。

### 6. 与 R2R/FDC/良率关系
- VM 给 R2R 提供快速密集量测输入（W31）；给 FDC 提供"预测质量异常"线索（预测将超规格提前预警）；给 YMS 良率分析提供逐片过程-质量关联。VM 只预测不控制，控制仍走 R2R/GEM。
