# W32 · Day01 答案与参考实现

## 一、自测题标准答案
1. **解决什么/补全检**：物理量测依赖量测机，速度慢、成本高、通常抽检且滞后数批，等结果出来问题片已产生。VM 在加工过程数据（传感器 trace）本就被 EDA 采集的前提下，用监督学习建立"过程特征→输出质量"的模型，片一加工完无需上量测机就即时预测膜厚/CD/overlay 等结果，几乎零边际成本、可对每片都出值，因而把稀疏抽检"补成"逐片全检，让异常片当片即被发现、让 R2R 获得快速密集反馈。
2. **两类输入/无 marker 后果**：①过程 trace——EDA 高频采集的温度/压力/功率/流量/阻抗/端点等时间序列；②Step marker 与作业上下文——JobStart/StepChanged/Complete 事件及 recipe 版本、腔、Lot、Wafer、产品、设备/耗材状态。没有 Step marker，连续 trace 无法切到对应工艺段，不知道哪段是升温/稳态/降温，特征会跨步骤混算（把过渡段算进稳态均值），片间步骤时长不同更无法对齐，提取的特征张冠李戴，模型输入失真、预测不可信。marker 是"把一条波形翻译成结构化工艺特征"的分界依据。
3. **统计特征（≥8）**：均值（平均水平/设定跟随）、中位数（抗离群的中心）、标准差（波动/稳定性）、极差 max-min（波动幅度）、IQR 四分位距（抗离群离散度）、线性斜率（漂移趋势/上升下降速率）、首尾差（净变化）、积分/均值×时长（累积能量/剂量，如热预算、等离子剂量）、最大值/最小值及位置（峰值与发生时刻）、段时长（工艺步耗时）、稳态建立时间/超调量（达到稳态快慢与过冲）、两通道相关系数（变量协同关系是否被破坏，类似 FDC 多变量）。这些把变长波形压缩成定长、可跨片比较的特征向量。
4. **为何归一化对齐**：不同片同一 Step 的绝对时长会因工艺/调度略有差异，若按固定采样点序号或绝对时间取窗，同一工艺阶段在各片上对不齐（稳态段在 A 片是第 100 点、B 片是第 120 点），特征不可比、模型学到错位噪声。用 Step 起止 marker 做相对时间（段内位置 0–100%）或按稳态/过渡阶段重采样对齐，可消除时长差异、保证"同一位臵代表同一工艺阶段"，特征才稳定可比；必要时对段内等间隔重采样成固定点数。
5. **为何要置信度/PI**：单点预测无法表达"这次预测有多可信"。当输入落在训练分布之外（新工况/异常 trace/传感器异常）、或模型本身残差较大时，点预测可能很离谱却看不出来。置信度/预测区间（如 95% PI=ŷ±δ）量化不确定性：高置信才敢用于 R2R 闭环与放行，低置信则降权/不用、转等实测（W31 Day04）。带区间还能做风险判定（区间上界都在规格内才放心，跨规格线则需复测），避免把一个错误预测当成确定事实驱动控制或判废。
6. **建模到重训流程**：①数据准备——收集历史每片过程 trace，按 Step 提特征 X，并与该片**实测标签 y**按片严格对齐（监督学习必须有实测），带齐 recipe/腔/版本；②训练验证——清洗、划分训练/验证/测试（或按时间/Lot 划分防泄漏），训练模型，用 RMSE/MAE、PI 覆盖率、跨腔泛化评估，防过拟合；③部署上线——片结束实时提特征→推理出 ŷ+置信度，送 R2R/FDC/YMS；④监控重训——持续用"实测−预测"残差监控模型是否漂移（偏差变大、置信异常），在 recipe 变更、大保养/换件、新腔、残差超阈值时用新数据重训并版本化，灰度验证后替换；模型与特征清单都要版本可追溯。
7. **与 R2R/FDC 关系/能否控制**：VM 是"量测/信息提供者，只预测不控制"。对 R2R，它提供快速密集的虚拟量测作为反馈输入（实测优先、VM 补盲，见 W31）；对 FDC，预测质量将超规格可作为早期预警线索之一；对 YMS，提供逐片过程-质量关联用于良率分析。VM 本身不向设备下发任何设定/命令，控制决策由 R2R 做、下行经 RMS/EAP→GEM；这样预测错误不会直接变成设备动作，且可被置信度门槛与实测校正兜住。

## 二、参考实现（net8.0）：按 Step 分段的 Trace 特征提取

```csharp
namespace EapLab.Vm;
public readonly record struct Pt(double T,double V); // 相对时间, 值
public sealed class StepTrace(string step,IReadOnlyList<Pt> pts){ public string Step=step;public IReadOnlyList<Pt> Pts=pts; }
public sealed record Features(string Step,double Mean,double Std,double Slope,double Integral,double Min,double Max,double Duration,int N);

public static class TraceFeatureExtractor
{
    public static Features Extract(StepTrace s)
    { var p=s.Pts;if(p.Count==0)throw new ArgumentException("empty");
        int n=p.Count;double mean=p.Average(q=>q.V);
        double std=Math.Sqrt(p.Sum(q=>Math.Pow(q.V-mean,2))/n);
        // 最小二乘斜率
        double tMean=p.Average(q=>q.T);
        double num=p.Sum(q=>(q.T-tMean)*(q.V-mean)),den=p.Sum(q=>Math.Pow(q.T-tMean,2));
        double slope=den==0?0:num/den;
        double dt=p[^1].T-p[0].T;
        double integral=Trapezoid(p); // 积分(能量/剂量)
        return new Features(s.Step,mean,std,slope,integral,p.Min(q=>q.V),p.Max(q=>q.V),dt,n); }
    static double Trapezoid(IReadOnlyList<Pt> p){double a=0;for(int i=1;i<p.Count;i++)a+=(p[i].V+p[i-1].V)/2*(p[i].T-p[i-1].T);return a;}
    // 归一化重采样到固定点数, 消除片间时长差异
    public static StepTrace Resample(StepTrace s,int points)
    { var p=s.Pts;double t0=p[0].T,t1=p[^1].T;var outp=new List<Pt>();
        for(int i=0;i<points;i++){double x=t0+(t1-t0)*i/(points-1);outp.Add(new Pt(x,Interp(p,x)));}
        return new StepTrace(s.Step,outp); }
    static double Interp(IReadOnlyList<Pt> p,double t)
    { for(int i=1;i<p.Count;i++)if(t<=p[i].T){double f=(t-p[i-1].T)/(p[i].T-p[i-1].T);return p[i-1].V+f*(p[i].V-p[i-1].V);}return p[^1].V; }
}
```

public class FeatureTests
{
    [Fact] public void 线性上升_斜率正确_积分等于梯形面积()
    { var pts=new List<Pt>{new(0,0),new(1,10),new(2,20)};var f=TraceFeatureExtractor.Extract(new StepTrace("steady",pts));
      Assert.Equal(10,f.Slope,6);Assert.Equal(20,f.Integral,6);Assert.Equal(2,f.Duration); }
    [Fact] public void 恒定波形_标准差为0()
    { var pts=Enumerable.Range(0,5).Select(i=>new Pt(i,5.0)).ToList();
      Assert.Equal(0,TraceFeatureExtractor.Extract(new StepTrace("s",pts)).Std,6); }

    { Assert.Throws<ArgumentException>(()=>TraceFeatureExtractor.Extract(new StepTrace("s",new List<Pt>()))); }
}

## 三、VM 数据流（手绘参考）
```
EDA高频trace(温/压/功率/流量/阻抗) + GEM S6F11 Step marker(Job/Step起止, recipe/腔/Lot/片)
  → 按Step分段(marker对齐, 相对/归一化时间消除时长差, Bad/FDC段标记)
  → 每段提特征: 均值/中位/标准差/极差/斜率/首尾差/积分/极值与位置/时长/稳态时间/相关系数
     (WKN/单位统一, 跨腔可比) → 定长特征向量X
  → VM模型(历史 X↔实测y 训练/验证, RMSE/PI覆盖评估, 版本化)
  → 输出 ŷ + 置信度/预测区间PI ; 低置信→不闭环, 等实测
  → R2R快速反馈(实测优先VM补盲) / FDC质量预警 / YMS过程-良率关联
运维: 实测-预测残差监控漂移; 换recipe/大保养/新腔/残差超限→重训灰度替换
铁律: VM只预测不控制, 下行仍RMS/EAP→GEM; 无实测标签无法训练监督模型
```

## 四、今日易错点
1. 以为 VM 能无师自通（必须有历史实测标签做监督）。
2. 不用 Step marker，跨步骤混算特征。
3. 直接把全部高频原始点喂模型，不做分段与特征压缩。
4. 忽视片间时长差异，不做相对时间/重采样对齐。
5. 只出点预测、不给置信度/PI，错误预测被直接用于闭环。
6. 特征不带 WKN/单位，跨腔/跨设备不可比。
7. 随机划分数据导致同 Lot 泄漏、高估模型精度（应按时间/Lot 划分）。
8. 模型上线后不监控残差、不随 recipe/保养漂移重训。
9. 让 VM 直接下发控制（VM 只预测，控制归 R2R/GEM）。
