## 三、HsmsConnection 内部结构（组装目标）
```
HsmsConnection
 ├─ Tcp 层(Socket/Stream) + FrameReader/FrameWriter      (W1)
 ├─ HsmsHeader Encode/Decode + HsmsControl 工厂          (D2)
 ├─ HsmsControlStateMachine（唯一状态迁移 + 消息闸门）    (D3)
 ├─ PendingTransactions + SysGenerator（事务配对）        (D4)
 ├─ TimeoutScanner(T3/T5/T6/T7/T8) + 重连循环             (D5)
 └─ 事件：OnSelected / OnBroken / OnDataMessage(留给W3)
```
关键纪律：**任何收发先过状态机闸门；任何状态变化只走 ChangeState；任何等待都登记并受 T 参数约束。**

## 四、异常矩阵测试（6 例，必做）
1. Passive 未就绪时 Select → SelectStatus=2，Active 重连。
2. SELECTED 后第二个 Host 来 Select → Status=6 拒绝，原会话不受影响。
3. NOT SELECTED 发 Linktest → Reject Reason=1。
4. 不回 Select.rsp → T6 超时→T5 重连。
5. 选通后静默 → T8 Linktest → T6 判死→重连。
6. 对端直接关 TCP → 本端检测 Read=0 → 状态回 NOT CONNECTED → Active T5 重连。
