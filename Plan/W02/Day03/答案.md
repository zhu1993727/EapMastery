# W02 · Day03 答案与参考实现

## 一、自测题标准答案
1. **状态机（标准画法）**
```
        TCP Connect/Accept 成功            Select.req→rsp(Status=0)
 NOT ───────────────────────► NOT ───────────────────────────► SELECTED
CONNECTED ◄───────────────── SELECTED ◄──────────────────────  (可发SxFy/Linktest)
   ▲   TcpClosed/Separate/超时/Select失败      ▲ Deselect只回到NOT SELECTED
   └──────────────────────────────────────────┘
 Active: 主动Connect + 主动发Select.req；Passive: Accept + 收Select.req回rsp。
```
2. **迟迟不 Select 被谁关**：**T7**（连接建立后允许完成 Select 的时限，典型 10s 量级，以标准/配置为准），超时 Passive 主动关闭，Active 判选通失败。
3. **SELECTED 又收到 Select.req**：SS 单会话已选通，回 **Select.rsp，SelectStatus=6（会话已被选通）**拒绝，维持当前会话不被后来者顶替；同时上报告警（可能有第二个 Host 误连）。
4. **SELECTED→NOT CONNECTED 触发**：①收到/发出 Separate；②TCP 断开(FIN/RST)；③T8+Linktest 失败判定链路死；④Deselect 后再关 TCP。Active 随后：关 socket → 通知上层不可用 → **等 T5 再重连**（不立即狂连）。
5. **NOT SELECTED 收 S6F11 为何不缓存**：此状态下会话尚未选通，双方身份/会话未确认，数据消息不具备合法上下文；缓存会掩盖"没选通就发数据"的协议错误并可能错配会话。正确做法是 Reject（Reason=1，状态下不该出现）或直接丢弃并记日志。
6. **Deselect vs Separate**：Deselect 只解除选通、**保留 TCP**（SELECTED→NOT SELECTED，有 rsp，可再 Select）；Separate 解除选通**并关闭 TCP**（无 rsp）。实际现场几乎都是"要断就断干净、要连就重走 TCP+Select"，保留 TCP 的 Deselect 没有业务价值，故几乎只见 Separate。

## 二、参考实现（继承 W1 的 StateMachineBase）

### HsmsControlStateMachine.cs
```csharp
using EapLab.Transport.Connection;
using EapLab.Transport.Hsms;
using EapLab.Transport.Logging;

public enum HsmsCtrlState { NotConnected, NotSelected, Selected }
public enum Role { Active, Passive }

public sealed class HsmsControlStateMachine : StateMachineBase<HsmsCtrlState>
{
    public Role Role { get; }
    public HsmsControlStateMachine(Role role, ILogSink log)
        : base(HsmsCtrlState.NotConnected, log) => Role = role;

    protected override bool CanTransition(HsmsCtrlState f, HsmsCtrlState t) => (f, t) switch
    {
        (HsmsCtrlState.NotConnected, HsmsCtrlState.NotSelected) => true, // TCP 建立
        (HsmsCtrlState.NotSelected,  HsmsCtrlState.Selected)     => true, // Select 成功
        (HsmsCtrlState.Selected,      HsmsCtrlState.NotSelected) => true, // Deselect（保TCP）
        (HsmsCtrlState.NotSelected,  HsmsCtrlState.NotConnected)=> true, // Select失败/关TCP
        (HsmsCtrlState.Selected,      HsmsCtrlState.NotConnected)=> true, // Separate/断链
        _ => false
    };

    // —— 对外事件入口：全部走唯一迁移，非法自动拦截 ——
    public bool OnTcpOpened()    => ChangeState(HsmsCtrlState.NotSelected, "TCP opened");
    public bool OnTcpClosed()    => ChangeState(HsmsCtrlState.NotConnected, "TCP closed");
    public bool OnSelectOk()     => Current == HsmsCtrlState.NotSelected
                                    && ChangeState(HsmsCtrlState.Selected, "Select accepted");
    public bool OnDeselect()     => ChangeState(HsmsCtrlState.NotSelected, "Deselect");
    public bool OnSeparate()     => ChangeState(HsmsCtrlState.NotConnected, "Separate");

    /// <summary>状态×消息合法性闸门：所有收发先过这里。</summary>
    public bool IsMessageAllowed(HsmsSType t) => Current switch
    {
        HsmsCtrlState.NotConnected => false,
        HsmsCtrlState.NotSelected  => t is HsmsSType.SelectReq or HsmsSType.SelectRsp or HsmsSType.RejectReq,
        HsmsCtrlState.Selected     => true, // 数据消息/Linktest/Separate/Deselect 都允许
        _ => false
    };
}
```

### xUnit
```csharp
[Fact]
public void Active正常选通流程()
{
    var sm = new HsmsControlStateMachine(Role.Active, new ConsoleLogSink());
    Assert.True(sm.OnTcpOpened());
    Assert.True(sm.OnSelectOk());
    Assert.Equal(HsmsCtrlState.Selected, sm.Current);
    Assert.True(sm.IsMessageAllowed(HsmsSType.Data));
}
[Fact]
public void 未选通不允许数据消息()
{
    var sm = new HsmsControlStateMachine(Role.Passive, new ConsoleLogSink());
    sm.OnTcpOpened();
    Assert.False(sm.IsMessageAllowed(HsmsSType.Data)); // S6F11 会被闸门拦
}
[Fact]
public void 不能从NotConnected直接Selected()
{
    var sm = new HsmsControlStateMachine(Role.Active, new ConsoleLogSink());
    Assert.False(sm.OnSelectOk()); // 缺 TCP/NotSelected
}
```

## 三、今日易错点
1. 漏掉 NOT SELECTED，把状态机简化成"连/断"两态（无法解释"TCP 通却不能发数据"）。
2. 状态迁移到处直接赋值（必须唯一入口 + 合法边校验）。
3. 不做"状态×消息闸门"，未选通也收数据（协议错误被掩盖）。
4. 忘记 SELECTED 掉下来时 Active 要等 T5 再重连。
5. 第二个 Select 直接顶替当前会话（应回 Status=6 拒绝）。
