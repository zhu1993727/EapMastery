## 二、背景知识（先读，25 分钟）

### 1. 三个控制状态
- **NOT CONNECTED**：TCP 未建立。
- **CONNECTED / NOT SELECTED**：TCP 已建立，但 HSMS 未选通，只允许 Select 控制事务。
- **SELECTED**：选通成功，可双向收发数据消息(SxFy)与 Linktest。

### 2. 合法转换边（必背）
**Active（Host）路径：**
1. NOT CONNECTED →（TCP Connect 成功）→ NOT SELECTED
2. NOT SELECTED →（发出 Select.req 且收到 Select.rsp,Status=0）→ SELECTED
3. SELECTED →（收到/发出 Separate，或 TCP 断开/超时）→ NOT CONNECTED
4. NOT SELECTED →（Select 被拒/超时/TCP 断）→ NOT CONNECTED

**Passive（Equipment）路径：**
1. NOT CONNECTED →（Listen 后 Accept 成功）→ NOT SELECTED
2. NOT SELECTED →（收到 Select.req，回 Status=0 的 Select.rsp）→ SELECTED
3. SELECTED →（收到 Separate/链路断/本端 Separate）→ NOT CONNECTED

**Deselect（少用）**：SELECTED → NOT SELECTED（只解除选通、保留 TCP），再经 Select 重新选通。

### 3. 进入/退出状态的动作（专家要能讲"迁移副作用"）
- 进入 NOT SELECTED：启动 T7（必须在 T7 内完成 Select，否则关闭）；Active 立即发 Select.req 并启动 T6。
- 进入 SELECTED：停 T6/T7，启动 T8 保活计时；通知上层"链路可用"，触发 GEM 通信状态向 COMMUNICATING（W5 细讲）。
- 退出 SELECTED 到 NOT CONNECTED：停 T8；关闭 socket；通知上层"链路不可用"；Active 启动 T5 重连间隔；未决数据事务按 T3 失败处理/Spool（W5/W8）。

### 4. 状态与消息允许矩阵
| 状态 | 允许收发 |
|---|---|
| NOT CONNECTED | 无（TCP 都没通）|
| NOT SELECTED | 仅 Select.req/rsp、Reject；Linktest/数据消息非法 |
| SELECTED | 数据消息 SxFy、Linktest、Separate、Deselect |
