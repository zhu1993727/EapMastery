# W02 · Day02 答案与参考实现

## 一、自测题标准答案
1. **Length 口径**：不含自身 4 字节；**含**其后的 10 字节消息头 + 可选 data。即 Length = 10 + data.Length。
2. **S6F11 W=1 第 2 字节**：bit7=W=1，低 7 位=Stream 6（0000110），合成 `10000110 = 0x86`；第 3 字节 Function=11=`0x0B`。
3. **Linktest.req**：SessionID=`0xFFFF`（表示与会话无关的全局控制消息），SType=5。用 0xFFFF 是因为 Linktest 服务于整条链路、不绑定具体设备会话号；Select 则要带具体 SessionID。
4. **SelectStatus**：2=Passive 未就绪(Not Ready)，Active 应判选通失败、按流程 Separate/关闭后经 T5 重试；6=该 Session 已被选通（已有别的 Host 占用，SS 排他），Active 应放弃并上报告警，不要反复抢连。
5. **NOT SELECTED 收到 Linktest.req**：回 **Reject.req（SType=7）**，RejectReason=**1（当前状态下不该出现的控制消息）**，因为 Linktest 只允许在 SELECTED 状态收发。
6. **Separate 为何无 rsp**：它的语义是"立即、单向、无条件拆除"，发出后随即关 TCP，不存在可靠等待应答的连接；若要优雅、可确认地只解除选通而保留 TCP，用 Deselect（有 rsp）。

## 二、手算 hex（与代码对拍）
- **Select.req**（SessionID=0，System=1，无 data）：Length=10=`00 00 00 0A`；头=`00 00 00 00 00 01 00 00 00 01`。
  完整：`00 00 00 0A 00 00 00 00 00 01 00 00 00 01`
- **Linktest.req**（System=2）：Length=10；头=`FF FF 00 00 00 05 00 00 00 02`。
- **Select.rsp status=0**（System 复制 req=1）：Length=11=`00 00 00 0B`；头 SType=2 + data 1 字节 0：`00 00 00 00 00 02 00 00 00 01 00`。
- **S6F11 W=1 数据消息头**（DeviceID=0，System=10，暂无 data）：`00 00 86 0B 00 00 00 00 00 0A`（0x86=W+S6，0x0B=F11，SType=0）。

## 三、参考实现（net8.0，放 EapLab.Transport/Hsms/）

### HsmsHeader.cs
```csharp
using System.Buffers.Binary;

namespace EapLab.Transport.Hsms;

public enum HsmsSType : byte
{
    Data = 0, SelectReq = 1, SelectRsp = 2, DeselectReq = 3, DeselectRsp = 4,
    LinktestReq = 5, LinktestRsp = 6, RejectReq = 7, /*8 保留*/ SeparateReq = 9
}

public sealed class HsmsHeader
{
    public ushort SessionId { get; init; }
    public bool W { get; init; }
    public byte Stream { get; init; }
    public byte Function { get; init; }
    public byte PType { get; init; } = 0;       // SECS-II = 0
    public HsmsSType SType { get; init; }
    public uint SystemBytes { get; init; }

    public const int HeaderLen = 10;

    public byte[] Encode(int dataLen)
    {
        var b = new byte[HeaderLen];
        BinaryPrimitives.WriteUInt16BigEndian(b.AsSpan(0, 2), SessionId);
        b[2] = (byte)((W ? 0x80 : 0x00) | (Stream & 0x7F));
        b[3] = Function;
        b[4] = PType;
        b[5] = (byte)SType;
        BinaryPrimitives.WriteUInt32BigEndian(b.AsSpan(6, 4), SystemBytes);
        return b; // 外层 FrameWriter 写 Length=10+dataLen
    }

    public static HsmsHeader Decode(ReadOnlySpan<byte> h)
    {
        if (h.Length < HeaderLen) throw new ArgumentException("HSMS 头必须 10 字节");
        var stype = (HsmsSType)h[5];
        bool isData = stype == HsmsSType.Data;
        return new HsmsHeader
        {
            SessionId = BinaryPrimitives.ReadUInt16BigEndian(h.Slice(0, 2)),
            W = isData && (h[2] & 0x80) != 0,
            Stream = (byte)(h[2] & 0x7F),
            Function = h[3],
            PType = h[4],
            SType = stype,
            SystemBytes = BinaryPrimitives.ReadUInt32BigEndian(h.Slice(6, 4))
        };
    }

    public string SxFy => $"{Stream}F{Function}";
}
```

### 控制消息工厂
```csharp
public static class HsmsControl
{
    public static byte[] Build(HsmsSType t, uint sys, ushort session = 0xFFFF, byte? status = null)
    {
        var head = new HsmsHeader { SessionId = session, SType = t, SystemBytes = sys }.Encode(status is null ? 0 : 1);
        var len = 10 + (status is null ? 0 : 1);
        using var ms = new MemoryStream();
        Span<byte> lb = stackalloc byte[4];
        BinaryPrimitives.WriteUInt32BigEndian(lb, (uint)len);
        ms.Write(lb); ms.Write(head);
        if (status is { } s) ms.WriteByte(s);
        return ms.ToArray();
    }
}
```

### xUnit 对拍
```csharp
[Fact]
public void S6F11_W1_第二字节是0x86()
{
    var h = new HsmsHeader{ SessionId=0, W=true, Stream=6, Function=11, SType=HsmsSType.Data, SystemBytes=10 };
    var b = h.Encode(0);
    Assert.Equal(0x86, b[2]); Assert.Equal(0x0B, b[3]); Assert.Equal(0, b[5]);
}
[Fact]
public void Linktest_Session是FFFF_SType5()
{
    var frame = HsmsControl.Build(HsmsSType.LinktestReq, 2);
    Assert.Equal(0xFF, frame[4]); Assert.Equal(0xFF, frame[5]); Assert.Equal(5, frame[9]);
}
```

## 四、今日易错点
1. Length 漏算 10 字节头（整体错位，解析全崩）。
2. 数据消息把 W 位和 Stream 算错（0x80|Stream）。
3. Linktest 用了具体 SessionID（应为 0xFFFF）。
4. 控制消息也去填 Stream/Function（应清零，看 SType）。
5. 把 SType=8 当合法消息（保留未用，收到应 Reject/忽略）。
