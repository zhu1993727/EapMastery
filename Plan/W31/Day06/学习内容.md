# W31 · Day06（周六）多腔 R2R：C2C/C2O、腔间均衡与漂移补偿综合案例

> 建议时长：100 分钟。真实设备多为多腔/多站并行，腔间存在固有差异与不同漂移。今天讲多腔 R2R 策略：每腔独立控制器、C2C（腔到腔匹配）与 C2O（腔到最优目标）、腔间均衡、量测归属到腔、共享基线与独立 overlay，并做一个多腔漂移补偿综合案例，串起本周全部知识点。

## 二、背景知识（先读，40 分钟）

### 1. 为什么多腔要单独控制
- 多腔设备各腔硬件、积膜/损耗历史、保养时间不同，即便同一 recipe 基线，输出也有固定偏置（腔间差）且漂移速率不同。用一个统一 overlay 会"按下葫芦浮起瓢"——补了 A 腔却带偏 B 腔。
- 正确做法：recipe 主档共享（同一工艺基线），但**每腔一份 R2R 状态与 overlay**（Day03 作用域到腔）。

### 2. C2C vs C2O
- **C2O Chamber-to-Optimal**：每个腔独立地把自己的输出拉向全局最优/目标值 T（各腔对同一目标，允许各自不同补偿量）。最常用，保证无论片过哪个腔，输出都一致达标。
- **C2C Chamber-to-Chamber**：以腔间匹配为目标，先消除腔间相对差（让各腔输出彼此对齐），再整体对目标；常用于跨腔一致性要求极高、或先做腔匹配再统一调目标的场景。
- 实践常结合：先用 C2C 思想保证腔间差收敛到很小，再整体 C2O 对目标；数学上每腔独立 EWMA + 共同目标即可同时实现"对齐且达标"。

### 3. 量测归属（关键工程点）
- 一片/批在哪个腔加工必须可追溯（E90/E40 作业记录了片-腔对应，W15/W16）。量测回来要按"片→腔"归属，用该腔当时的 u 更新该腔控制器；归错腔等于用 B 腔结果调 A 腔，越调越乱。
- 一片过多个腔/多步时，要按工艺贡献拆分或用多输入模型（进阶），教学先做单腔归属。

### 4. 腔间均衡与漂移补偿
- 均衡目标：各腔输出均值都=T、腔间方差最小；监控腔间差，差过大提示硬件问题（非 R2R 能解决，转保养）。
- 漂移补偿：各腔 EWMA 独立跟踪本腔漂移、独立 overlay；保养/换件后该腔状态重置（基线变化，配合 Day03 版本/重置）。

### 5. 异常与缺量测隔离
- 某腔 FDC 异常/Hold/量测缺失：只冻结该腔控制器（保持其安全 overlay），其他腔继续闭环（故障域隔离，呼应 EDA/双通道隔离思想）。
- 某腔补偿撞限/残差异常：只停该腔自动、报警，不影响其他腔生产。

### 6. 综合案例（今天实现）
- 4 腔，初始偏置不同（+3/-2/+1/0）、漂移速率不同；每腔独立 EWMA、共享目标 T=100、共享 recipe 基线；量测按腔归属逐 run 更新；跑 N 个 run 后各腔输出应收敛到 T 附近、腔间差缩小；某腔中途缺量测/异常时其余腔不受影响。
