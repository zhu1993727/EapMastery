# W31 · Day02（周二）EWMA 控制器：状态估计、控制律与防发散

> 建议时长：100 分钟。EWMA（指数加权移动平均）是 R2R 最经典、现场最常用的控制器。今天把它的数学和实现吃透：如何用 EWMA 估计漂移状态、如何由估计与目标算下一 run 设定、单/双 EWMA（dEWMA 估斜率）、增益选择、控制限/步长/死区，以及量测延迟与异常量测下如何防过补偿与振荡。

## 一、今日目标
1. 推导并实现 EWMA 状态更新：`a_t = λ·y_t + (1-λ)·a_{t-1}`，理解 λ（遗忘/权重）含义。
2. 掌握单 EWMA 控制律：由过程增益 b，`u_{t+1}=u_t + (T-a_t)/b`，理解"估计偏差→设定补偿"。
3. 了解 dEWMA（双 EWMA）：第二个 EWMA 估计线性漂移斜率，补偿持续趋势。
4. 掌握稳定性手段：步长限幅、死区（小偏差不调）、控制限、量测异常剔除、延迟对齐。
5. 用 C# 实现 EwmaController/dEwmaController，仿真验证收敛、抗噪、限幅与延迟处理；xUnit。

## 二、背景知识（先读，45 分钟）

### 1. 过程模型（R2R 简化）
- 常用一阶线性模型：`y_t = α + b·u_t + ε_t`，其中 y 输出、u 可调设定、b 过程增益（设定对输出的影响系数，可正可负）、α 漂移项（随时间慢变）、ε 噪声。
- 控制目标：选 u 使 y 逼近目标 T。关键是估计慢变的 α（漂移状态），EWMA 就是对它做指数加权估计。

### 2. EWMA 状态估计
- `a_t = λ·(y_t - b·u_t) + (1-λ)·a_{t-1}`（用"扣除设定影响后的输出"估计固有漂移 α）。
- λ∈(0,1]：越大越信最新量测（跟踪快但噪声敏感），越小越平滑（稳但跟踪慢）；现场常在 0.1–0.5 间整定。
- 直观：EWMA 是无限历史的指数加权平均，越远的 run 权重指数衰减，既利用历史又跟得上慢漂移。

### 3. 控制律（单 EWMA）
- 令预测输出 `ŷ=a_t+b·u`，要 ŷ=T，得 `u_{t+1}=(T-a_t)/b`（或增量式 `u_{t+1}=u_t+(T-y_hat)/b`）。
- 每 run：加工→量测 y_t→更新 a_t→算 u_{t+1}→经 RMS/GEM 下发。

### 4. dEWMA（双 EWMA，估斜率）
- 漂移若带线性趋势（α 匀速变化），单 EWMA 会持续滞后；dEWMA 用第二个 EWMA 跟踪斜率：
  - `a_t=λ1·e_t+(1-λ1)(a_{t-1}+D_{t-1})`
  - `D_t=λ2·(a_t-a_{t-1})+(1-λ2)D_{t-1}`
  - 预测时把趋势项 D 计入，补偿匀速漂移、减小稳态偏差。
- λ1/λ2 需整定，λ2 通常更小（斜率要更平滑）。

### 5. 稳定性与防发散（工程重点）
- **步长限幅**：单次 |Δu|≤maxStep，防止异常量测/大误差导致一步过冲、来回振荡。
- **死区 deadband**：|T-a| 小于工艺可接受带就不调，避免对噪声无谓动作、减少设定抖动。
- **控制限**：u 必须在工艺允许区间 [uLo,uHi]，超限钳制并告警（联动 Day03 RMS 校验）。
- **量测异常剔除**：量测超物理可能/与 VM 严重冲突时标记不可信、不用于更新（或降权），避免坏量测带偏控制器（呼应 FDC 质量门控思想）。
- **量测延迟对齐**：量测晚 k 批回来时，要对回到产生它的那个 run 的设定 u 上去更新（用当时 u 算残差），不能拿旧结果对新设定，否则错配过补偿；缺量测时"保持上一设定/不更新"而非乱调。
- **安全兜底**：连续多批无法拉回目标（估计发散/超控制限）→停止自动 R2R、转人工并报警（R2R 只在受控窗口内自动）。

### 6. 与 SPC 的关系（W32 细讲）
- EWMA 控制器本身也产生可监控序列（估计 a、补偿 Δu、残差），SPC 控制图监控这些是否异常（如补偿量持续单调增大说明设备在持续漂移、需保养）。
