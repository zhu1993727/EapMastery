# W31 · Day02 答案与参考实现

## 一、自测题标准答案
1. **过程模型/更新式/扣除 b·u**：一阶线性模型 `y_t = α + b·u_t + ε_t`，y 输出、u 可调设定、b 过程增益、α 慢变漂移、ε 噪声。EWMA 估计漂移：`a_t = λ·(y_t - b·u_t) + (1-λ)·a_{t-1}`。必须扣除 b·u，是因为输出 y 里既含固有漂移 α，也含"我们主动给的设定 u 经增益 b 产生的效果"；要估计的是设备固有状态 α，就得先把已知的人为设定贡献 b·u 减掉，得到"在零设定/基准下设备本会产出多少"，否则控制器会把自己的调节动作误当成设备漂移，越调越偏（自我反馈错误）。
2. **λ 影响/选取**：λ 是本批量测残差的权重，(1-λ) 是历史估计权重。λ 大→更信最新量测、跟踪漂移快，但对量测噪声敏感、设定抖动大；λ 小→更平滑、抗噪，但对真实漂移跟踪慢、稳态滞后大。选取要平衡量测噪声水平与漂移速度：量测噪声大/漂移慢取小（如 0.1–0.2），量测准/需快速跟踪取大（0.3–0.5），现场用历史数据仿真整定，并用 SPC 观察残差与补偿序列是否平稳，避免设定频繁抖动。
3. **控制律/顺序**：令预测 `ŷ=a_t+b·u`，令其等于目标 T，解出 `u_{t+1}=(T-a_t)/b`（等价增量式 `u_{t+1}=u_t+(T-ŷ_t)/b`）。每 run 顺序：①用上一 run 下发的 u_t 加工；②量测 y_t（或 VM）；③用残差 `y_t-b·u_t` 更新 EWMA 状态 a_t；④按控制律算 u_{t+1}；⑤死区/步长限幅/控制限检查；⑥经 RMS 校验、EAP→GEM 下发并确认生效，供下一 run 使用。注意"用本 run 结果算的是下一 run 设定"，时序不能错。
4. **线性漂移滞后/dEWMA**：单 EWMA 把漂移当近似常数 α 估计，当 α 匀速变化（线性趋势）时，指数平滑始终在"追赶"移动目标，估计系统性落后于真实值，导致输出长期偏离目标一个稳态偏差（lag）。dEWMA 增加第二个 EWMA 估计斜率 D（漂移速度）：`a_t=λ1 e_t+(1-λ1)(a_{t-1}+D_{t-1})`（更新时先按上轮斜率外推）、`D_t=λ2(a_t-a_{t-1})+(1-λ2)D_{t-1}`（平滑斜率），预测/控制时把趋势项 D 计入，等于"估计当前水平+外推下一步趋势"，从而补偿匀速漂移、消除稳态滞后；λ2 通常更小以保证斜率估计平滑。
5. **限幅/死区/控制限各防什么**：步长限幅（|Δu|≤maxStep）防单次异常量测或大误差造成一步过冲、设定来回大幅振荡，让调节平滑渐进；死区（|T-a|<δ 不动作）防在目标附近因量测噪声反复微调、减少设定抖动与下发次数；控制限（u∈[uLo,uHi]）是工艺安全/设备允许的硬边界，超出钳制并告警，防止 R2R 把设定推到工艺验证范围之外（与 RMS 校验联动）。三者分别管"步幅、无谓动作、绝对边界"，共同保证自动控制平滑、安全、可审计。
6. **延迟对齐/错配后果**：R2R 更新要用"产生该量测的那个 run 当时下发的设定 u"来算残差 y-b·u。量测晚 k 批回来时，必须把它对回到对应 run、取当时存档的 u 计算，再并入当前状态（按时间序更新或带时间戳更新）。若拿旧 run 的结果去减当前最新 u，设定贡献对错了对象，残差失真，控制器会错误估计漂移，产生过补偿/欠补偿甚至振荡（典型"拿旧账对新钱"）。量测缺失的 run 不更新状态、保持上一安全设定，等量测回来再补算，绝不在无有效量测时凭空调。
7. **何时停自动转人工**：①估计/补偿持续发散——连续多 run 输出拉不回目标或残差单向扩大；②补偿量撞控制限或步长连续打满（说明靠 R2R 已无法补偿，可能硬件故障/工艺异常）；③量测持续不可信/长期缺失、VM 置信度不足，控制器失去有效反馈；④FDC 报严重故障、设备 Hold、工况/Recipe/产品切换（模型/增益不匹配，需重新初始化或确认）；⑤SPC 监控到补偿序列异常（如 Δu 单调累积指示设备需保养）。触发即退出自动、保持安全设定、报警转人工并留痕，R2R 只在受控窗口内自动运行。

## 二、参考实现（net8.0）：单/双 EWMA

```csharp
namespace EapLab.R2r;
public sealed class EwmaController
{
    public double Target{get;}public double B{get;}public double Lambda{get;}
    public double MaxStep{get;}public double Deadband{get;}public double ULo,UHi;
    double? _a;public double U{get;private set;}public int Updates{get;private set;}
    public EwmaController(double t,double b,double lambda,double u0,double maxStep,double dead,double ulo,double uhi)
    {Target=t;B=b;Lambda=lambda;U=u0;MaxStep=maxStep;Deadband=dead;ULo=ulo;UHi=uhi;}

    // 用run t的量测y(其设定为usedU, 延迟时传当时u)更新状态并算下一run设定
    public double? Update(double y,double usedU,bool reliable=true)
    { if(!reliable)return null;                                  // 坏量测不更新
        double resid=y-B*usedU;                                  // 扣除设定贡献
        _a=_a is null?resid:Lambda*resid+(1-Lambda)*_a.Value;
        double rawNext=(Target-_a.Value)/B;
        double du=Math.Clamp(rawNext-U,-MaxStep,MaxStep);        // 步长限幅
        if(Math.Abs(Target-_a.Value)<Deadband)return U;          // 死区不调
        U=Math.Clamp(U+du,ULo,UHi);Updates++;return U; }         // 控制限
    public double? State=>_a;
}

public sealed class DEwmaController // 双EWMA: 额外估斜率D
{
    readonly double _l1,_l2;public double B,Target,U,MaxStep,ULo,UHi;double? _a,_d,_prevA;
    public DEwmaController(double t,double b,double l1,double l2,double u0,double maxStep,double lo,double hi)
    {Target=t;B=b;_l1=l1;_l2=l2;U=u0;MaxStep=maxStep;ULo=lo;UHi=hi;}
    public double Update(double y,double usedU)
    { double e=y-B*usedU;
        if(_a is null){_a=e;_d=0;}
        else{ double aNew=_l1*e+(1-_l1)*(_a.Value+_d!.Value);     // 先按斜率外推
              double dNew=_l2*(aNew-_a.Value)+(1-_l2)*_d.Value;_a=aNew;_d=dNew; }
        double pred=_a.Value+_d!.Value;                           // 水平+趋势
        double raw=(Target-pred)/B;
        U=Math.Clamp(U+Math.Clamp(raw-U,-MaxStep,MaxStep),ULo,UHi);return U; }
}
```

public class EwmaTests

## 三、EWMA 闭环（手绘参考）
```
run t: 用u_t加工 → 量测y_t(或VM, 带质量) ──残差e=y_t-b·u_t(延迟则对回当时u)
   → EWMA: a_t=λe+(1-λ)a_{t-1}  (dEWMA再估斜率D, 外推趋势)
   → 控制律 u_{t+1}=(T-a_t)/b
   → 死区(小偏差不调)→步长限幅(|Δu|≤max)→控制限[uLo,uHi]
   → RMS校验(主档不变,叠加overlay)→EAP→GEM下发→S6F11生效 → run t+1
λ: 大跟踪快抗噪差, 小平滑跟踪慢; dEWMA补匀速漂移滞后
安全: 坏量测不更新/缺测保持/延迟对齐; 发散/撞限/切工况→停自动转人工
监控: a、Δu、残差送SPC控制图(W32), Δu持续累积=设备需保养信号
```

## 四、今日易错点
1. 残差不扣 b·u，把自己的调节当成设备漂移。
2. λ 一刀切（噪声大却取大值导致设定抖动）。
3. 用本 run 结果调本 run（应算下一 run）。
4. 线性漂移只用单 EWMA，长期稳态滞后却不知用 dEWMA。
5. 无步长限幅，异常量测一步过冲、来回振荡。
6. 目标附近无死区，被噪声带着反复微调。
7. 延迟量测拿旧结果对新设定，残差错配过补偿。
8. 坏量测照样更新、缺测乱调；撞控制限/发散不退出自动。
9. overlay 超工艺验证范围却不经 RMS 校验钳制。
