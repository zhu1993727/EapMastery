## 二、背景知识（先读，40 分钟）

### 1. 为什么需要 R2R
- 工艺会缓慢漂移：设备老化、腔体积膜/刻蚀损耗、耗材（电极/气体纯度）衰减、腔间差异、环境变化，导致同样设定下输出（膜厚/CD/overlay 套刻精度）逐渐偏离目标。
- 逐片/逐批实测后人工调太慢且不一致；R2R 自动地"看上一批结果、微调下一批设定"，把输出拉回目标、减小批间方差，是先进 FAB 良率与一致性的核心手段（光刻 overlay、CMP 厚度、刻蚀深度/CD 最典型）。

### 2. run 是什么
- run（批次/运行单元）：一次控制更新所覆盖的加工单元，可以是一批 Lot、一片 wafer、一个腔的一次工艺；R2R 通常在 run 结束拿到量测后、下个 run 开始前更新设定（区别于 FDC 在 run 进行中实时动作）。

### 3. 反馈 vs 前馈
- **反馈 Feedback**：本 run 加工→量测输出 y→与目标 T 比得误差 e→控制器算补偿→调整下一 run 设定 u。事后纠偏，抑制可观测漂移，是 R2R 主体。
- **前馈 Feedforward**：在加工前测得"扰动/来料差异"（如上游膜厚偏差、上道 CD、设备已知状态），不等本 run 结果，提前据此调整本 run 设定。主动补偿已知 incoming variation。
- 先进控制常反馈+前馈结合（如光刻用前片 overlay 反馈 + 本次曝光场/来料前馈）。

### 4. R2R 闭环环节（核心图）
1. 设备加工 run（用当前设定=recipe 基线 + overlay 补偿）。
2. 量测（inline/metrology 或 VM 预测）得到输出 y。
3. 状态估计：结合历史估计当前漂移状态（EWMA 等，Day02）。
4. 控制器：按目标 T 与估计状态算下一 run 设定补偿 Δu（受控制限/步长约束）。
5. 参数经 RMS 校验（不改主配方，生成 overlay）、EAP、GEM 下发设备（W30 下行铁律）。
6. 设备执行并回告生效（受理≠生效，S6F11 确认），进入下一 run，形成闭环。

### 5. 与其他系统边界（务必分清）
- **FDC vs R2R**：FDC 在 run 中实时检测/分类异常（秒级、保安全、可建议 Hold）；R2R 在 run 间调设定（批级、降漂移、提一致性），不处理突发故障。
- **RMS vs R2R**：RMS 管理 recipe 主档（版本/审批/校验/下发）；R2R 只产生受控的小幅 overlay 补偿，叠加在主配方上，不直接改主档（Day03 细讲）。
- **VM vs R2R**：VM 用过程数据"预测量测值"，为 R2R 提供更快/更密的量测输入（等量测机太慢/抽检太稀）；R2R 是用这些量测做控制决策。
- **SPC vs R2R**：SPC 统计监控（控制图）判断过程是否受控、发异常信号，本身不直接改设定；R2R 是自动控制器、直接产生设定调整。二者互补（W32）。
- **MES/EAP**：MES 提供 Lot/工艺路线/目标规格，EAP 承担设备侧受控下发与回告。

### 6. 设备端 EAP 在 R2R 闭环里的职责（你的岗位）
- 提供 R2R 所需过程/结果数据（经 EDA/GEM）；接收经 RMS/EAP 下发的 overlay 参数、在正确时机（run 开始前/片间）写入并校验范围、确认生效并回告；保证主配方不被越权修改、每次调整可追溯（Lot/腔/前后值/来源）。
