# EapMastery

A continuous learning series on **SEMI Standards** and **CIM (Computer Integrated Manufacturing)** — built step by step, with real code and real practice.

## About This Series

This repository is my ongoing journey of mastering the SEMI standards family and CIM concepts: from EAP (Equipment Automation Program) and SECS/GEM to HSMS, and further into the broader fab automation ecosystem. Every commit is a lesson learned; every folder is a milestone.

The series grows continuously as I explore, implement, and document:

- **SEMI Standards** — E5 (SECS-II), E30 (GEM), E37 (HSMS), E87 (Carrier Management), and beyond
- **CIM Ecosystem** — MES, FDC, RMS, and how they connect with the equipment side
- **Hands-on Code** — practical examples and experiments that bring the theory to life

## Contribution Rules — Read Only, Suggestions Welcome

To keep this series consistent and coherent as a personal learning path:

- **Read-only code**: The code and architecture here are for learning and reference. Please **do not** modify, rewrite, or submit direct changes to the code.
- **Suggestions are always welcome**: If you have ideas, improvements, or notice something that could be done better, feel free to open an **Issue** or start a **Discussion**. I will review every suggestion — once adopted, I'll apply the changes myself.

Learning is always better together. Whether you are just starting out with SEMI/CIM or you are a seasoned veteran, your insights and feedback are truly appreciated.
