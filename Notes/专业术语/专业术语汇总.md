# 半导体 EAP 专业术语卡片

> 统一模板：术语 / 全称 / 一句话 / 归属

---

## A. 协议侧（25 张）

### A-01 Equipment
术语：Equipment
全称：Equipment（设备）
一句话：半导体制造中执行工艺或检测的机台本体（如刻蚀机、薄膜机），是 SEMI 通讯协议中的被控方，负责执行 Host 下发的命令并回报状态
归属：E30 GEM

### A-02 Host
术语：Host
全称：Host（上位机/主机）
一句话：与设备通讯的上层系统（如 MES、EAP），负责调度与监控设备，在协议交互中通常作为事务发起方
归属：E30 GEM

### A-03 Primary
术语：Primary
全称：Primary Message（主消息）
一句话：事务中由发起方主动发送的第一条消息，SECS-II 中带 W-bit 的主消息要求对方回复 Reply
归属：E5 SECS-II

### A-04 Reply
术语：Reply
全称：Reply Message（回复消息）
一句话：收到带 W-bit 的主消息后，接收方返回的响应消息，用于确认或回传数据，与对应 Primary 构成一个事务
归属：E5 SECS-II

### A-05 W-bit
术语：W-bit
全称：Wait Bit（等待位）
一句话：SECS-II 消息头第 8 字节的最高位，置 1 表示对方必须回复 Reply，用于保证事务有响应、不悬挂
归属：E5 SECS-II

### A-06 System Bytes
术语：System Bytes
全称：System Bytes（系统字节）
一句话：消息头第 5~8 字节，唯一标识一个事务，同一事务的 Primary 与 Reply 携带相同 System Bytes 以相互关联
归属：E4 SECS-I / E37 HSMS

### A-07 Transaction
术语：Transaction
全称：Transaction（事务）
一句话：一条 Primary 与其对应的 Reply 构成的完整收发配对，通过 System Bytes 关联，是 SECS 消息交互的基本单元
归属：E5 SECS-II

### A-08 Stream/Function (S/F)
术语：Stream/Function (S/F)
全称：Stream/Function（流/功能码）
一句话：SECS-II 消息的分类编码，Stream 表示消息类别（如 S1 状态、S6 事件），Function 表示具体功能，二者共同唯一定位一条消息
归属：E5 SECS-II

### A-09 SVID
术语：SVID
全称：Status Variable ID（状态变量标识）
一句话：设备上可查询的实时状态量编号（如温度、压力、腔体状态），通过 S1F3 按 SVID 列表读取
归属：E30 GEM

### A-10 ECID
术语：ECID
全称：Equipment Constant ID（设备常量标识）
一句话：设备上可配置参数的编号（如超时、报警使能），通过 S2F13/S2F15 实现读写
归属：E30 GEM

### A-11 CEID
术语：CEID
全称：Collection Event ID（采集事件标识）
一句话：设备上某个"值得上报的时刻"的编号，触发时按链接的报告组帧 S6F11
归属：E30 GEM

### A-12 VID
术语：VID
全称：Variable ID（变量标识）
一句话：SVID、ECID 与数据变量（DVVAL）的统称，是报告、事件中引用数据点的通用编号体系
归属：E30 GEM

### A-13 RPT (Report)
术语：RPT (Report)
全称：Report（报告）
一句话：一组按 VID 预先定义的变量集合，被 CEID 链接后，事件触发时随 S6F11 一并上报
归属：E30 GEM

### A-14 ALID/ALCD/ALTX
术语：ALID/ALCD/ALTX
全称：Alarm ID / Alarm Code / Alarm Text（报警标识/报警码/报警文本）
一句话：设备报警三要素——ALID 唯一标识报警，ALCD 表示报警级别与置位/清除方向，ALTX 为报警描述文本，经 S5F1/S5F101 上报
归属：E30 GEM

### A-15 RCMD
术语：RCMD
全称：Remote Command ID（远程命令标识）
一句话：Host 通过 S2F41 下发给设备执行的远程命令编号（如启动、停止、切配方），设备在 S2F42 回报执行结果
归属：E30 GEM

### A-16 PP/Recipe
术语：PP/Recipe
全称：Process Program / Recipe（工艺程序/配方）
一句话：描述一次工艺的参数集（温度、时间、气体流量等），经 S7F1~S7F5 上传下载，由 RCMD 或 PJ 引用执行
归属：E30 GEM

### A-17 Carrier/FOUP/Load Port
术语：Carrier/FOUP/Load Port
全称：Carrier / Front Opening Unified Pod / Load Port（载具/前开式晶圆盒/装载口）
一句话：FOUP 是装载晶圆的标准载具，Carrier 是其泛称，Load Port 是机台上的装载接口，三者构成晶圆进出设备的第一环
归属：E87 GEM300

### A-18 Substrate/Slot
术语：Substrate/Slot
全称：Substrate / Slot（基板/槽位）
一句话：Substrate 指晶圆等被加工物，Slot 是载具内放置基板的槽位编号，Slot Map 记录各槽位的占用状态
归属：E87/E90 GEM300

### A-19 Process Job (PJ)
术语：Process Job (PJ)
全称：Process Job（工艺任务）
一句话：设备内一次实际加工的最小任务单元，绑定配方与载具/槽位，经 S2F41 下发，由 E90 的 S10F3 上报执行状态
归属：E90 GEM300

### A-20 Control Job (CJ)
术语：Control Job (CJ)
全称：Control Job（控制任务）
一句话：Host 下发的任务编排层，一个 CJ 可串起多个 PJ（如先后加工多批），PJ 全部完成后回报 CJ 结果
归属：E94 GEM300

### A-21 OSS Object
术语：OSS Object
全称：Object Service Object（对象服务对象）
一句话：SECS-II 面向对象扩展的通讯对象，将常用消息封装为可复用的方法调用，简化 S/F 消息的交互组织
归属：E5 SECS-II / E30 GEM

### A-22 Spooling
术语：Spooling
全称：Spooling（数据暂存）
一句话：通讯中断时把待发送数据（如事件、数据）暂存到本地介质，恢复后按序补发，防止数据丢失
归属：E30 GEM

### A-23 Local/Remote
术语：Local/Remote
全称：Local / Remote Mode（本地/远程模式）
一句话：设备的控制模式——Local 由机台面板操作，Remote 接受 Host 远程控制，通过 S1F1/S2F17 等查询与切换
归属：E30 GEM

### A-24 HSMS
术语：HSMS
全称：High-Speed SECS Message Services（高速 SECS 消息服务）
一句话：基于 TCP/IP 的 SECS 通讯协议，取代 RS-232 的 SECS-I，通过消息头长度与控制消息实现高速可靠传输
归属：E37 HSMS

### A-25 SECS-II/GEM
术语：SECS-II/GEM
全称：SECS-II (E5) / GEM (Generic Equipment Model, E30)
一句话：SECS-II 定义消息格式与数据项语法，GEM 在 SECS 之上定义设备行为标准（状态机、事件、报告、报警等），二者是 EAP 通讯的两大基石
归属：E5 SECS-II / E30 GEM

## B. CIM 系统侧（16 张）

### B-01 CIM
术语：CIM
全称：Computer Integrated Manufacturing（计算机集成制造）
一句话：将制造、设备、物流、质量通过信息系统统一集成与自动化的整体架构，是晶圆厂顶层信息化蓝图
归属：通用概念

### B-02 MES
术语：MES
全称：Manufacturing Execution System（制造执行系统）
一句话：负责工单下发、工艺路线、在制品跟踪与数据采集的工厂执行层系统，是 EAP 的主要上游
归属：通用概念

### B-03 DFS/RTD
术语：DFS/RTD
全称：Dynamic Flow Scheduling / Real-Time Dispatch（动态流程调度/实时派工）
一句话：根据实时在制品与机台状态，为每一批晶圆动态决策"去哪台机、跑哪个配方"的派工系统
归属：MES 子模块

### B-04 APC
术语：APC
全称：Advanced Process Control（先进过程控制）
一句话：基于模型与实时数据对工艺进行前馈/反馈调节的控制体系，统领 FDC、R2R、VM 等具体手段
归属：通用概念（参考 E133）

### B-05 FDC
术语：FDC
全称：Fault Detection and Classification（故障检测与分类）
一句话：实时采集设备与工艺数据，用规则或模型识别异常并归类根因，第一时间拦截异常批次
归属：E128 FDC

### B-06 R2R
术语：R2R
全称：Run-to-Run Control（批间控制）
一句话：根据上一批的工艺结果（如膜厚）自动修正下一批的工艺参数，实现批与批之间的闭环补偿
归属：APC 子模块

### B-07 VM
术语：VM
全称：Virtual Metrology（虚拟量测）
一句话：用模型根据设备状态与工艺数据实时预测量测结果，替代或补充实测量测，实现全数"虚拟"检验
归属：APC 子模块

### B-08 SPC
术语：SPC
全称：Statistical Process Control（统计过程控制）
一句话：用控制图等统计工具监控工艺与质量指标的波动，识别异常趋势，是质量管控的基础手段
归属：通用概念

### B-09 RMS
术语：RMS
全称：Recipe Management System（配方管理系统）
一句话：集中管理配方版本、下载分发与配方校验，确保机台运行的是经核准的正确配方
归属：E139 RMS

### B-10 YMS
术语：YMS
全称：Yield Management System（良率管理系统）
一句话：收集量测与缺陷数据，分析良率损失根因并定位到机台/工艺/物料，支撑良率提升决策
归属：通用概念

### B-11 EDA/Interface-A
术语：EDA/Interface-A
全称：Equipment Data Acquisition / Interface-A（设备数据采集）
一句话：SEMI E120 等定义的标准设备数据模型与采集接口，向分析系统提供高带宽、标准化的设备数据
归属：E120/E125/E132/E134

### B-12 iEMS/CMMS
术语：iEMS/CMMS
全称：Integrated Equipment Management System / Computerized Maintenance Management System（设备综合管理/计算机化维护管理）
一句话：管理设备台账、保养计划、备件与维修工单的系统，负责设备可用性与维护闭环
归属：通用概念

### B-13 RCM
术语：RCM
全称：Remote Call Management（远程呼叫管理）
一句话：设备按 E114 标准向维护系统发起远程呼叫（报修/求助）并回报处理结果，联动 CMMS 形成维护闭环
归属：E114 RCM

### B-14 MCS/AMHS
术语：MCS/AMHS
全称：Material Control System / Automated Material Handling System（物料控制系统/自动化物料搬运系统）
一句话：AMHS 用 OHT/天车等自动搬运晶圆载具，MCS 负责调度与跟踪搬运任务，实现厂内物流自动化
归属：通用概念

### B-15 ADC
术语：ADC
全称：Automatic Defect Classification（自动缺陷分类）
一句话：基于缺陷检测图像自动识别缺陷类型与严重度，替代人工复检，提升良率分析效率
归属：通用概念

### B-16 ECN
术语：ECN
全称：Engineering Change Notice（工程变更通知）
一句话：工程/工艺变更的正式通知与审批记录，驱动配方、流程或设备的受控修改
归属：通用概念
